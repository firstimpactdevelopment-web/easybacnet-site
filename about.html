About Easy BACnet

Updated 10 November 2026

In short

Easy BACnet is an independent site for people who work on building controls. It has a free BACnet points list library, browser tools for BACnet numbers and instances, plain-English guides, and the Easy BACnet app for Android. It is not run by a manufacturer, a BMS vendor or a standards body.

What is on the site

  • BACnet points list library: 1,185 equipment models, each with its object types, instance numbers, names, units and access, plus CSV, EDE and JSON downloads.
  • Instance calculators for 25 brands and gateways, where the instance number is worked out from a unit address.
  • Reference tools: the BACnet number lookup, the Object Identifier decoder, the Vendor ID lookup and a scan-to-points-list compare. They run in your browser and nothing you type is uploaded.
  • Guides on the problems that come up in the field: devices that don't show up, writes that are denied, overrides that won't release, MS/TP wiring, network numbers and more.

Where the points lists come from

Each list is typed up from the manufacturer's own public documentation, such as an integration manual, a PICS or a protocol guide, and every model page links to the document it came from. Where a list came from somewhere other than the manufacturer, such as a gateway vendor's profile, the page says so with a badge.

Before a list is published, its object types, instances and access are checked against that source. The BACnet number lookup is cross-checked against three independent BACnet stacks. Mistakes still get through, so treat every list as a starting point and confirm it against the live device. The terms of use cover this in full.

The app

Easy BACnet is an Android app that scans a network for BACnet IP devices, reads their points, writes and releases values by priority, and exports a report to Excel. Before each release it is tested against 19 independent BACnet stacks. Scanning, reading, writing and exporting are free. An optional Pro subscription removes the ads in the free version and unlocks unlimited custom remotes. The app, its optional subscription and ads on this site pay for the site.

Independence

Easy BACnet is not affiliated with, endorsed by or paid by any manufacturer named on this site, or by ASHRAE or BACnet International. Manufacturer and product names are used only to say which equipment a list is for. BACnet is a registered trademark of ASHRAE.

Corrections and contact

If a list is wrong, a document has moved, or there is a model you want added, email webmaster@easybacnet.com. Point to the page and, if you can, the manufacturer document that shows the right value. Corrections are made in the library and the page's updated date changes.
