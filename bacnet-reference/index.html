BACnet number lookup

Updated 7 November 2026

BACnet sends almost everything as a number: the units of a reading, the property you asked for, the reason a write failed. Type the number (or part of a name) and see what it means in every table at once.

BACnet number lookup

    The same number means different things in different tables (62 is degrees-celsius as a unit and Max_APDU_Length_Accepted as a property), so every match is labelled with its table.

    Short answer

    Common ones: units 62 = degrees-celsius, 64 = degrees-fahrenheit, 98 = percent; property 85 = Present_Value, 87 = Priority_Array; error code 31 = unknown-object, 32 = unknown-property, 40 = write-access-denied; reliability 12 = communication-failure.

    Full tables

    • BACnet engineering units listA BACnet analog object reports its units as a number.429 engineering units
    • BACnet property identifiersEvery BACnet property has a number.485 property
    • BACnet object typesThe object type is the top 10 bits of every BACnet Object Identifier.65 object type
    • BACnet error, reject and abort codesWhen a read or write fails, the device answers with an Error (class + code), a Reject or an Abort.8 error class, 229 error code, 11 reject reason, 12 abort reason
    • BACnet reliability, event state and device statusReliability says why a value may be wrong; Event_State says whether an object is in alarm; System_Status says what the device itself is doing.25 reliability, 6 event state, 21 event type, 6 device status
    • BACnet service choice numbersEvery BACnet request carries a service choice number.35 confirmed service, 15 unconfirmed service

    Values come from the open-source bacnet-stack 1.6.1 (bacenum.h), which follows ANSI/ASHRAE Standard 135, and were cross-checked one by one against two other independent BACnet stacks (bacpypes and @bacnet-js/client). Entries marked (newer) are in bacnet-stack only, because the other two stacks predate them. Numbers 0-255 (and the higher ASHRAE ranges) are standard; vendors may use proprietary numbers above them.
