BACnet engineering units list

Updated 7 November 2026

Short answer

A BACnet analog object reports its units as a number. Scans, EDE files and some front ends show that number instead of the unit. Find any of them here. Examples: 0 = square-meters, 1 = square-feet, 2 = milliamperes.

Looking for a number but not sure which list it belongs to? Use the BACnet number lookup, which searches every table at once.
