A point is missing from the list — can I add an object by number?

Updated 11 October 2026

Short answer

Yes. If a point isn't in the list, you can add it by object type and instance number. Easy BACnet builds the list by reading the device's Object_List one entry at a time and then each object's name, about two requests per object. On a very large device it stops after the first 2,000 objects so you're not waiting ten minutes. Anything past that is still reachable: tell the app you want, say, Analog Value 3001, and it reads that object directly.

Why the list can stop short

Plant controllers, big supervisory devices and integration gateways can expose several thousand objects. The app reads one property per request (it doesn't use ReadPropertyMultiple or segmentation, so it works on small controllers that support neither), which keeps it compatible but makes huge lists slow. When a device has more than 2,000 objects, the list says Showing the first 2000 of N objects. The points that loaded work normally.

Add the object you want

  1. Get the type and instance. For example AV 3001, BO 12, MSV 40. The contractor's points list, the head-end's point properties or an earlier export will have them.
  2. Open the device (from View Results or Browser Mode), tap the menu (three dots) and choose Add object by number.
  3. Pick the object type: Analog Input, Analog Output, Analog Value, Binary Input/Output/Value, or Multi-state Input/Output/Value. Type the Instance number and tap Add.
  4. The app reads that one object and adds it to the list with its value, units and status. From there you can open it, command it, or put it on a custom remote. If the device has no such object, you'll see The device has no….

You rarely need all of them. On a big plant controller you usually care about a dozen points. Adding those by number is quicker than loading thousands.

Don't know the number?

  • Ask for the points list. Whoever programmed the controller can give you the type and instance.
  • Check the head-end. Niagara, Metasys and most other front ends show each point's BACnet object type and instance in its properties.
  • Check an earlier export. If you exported this device before, the spreadsheet has the types and instance numbers.
  • Decode an Object Identifier. If you only have the raw 32-bit number, the Object Identifier decoder splits it into type and instance.

If the whole device is missing rather than one point, that's a discovery problem. See why can't I find my BACnet IP devices or add a device by IP.
