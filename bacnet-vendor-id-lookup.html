Free browser tool · nothing is uploaded · updated 5 November 2026

Where you will see a Vendor ID

  • In discovery. Every I-Am reply carries the Vendor ID, so a scan can tell you who made each device before reading anything else.
  • In the Device object. Vendor_Identifier (property 120) holds the number and Vendor_Name (property 121) holds the text the manufacturer chose. Easy BACnet's Browser Mode shows the Vendor_Name each device reports, and its raw read tool can read property 120 directly.
  • In EDE files and points lists. Engineering Data Exchange (EDE) exports include the vendor name and number so a head-end knows whose device the list describes.

Why the Vendor ID matters

BACnet lets each manufacturer add its own proprietary object types (numbers 128 to 1023), properties (512 and up) and enumeration values. Those numbers mean nothing on their own: proprietary property 5000 on a Trane controller and property 5000 on a Siemens controller are unrelated. The Vendor ID is the key that tells a tool whose definitions to use, which is why a head-end driver for one brand cannot make sense of another brand's proprietary objects. If a scan shows an object type such as “Type 130”, the Vendor ID tells you whose documentation to look in. See BACnet object types explained.

Field notes

  • A gateway reports its own Vendor ID. A rooftop unit behind a protocol gateway shows the gateway maker's number, not the rooftop unit maker's. The same goes for a router or a supervisory controller re-serving points from other devices.
  • Some companies hold several IDs. Siemens Schweiz, for example, holds 7, 9 and 22, often from separate product lines or companies they bought.
  • The name can be out of date. The register keeps the name used when the ID was assigned. TAC (11) is now part of Schneider Electric, and many smaller names on the list have been bought since.
  • Open-source and test stacks have IDs too. Software built on an open-source stack often keeps that stack's Vendor ID, so a device reporting a software vendor is not necessarily a fake.
  • A Vendor ID is not a Device ID. The Vendor ID is the same for every device a company makes; the Device ID (instance) must be unique on your network.

How a manufacturer gets a Vendor ID

Vendor IDs are assigned by ASHRAE and published by BACnet International. A company building a BACnet product requests one through bacnet.org; each number is given out once and the list only grows.
