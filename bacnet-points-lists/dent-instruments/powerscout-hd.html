BMS integration notes: DENT Instruments PowerScout HD (PS12HD / PS24HD / PS48HD) multi-circuit power meter

Integration in brief

Set the serial address/baud or IP settings, then configure each element's service type and CT ratings. Read each element's power sum, energy, demand, current and voltage at the element A instance plus 10000 x (element index - 1).

Network setup

  • Serial address (PIV 1069, 1-245) and baud (PIV 1131, 9600-115k) set the RS-485 port; IP address, netmask, gateway and DHCP/static are CSV 1079-1095 and BV 1077.
  • BACnet IP UDP port is PIV 2250; BBMD IP address is CSV 2264.
  • Demand window type and length are MV 2201 / PIV 2202 (15 min default).

Watch out for

  • Reset and clear BVs (2100-2105, 12102, 12103) act on writes of 1 or 1234; Clear Accumulated Measurements All zeroes every energy total.
  • Element blocks repeat every 10000; map by instance, since names are the same in each element.
  • Set each element's Service Type and CT full-scale ratings before trusting readings.

Integration notes

  • Element objects: element A instances are listed; element B adds 10000, C 20000 ... P 150000 (the 'BACnet object floor' in the workbook). System objects keep the same instance on every sheet.
  • The workbook has one sheet per element A-P; the PS12HD has fewer elements than the PS48HD, so higher element blocks only exist on larger models.
  • Some objects exist only on certain models (noted in the description, e.g. pulse inputs 3-4 on PS12HD only, Vin2 objects on PS24HD/PS48HD).
  • Phase Check and voltage alarm masks/status are BitString Value objects (listed as type Other).
  • Communications Mode (MV 2214) and Time Since CAM (AI 2368) have no R/W entry in the workbook and are listed as read-only.
  • Source: DENT PowerScout HD master register list (xlsx), BACnet Object / Object Type / Object Name columns.

Questions about the DENT Instruments PowerScout HD (PS12HD / PS24HD / PS48HD) multi-circuit power meter

How many BACnet points does the DENT Instruments PowerScout HD (PS12HD / PS24HD / PS48HD) multi-circuit power meter have?

This list has 187 BACnet objects: 103 analog inputs, 20 analog values, 19 binary values, 8 multi-state values, 8 characterstring values, 23 positive integer values, 6 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which DENT Instruments PowerScout HD (PS12HD / PS24HD / PS48HD) multi-circuit power meter BACnet points are writable?

77 of the 187 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
