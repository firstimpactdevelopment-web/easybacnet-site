Short answer

The PowerScout 3037 serves its data as Analog Value objects. Measurements cover system and per-phase power, energy (absolute, net, positive and negative), voltage, current, reactive and apparent power and energy, power factor, demand and frequency. Configuration AVs set CT values and types, multipliers, service type, demand window, serial settings, the pulse output and BBMD registration.

BMS integration notes: DENT Instruments PowerScout 3037 power meter

Integration in brief

Set the address switches (BACnet MS/TP MAC 1-127), put the meter in BACnet mode (ViewPoint, or write 1833 to Modbus register 44612), set the service type and CT values, then read system kW, kWh, demand, power factor, current, voltage and frequency.

Network setup

  • BACnet MS/TP defaults: 76800 baud, 8N1; BACnet rates 9600, 19200, 38400, 76800. MS/TP masters use addresses 1-127; 128-254 are for slaves.
  • Switch to BACnet in ViewPoint (Comms Setup), or write 1833 to Modbus register 44612; address switches at 00 return the meter to Modbus at 9600.
  • Device ID, Max Master and Max Info Frames are writable in the device object or from ViewPoint.
  • PS3037-E: register as a foreign device by writing the BBMD IP to AV 14014 (low word) and AV 14015 (high word), network order; TTL 60000 s. Write 0 to both to stop.

Watch out for

  • Clear Accumulated Measurements (AV 10140) only acts on the value 1234 and clears every energy total.
  • Once a non-factory device ID is written, an ID inside the factory range cannot be written back.
  • Set Service Type (AV 12080) to match the wiring: 0 Wye, 1 Delta.

Integration notes

  • The manual's object tables give the identifier, name and description only. Types are Analog Value: the manual's glossary says PowerScout measurements are Analog Values and DENT's PowerScout series PICS lists only the Device and Analog Value object types.
  • Access is not in the table. The PICS lists Present_Value as writable for Analog Values; configuration objects (10140 and 12xxx-14xxx) are marked W here and measurements R.
  • Object 6010 is printed twice: 'kVARh System' in the absolute table and again, signed net, in the positive table. It is listed once.
  • BACnet IP is on the Ethernet model (PS3037-E) only.
  • Source: PS3037 manual, 'All Things BACnet' chapter; object type from the PowerScout series PICS (August 28, 2014).

Questions about the DENT Instruments PowerScout 3037 power meter

How many BACnet points does the DENT Instruments PowerScout 3037 power meter have?

This list has 119 BACnet objects: 119 analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which DENT Instruments PowerScout 3037 power meter BACnet points are writable?

31 of the 119 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official DENT Instruments PowerScout 3037 power meter BACnet documentation?

The source is PowerScout 3037 Operator's Guide (All Things BACnet), published free by DENT Instruments at https://www.dentinstruments.com/wp-content/uploads/2022/04/PS3037_Manual.pdf.

What are the minimum BACnet points to integrate the DENT Instruments PowerScout 3037 power meter?

Start with AV 1030 kW System (Total real power, kW); AV 2000 kWh System Total (Total real energy, kWh); AV 1010 kW Demand System Now (kW demand, latest window); AV 1000 kW Demand System Maximum (Peak kW demand since reset); AV 9030 Apparent PF System (System power factor); AV 4010 Amps System Average (Average current, A); AV 3010 Volts Line to Neutral Average (Average line-to-neutral voltage, V); AV 10000 Measured Line Frequency (Line frequency, Hz).
