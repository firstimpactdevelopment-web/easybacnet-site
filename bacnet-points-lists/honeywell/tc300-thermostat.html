BMS integration notes: Honeywell TC300 Commercial Thermostats (TC300B-G / TC300C-G / TC320B-G / TC320C-G)

Integration in brief

Write the system mode to MV 3 ni_ApplicationMode and occupancy to MV 6 ni_OccupancySensorState (or schedule state MV 1), and adjust the occupied setpoints AV 7 / AV 4. Read space temperature AV 2001, effective setpoints AV 2003 / AV 2004, effective occupancy MV 2014 and the alarm objects. The BMS can feed space temperature, humidity, CO2 and outdoor air through the ni_ inputs.

Enable & remote start

The thermostat runs on its own; the BMS steers it through the ni_ network inputs (application mode, occupancy, schedule state, shutdown BV 4). ni_ApplicationMode is not kept over a power cycle.

Heartbeat & communication loss

Network fail detect: when a bound network input is not updated within its fail-detect delay (0-3600 s), it falls back to Invalid, the last good value or a fixed value. Per-input enable, fallback and delay objects exist for occupancy (BV 159, AV 262, MV 2021, AV 263), shutdown (BV 164, AV 273, BV 165, AV 274) and network sensors (BV 2087, AV 2507, AV 2508).

Sensors & values from the BMS

Network inputs: ni_SpaceTemp AV 104, ni_SpaceRH AV 80, ni_SpaceCO2 AV 2511, ni_OutdoorTemp AV 89, ni_OutdoorHum AV 194, ni_DATemp AV 2024 and ni_PipeTempMode MV 2012. Network sensor configuration decides whether these are used.

Network setup

  • MS/TP: the thermostat auto-detects the baud rate in the first four minutes after start-up, otherwise 76,800. Auto MAC addressing is on by default; MAC and Device ID can be set on the screen.
  • BACnet IP (TC320 models only) runs over Wi-Fi; Device ID, network number and UDP port are set on the BACnet IP settings page.

Watch out for

  • Schedule and calendar objects have limits: the calendar object is not supported by the schedule object.
  • Service mode (BV 6 ni_ServiceModeEn) lets the network drive outputs directly; set it back to NoOverride after commissioning.
  • The guide says COV works for up to 20 points, but its known-issues table says COV is not supported; plan to poll.

Questions about the Honeywell TC300 Commercial Thermostats (TC300B-G / TC300C-G / TC320B-G / TC320C-G)

How many BACnet points does the Honeywell TC300 Commercial Thermostats (TC300B-G / TC300C-G / TC320B-G / TC320C-G) have?

This list has 531 BACnet objects: 4 analog inputs, 9 analog outputs, 253 analog values, 9 binary inputs, 26 binary outputs, 116 binary values, 1 calendar, 1 schedule, 111 multi-state values, 1 characterstring value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Honeywell TC300 Commercial Thermostats (TC300B-G / TC300C-G / TC320B-G / TC320C-G) BACnet points are writable?

378 of the 531 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

What are the minimum BACnet points to integrate the Honeywell TC300 Commercial Thermostats (TC300B-G / TC300C-G / TC320B-G / TC320C-G)?

Start with MV 3 ni_ApplicationMode (System mode: auto, cool, heat, fan only, off); MV 6 ni_OccupancySensorState (Network occupancy: occupied, unoccupied, bypass, standby); AV 7 Cfg_Setpoints_OccHeatSp (Occupied heating setpoint); AV 4 Cfg_Setpoints_OccCoolSp (Occupied cooling setpoint); MV 583 Cfg_FanCoilManualSpeedSel (Fan speed: auto, low, medium, high); MV 2014 no_EffOccState (Effective occupancy state); AV 2001 no_SpaceTemp (Space temperature in use); AV 2003 no_EffHeatSp (Effective heating setpoint); AV 2004 no_EffCoolSp (Effective cooling setpoint); BV 2035 no_GenericAlarm (Any alarm active).

How do I enable BMS control of the Honeywell TC300 Commercial Thermostats (TC300B-G / TC300C-G / TC320B-G / TC320C-G)?

The thermostat runs on its own; the BMS steers it through the ni_ network inputs (application mode, occupancy, schedule state, shutdown BV 4). ni_ApplicationMode is not kept over a power cycle.

Does the Honeywell TC300 Commercial Thermostats (TC300B-G / TC300C-G / TC320B-G / TC320C-G) need a BACnet heartbeat or have a communication timeout?

Network fail detect: when a bound network input is not updated within its fail-detect delay (0-3600 s), it falls back to Invalid, the last good value or a fixed value. Per-input enable, fallback and delay objects exist for occupancy (BV 159, AV 262, MV 2021, AV 263), shutdown (BV 164, AV 273, BV 165, AV 274) and network sensors (BV 2087, AV 2507, AV 2508).

Can the BMS supply sensor values to the Honeywell TC300 Commercial Thermostats (TC300B-G / TC300C-G / TC320B-G / TC320C-G)?

Network inputs: ni_SpaceTemp AV 104, ni_SpaceRH AV 80, ni_SpaceCO2 AV 2511, ni_OutdoorTemp AV 89, ni_OutdoorHum AV 194, ni_DATemp AV 2024 and ni_PipeTempMode MV 2012. Network sensor configuration decides whether these are used.
