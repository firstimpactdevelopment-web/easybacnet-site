Short answer

The BACnet FF (TB3026B) is a fixed-function thermostat/controller on BACnet MS/TP that runs one of 19 built-in applications (fan coils, heat pumps, unit ventilators and others). This list is the platform's ordered list of named control points: setpoints and limits, displayed and sensed values, occupancy and schedule control, maintenance timers, humidity setpoints and the many screen-control objects. The application in use adds its own AV 0-89 / BV 0-63 points, documented per application in the guide.

This page lists 245 BACnet objects for the Honeywell TB3026B / TB3026B-W BACnet FF fixed-function thermostat — 208 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of Honeywell’s documentation hosted by Galco, not by Honeywell itself, so treat it as unofficial.

BMS integration notes: Honeywell TB3026B / TB3026B-W BACnet FF fixed-function thermostat

Integration in brief

Set the MS/TP MAC and device instance in the ISU menu, then write occupancy (BV 40, or let the internal schedule run) and the occupied setpoint AV 90. Read the sensed room temperature, the active heating/cooling setpoints and the occupied status. Application-specific outputs and alarms are in the per-application tables of the guide.

Enable & remote start

Occupancy comes from BV 40 (priority array) or the internal schedule (BV 133).

Network setup

  • Factory defaults: MS/TP MAC 0 (valid 0-127), device instance 0009999 (valid 0-4194302).
  • MS/TP MAC and device instance are set through ISU parameters on the thermostat.
  • Application selection is an ISU / setup setting; it decides which AV 0-89 / BV 0-63 points are used.

Watch out for

  • Many BVs and AVs above 200 only control the display layout; do not map them for HVAC control.

Integration notes

  • The appendix gives each object a label in an 'Object Name' column, but its property tables say the Object_Name property reads 'AV-nnn' / 'BV-nnn' / 'MV-nnn' for most objects. The labels are used as names here; a scan may show the AV-nnn form.
  • Physical I/O objects (AI 0-2, AO 0-7, BI 0-2, BO 0-5) and the general-use AV 0-89 / BV 0-63 depend on the loaded application (DDC file); they are not listed here except where the guide names them.
  • BV 40 (general-use range) is the occupancy command and supports a priority array.
  • Access comes from the appendix where it has an access column; otherwise it is inferred (displayed/sensed/current/status points and multistates read-only, others writable).
  • Taken from Appendix B (ordered list of control points) with access and descriptions from Appendix A of the guide.

How many BACnet points does the Honeywell TB3026B / TB3026B-W BACnet FF fixed-function thermostat have?

This list has 245 BACnet objects: 74 analog values, 153 binary values, 18 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Honeywell TB3026B / TB3026B-W BACnet FF fixed-function thermostat BACnet points are writable?

208 of the 245 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Honeywell TB3026B / TB3026B-W BACnet FF fixed-function thermostat BACnet documentation?

Honeywell does not publish it on its own website. This list comes from BACnet FF Installation and Operations Guide (31-00098-01), a copy hosted by Galco at https://docs.galco.com/techdoc/hnwl/31-00098_opm.pdf. Ask Honeywell or its representative for the current revision.

What are the minimum BACnet points to integrate the Honeywell TB3026B / TB3026B-W BACnet FF fixed-function thermostat?

Start with AV 90 Setpoint (SP) (Occupied space setpoint); AV 95 Unoccupied Cooling SP (Unoccupied cooling setpoint); AV 96 Unoccupied Heating SP (Unoccupied heating setpoint); BV 133 Enable internal schedule (Internal schedule on/off); AV 104 Sensed Room Temperature (Room temperature (built-in sensor)); BV 67 Occupied/Unoccupied Status (Occupied / unoccupied status); AV 99 Current Cooling SP (Active cooling setpoint); AV 100 Current Heating SP (Active heating setpoint).

How do I enable BMS control of the Honeywell TB3026B / TB3026B-W BACnet FF fixed-function thermostat?

Occupancy comes from BV 40 (priority array) or the internal schedule (BV 133).

How do I check these points on the real TB3026B / TB3026B-W BACnet FF fixed-function thermostat?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
