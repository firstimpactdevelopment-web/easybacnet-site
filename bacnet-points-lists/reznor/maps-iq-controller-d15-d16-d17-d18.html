Short answer

MAPS III and MAPS IV units with control options D15-D18 use the Reznor IQ system controller, which speaks BACnet over MS/TP as standard (BACnet over ARCNET and LonWorks are options). The network point list has about 230 objects: occupancy and BAS on/off commands, space, neutral air and discharge air setpoints, fan, damper and economizer settings for each control option, heating, cooling and reheat settings, alarm flags, output status and the energy recovery module interface.

BMS integration notes: Reznor MAPS / MAPS III / MAPS IV IQ Controller, Options D15 / D16 / D17 / D18 (BACnet point list)

Integration in brief

Set the IQ controller's MS/TP baud and address on its DIP and rotary switches and the network number and device instance in the BACnet menu. If the schedule is configured for BAS control, command occupancy with BV 50 and on/off with BV 51, then write the occupied space setpoints or the neutral air setpoint. Monitor unit mode, occupancy status, the system shutdown flag and the alarm BVs.

Enable & remote start

BV 50 bas_occ_unocc_cmd_1 and BV 51 bas_on_off_cmd_1 control occupancy and on/off, but only when BAS control is selected in the schedule configuration. AV 52 lets a BACnet schedule pass minutes-until-occupied for optimum start. BV 178 resets a system shutdown.

Network setup

  • MS/TP is the standard protocol; default baud 9600 (19.2K, 38.4K and 76.8K selectable on DIP switches 1-2); protocol on switches 5-8.
  • Default network number 12345; device instance = 2400 + rotary address (default 02, so 2402).
  • The ERM controller has its own default device instance 2499.
  • Power must be cycled after changing DIP settings.

Watch out for

  • Some objects' Type column contradicts the Object ID; verify AV 328 and BV 346-350 on the unit.
  • AV 186-189 change meaning with the fan or damper control option fitted.

Integration notes

  • Access comes from the Direction column: Input points are shown writable, Output points read-only. The guide has no explicit read/write column.
  • The object type is taken from the Object ID column. For AV 328 and BV 346-350 the Type column disagrees (BBV vs AV:328, BAV vs BV:346-350); the IDs are kept as printed.
  • AV 181 and AV 182 are listed twice (fan and damper sections) and kept once. AV 186-189 are reused: listed here with the four-speed supply fan names; in the GF four-position damper section the same IDs are four_pos_opn_min_1, four_spd_in1_pos_1, four_spd_in2_pos_1 and four_spd_cls_pos_1.
  • Most setpoints only apply to the fan (VFC), damper (GF), heating, cooling and reheat options ordered; ERM points need the energy recovery module.
  • Source: 9.6 BACnet Network Point List, guide pages 66-72 (form pages 65-71).

Questions about the Reznor MAPS / MAPS III / MAPS IV IQ Controller, Options D15 / D16 / D17 / D18 (BACnet point list)

How many BACnet points does the Reznor MAPS / MAPS III / MAPS IV IQ Controller, Options D15 / D16 / D17 / D18 (BACnet point list) have?

This list has 227 BACnet objects: 122 analog values, 103 binary values, 2 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Reznor MAPS / MAPS III / MAPS IV IQ Controller, Options D15 / D16 / D17 / D18 (BACnet point list) BACnet points are writable?

87 of the 227 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Reznor MAPS / MAPS III / MAPS IV IQ Controller, Options D15 / D16 / D17 / D18 (BACnet point list) BACnet documentation?

The source is Control System Guide for Modular Air Processing System Units, Options D15, D16, D17, D18, D19 and D21 (MAPS III and MAPS IV) (MAPSIII&IV-D15-D16-D17-D18-D19-D21 (06-26) REV-A), revision 2026-06, published free by Reznor at https://assets.reznorhvac.com/download/bcd1b330-3a4f-11f1-ae67-0016e1e579b9/MAPSIII%26IV-D15-D16-D17-D18-D19-D21%20%2806-26%29%20REV-A.pdf.

What are the minimum BACnet points to integrate the Reznor MAPS / MAPS III / MAPS IV IQ Controller, Options D15 / D16 / D17 / D18 (BACnet point list)?

Start with BV 51 bas_on_off_cmd_1 (BAS on/off (schedule set for BAS)); BV 50 bas_occ_unocc_cmd_1 (BAS occupied/unoccupied (schedule set for BAS)); AV 100 occ_cool_sp_1 (Occupied space cooling setpoint); AV 101 occ_heat_sp_1 (Occupied space heating setpoint); AV 150 na_stpt_1 (Neutral air / discharge air setpoint); BV 178 bas_reset_sys_shtdwn_1 (Reset a system shutdown); AV 175 unit_mode_1 (Current unit mode); BV 54 occ_status_1 (Occupancy status); BV 191 shutdown_fail_1 (Unit shut down on alarm); BV 176 sf_fail_1 (Supply fan failure).

How do I enable BMS control of the Reznor MAPS / MAPS III / MAPS IV IQ Controller, Options D15 / D16 / D17 / D18 (BACnet point list)?

BV 50 bas_occ_unocc_cmd_1 and BV 51 bas_on_off_cmd_1 control occupancy and on/off, but only when BAS control is selected in the schedule configuration. AV 52 lets a BACnet schedule pass minutes-until-occupied for optimum start. BV 178 resets a system shutdown.
