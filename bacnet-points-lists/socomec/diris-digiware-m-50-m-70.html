Short answer

The DIRIS Digiware M-50 / M-70 is a BACnet IP gateway for Socomec metering. Each downstream device appears as its own BACnet device (instance 100 + its Modbus address) with Analog Input objects per load: voltages, currents, unbalance, active, reactive and apparent power and power factor per phase and total, load-curve values, THD and energy counters. The object number is the load number times 100 plus a fixed measurement index (0-61); this list shows load 1.

This page lists 62 BACnet objects for the Socomec DIRIS Digiware M-50 / M-70 BACnet IP gateway (per-load measurement objects) — 0 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of Socomec’s documentation hosted by Instrumentation2000, not by Socomec itself, so treat it as unofficial.

BMS integration notes: Socomec DIRIS Digiware M-50 / M-70 BACnet IP gateway (per-load measurement objects)

Integration in brief

Discover one BACnet device per metered device (instance 100 + Modbus address) behind the gateway, then read the per-load Analog Inputs: total power, energy, current, voltage and power factor. All values are read-only.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

BACnet IP is switched on in Easy Config System or the web server (BACnet activation).

Network setup

  • Main instance ID defaults to 100 and must be unique; a virtual network ID must also be set and be unique.
  • UDP port is fixed at 47808.
  • The PICS is on socomec.com.

Watch out for

  • Object numbers repeat per load: load 2 adds 100 to every instance.
  • Unsupported measurements read 0, not an error.

Integration notes

  • Only the index table is printed. Instance = load number x 100 + index (load 1 = AI 100-161, load 2 = AI 200-261 and so on); load 1 is listed here.
  • Device instances: the gateway itself is the main instance (default 100); a downstream device with Modbus address xx is device 100 + xx.
  • A device returns 0 for measurements it does not support (for example THD on a DIRIS Digiware I-30).
  • The manual also mentions Binary Input and Binary Output objects (auxiliary contacts, IO-10 outputs) but gives no table for them; they are not listed.
  • The guide gives no read/write column; all listed measurement objects are read-only values.
  • Copied from a distributor-hosted copy of the Socomec manual; socomec.com blocks automated downloads.
