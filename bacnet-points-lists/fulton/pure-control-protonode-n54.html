Short answer

Fulton's N54 ProtoNode publishes a block of 58 objects for each hydronic boiler with the PURE control. It covers burner phase, lead/lag role, modulation, combustion fan drive and O2 sensor data, water temperatures, safety switch states, alarms and pump/isolation valve status. The BMS can enable the boiler, send a water setpoint and a heartbeat, and supply header, outdoor and DHW temperatures when the boiler is set up for them.

BMS integration notes: Fulton PURE Control - Endura+ EDR+ 2500-6000 (N54 ProtoNode)

Integration in brief

Remove the BMS enable jumper at the boiler, then write BMS Enable = 1, send the water setpoint to the BMS Network Setpoint and keep writing 1 to the BMS Heartbeat at least every 10 s. Watch Current Setpoint Mode to confirm the boiler is on BMS Network, and read LMV status, outlet temperature, modulation rate and the alarm points.

Enable & remote start

Remove the physical jumper at the boiler, then write BV (X)057 BMS Enable = 1. The setpoint comes from AV (X)052 BMS Network Setpoint (40-185 °F); AI (X)051 Current Setpoint Mode reads 3 when the BMS network setpoint is in use.

Heartbeat & communication loss

AV (X)058 BMS Heartbeat: the BMS must write 1 at least once every 10 seconds for remote operation. What the boiler does when the heartbeat stops is not stated.

Sensors & values from the BMS

AV (X)025 outdoor air, (X)026 header supply, (X)027 header return and (X)029 DHW temperature are writable only when the boiler program is set to accept that value from the BMS (°F).

Network setup

  • Object ID = boiler Modbus address followed by the three-digit point number: (X)001-(X)058. Boiler 1 = 1001-1058, boiler 2 = 2001-2058.
  • The sheet gives no device instance, MAC address or baud rate; those are set on the ProtoNode gateway.

Watch out for

  • BMS Enable does nothing until the physical jumper is removed.
  • Safety BIs mostly read 0 = Fault, 1 = No Fault; the low water BIs read 1 = Fault.
  • For the isolation valve, read the output state together with the valve type chosen on the boiler; a spring-open valve is open when the output is off.

Integration notes

  • Object IDs are written (X)001-(X)058, where (X) is the boiler's Modbus address on the ProtoNode. This list shows boiler address 1 (1001-1058); boiler 2 uses 2001-2058, boiler 10 uses 10001-10058.
  • The sheet does not say which BACnet transport the gateway is set to; ProtoNode gateways are normally configured for BACnet IP or BACnet MS/TP.
  • The BMS Enable point only works after a physical jumper is removed at the boiler.
  • Outdoor, header and DHW temperature AVs are writable only when the boiler program is set to take that value from the BMS.
  • Current Alarm Index is decoded with Fulton's alarm chart and is only valid while Active Alarm = 1.
  • Several safety inputs use 0 = Fault, 1 = No Fault; low water inputs use the opposite. Check the states.

How many BACnet points does the Fulton PURE Control - Endura+ EDR+ 2500-6000 (N54 ProtoNode) have?

This list has 58 BACnet objects: 35 analog inputs, 6 analog values, 16 binary inputs, 1 binary value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Fulton PURE Control - Endura+ EDR+ 2500-6000 (N54 ProtoNode) BACnet points are writable?

7 of the 58 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
