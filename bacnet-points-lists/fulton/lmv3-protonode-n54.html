BMS integration notes: Fulton Boiler with Siemens LMV3 (N54 ProtoNode)

Integration in brief

Put the boiler in remote with the Modbus Mode BV, then run it with Operating Mode In Remote (Auto/On/Off) and the Remote Firing Rate. Monitor burner phase, firing rate, the alarm output and the LMV error code. Every boiler on the ProtoNode has its own block of object IDs based on its Modbus address.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

Write BV (X)026 Modbus Mode = 1 (Remote). In remote, AV (X)027 Operating Mode In Remote selects 0 = Auto, 1 = On or 2 = Off, and AV (X)028 Remote Firing Rate sets the rate; the boiler is only enabled at 20 % or more.

Network setup

  • Object ID = boiler Modbus address followed by the three-digit point number: (X)001-(X)028. Boiler 1 = 1001-1028, boiler 2 = 2001-2028.
  • The sheet gives no device instance, MAC address or baud rate; those are set on the ProtoNode gateway.

Watch out for

  • A remote firing rate below 20 % does not enable the boiler.
  • Error code points need the Siemens LMV manual to decode.

Integration notes

  • Object IDs are written (X)001-(X)028, where (X) is the boiler's Modbus address on the ProtoNode. This list shows boiler address 1 (1001-1028); boiler 2 uses 2001-2028, boiler 10 uses 10001-10028.
  • The sheet does not say which BACnet transport the gateway is set to; ProtoNode gateways are normally configured for BACnet IP or BACnet MS/TP.
  • Remote firing rate needs at least 20 % for the boiler to be enabled.
  • Error code, diagnostic, class and phase values are decoded with the Siemens LMV manual.
  • Burner phase and fuel type are analog inputs carrying a code; the code meanings are given in the states.

Questions about the Fulton Boiler with Siemens LMV3 (N54 ProtoNode)

How many BACnet points does the Fulton Boiler with Siemens LMV3 (N54 ProtoNode) have?

This list has 28 BACnet objects: 13 analog inputs, 2 analog values, 12 binary inputs, 1 binary value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Fulton Boiler with Siemens LMV3 (N54 ProtoNode) BACnet points are writable?

3 of the 28 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Fulton Boiler with Siemens LMV3 (N54 ProtoNode) BACnet documentation?

The source is LMV 3 Fulton N54 ProtoNode BACnet Network Addressing, revision 2020-04-08 (file date), published free by Fulton at https://fulton.com/app/uploads/2021/02/N54-LMV3-BACnet-list_2020-0408.pdf.

What are the minimum BACnet points to integrate the Fulton Boiler with Siemens LMV3 (N54 ProtoNode)?

Start with AV 1027 Boiler 1 Operating Mode In Remote (Run command in remote: 0 = Auto, 1 = On, 2 = Off); BV 1026 Boiler 1 Modbus Mode (Set 1 = Remote so network commands take effect); AV 1028 Boiler 1 Remote Firing Rate (Firing rate command, %; 20 % minimum to enable); BI 1014 Boiler 1 Controller On/Off Status (Burner controller on/off state); AI 1001 Boiler 1 Burner Control Phase (Burner sequence phase; 60 = operation, 0 = lockout); AI 1005 Boiler 1 Firing Rate (Actual firing rate, %); BI 1020 Boiler 1 Alarm Status (Boiler alarm active); AI 1010 Boiler 1 Current Error: Error Code (Active LMV error code).

How do I enable BMS control of the Fulton Boiler with Siemens LMV3 (N54 ProtoNode)?

Write BV (X)026 Modbus Mode = 1 (Remote). In remote, AV (X)027 Operating Mode In Remote selects 0 = Auto, 1 = On or 2 = Off, and AV (X)028 Remote Firing Rate sets the rate; the boiler is only enabled at 20 % or more.
