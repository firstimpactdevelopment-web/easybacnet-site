Short answer

The ECY-PTU-107 is a Distech Controls Eclypse terminal unit controller on BACnet IP that ships with preloaded fan coil, chilled beam/ceiling and heat pump applications, plus lighting and sunblind control. The preloaded program exposes a fixed set of value objects for setpoints, occupancy, mode, fan, valve, light and blind control. It is configured from the controller's web pages or the EC-gfxProgram Configuration Assistant.

This page lists 151 BACnet objects for the Distech Controls ECY-PTU-107 preloaded applications — 115 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Distech Controls’s own free documentation, linked below.

BMS integration notes: Distech Controls ECY-PTU-107 preloaded applications

Integration in brief

Command occupancy with MV 2 and the mode with MV 1, write the occupied setpoints AV 40 and AV 41, and read back MV 14, MV 11, AV 1 and MV 16. Leave MV 3 at Auto unless the BMS should pick the fan speed.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

Write MV 2 OccupancyCmd for occupancy and MV 1 HvacModeCmd for the mode; any value other than Auto forces the unit into that mode. MV 3 FanSpeedCmd set to Auto leaves the fan to the control loop.

Sensors & values from the BMS

The guide says AV 1 SpaceTemp and other measured values can be overridden through the BACnet priority array (it calls this a testing feature). MV 5 MotionSensor can be written from the network; the guide says to use a priority lower than 14 to override local control.

Network setup

  • Eclypse controllers connect over Ethernet; the guide reaches the configuration pages through the controller's IP address or factory host name.
  • Master/slave and remote light/blind groups use room numbers (AV 81 CtrlRoom and the light/blind room values).

Watch out for

  • Temperatures are in °C in this guide.
  • Configuration values (system type, valve and fan types) are commissioning settings; don't write them cyclically.

Questions about the Distech Controls ECY-PTU-107 preloaded applications

How many BACnet points does the Distech Controls ECY-PTU-107 preloaded applications have?

This list has 151 BACnet objects: 84 analog values, 28 binary values, 39 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Distech Controls ECY-PTU-107 preloaded applications BACnet points are writable?

115 of the 151 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Distech Controls ECY-PTU-107 preloaded applications BACnet documentation?

The source is ECY-PTU-107 Preloaded Applications User Guide (ECY-PTU-107 Preloaded_UG_10_EN), revision 2016-11 (version 1.0), published free by Distech Controls at https://docs.distech-controls.com/api/khub/documents/e_61tL2Fod11LBZ3m1MTDw/content.

What are the minimum BACnet points to integrate the Distech Controls ECY-PTU-107 preloaded applications?

Start with MV 2 OccupancyCmd (Occupancy command from the BMS); MV 1 HvacModeCmd (HVAC mode command (auto, heat, cool, off)); MV 3 FanSpeedCmd (Fan speed command (auto, off, low, med, high)); AV 40 OccCoolSp (Occupied cooling setpoint); AV 41 OccHeatSp (Occupied heating setpoint); MV 14 OccupancyStatus (Effective occupancy state); MV 11 HvacModeStatus (Actual HVAC mode); AV 1 SpaceTemp (Space temperature used for control); MV 16 FanSpeedSt (Actual fan speed); BV 2 CondSensorSt (Condensation alarm; cooling valve closes).

How do I enable BMS control of the Distech Controls ECY-PTU-107 preloaded applications?

Write MV 2 OccupancyCmd for occupancy and MV 1 HvacModeCmd for the mode; any value other than Auto forces the unit into that mode. MV 3 FanSpeedCmd set to Auto leaves the fan to the control loop.

Can the BMS supply sensor values to the Distech Controls ECY-PTU-107 preloaded applications?

The guide says AV 1 SpaceTemp and other measured values can be overridden through the BACnet priority array (it calls this a testing feature). MV 5 MotionSensor can be written from the network; the guide says to use a priority lower than 14 to override local control.

How do I check these points on the real ECY-PTU-107 preloaded applications?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
