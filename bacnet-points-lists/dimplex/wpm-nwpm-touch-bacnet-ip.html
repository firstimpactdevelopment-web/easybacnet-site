Short answer

The NWPM Touch card (article 378800) plugs into the Serial/BMS slot of the WPM heat pump manager and exposes it over BACnet IP. The published data point list (German names) covers status, lockout, fault and sensor-error codes, operating mode, temperatures and pressures, output states, run hours, heat quantities, heating-circuit settings, an outdoor temperature written by the BMS, Smart Grid control and BMS room-control inputs. All objects are Analog Values or Binary Values with instances 100000 / 200000 + key number.

This page lists 105 BACnet objects for the Dimplex WPM heat pump manager with NWPM Touch (BACnet IP) — 18 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Dimplex’s own free documentation, linked below.

BMS integration notes: Dimplex WPM heat pump manager with NWPM Touch (BACnet IP)

Integration in brief

Fit the NWPM Touch card and enable the network setting on the WPM. Read the status, lockout and fault codes and the main temperatures, and write the operating mode or circuit setpoints only if the BMS owns them. If the BMS supplies outdoor temperature or room values, the service technician must configure that on the WPM first.

Enable & remote start

Set the Netzwerk parameter on the WPM (home app setting) to activate the NWPM Touch extension. The list has no separate BMS enable; writes go straight to the mode and setpoint objects.

Sensors & values from the BMS

AV 100112 takes outdoor temperature from the BMS (configured by the service technician before WPM software M3.15). If no value is written after a power reset it stays at -99.9 °C and raises an outdoor sensor fault. For Smart-RTC+ room control (WPM_L23.1+), select a room address page with AV 200064, then write room temperature AV 100011, humidity AV 100013, room setpoint AV 200080 and release AV 100173 for up to 10 rooms per circuit.

Network setup

  • NWPM Touch: RJ45 10/100BaseT, BACnet IP (Annex J); usable from WPM software M3.3.
  • Dimplex publishes EDE files per WPM software version on the BACnet/IP Anbindung page.
  • To change 2nd or 3rd circuit settings, first write 2 or 3 to AV 200081, then write AV 200083-200087.

Watch out for

  • AV 100081-100092 are multiplexed: the meaning of the values depends on the selector written to AV 100081.
  • AV 100011 and AV 100013 are read as room temperature/humidity 1 but also act as BMS room inputs when room addressing via AV 200064 is in use.
  • Heat quantities must be combined from three AVs; reading one alone gives only part of the number.
  • The Betriebsmodus state texts are not published on the wiki.

Integration notes

  • Names are German as printed in the Dimplex wiki. The wiki gives object types as numeric codes: 2 = Analog Value (also used for 'Integer Variable' keys), 5 = Binary Value.
  • Instances are kept as printed. The Betriebsdaten page prints AV 11 as 1000011, but the room-control page prints the same object (Analog Variable 11) as 100011, so 100011 is used. AV 46 Raumtemperatur 1. Heizkreis is printed only once, as 1000046, and is kept that way although every other object follows 100000 + key number; check it with a device scan.
  • Heat quantities come in three parts (digits 1-4, 5-8, 9-12): total = (9-12 x 100000000) + (5-8 x 10000) + (1-4). Only heat pumps with a built-in heat meter report them.
  • The fault/lockout history uses AV 100081 as a selector: write 100-190 or 200-290 to choose one of the last 10 fault or lockout entries, then read AV 100082-100086 and 100092. Multiplexed objects are printed once per use with different names (AV 100092 also as Sperrwert (Siehe Sperrmeldungen), AV 200064 per circuit, AV 200081 as Auswahl Heizkreis 3); the first printed name is used.
  • BV 177 Zustand Stellventil is printed with instance 177, not 100177.
  • Status, lockout, fault and sensor codes are decimal values such as 2.8; the state lists are on the Systemstatus sub-pages and are copied into the states field.

Questions about the Dimplex WPM heat pump manager with NWPM Touch (BACnet IP)

How many BACnet points does the Dimplex WPM heat pump manager with NWPM Touch (BACnet IP) have?

This list has 105 BACnet objects: 81 analog values, 24 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Dimplex WPM heat pump manager with NWPM Touch (BACnet IP) BACnet points are writable?

18 of the 105 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the Dimplex WPM heat pump manager with NWPM Touch (BACnet IP)?

Start with AV 200014 Betriebsmodus (Operating mode command (writable)); AV 200036 Festwertsolltemperatur (Fixed-value setpoint, 1st circuit, °C); AV 100053 Ruecklaufsolltemperatur (Hz/Khl) (Return temperature setpoint in use, °C); AV 100103 Statusmeldungen (Operating state code (heating, hot water, defrost...)); AV 100001 Außentemperatur (R1) (Outdoor temperature, °C); AV 100002 Ruecklauftemperatur (R2) (Return water temperature, °C); AV 100003 Warmwassertemperatur (R3) (Hot water temperature, °C); BV 100041 Verdichter 1 (Compressor 1 running); AV 100104 Sperrmeldungen (Lockout code (why the heat pump is blocked)); AV 100105 Stoermeldungen (Fault code, 0 = no fault).

How do I enable BMS control of the Dimplex WPM heat pump manager with NWPM Touch (BACnet IP)?

Set the Netzwerk parameter on the WPM (home app setting) to activate the NWPM Touch extension. The list has no separate BMS enable; writes go straight to the mode and setpoint objects.

Can the BMS supply sensor values to the Dimplex WPM heat pump manager with NWPM Touch (BACnet IP)?

AV 100112 takes outdoor temperature from the BMS (configured by the service technician before WPM software M3.15). If no value is written after a power reset it stays at -99.9 °C and raises an outdoor sensor fault. For Smart-RTC+ room control (WPM_L23.1+), select a room address page with AV 200064, then write room temperature AV 100011, humidity AV 100013, room setpoint AV 200080 and release AV 100173 for up to 10 rooms per circuit.
