Short answer

The Veris E8951 discovers supported Veris Modbus RTU meters and presents each one as its own BACnet device on BACnet MS/TP or BACnet IP, with a fixed object profile per meter type. The E3xA/E profile is large: mains voltage, power, energy, PF and demand, then per-channel kWh, kW, current, demand, max values, power factor, phase angle and kWh snapshots for 42 branch channels, logical-circuit data, alarm registers, CT sizes, alarm thresholds and reset outputs.

BMS integration notes: Veris E8951 gateway - E3xA / E3xE branch circuit power meter profile

Integration in brief

Wire the meters to the E8951 downstream port at one baud rate with no parity, power up in Discovery mode and wait 2-3 minutes; each meter then shows up as a device behind the E8951's virtual network. Read the energy, power and alarm objects; AVs and AOs are meter set-up and reset registers.

Network setup

  • E8951 converts Modbus RTU (downstream RS-485) to BACnet MS/TP (up to 76.8 kbps) or BACnet IP; DIP switches A6/A7 pick the protocol, A0-A6 set the MS/TP MAC.
  • Meters sit behind a virtual router network (default network number 50); change it in the web GUI if 50 is in use.
  • Device ID offset (default 50000) is set in the GUI; written device instances and names stick even in Discovery mode.
  • Set S3 to Discovery to find meters on power-up (2-3 minutes), then Locked to skip rediscovery; all meters need the same baud and no parity.
  • Limits: 32 meters and 10,000 BACnet points per E8951; BBMD via an uploaded bdt.ini.

Watch out for

  • Invalid AV writes are not rejected over BACnet; read the value back after the next scan.
  • COV increments revert to their defaults and subscriptions are lost after a power cycle.

Integration notes

  • Objects as printed in the E8951 Appendix 1 profile table; names are the table's Data Variable column (the guide does not spell out the BACnet Object_Name).
  • The E8951 creates one virtual BACnet device per discovered Modbus meter; default device instance = 50000 + Modbus address, default device name = meter series abbreviation + "_" + Modbus address.
  • Which objects exist depends on meter firmware: descriptions marked (FW V1.023+) or (FW V1.016+) need that firmware; the guide gives 1793 objects for V1.023+, 783 for V1.016-1.022 and 737 below V1.016 (the printed table holds 1792).
  • E30A/E models with more than 42 channels and all E31A/E models use two Modbus addresses, so they appear as two BACnet devices with this same profile.
  • AO 1/AO 2 take magic numbers (e.g. 10203 clears kWh, 31010 resets latching alarms); AO 84 is printed as "Logical Ckt 30" although it follows Ckt 39.
  • E3x meters run at 9600, 19200 or 38400 baud.
