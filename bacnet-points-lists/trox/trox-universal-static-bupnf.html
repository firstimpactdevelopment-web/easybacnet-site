BMS integration notes: TROX UNIVERSAL static BUPNF duct pressure controller (VRU-...-BAC, BACnet MS/TP)

Integration in brief

Set MV 122 SpSource to Bus (factory setting is Analogue), then write AO 1 SpRel as a percentage between Min and Max; what it controls (airflow or pressure) follows MV 2 ApplicationSel. Read AI 19 airflow or AI 18 pressure, AI 1 damper position and BI 101 SummaryStatus. Set AV 130 if the unit should react to a lost BMS.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

MV 122 SpSource: 2 = Bus makes AO 1 SpRel active; 1 = Analogue (factory setting) uses the analogue input and AO 1 is ignored.

Heartbeat & communication loss

AV 130 BusWatchdog (0-3600 s, factory 0 = off). When set, the unit watches AO 1 and MO 1 for changes and resets the timer on each change; MI 110 StatusDevice shows when bus timeout monitoring has tripped. With SpSource = Analogue only MO 1 is watched.

Sensors & values from the BMS

Sensor 1 (AI 20 / BI 20) is configured with MV 220 Sens1Type; with RmPCasacade active it is the 0-10 V room cascade input.

Network setup

  • Default device instance 1.
  • MS/TP baud rates 9600, 19200, 38400, 76800 and 115200.

Watch out for

  • Min must stay below Max; Max range is 20-100 %.
  • MV 102 OperationMode only matters for VRU-M1R-BAC room pressure control.

Integration notes

  • The PICS names the product VRU-D3-BAC, VRU-M1-BAC, VRU-M1R-BAC; the object list follows the Belimo VAV-Universal VRU numbering, so it shares firmware with that Belimo product.
  • Several objects go Out_Of_Service depending on MV 2 ApplicationSel, MV 122 SpSource or MV 220 Sens1Type (see the status-flag notes in the data sheet).
  • SpSource leaves the factory set to Analogue; set it to Bus before writing AO 1.
  • The object name RmPCasacade (MV 10) is spelled this way in the data sheet.
