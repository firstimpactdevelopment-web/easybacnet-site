BMS integration notes: TROX EASYLAB TCU3 adapter module TAM without room management function (EM-BAC-MOD-01, BACnet MS/TP)

Integration in brief

This application takes no mode preset over BACnet; the BMS mainly reads airflow, damper and alarm values. Read AV 3 VolTotalExh, BV 1 LocalAlarm.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

ObjectNameWhyAccess
AV 3VolTotalExhTotal room extract airflow, l/sRead
AV 4VolTotalSupTotal room supply airflow, l/sRead
BV 1LocalAlarmAlarm on this controllerRead

Sensors & values from the BMS

AV 22 VolflowExh and AV 23 VolflowSup let the BMS feed extract and supply airflows of other equipment into the room balance.

Network setup

  • Default device instance is 32900 plus the network address set on hex switches X/Y.
  • MS/TP baud rate (9600, 19200, 38400 or 76800) is set on DIP switches 2 and 3; DIP 1 selects EASYLAB TCU3 or another controller.
  • Max_Master defaults to 127 and Max_Info_Frames to 1.

Watch out for

  • If the network interface fails the airflow controller keeps controlling; only data exchange with the BMS stops.

Integration notes

  • The module holds the objects of all applications; objects outside this application stay unused.
  • Units come from the EDE unit-code column; airflows are in l/s.
  • MV 1 COVU-Mode (MS/TP module only) sets how unsolicited COV notifications go out: 1 none, 2 local MS/TP broadcast, 3 global broadcast.
