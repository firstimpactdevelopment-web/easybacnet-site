BMS integration notes: TROX X-AIRCONTROL Master zone controller (TROX Auranor, BACnet IP)

Integration in brief

Read AI 111 for the master operating mode, AI 104 for the AHU state and AI 109/AI 110 for master and zone-module alarms. Per zone, write the room temperature setpoint (AV 1001 for zone 1, +100 per zone) and read room temperature (AI 1009), supply airflow (AI 1002) and zone status (AI 1000). Remember that values are scaled by 100.

Network setup

  • BACnet IP over the Master's RJ45 port; the device Object_Identifier is set automatically from the last five digits of the IP address (e.g. 172.21.0.95 gives 95).
  • Up to 300 values can be subscribed for COV.
  • TROX Norway offers the PICS and EDE files for the Master.

Watch out for

  • Scaled values: divide % and °C values by 100.
  • Changing the Master IP address changes its BACnet device instance.

Integration notes

  • Zone objects repeat per Zone Module: instance = 1000 + (zone - 1) x 100 + offset, zones 1-25 (all printed in the document). Master alarm objects repeat as 4000 + (master - 1) x 100.
  • Most values are scaled integers: % values run 0-10000 (1/100 %) and temperatures -4000..10000 (1/100 °C); airflows are m³/h.
  • Access follows the section headings: Binary Value and Analog Value are read/write, Analog Input and Binary Input are read-only.
  • Objects for zone modules that are not connected stay unused; AI 300 gives the number of connected modules.
  • AV 104 and AV 105 have no unit in the unit column; the remarks give them in 1/100 °C.
  • The PDF cover page uses a garbled font; the tables themselves extract cleanly.
