BMS integration notes: TROX TITAN FCU403 fan coil controller (config FCU403 TRX)

Integration in brief

Set the device instance, MAC address and baud rate on the RDU first. Then write AV 300 Set Point and MV 605 User Fan, write AV 700 Ext Temp if the BMS supplies the outdoor temperature, and read MV 602 Active Mode, AI 700 RDU Temp, the valve positions and BV 603 Fan Alarm.

Enable & remote start

MV 602 Active Mode is writable depending on BV 600 Off Selector (off signal from the RDU or a digital input). MV 600 Off Mode sets what runs while the unit is Off.

Sensors & values from the BMS

AV 700 Ext Temp takes an external temperature written over BACnet or from an analog input. Inputs (AI/BI) can be overridden only by setting Out_Of_Service True first.

Network setup

  • Device instance, MAC address (1-127) and baud rate (9600, 19200, 38400, 76800) are set on the RDU or programming tool by pressing all four buttons together.
  • With the default Device Object ID 0000000 the unit works on the local MS/TP network but does not send I-Am; enter a valid ID (1-4194302).
  • Group operation: one Group_Master sends setpoint, fan, occupancy and input values to Group_Slaves with the same group number (MSV 1000/1001).

Watch out for

  • Write BV 0 Flash Store only when you want current values kept after a reboot.
  • User Fan (MV 605) states depend on MSV 609 Fan Speeds and BV 602 Auto Fan Enable.
  • In a group, slaves use the grouped input only when their local input is out of service.

Integration notes

  • The controller is made by Titan Products Ltd (PICS vendor name); TROX hosts this document for its FCU403 TRX configuration.
  • Objects marked *1 in the document only exist with certain configurations; AV 220/221/222 and 230/231/232 change name with the valve type (TPC or PWM, heat, cool or combined).
  • Inputs (AI/BI) are writable only when Out_Of_Service is True, so they are listed as read-only here.
  • Outputs (AO/BO/MO) can be written above the controller priority 15 and are listed as commandable.
  • AV 608 is named "Offset Cool" in the function table and "Offset Heat" in the range table; the function-table name is used.
  • Analog input units and ranges depend on the input profile chosen in the engineer menu, so none are given.

How many BACnet points does the TROX TITAN FCU403 fan coil controller (config FCU403 TRX) have?

This list has 138 BACnet objects: 8 analog inputs, 3 analog outputs, 63 analog values, 6 binary inputs, 4 binary outputs, 22 binary values, 1 file, 1 multi-state output, 2 notification classs, 28 multi-state values. Which TROX TITAN FCU403 fan coil controller (config FCU403 TRX) BACnet points are writable?

114 of the 138 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
