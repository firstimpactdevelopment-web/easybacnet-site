Reflex Control Touch with Anybus CompactCom M30 BACnet MS/TP module BACnet points list

Updated 12 November 2026

Short answer

Reflex pressurisation, make-up and vacuum degassing units use the Control Touch controller. With the plug-in Anybus BACnet MS/TP module it publishes system pressure, vessel level, valve positions, run hours, make-up volume, output and input states, operating mode and a long list of fault and warning flags as Binary and Analog Values. The BMS can switch pumps or compressors and valves on and off and set the minimum operating pressure p0.

This page lists 105 BACnet objects for the Reflex Control Touch with Anybus CompactCom M30 BACnet MS/TP module — 15 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Reflex’s own free documentation, linked below.

BMS integration notes: Reflex Control Touch with Anybus CompactCom M30 BACnet MS/TP module

Integration in brief

Set the device number, MAC address and baud in the Control Touch service menu. Read AV 0 system pressure, AV 1 level, the mode BVs and the ER fault and warning flags. Remote commands work only when remote control is enabled in the controller and the unit is in AUTO.

Enable & remote start

Remote control from the BACnet master must be enabled in the Control Touch; binary commands are only taken over in AUTO mode.

Network setup

  • Settings > Service > Anybus module (shown only when a module is detected).
  • Device number (instance) 1-4194302, MAC address 0-127.
  • Baud 9600, 19200, 38400 or 76800.
  • 5-pin connector: 1 common, 2 Data-, 3 shield, 4 Data+.

Watch out for

  • Fit or remove the module only with the controller powered off.
  • The network LED flashes red on a BACnet timeout (no new message within the set time).

Integration notes

  • The source is in German; object names are as printed (English abbreviations) and descriptions are translated.
  • Many objects apply only to one unit type (Servitec, Servimat or CT-MK200); the unit type is shown in AV 8.
  • Commands BV 0-9 and BV 95-98 are separate ON and OFF objects (write 1 to act).
  • On Servitec units with 2x2-way ball valves, BV 6-9 and BV 12-13 drive the PV and CD valves instead.
  • BV 14 is printed 'BO relplen. valve'.

Questions about the Reflex Control Touch with Anybus CompactCom M30 BACnet MS/TP module

How many BACnet points does the Reflex Control Touch with Anybus CompactCom M30 BACnet MS/TP module have?

This list has 105 BACnet objects: 10 analog values, 95 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Reflex Control Touch with Anybus CompactCom M30 BACnet MS/TP module BACnet points are writable?

15 of the 105 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

How do I enable BMS control of the Reflex Control Touch with Anybus CompactCom M30 BACnet MS/TP module?
