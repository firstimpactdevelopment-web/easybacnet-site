Short answer

Greenheck's IVE indoor energy recovery units ship with a c.pCO Mini controller that can be licensed for BACnet IP or MS/TP. The BMS mainly enables the unit, commands occupancy, resets alarms and adjusts setpoints; it can also take over fan speeds and push its own sensor values in place of the unit's sensors. A BMS watchdog point must be written regularly or the unit raises an alarm and returns to local control. The points list is the same on every unit, so points for options a unit doesn't have simply won't mean anything.

BMS integration notes: Greenheck IVE Indoor Energy Recovery Ventilator (BACnet)

Integration in brief

With BACnet licensed and the network set at the controller, the minimum integration is to enable the unit (BV-2) and command occupancy (BV-3). Add alarm reset and global alarm monitoring, plus the temperature setpoint if needed. If the BMS will also drive fan speeds or send sensor values, it must keep writing the BMS watchdog, or the unit alarms and returns to local control.

Enable & remote start

BV-2 System_Enable enables or disables the unit from the BMS; in disabled mode some protective sequences may still run. By default occupancy is expected from BV-3 BMS_Occupancy_Command. The controller can instead be set to use an internal schedule, always occupied/unoccupied, or a digital input.

Heartbeat & communication loss

BV-1 BMS_Watchdog must be written to True (1) regularly whenever the BMS commands fan speeds or damper positions or sends sensor values. If it stays False longer than the Timeout Delay (15 minutes, adjustable), an alarm is raised and the controller falls back to local control and local sensor values. BV-24 shows watchdog status. If the relinquish-default-on-comm-loss option is enabled, priority arrays are cleared 5 minutes after the watchdog goes inactive.

Sensors & values from the BMS

For each sensor, set its source-select binary to BMS (BV-7 to BV-16, e.g. BV-8 Outside_Temp_Source_BMS, BV-16 Space_Temp_Source_BMS). Then write the matching *_from_BMS analog (AV-26 to AV-35, e.g. AV-27 outside temp, AV-35 space temp, AV-33 space RH, AV-30/31 space CO2). The watchdog must be satisfied; if it isn't, the controller reverts to the local sensor (if installed and valid) or to local control. Fan speeds are taken over the same way with BV-17/BV-18 plus AV-36/AV-37.

Network setup

  • The controller must have BACnet licensed and configured; otherwise get the license/config files from the rep (alarm 82 = BACnet license not installed).
  • BACnet MS/TP or IP settings are under Main Menu > Ctrl Variables > Advanced > Login > Network Settings.
  • BBMD and foreign-device registration, relinquish defaults and COV increments are in the Advanced BACnet Settings menu.
  • COV increments are shared by all objects with the same engineering unit.

Watch out for

  • The points list is the same on every unit, so points for options a unit lacks are meaningless on it.
  • Writing too often triggers alarm 32 (BMS Frequent Writes); reduce write traffic.
  • Status bits are packed into IV-6/8/9/10/11; use the 16-bit AV copies if the BMS can't read 32-bit integers.
  • Without Return to Default enabled, the controller boots after a power loss with the last written values.

Integration notes

  • BACnet must be licensed/enabled on the controller; without it the unit won't respond.
  • Write BV-1 BMS_Watchdog = Active regularly; after the timeout (default 15 min) the unit alarms and falls back to local values.
  • To use a BMS sensor value, set the matching *_Source_BMS binary to BMS, then write the *_from_BMS analog.
  • Status bits (cooling/heating on, filter alarm, wheel enable, preheat, etc.) are packed into IV-6/8/9/10/11, with 16-bit AV copies for systems that can't read 32-bit integers.
  • Unit_Status_Mode (AV-40) and LatestAlm (IV-5/AV-93) return codes; the source has the code tables.
  • This guide is a subset; Greenheck refers to the unit's full BMS points list for detailed alarms and trending.

How many BACnet points does the Greenheck IVE Indoor Energy Recovery Ventilator (BACnet) have?

Which Greenheck IVE Indoor Energy Recovery Ventilator (BACnet) BACnet points are writable?

42 of the 95 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
