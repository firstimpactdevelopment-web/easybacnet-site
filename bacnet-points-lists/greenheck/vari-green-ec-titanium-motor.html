Short answer

The Vari-Green (EC Titanium) motor has an integrated drive with an RS-485 port that speaks Modbus RTU or BACnet MS/TP (not both at once). BACnet is enabled with parameter 1103 = 9. The object list is short: run, direction and fault-reset commands, a speed setpoint in % of maximum speed, ramp and speed-limit settings, and readings for speed, frequency, current, power, temperature, energy, run hours, faults and I/O states.

BMS integration notes: Greenheck Vari-Green Motor (EC Titanium) BACnet MS/TP

Integration in brief

Set 1103 Primary Command Source Mode = 9 for BACnet MS/TP, set the address, baud rate and watchdog in 5302 and the device instance in 5840/5899. Command BV 10 run/stop and write the speed setpoint to AV 14 (% of maximum speed); reset faults with BV 14. Read BV 0, AV 1, AV 4, BV 2 and AV 16.

Enable & remote start

Set 1103 PRIMARY COMMAND SOURCE MODE = 9 (BACnet MS/TP; ramps from 2202/2203). Parameter 9902 then decides whether the speed reference and start/stop come from the network or the terminal strip. BV 4 shows Auto when the drive is under terminal or BACnet control.

Heartbeat & communication loss

Parameter 5302 includes a watchdog timeout of 0 (disabled), 30, 100, 1000 or 3000 ms. A 't' suffix trips the drive on loss of communication (fault F0010); an 'r' suffix coasts the motor to a stop without a trip.

Network setup

  • 5302 serial settings: drive address 0-63 (default 1), baud 9.6-115.2 kbps (default 38.4 kbps), watchdog timeout.
  • BACnet MS/TP format is 8N1; Modbus RTU and BACnet MS/TP cannot run at the same time.
  • Device instance is set with 5840 (Device Object ID Low) and 5899 (Device Object ID High); the manual's formula reads 5840 x 65536 + 5899.
  • 5841 BACnet maximum masters 0-127; takes effect after a reboot.
  • Connect RS-485 on the RJ45 port (pins 7 -, 8 +) or terminals T10 (+) / T11 (-); a third 0 V wire to T9 is recommended.

Watch out for

  • AV 14 is a percentage of maximum speed, not Hz or rpm.
  • Min/max speed, ramps and max current (AV 23-33) change motor settings; don't write them cyclically.
  • BV names are shifted against their descriptions in the manual; check BV 4-8 on a live unit.
  • The RJ45 port is RS-485, not Ethernet.

Integration notes

  • Object dictionary from appendix B.6 of the manual (pages 103-104).
  • The manual prints BI 8 twice: DI3 - Monitor and DI4 - Monitor (status of digital input 4). Only the DI3 row is listed to avoid a duplicate object ID; check where DI4 sits on a live unit.
  • Several BV names don't match their descriptions: BV 4 'Warning-Monitor' is described as Hand/Auto mode, BV 5 'Ready-Monitor' as the overload warning, and BV 7 and BV 8 are both named 'At-Setpoint-Monitor' (ready status and at-setpoint status). Names, descriptions and state texts are listed as printed.
  • BO 0 and BO 5 are marked read-only in the table.
  • AV 0 Output-RPM reads 0 unless the motor rated speed is entered in parameter 9908. AV 8 is printed with unit 'kW/h' and listed here as kWh.

Questions about the Greenheck Vari-Green Motor (EC Titanium) BACnet MS/TP

How many BACnet points does the Greenheck Vari-Green Motor (EC Titanium) BACnet MS/TP have?

This list has 45 BACnet objects: 2 analog inputs, 24 analog values, 5 binary inputs, 2 binary outputs, 12 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Greenheck Vari-Green Motor (EC Titanium) BACnet MS/TP BACnet points are writable?

10 of the 45 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Greenheck Vari-Green Motor (EC Titanium) BACnet MS/TP BACnet documentation?

The source is Vari-Green Motor (EC Titanium) single/three-phase User Manual (MN448), revision 01/2022, published free by Greenheck at https://webcontent.greenheck.com/atg-cms-v2-prod/docs/default-source/resource-library/installation-manuals/fans/single_threephase_varigreenmotor_usermanual_jan2022.pdf.

What are the minimum BACnet points to integrate the Greenheck Vari-Green Motor (EC Titanium) BACnet MS/TP?

Start with BV 10 RUN-STOP-Command (Run/stop command (1 = run)); AV 14 Input-Reference-1 (Speed setpoint, % of maximum speed); BV 14 Fault-Reset-Command (Fault reset (1 = reset)); BV 0 Run / Stop-Monitor (Running status); AV 1 Output-Freq (Output frequency in Hz); AV 4 Output-Current (Motor amps); BV 2 OK-Fault-Monitor (Drive fault status); AV 16 Active-Fault (Active fault code).

How do I enable BMS control of the Greenheck Vari-Green Motor (EC Titanium) BACnet MS/TP?

Set 1103 PRIMARY COMMAND SOURCE MODE = 9 (BACnet MS/TP; ramps from 2202/2203). Parameter 9902 then decides whether the speed reference and start/stop come from the network or the terminal strip. BV 4 shows Auto when the drive is under terminal or BACnet control.

Does the Greenheck Vari-Green Motor (EC Titanium) BACnet MS/TP need a BACnet heartbeat or have a communication timeout?

Parameter 5302 includes a watchdog timeout of 0 (disabled), 30, 100, 1000 or 3000 ms. A 't' suffix trips the drive on loss of communication (fault F0010); an 'r' suffix coasts the motor to a stop without a trip.
