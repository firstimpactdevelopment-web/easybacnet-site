Short answer

Greenheck's DOAS units use a factory controller that can be licensed for BACnet. The BMS mainly enables the unit, commands occupancy, resets alarms and adjusts temperature, dehumidification and airflow setpoints; it can also take over fan speeds, the outdoor air damper and sensor values. A BMS watchdog must be written regularly whenever the BMS does that, or the unit alarms and returns to local control. The points list is the same on every unit regardless of heating and cooling options.

BMS integration notes: Greenheck Dedicated Outdoor Air Systems (DOAS) - BACnet

Integration in brief

With BACnet licensed and set up on the controller, the minimum integration is to enable the unit (BV-2) and command occupancy (BV-3). Add alarm reset and global alarm monitoring, plus the temperature setpoint if needed. If the BMS will also drive fan speeds or the outdoor air damper, or send sensor values, it must keep writing the BMS watchdog, or the unit alarms and returns to local control.

Enable & remote start

BV-2 System_Enable enables or disables the unit from the BMS; in disabled mode some protective sequences may still run. By default occupancy is expected from BV-3 BMS_Occupancy_Command. The controller can instead be set to an internal schedule, always occupied/unoccupied, or a digital input. With warm-up/cool-down enabled, the unit recirculates after the occupied command until it reaches setpoint or the timer (default 30 min) ends.

Heartbeat & communication loss

BV-1 BMS_Watchdog must be written to True (1) regularly whenever the BMS commands fan speeds or damper positions or sends sensor values. If it stays False longer than the Timeout Delay (15 minutes, adjustable), an alarm is raised and the controller falls back to local control and local sensor values. BV-24 shows watchdog status. If the relinquish-default-on-comm-loss option is enabled, priority arrays are cleared 5 minutes after the watchdog goes inactive.

Sensors & values from the BMS

For each sensor, set its source-select binary to BMS (BV-7 to BV-16, e.g. BV-8 Outside_Temp_Source_BMS, BV-16 Space_Temp_Source_BMS). Then write the matching *_from_BMS analog (AV-26 to AV-35, e.g. AV-27 outside temp, AV-35 space temp, AV-33 space RH, AV-30/31 space CO2). The watchdog must be satisfied; if it isn't, the controller reverts to the local sensor (if installed and valid) or to local control. Fan speeds and the outdoor air damper are taken over the same way with BV-17/18/19 plus AV-36/37/38.

Network setup

  • The controller must have BACnet licensed and configured; otherwise get the license/config files from the rep (alarm 82 = BACnet license not installed).
  • BBMD and foreign-device registration, relinquish defaults and COV increments are in the Advanced BACnet Settings menu (Main Menu > Control Variables > Advanced > Network Settings > Advanced Settings).
  • COV increments are shared by all objects with the same engineering unit.
  • For BMS supply-air reset, set the reset mode (IV-1) to No Reset and write the temperature setpoint (AV-1).

Watch out for

  • The points list is the same on every unit, so points for options a unit lacks are meaningless on it.
  • Writing too often triggers alarm 32 (BMS Frequent Writes); reduce write traffic.
  • Status bits are packed into IV-6 to IV-11; use the 16-bit AV copies (AV-94 to AV-105) if the BMS can't read 32-bit integers.
  • Unit_Status_Mode (AV-40) can rotate between active modes every 3 seconds.
  • Without Return to Default enabled, the controller boots after a power loss with the last written values.

Integration notes

  • BACnet must be licensed/enabled on the controller; without it the unit won't respond.
  • Write BV-1 BMS_Watchdog = Active regularly; after the timeout (default 15 min) the unit alarms and falls back to local values.
  • To use a BMS sensor value, set the matching *_Source_BMS binary to BMS, then write the *_from_BMS analog.
  • Status bits (cooling/heating on, compressors, furnace stages, filter alarm, wheel, preheat, etc.) are packed into IV-6 to IV-11, with 16-bit AV copies.
  • Unit_Status_Mode (AV-40) and LatestAlm (IV-5/AV-93) return codes; the source has the code tables.
  • The guide only describes BBMD setup for IP networks; it does not say whether BACnet MS/TP is offered. Same controller family and object layout as the Greenheck IVE guide.

How many BACnet points does the Greenheck Dedicated Outdoor Air Systems (DOAS) - BACnet have?

Which Greenheck Dedicated Outdoor Air Systems (DOAS) - BACnet BACnet points are writable?

45 of the 109 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
