Greenheck Kitchen Controls (GKC) main board BACnet points list

Updated 7 November 2026

Short answer

Greenheck Kitchen Controls (GKC) run kitchen hood exhaust and supply fans, hood lights, hood wash and temperature or optic-based demand control. The main board talks BACnet MS/TP directly on J23; BACnet IP panels get a Modbus RTU to BACnet IP gateway. The list covers room, hood and supply temperatures, optic opacity, fan VFD data, zone and fan commands, hood light and wash commands, tuning values and packed status/fault words.

This page lists 276 BACnet objects for the Greenheck Kitchen Controls (GKC) main board — 135 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Greenheck’s own free documentation, linked below.

BMS integration notes: Greenheck Kitchen Controls (GKC) main board

Integration in brief

Turn zone fans on and off with BV 0-7 (Fans - Zone n) and hood lights with BV 8-24. Read hood and room temperatures (AI 0-8 and the HCB AIs), fan VFD frequency, and the Faults word (instance 11) for alarms. Hood wash can be started per hood control board with BV 38-53.

Enable & remote start

BV 0-7 turn zone fans on and off from the BMS. Each zone status word has a 'fan on via BMS' bit, so the BMS can see when its command is holding the fans on.

Network setup

  • BACnet MS/TP: default Device Instance 77000, MAC 0, Max Master 127, Max Info Frames 20; baud 9600-115200 (default 9600). Set under BMS Settings.
  • BACnet IP panels use a ProSoft Modbus RTU to BACnet IP QuickServer gateway; leave the main board at Modbus address 1 and 9600 baud. The gateway default IP is 192.168.2.101.
  • Wire BACnet MS/TP to the main board J23 terminals with shielded twisted pair.

Watch out for

  • Status and fault words must be unpacked bit by bit, and the bit order on MS/TP is the reverse of the IP gateway.

Integration notes

  • The list has objects for the full capacity (8 zones, 8 exhaust fans, 4 supply fans, 16 hood control boards); map only what the panel has.
  • Instances 0-11 (zone status, VFD fault, relay status and fault words) are BitString Value objects (BACnet type 39) on BACnet MS/TP; through the BACnet IP gateway the guide says they are Analog Values. The site has no BitString type, so they are listed as Other. Bit order is reversed between the two (bit 0 left-most on MS/TP, right-most over IP).
  • Access is from the R / R/W column of the BACnet points list.

Questions about the Greenheck Kitchen Controls (GKC) main board

How many BACnet points does the Greenheck Kitchen Controls (GKC) main board have?

This list has 276 BACnet objects: 129 analog inputs, 80 analog values, 55 binary values, 12 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Greenheck Kitchen Controls (GKC) main board BACnet points are writable?

135 of the 276 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Greenheck Kitchen Controls (GKC) main board BACnet documentation?

The source is Kitchen Controls Installation, Operation and Maintenance Manual - BACnet Points List (484600 Rev. 6), revision 2026-10, published free by Greenheck at https://content.greenheck.com/public/DAMProd/Original/10012/484600KitchenControls_iom.pdf.

What are the minimum BACnet points to integrate the Greenheck Kitchen Controls (GKC) main board?

Start with BV 0 Fans - Zone 1 (Zone 1 fans on/off (1 = on)); BV 8 Hood Lights - Main Board (Main board hood lights on/off); BV 25 Max Fan Enable (Max fan (full speed) on/off); AI 0 MB Room Sensor Temp (Room temperature at the main board); AI 1 MB Hood Temp Sensor 1 (Hood temperature sensor 1); Other 0 Zone 1 Status (Zone 1 status bits: why the fans are on); Other 11 Faults (Fault bits; first bit = any fault).

How do I enable BMS control of the Greenheck Kitchen Controls (GKC) main board?

BV 0-7 turn zone fans on and off from the BMS. Each zone status word has a 'fan on via BMS' bit, so the BMS can see when its command is holding the fans on.
