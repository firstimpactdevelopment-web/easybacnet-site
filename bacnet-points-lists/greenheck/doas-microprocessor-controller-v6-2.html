Greenheck DOAS Microprocessor Controller v6.2 (legacy points list) BACnet points list

Updated 6 November 2026

Short answer

This is the points list of Greenheck's DOAS controller at program v6.2, which uses different object numbering from the later DOAS programs (for example DOAS v9.4 and DOAS_10.006). It offers BACnet MS/TP, BACnet IP, Modbus RTU and Modbus TCP. The BMS can enable the unit, command occupancy, reset alarms, write setpoints, send sensor values and take over fans and the outdoor air damper through source-select points, with a watchdog. A long list of read-only binary values reports individual alarms, outputs and status.

BMS integration notes: Greenheck DOAS Microprocessor Controller v6.2 (legacy points list)

Integration in brief

Enable the unit with BV 2 Master System Enable and command occupancy with BV 3, write the main temperature setpoint AV 1 and reset alarms with BV 4. Keep the BV 1 watchdog alive if the BMS sends sensor values or controls fans or the damper. Monitor unit status (AV 40), supply temperature, the general alarm BV 24 and the most recent alarm IV 7.

Enable & remote start

BV 2 Master System Enable enables or disables the unit; BV 3 Occupancy Command sets occupancy (1 = Unoccupied).

Heartbeat & communication loss

The BMS watchdog must be toggled by the BMS within the timeout delay whenever the BMS replaces a hardwired sensor. If the timer expires the controller alarms and falls back to its hardwired sensors until the BMS returns.

Sensors & values from the BMS

Set the sensor's source-select BV to BMS (1), then write the matching 'from BMS' AV; fans and the outdoor air damper are taken over the same way (e.g. BV-59 with AV-136 for the damper).

Network setup

  • BMS protocol and network settings are in the controller's Network Settings menu; save and reboot after changes.

Watch out for

  • Shutdown alarms set System Enable false and keep the unit off until reset.
  • Numbering is not compatible with the later DOAS programs (v9.4, DOAS_10.006).

Questions about the Greenheck DOAS Microprocessor Controller v6.2 (legacy points list)

How many BACnet points does the Greenheck DOAS Microprocessor Controller v6.2 (legacy points list) have?

This list has 295 BACnet objects: 30 analog inputs, 85 analog values, 14 binary inputs, 160 binary values, 6 integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Greenheck DOAS Microprocessor Controller v6.2 (legacy points list) BACnet points are writable?

60 of the 295 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Greenheck DOAS Microprocessor Controller v6.2 (legacy points list) BACnet documentation?

The source is Microprocessor Controller for DOAS - Reference Guide (DOAS v6.2) (485175), revision 2021-04 (Rev. 1; program version date 7/21), published free by Greenheck at https://webcontent.greenheck.com/atg-cms-v2-prod/docs/default-source/resource-library/installation-manuals/dedicated-outdoor-air-systems/485175_-doascontroller_iom.pdf.

What are the minimum BACnet points to integrate the Greenheck DOAS Microprocessor Controller v6.2 (legacy points list)?

Start with BV 2 Master System Enable (Enables or disables the unit); BV 3 Occupancy Command (Occupancy; 1 = Unoccupied, 0 = Occupied); AV 1 Main Temperature Setpoint - Supply, Space, or Return (Main temperature setpoint); BV 1 BMS Watchdog Command (Heartbeat when BMS controls fans or sensors); BV 4 Alarm Reset Command (Remote alarm reset); AV 40 Unit Status (Current operating mode code); AI 45 Supply Temperature (Supply (discharge) air temperature); BV 24 General Alarm Status (Any (or shutdown) alarm active); IV 7 Most Recent Alarm (Most recent alarm code).

How do I enable BMS control of the Greenheck DOAS Microprocessor Controller v6.2 (legacy points list)?

BV 2 Master System Enable enables or disables the unit; BV 3 Occupancy Command sets occupancy (1 = Unoccupied).

Does the Greenheck DOAS Microprocessor Controller v6.2 (legacy points list) need a BACnet heartbeat or have a communication timeout?

The BMS watchdog must be toggled by the BMS within the timeout delay whenever the BMS replaces a hardwired sensor. If the timer expires the controller alarms and falls back to its hardwired sensors until the BMS returns.

Can the BMS supply sensor values to the Greenheck DOAS Microprocessor Controller v6.2 (legacy points list)?

Set the sensor's source-select BV to BMS (1), then write the matching 'from BMS' AV; fans and the outdoor air damper are taken over the same way (e.g. BV-59 with AV-136 for the damper).
