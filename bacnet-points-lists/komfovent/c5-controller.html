Komfovent C5 controller BACnet points list

Updated 4 November 2026

Short answer

The Komfovent C5 is the built-in controller of Komfovent air handling units. It speaks BACnet IP on its RJ-45 Ethernet port (no MS/TP). The list has 237 objects: sensor readings as AIs, output signals as AOs, wired contacts as BIs, relay outputs as BOs, alarms as BVs, and all commands, setpoints and function settings as AVs. On/off, modes and enable flags are AVs with numeric codes, not binary or multistate objects.

This page lists 237 BACnet objects for the Komfovent C5 controller — 85 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Komfovent’s own free documentation, linked below.

BMS integration notes: Komfovent C5 controller

Integration in brief

Start and stop the unit with AV 0 Unit On/Off and pick the ventilation mode with AV 2 Mode selection (Comfort1/2, Economy1/2, Special, Program). Each mode has its own supply/extract flow and temperature setpoint AVs. Read AV 1 Current mode, the supply, extract and outdoor temperatures (AI 0-2), the alarm BVs and BO 22 Alarm DOUT; reset alarms by writing 1 to AV 58.

Enable & remote start

AV 0 Unit On/Off switches the unit (0 = off, 1 = on). AV 2 Mode selection picks the operating mode; 6 = Program hands control to the unit's own schedule.

Sensors & values from the BMS

AV 73 External room temperature sensor accepts a room temperature from the BMS; a value outside -50..+120 °C disables the override.

Network setup

  • Factory network settings: IP 192.168.0.50, mask 255.255.0.0, BACnet port 47808, BACnet ID 1100.
  • Change them in the controller web server (Settings > Connectivity) or on the C5.1 panel (Settings > Air handling unit > Connectivity).
  • Komfovent recommends a polling interval of at least 1 second.
  • AV 83 enables BBMD (BACnet Broadcast Management Device) on the controller.

Watch out for

  • Commands and enable flags are AVs holding 0/1 or mode codes, not BVs or MVs.
  • Flow setpoint units follow AV 72; check it before writing flows.
  • AV 59-61 run-hour counters and AV 67-71 clock values are writable; don't write them cyclically.
  • AV 84 starts a heat exchanger calibration when 1 is written.

Integration notes

  • AIs, AOs, BIs, BOs and BVs are read-only; most AVs are R/W.
  • Flow AVs and AIs use the unit chosen in AV 72 Flow units (m3/h, l/s, m3/s or Pa).
  • AQC, OOD and REC setpoints take ppm, % or °C depending on the air quality sensor type fitted.
  • AV numbers have gaps by section: function settings use 0-57 and 77-90; alarm reset, counters and user settings use 58-76, 82 and 83.
  • Zone 1 / Zone 2 objects only matter when the extra zones are configured.

Questions about the Komfovent C5 controller

How many BACnet points does the Komfovent C5 controller have?

This list has 237 BACnet objects: 24 analog inputs, 18 analog outputs, 91 analog values, 17 binary inputs, 32 binary outputs, 55 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Komfovent C5 controller BACnet points are writable?

85 of the 237 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Komfovent C5 controller BACnet documentation?

The source is BACnet Connection C5 - Installation and Service Manual (BACnet-C5_25-07), revision 2025-07, published free by Komfovent at https://komfovent.com/en/downloads/Bacnet_connection_C5_EN.pdf.

What are the minimum BACnet points to integrate the Komfovent C5 controller?

Start with AV 0 Unit On/Off (Unit on/off command (1 = on)); AV 2 Mode selection (Ventilation mode command, 1-6); AV 5 Comfort1 Setpoint (Comfort1 supply temperature setpoint); AV 58 Actual alarms reset (Write 1 to reset current alarms); AV 1 Current mode (Active mode (0 = off/standby)); AI 0 Supply air temperature (Supply air temperature); AI 1 Extract air temperature (Extract air temperature); AI 2 Outdoor air temperature (Outdoor air temperature); BO 22 Alarm DOUT (Common alarm output (1 = alarm)).

How do I enable BMS control of the Komfovent C5 controller?

AV 0 Unit On/Off switches the unit (0 = off, 1 = on). AV 2 Mode selection picks the operating mode; 6 = Program hands control to the unit's own schedule.

Can the BMS supply sensor values to the Komfovent C5 controller?

AV 73 External room temperature sensor accepts a room temperature from the BMS; a value outside -50..+120 °C disables the override.

How do I check these points on the real C5 controller?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
