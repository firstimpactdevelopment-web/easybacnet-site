Short answer

The GLT option turns on BACnet IP (or Modbus TCP) on the Ethernet port of the ait-deutschland heating and heat pump controller used in Novelan heat pumps. Every data point is an Analog Input, Multistate Input, Binary Input or Accumulator; the writable ones also appear as Analog Values or Multistate Values with their own instance numbers (outdoor temperature, return and mixing-circuit setpoints, DHW setpoint, heating curves, operating modes, compressor release) and Binary Outputs reset faults or force pumps on. The guide lists data point names in German.

This page lists 144 BACnet objects for the ait-deutschland Novelan heat pump controller GLT (BACnet IP) — 37 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of ait-deutschland’s documentation hosted by ioBroker forum, not by ait-deutschland itself, so treat it as unofficial.

BMS integration notes: ait-deutschland Novelan heat pump controller GLT (BACnet IP)

Integration in brief

Release the heat pump with MV 1, set the heating and hot water modes (MV 2 / MV 3) and write setpoints such as the DHW setpoint (AV 6) or a mixing circuit flow setpoint. Read the operating state (MI 1), flow and return temperatures, and the two fault BIs; reset latching faults with BO 1.

Enable & remote start

MV 1 (Sperre / Freigabe Wärmepumpe) locks the heat pump or releases one or two compressors; the operating modes for heating, DHW, mixing circuits, cooling, ventilation and pool are set with MV 2-10.

Sensors & values from the BMS

The outdoor temperature can be written to AV 1 (Außentemperatur); the guide says to disconnect the heat pump's own outdoor sensor when doing so.

Network setup

  • BACnet IP on UDP 47808 over the controller's Ethernet port; IP settings via DHCP server, DHCP client or manual entry on the controller (Service > Systemsteuerung).
  • Device name, device ID, model name and location are set with the Novelan GLT Tool; the device ID must be unique on the network.
  • A wrong broadcast address stops the heat pump being found over BACnet IP.

Watch out for

  • Software older than V1.74/V2.74/V3.76/V4.76 supports only BACnet IP, not Modbus TCP; switching between them needs the GLT Tool.
  • BO 1 Fehlerreset returns to 0 by itself after a 1 is written.

Integration notes

  • The guide gives one table per object type with an Analog Input / Analog Value (or Multistate Input / Value) instance pair per row; AV and MV objects are the writable copies.
  • Names are the guide's German data point labels; descriptions are ours in English. Abbreviations follow the guide's list (HUP heating pump, BUP DHW pump, ZWE additional heat generator, EVU utility lock-out).
  • Points shaded in the guide need a comfort / expansion or ventilation board; points marked * apply to units with LIN or Modbus parts. Values not shown on the controller's display are invalid.
  • There is no MI 5 / MV 4 or BO 2 in the guide.
  • Resolution is 0.1 for temperatures, 0.01 for pressures and power.
  • GLT runs for 4 hours as a test after setup with the Novelan GLT Tool and is enabled permanently with a licence from the supplied USB dongle.

Questions about the ait-deutschland Novelan heat pump controller GLT (BACnet IP)

How many BACnet points does the ait-deutschland Novelan heat pump controller GLT (BACnet IP) have?

This list has 144 BACnet objects: 43 analog inputs, 15 analog values, 30 binary inputs, 13 binary outputs, 10 multi-state inputs, 9 multi-state values, 24 accumulators. The exact set on a given unit depends on its firmware, installed options and configuration.

Which ait-deutschland Novelan heat pump controller GLT (BACnet IP) BACnet points are writable?

37 of the 144 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

What are the minimum BACnet points to integrate the ait-deutschland Novelan heat pump controller GLT (BACnet IP)?

How do I enable BMS control of the ait-deutschland Novelan heat pump controller GLT (BACnet IP)?

MV 1 (Sperre / Freigabe Wärmepumpe) locks the heat pump or releases one or two compressors; the operating modes for heating, DHW, mixing circuits, cooling, ventilation and pool are set with MV 2-10.

Can the BMS supply sensor values to the ait-deutschland Novelan heat pump controller GLT (BACnet IP)?

The outdoor temperature can be written to AV 1 (Außentemperatur); the guide says to disconnect the heat pump's own outdoor sensor when doing so.
