Updated 12 November 2026

Short answer

CaptiveAire's HVLS control package runs up to ten VFD-driven fans in up to ten groups, switching them from room temperature, HMI buttons or the BMS. A factory-wired Protocessor gateway gives BACnet IP or BACnet MS/TP access to temperatures, per-fan VFD data, group settings and fault flags. With DDC mode enabled the BMS can put each group in DDC Auto or DDC Manual, switch groups on and off, and set occupied speed and fan direction.

BMS integration notes: CaptiveAire HVLS and General Ventilation Fan Control (ECPM03, Protocessor BACnet)

Integration in brief

Enable DDC mode on the HVLS controller so start and stop commands come over the network. For each fan group, write ModeG to DDC Auto (the controller runs the fans from its temperature sensors) or DDC Manual, and in Manual write ButtonG to switch the group on or off. SpeedF sets the occupied speed in Hz; monitor StateVFD, frequency and the fault flags.

Enable & remote start

Set the controller's DDC Mode menu to ENABLED; then all fan start and stop commands come from the network. Per group, ModeG selects DDC Auto (temperature control) or DDC Manual (ButtonG on/off).

Network setup

  • Protocessor default device instance 50000; MS/TP MAC 127 and 38400 baud by default, set in the Protocessor web configurator (Configure > Profile Configuration).
  • Protocessor default IP 192.168.1.24; change it under Diagnostics and Debugging > Setup > Network Settings, then restart.
  • The Protocessor is factory set to one field protocol; objects are reachable only on that port.

Watch out for

  • Each change in the Protocessor web configurator needs its own Submit and restarts the gateway.
  • Group settings use one implied decimal (725 = 72.5 °F).
  • Objects for fans or groups that are not installed still appear in the list.

Integration notes

  • The table has no read/write column. The Analog Variable and Binary Value objects carry LON input variables and are shown as writable; all inputs are read-only.
  • The manual's 'Object ID' numbers run 1-307 across all object types; they are used here as the instance of the printed type ('Analog Variable' listed as AV).
  • Per-fan objects are F1-F10 and per-group objects G1-G10; objects for fans or groups that are not installed have no meaning.
  • Group settings (modulation band, min/max frequency, activation temperature) are printed with one implied decimal, e.g. 72.5 °F is read as 725. The other temperature and frequency points say '1 decimal precision' without giving the scaling.
  • The manual prints no units for the room/HMI temperature points; the group settings are in °F.
  • VFD fault code meanings are in the manual's VFD fault list (0 = no fault).

Questions about the CaptiveAire HVLS and General Ventilation Fan Control (ECPM03, Protocessor BACnet)

How many BACnet points does the CaptiveAire HVLS and General Ventilation Fan Control (ECPM03, Protocessor BACnet) have?

This list has 307 BACnet objects: 175 analog inputs, 20 analog values, 92 binary inputs, 20 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which CaptiveAire HVLS and General Ventilation Fan Control (ECPM03, Protocessor BACnet) BACnet points are writable?

40 of the 307 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official CaptiveAire HVLS and General Ventilation Fan Control (ECPM03, Protocessor BACnet) BACnet documentation?

The source is High Volume Low Speed (HVLS) Fan - HVLS and General Ventilation Fan Control Software - Installation, Operation, and Maintenance Manual (A0025729), revision August 2026 Rev 26, published free by CaptiveAire at https://www.captiveaire.com/manuals/hvls/hvls-oim.pdf.

What are the minimum BACnet points to integrate the CaptiveAire HVLS and General Ventilation Fan Control (ECPM03, Protocessor BACnet)?

Start with BV 288 ModeG1 (Group 1: 0 = DDC Auto, 1 = DDC Manual); BV 298 ButtonG1 (Group 1 on/off in DDC Manual (1 = on)); AV 268 SpeedF1 (Group 1 occupied fan speed, Hz); AI 55 StateVFD1 (Fan 1 run state and reason code); AI 45 FrequencyF1 (Fan 1 VFD output frequency, Hz); AI 1 TempSensor1 (Room temperature, sensor 1); AI 85 VFDFaultF1 (Fan 1 VFD fault code (0 = no fault)); BI 175 EmergencyShutdownG1 (Group 1 hard-wired emergency shutdown active).

How do I enable BMS control of the CaptiveAire HVLS and General Ventilation Fan Control (ECPM03, Protocessor BACnet)?

Set the controller's DDC Mode menu to ENABLED; then all fan start and stop commands come from the network. Per group, ModeG selects DDC Auto (temperature control) or DDC Manual (ButtonG on/off).
