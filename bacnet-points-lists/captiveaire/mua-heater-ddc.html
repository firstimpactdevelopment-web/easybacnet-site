CaptiveAire MUA Heater DDC (Protocessor BACnet) BACnet points list

Updated 16 October 2026

Short answer

CaptiveAire make-up air heaters with the DDC package expose their unit-board data through a factory gateway for BACnet IP or MS/TP. The 161 objects include DDC heat/cool/blower commands, tempering and activation modes, occupied/unoccupied setpoints and blower/damper limits, a 42-point on-board schedule, sensor readings, occupancy flags and six active fault codes. As with the Paragon RTUs, the preferred BMS approach is setpoints plus the DDC Occupied Override binary rather than the raw DDC commands.

This page lists 161 BACnet objects for the CaptiveAire MUA Heater DDC (Protocessor BACnet) — 118 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from CaptiveAire’s own free documentation, linked below.

BMS integration notes: CaptiveAire MUA Heater DDC (Protocessor BACnet)

Integration in brief

Enable scheduling once (BV-8), set all on-board schedule slots (AV-61..102) to 1440, then drive occupancy from the BMS with BV-7 DDCOccupiedOverride and let the unit temper to its own setpoints. The guide calls setpoint adjustment plus the occupied override the preferred method; the DDC heat/cool/blower commands are only for jobs where the tempering modes are set to DDC. Monitor HVAC state, occupancy flags, temperatures and the six fault-code AIs.

Enable & remote start

BV-8 SchedulingEnabled must be on and the internal schedule AVs (61-102) all set to 1440 so BV-7 has full control of occupancy. DDC commands (BV-1..5, AV-6) work only with the heat/cool tempering modes (AV-9..12) set to DDC; this disables temperature-based activation and heat and cool cannot be called together.

Network setup

  • Protocessor default device instance 50000, MS/TP MAC 127, 38400 baud; default IP 192.168.1.24 /255.255.255.0.
  • Web configurator login admin/admin, or the password printed by the gateway's Ethernet port; each change needs Submit and a restart.
  • The gateway is factory set to BACnet IP or MS/TP for the job; only that port carries BACnet.

Watch out for

  • Factory setting points (modes, limits) should not be written on a regular basis.
  • SchedulingEnabled only allows scheduling; it is not an occupancy command.
  • Schedule values are minutes after midnight (0-1439); 1440 means no schedule, and both start and end of a set must be 1440.
  • The controller board reboots when some factory settings are changed.

Integration notes

  • Write BV-8 SchedulingEnabled once, set schedule AVs 61-102 to 1440 (no schedule), then use BV-7 DDCOccupiedOverride for occupancy.
  • DDC command points (BV-1..5, AV-6) require the heat/cool tempering modes (AV-9..12) set to DDC (3); heat and cool can't be called together.
  • Factory setting points (modes, limits) should not be written routinely.
  • Temperatures are F or C per the unit's Temp Units setting; the guide gives no engineering units.
  • Fault AIs 137-142 report codes from the guide's DDC fault list.

Questions about the CaptiveAire MUA Heater DDC (Protocessor BACnet)

How many BACnet points does the CaptiveAire MUA Heater DDC (Protocessor BACnet) have?

This list has 161 BACnet objects: 43 analog inputs, 111 analog values, 7 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which CaptiveAire MUA Heater DDC (Protocessor BACnet) BACnet points are writable?

118 of the 161 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official CaptiveAire MUA Heater DDC (Protocessor BACnet) BACnet documentation?

The source is DDC Application Guide for MUA Heater Units, revision 2024-10, published free by CaptiveAire at https://www.captiveaire.com/catalogcontent/fans/sup_ad/doc/ddc-application-guide.pdf.

What are the minimum BACnet points to integrate the CaptiveAire MUA Heater DDC (Protocessor BACnet)?

Start with BV 7 DDCOccupiedOverride (Occupied/unoccupied command from the BMS); BV 8 SchedulingEnabled (Must be on (once) for BV-7 to work); AV 45 DischargeHeatOccSP (Occupied discharge heating setpoint); AI 143 CurrentHvacState (Idle / blower / heating / cooling state); AI 148 CurrentOccupiedStatus (Confirms the occupancy command took effect); AI 121 DischargeStatTemp (Discharge air temperature); AI 154 GasValveOutput (Burner modulation level); AI 137 ActiveFault1Id (First active fault code).

How do I enable BMS control of the CaptiveAire MUA Heater DDC (Protocessor BACnet)?

BV-8 SchedulingEnabled must be on and the internal schedule AVs (61-102) all set to 1440 so BV-7 has full control of occupancy. DDC commands (BV-1..5, AV-6) work only with the heat/cool tempering modes (AV-9..12) set to DDC; this disables temperature-based activation and heat and cool cannot be called together.
