Strato Automation OPENSTAT OS214 / OS214x thermostat, RTU firmware BACnet points list

Updated 12 November 2026

Short answer

The OS214 is a BACnet MS/TP room thermostat with 2 inputs, 1 analog output and 4 binary outputs. In its rooftop unit (RTU) application it runs single-stage RTU, heat pump, economizer and ECM fan presets selected with MSV-127. Setpoints, modes and occupancy are writable; demands, effective setpoints, supply and outdoor temperatures and the PID loops are readable.

BMS integration notes: Strato Automation OPENSTAT OS214 / OS214x thermostat, RTU firmware

Integration in brief

Pick the application with MSV-127, then run the unit from the BMS with the system mode (MSV-3), fan mode (MSV-4), occupancy (BV-5 or MSV-6) and the room setpoint (AV-1). Monitor room temperature, heating and cooling demand and the help message (MSV-100) for alarms.

Enable & remote start

Occupancy can be written to BV-5 (system occupancy schedule); MSV-45 selects where the schedule comes from and MSV-6 forces local, occupied or unoccupied.

Sensors & values from the BMS

MSV-2 and MSV-27/28 select room, outdoor and supply sensor locations; 'External' lets a value come from the network.

Network setup

  • MS/TP address and baud are set in the thermostat's MSTP Config menu (setup menu: hold the two left buttons, then the PIN sequence).
  • Strato recommends writing MSVs and AVs at the default priority (16) and everything else at priority 8 down to 3.

Watch out for

  • Most MSVs are commissioning settings; avoid cyclic writes.
  • Changing a custom output MSV switches MSV-127 to Custom.

Integration notes

  • The guide has no read/write column. Access here follows its tags: Cfg, User and Cmd objects are shown writable, Status objects read-only, and BO/AO objects commandable (the guide lists them for output overrides). BV-5 (Occ_Sch) is tagged Status but shown writable because the guide says it can be written for occupancy.
  • BO and AO descriptions are generated from the MSV-127 preset when BV-4 (Autogenerate I/O descriptions) is On.
  • Changing any of MSV-7, 8, 16, 17, 23, 27, 28, 30, 44, 45 or 65 switches MSV-127 to Custom.
  • Multistate state numbers follow the order the states are printed, starting at 1.
  • The same guide has a separate FCU object list (see the OS214x FCU entry).

Questions about the Strato Automation OPENSTAT OS214 / OS214x thermostat, RTU firmware

How many BACnet points does the Strato Automation OPENSTAT OS214 / OS214x thermostat, RTU firmware have?

This list has 81 BACnet objects: 3 analog inputs, 1 analog output, 32 analog values, 4 binary outputs, 9 binary values, 5 loops, 1 schedule, 26 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Strato Automation OPENSTAT OS214 / OS214x thermostat, RTU firmware BACnet points are writable?

59 of the 81 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

What are the minimum BACnet points to integrate the Strato Automation OPENSTAT OS214 / OS214x thermostat, RTU firmware?
