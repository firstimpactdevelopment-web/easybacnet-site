Short answer

KMTM is RHOSS's plant sequencer for several chillers, heat pumps or multipurpose units on one primary loop, with an optional recovery branch. BACnet comes from a KBM card (BACnet MS/TP) or a KBE / KWEBU1 card (BACnet IP) fitted to the sequencer's pCO controller. The list has plant objects (on/off, season, setpoints, power limit, alarms), sequencer settings, and a block of read-only status, temperature and pressure objects for each unit (Unit 1 to Unit 8 for most blocks; some blocks run to Unit 10).

BMS integration notes: RHOSS KMTM Multi Thermal Manager (MTM) sequencer

Integration in brief

Start and stop the plant with Superv_OnOff (BV 3), pick the season with Cool_Heat_KeyB (BV 4) and write the cooling and heating setpoints (AV 13 / AV 15). Enable supervisor on/off with En_SPV_OnOff (BV 310). Read plant status and the active setpoint, and watch Any_Alarm (BV 5). An optional power limit is set with Power_Request_Limit (AV 11).

Enable & remote start

BV 3 Superv_OnOff switches the plant on or off from the supervisor; En_SPV_OnOff (BV 310) enables on/off from the supervisor. See RHOSS manual H58701 for sequencer settings.

Heartbeat & communication loss

Spv_Offline_Delay (AV 319, seconds) sets how long before the supervisor counts as disconnected, and Spv_Offline_Action (AV 318) picks what the plant does then: 1 = Off, 2 = On, 3 = None.

Network setup

  • KBM (BACnet MS/TP) factory values per RHOSS KBM/KBE manual H58230_C: device instance 77000, MAC 0, 38400 baud, Max Master 127, Max Info Frames 20; change them with the Carel BACset tool.
  • Per the same manual, on the KMTM set Support > Config. BMS (screen Hg02, installer password) to protocol MODBUS EXT, 19200 baud, address 1, no parity, 2 stop bits.
  • The KBM or KBE / KWEBU1 card is fitted to the sequencer's pCO5 / pCO5+ controller.

Watch out for

  • Values are in tenths: divide °C/10, bar/10 and %/10 objects by 10.
  • Setpoint limits (AV 19-26) are writable settings that bound the setpoints; they are not the setpoints.

Integration notes

  • Analog objects are scaled: units printed as °C/10, bar/10 or %/10 mean the value is in tenths (215 = 21.5 °C).
  • Multistate data is carried in AV objects that hold an enumerated value; the state texts are given in states.
  • Per-unit objects are printed for each unit (Unit 1, Unit 2 ...); the unit number is in the description, and the object name repeats with an index.
  • Rows printed as 'Not used' or 'Reserved' with no object name are left out (BV 11, BV 309, AV 12).
  • The alarm code objects use a table of about 600 codes printed at the end of the document; it is not copied here.
  • The guide covers the MTM communication table; see RHOSS manual H58701 for sequencer settings.

Questions about the RHOSS KMTM Multi Thermal Manager (MTM) sequencer

How many BACnet points does the RHOSS KMTM Multi Thermal Manager (MTM) sequencer have?

This list has 1110 BACnet objects: 834 analog values, 276 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which RHOSS KMTM Multi Thermal Manager (MTM) sequencer BACnet points are writable?

182 of the 1110 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the RHOSS KMTM Multi Thermal Manager (MTM) sequencer?

Start with BV 3 Superv_OnOff (Plant on/off from the BMS (1 = On)); BV 310 En_SPV_OnOff (Enables on/off from the supervisor (1 = Yes)); BV 4 Cool_Heat_KeyB (Plant season: 0 = Cooling, 1 = Heating); AV 13 Cooling_Temp_Set1 (Cooling setpoint 1, °C x10); AV 15 Heating_Temp_Set1 (Heating setpoint 1, °C x10); AV 11 Power_Request_Limit (Plant power limit, % x10); BV 7 Reset_Alarm (Alarm reset (1 = Reset)); AV 1 Group_Status (Plant on/off status (1 = Wait, 2 = ON, 3+ = Off cause)); AV 4 Current_Temp_Set (Active primary setpoint, °C x10); BV 5 Any_Alarm (Any active alarm).

How do I enable BMS control of the RHOSS KMTM Multi Thermal Manager (MTM) sequencer?

BV 3 Superv_OnOff switches the plant on or off from the supervisor; En_SPV_OnOff (BV 310) enables on/off from the supervisor. See RHOSS manual H58701 for sequencer settings.

Does the RHOSS KMTM Multi Thermal Manager (MTM) sequencer need a BACnet heartbeat or have a communication timeout?

Spv_Offline_Delay (AV 319, seconds) sets how long before the supervisor counts as disconnected, and Spv_Offline_Action (AV 318) picks what the plant does then: 1 = Off, 2 = On, 3 = None.
