BMS integration notes: Vertiv Liebert SRC (iCOM CMS card)

Integration in brief

Fit a Liebert iCOM CMS card (BACnet IP or MS/TP), give it a unique device instance and let it discover the unit; the objects are then created automatically. Map the on/off and setpoint objects if the BMS controls the unit, and the status, main measurements and event objects for monitoring.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

Questions about the Vertiv Liebert SRC (iCOM CMS card)

How many BACnet points does the Vertiv Liebert SRC (iCOM CMS card) have?

This list has 88 BACnet objects: 24 analog values, 32 binary values, 32 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert SRC (iCOM CMS card) BACnet points are writable?

32 of the 88 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert SRC (iCOM CMS card) BACnet documentation?

The source is Liebert IntelliSlot Modbus/BACnet Reference Guide (Modbus RTU and TCP, BACnet MSTP and IP) (SL-28170), revision 2024-04 (Rev 29), published free by Vertiv at https://www.vertiv.com/49fb41/globalassets/shared/liebert-intellislot-modbus-rtu-reference-guide-SL-28170_0.pdf.

What are the minimum BACnet points to integrate the Vertiv Liebert SRC (iCOM CMS card)?

Start with MV 102 bc01_1 (Unit 1 on/off command); MV 103 bc03_1 (Unit 1 fan speed); MV 101 bs02_1 (Unit 1 state); AV 102 bs03_1 (Unit 1 temperature); BV 101 ba01_1 (Unit 1 communication alarm); BV 104 ba04_1 (Unit 1 error).

How do I check these points on the real Liebert SRC (iCOM CMS card)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
