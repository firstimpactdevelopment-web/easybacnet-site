Short answer

The Liebert CRV in-row cooling reports to a BMS through a Liebert IntelliSlot card (IS-UNITY-DP for BACnet IP or BACnet MS/TP; some units also IS-IPBML). The object list has Binary Values for events, Analog Values for temperatures, humidity, setpoints and run hours, and Multi-state Values for states and control modes. Objects are created on the card when it discovers the unit, so only options fitted to the unit appear.

BMS integration notes: Vertiv Liebert CRV in-row cooling (iCOM v4)

Integration in brief

Fit a Liebert IntelliSlot BACnet card (IS-UNITY-DP for BACnet IP or MS/TP), give it a unique device instance and let it discover the unit; the objects are then created automatically. Map the on/off and setpoint objects if the BMS controls the unit, and the status, main measurements and event objects for monitoring.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

Questions about the Vertiv Liebert CRV in-row cooling (iCOM v4)

How many BACnet points does the Vertiv Liebert CRV in-row cooling (iCOM v4) have?

This list has 203 BACnet objects: 78 analog values, 74 binary values, 51 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert CRV in-row cooling (iCOM v4) BACnet points are writable?

81 of the 203 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert CRV in-row cooling (iCOM v4) BACnet documentation?

Start with MV 160 5143_1 (On/off command (1=off, 2=on)); AV 7 5008_1 (Air temperature setpoint, °C); AV 26 5029_1 (Humidity setpoint, %RH); MV 171 4717_1 (Acknowledge / reset events); MV 147 4706_1 (Run / standby / off state); MV 146 4123_1 (Normal, warning or alarm state); AV 1 5002_1 (Supply air temperature, °C); AV 2 4291_1 (Return air temperature, °C); AV 166 4624_1 (Supply fluid temperature, °C); AV 25 5028_1 (Return air humidity, %RH).

How do I check these points on the real Liebert CRV in-row cooling (iCOM v4)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
