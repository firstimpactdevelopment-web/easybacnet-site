Short answer

The Liebert FPC / PPC power distribution reports to a BMS through a Liebert IntelliSlot card (BACnet IP or BACnet MS/TP). Analog Values carry input, output, panel and branch circuit electrical data, Binary Values carry events and Multi-state Values carry status, breaker states and resets. Panel and branch objects repeat per panel and branch, so the list is long.

BMS integration notes: Vertiv Liebert FPC / PPC power distribution (VPMP controller)

Integration in brief

Fit a Liebert IntelliSlot BACnet card (IS-UNITY-DP for BACnet IP or MS/TP), give it a unique device instance and let it discover the equipment; the objects are then created automatically. Map the status, main measurements and event objects for monitoring.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

Questions about the Vertiv Liebert FPC / PPC power distribution (VPMP controller)

How many BACnet points does the Vertiv Liebert FPC / PPC power distribution (VPMP controller) have?

This list has 269 BACnet objects: 266 analog values, 3 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert FPC / PPC power distribution (VPMP controller) BACnet points are writable?

10 of the 269 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert FPC / PPC power distribution (VPMP controller) BACnet documentation?

The source is Liebert IntelliSlot Modbus/BACnet Reference Guide (Modbus RTU and TCP, BACnet MSTP and IP) (SL-28170), revision 2024-04 (Rev 29), published free by Vertiv at https://www.vertiv.com/49fb41/globalassets/shared/liebert-intellislot-modbus-rtu-reference-guide-SL-28170_0.pdf.

What are the minimum BACnet points to integrate the Vertiv Liebert FPC / PPC power distribution (VPMP controller)?

Start with MV 13 4717_1 (Acknowledge / reset events); MV 12 4123_1 (Normal, warning or alarm state); AV 43 5168_1 (Output load, %); AV 39 4209_1 (Output power, kVA); AV 1 4097_1 (Input voltage, V); AV 27 4201_1 (Output voltage, V); AV 33 4204_1 (Output current, A).
