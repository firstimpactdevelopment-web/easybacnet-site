Short answer

The Liebert CRV4 in-row cooling reports to a BMS through a Liebert IntelliSlot card (IS-UNITY-DP, for BACnet IP or BACnet MS/TP). The object list has Binary Values for events, Analog Values for temperatures, humidity, setpoints and run hours, and Multi-state Values for states and control modes. Objects are created on the card when it discovers the unit, so only options fitted to the unit appear.

BMS integration notes: Vertiv Liebert CRV4 in-row cooling

Integration in brief

Fit a Liebert IntelliSlot BACnet card (IS-UNITY-DP for BACnet IP or MS/TP), give it a unique device instance and let it discover the unit; the objects are then created automatically. Map the on/off and setpoint objects if the BMS controls the unit, and the status, main measurements and event objects for monitoring.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

  • Tables 5.27, 5.28, 5.29, pdf pages 1439-1450 of the 2024 guide (printed page numbers are 4 lower).
  • Object names are Vertiv data IDs (e.g. 5331_1); the description holds the guide's data label. Labels repeated for different sensors or circuits get the group name in brackets.
  • Most temperature objects come in pairs: a °C object and a °F object (name ending _deg_F), usually at instance + 10000.
  • The guide prints the same instance twice for: BV 651 (7552_1 and 7552_1_1); only the first is listed.

Questions about the Vertiv Liebert CRV4 in-row cooling

How many BACnet points does the Vertiv Liebert CRV4 in-row cooling have?

This list has 177 BACnet objects: 74 analog values, 93 binary values, 10 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert CRV4 in-row cooling BACnet points are writable?

22 of the 177 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert CRV4 in-row cooling BACnet documentation?

The source is Liebert IntelliSlot Modbus/BACnet Reference Guide (Modbus RTU and TCP, BACnet MSTP and IP) (SL-28170), revision 2024-04 (Rev 29), published free by Vertiv at https://www.vertiv.com/49fb41/globalassets/shared/liebert-intellislot-modbus-rtu-reference-guide-SL-28170_0.pdf.

What are the minimum BACnet points to integrate the Vertiv Liebert CRV4 in-row cooling?

Start with MV 60 7536_1 (Monitoring on/off (1=on, 2=off)); AV 8 5331_1 (Supply air temperature setpoint, °C); AV 9 5333_1 (Return air temperature setpoint, °C); MV 71 7528_1 (Run / standby / off state); AV 1 5002_1 (Supply air temperature, °C); AV 2 4291_1 (Return air temperature, °C); AV 6 5028_1 (Return air humidity, %RH); AV 487 5078_1_1 (Cooling output, %); AV 423 5077_1_1 (Fan speed, %); AV 457 4096_1 (Input voltage, V).
