Short answer

The Liebert XDC refrigerant chiller is part of a Liebert XD pumped-refrigerant cooling system and reports through a Liebert IntelliSlot card (BACnet IP or BACnet MS/TP). Binary Values carry events, Analog Values carry temperatures, capacities and settings, and Multi-state Values carry states, event control and event type settings. Objects are created when the card discovers the unit.

This page lists 309 BACnet objects for the Vertiv Liebert XDC refrigerant chiller — 144 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Vertiv’s own free documentation, linked below.

BMS integration notes: Vertiv Liebert XDC refrigerant chiller

Integration in brief

Fit a Liebert IntelliSlot BACnet card (IS-UNITY-DP for BACnet IP or MS/TP), give it a unique device instance and let it discover the unit; the objects are then created automatically. Map the on/off and setpoint objects if the BMS controls the unit, and the status, main measurements and event objects for monitoring.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

Questions about the Vertiv Liebert XDC refrigerant chiller

How many BACnet points does the Vertiv Liebert XDC refrigerant chiller have?

This list has 309 BACnet objects: 114 analog values, 91 binary values, 104 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert XDC refrigerant chiller BACnet points are writable?

144 of the 309 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert XDC refrigerant chiller BACnet documentation?

The source is Liebert IntelliSlot Modbus/BACnet Reference Guide (Modbus RTU and TCP, BACnet MSTP and IP) (SL-28170), revision 2024-04 (Rev 29), published free by Vertiv at https://www.vertiv.com/49fb41/globalassets/shared/liebert-intellislot-modbus-rtu-reference-guide-SL-28170_0.pdf.

What are the minimum BACnet points to integrate the Vertiv Liebert XDC refrigerant chiller?

Start with MV 841 5143_1 (On/off command (1=off, 2=on)); MV 876 4717_1 (Acknowledge / reset events); MV 838 4706_1 (Run / standby / off state); MV 837 4123_1 (Normal, warning or alarm state); AV 94 5490_1 (Cooling output, %); BV 458 5113_1_1 (Unit shut down by an event).

How do I check these points on the real Liebert XDC refrigerant chiller?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
