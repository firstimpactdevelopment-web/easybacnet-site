Short answer

The Liebert FDC / FPC / PPC / RDC power distribution reports to a BMS through a Liebert IntelliSlot card (BACnet IP or BACnet MS/TP). Analog Values carry input, output, panel and branch circuit electrical data, Binary Values carry events and Multi-state Values carry status, breaker states and resets. Panel and branch objects repeat per panel and branch, so the list is long.

This page lists 102 BACnet objects for the Vertiv Liebert FDC / FPC / PPC / RDC power distribution (CPM controller) — 4 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Vertiv’s own free documentation, linked below.

BMS integration notes: Vertiv Liebert FDC / FPC / PPC / RDC power distribution (CPM controller)

Integration in brief

Fit a Liebert IntelliSlot BACnet card (IS-UNITY-DP for BACnet IP or MS/TP), give it a unique device instance and let it discover the equipment; the objects are then created automatically. Map the status, main measurements and event objects for monitoring.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

Questions about the Vertiv Liebert FDC / FPC / PPC / RDC power distribution (CPM controller)

How many BACnet points does the Vertiv Liebert FDC / FPC / PPC / RDC power distribution (CPM controller) have?

This list has 102 BACnet objects: 81 analog values, 18 binary values, 3 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert FDC / FPC / PPC / RDC power distribution (CPM controller) BACnet points are writable?

4 of the 102 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert FDC / FPC / PPC / RDC power distribution (CPM controller) BACnet documentation?

The source is Liebert IntelliSlot Modbus/BACnet Reference Guide (Modbus RTU and TCP, BACnet MSTP and IP) (SL-28170), revision 2024-04 (Rev 29), published free by Vertiv at https://www.vertiv.com/49fb41/globalassets/shared/liebert-intellislot-modbus-rtu-reference-guide-SL-28170_0.pdf.

What are the minimum BACnet points to integrate the Vertiv Liebert FDC / FPC / PPC / RDC power distribution (CPM controller)?

Start with MV 13 4717_1 (Acknowledge / reset events); MV 12 4123_1 (Normal, warning or alarm state); AV 107 5187_1 (Panel 1 main voltage X-Y); AV 119 5199_1 (Panel 1 output power, kW); AV 122 5202_1 (Panel 1 load, %); BV 65 5212_1 (Panel 1 summary alarm).
