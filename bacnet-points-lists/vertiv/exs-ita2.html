Short answer

The Liebert EXS / ITA2 UPS reports to a BMS through a Liebert IntelliSlot card (BACnet IP or BACnet MS/TP). Analog Values carry input, bypass, output and battery measurements, Binary Values carry UPS events, and Multi-state Values carry system status, output source and settings. Objects are created when the card discovers the UPS.

This page lists 271 BACnet objects for the Vertiv Liebert EXS / ITA2 UPS — 16 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Vertiv’s own free documentation, linked below.

BMS integration notes: Vertiv Liebert EXS / ITA2 UPS

Integration in brief

Fit a Liebert IntelliSlot BACnet card (IS-UNITY-DP for BACnet IP or MS/TP), give it a unique device instance and let it discover the equipment; the objects are then created automatically. Map the status, main measurements and event objects for monitoring.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

Questions about the Vertiv Liebert EXS / ITA2 UPS

How many BACnet points does the Vertiv Liebert EXS / ITA2 UPS have?

This list has 271 BACnet objects: 111 analog values, 135 binary values, 25 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert EXS / ITA2 UPS BACnet points are writable?

16 of the 271 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert EXS / ITA2 UPS BACnet documentation?

The source is Liebert IntelliSlot Modbus/BACnet Reference Guide (Modbus RTU and TCP, BACnet MSTP and IP) (SL-28170), revision 2024-04 (Rev 29), published free by Vertiv at https://www.vertiv.com/49fb41/globalassets/shared/liebert-intellislot-modbus-rtu-reference-guide-SL-28170_0.pdf.

What are the minimum BACnet points to integrate the Vertiv Liebert EXS / ITA2 UPS?

Start with MV 63 4123_1 (Normal, warning or alarm state); MV 29 4872_1 (Load on inverter, bypass or battery); AV 53 4150_1 (Estimated battery runtime, min); AV 86 4208_1 (Output power, W); AV 1 4096_1 (Input voltage, V); AV 76 4385_1 (Output voltage, V); AV 82 4204_1 (Output current, A); BV 39 4168_1 (Load is on battery); BV 58 4300_1 (Internal communication lost).
