Short answer

The Liebert EXL UPS reports to a BMS through a Liebert IntelliSlot card (BACnet IP or BACnet MS/TP). Analog Values carry input, bypass, output and battery measurements, Binary Values carry UPS events, and Multi-state Values carry system status, output source and settings. Objects are created when the card discovers the UPS.

BMS integration notes: Vertiv Liebert EXL UPS

Integration in brief

Fit a Liebert IntelliSlot BACnet card (IS-UNITY-DP for BACnet IP or MS/TP), give it a unique device instance and let it discover the equipment; the objects are then created automatically. Map the status, main measurements and event objects for monitoring.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

Questions about the Vertiv Liebert EXL UPS

How many BACnet points does the Vertiv Liebert EXL UPS have?

This list has 575 BACnet objects: 310 analog values, 120 binary values, 145 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert EXL UPS BACnet points are writable?

4 of the 575 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert EXL UPS BACnet documentation?

The source is Liebert IntelliSlot Modbus/BACnet Reference Guide (Modbus RTU and TCP, BACnet MSTP and IP) (SL-28170), revision 2024-04 (Rev 29), published free by Vertiv at https://www.vertiv.com/49fb41/globalassets/shared/liebert-intellislot-modbus-rtu-reference-guide-SL-28170_0.pdf.

What are the minimum BACnet points to integrate the Vertiv Liebert EXL UPS?

Start with MV 117 4123_1 (Normal, warning or alarm state); MV 118 4872_1 (Load on inverter, bypass or battery); AV 58 4150_1 (Estimated battery runtime, min); AV 103 4208_1 (Output power, kW); AV 1 4097_1 (Input voltage, V); AV 96 4201_1 (Output voltage, V); AV 99 4204_1 (Output current, A); BV 40 4168_1 (Load is on battery); BV 155 4300_1 (Internal communication lost).

How do I check these points on the real Liebert EXL UPS?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
