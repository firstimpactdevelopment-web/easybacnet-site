BMS integration notes: Vertiv Liebert iCOM XDM precision cooling

Integration in brief

Fit a Liebert IntelliSlot BACnet card (IS-UNITY-DP for BACnet IP or MS/TP), give it a unique device instance and let it discover the unit; the objects are then created automatically. Map the on/off and setpoint objects if the BMS controls the unit, and the status, main measurements and event objects for monitoring.

Network setup

  • The card needs a unique Device Instance Number; the device object represents the card, not the unit.
  • The cards have no BBMD; IS-UNITY-DP and IS-IPBML support foreign device registration (BBMD address and time-to-live).
  • IS-UNITY-DP adds BACnet MS/TP; IS-WEBADPT and IS-IPBML are BACnet IP only. Check the compatibility table (guide section 1.1.3) for the card your unit supports.

Watch out for

  • Vertiv asks for no more than about two writes and two reads per second on average; do not rewrite setpoints continuously.
  • No segmented responses: large ReadPropertyMultiple requests can fail, so split them.
  • Only data the managed unit actually has is created on the card, so object counts vary by model and options.

Questions about the Vertiv Liebert iCOM XDM precision cooling

How many BACnet points does the Vertiv Liebert iCOM XDM precision cooling have?

This list has 680 BACnet objects: 286 analog values, 206 binary values, 188 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vertiv Liebert iCOM XDM precision cooling BACnet points are writable?

211 of the 680 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vertiv Liebert iCOM XDM precision cooling BACnet documentation?

The source is Liebert IntelliSlot Modbus/BACnet Reference Guide (Modbus RTU and TCP, BACnet MSTP and IP) (SL-28170), revision 2024-04 (Rev 29), published free by Vertiv at https://www.vertiv.com/49fb41/globalassets/shared/liebert-intellislot-modbus-rtu-reference-guide-SL-28170_0.pdf.

What are the minimum BACnet points to integrate the Vertiv Liebert iCOM XDM precision cooling?

Start with MV 115 5143_1 (On/off command (1=off, 2=on)); AV 2844 8143_1_1 (Fluid temperature setpoint, °C); AV 61 5029_1 (Humidity setpoint, %RH); MV 292 4717_1 (Acknowledge / reset events); MV 94 4706_1 (Run / standby / off state); MV 93 4123_1 (Normal, warning or alarm state); AV 19 5002_1_1 (Supply air temperature, °C); AV 31 4291_1 (Return air temperature, °C); AV 2584 4643_1 (Supply fluid temperature, °C); AV 60 5028_1 (Return air humidity, %RH).
