Short answer

Nilan's CTS602 controller speaks Modbus; on these commercial units a built-in Schneider spaceLYnk gateway serves a selected set of registers as a BACnet IP server. The BMS can switch the unit on and off, choose the operating mode and ventilation step, write the room temperature setpoint and cooling, supply-air limit, humidity and CO2 settings, reset alarms and edit the week program. It reads temperatures, pressures, humidity, CO2, fan speeds, relay outputs, digital inputs and the three most recent alarms.

This page lists 121 BACnet objects for the Nilan CTS602 with HMI350T - BACnet (spaceLYnk gateway) — 42 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Nilan’s own free documentation, linked below.

BMS integration notes: Nilan CTS602 with HMI350T - BACnet (spaceLYnk gateway)

Integration in brief

Connect the spaceLYnk gateway to the BACnet IP network, set its IP address and a unique Device ID and enable its BACnet server. Run the unit with Control.RunSet (BV 2481), set Control.ModeSet, Control.VentSet and Control.TempSet, and read back the actual state, temperatures and the alarm status and codes.

Enable & remote start

Control.RunSet (BV 2481) works like the panel ON/OFF keys; with it off, user input functions can still start the unit.

Network setup

  • spaceLYnk default IP 192.168.0.10/24; web login on that address (credentials in the manual).
  • BACnet server, Device ID, write priority, port (default 47808) and BBMD are set under Configurator > Utilities > System > Network > BACnet settings.
  • IP settings are under Configurator > Utilities > System > Network > Interfaces; the gateway reboots after Apply Changes.
  • Disable the KNX connection under Network > KNX connection.

Watch out for

  • The spaceLYnk takes the Relinquish Default from the first read of each object; it cannot be changed later.
  • Only a selected subset of the CTS602 Modbus list is published as BACnet objects.
  • Once a weekly damper self-test day is set (AV 2490) it cannot be switched off.
  • Some points apply only to Comfort, VPR or VPM models (see brackets).

Integration notes

  • The object instance is the number in the '#' column (2305-2582); the manual gives the BACnet type as '2 (AV)' or '5 (BV)'.
  • Square brackets list the unit families marked for a point when it does not apply to all of Comfort, VPR and VPM; T2_Inlet has no family marked.
  • Alarm dates and times are 16-bit words packed in DOS date/time format.
  • Control.ModeSet value 4 (Service) is read-only; the manual says to write Modbus register 1005 instead.
  • Disable the spaceLYnk KNX connection and always answer No to its KNX error box, or several gateways can overwrite each other's setup.
  • Source: Register layout, sections 4.1-4.13, pages 9-16 (121 objects).

Which Nilan CTS602 with HMI350T - BACnet (spaceLYnk gateway) BACnet points are writable?

42 of the 121 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
