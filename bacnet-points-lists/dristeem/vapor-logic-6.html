Short answer

Vapor-logic 6 is the DriSteem humidifier control board. Modbus is standard; BACnet MS/TP (terminal P7) or BACnet/IP (Ethernet) is an option enabled with an unlock code matched to the serial number. One shared object table covers all humidifier types, so many objects only apply to a specific product (marked GTS, XT, HPS, LMH, WM, XV or STS in the name).

This page lists 136 BACnet objects for the DriSteem Vapor-logic 6 — 85 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from DriSteem’s own free documentation, linked below.

BMS integration notes: DriSteem Vapor-logic 6

Integration in brief

Unlock and enable BACnet on the keypad, set the device instance and MS/TP station or IP settings, and set 'BACnet controlled' to Yes under Control via BACnet if the BMS will send the demand. Then write the demand to AV 9 (percent) or AV 8 (mass), or let the controller run its own PID on SpaceRHSetPoint (AV 5), and use MSV 1 RunMode for auto/standby/drain.

Enable & remote start

The humidifier must have its Main Enable input (P20) closed or jumpered (J402 shunt), otherwise the demand is ignored (message BV 60). RunMode (MSV 1) switches between Auto, Local standby, System standby and Manual drain; to let BACnet supply the demand, set Setup > Control via BACnet > BACnet controlled = Yes (default No).

Sensors & values from the BMS

No BMS-writable sensor values are listed: space RH, dew point and duct RH are read-only AIs from the controller's own transmitters. The BMS can instead send a demand (AV 8 FieldbusDemandMass or AV 9 FieldbusDemandPcnt, write-only) and setpoints (AV 5 space RH, AV 6 dew point, AV 7 duct high limit).

Network setup

  • Device instance defaults to 255 (0-4194303); MS/TP station 1, Max masters 127, Max info frames 1.
  • BACnet comm channel defaults to 19200 MS/TP; options run from BACnet IP up to 76800 MS/TP; MS/TP wiring lands on terminal P7.
  • BACnet/IP uses UDP 47808 by default (1024-65535); default IP 192.168.1.195/24, gateway 192.168.1.1, DHCP off.
  • Device instance and comm settings are set from the keypad/display; some items are not available in the web interface.

Watch out for

  • FieldbusDemandMass/Pcnt are write-only; a request above capacity runs the unit at 100 %.
  • Many objects only apply to one humidifier type; unused ones may read 0.
  • WaterUntilADS/WaterUntilService scale differently on Modbus (x100) than on BACnet (1 lb or kg).
  • Retrofitting BACnet needs a purchased unlock code tied to the unit serial number.

Integration notes

  • Object names prefixed with GTS:, HPS:, XT:, WM:, LMH:, STS: or XV: only apply to that humidifier type; where two types share an instance the names are joined with ' / '.
  • BACnet must be purchased/unlocked: Setup > Tank Setup > Communication > BACnet, enter the unlock code, choose the comm channel, then cycle power.
  • Units follow the controller's I-P or SI setting (e.g. lbs/hr or kg/h, °F or °C, psi or bar).
  • Fault and message BVs (BV 5-70) are listed RW in the manual; see the controller's alarm and diagnostics tables for their meaning.

Questions about the DriSteem Vapor-logic 6

How many BACnet points does the DriSteem Vapor-logic 6 have?

This list has 136 BACnet objects: 28 analog inputs, 19 analog values, 14 binary inputs, 73 binary values, 2 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which DriSteem Vapor-logic 6 BACnet points are writable?

85 of the 136 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official DriSteem Vapor-logic 6 BACnet documentation?

What are the minimum BACnet points to integrate the DriSteem Vapor-logic 6?

Start with MV 1 RunMode (Run mode: auto, local/system standby, manual drain); AV 9 FieldbusDemandPcnt (Demand from the BMS in % of capacity); AV 5 SpaceRHSetPoint (Space RH setpoint when Vapor-logic does the control); BV 4 ClearAllActiveAlarms (Write 1 to clear all active faults); AI 1 SpaceRH (Space RH measured by the humidifier); AV 2 SteamOutputPercent (Estimated steam output %); AI 5 SteamDemandPercent (Demand the unit is acting on, % of capacity); BV 60 MainEnableOpen (Main enable input open (demand ignored)); BV 3 ActiveManualClearAlarmsExist (A manual-clear alarm exists).
