BMS integration notes: Danfoss VLT AQUA Drive FC 202 with BACnet/IP MCA 125

Integration in brief

Give the drive a unique instance in 8-70 and an IP address in 12-0*, then write BV:1 RUN/STOP command and AV:1 Input reference 1 (%). Read BV:4, BV:5 and AV:0/AV:5/AV:6 for status, speed, current and power, plus pump points such as BV:49 No flow and BV:50 Dry pump. Use BV:3 to reset trips and set 8-03/8-04 so the drive goes to a known state if the BMS stops writing.

Heartbeat & communication loss

Parameter 8-03 Control Timeout Time (0.5-18000 s, factory 60.0 s) restarts on every write to any AO, AV 1/2/31, BV 1/2/25/26/27 or MSV 1. If the BMS stops writing for longer than that, the drive raises alarm 17 Ctrl.word TO and does whatever 8-04 Control Timeout Function selects (factory Off; options include stop and trip or max speed). 8-05 End-of-Timeout Function (factory Resume setup) sets what happens when writes resume. Danfoss suggests about 3 writes per timeout window.

Sensors & values from the BMS

The BMS can write the PID feedback to AV:31 Bus feedback 1 (parameter 8-94) and the PID setpoint to AV:30 Setpoint 1 (parameter 20-21). Writing AV:31 also restarts the control timeout.

Network setup

  • Device instance is parameter 8-70 (factory 1, range 0-4194302); the MCA 125 DIP switches override it unless they are all On or all Off.
  • IP address: 12-00 selects Manual, DHCP or BOOTP; manual addresses go in 12-01 to 12-03 and need a power cycle.
  • BACnet UDP port is 12-72 (factory 47808).
  • Foreign-device registration: BBMD address 12-75 (0.0.0.0 disables), port 12-76, re-register interval 12-77.
  • 8-74 sends I-Am at power-up only (factory) or about once a minute; 8-75 holds the reinitialize password (default admin).

Watch out for

  • The MCA 125 shares the 8-7* BACnet parameters with the built-in MS/TP port, so connect the drive to only one BACnet network.
  • The guide does not say which drive parameters (control site, control word source, reference source) must be set for bus control; check the drive programming guide.
  • Many objects need an option card (MCB 101/109/113/114/115, MCO) or a CBM license and are dead without it.
  • AV:102-AV:131 are blank until parameter 8-77 maps a drive parameter; unmapped ones are out of service or 'Not Configured'.
  • Warning 34 Fieldbus fault is suppressed for 60 s after power-up; 12-78 can flag a duplicate device instance.
  • The timeout trigger table also lists AV 36 and AV 41, which do not appear in the object tables.

Integration notes

  • Device instance comes from parameter 8-70 (default 1) unless the MCA 125 DIP switches set it.
  • Points marked 'needs MCB/MCO ...' only work when that option is installed.
  • CBM (condition-based monitoring) objects need a CBM license in the drive.
  • AV:102-AV:131 are custom objects; their names and units follow the drive parameters mapped in 8-77.
  • This file lists objects the guide marks for FC 202 or for both drive series; FC 102-only objects (pressure sensor AI/AV set) are left out.
  • MV:4-MV:7 (pressure sensor compare states) carry no drive-series mark in the guide, so they are kept, but their related sensor objects are FC 102-only.

Which Danfoss VLT AQUA Drive FC 202 with BACnet/IP MCA 125 BACnet points are writable?
