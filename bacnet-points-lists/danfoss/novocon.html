Short answer

NovoCon is a bus-connected actuator for Danfoss AB-QM pressure independent valves, talking BACnet MS/TP or Modbus RTU. In digital mode the BMS writes a flow setpoint and reads back flow, position, temperatures (with T1/T2/T3 sensors), power and energy. Many settings objects cover valve selection, units, energy management and ChangeOver6 control.

BMS integration notes: Danfoss NovoCon S / M / L / XL digital actuator

Integration in brief

Pick BACnet (DIP switch 10 or MSV 8, then power cycle), let auto MAC addressing and auto baud find a free address, and set the device instance. Choose the valve type (MSV 3) and Digital control (MSV 9 = 2, the default), set the design flow on AV 30/31, then write the flow setpoint on AV 1. Read flow, position and the alarm summary.

Enable & remote start

MSV 9 Application mode = 2 Digital control (default) makes AV 1 the command. In Analog control (state 1) the 0-10 V input drives the valve instead. MSV 10 commands heating or cooling for central change-over and ChangeOver6 use.

Network setup

  • Protocol from DIP switch or MSV 8 (1 DIP switch, 2 BACnet, 3 Modbus); a power cycle is needed after changing it.
  • MAC address: auto addressing by default (MSV 5 = 1); DIP switches set it manually; AV 7 shows/sets it (1-126).
  • Baud rate: auto detection by default (MSV 6), or 9600-115200 fixed.
  • Device instance range 0-4194302, set through the Device object; Max Master default 127.
  • Segmentation is supported (max APDU 480, 5 segments).

Watch out for

  • Write AV 1 = 0 to shut the valve; the CO6 shut-off state (MSV 10 = 3) is for maintenance only.
  • If AO 0 is written while BV 3 analog feedback is active it must be relinquished (write NULL) to return to feedback.
  • Changing the protocol needs a power cycle.
  • Design flow and units objects are persistent; set them once during commissioning.

Integration notes

  • Objects marked NovoCon S only (CO6 points) or NovoCon M, L/XL only (T3 points) exist only on those models.
  • Several objects allow their units to be changed (L/h, %, GPM, kW, kBTU/h, °C, °F, ohm) via the MSV 20-28 unit objects; the units shown here are the defaults.
  • AV 27 is a bit-weighted sum: BV 10 adds 1, BV 11 adds 2, ... BV 26 adds 65536.
  • The data sheet marks most configuration objects as persistent (stored in non-volatile memory).
  • The device also has a notification class (NC 0) for intrinsic alarm reporting and an averaging object (listed here as Other 0).
  • Multistate objects are printed as MSV in the data sheet.
