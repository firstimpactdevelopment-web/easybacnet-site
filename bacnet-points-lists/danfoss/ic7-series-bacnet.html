BMS integration notes: Danfoss iC7 Series drives with BACnet/IP (OS7BI) or BACnet MS/TP (OS7BN)

Integration in brief

Set Control Place Selection to Advanced Control/Fieldbus Control and the fieldbus reference and start sources to Fieldbus (parameter group 5.5), then write BV 1 RUN/STOP Command and AV 1 Fieldbus Speed Reference 1. Read Running (BV 33), Motor Speed (AV 3), current and power, and the Trip/Warning flags with Fault Status Word 1 for alarms.

Enable & remote start

Parameter group 5.5 Control Places: Control Place Selection (5.5.2.1, also AV 49) must be Advanced Control or Fieldbus Control, with Fieldbus Speed Reference Source and the Advanced Start/Stop/Coast inputs set to Fieldbus.

Heartbeat & communication loss

BACnet Connection Timeout (10.3.7.2.14, default 60 s, 10-18000 s) watches the fieldbus data. The response (10.3.7.2.16) can be set to info, warning, warning with a switch to the alternative control place (10.3.7.2.15), or fault (ramp then coast, or coast).

Network setup

  • Device instance is parameter 10.3.7.2.1 (default 1, range 1-4194303); APDU segment timeout default 5000 ms and APDU timeout default 6000 ms.
  • BACnet/IP: the X1/X2 Ethernet ports carry the fieldbus; BBMD and foreign-device registration are set through the Network Port object.
  • BACnet MS/TP (OS7BN): baud 9600-115200, Max Masters default 32 (0-127) and Max Info Frames default 1 (parameters 10.3.7.2.2-3).
  • A cold start resets drive parameters to factory defaults but keeps the BACnet communication settings.

Watch out for

  • Warm and cold start (ReinitializeDevice) are refused while the drive is running.
  • Control word bits 12-15 (BV 80-83) are user-defined; their function is set by parameters.
  • Fault Reset (BV 3) is printed read-only in the object table, so check on site whether a reset can be written over the network.

Integration notes

  • Taken from section 2.7 BACnet Objects (Tables 9-14) of the iC7 BACnet/IP operating guide; the iC7 BACnet MS/TP operating guide (AQ528743911395en-010101) prints the same 141 objects with the same names and access.
  • The description field gives the drive parameter number and index each object maps to, as printed.
  • Objects for I/O options (General Purpose I/O, Relay Option, Temperature Measurement OC7T0) and for MPC fixed-speed pumps only carry data when that option or function is used. The AI objects with a custom-unit flag take the unit configured for the input.
  • BV 41-50 (sleep, interlock, end of curve, no flow, dry run) are printed without access or parameter; they are listed as read-only.
  • BO 0 and BO 1 are both printed as 'Digital Output Term 15'; names kept as printed.
  • For AV 1-7 Danfoss prints the same parameter numbers, indexes and remarks as AI 20-24 (an apparent copy error in the guide); they are kept as printed, so don't rely on them.

Questions about the Danfoss iC7 Series drives with BACnet/IP (OS7BI) or BACnet MS/TP (OS7BN)

How many BACnet points does the Danfoss iC7 Series drives with BACnet/IP (OS7BI) or BACnet MS/TP (OS7BN) have?

This list has 141 BACnet objects: 7 analog inputs, 2 analog outputs, 59 analog values, 9 binary inputs, 9 binary outputs, 55 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Danfoss iC7 Series drives with BACnet/IP (OS7BI) or BACnet MS/TP (OS7BN) BACnet points are writable?

54 of the 141 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Danfoss iC7 Series drives with BACnet/IP (OS7BI) or BACnet MS/TP (OS7BN) BACnet documentation?

The source is iC7 Series BACnet/IP Operating Guide (BACnet/IP OS7BI) (AQ548636302177en-010101 (136R0460)), revision 2026.04, published free by Danfoss at https://assets.danfoss.com/documents/585354/AQ548636302177en-010101.pdf.

What are the minimum BACnet points to integrate the Danfoss iC7 Series drives with BACnet/IP (OS7BI) or BACnet MS/TP (OS7BN)?

Start with BV 1 RUN/STOP Command (Run/stop command (1 = run)); AV 1 Fieldbus Speed Reference 1 (Input Reference 1) (Speed reference, %); AV 30 Multi Zone Reference 1 (Setpoint 1) (Setpoint 1 when the drive runs its own PID); BV 33 Running (Running status); AV 3 Motor Speed (Motor Actual Speed) (Actual motor speed, %); AV 5 Motor Current (Motor current, A); AV 6 Output Power (Output power, kW); BV 22 Trip (Drive tripped); BV 21 Warning (Active warning); AV 61 Fault Status Word 1 (Fault code word).

How do I enable BMS control of the Danfoss iC7 Series drives with BACnet/IP (OS7BI) or BACnet MS/TP (OS7BN)?

Parameter group 5.5 Control Places: Control Place Selection (5.5.2.1, also AV 49) must be Advanced Control or Fieldbus Control, with Fieldbus Speed Reference Source and the Advanced Start/Stop/Coast inputs set to Fieldbus.

Does the Danfoss iC7 Series drives with BACnet/IP (OS7BI) or BACnet MS/TP (OS7BN) need a BACnet heartbeat or have a communication timeout?

BACnet Connection Timeout (10.3.7.2.14, default 60 s, 10-18000 s) watches the fieldbus data. The response (10.3.7.2.16) can be set to info, warning, warning with a switch to the alternative control place (10.3.7.2.15), or fault (ramp then coast, or coast).
