Short answer

The OPC-F1-BAC card gives the FRENIC-Eco a BACnet MS/TP port. It maps the drive's communication command words (S06/S07), status words (M13/M14) and monitor values to fixed objects: BVs for run/reverse/reset commands, drive status bits and the X-terminal link commands, BIs for the final X-terminal states, BOs for the Y and 30 relay outputs, AVs for frequency, current, voltage, temperatures, hour meters and fault history, plus select/value AV pairs that read or write any parameter by group.

This page lists 82 BACnet objects for the Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP) — 41 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Fuji Electric’s own free documentation, linked below.

BMS integration notes: Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP)

Integration in brief

Fit the card in option port A, set the device instance and baud rate on its DIP switches, set the Y-codes as listed in the guide and set H30 so frequency and run commands come from the link, then restart the drive. Command BV 0 forward run and write the frequency reference to AV 0 (Hz); reset trips with BV 2. Read BV 3, AV 2, AV 30, BV 13 and AV 7.

Enable & remote start

H30 selects where the frequency and run commands come from; the guide's example ('H30=-8') gives both frequency and run command control over BACnet MS/TP. Restart the drive after setting it. BV 14 Communications_Act shows when the link commands are in effect.

Sensors & values from the BMS

AV 1 PID_cmd (S13) takes a PID command from the BMS when the drive's PID is used.

Network setup

  • Device instance: address DIP switches A0-A7 give 37000-37255.
  • Baud rate DIP switches B0-B4: 9600, 19200, 38400, 76800 or auto.
  • Terminating and bias resistor DIP switches are on the card; turn them on at the end of the line if needed.
  • Guide's Y-code settings: Y01 = 1, Y02 = 0, Y03 = 2, Y04 = 4, Y05 = 0, Y06 = 0, Y07 = 1, Y08 = 0, Y09 = 0.01, Y10 = 0; Y11-Y20 the same; Y98 = 0, Y99 = 0.
  • The OPC-F1-RS option card may have to be removed to fit the OPC-F1-BAC.

Watch out for

  • AV 5 Output_Current is in % of rating; use AV 30 Output_Current_Real for amps.
  • Writes through the *_Parameter_Value AVs change drive parameters; don't write them cyclically.
  • BV 4 shares its object name with BV 1; tell them apart by instance.
  • Use either a link command (BV 16-22) or the terminal for each X input, not both.

Integration notes

  • Object list from the Start-Up Guide FECA-IN-112 (pages 6-9); the linked drive registers in the descriptions and the units come from the I/O Map Addendum FECA-TE-124 (https://americas.fujielectric.com/files/Frenic%20Eco%20Bacnet%20I_O%20Map%20Addendum%20FECA-TE-124.pdf).
  • The guide's unit column repeats the object name for the parameter select/value AVs and for AV 42-45; the addendum leaves those units blank, which is used here.
  • BV 4 is printed with the same name as BV 1 (Reverse_Command); the addendum links it to the reverse-rotation status bit (M14 bit 1), so it is a read-only status.
  • BV 16-22 hold the X1-XR terminal states written through the link (S06); BI 0-6 show the terminal states the drive actually uses (M13). Write BV 16-22 to drive a terminal over BACnet MS/TP.
  • Parameter access: write the parameter number to a *_Parameter_Select AV (e.g. AV 14 = 5 for S05), then read or write the matching *_Parameter_Value AV. An unsupported parameter returns 0 with reliability set to fault.

Questions about the Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP)

How many BACnet points does the Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP) have?

This list has 82 BACnet objects: 1 analog output, 46 analog values, 7 binary inputs, 5 binary outputs, 23 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP) BACnet points are writable?

41 of the 82 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP) BACnet documentation?

The source is Fuji BACnet (OPC-F1-BAC) Start-Up Guide for the Fuji Electric FRENIC-Eco VFD (FECA-IN-112 (with I/O Map Addendum FECA-TE-124)), revision 07/2012, published free by Fuji Electric at https://americas.fujielectric.com/files/Fuji_BACnet_Start-Up_Guide%20FECA-IN-112.pdf.

What are the minimum BACnet points to integrate the Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP)?

Start with BV 0 Forward_Command (Run forward command (1 = run)); AV 0 Frequency_Command_Setpt (Frequency reference in Hz); BV 2 Alarm_Reset (Resets a drive alarm); BV 3 Forward_Rotation (Running forward status); AV 2 Frequency_Command (Frequency command in use, Hz (M05)); AV 30 Output_Current_Real (Output current in amps); BV 13 Alarm_Relay (Alarm relay active (drive alarm)); AV 7 Latest_Alarm (Latest alarm code).

How do I enable BMS control of the Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP)?

Can the BMS supply sensor values to the Fuji Electric FRENIC-Eco OPC-F1-BAC (BACnet MS/TP)?
