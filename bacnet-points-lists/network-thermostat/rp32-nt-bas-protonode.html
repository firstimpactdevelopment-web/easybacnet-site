Updated 6 November 2026

Short answer

The NT-BAS ProtoNode reads a Network Thermostat RP32 over Ethernet and presents it as a BACnet MS/TP or BACnet IP device (Modbus, Metasys N2 and LonWorks are also offered). Each thermostat gets its own device instance. The profile exposes mode, fan and setpoint commands, temperatures, stage and override status, clock and vacation settings and the full 7-day, 4-period schedule.

This page lists 292 BACnet objects for the Network Thermostat RP32 IP-WiFi Thermostat (NT-BAS ProtoNode) — 260 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Network Thermostat’s own free documentation, linked below.

BMS integration notes: Network Thermostat RP32 IP-WiFi Thermostat (NT-BAS ProtoNode)

Integration in brief

Write the system mode, fan mode and cooling/heating setpoints, and read the indoor temperature, heat/cool status, stage and override status. The thermostat also carries its own schedule, which the BMS can read or rewrite.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • Add each thermostat in the ProtoNode Web Configurator by picking its profile and entering the thermostat IP address, IP port, user name, password and the BACnet device instance (1-4,194,303).
  • ProtoNode DIP switches: S bank selects the field protocol, A bank sets the BACnet MS/TP MAC address, B bank sets the MS/TP baud rate.
  • The ProtoNode's own Ethernet port defaults to 192.168.1.24 (subnet 255.255.255.0); change it in the Web Configurator for BACnet IP.

Watch out for

  • The guide gives no value codes for the Mode, Fan and other multi-state objects; read the State_Text from the device.
  • Schedule and vacation objects are stored in the thermostat; avoid cyclic writes.

Questions about the Network Thermostat RP32 IP-WiFi Thermostat (NT-BAS ProtoNode)

How many BACnet points does the Network Thermostat RP32 IP-WiFi Thermostat (NT-BAS ProtoNode) have?

This list has 292 BACnet objects: 23 analog inputs, 140 analog values, 4 binary inputs, 58 binary values, 5 multi-state inputs, 62 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Network Thermostat RP32 IP-WiFi Thermostat (NT-BAS ProtoNode) BACnet points are writable?

260 of the 292 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Network Thermostat RP32 IP-WiFi Thermostat (NT-BAS ProtoNode) BACnet documentation?

The source is Network Thermostat's ProtoNode Startup Guide (ProtoNode FPC-N34 and FPC-N35, NT-BAS), revision Document Revision 2.A, Template Revision 24, published free by Network Thermostat at https://www.networkthermostat.com/sites/default/files/2023-01/Protonode%20Startup%20Guide%20for%20NT-BAS.pdf.

What are the minimum BACnet points to integrate the Network Thermostat RP32 IP-WiFi Thermostat (NT-BAS ProtoNode)?

Start with MV 16 Mode (Thermostat system mode command); MV 17 Fan (Fan mode command); AV 19 Cool_Setpoint (Cooling setpoint); AV 20 Heat_Setpoint (Heating setpoint); AI 13 Indoor_Temp (Space temperature); MI 21 Heat_Cool_Status (Current heating/cooling state); AI 22 Stage (Active heat/cool stage); BI 23 Override_Status (Setpoint override active); AI 14 Outdoor_Temp (Outdoor temperature (if a sensor is fitted)).
