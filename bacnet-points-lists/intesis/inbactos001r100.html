BMS integration notes: Intesis INBACTOS001R100 (Toshiba gateway)

Integration in brief

Connect the gateway to the indoor unit (A/B remote-controller bus, no polarity), set the BACnet network on its DIP switches, then write the _command objects (on/off, mode, setpoint, fan) and read back the matching _status objects. One gateway serves one indoor unit (or one remote-controller group), so give each gateway its own MAC address and device instance.

Enable & remote start

No enable point or BMS/local switch is documented; the gateway accepts BACnet commands as soon as it is communicating with the unit. A wired remote controller can still be used in parallel; the LockRemoteControl..._command objects (BO 6-11) lock it per function.

Sensors & values from the BMS

Write the BMS room temperature to AO 1 RoomTemperature_command and keep using AO 0 SetPoint_command for the user setpoint. The gateway then runs its Virtual Temperature function: it offsets the setpoint it sends to the unit by the difference between the BMS temperature and the unit's own return temperature, so AI 0 SetPoint_status can differ from what you wrote. Until a first value is written, AO 1 shows Reliability = UNRELIABLE_OTHER and the function stays off.

Network setup

  • BACnet MS/TP only; the EIA-485 port has DIP switches for the 120-ohm terminator and bus biasing.
  • MS/TP MAC address 0-127 is set on DIP switches; baud rate is DIP-selectable (9600-115200) with autobaud as the default, which matches the baud rate of another MS/TP device running a fixed rate.
  • Default device instance 246000. In automatic mode the instance is 246000 + the MAC address; writing Object_Identifier from BACnet switches to manual mode until a factory reset.

Watch out for

  • Every function has a separate _command (AO/BO/MO, commandable) and _status (AI/BI/MI) object; write the command, read the status.
  • Temperatures follow the Celsius/Fahrenheit DIP switch; the BACnet Units property changes with it.
  • The Occupancy MV and its four AVs drive built-in logic that sets mode, setpoint and on/off; leave Occupancy at 3 (Disabled) unless you use it, and any manual on/off, mode or setpoint change cancels it.

Questions about the Intesis INBACTOS001R100 (Toshiba gateway)

How many BACnet points does the Intesis INBACTOS001R100 (Toshiba gateway) have?

This list has 42 BACnet objects: 7 analog inputs, 2 analog outputs, 5 analog values, 9 binary inputs, 8 binary outputs, 2 binary values, 5 multi-state inputs, 3 multi-state outputs, 1 multi-state value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Intesis INBACTOS001R100 (Toshiba gateway) BACnet points are writable?

16 of the 42 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
