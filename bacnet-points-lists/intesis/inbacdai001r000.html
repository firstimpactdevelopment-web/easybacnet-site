BMS integration notes: Intesis INBACDAI001R000 (Daikin Sky and VRV gateway, BACnet IP and MS/TP)

Integration in brief

Connect the gateway anywhere on the P1P2 bus, pick BACnet MS/TP or BACnet IP on its DIP switch, set the MAC address or IP, then write the _command objects (on/off, mode, setpoint, fan) and read the _status objects.

Enable & remote start

No enable point is documented. BV 2 LockRemoteControl locks the wired remote.

Sensors & values from the BMS

AO 1 RoomTemperature_command only works with the gateway set as P1P2 master and SW4 set to controller reference temperature; RoomTemperature_status then follows the written value. As slave, the command object is disabled.

Network setup

  • A DIP switch selects BACnet MS/TP (default) or BACnet IP; switch changes apply after a power cycle.
  • BACnet IP: factory static IP 192.168.100.246; change it or select DHCP in the configuration tool.
  • Default device instance 246000; in automatic mode it is a base address + the SW2 address.
  • A DIP switch sets the gateway as slave (default) or master on the P1P2 bus; a Daikin wired remote must take the other role. With Daikin IR remotes the gateway must be master.

Watch out for

  • The Occupancy MV drives built-in logic; leave it at 3 (Disabled) if the BMS handles scheduling.
  • Write the _command object and read the _status object.

Integration notes

  • The manual's property tables show Present_Value as R for every object; output objects (AO/BO/MO) have a priority array and are shown here as commandable. The occupancy setpoint AVs are shown read-only as printed; the manual describes setting them in the configuration tool.
  • FilterSign, FilterReset, IndoorLiquidPipeTemp, IndoorGasPipeTemp and IndoorEEVOpening are in the member table but have no property table, so their state texts and units are not stated.
  • ThermostatON is printed as 'Thermostat ON' in the member table; the name here follows Object_Name.
  • Fan speed states change if 'Legacy Fan speed' is selected in the configuration tool.
  • Different product from the IN485DAI001R000 (MS/TP and Modbus RTU), which is listed separately.
  • Temperature objects follow the °C/°F DIP switch (SW3).

How many BACnet points does the Intesis INBACDAI001R000 (Daikin Sky and VRV gateway, BACnet IP and MS/TP) have?

This list has 31 BACnet objects: 7 analog inputs, 2 analog outputs, 5 analog values, 4 binary inputs, 2 binary outputs, 3 binary values, 4 multi-state inputs, 3 multi-state outputs, 1 multi-state value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Intesis INBACDAI001R000 (Daikin Sky and VRV gateway, BACnet IP and MS/TP) BACnet points are writable?

11 of the 31 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
