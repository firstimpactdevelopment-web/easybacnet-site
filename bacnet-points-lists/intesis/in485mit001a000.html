BMS integration notes: Intesis IN485MIT001A000 (Mitsubishi Electric Ecodan gateway, BACnet MS/TP)

Integration in brief

Plug the gateway into CN105 on the Ecodan board, leave SW1 position 5 OFF for BACnet MS/TP and set the MAC address on SW2. Turn the system on with OnOff_command, set heat or cool with ZonesMode_command (both zones follow), and write zone and DHW setpoints to their _command objects.

Enable & remote start

BO 3 RemoteControlLock_command = 1 lets only the BMS control the unit; remote-controller commands are then ignored.

Sensors & values from the BMS

Write a BMS room temperature to AO 8 Zone1TempBACnetRoomThermAmbientRef_command (AO 22 for zone 2). Once a valid value is written, the gateway's Virtual Temperature function uses it to offset the setpoint.

Network setup

  • SW1 P5: OFF = BACnet MS/TP (default), ON = Modbus RTU; SW1 P6-P8 baud rate, autobaud by default.
  • MS/TP MAC address on SW2 P1-P7; SW2 P8 selects °C (default) or °F.
  • Default device instance 246000; in automatic mode it is 246000 + the MAC address. Writing Object_Identifier switches to manual addressing until a factory reset.
  • DIP switch changes take effect after a reboot.

Watch out for

  • Write the _command object and read the matching _status object; they have different object types and instance numbers.
  • Custom setpoint limits cannot go past the unit's own limits (the Unit...Limit objects); the Applied...Limit objects show the range in force.
  • Write 0 to CompressorOperatingTime_command or CirculationPumpOperatingTime_command to reset that run-hour counter.

Integration notes

  • The manual's object table has no read/write column. Access is inferred: AO/BO/MO command objects as commandable, inputs as read-only.
  • Footnote numbers printed after some object names in the table (for example ErrorCode_status2) are not part of the name and were removed.
  • ErrorCode_status (AI 2) shows the code as a Mitsubishi centralized controller shows it; ErrorSubCode_status (AI 3) shows it as the Ecodan unit shows it.
  • Run-hour and flow counters roll back to 0 at 720896; energy counters at 2147483647 kWh.
  • Temperatures follow the °C/°F setting on DIP switch SW2 position 8.
