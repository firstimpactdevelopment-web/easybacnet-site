BMS integration notes: Intesis IN770AIR***O000 for Samsung NASA VRF (700 Series Air Gateway)

Integration in brief

Connect the Samsung NASA R1/R2 bus to AC-Port B (B1 R1, B2 R2), set the outdoor and indoor units to manual addressing, pick BACnet IP or BACnet MS/TP in Intesis MAPS, scan the units, send the project, then map each indoor unit's objects from its (IU x 100) block. Check the Unit type object first: other unit types use different objects in the same block.

Enable & remote start

No enable point is documented. OXXUXX_RC Restriction_C (BO 103) restricts the unit's remote controller.

Network setup

  • BACnet IP: DHCP for 30 seconds at first start-up, then the default IP 192.168.100.246.
  • BACnet MS/TP uses the gateway's EIA-485 port.
  • Units are found and configured in Intesis MAPS; send the project to the gateway after changes.

Watch out for

  • Global objects (BO 0-3, MO 0-1, AO 0) act on all units at once.
  • Samsung EHS units need an external sensor for setpoint and room temperature objects.
  • Manual addressing may be needed on the outdoor units if BI 16 OU Addressing Error is active.

Integration notes

  • Indoor unit instance = (IU x 100) + offset, IU 1-64; IU 1 is shown (100-117).
  • Left out because they reuse instances of the IU set for other unit types: mode objects for HE, EHS/ERV+ and chiller units, AHU discharge setpoints, hot-water mode and setpoints, water temperatures and the slave-chiller error objects (see the manual).
  • The outdoor communication-error object is printed with instance OU[0..15] + 1; outdoor unit 00 is shown at BI 1. As printed, OU 15 would land on BI 16, the OU Addressing Error object.
  • OXXUXX_Air Clean_C (Binary Output) is printed without an instance offset and is left out; OXXUXX_Air Clean_S is BI 107.
  • Mode numbering here is 1=Heat, 2=Cool, 3=Fan, 4=Dry, 5=Auto, unlike the older INBACSAM manual. Consumption is Wh or kWh as set in MAPS.
  • The BACnet table has no read/write column; access is inferred from object type. Replaces the INBACSAM004O000-064O000 BACnet servers (listed separately).
