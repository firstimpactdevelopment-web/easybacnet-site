Accurex Vari-Flow Air Management System v2.00 BACnet points list

Updated 7 November 2026

Short answer

Vari-Flow is Accurex's demand-controlled kitchen ventilation controller. It modulates exhaust and supply fans from hood temperatures and can talk BACnet MS/TP or BACnet IP through a communication card. The v2.00 points list covers hood control temperatures, fan speeds and status, temperature settings, hood system on/off commands, remote enable, wash and alarm flags.

This page lists 167 BACnet objects for the Accurex Vari-Flow Air Management System v2.00 — 60 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Accurex’s own free documentation, linked below.

BMS integration notes: Accurex Vari-Flow Air Management System v2.00

Integration in brief

Enable the system with BV 102 Remote Enable and switch hood systems with BV 11-20. Read hood control temperatures (AV 11-20), fan speeds (AV 1011 up) and fan status BVs, and watch BV 10 Global Alarm and BV 101 fire status.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

BV 102 Remote Enable (1 = on) and the per-system On/Off BVs (BV 11-20) let the BMS run the hood systems.

Network setup

  • BACnet MS/TP or BACnet IP needs the matching communication card in the controller serial card port, with BACnet Plugin set to YES.
  • Default device instance is 77000; MS/TP MAC, baud and IP settings are adjusted from the controller display (BACnet IP cards ship in DHCP mode).

Watch out for

  • Network settings changed on the display only take effect after a Write on the BACnet Read/Write screen and a power cycle.

Integration notes

  • The points list states the mapping: Analog and Integer variables are Analog Value objects, Digital variables are Binary Value objects.
  • The list has objects for up to 10 hood systems, 10 exhaust fans and 4 supply fans; map only the ones the job has.
  • Access is from the points list's R / R/W column.
  • The Accurex Auto Scrubber Control Panel (ASCP v2.00, document 481510) prints the same 167 objects; it is covered by this entry.
  • Vari-Flow v3.00 renumbers and adds objects (63 of the v2.00 objects are not in v3.00); use the list that matches the controller program version.

Questions about the Accurex Vari-Flow Air Management System v2.00

How many BACnet points does the Accurex Vari-Flow Air Management System v2.00 have?

This list has 167 BACnet objects: 114 analog values, 53 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Accurex Vari-Flow Air Management System v2.00 BACnet points are writable?

60 of the 167 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Accurex Vari-Flow Air Management System v2.00 BACnet documentation?

The source is Vari-Flow Air Management System - Installation, Operation and Maintenance Manual, BMS Points List (v2.00) (481515 Rev. 3), revision 2019-08, published free by Accurex at https://content.accurex.com/accurex-cms-prod/docs/default-source/ioms/vari-flow_management_system_iom.pdf?sfvrsn=ff6579ed_6.

What are the minimum BACnet points to integrate the Accurex Vari-Flow Air Management System v2.00?

Start with BV 102 Rem_En (Remote enable of the system (1 = on)); BV 11 Sys1_On_Off (Hood system 1 on/off (1 = on)); AV 11 H1_Ctemp (Hood 1 control temperature); AV 1011 Ef1_Speed (Exhaust fan 1 speed, %); BV 171 Ef1_Status (Exhaust fan 1 running); BV 181 Sf1_Status (Supply fan 1 running); BV 101 Fire_Alm (Fire system active); BV 10 GLOBAL_ALARM (Any active alarm).

How do I enable BMS control of the Accurex Vari-Flow Air Management System v2.00?

BV 102 Remote Enable (1 = on) and the per-system On/Off BVs (BV 11-20) let the BMS run the hood systems.

How do I check these points on the real Vari-Flow Air Management System v2.00?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
