BMS integration notes: Accurex Make-Up Air (MUA) controller (MUA_01.001)

Integration in brief

With the BACnet license installed, set the BACnet network settings at the controller. Write BV 2 to enable the unit and BV 3 for occupancy, and adjust setpoints such as AV 1. To command the supply fan, damper or sensor values, set the matching BMS-source BV and write BV 1 watchdog repeatedly.

Enable & remote start

BV 2 System_Enable enables or disables the unit, and BV 3 BMS_Occupancy_Command sets occupancy (default occupancy mode expects the BMS command; schedule, digital input or fixed modes can be chosen at the controller).

Heartbeat & communication loss

BV 1 BMS_Watchdog must be written True regularly whenever the BMS commands the fan, damper or sensor values. If it stays False longer than the timeout (default 15 min, adjustable), an alarm is raised (alarm 19) and the controller goes back to local control and sensors. With Enable Relinquish Default on, commandable points are cleared 5 minutes after the watchdog drops.

Sensors & values from the BMS

Set the source BV to BMS (BV 6, 9, 10, 12, 13) and write the value to AV 30 outside temperature, AV 33 space CO2, AV 34 return CO2, AV 36 space static or AV 37 space temperature. Keep the watchdog alive or the controller falls back to its local sensor.

Network setup

  • BACnet needs a license on the controller; contact the rep if it is not enabled.
  • BBMD, foreign device, COV increments and relinquish default options are in the BACnet Advanced Settings menu.

Watch out for

  • BV 3 is 1 = Unoccupied, 0 = Occupied.
  • For BMS supply temperature reset, set IV 1 to No Reset and write AV 1.
  • Integer words must be unpacked bit by bit in the BMS.

Integration notes

  • This is Accurex's integration guide list, not every object in the controller; not all points apply to every unit.
  • The guide has no read/write column; access is inferred from the guide text (commands, setpoints and BMS inputs writable, the rest read-only).
  • IV 10-15 are 32-bit words with one status or alarm per bit (bit 0 = lowest); the states field lists every bit the guide prints for each word (unlisted bits are unused). The guide also prints some bits as separate rows, e.g. IV-15 bit 20 Cooling_is_On, bit 21 Heating_is_On, IV-13 bit 3 Filter_Alarm_Digital_Input, IV-10 bits 3-4 compressor 1-2.
  • The guide titles the unit status bit table "IV-11", but the status rows and the object list put Unit_Status_Word on IV-15; IV-11 is the cooling alarm word.
  • AV 41 shows a numeric mode from the status mode table (e.g. 10 System On, 20 Economizing); IV 9 returns an alarm table code (0 = none, 19 = BMS offline).
  • Object numbers differ from the Accurex DOAS guide even where names match.

Questions about the Accurex Make-Up Air (MUA) controller (MUA_01.001)

How many BACnet points does the Accurex Make-Up Air (MUA) controller (MUA_01.001) have?

This list has 58 BACnet objects: 7 analog inputs, 27 analog values, 2 binary inputs, 13 binary values, 9 integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Accurex Make-Up Air (MUA) controller (MUA_01.001) BACnet points are writable?

28 of the 58 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Accurex Make-Up Air (MUA) controller (MUA_01.001) BACnet documentation?

What are the minimum BACnet points to integrate the Accurex Make-Up Air (MUA) controller (MUA_01.001)?

Start with BV 2 System_Enable (Unit enable (1 = enabled)); BV 3 BMS_Occupancy_Command (Occupancy: 0 = occupied, 1 = unoccupied); AV 1 Temperature_Setpoint (Occupied temperature setpoint, °F); BV 1 BMS_Watchdog (Watchdog; write 1 regularly when BMS commands); BV 4 Reset_All_Alarms (Resets alarms); AV 41 Unit_Status_Mode (Unit mode number (status mode table)); AI 2 Supply_Temp_Analog_Input (Supply air temperature, °F); BI 2 Supply_Fan_1_Status_Digital_Input (Supply fan running); BV 19 Global_Alarm (Any active alarm); IV 9 LatestAlm (Latest alarm code; 0 = none).

How do I enable BMS control of the Accurex Make-Up Air (MUA) controller (MUA_01.001)?

BV 2 System_Enable enables or disables the unit, and BV 3 BMS_Occupancy_Command sets occupancy (default occupancy mode expects the BMS command; schedule, digital input or fixed modes can be chosen at the controller).

Does the Accurex Make-Up Air (MUA) controller (MUA_01.001) need a BACnet heartbeat or have a communication timeout?

BV 1 BMS_Watchdog must be written True regularly whenever the BMS commands the fan, damper or sensor values. If it stays False longer than the timeout (default 15 min, adjustable), an alarm is raised (alarm 19) and the controller goes back to local control and sensors. With Enable Relinquish Default on, commandable points are cleared 5 minutes after the watchdog drops.

Can the BMS supply sensor values to the Accurex Make-Up Air (MUA) controller (MUA_01.001)?
