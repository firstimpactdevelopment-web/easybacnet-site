BMS integration notes: Flexit Nordic series (Nordic Basic BACnet list)

Integration in brief

Set BV 50 Comfort button to 1 so the unit follows MV 42 Room operating mode, then write MV 42 (Stop/Away/Home/High). Write the home and away temperature setpoints (instance depends on supply or extract control). Read MV 361 for the present mode, the temperatures and fan speeds, and the A/B alarm indication points; MV 344 acknowledges or resets A alarms.

Enable & remote start

MV 42 Room operating mode only works when BV 50 Comfort button is 1; with BV 50 at 0 the unit goes to Away after the AWAY delay (PIV 318). A ventilation mode wired to a digital input overrides MV 42.

Network setup

  • BACnet IP is built in; default device ID is 2.
  • Change BACnet settings in the Flexit GO app as installer (Other > Installer > BACnet settings); the unit restarts to apply them.
  • Network settings can also be written over BACnet on the network port object (device instance, IP, UDP port); set property 4894 to 1 to save.

Watch out for

  • Flexit says to write commandable objects at priority 13 only; other priorities can leave the unit out of control.
  • The home/away setpoint instance depends on temperature control mode: 1994/1985 for supply air control, 2070/1988 for extract air cascade.
  • Input and output objects change instance with the terminal they are configured on.

Integration notes

  • Rows that depend on wiring (DI1, DI2, X8, Q1-Q3, CI79) or on temperature control mode (supply air vs extract air cascade) are listed once per printed instance; the description says which. Instances marked default in the list are noted.
  • AI 50 is printed twice: extract air humidity or room air quality, depending on what is configured on X3.
  • Many objects exist only when the matching option is configured (water or electric heating, cooling, duct pressure fan control, wireless room sensors CI75/CI76/CI77).
  • AI 31 (frost protection temperature) is printed with unit Pa and a -3000 to 3000 range in the source; kept as printed.
  • The object list is a spreadsheet; it has no document number. Network settings come from Flexit's GO BACnet guide 118278-02 (2025-04).

Questions about the Flexit Nordic series (Nordic Basic BACnet list)

How many BACnet points does the Flexit Nordic series (Nordic Basic BACnet list) have?

This list has 85 BACnet objects: 12 analog inputs, 6 analog outputs, 17 analog values, 25 binary inputs, 10 binary outputs, 1 binary value, 11 multi-state values, 3 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Flexit Nordic series (Nordic Basic BACnet list) BACnet points are writable?

16 of the 85 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Flexit Nordic series (Nordic Basic BACnet list) BACnet documentation?

The source is BACnet Basic list - Nordic, revision 2020-10, published free by Flexit at https://flexitwebsiteprodstorage.blob.core.windows.net/product-documents/2963.

What are the minimum BACnet points to integrate the Flexit Nordic series (Nordic Basic BACnet list)?

Start with BV 50 Comfort button (Must be 1 for MV 42 to take effect); MV 42 Room operating mode (Mode command: 1 Stop, 2 Away, 3 Home, 4 High); AV 1994 Setpoint temperature when home (Home setpoint (supply air control default)); MV 344 A-Alarm acknowledgement (Write 2 to acknowledge, 3 to reset A alarms); MV 361 Heat recovery ventilation state (Present ventilation mode); AI 4 Supply air temperature (Supply air temperature); AI 1 Outside air temperature (Outdoor air temperature); AI 59 Extract air temperature (Extract (return) air temperature); MV 343 A-Alarm indication (A alarm active when 2); MV 340 B-Alarm indication (B alarm active when 2).

How do I enable BMS control of the Flexit Nordic series (Nordic Basic BACnet list)?

MV 42 Room operating mode only works when BV 50 Comfort button is 1; with BV 50 at 0 the unit goes to Away after the AWAY delay (PIV 318). A ventilation mode wired to a digital input overrides MV 42.
