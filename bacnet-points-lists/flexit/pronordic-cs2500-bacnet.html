BMS integration notes: Flexit ProNordic with CS2500 controller (SP85 BACnet IP module)

Integration in brief

Write MV 32040 BMS Regulation to run the unit from the BMS (Auto, Off, or Economy/Comfort steps 1-3). Adjust the comfort and economy heating setpoints if needed. Read MV 6080 for the actual operating mode, the outdoor/supply/extract temperatures, the fan values and the A/B/C alarm MVs; MV 19 resets alarms.

Network setup

  • BACnet IP needs the SP85 communication module on the CS2500 controller.

Watch out for

  • MV 56125 temperature regulation mode is status only; Flexit says not to change it.
  • Several instances are printed twice for different points; confirm against the live unit's object list.

Integration notes

  • The spreadsheet has no read/write column. Access here is inferred: the BMS mode command, the alarm reset and the setpoint/fan-step AVs are marked W, everything else R.
  • Printed instance clashes are kept as printed: AI 40895 is listed for both exhaust temperature and return water temperature, and MV 38643 for both B-alarm and C-alarm. AV 30463 and AO 30463 are different object types.
  • BV 32321 Status AHU is printed as a Binary Value but with 17 state texts (2-18); check the type on the live unit.
  • State texts follow the Norwegian sheet where the English sheet differs: MV 30094 1=Off/2=On and BO 5714 0=Normal/1=Alarm (the English sheet prints them the other way or 1/2).
  • Fan step and fan value AVs are in Pa (pressure accessory), m3/h (standard) or l/s (by configuration).
  • The file also has Norwegian and Swedish sheets with the same instances; names here are from the English sheet, typos included.

Questions about the Flexit ProNordic with CS2500 controller (SP85 BACnet IP module)

How many BACnet points does the Flexit ProNordic with CS2500 controller (SP85 BACnet IP module) have?

This list has 79 BACnet objects: 10 analog inputs, 8 analog outputs, 37 analog values, 5 binary inputs, 7 binary outputs, 1 binary value, 11 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Flexit ProNordic with CS2500 controller (SP85 BACnet IP module) BACnet points are writable?

21 of the 79 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

What are the minimum BACnet points to integrate the Flexit ProNordic with CS2500 controller (SP85 BACnet IP module)?

Start with MV 32040 BMS Regulation (Mode command: 1 Auto, 2 Off, 3-8 Economy/Comfort steps); AV 22817 Setpoint Komfort Heating (Comfort heating setpoint); AV 35713 Setpoint Economi Heating (Economy heating setpoint); MV 19 Reset Alarm (A,B,C) (Alarm reset); MV 6080 Operating mode Operation Aggregate (Actual operating mode (off, comfort, economy, start)); AI 45150 Supply temperature (Supply air temperature); AI 53218 Outdoor temperature (Outdoor air temperature); AI 28256 Extract temperature (Extract air temperature); MV 46769 A-Alarm Danger (A alarm active when 2); MV 38643 B-Alarm (B alarm active when 2).

How do I enable BMS control of the Flexit ProNordic with CS2500 controller (SP85 BACnet IP module)?
