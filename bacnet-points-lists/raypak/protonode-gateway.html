Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86) BACnet points list

Updated 16 October 2026

Short answer

The ProtoNode RER reads one or more Raypak VERSA IC controls over Modbus RTU and makes each one a separate BACnet IP or BACnet MS/TP device. The Master profile used for single boilers and cascade masters has 173 objects: system temperatures and calls, a 29-point block for each of up to 4 boilers, writable setpoint, outdoor reset, DHW, tank and pool settings, and on/off commands per boiler. Cascade followers use a smaller Follower profile.

This page lists 173 BACnet objects for the Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86) — 32 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Raypak’s own free documentation, linked below.

BMS integration notes: Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86)

Integration in brief

Add a Master profile in the ProtoNode Web Configurator for each VERSA IC (Follower profile for cascade followers) with its Modbus node ID, then find each one as its own BACnet device. Turn boilers on with the Blr On/Off BVs and set the target with Target Mode plus Setpoint Target or Target Mod Rate; read supply temperature, boiler outlet temperature, modulation rate, ignition status and error code.

Enable & remote start

The Master profile has writable on/off BVs per boiler (BV 162-165) and a Target Mode BV with Setpoint Target (AV 135), Target temperature (AV 158) and Target Mod Rate (AV 160). The manual does not explain the Target Mode values or which target applies in each mode.

Network setup

  • Device instance = BN_Node_Offset + Modbus node ID; the offset defaults to 50000 and is changed in the Web Configurator (node 10 -> 50010).
  • S-bank DIP switches pick the protocol: all off = BACnet IP (default), S0 on = BACnet MS/TP.
  • BACnet MS/TP: one MAC address (1-127) for the whole ProtoNode on the A-bank switches; baud on B0-B3 (9600, 19200, 38400, 57600 or 76800).
  • VERSA IC side: Modbus RTU at 19200 baud, each unit with a unique node ID; up to 8 Master units (1400 registers) per ProtoNode RER.
  • Default ProtoNode IP address 192.168.1.24; the Web Configurator is used to add profiles and set the offset.

Watch out for

  • Use the Master profile only for single boilers or the cascade master; followers on the Ft-bus/TN-bus need the Follower profile.
  • The ProtoNode connects only to a master unit, not directly to a follower.
  • Never set an MS/TP MAC address above 127; 128-255 cannot be auto-discovered.
  • Writable AVs are boiler settings; avoid rewriting them cyclically.

Integration notes

  • Each VERSA IC unit is its own BACnet device: device instance = BN_Node_Offset (default 50000) + its Modbus node ID. Object IDs below are the same on every device.
  • No read/write column is given. AVs and BVs map to LonWorks input variables and are marked writable; AIs and BIs are read-only.
  • Object ID 133 is not used.
  • Follower profile (cascade followers only): BI 1 Blr 1 detected, AI 2-29 the same Blr 1 values as AI 18-45 here, BV 30 Blr 1 On/Off, AI 31 Blr 1 Flow Sensor, AI 32 Blr 1 Flame Current.
  • No units or state texts are given in the object table.
  • The object table in the manual is not selectable text; it was keyed in by hand.

Questions about the Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86)

How many BACnet points does the Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86) have?

This list has 173 BACnet objects: 136 analog inputs, 23 analog values, 5 binary inputs, 9 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86) BACnet points are writable?

32 of the 173 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86) BACnet documentation?

The source is Installation & Operating Instructions - ProtoNode RER and ProtoNode LER (FPC N34 / FPC N35) B-85 / B-86 (P/N 241515 Rev. 5), revision Effective 08-25-23, published free by Raypak at https://s3.amazonaws.com/AWSProd/sites/raypakcom/documents/241515.pdf.

What are the minimum BACnet points to integrate the Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86)?

Start with BV 162 Blr 1 On/Off (Boiler 1 on/off command (BV 163-165 for 2-4)); BV 134 Target Mode (Selects which target applies (values not documented)); AV 135 Setpoint Target (Target water setpoint); AV 160 Target Mod Rate (Target modulation rate); AI 25 Blr 1 Ignition Status (Boiler 1 ignition state code); AI 2 System Supply Temperature (System supply water temperature); AI 18 Blr 1 Outlet temperature (Boiler 1 outlet water temperature); AI 23 Blr 1 Mod Rate (Boiler 1 modulation rate); AI 30 Blr 1 Error Code (Boiler 1 active error code).

How do I enable BMS control of the Raypak VERSA IC - ProtoNode RER/LER (B-85 / B-86)?

The Master profile has writable on/off BVs per boiler (BV 162-165) and a Target Mode BV with Setpoint Target (AV 135), Target temperature (AV 158) and Target Mod Rate (AV 160). The manual does not explain the Target Mode values or which target applies in each mode.
