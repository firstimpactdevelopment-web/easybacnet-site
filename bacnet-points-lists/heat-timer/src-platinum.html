Short answer

The SRC Platinum controls steam heating on outdoor temperature, either through a burner/valve or a modulating district steam valve with position feedback or timed control. Its BACnet board exposes the settings, valve trims and position, schedule slots and sensor readings as Analog, Binary and Multi-state Values with instances in steps of 100.

BMS integration notes: Heat-Timer SRC Platinum (BACnet)

Integration in brief

The SRC runs steam heating (burner/valve or a district steam valve) on outdoor temperature. From the BMS, read the system and outdoor temperatures, the valve position and the burner status; adjust the system setpoint or heat adjustments, set a manual valve target, and force a day/night shift if needed.

Network setup

  • BACnet IP or BACnet MS/TP is chosen at the panel (Network Settings > Switch to IP / Switch to MS/TP).
  • Device ID is a 7-digit number entered at the panel; the device object name is HTC_ followed by the panel serial number.
  • MS/TP: MAC address 1-127 (default 1), baud 9600, 19200 or 38400 (default 9600), 8 data bits, no parity, 1 stop bit.
  • IP: leave the IP and mask blank for DHCP, or enter a fixed address at the panel.

Watch out for

  • XYZMIN applies in District Steam mode; XYZTEMP in Burner/valve mode.
  • BOOSTADJ applies with BOOSTMODE VariDay/VariDayNight; BOOSTTIME with ManualBoost.
  • The weekly schedule is 56 AV slots (instances 2700-2755), minutes since midnight; 1440 = empty slot.

Integration notes

  • Objects are Analog, Binary and Multi-state Values only. Rows without a read-only mark in the manual are listed as writable.
  • Temperature objects use °F or °C depending on the INMODE (sensor type/mode) setting.
  • Start-up settings can be read but not written over BACnet; Heat-Timer says to set them at the panel first.
  • The manual prints some rows as ranges (SCHEDULES00-55 = 2700-2755). Only the first and last printed objects of each range are listed here; the ones in between follow the same pattern.
  • CUTOFFPCT is printed with an asterisk in the manual; the footnote is not explained on the page.
  • BOOSTADJ is printed with the range "0 1 - 6 4" (decimal points appear to be missing).
  • Variable list: manual pages 18-19.

Questions about the Heat-Timer SRC Platinum (BACnet)

How many BACnet points does the Heat-Timer SRC Platinum (BACnet) have?

This list has 41 BACnet objects: 27 analog values, 10 binary values, 4 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Heat-Timer SRC Platinum (BACnet) BACnet points are writable?

35 of the 41 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Heat-Timer SRC Platinum (BACnet) BACnet documentation?

The source is Platinum BACnet Installation and Configuration Manual (IP and MS/TP) - SRC Platinum BACnet Variable List (pp. 18-19) (HT# 059082-00C), published free by Heat-Timer at https://www.heat-timer.com/wp-content/uploads/2019/04/Platinum-BACnet-Configuration-Manual-059082C-Color.pdf.

What are the minimum BACnet points to integrate the Heat-Timer SRC Platinum (BACnet)?

Start with MV 2900 SHIFT (Force day/night: 1 To-Day, 2 To-Night, 3 Extend-Day); AV 3900 XYZTEMP (System setpoint (burner/valve mode)); AV 1500 MVTARGET (Manual valve target, %); AV 3000 SYSSEN (System sensor temperature); AV 1800 ODTEMP (Outdoor temperature); AV 3200 VALVE (Valve position, %); BV 400 BURNER (Burner status (1 = on)).

How do I check these points on the real SRC Platinum (BACnet)?
