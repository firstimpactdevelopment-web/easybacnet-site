Short answer

With the cascade profile, the Navien Modbus/BACnet gateway presents a whole NFB-C cascade (Main plus Sub 1-31) as one BACnet IP or BACnet MS/TP device. It exposes the cascade commands and setpoints, cascade state, and a block of status, temperature, error and counter points for the Main and each Sub boiler.

BMS integration notes: Navien NFB-C Fire Tube Boiler - Cascade Main + Sub 1-31 (Modbus/BACnet Gateway)

Integration in brief

Command the cascade from the BMS (on/off, space heating, setpoints) and read cascade state plus the Main and Sub boiler status and error points. Map only the Sub blocks that exist on site.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

Boiler On/Off command (AV 1) and SH operation on/off control (BV 1) switch the cascade and space heating; DHW operation ON/OFF control (BV 4) does the same for hot water.

Network setup

  • Gateway part number GXXX001932 (ports: RS-485 R1 to the boilers, Ethernet, RS-485 R2 for BACnet MS/TP).
  • Boiler side: Modbus RTU at 9600 baud, 8 data bits, no parity, 1 stop bit; give each boiler a unique Node-ID (1-255).
  • Device instance = Node_Offset + Node-ID; Node_Offset defaults to 50,000, so Node-ID 1 gives 50,001.
  • Default gateway IP is 192.168.1.24 (Wi-Fi access point 192.168.50.1); pick the field protocol and the device profile in the Web Configurator.
  • Set BACnet Virtual Server Nodes to Yes when more than one device is connected to the gateway.

Watch out for

  • The full profile is large (Main + 31 Subs); auto-discovery returns every Sub block whether or not that boiler exists.
  • The guide gives no state or value tables; check status and error codes against the boiler manual.

Which Navien NFB-C Fire Tube Boiler - Cascade Main + Sub 1-31 (Modbus/BACnet Gateway) BACnet points are writable?

Boiler On/Off command (AV 1) and SH operation on/off control (BV 1) switch the cascade and space heating; DHW operation ON/OFF control (BV 4) does the same for hot water.
