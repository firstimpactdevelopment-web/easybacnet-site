Updated 28 October 2026

Short answer

RenewAire's Premium Commercial Controls run on a Carel c.pCO Mini with a c.pCOe expansion module and talk BACnet IP or BACnet MS/TP once a BACnet license is installed. The fixed object map covers sensors, fan, heating, cooling, economizer, dehumidification and frost-control settings, and about 60 alarm flags. Many points only mean something with the matching options and control types; writes go straight to Present_Value (no priority array).

This page lists 184 BACnet objects for the RenewAire Premium Commercial Controls (ERV & DOAS) — 66 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from RenewAire’s own free documentation, linked below.

BMS integration notes: RenewAire Premium Commercial Controls (ERV & DOAS)

Integration in brief

Install the BACnet license, pick BACnet IP or MS/TP as the BMS type and cycle power. Turn on BMS control at the keypad, then start and stop the unit with BV 10 and switch it to unoccupied with BV 63. Read BI 21 and MI 7 for status and BI 72 / BI 17 for alarms. Writes land directly on Present_Value with no priority array, and setpoints marked retained should not be written in a loop.

Enable & remote start

BMS control of on/off is switched on at the keypad (first BMS screen). Once on, the unit will not start until the BMS writes BV 10 = On, so enable it only when the BMS is ready. The unit also needs the start/stop digital input closed, the keypad set On, the scheduler (if used) in an ON period and no serious alarm; any of these can stop it. BI 76 shows whether BMS control is enabled.

Heartbeat & communication loss

No BACnet timeout setting is documented. BI 503 Al_BMS_Offline flags that the BMS is offline and clears itself (auto reset); the manual does not say what the unit does then and documents no keep-alive write.

Sensors & values from the BMS

AV 53 BMS_CO2_Reading takes a CO2 value from the BMS in place of a wired sensor. AV 54 is named BMS_Space_Press_Reading but the table describes it as a coil leaving-air setpoint for dehumidification, so check it on site. The BMS can also force heat or cool: set BV 60 to Allow, then write BV 61 (0 = heat, 1 = cool).

Network setup

  • BACnet needs a BACnet license file (.ap1, ordered against the controller's Hardware ID), installed from the controller web page Upgrade tab or a USB stick folder named UPGRADE.
  • BMS settings are in the keypad's General Settings menu after the scheduler. BMS type: None, BACnet MS/TP, BACnet IP, Modbus RTU or Modbus IP; the BACnet choices appear only once the license is installed. Cycle controller power after changing it.
  • BACnet IP: RJ45 port on the controller. For a static address turn DHCP off, enter IP, mask and gateway, set Update? to Yes and cycle power. Only private address ranges (10.x, 172.x, 192.x) are supported. Device ID is entered digit by digit.
  • BACnet MS/TP: set Device ID, MAC, baud, Max Master and Max Info Frames. Wire to the 4-pin J3 Disp connector (+, -, GND); it is shared with the remote display, so both can't be used at once, and +Vterm is not used.
  • The manual gives no default device instance or MAC address.

Watch out for

  • Points marked retained (EEPROM) survive power loss. Writing them repeatedly raises BI 500/501 (too many writes to retained memory) and can damage the controller. For fan speed loops use AV 80/AV 81 (firmware 03_00_26 and later), with the fan in constant-speed mode and its BMS direct option set to Yes.
  • Priority_Array is not supported: a BMS write goes straight to Present_Value and a later keypad change overwrites it (last one wins).
  • Exhaust-fan-only mode: the application notes point to BV 74 (UnitOnOffMng.BMSEFOnly), but the object table has BV 11 OnOffUnitMng.BmsEfOnly for that and BV 74 as the hot-water valve permission. Confirm on the unit.
  • To drive the hot-water valve from the BMS, set BV 74 to Allow (or Valve Control = BMS at the keypad), then write AV 34 (0-100 % = 0-10 V) and BV 75.
  • Older firmware wrote through the priority array with a smaller object map; a Pri Array legacy setting keeps that old map, which is not this list.
  • Which setpoints matter depends on the fan control types (MI 2, MI 3) and the heating and cooling options fitted.

Integration notes

  • Use this list for current Premium Commercial Controls on ERVs and DOAS units (manual 147641). For older ERVs on Premium controls v3.xx use the legacy list (premium-controls-legacy).
  • Compared with the legacy manual this map adds DOAS points (reheat, unoccupied and boost setpoints, preheat, bypass, more CO2 sensors, refrigerant-leak and VRV alarms, alarm limits AV 500-512). AI 30/31 and the BI 514/521 alarm names changed, BI 71 is now off-by-VRF-defrost (boost status moved to BI 73) and BI 560/561 swap OA and RA.
  • Retained (EEPROM) points are marked '(retained)' in the descriptions.
  • The table repeats some objects under two instances: AV 35/36 and AV 500/501 (filter alarm levels, OA and RA in opposite order), BI 22/23 and BI 510/511, BI 50 and BI 504.
  • As printed: BI 548 carries the name Al_CO2_2_Prb.Active (same as BI 546); BV 11 has no access or range in the table and is listed read only here; BV 566-571 are alarm flags marked read only.
  • The file name says 147641_010_MAY26; the back cover prints 147641_011_JUL26.

Questions about the RenewAire Premium Commercial Controls (ERV & DOAS)

How many BACnet points does the RenewAire Premium Commercial Controls (ERV & DOAS) have?

This list has 184 BACnet objects: 30 analog inputs, 57 analog values, 74 binary inputs, 16 binary values, 7 multi-state inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which RenewAire Premium Commercial Controls (ERV & DOAS) BACnet points are writable?

66 of the 184 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official RenewAire Premium Commercial Controls (ERV & DOAS) BACnet documentation?

The source is Premium Commercial Controls Installation, Operation and Maintenance Manual (ERV & DOAS) (147641_010_MAY26), revision 2026-05, published free by RenewAire at https://renewaire.com/wp-content/uploads/2025/05/Premium-Controls-Supplement_147641_010_MAY26.pdf.

What are the minimum BACnet points to integrate the RenewAire Premium Commercial Controls (ERV & DOAS)?

Start with BV 10 OnOffUnitMng.BmsOnOff (Run/stop command (1 = on)); BV 63 BmsUnocc (Unoccupied mode command (1 = yes, unit stays on)); AV 55 Occ_HTG_Setp.Val (Occupied heating setpoint, °F (retained)); AV 56 Occ_CLG_Setp.Val (Occupied cooling setpoint, °F (retained)); AV 80 BMS_SupplyFanCommand (Supply fan speed, 0-100 % (BMS direct mode)); AV 81 BMS_ExhaustFanCommand (Exhaust fan speed, 0-100 % (BMS direct mode)); BV 12 AlarmMng.AlrmResByBms (Alarm reset (1 = reset; the unit clears it)); BI 21 UnitOn (Unit running status (1 = on)); MI 7 UnitStatus_BN (Operating state, or why the unit is off); BI 72 Any_Alarm_Out.Val (Any active alarm).
