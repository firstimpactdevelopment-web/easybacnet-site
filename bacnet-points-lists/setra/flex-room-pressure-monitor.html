Short answer

The Setra FLEX is a touch-screen room pressure and environmental monitor that watches up to three rooms with six parameters each (pressure, temperature, humidity, ACH and two user-defined). It talks BACnet IP or BACnet MS/TP and exposes the room readings, alarm states, limits and almost all setup as objects; each room parameter can come from an on-board input or be read from another BACnet device. The FLEX-RC version can also control equipment with PI loops or BACnet setpoint overrides.

This page lists 513 BACnet objects for the Setra Setra FLEX Room Pressure Monitor — 455 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Setra’s own free documentation, linked below.

BMS integration notes: Setra Setra FLEX Room Pressure Monitor

Integration in brief

Read the room pressure, temperature and humidity AIs and the per-room and system alarm state MIs; map the door inputs if used. Room standby (BV 72-74) and the active room profile (MV 19-21) can be written from the BMS to switch modes such as occupied and unoccupied. On FLEX-RC units the four setpoint controls have preset A/B setpoints and limits in AV 177-206.

Enable & remote start

Room 1-3 Standby (BV 72-74) put a room in standby, and Room 1-3 Room Profile (MV 19-21) pick which of the four profiles (alarm limits and control presets) is active.

Sensors & values from the BMS

Each room parameter has a source selector (MV 1-18, 6 = BACnet). With BACnet selected, the FLEX reads the value from another device set by the matching device instance, object instance and object type objects (AV 141-176, MV 55-72). The four setpoint controls point at external BACnet setpoint objects set by AV 183/184, 191/192, 199/200 and 207/208 (device and object instance).

Network setup

  • BACnet IP uses IPv4 with static IP or DHCP; BACnet MS/TP runs at up to 76.8 kbps (Setra data sheet and specification guide).
  • The device object is listed as Device-4194302 with an instance range of 0-4194303, where 4194303 means unconfigured.
  • Setra states that anything set up on the touch screen can also be set over BACnet, except passwords, the device ID and read-only items.

Watch out for

  • Most of the list is configuration (limits, delays, display, sources); avoid writing those objects cyclically from the BMS.
  • MV 90-93 set the BACnet priority used for the setpoint overrides; check they do not clash with the BMS command priority.
  • Execute BACnet Time Sync? (BV 7) must be 1 for the unit to accept BACnet time synchronization.
  • Operator Password (CSV 18) is writable over BACnet; restrict write access on the BMS side.

Integration notes

  • Access is taken from the list's Writable column. AI, BI and MI objects are marked writable only when out of service; they are shown here as read-only.
  • The list gives no engineering units; room values follow the units of their configured source (BV 82-99 choose local or BACnet-source units).
  • Analog input and alarm-limit values are bounded by each object's min-pres-value and max-pres-value.
  • Room parameters, alarm limits and source settings repeat for Room 1, 2 and 3; profile settings repeat for profiles 1-4.
  • MV 49 and MV 50 are both printed as "Room Profile 3 Control Preset"; names are kept as printed.
  • The Loop rows print "Loop 1" to "Loop 4" in the type/instance column (without the hyphen the other rows use); they are read here as Loop instances 1-4.

Questions about the Setra Setra FLEX Room Pressure Monitor

How many BACnet points does the Setra Setra FLEX Room Pressure Monitor have?

This list has 513 BACnet objects: 22 analog inputs, 1 analog output, 211 analog values, 6 binary inputs, 1 binary output, 99 binary values, 1 device, 4 loops, 22 multi-state inputs, 122 multi-state values, 24 characterstring values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Setra Setra FLEX Room Pressure Monitor BACnet points are writable?

455 of the 513 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Setra Setra FLEX Room Pressure Monitor BACnet documentation?

The source is SetraFLEX Master BACnet Object List (SS-FLEX-BAC-OBJ), revision print D, published free by Setra at https://www.setra.com/hubfs/SS-FLEX-BAC-OBJ_D.pdf.

What are the minimum BACnet points to integrate the Setra Setra FLEX Room Pressure Monitor?

Start with BV 72 Room 1 Standby (Room 1 standby: 1 = Standby, 0 = Active); MV 19 Room 1 Room Profile (Active room profile 1-4 (e.g. occupied/unoccupied)); AV 177 Setpoint Control 1 - Preset A Setpoint (Control 1 setpoint, preset A (FLEX-RC)); AI 13 Room 1 Pressure (Room 1 differential pressure); AI 14 Room 1 Temperature (Room 1 temperature, from its configured source); AI 15 Room 1 Humidity (Room 1 humidity, from its configured source); BI 13 Room 1 Door Input (Room 1 door switch); MI 19 Room 1 Alarm State (Room 1: 1 Normal, 2 Warning, 3 Alarm, 4 Standby); MI 22 System Alarm State (Whole-unit alarm state, same states).

How do I enable BMS control of the Setra Setra FLEX Room Pressure Monitor?

Room 1-3 Standby (BV 72-74) put a room in standby, and Room 1-3 Room Profile (MV 19-21) pick which of the four profiles (alarm limits and control presets) is active.

Can the BMS supply sensor values to the Setra Setra FLEX Room Pressure Monitor?

Each room parameter has a source selector (MV 1-18, 6 = BACnet). With BACnet selected, the FLEX reads the value from another device set by the matching device instance, object instance and object type objects (AV 141-176, MV 55-72). The four setpoint controls point at external BACnet setpoint objects set by AV 183/184, 191/192, 199/200 and 207/208 (device and object instance).
