Short answer

A ProtoNode FPC-N34 reads a Greengate lighting relay panel over IP and presents it as a BACnet IP or BACnet MS/TP device. The 3264640000 profile has 32 relays, 64 switch inputs, 64 remote points, plus a panel reset. Relays and remote points are Binary Values; switch input states are Binary Inputs. Cooper marks this guide as discontinued (watermark dated 13-10-2023), so the list is for existing Greengate installations.

BMS integration notes: Cooper Lighting Solutions Greengate 3264640000 Relay Panel (ProtoNode)

Integration in brief

Command lighting relays through the Relay BVs, use the Remote BVs as the panel's remote inputs, and read the switch input BIs for local switch states.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

ObjectNameWhyAccess
BV 1Relay01Relay 1 on/off commandWrite
BV 101Remote01Remote point 1 (panel remote input)Write
BI 1Switch01Switch input 1 statusRead

Network setup

  • The Greengate panel must be on the same IP subnet as the ProtoNode; record its IP address, port and panel address for the Web Configurator.
  • Device instance = Node_Offset + Greengate Node-ID; Node_Offset defaults to 50,000. The ProtoNode default IP is 192.168.1.24.

Watch out for

  • Map only the relays and switches that are wired; the profile lists every channel the panel model supports.

Questions about the Cooper Lighting Solutions Greengate 3264640000 Relay Panel (ProtoNode)

How many BACnet points does the Cooper Lighting Solutions Greengate 3264640000 Relay Panel (ProtoNode) have?

This list has 161 BACnet objects: 64 binary inputs, 97 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Cooper Lighting Solutions Greengate 3264640000 Relay Panel (ProtoNode) BACnet points are writable?

97 of the 161 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Cooper Lighting Solutions Greengate 3264640000 Relay Panel (ProtoNode) BACnet documentation?

The source is ProtoNode FPC-N34 and FPC-N35 Startup Guide for Cooper Lighting Solutions Greengate and iLUMIN, revision Document Revision 1.H, Template Revision 53, published free by Cooper Lighting Solutions at https://cooperlighting.com/api/assets/v1/file/Signify/content/1e56df1e31ec4bcc8d6bad40006c1682/ProtoNode-Startup-Guide-for-CLS.

What are the minimum BACnet points to integrate the Cooper Lighting Solutions Greengate 3264640000 Relay Panel (ProtoNode)?

Start with BV 1 Relay01 (Relay 1 on/off command); BV 101 Remote01 (Remote point 1 (panel remote input)); BI 1 Switch01 (Switch input 1 status).
