BMS integration notes: EVAPCO eco-Air Controller, pCO version (EC Fans, 2020)

Integration in brief

Fit the BACnet expansion card (pCONet for MS/TP or pcoWeb for IP), set its parameters through the controller BIOS menu, then enable the unit via BV 100009. Read AV 200001 unit state, AV 100001 outlet temperature and BV 100026 common alarm, and write AV 100004 for the process setpoint.

Enable & remote start

Write BV 100009 Enable Unit = 1; it only applies when the unit is configured to be enabled via BMS. AV 200001 = 4 means off via Modbus/BACnet.

Network setup

  • BACnet requires an optional card: pCONet (BACnet MS/TP) or pcoWeb (BACnet IP / Modbus TCP); Modbus RTU on J25 is always available.
  • Card settings are changed from the BIOS menu: hold ALARM + ENTER for 3 s, Other Information > pcoWeb/Net Config, then pCOWeb or pCONet settings.
  • Default parameters are on page 1 of the panel wiring diagram.

Watch out for

  • Writable parameters are stored in the PLC's non-volatile memory, rated for about 100,000 writes; never write them cyclically.
  • Points marked for adiabatic units (pre-cooling valves, flush, wet-stage timers) can be ignored on dry-only units.
  • Scaled values: divide 0.1 °F / 0.1 psi points by 10 if your front end does not apply the scale.

Questions about the EVAPCO eco-Air Controller, pCO version (EC Fans, 2020)

How many BACnet points does the EVAPCO eco-Air Controller, pCO version (EC Fans, 2020) have?

This list has 187 BACnet objects: 134 analog values, 53 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which EVAPCO eco-Air Controller, pCO version (EC Fans, 2020) BACnet points are writable?

33 of the 187 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official EVAPCO eco-Air Controller, pCO version (EC Fans, 2020) BACnet documentation?

The source is EVAPCO Controller User's Manual Addendum - Communications Guide EC Fan Edition (COMM20EC), revision 2020-04, published free by EVAPCO at https://www.evapco.com/sites/evapco.com/files/2020-04/Communications%20Guide%20EC%20Motors%20.pdf.

What are the minimum BACnet points to integrate the EVAPCO eco-Air Controller, pCO version (EC Fans, 2020)?

Start with BV 100009 Enable Unit (BMS enable when configured for BMS enable); AV 200001 Actual Unit State (Running, off by alarm, off by BMS, scheduler or local); AV 100001 Outlet Temperature (Process outlet temperature (0.1 °F)); AV 100003 Active Set Point (Setpoint currently in control); AV 100004 Set Point 1 Temperature (Primary setpoint (writable)); BV 100026 Common Alarm Digital Output Status (Common alarm); AV 200029 Reference Fan Speed (Commanded fan speed).

How do I enable BMS control of the EVAPCO eco-Air Controller, pCO version (EC Fans, 2020)?

Write BV 100009 Enable Unit = 1; it only applies when the unit is configured to be enabled via BMS. AV 200001 = 4 means off via Modbus/BACnet.
