Short answer

Same eco-Air PLC as the EC edition but for units with conventional AC fan motors, so the per-EC-fan objects are unused. BACnet IP runs on the Ethernet port and BACnet MS/TP on the RS-485 terminal shared with Modbus RTU. The object list covers enable and state, temperatures, setpoints, fan-speed limits, adiabatic pre-cooling stages and remote fan-speed control.

BMS integration notes: EVAPCO eco-Air Controller (AC / NEMA Motors)

Integration in brief

Select BACnet MS/TP or Modbus RTU for the serial port on the HMI (BACnet IP is always on the Ethernet port), set addresses under Service > BMS & Network, then use BV 0 to enable the unit from the BMS. Read AV 16, AV 0 and the common alarm and write AV 3 for the process setpoint; remote fan speed works through BV 77, AV 101 and AV 105.

Enable & remote start

Write BV 0 bnEnableUnit = 1 (only works when the unit is configured to be enabled via BMS); AV 16 = 4 means off via BMS.

Sensors & values from the BMS

Remote fan speed: BV 77 bnRemoteEnable = 1, AV 101 bnRemoteSource = 2 (Communication), then write AV 105. AV 103/AV 104 set the fallback speeds used if the analog speed input is lost.

Network setup

  • Default communication parameters are on page 1 of the panel wiring diagram.
  • Switch the unit off, log in at Service level, open Service > BMS & Network, change values and hold Update for 3 s; the HMI and PLC restart.
  • The serial port is either MS/TP or Modbus RTU; BACnet IP and Modbus TCP both run on Ethernet.

Watch out for

  • Writable parameters are stored in the PLC's non-volatile memory, rated for about 100,000 writes; never write them cyclically.
  • Points marked for adiabatic units (pre-cooling valves, flush, wet-stage timers) can be ignored on dry-only units.

Questions about the EVAPCO eco-Air Controller (AC / NEMA Motors)

How many BACnet points does the EVAPCO eco-Air Controller (AC / NEMA Motors) have?

This list has 68 BACnet objects: 54 analog values, 14 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which EVAPCO eco-Air Controller (AC / NEMA Motors) BACnet points are writable?

38 of the 68 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official EVAPCO eco-Air Controller (AC / NEMA Motors) BACnet documentation?

The source is EVAPCO Controller User's Manual Addendum - Communications Guide AC Motor Edition (COMM24 AC-E), revision 2025-10, published free by EVAPCO at https://www.evapco.eu/media/772760.

What are the minimum BACnet points to integrate the EVAPCO eco-Air Controller (AC / NEMA Motors)?

Start with BV 0 bnEnableUnit (BMS enable/disable when configured for BMS enable); AV 16 bnUnitState (Operating state and reason it is off); AV 0 bnOutletTemp (Process fluid outlet temperature); AV 2 bnActiveSetpoint (Setpoint currently in control); AV 3 bnSetpointTemp (Primary process setpoint (writable)); BV 10 bnCommonAlarmStatus (Common alarm output status); AV 33 bnRefFanSpeed (Commanded fan speed).

How do I enable BMS control of the EVAPCO eco-Air Controller (AC / NEMA Motors)?

Write BV 0 bnEnableUnit = 1 (only works when the unit is configured to be enabled via BMS); AV 16 = 4 means off via BMS.

Can the BMS supply sensor values to the EVAPCO eco-Air Controller (AC / NEMA Motors)?

Remote fan speed: BV 77 bnRemoteEnable = 1, AV 101 bnRemoteSource = 2 (Communication), then write AV 105. AV 103/AV 104 set the fallback speeds used if the analog speed input is lost.
