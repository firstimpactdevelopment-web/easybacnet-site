Short answer

The JOHB-SMP3 is a plug-in card that puts Yaskawa HVAC and general-purpose drives on BACnet IP. Each object maps to a drive Modbus register, so the same list covers several drive families; bypass-only and gateway-mode objects simply do not appear on a plain drive. AV29/AV30 give generic read/write access to any drive register.

This page lists 213 BACnet objects for the Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives) — 67 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Yaskawa’s own free documentation, linked below.

BMS integration notes: Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives)

Integration in brief

Set b1-01 = 3 (Option PCB) so the BMS sets frequency and b1-02 = 3 or 9 so it starts and stops the drive. Write BV1 Run FWD Cmd (BV58 on a bypass) and AV2 Frequency Cmd, read BV13/BV16 and AV10/AV12/AV13, and reset with BV4. Set the device instance in F6-48/F6-49 and the IP settings in F7-xx, and decide on the F7-57 bus timeout.

Enable & remote start

b1-01 Frequency Reference Selection 1 = 3 (Option PCB) and b1-02 Run Command Selection 1 = 3 (Option PCB) or 9 (AUTO Command + Option Run); both default to 1. On a bypass use BV58/BV59 instead of BV1/BV2. BV5 Drive Com Net Command and BV6 Drive Com Control Command (COM/LOCAL) are also provided. In HAND or LOCAL mode the drive ignores the network and disables the bus timeout.

Heartbeat & communication loss

F7-57 BACnet/IP bUS Timeout Value: when above 0 the BMS must keep sending AV2 Frequency Cmd or a run command (AV1, BV1, BV2, BV58, BV59, AV43-AV51). If none arrives within that time while the drive is running, it trips on bUS Option Communication Error, handled per F6-01 (0 ramp, 1 coast (default), 2 fast stop, 3 alarm only, 4 alarm and run at d1-04, 5 alarm and ramp stop). F7-57 = 0 disables it. Switching to AUTO/REMOTE with no recent command gives an immediate bUS. With F6-14 = 1 and F6-01 set to 0-2, the option resets the fault and returns control to BACnet when comms recover.

Sensors & values from the BMS

AV3 PI Setpoint Cmd lets the BMS write the PI setpoint; BO4 Ref Sel: PI Setpoint (or AV5 bit 1) selects it as the setpoint input.

Network setup

  • Device instance = F6-49 (high word) and F6-48 (low word), in hex; e.g. instance 1234 is F6-48 = 4D2, F6-49 = 0.
  • F7-13 picks static or DHCP addressing (default DHCP); static IP, mask and gateway are F7-01 to F7-12 (defaults 192.168.1.20 / 255.255.255.0 / 192.168.1.1).
  • F7-50 sets the BACnet UDP port (default 47808); F7-51 to F7-56 set BBMD foreign registration.
  • F6-xx/F7-xx changes need a power cycle, or F6-15 = 1 Reload Now on non-Z1000U drives.
  • DIP switch S1 must read 75 in monitor U4-75 (switches 1 and 3 on) for BACnet/IP to work.
  • U6-80 to U6-83 show the IP address actually in use.

Watch out for

  • Bits written to AV1 and BV7-BV11 are ORed with the hard-wired digital inputs.
  • Do not combine AV4 with BO1-BO3/BV12, or AV5 with AV1, BO4 or BV9-BV11.
  • F6-01 = 3 or 4 keeps the drive running after a bus fault; provide separate safety stops.
  • With RSTP ring networks, set F7-57 long enough for the ring to converge.
  • Frequency units for AV2, AV9 and AV10 follow drive parameter o1-03.
  • Bypass-only and gateway-mode objects are missing on a plain drive.

Integration notes

  • Device instance is built from drive parameters F6-49 and F6-48; the default object name is 'Yaskawa VFD ID' plus those values in hex.
  • IP settings come from F7-01 to F7-13 (or DHCP); the UDP port is set by F7-50.
  • Object names in the drive may use the shorter network display name shown in each description.
  • Points marked 'bypass only' exist only when the card is in an HV600 or FP605 bypass.
  • AV43-AV65 are gateway-mode objects for up to four downstream drives and only appear in gateway mode.
  • AV4 must not be combined with BO1-BO3 or BV12; AV5 must not be combined with AV1, BO4 or BV9-BV11.

Questions about the Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives)

How many BACnet points does the Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives) have?

This list has 213 BACnet objects: 10 analog inputs, 2 analog outputs, 64 analog values, 32 binary inputs, 11 binary outputs, 94 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives) BACnet points are writable?

67 of the 213 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives) BACnet documentation?

The source is YASKAWA AC Drive Option BACnet/IP Technical Manual, Model JOHB-SMP3 (SIEP C730600 0MB), revision 2023-11, published free by Yaskawa at https://www.yaskawa.eu.com/_downloads/download_d22897.

What are the minimum BACnet points to integrate the Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives)?

Start with BV 1 Run FWD Cmd (Start/stop from the BMS (drive)); AV 2 Frequency Cmd (Frequency reference, units per o1-03); BV 4 Drive Fault Reset (Reset a tripped drive); BV 13 RUN-STOP (Running status); BV 16 FAULT (Fault status); BV 15 READY (Drive ready); AV 10 Output Frequency (Output frequency); AV 12 Output Current (Motor amps); AV 13 Output Power (Drive power); AV 40 Last Drive Fault (Most recent fault code).

How do I enable BMS control of the Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives)?

b1-01 Frequency Reference Selection 1 = 3 (Option PCB) and b1-02 Run Command Selection 1 = 3 (Option PCB) or 9 (AUTO Command + Option Run); both default to 1. On a bypass use BV58/BV59 instead of BV1/BV2. BV5 Drive Com Net Command and BV6 Drive Com Control Command (COM/LOCAL) are also provided. In HAND or LOCAL mode the drive ignores the network and disables the bus timeout.

Does the Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives) need a BACnet heartbeat or have a communication timeout?

F7-57 BACnet/IP bUS Timeout Value: when above 0 the BMS must keep sending AV2 Frequency Cmd or a run command (AV1, BV1, BV2, BV58, BV59, AV43-AV51). If none arrives within that time while the drive is running, it trips on bUS Option Communication Error, handled per F6-01 (0 ramp, 1 coast (default), 2 fast stop, 3 alarm only, 4 alarm and run at d1-04, 5 alarm and ramp stop). F7-57 = 0 disables it. Switching to AUTO/REMOTE with no recent command gives an immediate bUS. With F6-14 = 1 and F6-01 set to 0-2, the option resets the fault and returns control to BACnet when comms recover.

Can the BMS supply sensor values to the Yaskawa JOHB-SMP3 BACnet/IP option (HV600, Z1000U, GA800 drives)?

AV3 PI Setpoint Cmd lets the BMS write the PI setpoint; BO4 Ref Sel: PI Setpoint (or AV5 bit 1) selects it as the setpoint input.
