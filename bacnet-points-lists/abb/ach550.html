Short answer

The ACH550 talks native BACnet MS/TP on its built-in RS-485 port, as master or slave at up to 76.8 kbps. The object list is static: relay and digital input status, relay commands, run/stop and direction commands, two speed references, drive measurements, energy meters, fault history and a parameter mailbox (AV25/AV26 with BV15/BV16). BMS integration notes: ABB ACH550 HVAC drive (embedded BACnet MS/TP)

Integration in brief

Wire the drive to the MS/TP trunk, then command BV10 RUN/STOP CMD and AV16 INPUT REF 1 once the drive is configured for BACnet control. Read BV0, BV2, AV1, AV4 and AV6 for run status, fault, frequency, current and power, and reset faults with BV14. BV18 gives the BMS override control when the normal source is not BACnet.

Enable & remote start

The PICS says command objects only work when the drive is configured for BACnet control, but does not name the parameters. BV18 CTL OVERRIDE CMD hands drive control to BACnet from its normal source; panel HAND has priority over it.

Sensors & values from the BMS

AV27 EXT PID STPT lets the BMS write the external PID setpoint (drive must be configured for BACnet control).

Network setup

  • Native BACnet MS/TP, master or slave, at 9600, 19200, 38400 or 76800 baud.
  • B-ASC device profile, BACnet protocol revision 7, no segmentation.
  • Static device binding is not supported.
  • The PICS does not name the parameters for MAC address, baud or device instance.

Watch out for

  • BI3-BI5 and BO3-BO5 need the OREL-01 relay option.
  • BV16 MBOX WRITE writes any drive parameter by number; double-check AV25 before using it.
  • BV17 LOCK PANEL blocks parameter changes at the keypad.

Integration notes

  • Commandable run, direction and reference objects only work when the drive is configured for BACnet control.
  • BI3-BI5 and BO3-BO5 (relays 4-6) need the OREL-01 relay extension option.
  • BACnet protocol revision 7; B-ASC device profile; no segmentation.
  • The mailbox objects let you read or write any drive parameter by number.

Questions about the ABB ACH550 HVAC drive (embedded BACnet MS/TP)

How many BACnet points does the ABB ACH550 HVAC drive (embedded BACnet MS/TP) have?

This list has 72 BACnet objects: 2 analog inputs, 2 analog outputs, 28 analog values, 12 binary inputs, 6 binary outputs, 22 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which ABB ACH550 HVAC drive (embedded BACnet MS/TP) BACnet points are writable?

28 of the 72 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official ABB ACH550 HVAC drive (embedded BACnet MS/TP) BACnet documentation?

The source is BACnet Protocol Implementation Conformance Statement - ACH550, revision 2015-03-10, published free by ABB at https://library.e.abb.com/public/e5f255b16dbb950fc1257e04002a0f78/ACH550_PICS_10_03_2015.pdf.

What are the minimum BACnet points to integrate the ABB ACH550 HVAC drive (embedded BACnet MS/TP)?

Start with BV 10 RUN/STOP CMD (Start/stop from the BMS); AV 16 INPUT REF 1 (Speed reference in %); BV 14 FAULT RESET (Reset a tripped drive); BV 0 RUN/STOP ACT (Running status); BV 2 FAULT ACT (Fault status); BV 4 HAND/AUTO ACT (Shows if the panel has the drive in Hand); AV 1 OUTPUT FREQ (Output frequency); AV 4 CURRENT (Motor amps); AV 6 POWER (Drive power in kW); AV 18 LAST FLT (Most recent fault code).

How do I enable BMS control of the ABB ACH550 HVAC drive (embedded BACnet MS/TP)?

The PICS says command objects only work when the drive is configured for BACnet control, but does not name the parameters. BV18 CTL OVERRIDE CMD hands drive control to BACnet from its normal source; panel HAND has priority over it.

Can the BMS supply sensor values to the ABB ACH550 HVAC drive (embedded BACnet MS/TP)?

AV27 EXT PID STPT lets the BMS write the external PID setpoint (drive must be configured for BACnet control).
