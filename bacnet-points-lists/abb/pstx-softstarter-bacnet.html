Updated 6 November 2026

Short answer

The PSTX softstarter talks BACnet MS/TP or BACnet IP through a plug-in Anybus CompactCom module. Binary Values carry run, fault, warning and I/O status plus start/stop, reset, motor heating, emergency mode and relay commands; Analog Values carry mains and motor electrical data, energy, temperatures, event codes and a mailbox for any other parameter. BACnet control starts only after BV 18 Control-Override-Command is set.

BMS integration notes: ABB PSTX softstarter with Anybus CompactCom BACnet (MS/TP and IP)

Integration in brief

Set 12.02 FB interface connector = Anybus and a valid device instance in 12.33 (the default 4194303 does not work), plus the IP or MS/TP address. Write BV 18 = On to give BACnet control, then start/stop with BV 10 and reset faults with BV 14. Read run, fault and ready status and the motor current.

Enable & remote start

Write BV 18 Control-Override-Command = 1 (On) to put the softstarter in BACnet control; BACnet then overrides the DI logic for start/stop, motor heating, lock parameters, emergency mode, user-defined trip and stand still brake. Local control from the HMI always has priority. Parameter 12.03 Fieldbus control is not needed for control; it only enables the timeout protection.

Heartbeat & communication loss

BACnet has no built-in timeout. To trip on lost communication set 12.03 Fieldbus control = On, 19.03 Fieldbus failure out (event group), 19.04 Fieldbus failure op (action) and 19.12 Fieldbus failure timeout (seconds without a message).

Network setup

  • 12.02 FB interface connector = Anybus.
  • 12.33 Fieldbus BACnet Device Instance: 0-4194302; the default 4194303 is invalid and communication will not work.
  • BACnet IP: 12.05 IP address; foreign device registration with 12.34 BBMD IP, 12.35 BBMD UDP port and 12.36 registration interval.
  • BACnet MS/TP: 12.04 MAC address 0-127; baud 9600-76800.
  • Power-cycle, or set 12.02 to None and back to Anybus, after changing communication parameters.

Watch out for

  • The HMI local mode always beats BACnet control override.
  • Restoring default object names needs a full parameter reset from the HMI, which also resets the communication parameters.
  • Device Communication Control default password is Admin.

Integration notes

  • Instance gaps are reserved by ABB and do not exist.
  • BV 9 Enable-Monitor has no access mark in the manual; listed as read-only.
  • AV 125 fault codes include 0 none, 1 high current, 2 phase loss, 3 heat sink overtemperature, 4 bad network quality and more; AV 126 / AV 127 list warning and protection codes the same way (see the manual pp24-25).
  • Temperatures are printed as 'in degrees' without a unit; no unit is shown.
  • Ranges such as '10 x nominal current' depend on the softstarter size.
  • Any other PSTX parameter can be read or written through the mailbox: write its fieldbus ID to AV 25, then read or write AV 26.
