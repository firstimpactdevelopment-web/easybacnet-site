Short answer

The M4M 20 and M4M 30 BACnet network analyzers serve BACnet IP with a fixed object list. Readings are Analog Values: voltages, currents, energies by tariff, power, power quality (THD, unbalance, frequency, power factor), phase angles, average/min/max values and, on the M4M 30, individual harmonics 2-40. A few Integer Values and one Multi-state Value hold CT/VT ratios, wiring scheme and active tariff.

BMS integration notes: ABB M4M 20 / M4M 30 network analyzer (BACnet IP)

Integration in brief

Give the meter a unique device instance and IP settings, then read energy (AV 100), total power (AV 220), voltages, currents, frequency and power factor. Set the CT/VT ratios (IV 3400-3403) and wiring scheme (MV 3501) at commissioning, not from the BMS in normal operation.

Network setup

  • Device object identifier and object name are writable (example shows device 228).
  • Foreign device registration: enable BBMD mode and set the BBMD IP address, UDP port and TTL in the meter.
  • Device profile B-ASC; DeviceCommunicationControl is supported for a finite time only, no password.

Watch out for

  • No segmentation: requests whose reply exceeds 480 octets are rejected; split them.
  • IV 3301 Active tariff is only writable when the tariff source is set to communication (M4M 30).

Integration notes

  • The manual gives no units and no access column for the measurement objects; they are read-only measurements (access inferred). The configuration IVs and the MV are marked writable in the manual.
  • Harmonics objects 1102-1940 (2nd-40th harmonic of voltages L1, L2, L3, L1-L2, L2-L3, L1-L3 and currents L1, L2, L3) exist on the M4M 30 only.
  • Object types come from the section headings: 3.2.2-3.2.9 Analog Value, 3.2.10 Integer Value, 3.2.11 Multi-state Value, 3.2.12 Characterstring Value.
  • Some names are printed with typos (e.g. 'Unbalace current'); kept as printed.
  • No segmentation; max APDU 480 octets, so split large ReadPropertyMultiple requests.

Questions about the ABB M4M 20 / M4M 30 network analyzer (BACnet IP)

How many BACnet points does the ABB M4M 20 / M4M 30 network analyzer (BACnet IP) have?

This list has 492 BACnet objects: 483 analog values, 1 multi-state value, 1 characterstring value, 7 integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which ABB M4M 20 / M4M 30 network analyzer (BACnet IP) BACnet points are writable?

8 of the 492 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official ABB M4M 20 / M4M 30 network analyzer (BACnet IP) BACnet documentation?
