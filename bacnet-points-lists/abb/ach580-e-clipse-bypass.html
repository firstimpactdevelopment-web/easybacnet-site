Short answer

The E-Clipse bypass has its own controller with an embedded BACnet MS/TP port. Its objects cover bypass relay and digital I/O status, system run, fault, warning and mode flags, start/stop, override, permissive, interlock and reset commands, and current, voltage, energy and run-time values. With bypass parameter 1625 COMM CTL = SYSTEM, start/stop and interlocks go through these bypass objects instead of the drive's.

BMS integration notes: ABB ACH580 E-Clipse and packaged bypass (bypass BACnet objects)

Integration in brief

Set 9802 COMM PROT SEL = BACNET (5). The bypass is its own MS/TP node: give it a unique MAC in 5003 (default 256 keeps it off the network) and a device instance in 5040/5099. Then set 1625 COMM CTL = SYSTEM and 1601 = COMM, command BV10 and read BV0, BV3, BV4 and AV0.

Enable & remote start

Bypass parameter 1625 COMM CTL = (1) SYSTEM makes the bypass objects the control path; 1601 = COMM is needed for BV10 run/stop and 1701 = COMM for BV11 override. BV20 CTL OVERRIDE CMD puts the bypass in BACnet control override; panel HAND mode still has priority.

Heartbeat & communication loss

Bypass parameters 3004 COMM LOSS (action) and 3005 COMM TIME (timeout) set the reaction to lost communication; fault 3028 EXT COMM LOSS shows when the BMS does not poll within 3005.

Network setup

  • 9802 COMM PROT SEL = BACNET (5) turns on the shared EIA-485 port; baud (5804) and parity (5805) in group 58 apply to both the drive and bypass nodes.
  • Bypass node: MS/TP MAC in 5003 (default 256 = not visible on the network; set a unique value 1-127 to use the bypass objects). Setting 5003 to 0 holds the channel in reset.
  • Bypass device instance = 5040 (lower word) + 5099 (upper word).
  • The drive node is set separately in group 58 (MAC 5803, device instance 5840/5899); drive and bypass addresses must be unique.
  • After changing communication settings, cycle power or set the station ID to 0 and back.
  • Only the Device object name is writable; set it from the BMS so it is unique.

Watch out for

  • BV10-BV18 do nothing while 1625 COMM CTL = DRIVE ONLY.
  • Panel HAND mode beats BACnet control override (BV20).
  • Bypass MS/TP token counter 5013 should keep rising when communication is healthy.

Integration notes

  • The drive's own objects (manual pp135-144) follow the ACH580 drive list and are in the separate ACH580 entry.
  • With 1625 COMM CTL = DRIVE ONLY, bypass objects BV10-BV18 are not valid and the drive objects are used; with 1625 = SYSTEM the drive's control objects are not available.
  • Commands need their bypass source parameter set to COMM: 1601 for BV10 run/stop, 1602 BV12 permissive, 1607 BV14 reset, 1603-1606 BV15-BV18 interlocks, 1701 BV11 override; relay outputs BO0-BO4 need 1401/1404/1407/1410/1413.
  • AV12 is printed with the name 'C-B VOLT' but described as phase C - phase A voltage; kept as printed.
  • AV5 WARNING WORD 2 is described in the manual as the 'first' warning word, apparently a copy error.

Questions about the ABB ACH580 E-Clipse and packaged bypass (bypass BACnet objects)

How many BACnet points does the ABB ACH580 E-Clipse and packaged bypass (bypass BACnet objects) have?

This list has 54 BACnet objects: 15 analog values, 11 binary inputs, 5 binary outputs, 23 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which ABB ACH580 E-Clipse and packaged bypass (bypass BACnet objects) BACnet points are writable?

22 of the 54 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
