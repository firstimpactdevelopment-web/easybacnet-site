Short answer

The Multistack web portal is a gateway that talks to a COMPU25 chiller master controller over RS-232 and publishes its data as BACnet IP Analog and Binary Values. The BAS can start and stop the chiller, write the upper/lower chilled water setpoints, VSP and load limit, and read system temperatures, per-compressor status, suction and leaving water temperatures, coded fault values and a 20-entry fault review. This is an older product; the manual dates from 2008.

BMS integration notes: Multistack COMPU25 Chiller Controller - BACnet Web Portal (legacy)

Integration in brief

Connect the portal's 10BaseT port to the BACnet IP network and discover device 610001. Start and stop the chiller with BV 33 and check BV 1 for the real state, since the chiller keypad can override it. Write the upper/lower setpoints and load limit to AV 135, 136 and 138, and supervise with the system water temperatures, capacity and fault points.

Enable & remote start

BV 33 ON/OFF CONTROL turns the chiller on (1) or off (0) and should stay on while the BAS wants it running. The hard-wired EX2 input on the COMPU25 must also be closed for the chiller to run; its state shows on BV 3. Multistack also suggests a BAS dry contact on EX2 as an alternative to the network command.

Network setup

  • Default device instance 610001; changing it needs Multistack.
  • Default IP 192.168.1.101, mask 255.255.255.0, gateway 0.0.0.0, UDP port 47808, BACnet network number 6100.
  • The portal runs BACnet IP only over its 10 Mbps 10BaseT port; the BAS supplies the CAT5 cable.
  • Portal-to-COMPU25 link is RS-232 at 2400 baud, 8N1, fixed; maximum 50 ft, with the RS232/RS485 jumper set to RS-232.
  • Addressing DIP switches should be set with 3 and 4 ON, 1, 2 and 5 OFF.

Watch out for

  • BV 33 has the same priority as the chiller's keypad. If someone stops the chiller locally, BV 1 goes off while BV 33 stays on; the BAS must write BV 33 off briefly, then on again to restart.
  • Write points are write-only; read the current values from the separate read points.
  • FAULTS C1-C24 and FAULT 1-20 TYPE are coded numbers; decode them with the manual's fault tables (Off mode, Current, Reset, Record).
  • Fault review entries rotate: MOST CURRENT FAULT (AV 154) says which of the 20 slots is newest.
  • Most system faults (EX1, EX3, flow, low CHW temperature) need a reset at the COMPU25 before the chiller restarts.

Integration notes

  • Legacy product: the manual is dated May 2008. This copy is hosted by a third party (Chipkin), not on a Multistack site.
  • Points exist for 24 compressors; AV 1 reports how many are actually installed.
  • Write points (AV 135-143, BV 33) are write-only; read the values back from the matching read points (AV 9-17, BV 1).
  • The manual's text gives different instance numbers for some points (write setpoints as AV 134-142, flush time/duration as AV 153/154) than its Table 3. Table 3 is self-consistent (AV 134 is FAULT 20 COMP #, AV 153-154 are HRS @ 90-100% and MOST CURRENT FAULT) and the text has other slips, so this list follows Table 3; confirm with a device discovery.
  • Units are not printed in the table; temperatures follow the manual's degrees F.
  • Object names are the table's reference names; the short labels (e.g. ENT CHW SYS TEMP) are in the descriptions.

How many BACnet points does the Multistack COMPU25 Chiller Controller - BACnet Web Portal (legacy) have?

This list has 187 BACnet objects: 154 analog values, 33 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Multistack COMPU25 Chiller Controller - BACnet Web Portal (legacy) BACnet points are writable?

10 of the 187 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
