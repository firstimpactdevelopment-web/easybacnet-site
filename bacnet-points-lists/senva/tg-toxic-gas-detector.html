Senva TG Series toxic gas detector (BACnet MS/TP) BACnet points list

Updated 6 November 2026

Short answer

The TG is a Senva toxic gas detector with BACnet MS/TP. Each measurement (temperature, gas sensor 1 and 2, supply voltage) has a primary Analog Input plus Smoothed, Minimum, Maximum and Average objects. Analog Values hold the warning and alarm setpoints, hysteresis, sensor life and RS-485 settings; commandable Binary Outputs drive the fan relay, alarm relay and buzzer, and MSV 170 reports the Normal / Warning / Alarm / Extended Alarm state.

BMS integration notes: Senva TG Series toxic gas detector (BACnet MS/TP)

Integration in brief

Connect to an active MS/TP network and let the TG auto-detect baud, protocol and address, then read the gas readings and MSV 170. The relays and buzzer run automatically from the setpoints; the BMS can override them through the BO priority array.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

The device writes the relays at priority 16 from the system state; commands at priorities 1-5 override immediately, 7-15 respect minimum on/off times. Priority 6 is reserved.

Network setup

  • Factory default is automatic baud (9600-115200), protocol and MAC (0-127) detection on an active MS/TP network.
  • Writing AV 123 or AV 124 turns off the automatic address or baud selection.
  • Device Max_Master and Max_Info_Frames are writable.

Watch out for

  • There is no remote way back after changing the baud rate; the device goes silent until the controller matches it.
  • AV 190 (key 9699690) wipes the configuration, including the RS-485 settings.
  • With BV 114 Auto Baud active, the TG will not start a token on an idle line.

Integration notes

  • Points from the object list and object sections of protocol guide 154-0035-0B; it replaces the older TG guide 154-0032-0A.
  • The secondary analog inputs are printed only as "Smoothed", "Minimum", "Maximum" and "Average" under each primary AI (primary + 2, 4, 6, 8); names kept as printed.
  • Minimum, Maximum and Average reset when 0 is written to them, when AV 192 is written with its key, or on read if BV 195 is active.
  • Sensor 2 and thermistor objects exist only on models with those features. Gas units are not printed; ppm is assumed from the setpoint text.
  • Multistate objects are MSV in the guide; listed here as MV. FILE 25000 holds a read-only copy of the configuration.

Questions about the Senva TG Series toxic gas detector (BACnet MS/TP)

How many BACnet points does the Senva TG Series toxic gas detector (BACnet MS/TP) have?

This list has 61 BACnet objects: 20 analog inputs, 24 analog values, 3 binary outputs, 9 binary values, 1 file, 4 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Senva TG Series toxic gas detector (BACnet MS/TP) BACnet points are writable?

50 of the 61 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Senva TG Series toxic gas detector (BACnet MS/TP) BACnet documentation?

The source is BACnet Protocol Guide TG (154-0035-0B), revision 2021-03-12, published free by Senva at https://www.senvainc.com/catalog/documents/downloadcenter/TG%20BACnet%20Protocol%20Guide%20154-0035-0B.pdf.
