BMS integration notes: Nuaire EcoSmart Connect (CO) control (XBOXER XBC, BPS, BOXER), 2026 object list

Integration in brief

Write MV 28511 Unit Enable to 1 (On) to run the unit, then set AV 28632 Fan Speed Command (0-100 %) and AV 28654 Software Setpoint (12-28 °C). Read the supply, fresh and return air temperatures, MV 28536 Fan Command and the alarm MSVs; MV 28660 resets alarms. Nuaire recommends writing AVs and MSVs at priority 16.

Enable & remote start

The unit runs when any enable source is active: the Unit Enable MSV (local display or network), volt-free inputs, night cooling, the internal enable schedule, a fan speed override or a room module PIR. When the enable is removed the unit runs on for the run-on time.

Sensors & values from the BMS

MV 28612 Setpoint Operation picks whether the last changed setpoint wins, software only, or last changed with a timeout.

Network setup

  • BACnet MS/TP only; default MS/TP address 4 (AV 29506, range 4-127). Baud rate is MV 28507.
  • Device instance (AV 29505 Device OID) is unique from the factory.

Watch out for

  • Write AVs and MSVs at priority 16. Do not write outputs; if you must for testing use priority 8 and relinquish afterwards.
  • Priorities 8 and 16 survive a power cycle; other priority levels are cleared.
  • Instance numbers changed between Nuaire's 2022 and 2026 manuals; confirm against the unit.

Integration notes

  • The list has no read/write column. Access here is inferred: sensor values, statuses, outputs, alarms and trend logs are R; enables, setpoints, commands and configuration are W.
  • Multistate values are printed with 0-based numbers (0 = Off, 1 = On); listed as printed. Check the live State_Text, since BACnet multistate values normally start at 1.
  • MV 28677 is printed twice, as PAC Board Alarm (BPS, reverse cycle DX only) and as Sensor Alarm; both rows are kept. IN16 CO2 Sensor (28512) and IN16 Temperature Sensor (28513) are printed as MSV with analogue ranges.
  • Rows repeated in the source (four schedules, RM200 temperature and humidity) were listed once; the device object row is left out.
  • RM199-RM206 are up to eight room modules on the controller's sensor bus; their objects only carry values when that module is fitted.
  • Nuaire's 2022 manual (672040) uses different instance numbers for many objects; that list is kept as a separate entry.

Which Nuaire EcoSmart Connect (CO) control (XBOXER XBC, BPS, BOXER), 2026 object list BACnet points are writable?

119 of the 207 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
