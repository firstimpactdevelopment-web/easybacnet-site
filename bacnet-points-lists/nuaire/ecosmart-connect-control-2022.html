Short answer

The EcoSmart Connect controller is a BACnet MS/TP device (default MAC address 4) built into Nuaire XBC, BPS and BOXER units. Nuaire's object list has 192 numbered objects, all AVs and multistate values in the 28501-28693 range: unit enable, network setpoint and fan speed command, sensor readings from up to eight RM room modules, configuration selections, and alarm MSVs. Two schedules and seven trend logs are listed without instance numbers and are not included here.

BMS integration notes: Nuaire EcoSmart Connect control (XBOXER XBC, BPS, BOXER), 2022 object list

Integration in brief

Write MV 28512 Unit Enable to On to run the unit, then set AV 28637 Fan Speed Command (0-100 %) and AV 28669 Network Setpoint. Read the fresh, supply and return air temperatures, MV 28537 Fan Command and the alarm MSVs; MV 28681 resets alarms. Nuaire recommends writing AVs and MSVs at priority 16.

Enable & remote start

The unit runs when any enable source is active: the Unit Enable MSV (local display or network), volt-free inputs, night cooling, the weekly schedule, a fan speed override or a room module PIR. When the enable is removed the unit runs on for the run-on time.

Sensors & values from the BMS

MV 28613 Setpoint Operation picks whether the last changed setpoint wins, software only, or last changed with a timeout (AV 28665 Setpoint Timeout). AV 28623 accepts a 0-10 V style fan speed demand from the network.

Network setup

  • BACnet MS/TP only; default MS/TP address 4 (AV 28505, range 4-127). Baud rate is MV 28508, Auto by default.
  • Device instance is assigned at the factory and normally left as is; AV 28506 Device OID holds it.

Watch out for

  • Write AVs and MSVs at priority 16. Do not write outputs; if you must for testing use priority 8 and relinquish afterwards.
  • Priorities 8 and 16 survive a power cycle; other priority levels are cleared.
  • The manual's operation text calls the fan and setpoint objects 'Fan Speed Demand' and 'Software Setpoint'; the object list names them Fan Speed Command and Network Setpoint.

Integration notes

  • The list has no read/write column. Access here is inferred: sensor values, statuses, outputs and alarms are R; enables, setpoints and configuration are W.
  • Multistate ranges are printed as state texts only (for example Off / On / Hold); they are listed in that order. Enumerated AVs (fan speed request, occupancy) give their numbers.
  • RM199-RM206 are up to eight room modules on the controller's sensor bus; their objects only carry values when that module is fitted.
  • Rows printed without an instance (service and notification objects, two schedules, seven trend logs) are left out.
  • Nuaire's July 2026 manual (672059) renumbers many objects and is a separate entry; some Nuaire quick guides use a 10xxx range. Match the list to the unit's own manual.

Questions about the Nuaire EcoSmart Connect control (XBOXER XBC, BPS, BOXER), 2022 object list

How many BACnet points does the Nuaire EcoSmart Connect control (XBOXER XBC, BPS, BOXER), 2022 object list have?

This list has 192 BACnet objects: 113 analog values, 79 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Nuaire EcoSmart Connect control (XBOXER XBC, BPS, BOXER), 2022 object list BACnet points are writable?

117 of the 192 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Nuaire EcoSmart Connect control (XBOXER XBC, BPS, BOXER), 2022 object list BACnet documentation?

The source is EcoSmart Connect Control Operation Manual, 1.36 BACnet Object List (By Category) (672040), revision 2022-02-15, published free by Nuaire at https://info.nuaire.co.uk/IandM/672040.pdf.

What are the minimum BACnet points to integrate the Nuaire EcoSmart Connect control (XBOXER XBC, BPS, BOXER), 2022 object list?

Start with MV 28512 Unit Enable (Unit enable (Off / On)); AV 28637 Fan Speed Command (Fan speed demand, 0-100 %); AV 28669 Network Setpoint (Temperature setpoint from the network, 12-28); MV 28681 Alarm Reset (Alarm reset); MV 28537 Fan Command (Fan enable output (OUT10) status); AV 28502 Supply Air Temperature (Supply air temperature); AV 28501 Fresh Air intake (Fresh (outdoor) air temperature); AV 28503 Return Air Temperature (Return air temperature); MV 28539 Unit Fault Status (Fault relay status); MV 28685 Active Critical Alarms (Critical alarm active).

How do I enable BMS control of the Nuaire EcoSmart Connect control (XBOXER XBC, BPS, BOXER), 2022 object list?

The unit runs when any enable source is active: the Unit Enable MSV (local display or network), volt-free inputs, night cooling, the weekly schedule, a fan speed override or a room module PIR. When the enable is removed the unit runs on for the run-on time.

Can the BMS supply sensor values to the Nuaire EcoSmart Connect control (XBOXER XBC, BPS, BOXER), 2022 object list?

MV 28613 Setpoint Operation picks whether the last changed setpoint wins, software only, or last changed with a timeout (AV 28665 Setpoint Timeout). AV 28623 accepts a 0-10 V style fan speed demand from the network.
