BMS integration notes: Regin Exigo 4.3 heating controller

Integration in brief

Use MV 30002 ModeSwitch for the plant mode (off, auto, summer, holiday, continuous) and MV 31390 HS1_Select for heating circuit 1. Read AV 40001 outdoor temperature, AV 40026 / AV 40032 HS1 supply temperature and calculated setpoint, AV 40027 room temperature, BV 20004 pump status and the deviation alarms. BV 10014 acknowledges all alarms.

Enable & remote start

MV 30002 ModeSwitch sets the overall mode; each circuit also has a Manual/Auto selector (for example MV 31390 HS1_Select) that must be on Auto for normal control.

Watch out for

  • Setpoints and configuration values are stored in the controller; do not write them cyclically.

Integration notes

  • Temperature and pressure objects marked "(configurable)" in the EDE take the unit set in the controller (for example °C or °F), so no unit is given for them.
  • Objects for circuits, boilers and meters that are not configured stay unused.
  • Object names with (0) in them are printed that way in the EDE.
  • There is no single sum-alarm object; alarms are individual BVs (AlaPt(n)) plus three notification classes.
  • The EDE file does not say which BACnet data link (BACnet IP or BACnet MS/TP) the controller uses; check the model data sheet.

Questions about the Regin Exigo 4.3 heating controller

How many BACnet points does the Regin Exigo 4.3 heating controller have?

This list has 623 BACnet objects: 304 analog values, 195 binary values, 11 calendars, 3 notification classs, 11 schedules, 89 multi-state values, 10 characterstring values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Regin Exigo 4.3 heating controller BACnet points are writable?

236 of the 623 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Regin Exigo 4.3 heating controller BACnet documentation?

The source is Exigo 4.3 BACnet files (EDE) (BACnet_Exigo43_EDE), revision 2026-04, published free by Regin at https://www.regincontrols.com/globalassets/pimmediafiles/documents/exigo-4.3-bacnet-files2.zip.

What are the minimum BACnet points to integrate the Regin Exigo 4.3 heating controller?

Start with MV 30002 ModeSwitch (1 off, 2 auto, 3 summer, 4 holiday, 5 continuous); MV 31390 HS1_Select(0) (Heating circuit 1: off, manual, auto); AV 30003 HS1RoomSetP_OT1 (HS1 room setpoint, occupancy time 1); AV 40001 OutDoorTemp(0) (Outdoor temperature); AV 40026 HS1SupplyTemp(0) (HS1 supply temperature); AV 40032 HS1CalcSetpointSupply(0) (HS1 calculated supply setpoint); AV 40027 HS1RoomTemp(0) (HS1 room temperature); BV 20004 HS1PumpARun(0) (HS1 pump P1A running); BV 20158 AlaPt(2) (HS1 supply temperature deviation alarm).

How do I enable BMS control of the Regin Exigo 4.3 heating controller?

MV 30002 ModeSwitch sets the overall mode; each circuit also has a Manual/Auto selector (for example MV 31390 HS1_Select) that must be on Auto for normal control.
