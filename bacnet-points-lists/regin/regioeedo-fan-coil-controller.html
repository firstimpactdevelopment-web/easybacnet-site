Regin RegioEedo fan coil room controller BACnet points list

Updated 4 November 2026

Short answer

RegioEedo is a 230 V fan coil controller for ceiling-void or DIN-rail mounting, with 3-speed or EC fan control, heating/cooling valves, change-over, CO2 and presence functions. It talks EXOline, Modbus or BACnet MS/TP on its RS485 ports and BACnet IP on Ethernet. Its fixed BACnet list shares names and instance numbers with the RegioArdo, but covers one room.

This page lists 258 BACnet objects for the Regin RegioEedo fan coil room controller — 136 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Regin’s own free documentation, linked below.

BMS integration notes: Regin RegioEedo fan coil room controller

Integration in brief

Select BACnet on the RS485 port (or BACnet IP on the Ethernet port) in Application tool, then command the unit state with RegioControllerStateRemote (MV 30010) and set the comfort setpoints. If the communication heartbeat is enabled, the BMS must keep writing RegioCommFailsafe (BV 10009). Read RegioControlState, RegioRoomTemp and the sum alarm for status.

Enable & remote start

RegioControllerStateRemote (MV 30010) forces off, unoccupied, standby or occupied; 6 = no remote control hands control back to the controller's own logic.

Heartbeat & communication loss

Optional communication heartbeat: when enabled (RegioEnableCommFailsafe, BV 10010) the BMS must set RegioCommFailsafe (BV 10009) to 1 within the failsafe time (default 10 min). If it doesn't, the controller goes to the configured failsafe state (RegioFailsafeState, MV 30182; default Off), raises an alarm and shows RegioCommFailsafeActive (BV 20099).

Sensors & values from the BMS

In the BACnet list only the underfloor temperature can come from the network: set RegioRemoteUnderfloorTempSelect (BV 10012) and write RegioRemoteUnderfloortemp (AV 30202). The BMS can also shift the setpoint with RegioSetPOffsetRemote (AV 30009).

Network setup

  • RS485 ports 1 and 2 support EXOline, Modbus or BACnet MS/TP; the Ethernet port supports BACnet IP (RegioBACnetIpEnable).
  • Protocol, MAC address and device ID are set in Application tool.

Watch out for

  • With the heartbeat enabled, a BMS that stops writing BV 10009 puts the room into the failsafe state (Off by default).
  • Setpoints, P-band, I-time and alarm delays are stored settings; don't write them cyclically.

Integration notes

  • Object list from Appendix D of the RegioEedo manual rev G (2023-09-19), pages 104-116.
  • The manual lists only Multistate Value, Binary Value and Analog Value objects; the instance numbers are fixed (BV 1xxxx/2xxxx, AV and MV 3xxxx/4xxxx).
  • The BACnet table has no units column; units are left blank here (temperatures are °C).
  • Signals footnoted in the manual need firmware 2.0-1-04 or later (some alarm and underfloor-heating objects need 2.0-1-05).
  • Value objects are not commandable; the last write wins. Object names can be renamed from BACnet or Application tool.

Questions about the Regin RegioEedo fan coil room controller

How many BACnet points does the Regin RegioEedo fan coil room controller have?

This list has 258 BACnet objects: 136 analog values, 68 binary values, 54 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Regin RegioEedo fan coil room controller BACnet points are writable?

136 of the 258 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Regin RegioEedo fan coil room controller BACnet documentation?

The source is RegioEedo manual (MA30002), revision Rev. G, 2023-09-19, published free by Regin at https://www.regincontrols.com/globalassets/pimmediafiles/documents/regio_eedo_ma30002_en.pdf.

What are the minimum BACnet points to integrate the Regin RegioEedo fan coil room controller?

Start with MV 30010 RegioControllerStateRemote (Unit state command: off, unoccupied, standby, occupied); AV 30001 RegioHeatSetPointOccupied (Occupied heating setpoint); AV 30002 RegioCoolSetPointOccupied (Occupied cooling setpoint); MV 30118 RegioFanSelect (Fan speed command: off, speed 1-3 or auto); BV 10009 RegioCommFailsafe (Heartbeat; write 1 to reset the failsafe timer); MV 40027 RegioControlState (Current unit state); AV 40026 RegioRoomTemp (Room temperature (internal or external sensor)); BV 20033 RegioSumAlarm (Sum alarm); BV 20042 RegioRoomTempSensorAlarm (Room sensor fault).

How do I enable BMS control of the Regin RegioEedo fan coil room controller?

RegioControllerStateRemote (MV 30010) forces off, unoccupied, standby or occupied; 6 = no remote control hands control back to the controller's own logic.

Does the Regin RegioEedo fan coil room controller need a BACnet heartbeat or have a communication timeout?

Optional communication heartbeat: when enabled (RegioEnableCommFailsafe, BV 10010) the BMS must set RegioCommFailsafe (BV 10009) to 1 within the failsafe time (default 10 min). If it doesn't, the controller goes to the configured failsafe state (RegioFailsafeState, MV 30182; default Off), raises an alarm and shows RegioCommFailsafeActive (BV 20099).

Can the BMS supply sensor values to the Regin RegioEedo fan coil room controller?

In the BACnet list only the underfloor temperature can come from the network: set RegioRemoteUnderfloorTempSelect (BV 10012) and write RegioRemoteUnderfloortemp (AV 30202). The BMS can also shift the setpoint with RegioSetPOffsetRemote (AV 30009).

How do I check these points on the real RegioEedo fan coil room controller?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
