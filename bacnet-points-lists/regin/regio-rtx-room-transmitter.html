Short answer

Regio RTX is a communicating room transmitter in the Regio family, connected over RS485 with EXOline, Modbus or BACnet MS/TP. The variable list gives 119 BACnet objects: room temperature, CO2, humidity, VOC and presence readings, remote values with enable selectors, per-channel analog/digital input values and overrides, analog outputs with comm-loss defaults, display settings, an extension timer and two custom text rows.

BMS integration notes: Regin Regio RTX room transmitter (firmware 2.0)

Integration in brief

Read AV 10002 room temperature, AV 10011 CO2, AV 10071 humidity, AV 10281 VOC index and BV 10001 presence. Keep BV 9101 RC_OfflineTrigger pulsing if the offline function is used. Values from the BMS can replace the local sensors through the …Remote AVs and their …RemoteSelect BVs.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Heartbeat & communication loss

BV 9101 RC_OfflineTrigger must be written to 1 periodically (the application sets it back to 0) within RC_OfflineTimeout, default 10 s (that timeout is not a BACnet object). MV 9301 RC_OfflineFunction sets the offline reaction. Analog outputs fall back to their IoAnaOut_n_default AV when communication is lost.

Sensors & values from the BMS

AV 10611 / 10621 / 10681 / 10691 take remote room temperature, CO2, humidity and VOC values, each enabled by its …RemoteSelect BV (10321 / 10331 / 10391 / 10401). BV 10411 with BV 10481 does the same for the presence input.

Network setup

  • Port 1 (RS485) protocol, baud rate and format are MV 9001 / 9101 / 9201; write BV 9001 RC_CommSettingsCommit = 1 to apply them.

Watch out for

  • The ..._override_en BVs force an input or output to its override value; clear them after testing.

Questions about the Regin Regio RTX room transmitter (firmware 2.0)

How many BACnet points does the Regin Regio RTX room transmitter (firmware 2.0) have?

This list has 119 BACnet objects: 62 analog values, 43 binary values, 7 multi-state values, 2 characterstring values, 5 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Regin Regio RTX room transmitter (firmware 2.0) BACnet points are writable?

80 of the 119 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Regin Regio RTX room transmitter (firmware 2.0) BACnet documentation?

The source is RTX-2.0-1-02 - Variable list (variables_rtx (Revision A)), published free by Regin at https://www.regincontrols.com/globalassets/pimmediafiles/documents/variables_rtx.xlsx.

What are the minimum BACnet points to integrate the Regin Regio RTX room transmitter (firmware 2.0)?

Start with BV 9101 RC_OfflineTrigger (Write 1 periodically to stay in normal mode); AV 10002 RC_RoomTemp (Room temperature, °C); AV 10011 RC_CO2Level (Room CO2, ppm); AV 10071 RC_Humidity (Room relative humidity); AV 10281 RC_VOC (VOC index); BV 10001 RC_Presence (Presence indication).

Does the Regin Regio RTX room transmitter (firmware 2.0) need a BACnet heartbeat or have a communication timeout?

BV 9101 RC_OfflineTrigger must be written to 1 periodically (the application sets it back to 0) within RC_OfflineTimeout, default 10 s (that timeout is not a BACnet object). MV 9301 RC_OfflineFunction sets the offline reaction. Analog outputs fall back to their IoAnaOut_n_default AV when communication is lost.

Can the BMS supply sensor values to the Regin Regio RTX room transmitter (firmware 2.0)?

AV 10611 / 10621 / 10681 / 10691 take remote room temperature, CO2, humidity and VOC values, each enabled by its …RemoteSelect BV (10321 / 10331 / 10391 / 10401). BV 10411 with BV 10481 does the same for the presence input.

How do I check these points on the real Regio RTX room transmitter (firmware 2.0)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
