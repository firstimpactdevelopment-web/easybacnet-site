BMS integration notes: Regin Regio RCX room controller (firmware 2.1)

Integration in brief

Write MV 10051 RC_RemoteControllerState to set the controller state (off/unoccupied/standby/occupied/bypass) from the BMS, and the occupied heating/cooling setpoints (AV 10361 / AV 10391) or AV 10401 setpoint offset. Keep BV 9101 HeartbeatTrigger pulsing. Read MV 10001 RC_ControllerState, MV 10011 RC_ControllerMode, AV 10002 room temperature, AV 10081 active setpoint and BV 10271 sum alarm.

Enable & remote start

MV 10051 RC_RemoteControllerState sets the state directly via communication; MV 10041 RC_ControllerStateDefault is the state used when nothing else controls it.

Heartbeat & communication loss

BV 9101 HeartbeatTrigger must be written to 1 periodically to keep normal operation (the controller resets it to 0); MV 9301 RC_OfflineFunction sets what happens when the trigger stops (disabled, output defaults, application). MV 10081 RC_ControllerStateFail sets the controller state during communication faults. No timeout value is given in the list.

Sensors & values from the BMS

Each measured value has a remote copy and an enable BV: write AV 10611 RC_RoomTempRemote and set BV 10321 RC_RoomTempRemoteSelect to use a BMS room temperature; the same pattern covers CO2 (AV 10621 / BV 10331), airflow, changeover temperatures, supply air, humidity, VOC, damper position and the digital inputs.

Network setup

  • Port 1 (RS485) protocol, baud rate and format are MV 9001 / 9101 / 9201; write BV 9001 CommCommit = 1 to apply them.

Watch out for

  • Manual/auto select objects (…ManSelect) left on Manual keep an output fixed; BV 10311 RC_AlarmManualOutput flags it.
  • Setpoints and configuration are stored values; do not write them cyclically.

Questions about the Regin Regio RCX room controller (firmware 2.1)

How many BACnet points does the Regin Regio RCX room controller (firmware 2.1) have?

This list has 327 BACnet objects: 169 analog values, 97 binary values, 54 multi-state values, 2 characterstring values, 5 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Regin Regio RCX room controller (firmware 2.1) BACnet points are writable?

230 of the 327 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Regin Regio RCX room controller (firmware 2.1) BACnet documentation?

The source is RCX-... 2.1-1-xx - Variable list (variables_rcx_2.1-1-xx (Revision A)), published free by Regin at https://www.regincontrols.com/globalassets/pimmediafiles/documents/variables_rcx_2.1-1-xx.xlsx.

What are the minimum BACnet points to integrate the Regin Regio RCX room controller (firmware 2.1)?

Start with MV 10051 RC_RemoteControllerState (Controller state set from the BMS); AV 10361 RC_RoomSetpointHeatOccupied (Heating setpoint, occupied, °C); AV 10391 RC_RoomSetpointCoolOccupied (Cooling setpoint, occupied, °C); BV 9101 HeartbeatTrigger (Write 1 periodically to stay in normal mode); MV 10001 RC_ControllerState (Current controller state); MV 10011 RC_ControllerMode (Current mode: off, heating, cooling); AV 10002 RC_RoomTemp (Room temperature, °C); AV 10081 RC_RoomActiveSetpoint (Active room setpoint, °C); BV 10271 RC_SumAlarm (Sum alarm).

How do I enable BMS control of the Regin Regio RCX room controller (firmware 2.1)?

MV 10051 RC_RemoteControllerState sets the state directly via communication; MV 10041 RC_ControllerStateDefault is the state used when nothing else controls it.

Does the Regin Regio RCX room controller (firmware 2.1) need a BACnet heartbeat or have a communication timeout?

BV 9101 HeartbeatTrigger must be written to 1 periodically to keep normal operation (the controller resets it to 0); MV 9301 RC_OfflineFunction sets what happens when the trigger stops (disabled, output defaults, application). MV 10081 RC_ControllerStateFail sets the controller state during communication faults. No timeout value is given in the list.

Can the BMS supply sensor values to the Regin Regio RCX room controller (firmware 2.1)?

Each measured value has a remote copy and an enable BV: write AV 10611 RC_RoomTempRemote and set BV 10321 RC_RoomTempRemoteSelect to use a BMS room temperature; the same pattern covers CO2 (AV 10621 / BV 10331), airflow, changeover temperatures, supply air, humidity, VOC, damper position and the digital inputs.

How do I check these points on the real Regio RCX room controller (firmware 2.1)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
