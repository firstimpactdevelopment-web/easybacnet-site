Short answer

PDTN measures one or two differential pressures and can calculate airflow from them (K-factor formulas). Over RS485 it speaks EXOline, Modbus or BACnet MS/TP. The variable list gives 91 BACnet objects: pressure and flow per channel, range/unit/formula settings, zero calibration, analogue output values with comm-loss defaults, and display settings.

BMS integration notes: Regin Presigo PDTN differential pressure transmitter (firmware 1.1)

Integration in brief

Read AV 10002 PS_1_pressure (and AV 10003 for channel 2) or the calculated flows AV 10004 / AV 10005. Set the units, range and flow formula once at commissioning.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

ObjectNameWhyAccess
AV 10002PS_1_pressureChannel 1 pressure, unit per MV 10003Read
AV 10004PS_1_flowChannel 1 calculated flowRead
AV 10003PS_2_pressureChannel 2 pressure, unit per MV 10004Read
AV 10005PS_2_flowChannel 2 calculated flowRead

Network setup

  • Port 1 (RS485) protocol, baud rate and format are MV 9001 / 9101 / 9201; write BV 9001 CommCommit = 1 to apply them.
  • BV 10001 / BV 10002 PS_x_set_zero run a zero calibration when written to 1.

Watch out for

  • Range, unit and formula objects are configuration; do not write them cyclically.

Integration notes

  • Taken from Regin's variable list (xlsx), "Default BACnet name", "Object type", "Instance", "Unit" and "Writeable" columns; the same file lists the EXOline and Modbus addresses.
  • Names follow the variable list's "Default BACnet name" column. Regin's EDE file for 1.1-1-00 uses other, upper-case names (for example AO1_VALUE for AV 1201 Output_Channel_1_value) and puts most PS1/PS2 settings on the same instance (10000), so it can't be used as an object list.
  • AV 10002/10003 pressures are in the unit set by MV 10003/10004; flows follow MV 10005/10006.
  • Multistate state texts come from the EDE file where the object could be matched by name.

Questions about the Regin Presigo PDTN differential pressure transmitter (firmware 1.1)

How many BACnet points does the Regin Presigo PDTN differential pressure transmitter (firmware 1.1) have?

This list has 91 BACnet objects: 55 analog values, 9 binary values, 19 multi-state values, 2 characterstring values, 6 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Regin Presigo PDTN differential pressure transmitter (firmware 1.1) BACnet points are writable?

79 of the 91 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Regin Presigo PDTN differential pressure transmitter (firmware 1.1) BACnet documentation?

The source is PDTN - 1.1-1-00 Variable list (variables_pdtn_1.1-1-00 (Revision A)), published free by Regin at https://www.regincontrols.com/globalassets/pimmediafiles/documents/variables_pdtn_1.1-1-00.xlsx.

What are the minimum BACnet points to integrate the Regin Presigo PDTN differential pressure transmitter (firmware 1.1)?

Start with AV 10002 PS_1_pressure (Channel 1 pressure, unit per MV 10003); AV 10004 PS_1_flow (Channel 1 calculated flow); AV 10003 PS_2_pressure (Channel 2 pressure, unit per MV 10004); AV 10005 PS_2_flow (Channel 2 calculated flow).
