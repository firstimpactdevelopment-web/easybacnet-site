BMS integration notes: Regin Corrigo 5.0 ventilation (AHU) controller

Integration in brief

Use MV 30788 AirUnitAutoMode to run the unit (off, manual, auto or a forced speed) and AV 30811 SupplySetpoint for the supply air setpoint in constant supply air control. Read MV 40428 UnitMode and MV 40429 UnitModeControl for what is running and why, the supply and outdoor temperatures, and BV 20008/20009 for A- and B-alarms. BV 10000 acknowledges all alarms.

Enable & remote start

MV 30788 AirUnitAutoMode sets the unit running mode (1 OFF, 2 Manual, 3 AUTO, 4-6 low/normal/high speed). MV 30796 ExternalControl selects extended-run speeds; MV 30797 AirUnitServiceStop stops the unit with top priority.

Network setup

  • MV 30808 VentControl selects the temperature control mode (constant supply, outdoor compensated, cascade room, ...); AV 30811 only applies to constant supply air control.

Watch out for

  • Setpoints and configuration values are stored in the controller; do not write them cyclically.
  • Time channel status MVs (TC_..._Status) can force fan speeds on or off; leave them on Auto for schedule control.

Integration notes

  • Temperature and pressure objects marked "(configurable)" in the EDE take the unit set in the controller (for example °C or °F), so no unit is given for them.
  • Which objects carry values depends on the configured functions (control mode, fan type, sequences, expansion units).
  • Descriptions are short forms of the EDE descriptions.
  • The EDE lists the device instance and name as placeholders (@DeviceID / @DeviceName).
  • The EDE file does not say which BACnet data link (BACnet IP or BACnet MS/TP) the controller uses; check the model data sheet.

Questions about the Regin Corrigo 5.0 ventilation (AHU) controller

How many BACnet points does the Regin Corrigo 5.0 ventilation (AHU) controller have?

This list has 840 BACnet objects: 552 analog values, 212 binary values, 1 calendar, 3 notification classs, 7 schedules, 65 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Regin Corrigo 5.0 ventilation (AHU) controller BACnet points are writable?

330 of the 840 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Regin Corrigo 5.0 ventilation (AHU) controller BACnet documentation?

The source is Corrigo 5.0 BACnet files (EDE) (BACnet_Corrigo50_EDE), revision 2023-10, published free by Regin at https://www.regincontrols.com/globalassets/pimmediafiles/documents/corrigo-5.0-bacnet-files.zip.

What are the minimum BACnet points to integrate the Regin Corrigo 5.0 ventilation (AHU) controller?

Start with MV 30788 AirUnitAutoMode (Unit run mode: off, manual, auto or fixed speed); AV 30811 SupplySetpoint (Supply air setpoint (constant supply control)); MV 40428 UnitMode (Actual run mode: stop, start-up, low/normal/high); MV 40429 UnitModeControl (What triggers the current run mode); AV 40292 AI_SupplyAirTemp (Supply air temperature); AV 40290 AI_OutDoorTemp (Outdoor temperature); MV 40451 SAFSpeed (Supply fan speed state); BV 20008 SumAlarmA (Sum A-alarm); BV 20009 SumAlarmB (Sum B-alarm).

How do I enable BMS control of the Regin Corrigo 5.0 ventilation (AHU) controller?

MV 30788 AirUnitAutoMode sets the unit running mode (1 OFF, 2 Manual, 3 AUTO, 4-6 low/normal/high speed). MV 30796 ExternalControl selects extended-run speeds; MV 30797 AirUnitServiceStop stops the unit with top priority.
