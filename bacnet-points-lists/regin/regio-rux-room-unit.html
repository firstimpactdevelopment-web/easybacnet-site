Short answer

BMS integration notes: Regin Regio RUX room unit / display (firmware 2.1)

Integration in brief

Read AV 10002 room temperature, AV 10011 CO2, AV 10071 humidity and AV 10081 active setpoint; write the state setpoints or AV 10401 offset if the BMS manages them. Keep BV 9101 HeartbeatTrigger pulsing if the offline function is used.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Heartbeat & communication loss

BV 9101 HeartbeatTrigger must be written to 1 periodically (the unit resets it to 0); MV 9301 RC_OfflineFunction sets the reaction when it stops. No timeout is given.

Sensors & values from the BMS

AV 10611 / 10621 / 10681 / 10691 take remote room temperature, CO2, humidity and VOC values, each enabled by its …RemoteSelect BV.

Network setup

  • Port 1 (RS485) protocol, baud rate and format are MV 9001 / 9101 / 9201; write BV 9001 CommCommit = 1 to apply them.

Integration notes

  • Taken from Regin's variable list (xlsx), "Default BACnet name", "Object type", "Instance", "Unit" and "Writeable" columns; the same file lists the EXOline and Modbus addresses.
  • Names follow the variable list's "Default BACnet name" column. Regin's EDE zip for RCX/RTX/RUX 2.1-1-01 holds only an RCX file, which uses upper-case names (for example REG_CONTROLLERSTATE) and repeats instances, so it was not used for names.
  • Multistate state texts come from the RCX EDE state-text file (matched by instance or object name); the variable list does not print them.

Questions about the Regin Regio RUX room unit / display (firmware 2.1)

How many BACnet points does the Regin Regio RUX room unit / display (firmware 2.1) have?

This list has 83 BACnet objects: 61 analog values, 6 binary values, 13 multi-state values, 2 characterstring values, 1 positive integer value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Regin Regio RUX room unit / display (firmware 2.1) BACnet points are writable?

70 of the 83 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Regin Regio RUX room unit / display (firmware 2.1) BACnet documentation?

What are the minimum BACnet points to integrate the Regin Regio RUX room unit / display (firmware 2.1)?

Start with AV 10401 RC_RoomSetpointOffset (Setpoint offset, °C); BV 9101 HeartbeatTrigger (Write 1 periodically to stay in normal mode); AV 10002 RC_RoomTemp (Room temperature, °C); AV 10011 RC_CO2Level (Room CO2, ppm); AV 10071 RC_Humidity (Room relative humidity); AV 10081 RC_RoomActiveSetpoint (Active room setpoint, °C); MV 10031 RC_FanSelect (Fan speed selected on the unit).

Does the Regin Regio RUX room unit / display (firmware 2.1) need a BACnet heartbeat or have a communication timeout?

BV 9101 HeartbeatTrigger must be written to 1 periodically (the unit resets it to 0); MV 9301 RC_OfflineFunction sets the reaction when it stops. No timeout is given.

Can the BMS supply sensor values to the Regin Regio RUX room unit / display (firmware 2.1)?

AV 10611 / 10621 / 10681 / 10691 take remote room temperature, CO2, humidity and VOC values, each enabled by its …RemoteSelect BV.
