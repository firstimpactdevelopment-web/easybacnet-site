BMS integration notes: Johnson Controls TEC26x6(H)-4 and TEC26x6H-4+PIR Fan Coil Thermostat (BACnet MS/TP)

Integration in brief

Address the thermostat on the BACnet MS/TP trunk, then command System Mode (MV 16) and Occupancy Command (MV 18) and Fan Mode (MV 17) and write the occupied setpoints (AV 39/40). Read Room Temp, Effective Occupancy, Fan Status and the filter and service alarms.

Enable & remote start

Occupancy Command (MV 18, 1=Local Occupancy, 2=Occupied, 3=Unoccupied) sets occupancy from the BAS; the first state hands occupancy back to the thermostat. System Mode (MV 16) can switch the unit off.

Heartbeat & communication loss

The guide marks some objects (Room Temp and Fan Status) as possibly releasing on their own after 10 minutes with no BACnet traffic. Keep writing overridden values.

Sensors & values from the BMS

To feed room temperature from the BAS, set Room Temp Override (BV 8) to Override, then write Room Temp (AV 7). Outdoor Temperature (AV 9) is only valid when it is written over the network.

Network setup

  • BACnet MS/TP only. Set the MS/TP address (4 to 127) with the Com addr parameter at the thermostat.
  • The thermostat names itself TEC26x6-aaa and picks device instance 73aaa, where aaa is the MS/TP address (e.g. 73004). Change either before mapping points if needed.
  • Leave the thermostat on automatic baud detection; at least one device on the trunk (normally the supervisory controller) needs a fixed baud rate.
  • Max_Master in the device object is writable.

Watch out for

  • Writing one setpoint of a heating/cooling pair can make the thermostat move the other one to keep the minimum deadband.
  • Set the configuration parameters before mapping; the guide recommends re-mapping all objects if configuration changes afterwards.
  • TEC26xx-4 objects do not line up with the older TEC26xx-2 objects; rediscover all points when replacing a -2 thermostat.
  • Objects with no access mark in the guide are listed here as read-only.
