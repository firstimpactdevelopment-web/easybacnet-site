Updated 4 November 2026

Short answer

The EEM multi-circuit meter measures up to two voltage references and many CT loads and talks BACnet MS/TP or BACnet IP. Its root device carries the panel-level values for both voltage inputs (Vin1 and Vin2): line-neutral and line-line voltages, phase angles, harmonic distortion, frequency and total energy, plus the service type of each input and the two pulse inputs.

BMS integration notes: Johnson Controls EEM Multi-Circuit Electric Energy Meter - Root Device

Integration in brief

Choose BACnet MS/TP or BACnet IP in the meter web portal, set the base device instance, then discover the root device and the per-load virtual devices. On the root device read the Vin1/Vin2 voltages, frequency and total energy.

Network setup

  • Protocol is chosen in the meter's web portal: BACnet MS/TP, BACnet IP, Modbus RTU or Modbus TCP.
  • BACnet settings: base device instance (0 to 4194328 per the manual), base device name, virtual network number; BACnet IP adds UDP port and BBMD address/TTL; BACnet MS/TP adds MAC 0 to 127, Max Master and Max Info Frames.
  • MS/TP baud rates 9600, 19200, 38400 (default), 57600 and 76800; 8 data bits, no parity, 1 stop bit.
  • Each configured load gets its own virtual device instance (VDI); the manual says to give every load a unique VDI.

Watch out for

  • Load measurements (kW, kWh, amps) are on the per-load virtual devices, not on the root device.
  • Root and load devices reuse the same AI instance numbers; map them by device.

Integration notes

  • Objects from the Root Device Object List, page 1 of LIT-12013610.
  • The meter shows up as a root device plus one virtual BACnet device per configured load; the two object lists are separate library entries.
  • The object list has no access column. Access is inferred: measurements read-only; the guide notes the phase angle units can be written (radians or degrees-phase).
  • Network settings in the integration notes come from the EEM Multi-Circuit Installation and Operation Manual (LIT-12013609) on the same portal.
  • The pulse inputs are Pulse Converter objects, listed here with type Other.
  • The device object name defaults to "No Panel Name".
