Short answer

The TEC3630 and TEC3631 are field-selectable BACnet MS/TP or N2 networked thermostats for single- or two-stage rooftop units and heat pumps with an optional economizer. BMS integration notes: Johnson Controls TEC3000 Series TEC3630 / TEC3631 Single- or Two-Stage RTU / Heat Pump Thermostat with Economizer (BACnet MS/TP)

Integration in brief

Put the TEC on the MS/TP trunk with a unique address and instance, set OCC-CONFIG to External and command NET-OCC from the BAS. Write the occupied setpoints, control mode and fan mode, and read the operational zone temperature, unit status, stage outputs and the critical event MV.

Enable & remote start

Set Occupancy Configuration Source (OCC-CONFIG, MV 29520) to External, then command Supervisor Occupancy (NET-OCC, MV 29519) occupied, unoccupied or standby. With OCC-CONFIG = Schedule the internal schedule writes LOCAL-OCC instead. Unit Enable (MV 29501) shuts the unit down or enables it, and Control Mode (MV 29500) picks auto, cooling or heating. A manual override at the display, an occupancy input or the motion sensor can still change the effective occupancy.

Sensors & values from the BMS

The BAS can supply outdoor air temperature (NET-OAT, AV 29513), outdoor air humidity (NET-OAH, AV 29514), zone humidity (NET-ZNH, AV 29516) and supply air temperature (NET-SAT, AV 29515). The guide gives no timeout for these values.

Network setup

  • Out of the box the thermostat runs BACnet MS/TP; N2 is chosen with FC Comm Mode in the Network Setup menu (the unit reboots).
  • BACnet Instance ID: 1 to 4,194,302, default 1. MS/TP address: 4 to 127, default 4.
  • MS/TP baud rate default is Auto; fixed choices are 1200, 9600, 19200, 38400 and 76800.
  • Character encoding defaults to ISO 10646 (UCS-2) for Metasys; a third-party BAS may need a different setting.

Watch out for

  • The guide says AV and MV objects are written without a priority (Metasys Change Default); the last such write received is the one executed.
  • The passcode cannot be changed from the BAS, only at the display or through the Mobile Access Portal.
  • LOCK-LVL (MV 29531) can hide the menu or most display functions; State 0 gives full access.
