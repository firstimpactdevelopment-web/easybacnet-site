Short answer

Application 1732-5 (Var Speed Series Fan) is one of the ten preloaded applications in the Johnson Controls VAV1732 controller, which has a built-in damper actuator and velocity pressure sensor and runs on BACnet MS/TP. It controls a series fan-powered VAV box with a variable-speed fan. Points cover occupancy and unit enable, temperature and airflow setpoints, zone sensors, airflow in L/s, CFM and CMH, damper output, the fan command and the loop and state diagnostics.

BMS integration notes: Johnson Controls VAV1732 VAV Controller - Application 1732-5 (Var Speed Series Fan)

Integration in brief

Set the MS/TP address on the DIP switches, load the 1732-5 application, then enable the unit with UNITEN-MODE, drive occupancy through OCC-SCHEDULE and write the occupied setpoints. Read zone temperature, effective occupancy, airflow and damper output plus the fan command.

Enable & remote start

UNITEN-MODE (Shutdown or Enable, default Enable) turns the box on or off. Occupancy comes from OCC-SCHEDULE (Occupied, Unoccupied, Standby or Not Set) written by the supervisory schedule; OCC-OVERRIDE overrides it, and EFF-OCC shows the result. SYSTEM-MODE (default Auto) can force cool only, heat only, fan only, water flush or purge.

Sensors & values from the BMS

SA-T (writable, default 13 °C) is the supply air temperature used for automatic warmup: warmup starts when SA-T and ZN-T are reliable and SA-T exceeds ZN-T plus WCT-DIFF; otherwise the BAS can command warmup with WC-C. With ZONE SETPOINT SOURCE set to Remote, the box uses BAS ZN-SP instead of the sensor setpoint.

Network setup

  • BACnet MS/TP (default) as a B-ASC; the controller can also be set to N2. Valid MS/TP addresses are 4 to 127, set on the address DIP switches before power-up.
  • Select one of the ten preloaded applications for the box type; the point list and BACnet IDs depend on the application.
  • Commission airflow with SA-AREA (box area) and SA-KFACTOR (pickup gain); AUTOCAL-STATE shows autocalibration.

Watch out for

  • Several BACnet IDs (ZN-T and the zone sensor points among them) differ between applications, so a template from one application does not fit another.
  • CLGOCC-MINFLOW, CLG-MAXFLOW, SA-AREA, SA-KFACTOR and the time settings are commissioning values; don't write them cyclically.

Integration notes

  • Objects from Table 34 on pages 50-52 of the VAV1717 and VAV1732 Application Note (LIT-12013794). Access, units, defaults and state text come from Table 19 (All BACnet points).
  • Some BACnet IDs (for example ZN-T and the zone sensor points) are specific to this application and differ in other VAV1732 applications.
  • Units are metric as printed (°C, L/s, Pa); SA-F-CFM and SA-F-CMH give airflow in CFM and m³/h.
  • The MAP Gateway table in the same note shows some commands (heating stage and fan commands, DPR-O, AUTOCAL-C) as writable, but the BACnet point table lists them as read-only; access here follows the BACnet table.
  • Multistate state text is listed in the order printed; the table gives no state numbers.
