Short answer

The Simplicity LINC is a small gateway mounted in the rooftop unit's control panel. It polls the Simplicity unit controller over Modbus RTU and exposes a fixed set of points on BACnet MS/TP; no configuration is needed. The map has 34 analog inputs, 58 analog values (setpoints, sensor values and settings), 65 binary inputs (outputs, safeties, alarms) and 40 binary values (option and mode enables, comm-value selects, redline/loadshed).

BMS integration notes: Johnson Controls Simplicity LINC Gateway (YORK / JCI Unitary Products rooftops)

Integration in brief

Set the MAC address (1-99) on DIP switches A0-A7 and the baud on B0-B3 (default 38400); the device instance combines the DE modifier 230 with the MAC (default 23001). The BAS writes the occupied/unoccupied cooling and heating setpoints and can supply space temperature, outdoor temperature, humidity and IAQ values once the matching COMM_ accept BV is set. Read supply air temperature, the active alarm and the alarm buffers.

Sensors & values from the BMS

AV 6 SPACE_TEMP, AV 7 AMB_TEMP, AV 10 AMB_AIR_HUM, AV 12 RET_AIR_HUM and AV 8 IAQ_VALUE are writable; set BV 108 COMM_ST, BV 101 COMM_OAT, BV 100 COMM_OH, BV 99 COMM_RH or BV 109 COMM_IAQ so the controller accepts the BAS value.

Network setup

  • MAC address 1-99 on DIP switches A0-A7 (default 1); baud on B0-B3 (default 38400).
  • Device instance = DE modifier 230 combined with the MAC address (default 23001); default unit name YORK_RTU.
  • The Simplicity board must stay at Modbus address 1 to talk to the gateway.

Watch out for

  • The Simplicity flash memory is rated for 1,000,000 writes; do not write settings more than about once every 10 minutes on average.
  • New data can take up to two minutes to show.
