Short answer

Application #4009 is one of the fan coil applications for the Johnson Controls ATC1500 (4 UI, 2 BI, 2 BO, 4 RO, 3 CO) Advanced Terminal Unit Controller, which connects over BACnet MS/TP (it can also run N2 or Modbus). It drives a four-pipe fan coil with 0-10 V proportional valve control, a variable-speed fan, a two-wire PWM heating option and an optional floating fresh-air damper with position output. Points cover unit enable, occupancy and mode commands, network setpoint and network sensor overrides, fan, valve and damper status, PID tuning, fault detection flags and the controller's network settings.

BMS integration notes: Johnson Controls ATC1500 Fan Coil Controller - Application #4009 (Four-Pipe, 0-10V Valve, Var-Speed Fan, Floating Damper)

Integration in brief

Set the controller to BACnet MS/TP (FC Comm Mode Wired Field Bus) with an MS/TP address of 4-127, then enable the unit with Unit Enable Mode, drive occupancy through Occupancy Schedule and write Network Setpoint (Spt Source defaults to Network Input). Read unit status, effective occupancy, zone temperature and the fan state.

Enable & remote start

Unit Enable Mode (Shutdown or Enable, default Enable) turns the unit off or on. Effective occupancy follows Occupancy Override first, then the bypass timer, Occupancy Schedule and the occupancy sensor. System Mode is the writable mode command (cool only, heat only, fan only and others).

Sensors & values from the BMS

With Spt Source at Network Input (the default) the zone setpoint comes from Network Setpoint (default 22 °C). Network Override Zone Temperature, Network Override Outdoor Air Temperature and Network Override Indoor Air Quality are writable network inputs; a network CO2 value takes priority over the local sensor, and summer-winter setpoint compensation only works with a reliable network outdoor air temperature.

Network setup

  • FC Comm Mode picks the field bus (Wired Field Bus for BACnet MS/TP, N2 or Modbus). MSTP Device Address is 4-127 and Device Object ID 0-4194302.
  • FCB Baud Rate defaults to Auto; Operating Baud Rate shows the rate in use and Communication Status the MS/TP state.
  • Units (MV 28016) selects IP or SI; the default is SI.

Watch out for

  • BACnet IDs (AV 280xx / MV 280xx) are reused across the ATC applications but do not always mean the same point; map each application from its own list.
  • Occupancy Override and Occupancy Schedule read Not Set after a reset until written again; with both Not Set and no occupancy sensor the unit falls back to Default Occupancy (Occupied unless changed).
  • PID tuning, minimum on/off times and fault delays are commissioning values; don't write them cyclically.
