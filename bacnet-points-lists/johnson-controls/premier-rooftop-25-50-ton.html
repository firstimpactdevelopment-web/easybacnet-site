Johnson Controls Premier Rooftop Units 25-50 Ton BACnet points list

Updated 28 October 2026

Short answer

The Premier 25-50 ton rooftop units use the Applied Smart Equipment controller, which has BACnet MS/TP (plus Modbus and N2) on its FC bus and BACnet IP through an optional plug-in card. The points list is all AV, MV and CSV objects in the 29501-30079 range: occupancy and unit enable commands, heating and cooling setpoints, network override inputs for zone and outdoor sensors, unit, fan, cooling and heating status, refrigerant circuit values, runtimes and fault flags. Many points belong to options and stay unused on units without them.

This page lists 322 BACnet objects for the Johnson Controls Premier Rooftop Units 25-50 Ton — 115 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Johnson Controls’s own free documentation, linked below.

BMS integration notes: Johnson Controls Premier Rooftop Units 25-50 Ton

Integration in brief

Pick the field bus mode (BACnet MS/TP on the FC bus, or BACnet IP with the optional card) and set the device OID in Controller > Network. Set OccMode (MV 29518) to External so the BAS occupancy request on NetOcc (MV 29520) is used, keep UnitEn (MV 29896) at Enable, and write the occupied heating and cooling setpoints. Read Unit-S, Fan-S, the zone temperature in use and DAT for status.

Enable & remote start

UnitEn (MV 29896) enables or shuts down the unit; the default is Enable. With OccMode (MV 29518) at Schedule the unit follows its internal schedule. With OccMode at External, an occupied command from the BAS (NetOcc, MV 29520), a zone sensor override or the hard-wired occupancy input makes the unit occupied.

Heartbeat & communication loss

No unit-level heartbeat point is listed. A zone temperature written by the BAS times out after 15 minutes without an update; the controller then falls back to a NetSensor, the wired zone sensor, then return air temperature.

Sensors & values from the BMS

Write zone temperature to NetZT (AV 29526), setpoint offset to NetSSO (AV 29540), zone humidity to NetSH (AV 29533), indoor CO2 to NetIAQ (AV 29530), and outdoor air temperature, humidity and CO2 to NetOAT, NetOAH and NetOAQ. A BAS zone temperature has top priority over local sensors. ZTSrc, IAQSrc, SHSrc and OATSrc show which source is in use.

Network setup

  • BACnet MS/TP: set FCBusMode to Wired Field Bus; default MAC address 4 (range 4-255), default baud 38400.
  • BACnet IP needs the optional BACnet IP card; with it installed, BACnet MS/TP, Modbus and N2 on the FC bus do not work. Choose DHCP or a static IP, mask and router in Controller > Network.
  • Device OID range 0-4194302, set from the local display or a MAP gateway; it is also writable as DeviceId (AV 29897).
  • FC bus cable: 22 AWG 3-wire twisted shielded; set the EOL switch ON at each end of a bus segment. Use Cat 5/5e/6 for BACnet IP.
  • SZVAV must be enabled at commissioning (SZVAVEn); MZVAV is the default unit type.

Watch out for

  • Multistate values in the table start at 0; confirm the numbering on the device before writing NetOcc, OccMode or UnitEn.
  • NetOcc only acts when OccMode is External.
  • DctShutdownSp (AV 29567) is a high duct static limit; exceeding it locks the unit out as a critical fault. ResetLO (MV 29826) resets lockouts.
  • Unit name, serial number and device name are writable CSVs; do not write them cyclically.

Integration notes

  • Taken from Table 32 (BACnet Points List) of the 25-50 ton Premier start-up and operation guide; the table has only AV, MV and CSV objects.
  • Multistate states are printed from 0 in the table. BACnet multistate values start at 1, so the device may report the printed number + 1; check the state text on discovery.
  • Enable polarity is not consistent: FanOnOcc and C1A-En/C1B-En/C2A-En print 0 = YES, 1 = NO, while C2B-En and most other enables print 0 = NO, 1 = YES.
  • The last six rows (MVCritical, MVServicePriority and MVService Active/Inactive Event, instances 29995-30000) give object type "0" and no description; they are listed here as type Other.
  • Points for heat stages 4-8, the second circuit, exhaust, energy recovery wheel, HGRH, humidification and UV lights only carry data on units with those options.
  • Writable setpoint ranges from the table are in the descriptions.

Questions about the Johnson Controls Premier Rooftop Units 25-50 Ton

How many BACnet points does the Johnson Controls Premier Rooftop Units 25-50 Ton have?

This list has 322 BACnet objects: 172 analog values, 140 multi-state values, 4 characterstring values, 6 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Johnson Controls Premier Rooftop Units 25-50 Ton BACnet points are writable?

115 of the 322 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Johnson Controls Premier Rooftop Units 25-50 Ton BACnet documentation?

The source is Premier Rooftop Units 25-50 Tons Start-Up & Operation Guide (5586996-JSG-A-520), revision 2020-05, published free by Johnson Controls at https://docs.johnsoncontrols.com/ductedsystems/api/khub/documents/n3TN8DoIvhMOr21N5iDrIg/content.

What are the minimum BACnet points to integrate the Johnson Controls Premier Rooftop Units 25-50 Ton?

Start with MV 29896 UnitEn (Unit enable (0 = shutdown, 1 = enable)); MV 29520 NetOcc (BAS occupancy: occupied, unoccupied or not set); MV 29518 OccMode (Must be External for BAS occupancy); AV 29608 ClgOcc-Sp (Occupied cooling setpoint, 45-98 °F); AV 29723 HtgOcc-Sp (Occupied heating setpoint, 40-85 °F); MV 29803 Unit-S (Unit state: idle, SD alarm, purge, start-up wizard); MV 29550 Fan-S (Fan state: off/idle, on/purge, on/valve or limit fault, on); AV 29522 OprZT (Zone temperature in use); AV 29564 DAT (Discharge air temperature); MV 29969 DownInOccAlm (Unit down during occupied mode (1 = alarm)).

How do I enable BMS control of the Johnson Controls Premier Rooftop Units 25-50 Ton?

UnitEn (MV 29896) enables or shuts down the unit; the default is Enable. With OccMode (MV 29518) at Schedule the unit follows its internal schedule. With OccMode at External, an occupied command from the BAS (NetOcc, MV 29520), a zone sensor override or the hard-wired occupancy input makes the unit occupied.

Does the Johnson Controls Premier Rooftop Units 25-50 Ton need a BACnet heartbeat or have a communication timeout?

No unit-level heartbeat point is listed. A zone temperature written by the BAS times out after 15 minutes without an update; the controller then falls back to a NetSensor, the wired zone sensor, then return air temperature.

Can the BMS supply sensor values to the Johnson Controls Premier Rooftop Units 25-50 Ton?

Write zone temperature to NetZT (AV 29526), setpoint offset to NetSSO (AV 29540), zone humidity to NetSH (AV 29533), indoor CO2 to NetIAQ (AV 29530), and outdoor air temperature, humidity and CO2 to NetOAT, NetOAH and NetOAQ. A BAS zone temperature has top priority over local sensors. ZTSrc, IAQSrc, SHSrc and OATSrc show which source is in use.
