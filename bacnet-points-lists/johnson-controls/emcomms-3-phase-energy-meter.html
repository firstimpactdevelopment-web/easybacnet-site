Short answer

BMS integration notes: Johnson Controls EM Series 3-Phase Energy Meter with EMCOMMS Module (BACnet MS/TP)

Integration in brief

Connect the RS485 terminals to a live MS/TP trunk and let the meter auto-detect baud rate, protocol and MAC address, then discover it (device ID 665 plus the last three serial digits). Read system real power, energy, voltage, current, power factor and demand, and watch the condition flags for wiring or sensor problems.

Network setup

  • Factory default is automatic: the meter learns baud rate (9600-115200), protocol and a free MAC address (0-127) by listening to an active MS/TP master on the trunk. It cannot learn on an idle line.
  • Default device ID is 665000 plus the last three digits of the label serial number (serial 123456 gives 665456).
  • To lock the settings, write AV 123 (MAC address), AV 124 (baud rate) and MSV 126 (parity); writing them turns the matching Auto BV off.
  • MAC addresses 128-254 always run as MS/TP subordinate (no token passing); 0-127 run as master when Max Info Frames is not 0 and the address is within Max Master.
  • Holding the setup button while powering up clears the learned automatic settings.

Watch out for

  • Writing a new baud rate to AV 124 cannot be undone remotely; the meter goes silent until the trunk matches.
  • AV 190 with the reset key wipes the whole configuration, including energy totals, MAC address and device ID.
  • Leaving an energy object Out Of Service stops it from accumulating new energy.
  • S and T phase objects sit at R phase instance +1000 and +2000; System Phase Selection (MSV 161) sets which phases feed the system totals.
  • Accumulator (ACC) energy objects wrap to 0 at 999,999; the AI versions of the same energy do not wrap.

Integration notes

  • Objects from the BACnet Protocol Guide EMCOMMS (LIT-12013039, Rev 0A, 2018-08-17), pages 10-48; the guide describes one object per heading rather than in a single table.
  • Only the system and R phase objects are listed. S phase and T phase objects repeat the R phase ones at instance +1000 and +2000 (for example AI 2600 and AI 3600 are S and T phase real power).
  • Statistic and part objects (Smoothed, Minimum, Maximum, Average, Previous, Import, Export, Net) are printed only as an ID with a short label under their main object; the names here join the main object name and that label and may differ from the object names the meter reports.
  • Units are the defaults. Power, energy, temperature and angle units follow MSV 163, MSV 173, MSV 133 and MSV 153.
  • Access W covers read/write objects, write-only reset keys (AV 190, AV 192, AV 1192) and W0 objects, where only writing 0 is allowed (it resets that statistic or clears latched flags).
  • The guide lists Accumulator objects (energy and pulse counts) next to Analog Input versions of the same energy values; both read the same internal register.
