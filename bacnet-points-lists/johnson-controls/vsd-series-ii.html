Short answer

The VSD Series II has BACnet MS/TP on its RS-485 terminals (P4.7.1.1 Protocol = 3 BACnet MSTP) and BACnet IP on its Ethernet port (P4.8.3.1.3 Protocol in use = 1). BVs cover drive status, general status bits, run/stop, direction, reset, bypass, fire mode, setback, network digital inputs and relay outputs; AVs cover monitors, the speed reference (% of nominal), limits, ramps, process data, AnyParam access and the fixed control/status words.

BMS integration notes: Johnson Controls VSD Series II HVAC drive (BACnet MS/TP and BACnet IP)

Integration in brief

Select BACnet MSTP (P4.7.1.1 = 3) or turn on BACnet IP (P4.8.3.1.3 = 1), set the MAC address, baud and instance (P4.7.3.1) or IP settings (P4.8.1), then make Fieldbus the remote control place (Basic Parameters > START SRC AUTO) and the fieldbus the auto speed source. Command BV 15 run/stop and AV 24 speed reference, and read BV 1, AV 1 and the fault points.

Enable & remote start

Select Fieldbus control as the remote control place (Main Menu > Parameters > Basic Parameters > START SRC AUTO) and the fieldbus as reference (Speed Setup Auto). BV 15 is documented as the start command when fieldbus control is active.

Heartbeat & communication loss

MS/TP: P4.7.3.1.5 Communication time-out (0-65535 s, default 10 s, 0 = not used). BACnet IP: P4.8.3.1.2 Communication time-out (default 0 = not used). P2.8.1.12 FieldbusComm Flt sets the drive's response when the fieldbus timeout occurs.

Network setup

  • MS/TP: P4.7.1.1 Protocol = 3 (BACnet MSTP); P4.7.3.1.1 baud (1 = 9600 default, 2 = 19200, 3 = 38400, 4 = 76800); P4.7.3.1.2 autobauding; P4.7.3.1.3 MAC address 1-127 (default 1).
  • MS/TP: P4.7.3.1.4 Instance number 0-65535, 0 (default) = generated automatically.
  • BACnet IP: P4.8.1.1 IP address mode (default 1 = DHCP with Auto IP, 2 = fixed IP), P4.8.1.2-4 address, mask and gateway.
  • BACnet IP: P4.8.3.1.1 instance (0 = serial number), P4.8.3.1.3 Protocol in use = 1, P4.8.3.1.4-6 BBMD IP, port and time to live.
  • Terminate the first and last drive on the MS/TP segment.

Watch out for

  • BV 15 run/stop only works when fieldbus control is the active control place.
  • BV 18 Force Bypass, BV 28 Fire Mode and BV 29 Setback (set drive to defaults) are commandable over BACnet.
  • Process data objects depend on the drive application.

Integration notes

  • From the VSD Series II manual LIT-12011771 (April 2013), Communications section, Binary and Analog Value Object tables (PDF pp102-103).
  • The Analog Value list matches the Vacon 100 internal BACnet list object for object; the Binary Value list differs (general status bits, bypass, DIN 3-6, relay outputs, fire mode and setback), so it is a separate entry.
  • BV 4 is named Warning State but its active text is Alarm, as printed.
  • BV 7-14 and AV 15-22 / AV 30-33 are application-specific status bits and process data.
  • AV 36/AV 37 are IEEE-754 floats; binary coding works only for values without decimals.
  • Control word bits: B0 start/stop, B2 fault reset. Status word bits: B0 ready, B1 run, B2 direction, B3 fault, B4 alarm, B5 at reference, B6 zero speed.

Questions about the Johnson Controls VSD Series II HVAC drive (BACnet MS/TP and BACnet IP)

How many BACnet points does the Johnson Controls VSD Series II HVAC drive (BACnet MS/TP and BACnet IP) have?

This list has 71 BACnet objects: 40 analog values, 31 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Johnson Controls VSD Series II HVAC drive (BACnet MS/TP and BACnet IP) BACnet points are writable?

30 of the 71 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

The source is VSD Series II, Communications: BACnet Protocol (LIT-12011771), revision 2013-04, published free by Johnson Controls at https://docs.johnsoncontrols.com/bas/api/khub/documents/a_MFNL2qPXw9QEMkukAHPw/content.

Start with BV 15 Run/Stop CMD (Run/stop command (1 = run)); AV 24 Speed Reference (Speed reference, % of nominal speed); BV 17 Reset Fault (Resets the active fault); BV 1 Run/Stop State (Running status); AV 1 Output Frequency (Output frequency, Hz); AV 5 Motor Current (Motor current, A); AV 3 Load (power) (Motor shaft power, %); BV 3 Fault State (Any active drive fault); AV 23 Active Fault Code (Which fault is active).

How do I enable BMS control of the Johnson Controls VSD Series II HVAC drive (BACnet MS/TP and BACnet IP)?

Select Fieldbus control as the remote control place (Main Menu > Parameters > Basic Parameters > START SRC AUTO) and the fieldbus as reference (Speed Setup Auto). BV 15 is documented as the start command when fieldbus control is active.

Does the Johnson Controls VSD Series II HVAC drive (BACnet MS/TP and BACnet IP) need a BACnet heartbeat or have a communication timeout?

MS/TP: P4.7.3.1.5 Communication time-out (0-65535 s, default 10 s, 0 = not used). BACnet IP: P4.8.3.1.2 Communication time-out (default 0 = not used). P2.8.1.12 FieldbusComm Flt sets the drive's response when the fieldbus timeout occurs.
