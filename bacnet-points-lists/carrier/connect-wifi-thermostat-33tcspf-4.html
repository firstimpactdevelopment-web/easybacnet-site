Short answer

The Connect 33TCSPF-4 / 33TWSPF-4 thermostat exposes 149 BACnet objects (plus two network port objects) over BACnet MS/TP or BACnet IP over Wi-Fi (it has an MS/TP network port object and an IPv4 network port object). Compared with the earlier 33CONNECTSTAT43 list it adds outdoor air quality values, standby setpoints, hydronic fan coil and analog output (hot water valve) points, door switch points and network general purpose outputs. Configuration objects are gated: they only accept writes after BACnet Config Write Enable is turned on.

This page lists 149 BACnet objects for the Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4 — 97 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Carrier’s own free documentation, linked below.

BMS integration notes: Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4

Integration in brief

Connect the thermostat on MS/TP or IP, then drive it with the user mode (MV 400), heat/cool setpoints and the BMS occupancy point (BV 405, enabled by BV 507). Read current mode, space temperature for control and the stage output BVs. Turn on BV 511 only when you need to change gated configuration objects.

Enable & remote start

BMS occupancy is used only when BMS Occupancy Enable (BV 507) is enabled; the BMS then writes BACnet BMS Occupancy (BV 405). Gated configuration objects need BACnet Config Write Enable (BV 511).

Heartbeat & communication loss

Network Space Temperature (AV 103) and Network Space Humidity (AV 105) must be rewritten at least every 5 minutes; if not, the control value falls back to the thermostat's own sensor (AI 100 / AI 101).

Sensors & values from the BMS

Network Space Temperature (AV 103) and Network Space Humidity (AV 105) are written by the BMS and take effect only when BV 407 / BV 408 are enabled and the value was written within the last 5 minutes. AV 104 and AV 106 show the values the control logic actually uses.

Network setup

  • Network port objects: MSTP_PORT (500) for MS/TP and IP_PORT (501) for BACnet IP, including BBMD foreign device settings.
  • Up to 7 concurrent COV subscriptions, for BV and MV objects only, lifetime 1 s to 8 h.

Watch out for

  • The BACnet Reliability property is used to flag objects that the current configuration does not use (e.g. no-sensor, no-output).
  • Leave CFG_WR_EN (BV 511) disabled in normal operation so gated settings cannot be changed by accident.

Integration notes

  • Carrier's tables call value objects 'Analog Variable' / 'Binary Variable'; they are AV and BV objects.
  • Access mapping: READ_ONLY = R; READ_WRITE and GATED_WRITE = W (GATED_WRITE needs BV 511 CFG_WR_EN enabled); WRITE_WHEN_OOS (the three AIs) = R, writable only when the object is out of service.
  • BV 916 LOCKOUT_FAIL is printed as removed (changed from a fault to a system event) and is left out.
  • The 33TWSPF-4 has its own guide (11-808-1227-01) with the same object appendix.
  • Multistate state numbers (1, 2, 3...) follow the printed order of the state list; MV 509 states continue across a page break.

Questions about the Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4

How many BACnet points does the Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4 have?

This list has 149 BACnet objects: 3 analog inputs, 60 analog values, 58 binary values, 28 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4 BACnet points are writable?

97 of the 149 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4 BACnet documentation?

The source is Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4 Installation Guide (Appendix A, BACnet Objects) (11-808-1226-01), revision 2026-06, published free by Carrier at https://brandportal.carrier.com/asset/18e1e0a0-9538-47b1-b623-d4ea88f27b22/11-808-1226-01.pdf.

What are the minimum BACnet points to integrate the Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4?

Start with MV 400 USER_MODE (System mode: Off, Heat, Cool, Auto, E-Heat); BV 405 BMS_OCC (BMS occupancy command (needs BV 507 enabled)); AV 400 OCC_HT_SP (Occupied heating setpoint); AV 401 OCC_CL_SP (Occupied cooling setpoint); AV 103 NET_SP_TEMP (Network space temperature (with BV 407 enabled)); MV 300 CURRENT_MODE (Current mode status: Off, Heat, Cool); AV 104 SP_TEMP_CTRL (Space temperature used for control); BV 205 G_OUT (Fan output status); BV 200 Y1_OUT (First stage cooling output status); BV 203 W1_OUT (First stage heating output status).

How do I enable BMS control of the Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4?

BMS occupancy is used only when BMS Occupancy Enable (BV 507) is enabled; the BMS then writes BACnet BMS Occupancy (BV 405). Gated configuration objects need BACnet Config Write Enable (BV 511).

Does the Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4 need a BACnet heartbeat or have a communication timeout?

Network Space Temperature (AV 103) and Network Space Humidity (AV 105) must be rewritten at least every 5 minutes; if not, the control value falls back to the thermostat's own sensor (AI 100 / AI 101).

Can the BMS supply sensor values to the Carrier Connect Wi-Fi Thermostat 33TCSPF-4 / 33TWSPF-4?

Network Space Temperature (AV 103) and Network Space Humidity (AV 105) are written by the BMS and take effect only when BV 407 / BV 408 are enabled and the value was written within the last 5 minutes. AV 104 and AV 106 show the values the control logic actually uses.
