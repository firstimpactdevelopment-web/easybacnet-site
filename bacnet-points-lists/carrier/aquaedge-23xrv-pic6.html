Short answer

The PIC6 controller on the 23XRV talks BACnet MS/TP (port J8) or BACnet IP (Ethernet) natively, plus Modbus, with no translator. The object list is a flat set of AV, BV and MSV objects named <CCN table>_<point>, covering unit status, temperatures and pressures per circuit, capacity, VFD data, setpoints and service settings. Network start must be enabled on the controller before BMS commands are obeyed.

This page lists 591 BACnet objects for the Carrier AquaEdge 23XRV (PIC6) — 155 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Carrier’s own free documentation, linked below.

BMS integration notes: Carrier AquaEdge 23XRV (PIC6)

Integration in brief

Enable BACnet MS/TP or BACnet IP under System Configuration > BMS protocol, then enable Network start on the Configure Startup Options screen. In Network mode the chiller runs when both its start/stop and occupancy inputs are true; monitor unit status, leaving/entering water and alarms, and write the LCW setpoint.

Enable & remote start

Network start for BACnet must be ticked on the Configure Startup Options screen (User login or higher). In Network mode the chiller starts only when CHIL_S_S and CHIL_OCC are both true; each enabled start source must send a stop to stop the chiller. BACnet emergency stop (PROTOCOL_BACESTOP) is one of the emergency-stop sources.

Network setup

  • Port J8 is RS-485 for BACnet MS/TP or Modbus RTU; BACnet MS/TP and BACnet IP cannot both be enabled.
  • Modbus RTU can run alongside BACnet IP, and BACnet MS/TP alongside Modbus TCP.
  • Ethernet ports: J15 defaults to 169.254.1.1/16, J16 to 192.168.100.100/24; DHCP is not supported.
  • For BACnet IP set the IP config and any BBMD, then select Reboot; for MS/TP set MAC, baud and keep Max Masters low.

Watch out for

  • The points table marks the PROTOCOL_BAC* command objects read-only; confirm which objects accept writes on the live controller before mapping commands.
  • Object names carry the CCN table prefix (e.g. TEMP_, SETPOINT_, GENUNIT_); several descriptions in the table are internal variable names.

Questions about the Carrier AquaEdge 23XRV (PIC6)

How many BACnet points does the Carrier AquaEdge 23XRV (PIC6) have?

This list has 591 BACnet objects: 415 analog values, 161 binary values, 15 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaEdge 23XRV (PIC6) BACnet points are writable?

155 of the 591 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier AquaEdge 23XRV (PIC6) BACnet documentation?

The source is AquaEdge 23XRV Variable Speed High-Efficiency Screw Liquid Chillers - Controls Operation and Troubleshooting (23XRV-3T), revision 2025-01, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/0B/23XRV-3T.pdf.

What are the minimum BACnet points to integrate the Carrier AquaEdge 23XRV (PIC6)?

Start with AV 404 SETPOINT_lcw_sp (Cooling leaving water setpoint (writable)); AV 407 SETPOINT_dem_base (Base demand limit from the BMS, %); BV 136 PROTOCOL_BAC_S_S (Start/stop command; listed read-only, test writes); BV 133 PROTOCOL_BACOCC (Occupancy command; listed read-only, test writes); BV 134 PROTOCOL_BACESTOP (Emergency stop; listed read-only, test writes); MV 4 GENUNIT_STATUS (Unit run status); AV 41 TEMP_LCW (Leaving chilled water temperature); AV 40 TEMP_ECW (Entering chilled water temperature); AV 35 GENUNIT_CTRL_PNT (Control point in use); AV 410 ALARMRST_SYS_ALM (System alert/alarm state).

How do I enable BMS control of the Carrier AquaEdge 23XRV (PIC6)?

Network start for BACnet must be ticked on the Configure Startup Options screen (User login or higher). In Network mode the chiller starts only when CHIL_S_S and CHIL_OCC are both true; each enabled start source must send a stop to stop the chiller. BACnet emergency stop (PROTOCOL_BACESTOP) is one of the emergency-stop sources.

How do I check these points on the real AquaEdge 23XRV (PIC6)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
