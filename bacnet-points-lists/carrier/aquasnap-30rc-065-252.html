BMS integration notes: Carrier AquaSnap 30RC 065-252 (Carrier Controller)

Integration in brief

Enable BACnet (bacena) under Main Menu > Configuration > Network > BACnet, set the device ID and network, then select the Network control method with the Start/Stop button. Command through the _wr objects (start/stop, occupancy, control point, demand limit) and read run status, water temperatures, capacity and alarms.

Enable & remote start

Select the Network machine control method with the Start/Stop button; the unit then follows CCN, BACnet (if enabled) or Modbus (if enabled) commands and ignores the remote control contacts. Start/stop and occupancy are written to the _wr objects.

Heartbeat & communication loss

The manual says that if communication with the network is lost, the machine starts and is controlled locally.

Network setup

  • BACnet Enable (bacena) defaults to Disable; the appendix lists 1 = BACnet IP and 2 = BACnet MS/TP.
  • Defaults shown: network 1600, UDP port 47808, manual device ID 1600001, auto device ID option off, alarm reporting on.
  • IP port interface option 0 = J5/J15, 1 = J16.

Watch out for

  • Write the _wr object, not the _rd one; the _rd copy only reports the current value.
  • The BACnet menu has a BACnet Manage Occupancy option (mng_occ, default No) and the list has a writable BACnet_BMS_OCC (AV 66, 0 = unocc, 1 = occ, 2 = none); check how they interact with CHIL_OCC before relying on either.

Questions about the Carrier AquaSnap 30RC 065-252 (Carrier Controller)

How many BACnet points does the Carrier AquaSnap 30RC 065-252 (Carrier Controller) have?

This list has 738 BACnet objects: 469 analog values, 268 binary values, 1 multi-state value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaSnap 30RC 065-252 (Carrier Controller) BACnet points are writable?

23 of the 738 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier AquaSnap 30RC 065-252 (Carrier Controller) BACnet documentation?

The source is AquaSnap 30RC 065-252 Air-Cooled Chillers with Carrier Controller - Controls, Start-Up, Operation, Service and Troubleshooting (Appendix D, BACnet IP and MS/TP Points) (30RC-3T), revision 2026-07, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/09/30RC-3T.pdf.

What are the minimum BACnet points to integrate the Carrier AquaSnap 30RC 065-252 (Carrier Controller)?

Start with BV 10012 GENUNIT_CHIL_S_S_wr (Network start/stop command); BV 10058 GENUNIT_CHIL_OCC_wr (Network occupied command); AV 10006 GENUNIT_CTRL_PNT_wr (Leaving water control point from the BMS); AV 10008 GENUNIT_DEM_LIM_wr (Demand limit command); AV 21 GENUNIT_CTRL_TYP (Control type: Local, Network or Remote); AV 22 GENUNIT_STATUS (Running status); AV 2 TEMP_LWT (Leaving water temperature); AV 1 TEMP_EWT (Entering water temperature); AV 9 GENUNIT_CAP_T (Percent total capacity); AV 990 ALARMRST_ALM (Unit alarm state).

How do I enable BMS control of the Carrier AquaSnap 30RC 065-252 (Carrier Controller)?

Select the Network machine control method with the Start/Stop button; the unit then follows CCN, BACnet (if enabled) or Modbus (if enabled) commands and ignores the remote control contacts. Start/stop and occupancy are written to the _wr objects.

Does the Carrier AquaSnap 30RC 065-252 (Carrier Controller) need a BACnet heartbeat or have a communication timeout?

The manual says that if communication with the network is lost, the machine starts and is controlled locally.
