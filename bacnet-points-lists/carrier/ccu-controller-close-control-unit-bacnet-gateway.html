Updated 7 November 2026

Short answer

Carrier's European close control units use the CCU controller, which speaks Modbus RTU. An optional factory gateway kit republishes a short set of values on BACnet IP or BACnet MS/TP for up to two units: temperatures and humidity, cooling, heating and humidity setpoints, fan speed command, coil, humidifier and fresh-air outputs, run states and fault flags.

BMS integration notes: Carrier CCU Controller close control unit (Modbus to BACnet gateway option)

Integration in brief

Set the CCU controller's Modbus parameters (P700-P706) so the gateway can poll it, then use OnOff (BV 13) and the temperature and humidity setpoints from the BMS, and read the controlled temperature and humidity, fan state and the two fault summaries.

Enable & remote start

P706 must be set to Remote on the controller for gateway (BMS) control.

Network setup

  • Controller Modbus settings: P700 = Modbus, P701 = 9600 baud, P702 = no parity, P703 = 1 stop bit, P704 = not swapped, P705 = bus no. 1.
  • Gateway default device ID is 1003; with two gateway kits on one site, have service change it.
  • BACnet IP kit uses UDP port 47808; BACnet MS/TP kit runs at 38400 baud, 8 data bits, no parity, 1 stop bit, max master 1.
  • One or two units can be connected to the gateway; the device name published on BACnet is AHU.
  • Controller software V21 or later is required for the gateway.

Watch out for

  • The gateway does not support segmentation; read objects one at a time.

Integration notes

  • Objects for unit (AHU) 1 are listed. The guide prints a second AV block for AHU 2 (AV 50-74, same names) and repeats the AHU 1 BV numbers for AHU 2.
  • Names are the gateway mnemonics (several are French: Pour = percentage, Def = fault, Souf = supply).
  • The controller needs P700 = Modbus, 9600 baud, no parity, 1 stop bit, bus no. 1 and P706 = Remote for the gateway to work.
  • The gateway does not support segmentation; read objects one by one.

Questions about the Carrier CCU Controller close control unit (Modbus to BACnet gateway option)

How many BACnet points does the Carrier CCU Controller close control unit (Modbus to BACnet gateway option) have?

This list has 41 BACnet objects: 18 analog values, 23 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier CCU Controller close control unit (Modbus to BACnet gateway option) BACnet points are writable?

6 of the 41 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier CCU Controller close control unit (Modbus to BACnet gateway option) BACnet documentation?

The source is Control Manual, Close control units, Carrier CCU Controller (EN7519369-06), revision 2023-02, published free by Carrier at https://brandportal.carrier.com/asset/a3ef0f71-85f8-4053-9dd3-eaafdf78559c/EN7519369-06_IOM_Control_02_2023_CCU-Controller.pdf.

What are the minimum BACnet points to integrate the Carrier CCU Controller close control unit (Modbus to BACnet gateway option)?

Start with BV 13 OnOff (Unit on/off command, 1 = on); AV 7 CoolSetpt (Cooling temperature setpoint); AV 4 HeatSetpt (Heating temperature setpoint); AV 5 DeshuSetpt (Dehumidification humidity setpoint); AV 6 HumidSetpt (Humidification humidity setpoint); BV 14 VentilSouf (Supply fan running); AV 1 TempRegulee (Controlled (room/return) temperature); AV 15 HygroRegulee (Controlled humidity); BV 28 DefImportant (Critical fault summary); BV 27 DefSimple (Non-critical fault summary).

How do I enable BMS control of the Carrier CCU Controller close control unit (Modbus to BACnet gateway option)?

P706 must be set to Remote on the controller for gateway (BMS) control.

How do I check these points on the real CCU Controller close control unit (Modbus to BACnet gateway option)?
