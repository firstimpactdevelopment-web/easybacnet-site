Short answer

The 19MV's PIC6 controller offers BACnet MS/TP on RS-485 port J8 or BACnet IP on Ethernet port J15, with about 300 AV, BV and MV objects named after their CCN table and point. Commands use paired read (_rd) and write (_wr) objects for start/stop, occupancy, control point, demand limit, emergency stop, free cooling and heat/cool select. It repeats 228 of the 19DV PIC6 objects (all but the BACnet dongle input) and adds about 70 more, mostly magnetic bearing controller (MBC) points plus UPS battery, EXV and liquid bypass points.

BMS integration notes: Carrier AquaEdge 19MV (PIC6)

Integration in brief

Enable BACnet in the CONNECT (BMS Protocol) menu: J8 option for MS/TP or BACnet Enable for BACnet IP. Set the identifier and network, and put the chiller in NETWORK control mode. The chiller then starts when both BV 66 start/stop and BV 68 occupancy are true; write control point and demand limit through the _wr objects and read status, water temperatures and alarms.

Enable & remote start

In NETWORK control mode the chiller starts and stops from the CHIL_S_S and CHIL_OCC points written over the network (both must be true). Use EMSTOP or the HMI to shut it down.

Network setup

  • CONNECT menu: Port J8 option 0 = None, 1 = BACnet MS/TP, 2 = Modbus RTU; BACnet Enable (bacena) defaults to disabled. The menu needs the Service password.
  • Defaults: BACnet network 1600, identifier 1600001, MS/TP MAC 1, MS/TP baud option 2 (38400), Max Master 3.
  • BACnet IP and Modbus TCP use Ethernet port J15 (default IP 169.254.0.1, mask 255.255.0.0).
  • BACnet MS/TP and BACnet IP are mutually exclusive, as are BACnet MS/TP and Modbus RTU. Changing the protocol reboots the PIC6.
  • After changing the IP address, reboot or power-cycle the PIC6 to rebuild the BACnet stack.

Watch out for

  • Write the _wr objects; the _rd objects only echo the current value.
  • Configuration parameters are generally read-only over BACnet; setpoints are read/write.

Questions about the Carrier AquaEdge 19MV (PIC6)

How many BACnet points does the Carrier AquaEdge 19MV (PIC6) have?

This list has 299 BACnet objects: 215 analog values, 73 binary values, 11 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaEdge 19MV (PIC6) BACnet points are writable?

14 of the 299 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier AquaEdge 19MV (PIC6) BACnet documentation?

The source is AquaEdge 19MV Two-Stage High-Efficiency Semi-Hermetic Centrifugal Liquid Chillers with Greenspeed Intelligence, PIC6 Controls - Controls Operation and Troubleshooting (Appendix C, Table C BACnet Object Table) (19MV-CLT-3T), revision 7-25, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/09/19MV-CLT-3T.pdf.

What are the minimum BACnet points to integrate the Carrier AquaEdge 19MV (PIC6)?

Start with BV 66 GENUNIT_CHIL_S_S_wr (Network start/stop command); BV 68 GENUNIT_CHIL_OCC_wr (Network occupied command); BV 67 GENUNIT_EMSTOP_wr (Emergency stop command); AV 147 GENUNIT_CTRL_PNT_wr (Control point command); AV 148 GENUNIT_DEM_LIM_wr (Demand limit command); MV 1 GENUNIT_ctl_mode (Control mode: Local, Network, Remote, Local Sched); AV 7 GENUNIT_ch_state (Chiller status code); AV 9 TEMP_LCW (Leaving chilled water temperature); AV 8 TEMP_ECW (Entering chilled water temperature); AV 85 ALARMRST_alarm_1 (Current alarm 1).

How do I enable BMS control of the Carrier AquaEdge 19MV (PIC6)?

In NETWORK control mode the chiller starts and stops from the CHIL_S_S and CHIL_OCC points written over the network (both must be true). Use EMSTOP or the HMI to shut it down.
