Carrier Fan Coil Open BACnet points list

Updated 28 October 2026

Short answer

The Fan Coil (OPN-FC) controller ships as an integrated part of Carrier packaged fan coil units. DIP switches and the communications selector choose BACnet MS/TP (the default), BACnet ARC156, Modbus or N2, and a LonWorks option card is available. The default device instance is 16101 followed by the two-digit rotary address. Points cover setpoints, space and supply temperatures, fan speed and valve outputs, 2-pipe changeover, alarms and the 'system' points a BAS writes in place of local sensors.

This page lists 80 BACnet objects for the Carrier Fan Coil Open — 33 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Carrier’s own free documentation, linked below.

BMS integration notes: Carrier Fan Coil Open

Integration in brief

Set the Fan Coil Open for BACnet MS/TP with its DIP switches and rotary address. Disable the local Occupancy Schedules so the BAS can command occupancy through keypad_ovrde, then write setpoints directly. Space temperature, humidity, CO2, OAT and 2-pipe water temperature from the BMS go into the system_* points at priority 16 and have to be refreshed within each point's window.

Enable & remote start

The unit runs occupied 24/7 until a schedule or the BAS takes over. Disable Occupancy Schedules (Configuration > Unit Configuration) so the BAS can control it, then write BAS On/Off keypad_ovrde (MSV:1 in the points list): 1=Inactive, 2=Occupied, 3=Unoccupied. Shutdown (BV:9001) stops the unit from the network. Cool Enable (BV:1011) and Heat Enable (BV:1012) lock out cooling or heating.

Heartbeat & communication loss

No general heartbeat. Each system point is only used while it is refreshed within its window: space temperature 1 min / 5 min, RH and CO2 5 min / 10 min, OAT and water temperature 5 min / 60 min.

Sensors & values from the BMS

Write system_spt (AV:1902), system_rh (AV:1904), system_iaq (AV:1903), system_oat (AV:1901), system_water_temp (AV:1905) and system_stpt_adj (AV:1913) at BACnet priority 16, no more than once a minute. A network value overrides the local sensor while it is refreshed in time. system_water_temp sets the 2-pipe changeover mode and takes priority over the local changeover sensor. The controller clears a system point after processing it, so read the matching control point instead (space_temp, space_rh, iaq, oa_temp, chgovr_mode) at least 30 s after the write.

Network setup

  • MS/TP MAC address is set on the rotary switches (tens and ones); valid 1-99. The address is read only at power-up.
  • Default device instance is 16101xx (xx = rotary address); it can be changed with an Equipment Touch.
  • Baud is set on DIP 1-2 (9600/19.2k/38.4k/76.8k); 76.8k is the default; 8N1 fixed. DIP 3 and 4 both Off = BACnet MS/TP.
  • Set the communications selector to EIA-485; switch changes only take effect after a power cycle.
  • Max Masters defaults to 127 and Max Info Frames to 10 (adjustable via Equipment Touch). The controller counts as a full load on the MS/TP bus.

Watch out for

  • System points must be written at priority 16; writes at any other priority are ignored.
  • Never write a system point more than once per minute (60 s).
  • Only controllers set as MS/TP masters answer Who-Is.
  • The guide says the unit accepts three network demand-limit levels, but cool_demand_level (AV:9006) and heat_demand_level (AV:9036) are listed read-only.
  • Some points only apply with certain options (2-pipe changeover, electric heat, DCV damper, reheat, humidity sensor, linkage).

Integration notes

  • System points (system_spt, system_rh, system_iaq, system_oat, system_water_temp, system_stpt_adj) must be written at BACnet priority 16 and no more than once per minute; -999 means no network value.
  • The guide's generic system-point table also lists system_oaq (AV:1908), oae (BV:1901), press_override (BV:1906) and fire_shutdown (BV:1907). They are not in the Fan Coil points list, so they are left out here.
  • The points list gives BAS On/Off (keypad_ovrde) as MSV:1, while the system-point table in the same guide shows msv:1001 as on other Open controllers. Check which instance the controller exposes.
  • Defaults in the points list differ from the sequence text for Fan On Delay (10 s vs 30 s), Fan Off Delay (90 s vs 120 s) and Power Fail Restart Delay (5 s vs 60 s); check on the controller.
  • Occ Override Delay (AV:9028) is listed twice in the source; it is kept once here. Several display names in the source are just 'Setpoint'; the object name tells you which one.
  • Each point also has a Modbus register in the same table; only the BACnet side is captured here.

Check it against the live device. A points list tells you what the controller can expose; the unit in front of you may differ by firmware or installed options. Questions about the Carrier Fan Coil Open

How many BACnet points does the Carrier Fan Coil Open have?

This list has 80 BACnet objects: 41 analog values, 33 binary values, 6 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier Fan Coil Open BACnet points are writable?

33 of the 80 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier Fan Coil Open BACnet documentation?

The source is Fan Coil Integration Guide (Appendix A: Fan Coil Network Points List) (11-808-540-01), revision 2022-07-21, published free by Carrier at https://www.shareddocs.com/hvac/docs/1000/Public/0E/11-808-540-01.pdf.

What are the minimum BACnet points to integrate the Carrier Fan Coil Open?

Start with MV 1 keypad_ovrde (BAS occupancy command: occupied/unoccupied); BV 9001 shutdown (Network shutdown command); AV 3001 occ_cl_stpt (Occupied cooling setpoint); AV 3002 occ_ht_stpt (Occupied heating setpoint); MV 2002 run_status (Current system mode); BV 2008 occ_status (Confirms occupied/unoccupied); AV 2007 space_temp (Space temperature the unit controls to); AV 1008 sa_temp (Supply air temperature); BV 7008 sfan_fail_alarm (Supply fan failure alarm); BV 7028 overflow_alarm (Condensate overflow alarm; stops the fan).

How do I enable BMS control of the Carrier Fan Coil Open?

The unit runs occupied 24/7 until a schedule or the BAS takes over. Disable Occupancy Schedules (Configuration > Unit Configuration) so the BAS can control it, then write BAS On/Off keypad_ovrde (MSV:1 in the points list): 1=Inactive, 2=Occupied, 3=Unoccupied. Shutdown (BV:9001) stops the unit from the network. Cool Enable (BV:1011) and Heat Enable (BV:1012) lock out cooling or heating.

Does the Carrier Fan Coil Open need a BACnet heartbeat or have a communication timeout?

No general heartbeat. Each system point is only used while it is refreshed within its window: space temperature 1 min / 5 min, RH and CO2 5 min / 10 min, OAT and water temperature 5 min / 60 min.

Can the BMS supply sensor values to the Carrier Fan Coil Open?

Write system_spt (AV:1902), system_rh (AV:1904), system_iaq (AV:1903), system_oat (AV:1901), system_water_temp (AV:1905) and system_stpt_adj (AV:1913) at BACnet priority 16, no more than once a minute. A network value overrides the local sensor while it is refreshed in time. system_water_temp sets the 2-pipe changeover mode and takes priority over the local changeover sensor. The controller clears a system point after processing it, so read the matching control point instead (space_temp, space_rh, iaq, oa_temp, chgovr_mode) at least 30 s after the write.

How do I check these points on the real Fan Coil Open?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
