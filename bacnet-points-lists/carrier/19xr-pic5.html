Short answer

The PIC 5 controller on the 19XR talks BACnet IP over its Ethernet port once the optional BACnet dongle is fitted and BACnet is enabled in the CONNECT menu. It exposes up to 500 AV and BV objects named <CCN table>_<point>; the published table lists 159. Commands use paired _rd and _wr objects, with the _wr copies marked commandable; setpoints in the SETPOINT table are read/write.

BMS integration notes: Carrier AquaEdge 19XR (PIC 5)

Integration in brief

Fit the BACnet dongle, set BACnet Enable, network number and identifier in the CONNECT menu, and put the chiller in NETWORK control mode. It then starts when both BV 40 start/stop and BV 42 occupancy are true; write control point and demand limit through the _wr objects and read status, water temperatures and alarms.

Enable & remote start

In NETWORK control mode the chiller starts and stops from the CHIL_S_S and CHIL_OCC points written over the network (both must be true). Use EMSTOP or the HMI to shut it down. A STOP OVERRIDE point in GENUNIT, if enabled, prevents starting.

Network setup

  • BACnet settings are in Main Menu > Configuration Menu > CONNECT (Advanced User password): BACnet Enable, BACnet Metric Unit, BACnet Network, BACnet Identifier.
  • Defaults: BACnet identifier 1600001, BACnet network 1601; change both if more than one Carrier chiller is on the network.
  • Changing a BACnet parameter reboots the board after about a minute; changing the IP address in SETUP needs a manual reboot or power cycle.
  • Set the unit IP address, mask and gateway on the Setup > Network screen (DHCP can be enabled there).
  • An IP router between the chiller and the BMS stops it responding; check the dongle shows Yes under Inputs Status.

Watch out for

  • Write the _wr objects; the _rd objects only echo the current value.
  • Free cooling start (BV 43) is ignored while the chiller is running.
  • Object names carry the CCN table prefix (GENUNIT_, TEMP_, SETPOINT_); some descriptions are internal labels such as 'Jbus Current Alarm'.

Integration notes

  • This is the older PIC 5 controller generation; the AquaEdge 19DV and 23XRV files cover the PIC6 controller.
  • BACnet needs the blue BACnet dongle plugged into the PIC 5 board; no BACnet MS/TP option is described.
  • Objects the table marks CMD are mapped as commandable (C); other RW objects as writable (W).
  • No units column; values are metric unless BACnet Metric Unit is set to NO.
  • Several AV objects carry coded values (control mode, valve status, surge region); the codes are in the states field.

Questions about the Carrier AquaEdge 19XR (PIC 5)

How many BACnet points does the Carrier AquaEdge 19XR (PIC 5) have?

This list has 159 BACnet objects: 116 analog values, 43 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaEdge 19XR (PIC 5) BACnet points are writable?

14 of the 159 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier AquaEdge 19XR (PIC 5) BACnet documentation?

The source is AquaEdge 19XR Two-Stage High-Efficiency Semi-Hermetic Centrifugal Liquid Chillers with PIC 5 Controls - Controls Operation and Troubleshooting (Appendix D) (19XR-CLT-3T), revision 2016-11, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/05/19XR-CLT-3T.pdf.

What are the minimum BACnet points to integrate the Carrier AquaEdge 19XR (PIC 5)?

Start with BV 40 GENUNIT_CHIL_S_S_wr (Network start/stop command); BV 42 GENUNIT_CHIL_OCC_wr (Network occupied command); BV 41 GENUNIT_EMSTOP_wr (Emergency stop command); AV 114 GENUNIT_CTRL_PNT_wr (Control point command); AV 115 GENUNIT_DEM_LIM_wr (Demand limit command); AV 1 GENUNIT_ctl_mode (Control mode: Local, Network, Remote, Local Sched); AV 7 GENUNIT_ch_state (Chiller status code); AV 9 TEMP_LCW (Leaving chilled water temperature); AV 8 TEMP_ECW (Entering chilled water temperature); AV 68 ALARMRST_alarm_1 (Current alarm 1).

How do I enable BMS control of the Carrier AquaEdge 19XR (PIC 5)?

In NETWORK control mode the chiller starts and stops from the CHIL_S_S and CHIL_OCC points written over the network (both must be true). Use EMSTOP or the HMI to shut it down. A STOP OVERRIDE point in GENUNIT, if enabled, prevents starting.
