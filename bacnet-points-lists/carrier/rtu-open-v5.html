Carrier RTU Open v5 BACnet points list

Short answer

RTU Open is Carrier's multi-protocol controller for packaged rooftop units and heat pumps. It speaks BACnet MS/TP or ARC156 natively and can be switched to Modbus, N2 or LonWorks. Its device instance is derived from Carrier's vendor ID (16) and the rotary address switches. Points cover setpoints, sensor values, stages, economizer/ventilation, alarms and the 'system' points a BAS can write in place of local sensors.

BMS integration notes: Carrier RTU Open v5

Integration in brief

Set the RTU Open for BACnet MS/TP with its DIP switches and rotary address, then set Occupancy Source to BAS On/Off so the BMS can command occupancy through keypad_ovrde. Write setpoints directly. Any sensor the BMS supplies (space temp, OAT, RH, CO2) goes into the system_* points at priority 16 and has to be refreshed within each point's refresh window.

Enable & remote start

Occupancy Source (occ_source, MSV:1002) defaults to Always Occupied. Set it to 3 = BAS On/Off, then write keypad_ovrde (MSV:1001): 1=Inactive, 2=Occupied, 3=Unoccupied. The shutdown point (BV:9001) stops the unit from the network.

Heartbeat & communication loss

No general heartbeat. Each system point has a recommended refresh time (min/max), e.g. space temperature 1 min / 5 min, OAT 5 min / 60 min. The network value is only used while it keeps being refreshed within that window; for OAT, a lost network value raises the Outdoor Air Temp Sensor alarm and the OAT lockouts stop working.

Sensors & values from the BMS

Write system_spt (AV:1902), system_oat (AV:1901), system_rh (AV:1904), system_iaq (AV:1903), system_oaq (AV:1908) and oae (BV:1901, OA enthalpy) at BACnet priority 16, no more than once a minute. A network value overrides the local sensor while it is refreshed in time. Don't read the system point back to confirm a write, because the controller clears it after processing. Read the matching control point instead (space_temp, oa_temp, space_rh, iaq, oaq), at least 30 s after the write.

Network setup

  • MS/TP MAC address is set on rotary switches SW1 (tens) and SW2 (ones); valid 01-99.
  • Device instance is generated automatically as 16101xx (16 = Carrier vendor ID, xx = rotary address); it can be changed with an Equipment Touch.
  • Baud is set on SW3 DIP 1-2 (9600/19.2k/38.4k/76.8k); 76.8k is the Carrier default; 8N1 fixed.
  • Protocol DIP switches must be set for BACnet MS/TP and the jumper set to EIA-485; switch changes only take effect after a power cycle.
  • Max Masters defaults to 127 and Max Info Frames to 10 (adjustable via Equipment Touch).

Watch out for

  • System points must be written at priority 16; writes at any other priority are ignored.
  • Never write a system point more than once per minute (60 s).
  • Only controllers set as MS/TP masters answer Who-Is.
  • Some points only apply with certain options (heat pump, VFD fan, economizer, humidity sensors).

Integration notes

  • System points (system_spt, system_oat, system_rh, system_iaq, etc.) must be written at BACnet priority 16 and no more than once per minute; -999 means no network value.
  • Some points only apply to certain unit configurations (heat pump, VFD fan, economizer, humidity options).
  • Several display names in the source table are just 'Setpoint'; the BACnet object name tells you which one (e.g. unocc_ht_stpt).
  • Instances use Carrier's numbering scheme (e.g. AV:1901, BV:7011), not small sequential numbers.
  • AV:83010 is listed twice in the source (ht_spd_volt and stg_3_sat); verify on the controller which one is present.
  • Each point also has a Modbus register in the same table; only the BACnet side is captured here.

Questions about the Carrier RTU Open v5

How many BACnet points does the Carrier RTU Open v5 have?

This list has 200 BACnet objects: 8 analog inputs, 80 analog values, 5 binary inputs, 83 binary values, 24 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier RTU Open v5 BACnet points are writable?

104 of the 200 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier RTU Open v5 BACnet documentation?

The source is RTU Open v5 Integration Guide (Appendix A: Network Points List) (11-808-697-01), revision 2019-11-19, published free by Carrier at https://www.shareddocs.com/hvac/docs/1000/Public/04/11-808-697-01.pdf.

What are the minimum BACnet points to integrate the Carrier RTU Open v5?

Start with MV 1002 occ_source (Set to 3 (BAS On/Off) to allow network occupancy); MV 1001 keypad_ovrde (BAS occupancy command: occupied/unoccupied); BV 9001 shutdown (Network shutdown command); AV 3001 occ_cl_stpt (Occupied cooling setpoint); AV 3002 occ_ht_stpt (Occupied heating setpoint); MV 2002 run_status (Current system mode); BV 2008 occ_status (Confirms occupied/unoccupied); AV 2007 space_temp (Space temperature the unit controls to); AV 1008 sa_temp (Supply air temperature); BV 7008 sfan_fail_alarm (Supply fan failure alarm).
