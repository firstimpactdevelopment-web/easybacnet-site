Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43) BACnet points list

Updated 4 November 2026

Short answer

The 33CONNECTSTAT43 is a Wi-Fi thermostat that also speaks BACnet MS/TP on its A+/B- terminals (B-ASC profile). Its 113 objects cover space temperature and humidity, setpoints, stage output status, fault flags, mode and fan mode, and most installer settings. Installer settings are 'gated' writes that only work when BACnet Config Write is enabled at the thermostat, and BMS occupancy only works when BACnet BMS Occ is enabled.

This page lists 113 BACnet objects for the Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43) — 74 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Carrier’s own free documentation, linked below.

BMS integration notes: Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43)

Integration in brief

Wire the thermostat to the MS/TP trunk and set MAC address, baud and device ID in its advanced system settings. Turn on BACnet BMS Occ at the thermostat if the BMS should drive occupancy through BMS_OCC, and BACnet Config Write only if the BMS must change installer settings. Write the baseline occupied/unoccupied setpoints for permanent changes; writes to HEAT_SP/COOL_SP are temporary holds.

Enable & remote start

BACNET BMS OCC (set at the thermostat screen) enables BACnet occupancy control through BMS_OCC (BV:405); setting it to YES forces the thermostat to non-programmable mode and turns off a remote sensor set to Occupancy. BACNET CONFIG WRITE (also local) allows writes to all GATED_WRITE points. USER_MODE (MSV:400) sets the system mode.

Heartbeat & communication loss

No communication-loss timeout is described. Network general purpose outputs return to inactive if not rewritten within the General Purpose Output Timeout (MSV:508: 2 min, 20 min, 1 h or unlimited).

Sensors & values from the BMS

Network Space Temperature (AV:103) and Network Space Humidity (AV:105) are writable, with enables Network Space Temp Enable (BV:407) and Network Space Hum Enable (BV:408). The guide gives no refresh time for them. Read SP_TEMP_CTRL (AV:104) and SP_HUM_CTRL (AV:106) for the values in use.

Network setup

  • MS/TP on terminals A+ and B-; do not terminate the shield at the thermostat. 22 or 24 AWG shielded twisted pair, 2000 ft per segment.
  • Baud 9600, 19200, 38400, 76800 (default) or 115200; MAC address 1-127 (default 1); Max Masters default 127.
  • Device ID defaults to Carrier's BACnet identifier 16 plus the last 4 digits of the serial number; device object name up to 16 characters.
  • BACnet UTC offset is set at the thermostat (-13 to +13 h).

Watch out for

  • Writing HEAT_SP (AV:409) or COOL_SP (AV:410) puts the thermostat in a temporary hold until Max Temperature Hold Time (AV:502, default 2 h) expires; write AV:400-403 for lasting changes.
  • GATED_WRITE points are rejected unless BACnet Config Write is enabled; the guide says the two gate settings are only accessible from the local screen.
  • BMS occupancy can't be used with programmable mode or a remote occupancy sensor at the same time.

Integration notes

  • The table prints four access levels: READ_ONLY, READ_WRITE, GATED_WRITE and WRITE_WHEN_OOS. GATED_WRITE points are marked W here and noted in the description; the two WRITE_WHEN_OOS inputs (AI:100, AI:101) are marked R.
  • Some units look like copy errors in the source and are kept as printed: Indoor Equip Stages (AV:500) in %RH and Outdoor Equip Stages (AV:501) in °F.
  • Fault flag ID TEMP SENSOR HIGH (BV:900) is printed with DISABLED/ENABLED states, unlike the other fault flags; kept as printed.
  • The Network GP Y3/W2/OB outputs (BV:211-213) only accept writes when their Net GP mode (MSV:509-511) is not Disabled, and they can time out per General Purpose Output Timeout (MSV:508).
  • Current Fan Mode (MSV:406) is printed with the object name 'FAN MODE' (with a space), unlike the other underscore names.

Questions about the Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43)

How many BACnet points does the Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43) have?

This list has 113 BACnet objects: 2 analog inputs, 43 analog values, 48 binary values, 20 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43) BACnet points are writable?

74 of the 113 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43) BACnet documentation?

The source is Carrier Connect Wi-Fi Thermostat 33CONNECTSTAT43 Installation Guide (Appendix: BACnet Points List) (11-808-728-01), revision 2022-12-02, published free by Carrier at https://www.shareddocs.com/hvac/docs/1000/Public/0C/11-808-728-01.pdf.

What are the minimum BACnet points to integrate the Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43)?

Start with MV 400 USER_MODE (Mode command: off, heat, cool, auto, emergency heat); BV 405 BMS_OCC (BMS occupancy; needs BACnet BMS Occ enabled locally); AV 400 OCC_HT_SP (Occupied heating setpoint); AV 401 OCC_CL_SP (Occupied cooling setpoint); MV 404 OCC_FAN (Occupied fan mode: auto or on); MV 300 CURRENT_MODE (Mode now running: off, heat or cool); AV 104 SP_TEMP_CTRL (Space temperature used for control); BV 205 G_OUT (Fan output status); BV 911 OD_TEMP_FAIL (Outdoor sensor failure).

How do I enable BMS control of the Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43)?

BACNET BMS OCC (set at the thermostat screen) enables BACnet occupancy control through BMS_OCC (BV:405); setting it to YES forces the thermostat to non-programmable mode and turns off a remote sensor set to Occupancy. BACNET CONFIG WRITE (also local) allows writes to all GATED_WRITE points. USER_MODE (MSV:400) sets the system mode.

Does the Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43) need a BACnet heartbeat or have a communication timeout?

No communication-loss timeout is described. Network general purpose outputs return to inactive if not rewritten within the General Purpose Output Timeout (MSV:508: 2 min, 20 min, 1 h or unlimited).

Can the BMS supply sensor values to the Carrier Connect Wi-Fi Thermostat (33CONNECTSTAT43)?

Network Space Temperature (AV:103) and Network Space Humidity (AV:105) are writable, with enables Network Space Temp Enable (BV:407) and Network Space Hum Enable (BV:408). The guide gives no refresh time for them. Read SP_TEMP_CTRL (AV:104) and SP_HUM_CTRL (AV:106) for the values in use.
