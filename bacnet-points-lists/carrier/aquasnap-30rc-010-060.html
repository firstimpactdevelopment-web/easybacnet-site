Short answer

The 30RC's Carrier Controller provides BACnet IP on Ethernet port J5 and BACnet MS/TP on RS-485 port J10, configured from the BACnet Standard Conf. menu. Command points come as separate read (_rd) and write (_wr) objects, with the writable copies at 10000+ instances. Alarm objects are numbered after Carrier's alarm codes (e.g. BV 110001).

This page lists 232 BACnet objects for the Carrier AquaSnap 30RC 010-060 — 24 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Carrier’s own free documentation, linked below.

BMS integration notes: Carrier AquaSnap 30RC 010-060

Integration in brief

Set bacena to BACnet IP or MS/TP in Main Menu > Configuration > BACnet, set device ID and network, then select the Network control method on the chiller. Command through the _wr objects (start/stop, occupancy, control point, demand limit, emergency stop) and read status, water temperatures, capacity and alarms.

Enable & remote start

Select the Network machine control method with the Start/Stop button; the unit then follows CCN, BACnet (if enabled) or Modbus commands and ignores the remote contacts. Start/stop and occupancy are written to the _wr objects.

Heartbeat & communication loss

The manual says that if communication with the network is lost while under network control, the chiller starts and runs under local control.

Network setup

  • BACnet is disabled by default (bacena 0); set 1 for BACnet IP or 2 for BACnet MS/TP.
  • Defaults shown: network number 1600, UDP port 47808, device ID 1600001 (manual or auto device ID option).
  • MS/TP defaults: baud option 2 (38400), Max Master 10, Max Info Frames 5; MAC 1-127.
  • J5 (ETH0) carries BACnet IP / Modbus TCP; J10 is RS-485 for BACnet MS/TP or secondary Modbus RTU.

Watch out for

  • Write the _wr object, not the _rd one; the _rd copy only reports the current value.
  • The BACnet menu has a 'BACnet Manage Occupancy' option (mng_occ) and the list has a writable BACnet_BMS_OCC (AV 66); check how they interact with CHIL_OCC before relying on either.

Questions about the Carrier AquaSnap 30RC 010-060

How many BACnet points does the Carrier AquaSnap 30RC 010-060 have?

This list has 232 BACnet objects: 137 analog values, 94 binary values, 1 multi-state value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaSnap 30RC 010-060 BACnet points are writable?

24 of the 232 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier AquaSnap 30RC 010-060 BACnet documentation?

The source is AquaSnap 30RC 010-060 Air-Cooled Chillers - Controls, Start-Up, Operation, Service and Troubleshooting (Appendix D, BACnet IP Points) (30RC-101T), revision 2025-10, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/04/30RC-101T.pdf.

What are the minimum BACnet points to integrate the Carrier AquaSnap 30RC 010-060?

Start with BV 10012 GENUNIT_CHIL_S_S_wr (Network start/stop command); BV 10058 GENUNIT_CHIL_OCC_wr (Network occupied command); AV 21 GENUNIT_CTRL_TYP (Control type: Local, Network or Remote); AV 22 GENUNIT_STATUS (Running status); AV 2 TEMP_LWT (Leaving water temperature); AV 1 TEMP_EWT (Entering water temperature); AV 900 SETPOINT_csp1 (Cooling setpoint 1 (writable)); AV 10008 GENUNIT_DEM_LIM_wr (Demand limit command); AV 9 GENUNIT_CAP_T (Percent total capacity); AV 990 ALARMRST_ALM (Unit alarm state).

How do I enable BMS control of the Carrier AquaSnap 30RC 010-060?

Select the Network machine control method with the Start/Stop button; the unit then follows CCN, BACnet (if enabled) or Modbus commands and ignores the remote contacts. Start/stop and occupancy are written to the _wr objects.

Does the Carrier AquaSnap 30RC 010-060 need a BACnet heartbeat or have a communication timeout?

The manual says that if communication with the network is lost while under network control, the chiller starts and runs under local control.

How do I check these points on the real AquaSnap 30RC 010-060?
