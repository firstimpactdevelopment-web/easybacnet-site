Short answer

The SMS is a plant controller for up to four modular R-290 air-source heat pumps; it talks to the heat pumps over BACnet IP and offers BACnet IP and Modbus TCP to the BMS through the Ethernet switch in its cabinet. The object list has 315 objects grouped by function: general system commands and status, schedules, two heating/cooling zones, customer and DHW pump sets, the heat pump manager, and one block per heat pump.

BMS integration notes: Carrier System Management Sequencer (SMS) Option 275A for modular R-290 air-source heat pumps

Integration in brief

Connect the BMS to the Ethernet switch in the SMS cabinet. Put the system in Auto operating type with the front button, then drive it with the On/Off input command (MV 502) and the heating/cooling selection (MV 521), adjust zone setpoints, and read system status, temperatures, heat pump status and the synthesis alarm.

Enable & remote start

The system follows the On/Off input command only in the Auto operating type selected with the SMS front button (AV 501 reports it). In Auto the command can be Off, On or Based on Schedule. The network emergency stop shuts the system down in any operating type.

Sensors & values from the BMS

Zone relative humidity for dew point calculation (AV 264) can be written by the BMS when floor sensors are used.

Network setup

  • The SMS has five Ethernet ports for the heat pumps (BACnet IP) and the BMS (BACnet IP, Modbus TCP).
  • Each heat pump must be set to Network control mode, or the SMS raises a 'not in network mode' alarm and drops it from the sequence.

Watch out for

  • Maintenance-mode BVs (e.g. BV 126-129) stop a heat pump or pump when set; do not leave them active.
  • Several points are labelled 'Zone n°1 or No Zone'; on a single-zone plant only the zone 1 points apply.
