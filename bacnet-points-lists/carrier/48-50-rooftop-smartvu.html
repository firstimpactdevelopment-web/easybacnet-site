Short answer

The SmartVu touchscreen control with PIC 6.1 hardware runs Carrier's 48/50K and 48/50V applied rooftop units. It speaks BACnet MS/TP on port J8 or BACnet IP on either Ethernet port, plus CCN; Modbus is not offered for BAS use. Almost every object is an analog, binary or multistate value, grouped into setpoints, sensor readings, network inputs, unit states, outputs, runtimes and a large set of configuration and alert-limit values.

BMS integration notes: Carrier 48/50K and 48/50V Rooftop (SmartVu PIC 6.1)

Integration in brief

On the SmartVu Controller Config screens (user password 1111) set Primary BAS Network to BACnet and BACnet Enable to MS/TP or BACnet IP, then reboot. Occupancy comes from BACnet schedule objects or the Network Occupancy point (AV 363); write the occupied setpoints directly and read unit states, temperatures and the alarm relay. Check the numeric codes of configuration AVs on the touchscreen before writing them.

Enable & remote start

Primary BAS Network selects the network that drives occupancy; it must be BACnet to use the Network Occupancy point (GENUNIT_NETOCC, AV 363) when BACnet schedule objects are not used. The guide does not say what the 0-2 values of AV 363 mean (default 2). Occupancy Source (MV 26) shows where occupancy currently comes from.

Sensors & values from the BMS

The Network Inputs group has writable objects for BMS values, e.g. Net SPT (AV 360), Net OAT (AV 362), Net SPRH (AV 347), Net Indoor Air Quality (AV 357), Net Building Pressure (AV 352), and network thermostat calls Network Y1/Y2/W1/W2/G/HSTAT (BV 141-146). The guide does not explain how the unit selects them or give any refresh timeout.

Network setup

  • Communication settings are on the Controller Config screen, shown only after logging in with the user password 1111 (touchscreen or VNC).
  • BACnet MS/TP uses port J8 (field-supplied plug). First set Zone Sensor Config > Serial Port Config to Modbus_J8_MSTP so J10 stays Modbus for the internal drives, then set BACnet Enable = MS/TP, MAC, baud, network and identifier. Max Masters 127 and Max Info Frames 20 or less are recommended.
  • BACnet IP: Ethernet 0 (J15, default 169.254.1.1/255.255.0.0) or Ethernet 1 (J16, default 192.168.100.100/255.255.0.0); UDP 47808 by default; BACnet Mgmt Device can be None, Foreign Device or BBMD. Reboot after IP changes.
  • J8 carries either BACnet MS/TP or Rnet sensors, not both, on software 2.5.0.
  • The SmartVu is locally biased: don't put it on a network-biased segment, and terminate with a TERM485 rather than router end-of-line switches.

Watch out for

  • The list is for software 2.5.0; versions before 2.4.0 may use different instances and names.
  • Most configuration values are AVs with undocumented numeric codes; read the current value and check the touchscreen before writing.
  • BV 83 is the alarm relay output. Alarm Output (BV 101, Equipment Configs) and Alarm Relay inversion (BV 206, Switch Inversion) also exist; the guide doesn't explain them, so check on the touchscreen.
  • Percentages read as 0.00-1.00 or 0-100 depending on the Percentage Conversion setting.

Integration notes

  • Point availability varies by model, unit type, size and options; not every object exists on every unit.
  • Units are shown as printed (imperial). The Metric Units setting switches units, and the Percentage Conversion setting changes percentages between 0-100 and 0.00-1.00.
  • Binary and multistate states are listed as printed, numbered from 1 (e.g. 1=OFF, 2=ON).
  • Some multistate texts are printed oddly and kept as is: CF 1-3 Mode lists DP_LOW twice, Comp A1-B2 Mode splits '5=DP; 6=LOW', and Heater/Indoor Fan Mode carry unnumbered extra values.
  • Many configuration points are AVs holding numeric option codes (e.g. Network Occupancy 0-2, Demand Limit Source 0-3) that the guide does not decode.
  • The table also lists CCN point names; only the BACnet side is captured here.

Questions about the Carrier 48/50K and 48/50V Rooftop (SmartVu PIC 6.1)

How many BACnet points does the Carrier 48/50K and 48/50V Rooftop (SmartVu PIC 6.1) have?

This list has 715 BACnet objects: 502 analog values, 186 binary values, 27 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier 48/50K and 48/50V Rooftop (SmartVu PIC 6.1) BACnet points are writable?

393 of the 715 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier 48/50K and 48/50V Rooftop (SmartVu PIC 6.1) BACnet documentation?

The source is SmartVu Controls Version 2.X for Applied Rooftop Integration Guide (Appendix A: BACnet and CCN Network Points) (48-50-ART-SVU-1T), revision 2025-03, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/0F/48-50-ART-SVU-1T.pdf.

What are the minimum BACnet points to integrate the Carrier 48/50K and 48/50V Rooftop (SmartVu PIC 6.1)?

Start with AV 363 GENUNIT_NETOCC (Network occupancy; Primary BAS Network must be BACnet); AV 195 COOLSTP_CLSP_OCC (Occupied cooling setpoint); AV 313 HEATSTP_HTSP_OCC (Occupied heating setpoint); BV 1 ALARMRST_RST_ALM (Alarm reset command); MV 22 STATES_IDFNUM (Indoor fan state; 5 = running); AV 289 GENUNIT_OCCUPIED (Confirms occupied/unoccupied); AV 7 AIRTEMP_SPT (Space temperature); AV 4 AIRTEMP_SAT (Supply air temperature); BV 83 DISCOUT_ALMOUT (Common alarm relay output).

How do I enable BMS control of the Carrier 48/50K and 48/50V Rooftop (SmartVu PIC 6.1)?

Primary BAS Network selects the network that drives occupancy; it must be BACnet to use the Network Occupancy point (GENUNIT_NETOCC, AV 363) when BACnet schedule objects are not used. The guide does not say what the 0-2 values of AV 363 mean (default 2). Occupancy Source (MV 26) shows where occupancy currently comes from.

Can the BMS supply sensor values to the Carrier 48/50K and 48/50V Rooftop (SmartVu PIC 6.1)?

The Network Inputs group has writable objects for BMS values, e.g. Net SPT (AV 360), Net OAT (AV 362), Net SPRH (AV 347), Net Indoor Air Quality (AV 357), Net Building Pressure (AV 352), and network thermostat calls Network Y1/Y2/W1/W2/G/HSTAT (BV 141-146). The guide does not explain how the unit selects them or give any refresh timeout.
