Short answer

The 19DV's PIC6 controller speaks BACnet MS/TP on RS-485 port J8 or BACnet IP on Ethernet, plus Modbus RTU/TCP. Commands use paired read (_rd) and write (_wr) objects; the write copies (start/stop, occupancy, control point, demand limit, emergency stop, free cooling, heat/cool select) are marked CMD. The list also includes temperatures, pressures, guide-vane and VFD data, surge and alarm points.

BMS integration notes: Carrier AquaEdge 19DV (PIC6)

Integration in brief

Enable BACnet in the BMS Protocol menu (J8 option for MS/TP or BACnet/IP Enable), set the identifier and network, and enable Network start. The chiller then starts when both BV 66 start/stop and BV 68 occupancy are true; write control point and demand limit through the _wr objects and read status, water temperatures and alarms.

Enable & remote start

In NETWORK control mode the chiller starts and stops from the CHIL_S_S and CHIL_OCC points written over the network (both must be true). Use EMSTOP for a quick shutdown. A STOP OVERRIDE point in GENUNIT, if enabled, prevents starting.

Network setup

  • BMS Protocol menu (CONNECT table): Port J8 option 0=None, 1=BACnet MS/TP, 2=Modbus RTU; BACnet/IP Enable is separate.
  • Defaults: BACnet identifier 1600001, BACnet network 1600, MS/TP MAC 1, MS/TP baud option 2 (38400), Max Master 3, Max Info Frames 5.
  • Ethernet: J15 defaults to 169.254.1.1/16, J16 to 192.168.100.100/24; DHCP is not supported.
  • BACnet MS/TP and BACnet IP cannot both be enabled; Modbus RTU can run with BACnet IP.

Watch out for

  • Write the _wr objects; the _rd objects only echo the current value.
  • BV 66 shows multistate text in the guide; it is a two-state start/stop command.

Questions about the Carrier AquaEdge 19DV (PIC6)

How many BACnet points does the Carrier AquaEdge 19DV (PIC6) have?

This list has 229 BACnet objects: 151 analog values, 69 binary values, 9 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaEdge 19DV (PIC6) BACnet points are writable?

14 of the 229 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier AquaEdge 19DV (PIC6) BACnet documentation?

The source is AquaEdge 19DV Two-Stage High-Efficiency Centrifugal Chiller - Controls Operation and Troubleshooting (Appendix D) (19DV-CLT-3T), revision 2020-02, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/0D/19DV-CLT-3T.pdf.

What are the minimum BACnet points to integrate the Carrier AquaEdge 19DV (PIC6)?

Start with BV 66 GENUNIT_CHIL_S_S_wr (Network start/stop command); BV 68 GENUNIT_CHIL_OCC_wr (Network occupied command); MV 1 GENUNIT_ctl_mode (Control mode: Local, Network, Remote, Local Sched); AV 7 GENUNIT_ch_state (Chiller status code); AV 9 TEMP_LCW (Leaving chilled water); AV 8 TEMP_ECW (Entering chilled water); AV 147 GENUNIT_CTRL_PNT_wr (Control point command); AV 148 GENUNIT_DEM_LIM_wr (Demand limit command); BV 67 GENUNIT_EMSTOP_wr (Emergency stop command); AV 85 ALARMRST_alarm_1 (Current alarm 1).

How do I enable BMS control of the Carrier AquaEdge 19DV (PIC6)?

In NETWORK control mode the chiller starts and stops from the CHIL_S_S and CHIL_OCC points written over the network (both must be true). Use EMSTOP for a quick shutdown. A STOP OVERRIDE point in GENUNIT, if enabled, prevents starting.

How do I check these points on the real AquaEdge 19DV (PIC6)?
