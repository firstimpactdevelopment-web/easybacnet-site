Short answer

The 30XV Carrier Controller has native BACnet IP on Ethernet-0 (J15) and BACnet MS/TP on RS485-4 (J8), with about 765 objects: AVs, BVs and a few MVs named after their CCN table and point. BMS integration notes: Carrier AquaForce 30XV 140-500 Series B (PIC6.1 Carrier Controller)

Integration in brief

Enable BACnet (bacena), pick BACnet IP or MS/TP in the BACnet configuration menu, set the identifier and network number, then select the Network machine control method with the Start/Stop button. Command through the _wr objects (start/stop, occupancy, control point, demand limit, emergency stop) and read run status, water temperatures, capacity and alarm state.

Enable & remote start

Select the Network machine control method with the Start/Stop button; the unit then follows network commands and ignores the remote control contacts and the Enable-Off-Remote switch (SW1). Start/stop and occupancy are written to the _wr objects. In Local On, Local Schedule or Remote the unit ignores network commands except emergency stop.

Heartbeat & communication loss

The manual says that if communication with the network is lost while under network control, the machine starts and is controlled locally.

Network setup

  • BACnet is enabled with the bacena service parameter; the data link (bacdlink) defaults to BACnet IP and can be set to MS/TP.
  • Defaults shown: network 1601, identifier 1600001, BBMD/foreign device off (0 = none, 1 = FD, 2 = BBMD).
  • MS/TP defaults: MAC 1, 38400 baud (9600-115200), Max Master 3, Max Info Frames 5.
  • BACnet IP uses Ethernet-0 (J15); BACnet MS/TP uses RS485-4 (J8).

Watch out for

  • Write the _wr object, not the _rd one; the _rd copy only reports the current value.
  • Cooling setpoints (AV 545-547) and switch limit setpoints (AV 549-551) are also writable directly, besides the GENUNIT _wr commands.
  • AV 109 ALARMRST_ALM and MV 109 Alarm_State share instance 109 but are different object types.

Questions about the Carrier AquaForce 30XV 140-500 Series B (PIC6.1 Carrier Controller)

How many BACnet points does the Carrier AquaForce 30XV 140-500 Series B (PIC6.1 Carrier Controller) have?

This list has 765 BACnet objects: 532 analog values, 227 binary values, 6 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaForce 30XV 140-500 Series B (PIC6.1 Carrier Controller) BACnet points are writable?

20 of the 765 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier AquaForce 30XV 140-500 Series B (PIC6.1 Carrier Controller) BACnet documentation?

The source is AquaForce 30XV140-500, Series B Variable Speed Air-Cooled Liquid Chillers with Greenspeed Intelligence and Carrier PIC6.1 Controller - Controls, Start-Up, Operation, Service and Troubleshooting (Appendix E, BACnet IP and MS/TP Points) (30XV-6T), revision 5-26, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/00/30XV-6T.pdf.

What are the minimum BACnet points to integrate the Carrier AquaForce 30XV 140-500 Series B (PIC6.1 Carrier Controller)?

Start with BV 123 GENUNIT_CHIL_S_S_wr (Network start/stop command); BV 129 GENUNIT_CHIL_OCC_wr (Network occupied command); AV 552 GENUNIT_CTRL_PNT_wr (Leaving water control point from the BMS); AV 553 GENUNIT_DEM_LIM_wr (Demand limit command); AV 20 GENUNIT_CTRL_TYP (Control type: Local, Network or Remote); AV 21 GENUNIT_STATUS (Running status); AV 30 TEMP_COOL_LWT (Leaving chilled water temperature); AV 29 TEMP_COOL_EWT (Entering chilled water temperature); AV 24 GENUNIT_CAP_T (Percent total capacity); AV 109 ALARMRST_ALM (Unit alarm state).

How do I enable BMS control of the Carrier AquaForce 30XV 140-500 Series B (PIC6.1 Carrier Controller)?

Select the Network machine control method with the Start/Stop button; the unit then follows network commands and ignores the remote control contacts and the Enable-Off-Remote switch (SW1). Start/stop and occupancy are written to the _wr objects. In Local On, Local Schedule or Remote the unit ignores network commands except emergency stop.

Does the Carrier AquaForce 30XV 140-500 Series B (PIC6.1 Carrier Controller) need a BACnet heartbeat or have a communication timeout?

The manual says that if communication with the network is lost while under network control, the machine starts and is controlled locally.
