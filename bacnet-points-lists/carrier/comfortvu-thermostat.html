Carrier ComfortVu BACnet Thermostat BACnet points list

Updated 16 October 2026

Short answer

The ComfortVu is a touchscreen room thermostat that can talk BACnet MS/TP on an RS-485 bus (a DIP switch selects BACnet or Modbus). Its object list mixes live values (temperatures, outputs, occupancy) with the technician settings, so many installer parameters are writable over the network. Several object instances are reused with different names depending on whether the thermostat is set up for a fan coil (FC) or an AC/heat pump (AC) system, so expect only one of each pair to exist on a given unit.

This page lists 165 BACnet objects for the Carrier ComfortVu BACnet Thermostat — 115 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Carrier’s own free documentation, linked below.

BMS integration notes: Carrier ComfortVu BACnet Thermostat

Integration in brief

Put the thermostat on BACnet MS/TP, then command it like a wall stat: turn it on/off with OnOff, pick the mode and fan speed, and write the cooling and heating setpoints. Read back the effective setpoint, mode, fan and occupancy to confirm what the thermostat is actually doing. The points list gives no network timeout and no network space-temperature input.

Enable & remote start

BV0 OnOff turns the thermostat on/off over the network. BI10 S1_8_UseBacnet shows whether the DIP switch has it set to BACnet (1) or Modbus (0).

Network setup

  • MS/TP at 9600, 19200, 38400 or 76800 baud, no parity, 8 data bits, 1 stop bit.
  • A DIP switch selects BACnet or Modbus; read it back on BI10 S1_8_UseBacnet.
  • The device instance is AV42 BacnetDeviceInstanceNumber, writable, range 10000 to 4000193.
  • DIP switches also set AC vs fan coil (FC) system type, which changes which objects exist.

Watch out for

  • Mode, fan speed and occupancy are integer-coded Analog Values, not Multistate objects.
  • Several instances are reused: the same BI/BO number has an AC name and an FC name, and only one applies.
  • Many writable AVs are the thermostat's technician (P) settings, so writing them changes the installer configuration.

Integration notes

  • MS/TP baud rates 9600, 19200, 38400 or 76800, 8N1.
  • DIP switch configuration (AC vs FC system) decides which objects exist; some instances appear twice in the list with an AC name and an FC name.
  • Mode, fan speed and similar enumerations are Analog Values carrying integer codes, not Multistate objects.
  • The device instance itself can be changed by writing AV42 (BacnetDeviceInstanceNumber).
  • Many writable AVs mirror the thermostat's technician (P) settings.

Questions about the Carrier ComfortVu BACnet Thermostat

How many BACnet points does the Carrier ComfortVu BACnet Thermostat have?

This list has 165 BACnet objects: 2 analog inputs, 5 analog outputs, 105 analog values, 16 binary inputs, 13 binary outputs, 24 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier ComfortVu BACnet Thermostat BACnet points are writable?

115 of the 165 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier ComfortVu BACnet Thermostat BACnet documentation?

The source is ComfortVu BACnet Thermostat Points List and Technician Settings (11-808-726-01), published free by Carrier at https://www.shareddocs.com/hvac/docs/1000/Public/06/11-808-726-01.pdf.

What are the minimum BACnet points to integrate the Carrier ComfortVu BACnet Thermostat?

Start with BV 0 OnOff (Turns the thermostat on or off); AV 4 Mode (Selects fan only, cool, heat or auto); AV 0 SetPoint_SetPointCool (Cooling setpoint); AV 1 SetPointHeat (Heating setpoint); AV 6 FanSpeed (Fan auto/low/medium/high); BV 28 UnoccupiedByNetwork (Network unoccupied/occupied command); AV 3 ReturnAirSensorEffective (Temperature the thermostat controls to); AV 13 OccupancyEffectiveHVAC (Resulting occupancy state); AV 5 ModeEffective (Mode actually running).

How do I enable BMS control of the Carrier ComfortVu BACnet Thermostat?

BV0 OnOff turns the thermostat on/off over the network. BI10 S1_8_UseBacnet shows whether the DIP switch has it set to BACnet (1) or Modbus (0).

How do I check these points on the real ComfortVu BACnet Thermostat?
