BMS integration notes: Carrier AquaSnap 30RAP 010-150 (UPC Open BACnet option)

Integration in brief

Address the UPC Open, set the MS/TP DIP switches, and set the chiller control method to CCN (Configuration > OPT2 > CTRL = 3). The BMS then starts and stops the unit with BV 4 (CHIL_S_S) and can write control point and demand limit; read control mode, leaving fluid temperature, capacity and alarm state.

Enable & remote start

Set the control method to CCN (Configuration > OPT2 > CTRL = 3). An external CCN device then forces CHIL_S_S (BV 4) between start and stop.

Network setup

  • The BACnet option adds a UPC Open controller; it speaks BACnet MS/TP at 9600, 19.2k, 38.4k or 76.8k (Carrier default 76.8k), set on BAS port DIP switches DS1-DS2.
  • For MS/TP set DS3 to enable, DS4 to E1-485 and the protocol switches DS5-DS8 to MSTP; the EIA-485 jumpers must be set to EIA-485 and 2W.
  • MAC address from the two rotary switches (tens and ones); the controller reads switches and DIP settings only at power-up.
  • Device instance is auto-generated as the network number (default 16101) followed by the MAC address, e.g. MAC 20 gives 1610120; change it with i-Vu Tools or a BACview.
  • Fit a BT485 terminator on the first and last controller of the MS/TP segment.

Watch out for

  • Several points (pumps, head pressure, Greenspeed fan drive) depend on unit options.

Integration notes

  • BACnet comes from the optional UPC Open controller, mounted in the main control box; object names end in _1.
  • The Network Points List gives a point description, CCN name, read/write, units, default and range for each object; descriptions here are the printed point descriptions.
  • The table lists multistate values as MSV (mapped as MV here), e.g. MV 1 Alarm State and MV 5 Control Method.
  • AV 8 Control Mode codes: 1 Test, 2 Local Off, 3 CCN Off, 4 Clock Off, 5 Emergency Stop, 6 Local On, 7 CCN On, 8 Clock On, 9 Heat Enabled, 10 Pump Delay.

Questions about the Carrier AquaSnap 30RAP 010-150 (UPC Open BACnet option)

How many BACnet points does the Carrier AquaSnap 30RAP 010-150 (UPC Open BACnet option) have?

This list has 161 BACnet objects: 85 analog values, 71 binary values, 5 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaSnap 30RAP 010-150 (UPC Open BACnet option) BACnet points are writable?

34 of the 161 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier AquaSnap 30RAP 010-150 (UPC Open BACnet option) BACnet documentation?

The source is AquaSnap 30RAP010-150 Air-Cooled Chillers and 30RAP011-060 with Greenspeed Intelligence - Controls, Start-Up, Operation, Service, and Troubleshooting (Appendix D, BACnet Communication Option, Network Points List) (30RAP-8T), revision 3-23, published free by Carrier at https://www.shareddocs.com/hvac/docs/1005/Public/0E/30RAP-8T.pdf.

What are the minimum BACnet points to integrate the Carrier AquaSnap 30RAP 010-150 (UPC Open BACnet option)?

Start with BV 4 chil_s_s_1 (Network start/stop); BV 6 emstop_1 (Emergency stop command); AV 5 ctrl_pnt_1 (Control point (leaving fluid setpoint)); AV 2 dem_lim_1 (Demand limit, 0-100 %); AV 8 stat_1 (Control mode code); AV 31 cool_lwt_1 (Cooler leaving fluid temperature); AV 30 cool_ewt_1 (Cooler entering fluid temperature); AV 3 cap_t_1 (Percent total capacity); MV 1 alm_msv_1 (Alarm state: 1 Normal, 2 Alert, 3 Alarm).

How do I enable BMS control of the Carrier AquaSnap 30RAP 010-150 (UPC Open BACnet option)?

Set the control method to CCN (Configuration > OPT2 > CTRL = 3). An external CCN device then forces CHIL_S_S (BV 4) between start and stop.
