BMS integration notes: Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0)

Integration in brief

On the SmartVu Controller Config screens (user password 1111) set Primary BAS Network to BACnet and BACnet Enable to MS/TP or IP, then reboot. Occupancy comes from BACnet schedule objects or the Network Occupancy point (AV 363); write the occupied setpoints directly and read unit states, temperatures and the alarm relay.

Enable & remote start

Primary BAS Network sets which network drives the occupancy schedule (BACnet, CCN, a CCN local schedule or none); CCN schedule zero makes the unit always occupied. The guide does not explain the values of Network Occupancy (GENUNIT_NETOCC, AV 363). Occupancy Source (MV 26) shows where occupancy currently comes from.

Heartbeat & communication loss

The list includes Network Input Timeout (SERVICE_NETINTO, AV 500), but the guide does not explain it or give a default.

Sensors & values from the BMS

Writable network inputs include Net SPT (AV 360), Net OAT (AV 362) and network thermostat calls Network Y1/Y2/W1/W2/G/HSTAT (BV 141-146). The guide does not explain how the unit selects them.

Network setup

  • Communication settings are on the Controller Config screen, shown only after logging in with the user password 1111.
  • BACnet MS/TP on port J8 of the touchscreen: set Serial Port Config to MS/TP, BACnet Enable to MS/TP, then network, MAC, identifier and baud. Max Masters 127 and Max Info Frames 20 or less are recommended; 32 nodes at 76,800 baud, 16 at 38,400.
  • BACnet IP on Ethernet 0 (J15) or Ethernet 1 (J16); UDP 47808 by default; BACnet Mgmt Device can be None, Foreign Device or BBMD. Reboot after IP changes.
  • The SmartVu is locally biased: don't put it on a network-biased segment; terminate with a TERM485 instead of router end-of-line switches. Fit 120 ohms at the first and last node.

Watch out for

  • Many configuration values are AVs or BVs without documented codes; read the current value and check the touchscreen before writing.
  • Percentages read as 0.00-1.00 or 0-100 depending on the Percentage Conversion setting.
  • Modbus BAS and Rnet on J8 are not supported in this SmartVu version.

Questions about the Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0)

How many BACnet points does the Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0) have?

This list has 1049 BACnet objects: 572 analog values, 450 binary values, 27 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0) BACnet points are writable?

444 of the 1049 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0) BACnet documentation?

The source is SmartVu Controls Version 2.X for Light Commercial and Applied Rooftop Gas Heat/Electric Cooling and Electric Heat/Electric Cooling Units with PIC 6.0 Hardware - Integration Guide (Appendix A: BACnet Points for 48/50LC*H) (48-50-LRT-SMVU-2T), revision 4-25, published free by Carrier at https://brandportal.carrier.com/asset/372917a4-9cbe-4b10-b124-328f4316d083/48-50-LRT-SMVU-2T.pdf.

What are the minimum BACnet points to integrate the Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0)?

Start with AV 363 GENUNIT_NETOCC (Network occupancy; Primary BAS Network must be BACnet); AV 195 COOLSTP_CLSP_OCC (Occupied cooling setpoint); AV 313 HEATSTP_HTSP_OCC (Occupied heating setpoint); BV 1 ALARMRST_RST_ALM (Alarm reset command); MV 22 STATES_IDFNUM (Indoor fan state); AV 289 GENUNIT_OCCUPIED (Confirms occupied/unoccupied); AV 7 AIRTEMP_SPT (Space temperature); AV 4 AIRTEMP_SAT (Supply air temperature); BV 83 DISCOUT_ALMOUT (Common alarm relay output).

How do I enable BMS control of the Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0)?

Primary BAS Network sets which network drives the occupancy schedule (BACnet, CCN, a CCN local schedule or none); CCN schedule zero makes the unit always occupied. The guide does not explain the values of Network Occupancy (GENUNIT_NETOCC, AV 363). Occupancy Source (MV 26) shows where occupancy currently comes from.

Does the Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0) need a BACnet heartbeat or have a communication timeout?

The list includes Network Input Timeout (SERVICE_NETINTO, AV 500), but the guide does not explain it or give a default.

Can the BMS supply sensor values to the Carrier 48/50LC*H Light Commercial Rooftop (SmartVu 2.X, PIC 6.0)?

Writable network inputs include Net SPT (AV 360), Net OAT (AV 362) and network thermostat calls Network Y1/Y2/W1/W2/G/HSTAT (BV 141-146). The guide does not explain how the unit selects them.
