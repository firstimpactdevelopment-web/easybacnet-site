Short answer

It publishes about 300 AV and BV objects (names ending in _1) covering start/stop, emergency stop, control point, demand limit, heat/cool select, setpoints, temperatures, pressures, compressor and fan status for up to three circuits, run hours and alarm state.

BMS integration notes: Carrier AquaSnap 30RB 060-390 (UPC Open BACnet option)

Integration in brief

Address the UPC Open (rotary switches), set the MS/TP baud and protocol DIP switches, and configure the chiller for CCN control. The BMS then starts and stops the chiller with BV 1500 (CCN Chiller Start/Stop) and can write control point, demand limit and heat/cool select; read run status, leaving water temperature, capacity and alarm state.

Enable & remote start

Set the Operating Control Type to 2 (CCN Control). An external CCN device then forces CHIL_S_S (BV 1500) between start and stop. The Status Unit Control Type reads 2 (CCN) when the Enable/Off/Remote Contact switch is On and 0 (Local Off) when it is Off.

Network setup

  • The BACnet option adds a UPC Open controller; it speaks BACnet MS/TP at 9600, 19.2k, 38.4k or 76.8k (Carrier default 76.8k), set on BAS port DIP switches DS1-DS2.
  • For MS/TP set DS3 to enable, DS4 to E1-485 and the protocol switches DS5-DS8 to MSTP; the EIA-485 jumpers must be set to EIA-485 and 2W.
  • MAC address from the two rotary switches (tens and ones); the controller reads switches and DIP settings only at power-up.
  • Device instance is auto-generated as the network number (default 16101) followed by the MAC address, e.g. MAC 20 gives 1610120; change it with i-Vu Tools or a BACview.
  • Fit a BT485 terminator on the first and last controller of the MS/TP segment.

Watch out for

  • The Enable/Off/Remote Contact switch must be On for network start/stop to take effect.
  • Many objects only apply with options such as heat reclaim, free cooling or a third circuit.

Integration notes

  • BACnet comes from the optional UPC Open controller, mounted in a separate enclosure below the main control box; object names end in _1.
  • The Network Points List gives a point description, CCN name, read/write, units, default and range for each object; descriptions here are the printed point descriptions.
  • AV 137 Run Status codes: 0 Off, 1 Running, 2 Stopping, 3 Delay, 4 Tripout, 5 Ready, 6 Override, 7 Defrost, 8 Run Test, 9 Test. AV 2 Alarm State: 0 Normal, 1 Partial, 2 Shutdown.
  • The printed table gives Cooling Setpoint 2 (AV 103) the unit "min" and the Cooling Ice Setpoint (AV 99) a delta unit; both are absolute setpoints and are shown here in °F. Some other printed units and defaults look shifted by a row and are kept as printed.

Questions about the Carrier AquaSnap 30RB 060-390 (UPC Open BACnet option)

How many BACnet points does the Carrier AquaSnap 30RB 060-390 (UPC Open BACnet option) have?

This list has 302 BACnet objects: 169 analog values, 133 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier AquaSnap 30RB 060-390 (UPC Open BACnet option) BACnet points are writable?

36 of the 302 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the Carrier AquaSnap 30RB 060-390 (UPC Open BACnet option)?

Start with BV 1500 chil_s_s_1 (Network start/stop (Enable/Disable)); BV 68 emstop_1 (Emergency stop command); AV 110 hc_sel_1 (Heat/cool select: 0 Cool, 1 Heat, 2 Auto); AV 96 ctrl_pnt_1 (Control point (leaving water setpoint)); AV 1 dem_lim_1 (Demand limit, 0-100 %); AV 137 status_1 (Run status code); AV 151 lwt_1 (Leaving water temperature); AV 1700 cap_t_1 (Percent total capacity); AV 2 alm_1 (Alarm state: 0 Normal, 1 Partial, 2 Shutdown).

How do I enable BMS control of the Carrier AquaSnap 30RB 060-390 (UPC Open BACnet option)?

Set the Operating Control Type to 2 (CCN Control). An external CCN device then forces CHIL_S_S (BV 1500) between start and stop. The Status Unit Control Type reads 2 (CCN) when the Enable/Off/Remote Contact switch is On and 0 (Local Off) when it is Off.
