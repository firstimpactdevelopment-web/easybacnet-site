Short answer

On 38APS/38APD condensing units the BACnet option is a UPC Open controller in the main control box. It talks BACnet MS/TP to the BMS and CCN to the unit's ComfortLink board. BMS integration notes: Carrier 38APS/38APD 025-130 Condensing Unit (ComfortLink, UPC Open BACnet option)

Integration in brief

Address the UPC Open on its rotary switches and set the BAS port DIP switches for MS/TP. Set the unit control method to CCN Control (CTRL=3); the BMS then starts and stops the unit with BV 4 chil_s_s_1 and can limit capacity with AV 2 dem_lim_1. Read the control mode (AV 8), capacity, circuit pressures and the comm alarm.

Enable & remote start

Set the control method to CCN Control (Configuration > OPT2 > CTRL = 3); the manual says units run by a third-party BAS through the UPC Open must use it. The unit switch must be in Enable, or in Remote Control with the external contacts closed. The BMS then writes CHIL_S_S Start/Stop; EMSTOP (BV 6) stops all cooling until set back to Enable.

Heartbeat & communication loss

The manual says loss of CCN communication puts the unit in stand-alone mode. BV 58 comm_lost_alm and BV 2999 element_stat_1 show the UPC Open link to the unit.

Sensors & values from the BMS

Outside Air Temperature (AV 1003) and Space Temperature (AV 2007) are writable; the space temperature is used with the SPT control types.

Network setup

  • Set the MAC address on the UPC Open Tens and Ones rotary switches; it reads switches, DIP switches and jumpers only at power-up.
  • Device instance = network number (default 16101) followed by the MAC address, e.g. MAC 20 gives 1610120.
  • BAS port: DS3 enable, DS4 E1-485, DS5-DS8 set to MSTP; baud on DS1-DS2 (9600, 19.2k, 38.4k or 76.8k, Carrier default 76.8k); 8N1 fixed. EIA-485 jumpers to EIA-485 and 2W.
  • Fit a BT485 terminator on the first and last controller of the MS/TP segment.
  • The UPC Open and the ComfortLink board must use the same CCN element and bus numbers (factory 1 and 0).

Watch out for

  • Start/stop over BACnet only works with the control method set to CCN; monitoring alone does not need it.
  • Points depend on unit size and options (number of compressors and fans, head pressure control, digital compressor).
  • Thermostat inputs Y1-Y4 are read-only in this list.

Integration notes

  • Object names end in _1, except a few printed without it (stat, oa_temp, space_temp, comm_lost_alm).
  • Multistate objects (MSV) are copies of CCN points made for i-Vu and BACnet; their state numbers are printed from 0, so the device may report them +1 (BACnet multistate values start at 1). Check by discovery.
  • Binary states are shown as 0/1 from the printed ON_OFF, YES_NO and ENA_DIS ranges. Numeric ranges are added to descriptions.
  • Rows appear for both circuits (A and B) with the same description; the object name tells them apart.
  • The 5 user-defined analog and 5 binary values are spare objects with no unit function.

The unit switch must be in Enable, or in Remote Control with the external contacts closed. The BMS then writes CHIL_S_S Start/Stop; EMSTOP (BV 6) stops all cooling until set back to Enable.

Does the Carrier 38APS/38APD 025-130 Condensing Unit (ComfortLink, UPC Open BACnet option) need a BACnet heartbeat or have a communication timeout?

The manual says loss of CCN communication puts the unit in stand-alone mode. BV 58 comm_lost_alm and BV 2999 element_stat_1 show the UPC Open link to the unit.

Can the BMS supply sensor values to the Carrier 38APS/38APD 025-130 Condensing Unit (ComfortLink, UPC Open BACnet option)?

Outside Air Temperature (AV 1003) and Space Temperature (AV 2007) are writable; the space temperature is used with the SPT control types.
