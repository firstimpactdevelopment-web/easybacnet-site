Short answer

On 48/50A rooftops the BACnet option is a UPC Open controller in its own enclosure below the main control box. It speaks BACnet MS/TP to the BMS and CCN to the unit's ComfortLink board. The list has 156 AVs and BVs: setpoints, air temperatures and pressures, compressor and heat relays, economizer and VFD outputs, thermostat inputs, demand limit, alarms and 40 user-defined spare values.

This page lists 156 BACnet objects for the Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option) — 85 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Carrier’s own free documentation, linked below.

BMS integration notes: Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option)

Integration in brief

The BMS talks BACnet MS/TP to the UPC Open, which reads and writes the 48/50A ComfortLink control over CCN. Set the CCN schedule number for the occupancy source you want, then write occupancy, setpoints and (for VAV) the supply air setpoint; read HVAC mode, temperatures and alarm state. Values the BMS feeds in (space, return or outdoor temperature, RH, CO2) are forces that clear if not refreshed.

Enable & remote start

Occupancy follows the ComfortLink CCN schedule number (Configuration > CCN > SC.OV > SCH.N): 0 = always occupied, 1 = local schedule (default), 65-99 = a CCN/global schedule. The points list makes Occupied? (BV:2008) writable, but the manual does not describe how a write interacts with SCH.N; test it on site. A remote switch input (RM.CF) can also set occupancy or start/stop the unit.

Heartbeat & communication loss

The manual says forces at CCN priority 7 clear unless rewritten in time: outside air temperature, outside RH, outside air quality and static pressure reset after 30 minutes, return air and space temperature after 3 minutes.

Sensors & values from the BMS

Space Temperature (AV:137), Return Air Temperature (AV:135), Outside Air Temperature (AV:1003), Outside Air RH (AV:119), IAQ (AV:1009) and OAQ (AV:113) are writable. Refresh them within the force timeouts (3 min for space and return temperature, 30 min for outdoor values).

Network setup

  • Set the MAC address on the UPC Open's Tens and Ones rotary switches; the controller reads switches, DIP switches and jumpers only at power-up.
  • Device instance = network number (default 16101) followed by the MAC address, e.g. MAC 20 gives 1610120.
  • BAS port: DS3 enable, DS4 E1-485, DS5-DS8 set to MSTP; baud on DS1-DS2 (9600, 19.2k, 38.4k or 76.8k, Carrier default 76.8k); 8N1 fixed. EIA-485 jumpers to EIA-485 and 2W.
  • Fit a BT485 terminator on the first and last controller of the MS/TP segment.
  • The UPC Open and the ComfortLink board must use the same CCN element and bus numbers (factory 1 and 0); the CCN side stays at 9600 baud.

Watch out for

  • Points depend on unit options (heat type, economizer, Humidi-MiZer, VFDs, expansion boards); objects for options not fitted carry no useful data.
  • Thermostat inputs (Y1, Y2, W1, W2, G) are writable BVs, but the thermostat control types are C.TYP 3 and 4.
  • The 20 user-defined analog and 20 binary values are spare objects with no unit function.

Integration notes

  • Object names end in _1. The 48/50A table has no CCN point name or default value columns.
  • Ranges are added to descriptions as printed. Units printed as °^F are shown as Δ°F (temperature differences).
  • Heating Supply Air Setpt (AV:3008) is printed with 'no unit'.
  • Two rows are both named Current Running Capacity: cool_capacity_1 (AV:1023) and htsg_cap_1 (AV:44, heating).
  • The 48/50P list (48-50P-15T) uses the same layout but differs in several objects (e.g. compressor A3/B3, CFM values, comm-loss alarm BV:105 instead of BV:15, user binaries at BV:2951+), so it is a separate entry.
  • This is ComfortLink + UPC Open, not the SystemVu or SmartVu controls used on other Carrier rooftops.

Questions about the Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option)

How many BACnet points does the Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option) have?

This list has 156 BACnet objects: 96 analog values, 60 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option) BACnet points are writable?

85 of the 156 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option)?

Start with BV 2008 occ_status_1 (Occupied? (0 = no, 1 = yes); writable); AV 3001 occ_cl_stpt_1 (Occupied cooling setpoint); AV 3002 occ_ht_stpt_1 (Occupied heating setpoint); AV 3007 sa_temp_stpt_1 (Supply air setpoint (VAV units)); AV 1022 hvac_mode_1 (HVAC mode as a number); BV 94 sfan_rly_1 (Supply fan relay on/off); AV 43 ctrltemp_1 (Control temperature (RAT, SPT or zone)); AV 10 sat_1 (Supply air temperature leaving the fan); BV 9 alm_1 (Unit alarm state); BV 15 comm_lost_alm_1 (UPC lost CCN communication with the unit).

How do I enable BMS control of the Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option)?

Occupancy follows the ComfortLink CCN schedule number (Configuration > CCN > SC.OV > SCH.N): 0 = always occupied, 1 = local schedule (default), 65-99 = a CCN/global schedule. The points list makes Occupied? (BV:2008) writable, but the manual does not describe how a write interacts with SCH.N; test it on site. A remote switch input (RM.CF) can also set occupancy or start/stop the unit.

Does the Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option) need a BACnet heartbeat or have a communication timeout?

The manual says forces at CCN priority 7 clear unless rewritten in time: outside air temperature, outside RH, outside air quality and static pressure reset after 30 minutes, return air and space temperature after 3 minutes.

Can the BMS supply sensor values to the Carrier WeatherMaker 48/50A Rooftop (ComfortLink, UPC Open BACnet option)?

Space Temperature (AV:137), Return Air Temperature (AV:135), Outside Air Temperature (AV:1003), Outside Air RH (AV:119), IAQ (AV:1009) and OAQ (AV:113) are writable. Refresh them within the force timeouts (3 min for space and return temperature, 30 min for outdoor values).
