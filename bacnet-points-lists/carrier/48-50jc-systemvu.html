BMS integration notes: Carrier 48/50JC 04-06 Rooftop (SystemVu)

Integration in brief

The SystemVu control has one RS-485 BMS port. Set BAS Protocol to BACnet on the unit display (Settings > Network Settings), set the MAC address and baud rate, power-cycle and connect to the MS/TP trunk. Run occupancy from a BACnet schedule or the BMS Occupancy Request point, write the occupied setpoints, and read the system mode, temperatures and the active fault count.

Enable & remote start

Set BAS Protocol Select to BACnet on the unit display (Settings > Network Settings > BAS Protocol; default None). With BACnet selected the local occupancy schedule is reset and scheduling comes from the BACnet side: a BACnet schedule, or the BMS Occupancy Request (MV 12; the display tables list Unocc, Occupied and Disabled). Unit Control Type (MV 2) decides whether the unit runs from thermostat inputs or a space sensor.

Heartbeat & communication loss

Network Input Timeout (AV 9089, default 30 min per the display tables) applies to the network input values. The guide does not say what the unit does when it expires, so keep any written network value refreshed well inside that time.

Sensors & values from the BMS

Writable network inputs exist for space temperature (Network Space Temp Value, AV 7006), outdoor air temperature (AV 7007), return air temperature (AV 7005), space RH (AV 376), outdoor RH (AV 7003), IAQ and OAQ CO2 (AV 7001, AV 7002) and OA cfm (AV 371). The guide doesn't explain how the unit picks a network value over a local sensor; check the sensor channel settings on the display. The 'BACnet device for ...' and 'Object instance for ...' AVs let the unit read a sensor from another BACnet device.

Network setup

  • BACnet MS/TP only, on the single RS-485 BMS port that is also used for CCN. Defaults: MAC address 01, baud 76800 (BACNET BAUDRATE 4).
  • i-Vu auto ID: with the auto ID scheme on, set the MAC and the device ID becomes the network number plus the MAC. With it off, set the MAC and write the device ID over BACnet; the controller keeps it.
  • To set the device ID by hand, set BACnet ID to manual on the display and enter it there. The MAC range for each mode is in the guide's BACnet settings table.
  • Power the controller down after changing the BACnet settings, then connect it to the MS/TP network.

Watch out for

  • Instances are not sequential (AV 9089, BV 7048, MV 2002 and so on); map by instance, not by position in the table.
  • Many configuration MVs and AVs are option codes or sensor channel numbers; read the current value and check the display before writing.
  • The guide gives only a numeric range for MV 12 and the other multistates; confirm the state numbering on the unit before writing.
  • BV 7048 shows the alarm relay; which alerts drive the relay is set under Unit Configurations > Alarm Relay.

Questions about the Carrier 48/50JC 04-06 Rooftop (SystemVu)

How many BACnet points does the Carrier 48/50JC 04-06 Rooftop (SystemVu) have?

This list has 722 BACnet objects: 426 analog values, 233 binary values, 63 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier 48/50JC 04-06 Rooftop (SystemVu) BACnet points are writable?

487 of the 722 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier 48/50JC 04-06 Rooftop (SystemVu) BACnet documentation?

The source is 48/50JC 04-06 Ultra High Efficiency Single Package Rooftop Units with SystemVu Controls Version 4.X, Controls, Start-Up, Operation and Troubleshooting (Appendix E: BACnet Points List) (48-50JC-4-6-05T), revision 2025-07, published free by Carrier at https://brandportal.carrier.com/asset/649f4f97-c004-4502-b520-8344d32ee884/48-50JC-4-6-05T.pdf.

What are the minimum BACnet points to integrate the Carrier 48/50JC 04-06 Rooftop (SystemVu)?

Start with MV 12 bms_occ (Occupancy request from the BMS (unocc / occupied / disabled)); AV 288 ocsp (Occupied cooling setpoint); AV 289 ohsp (Occupied heating setpoint); BV 33 alarm_reset (Resets all current alarms); MV 2002 sys_mode (Current mode (off, cool, heat, vent, test)); AV 35 req_fan_spd (Indoor fan speed the control is calling for, %); AV 296 space_t (Space temperature); AV 1008 sa_temp (Supply air temperature); BV 7048 equip_alarm (Alarm output relay state); AV 335 num_active_faults (Count of active faults).

How do I enable BMS control of the Carrier 48/50JC 04-06 Rooftop (SystemVu)?

Set BAS Protocol Select to BACnet on the unit display (Settings > Network Settings > BAS Protocol; default None). With BACnet selected the local occupancy schedule is reset and scheduling comes from the BACnet side: a BACnet schedule, or the BMS Occupancy Request (MV 12; the display tables list Unocc, Occupied and Disabled). Unit Control Type (MV 2) decides whether the unit runs from thermostat inputs or a space sensor.

Does the Carrier 48/50JC 04-06 Rooftop (SystemVu) need a BACnet heartbeat or have a communication timeout?

Network Input Timeout (AV 9089, default 30 min per the display tables) applies to the network input values. The guide does not say what the unit does when it expires, so keep any written network value refreshed well inside that time.

Can the BMS supply sensor values to the Carrier 48/50JC 04-06 Rooftop (SystemVu)?

Writable network inputs exist for space temperature (Network Space Temp Value, AV 7006), outdoor air temperature (AV 7007), return air temperature (AV 7005), space RH (AV 376), outdoor RH (AV 7003), IAQ and OAQ CO2 (AV 7001, AV 7002) and OA cfm (AV 371).
