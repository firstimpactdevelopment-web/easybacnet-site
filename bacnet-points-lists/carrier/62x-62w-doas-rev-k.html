Short answer

62X and 62W dedicated outdoor air units with Revision K controls use an Automated Logic LS-1628u controller that speaks BACnet MS/TP on its RS-485 ports and BACnet IP on its Gig-E port. The Table C mapping lists 248 AVs, BVs and two MSVs: occupancy and BAS heartbeat points, supply air, zone and dehumidification setpoints, sensor readings, compressor, fan, wheel and damper status, PID override points and many individual alarms. The 62X and 62W manuals print the same table.

BMS integration notes: Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls)

Integration in brief

The 62X/62W uses an Automated Logic LS-1628u controller (third-party to i-Vu). Set Occupancy Control Options to BAS, then command occupancy with BAS Manual Occ Control and toggle Field BAS Comm. Status faster than the BAS lost delay. Write the supply air setpoints the unit discharges to, read operating mode, occupancy, SAT and the alarm status.

Enable & remote start

Occupancy Control (Occupancy Control Options, MSV 101) chooses BAS control, local schedule, 24/7 or CO2. With BAS control, BAS Manual Occ Control (BV 101) puts the unit in occupied or unoccupied mode. Enable Unit Operation (Tech Set Up) must be on. Emergency Shutdown in Tech Set Up disables the unit; Emerg. Shutdown Enable (BV 821) is writable over BACnet.

Heartbeat & communication loss

Field BAS Comm. Status (BV 110) must change state before the BAS Comm. Lost Delay (AV 103, default 60 s) runs out, or BAS Communication Lost (BV 107) and the BAS LOST alarm (BV 899) are set. Enable BAS Monitor Schedule (BV 106) lets the unit fall back to its local schedule on a loss. The manual does not describe the OAT/OARH loss action beyond its status point (BV 1102).

Sensors & values from the BMS

The BAS can write zone temperature (ZAT From BAS, AV 208), zone RH (AV 211), CO2 (AV 213), outdoor temperature (AV 1104) and outdoor RH (AV 1106). BAS outdoor values are monitored when Enable BAS Mon OAT/OARH (BV 1100) is on; Local OAT/OARH Sensor Enabled (BV 1115) selects the unit's own sensors.

Network setup

  • BACnet device instance defaults to 1602; with Auto Generate Device ID = Yes, the rotary switch address is added to 1602. Set it on the Equipment Touch (BAS Set Up > Communication).
  • MS/TP on Port S1 (Port S1 rotary switch = 1) or Port S2; MAC 0-127 on the three rotary switches; baud default 76.8k or autobaud.
  • BACnet IP or BACnet Ethernet on the Gig-E port; IP by DHCP, custom static, or default 192.168.168.x from the rotary switches.
  • Set the port's End of Net? switch to Yes at either end of an MS/TP segment.
  • Service port web pages at http://169.254.1.1 (laptop 169.254.1.2-7, mask 255.255.255.248).

Watch out for

  • BAS Manual Occ Control only works when Occupancy Control is set to BAS control.
  • The PID Output Override and Override Lock points (SF, EF, OADA, heat, HGRH) fix outputs for CAV setups; don't write them for normal control.
  • Operating mode and condition are integer AVs; see the Appendix B code lists in the notes.
  • To use the unit with Carrier i-Vu Open it needs an i-Vu Link and i-Vu Open Plus.

Questions about the Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls)

How many BACnet points does the Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls) have?

This list has 248 BACnet objects: 110 analog values, 136 binary values, 2 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls) BACnet points are writable?

84 of the 248 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls) BACnet documentation?

The source is 62X 03-55 Tons Revision K Controls Dedicated Outdoor Air Unit - Controls, Operation, Start-Up and Troubleshooting (Appendix A, Table C: Mapping Points - Carrier 62X Rev. K - 100% Outdoor Air) (62X-6T), revision 4-26, published free by Carrier at https://brandportal.carrier.com/asset/aed21172-6c56-4004-b609-dceb606c3ca2/62X-6T.pdf.

What are the minimum BACnet points to integrate the Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls)?

Start with BV 101 occ_en (BAS occupied/unoccupied command); MV 101 occ_ctrl_opts (Must be BAS for BAS occupancy control); AV 313 clg_sat_sp_o (Occupied cooling supply air setpoint); AV 354 htg_sat_sp_o (Occupied heating supply air setpoint); BV 110 bas_comm_status (Heartbeat: toggle before the BAS lost delay ends); BV 900 alarm_reset (Alarm reset); AV 112 op_mode (Operating mode code (Appendix B)); BV 105 occ_status (Occupied/unoccupied status); AV 235 sat_stat (Supply air temperature); BV 851 alarm_status (Unit alarm status).

How do I enable BMS control of the Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls)?

Occupancy Control (Occupancy Control Options, MSV 101) chooses BAS control, local schedule, 24/7 or CO2. With BAS control, BAS Manual Occ Control (BV 101) puts the unit in occupied or unoccupied mode. Enable Unit Operation (Tech Set Up) must be on. Emergency Shutdown in Tech Set Up disables the unit; Emerg. Shutdown Enable (BV 821) is writable over BACnet.

Does the Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls) need a BACnet heartbeat or have a communication timeout?

Field BAS Comm. Status (BV 110) must change state before the BAS Comm. Lost Delay (AV 103, default 60 s) runs out, or BAS Communication Lost (BV 107) and the BAS LOST alarm (BV 899) are set. Enable BAS Monitor Schedule (BV 106) lets the unit fall back to its local schedule on a loss. The manual does not describe the OAT/OARH loss action beyond its status point (BV 1102).

Can the BMS supply sensor values to the Carrier 62X / 62W Dedicated Outdoor Air Unit (Rev. K controls)?

The BAS can write zone temperature (ZAT From BAS, AV 208), zone RH (AV 211), CO2 (AV 213), outdoor temperature (AV 1104) and outdoor RH (AV 1106). BAS outdoor values are monitored when Enable BAS Mon OAT/OARH (BV 1100) is on; Local OAT/OARH Sensor Enabled (BV 1115) selects the unit's own sensors.
