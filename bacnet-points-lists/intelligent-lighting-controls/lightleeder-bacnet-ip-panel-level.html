Updated 12 November 2026

Short answer

Panel-level BACnet IP point map for a LightLEEDer lighting panel. Binary Outputs give status and control of 64 relays (on/off and on/blink), 48 relay groups (on/off and on/blink) and 48 presets; Analog Outputs read LightSync device inputs and photocells, set and read dimmer outputs, run motor outputs and disable individual LightSync devices.

BMS integration notes: Intelligent Lighting Controls LightLEEDer BACnet IP panel-level interface (SMD point map)

Integration in brief

Command relays (BO 1-64), groups (BO 129-176) or presets (BO 225-272) and read back their status from the same objects.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

ObjectNameWhyAccess
BO 1SMD_DO_00001Relay 1 status and on/offWrite
BO 129SMD_DO_00513Group 1 status and on/offWrite
BO 225SMD_DO_01025Preset 1 status and activationWrite
AO 4SMD_AO_40004Photocell level, 0-255Write

Watch out for

  • Each relay and group has two objects, on/off (BO 1-64, 129-176) and on/blink (BO 65-128, 177-224); map the one that matches the control you want.

Integration notes

  • The map prints types as DO and AO; they are listed here as Binary Output and Analog Output.
  • Several AOs work as an index/value pair: write the device number first (AO 1, 5, 15), then read or write the related values.
  • Motor control time is split over MSByte (AO 20-23) and LSByte (AO 24-27) objects.
  • Access is not printed; outputs are taken as writable (access inferred).

Questions about the Intelligent Lighting Controls LightLEEDer BACnet IP panel-level interface (SMD point map)

How many BACnet points does the Intelligent Lighting Controls LightLEEDer BACnet IP panel-level interface (SMD point map) have?

This list has 363 BACnet objects: 91 analog outputs, 272 binary outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Intelligent Lighting Controls LightLEEDer BACnet IP panel-level interface (SMD point map) BACnet points are writable?

363 of the 363 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Intelligent Lighting Controls LightLEEDer BACnet IP panel-level interface (SMD point map) BACnet documentation?

The source is LightLEEDer BACnet IP Panel Level Point Map (Rev. A), published free by Intelligent Lighting Controls at https://www.ilc-usa.com/sites/default/files/resources/pdf/LL_BACnet_IP_Panel_Level_Point_Map_0.pdf.

What are the minimum BACnet points to integrate the Intelligent Lighting Controls LightLEEDer BACnet IP panel-level interface (SMD point map)?

Start with BO 1 SMD_DO_00001 (Relay 1 status and on/off); BO 129 SMD_DO_00513 (Group 1 status and on/off); BO 225 SMD_DO_01025 (Preset 1 status and activation); AO 4 SMD_AO_40004 (Photocell level, 0-255).
