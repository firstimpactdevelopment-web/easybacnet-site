Short answer

The ILC Advanced BACnet/IP gateway exposes a LightLEEDer panel group: 64 network relay groups and 64 presets (BVs 1-128) plus a global scene AV, and for each of up to 64 panels a block of LightSync inputs (BI), relays and scenes (BV) and PC/dimmer/VDI and dimmer levels (AV). This list has the group block and the printed panel 01 block; other panels repeat it at +1000 per panel.

BMS integration notes: Intelligent Lighting Controls LightLEEDer / LL-EVO Advanced BACnet/IP Gateway

Integration in brief

Switch lighting through the relay group BVs (1-64) or presets (65-128); use the per-panel relay BVs and LightSync BIs for panel-level control and status.

Integration notes

  • Panel points repeat for every panel: object ID = panel number x 1000 + point (panel 01 = 1001-1128, panel 40 hex = 64001...). Only the printed panel 01 block is listed.
  • Names are printed with all four panel-group prefixes (PNL01/41/81/C1); on a real gateway the name carries the one hex panel number for the selected panel group.
  • Group and preset numbers likewise show four values (e.g. Group 001/065/129/193) for panel groups 1-4; the object IDs stay the same.
  • Access per the mapping: AV and BV read/write, BI read only.
  • The 132-page document prints all 64 panel blocks; they differ only in names and IDs.

Questions about the Intelligent Lighting Controls LightLEEDer / LL-EVO Advanced BACnet/IP Gateway

How many BACnet points does the Intelligent Lighting Controls LightLEEDer / LL-EVO Advanced BACnet/IP Gateway have?

This list has 361 BACnet objects: 37 analog values, 128 binary inputs, 196 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Intelligent Lighting Controls LightLEEDer / LL-EVO Advanced BACnet/IP Gateway BACnet points are writable?

233 of the 361 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Intelligent Lighting Controls LightLEEDer / LL-EVO Advanced BACnet/IP Gateway BACnet documentation?

The source is Intelligent Lighting Controls Vendor Protocol Mappings (Document Revision 1.D), revision 2020-07, published free by Intelligent Lighting Controls at https://www.ilc-usa.com/sites/default/files/resources/pdf/LLABG%20-%20Intelligent%20Lighting%20Controls%20Vendor%20Mappings.pdf.

What are the minimum BACnet points to integrate the Intelligent Lighting Controls LightLEEDer / LL-EVO Advanced BACnet/IP Gateway?

Start with BV 1 Group 001/065/129/193 (Relay group 1 on/off); BV 65 Preset 001/065/129/193 (Preset 1 activation); AV 1 Global Scene Control (Global scene command); BV 1001 PNL01/41/81/C1 Relay 01 (Panel 1 relay 1 on/off); BI 1001 PNL01/41/81/C1 LS Device 01 - Input 1 (Panel 1 LightSync input status).
