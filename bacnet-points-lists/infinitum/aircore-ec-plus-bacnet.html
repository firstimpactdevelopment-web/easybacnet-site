Infinitum Aircore EC+ BACnet MS/TP module BACnet points list

Updated 6 November 2026

Short answer

Aircore EC+ motors get BACnet MS/TP from a BTL-certified plug-in module on the motor's CIM (communication interface module) board. Each Modbus-style register is mirrored as one BACnet object: binary and analog outputs for run/stop, direction, speed command, operating limits, control-source and terminal settings, and analog and binary inputs for bus voltage and current, temperatures, actual speed and run state, I/O states, fault and warning words, motor identity, firmware and run-time counters.

BMS integration notes: Infinitum Aircore EC+ BACnet MS/TP module

Integration in brief

Set each motor's device instance and baud rate with Infinitum's NPU tool over the CIM board's micro-USB port, terminate the bus ends with the on-board DIP switch, then command BO 1 run/stop and AO 3 speed command. Read BI 74, AI 76, AI 63 and BI 86/AI 90, and clear faults with BO 88.

Enable & remote start

The list includes source selectors for speed (AO 21 Speed Source), run/stop (AO 22 Run/Stop Source), direction (AO 23) and fault clearing (AO 24); this manual doesn't give their values, so set them per the Aircore EC+ IOM manual before commanding over BACnet MS/TP.

Network setup

  • Device instance and baud rate are set with the Infinitum NPU tool (NPU.exe) over a USB to micro-USB cable to the CIM board; don't change the MAC address.
  • Baud rates 9600 to 115200 bit/s; up to 32 devices per segment, 1000 m maximum cable.
  • A DIP switch on the CIM board connects a 120 ohm terminating resistor; use it at each end of the bus.
  • RS-485 is on the CIM terminal strip, shared with Modbus RTU.
  • BACnet is a factory option (catalog VFD/I-O code B); Infinitum service can add the module in the field.

Watch out for

  • Operating limits, sources and terminal settings (AO 4-59) are configuration; write them only when needed, not cyclically.
  • AO 125 Parameter Save stores parameters; use it only after deliberate changes.
  • The manual gives no units; check speed and current scaling on a live motor.
  • The BACnet module can be damaged if fitted the wrong way round on the CIM board.

Integration notes

  • Object list from section 9 of the manual (pages 7-9). Object names here are the 'BACnet point name' column (16 characters max); the descriptions give the register name and number.
  • The manual's 'BACnet object name' column groups the points (Motor Control, Oper Limits, Operation Type, Fault Reset, Term Setting, Monitor Env, Monitor Temp, Actual, Faults, Parameters, Motor ID, Runtime, Parameter Save).
  • The manual gives no access or units column: outputs are listed as commandable and inputs as read-only from the object type.
  • Some point names are printed as placeholders (dummy1-dummy4 on AI 25, AI 26, AI 35, AI 36), and the skip-speed point names (AO 10-13) differ from their register names; all are kept as printed.
  • A PICS is attached as an appendix image in the manual.

Questions about the Infinitum Aircore EC+ BACnet MS/TP module

How many BACnet points does the Infinitum Aircore EC+ BACnet MS/TP module have?

This list has 125 BACnet objects: 63 analog inputs, 45 analog outputs, 10 binary inputs, 7 binary outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Infinitum Aircore EC+ BACnet MS/TP module BACnet points are writable?

52 of the 125 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Infinitum Aircore EC+ BACnet MS/TP module BACnet documentation?

The source is Aircore EC+ BACnet User Manual (BACnet Version 1.4, Release Gen4), revision October 2025, published free by Infinitum at https://support.goinfinitum.com/hc/en-us/article_attachments/52467145317907.

What are the minimum BACnet points to integrate the Infinitum Aircore EC+ BACnet MS/TP module?

Start with BO 1 Run/Stop Cmd (Run/stop command); AO 3 Speed Command (Speed command from the BMS); BO 88 Clear Faults (Clears active faults); BI 74 Run/Stop Actual (Actual run state); AI 76 Speed Actual (Actual motor speed); AI 63 Avg Current (Average motor current); BI 86 Active Faults (Any active fault); AI 90 Fault Word (Bit-coded fault word).

How do I enable BMS control of the Infinitum Aircore EC+ BACnet MS/TP module?

The list includes source selectors for speed (AO 21 Speed Source), run/stop (AO 22 Run/Stop Source), direction (AO 23) and fault clearing (AO 24); this manual doesn't give their values, so set them per the Aircore EC+ IOM manual before commanding over BACnet MS/TP.

How do I check these points on the real Aircore EC+ BACnet MS/TP module?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
