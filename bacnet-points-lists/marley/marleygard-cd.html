Short answer

The MarleyGard CD is a cooling-tower water treatment controller. It is a BACnet IP device that reports conductivity, pH, ORP, temperatures, water and flow meter totals, flow rates and 4-20 mA inputs for up to four systems, the setpoints and alarm limits, relay states and a large set of alarm flags. Every object in this list is read-only.

BMS integration notes: Marley MarleyGard CD controller (BACnet)

Integration in brief

Treat the MarleyGard CD as a monitoring device: read the chemistry inputs (conductivity, pH, ORP) and the flow switch for each system in use, and map the per-system All Alarms flags (BV 11, 80, 149, 218) as summary alarms.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

ObjectNameWhyAccess
AI 0AI-000System 1 conductivityRead
AI 8AI-008System 1 pHRead
AI 12AI-012System 1 ORPRead
BI 0BI-000System 1 flow switchRead
BV 11BV-011System 1: any active alarmRead

Network setup

  • BACnet IP only (Annex J), on the same Ethernet port used for the WebAdvantage service.
  • Set the device instance in Configure > Network settings > BAC (some versions show DEV); 4194303 means unconfigured. The UDP port (47808) is set on the same screen.
  • The BMS must be on the same subnet as the controller, or routing must be set up for BACnet traffic.
  • Protocol revision 5, B-ASC; ReadProperty only (DS-RP-B).

Watch out for

  • All objects are read-only in this edition; setpoints and limits cannot be changed from the BMS.
  • ReadProperty only: no ReadPropertyMultiple or COV, so poll at a modest rate.
  • BV 93-133 are missing from the published list.

This older edition lists fewer objects and marks every one read-only.
  • The published PDF repeats page 8 as page 9 and does not print BV 93-133; those objects are not listed here.
  • No engineering units or relay state texts are given; values follow the units configured in the controller.
  • Most points repeat for System #1 to #4 whether or not those systems are installed.
