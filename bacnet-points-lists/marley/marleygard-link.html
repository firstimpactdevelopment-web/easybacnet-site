Short answer

The MarleyGard LINK is an add-on enclosure with a Contemporary Controls BAScontrol22C I/O module that turns status contacts and 4-20 mA signals from a Marley tower control panel into BACnet/IP objects. It is a monitoring interface: inputs cover vibration, gearbox oil level, basin level and temperature, makeup water, basin heater, and on CoolBoost fluid coolers the spray pumps and dampers. Marley VFDs with a LINK interface connect over Ethernet separately.

BMS integration notes: Marley MarleyGard LINK BACnet/IP Panel

Integration in brief

Plug the BMS into the LINK panel's RJ45 port, browse to the module (default 192.168.92.68), set the IP settings and a unique BACnet device instance and name, then discover and read the inputs. The panel only monitors; start/stop and speed stay with the Marley control panel or VFD.

Network setup

  • Default IP address 192.168.92.68; the web pages need a login (default credentials are in the manual - change them).
  • Choose DHCP or a static IP with mask, gateway and DNS on the System Configuration page.
  • Enter a BACnet Device Instance and Device Object Name that are unique across the whole internetwork.
  • Each LINK panel carries the cooling tower order number on the inside of the door; quote it for support.

Watch out for

  • The web page can force point values for testing; forced values stay until unchecked or the module is power-cycled.
  • CoolBoost panels have two I/O modules (two BACnet devices) with overlapping BI numbers.
  • Points are pre-programmed per project, so confirm the live object list against the job submittal.

Integration notes

  • This is Marley's 'typical' input assignment; the module is programmed per job, so the actual points vary.
  • CoolBoost fluid cooler panels use a second I/O module (Module 2), a separate BACnet device whose instances overlap Module 1's.
  • AI 8 VIB_LVL_XMTR is listed twice in the guide (panel- or switch-powered transmitter); it is one object.
  • Binary inputs use normally open field contacts unless noted.
  • The table has no access column; all objects are inputs and are marked read-only.

Questions about the Marley MarleyGard LINK BACnet/IP Panel

How many BACnet points does the Marley MarleyGard LINK BACnet/IP Panel have?

This list has 24 BACnet objects: 3 analog inputs, 21 binary inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Marley MarleyGard LINK BACnet/IP Panel BACnet points are writable?

None of the listed objects are marked writable in the source documentation. The source has no read/write column, so this is inferred from object type.

Where is the official Marley MarleyGard LINK BACnet/IP Panel BACnet documentation?

The source is MarleyGard LINK BACnet/IP Communication Panel - User Manual (Installation - Operation) (Z1126362), revision 2020-09, published free by Marley at https://spxcooling.com/wp-content/uploads/Z1126362.pdf.

What are the minimum BACnet points to integrate the Marley MarleyGard LINK BACnet/IP Panel?

Start with BI 12 VIB_SW_TRIP (High-vibration shutdown); BI 10 OIL_LVL_ALM (Gearbox low oil); AI 6 WATER_TEMP_CWB (Basin (cold water) temperature); BI 3 WATER_LOW_ALM (Basin low water); BI 5 WATER_HIGH_ALM (Basin high water); BI 1 BASIN_HEATER_FAIL (Basin heater failure).

How do I check these points on the real MarleyGard LINK BACnet/IP Panel?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
