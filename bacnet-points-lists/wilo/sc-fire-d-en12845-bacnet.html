Short answer

Wilo's SC-family switch boxes control multi-pump systems and act as a BACnet MS/TP slave on their RS-485 port; BACnet IP needs an added gateway in the panel. The SC Fire D EN12845 list covers the operating command, fire-pump switch states, battery/engine or mains values and fire error bits. Fieldbus write access is governed by a bus command timer that must be refreshed every five minutes.

BMS integration notes: Wilo SC Fire D EN12845 (BACnet MS/TP / IP)

Integration in brief

Read the switch states (pump running, sprinkler request, standby) and the fire error bits for monitoring. Drives on/off (BO 224) switches automatic operation; for any fieldbus write, first write Set to the Bus command timer (MO 208) and repeat it within five minutes. Acknowledge alarms with BO 1985.

Enable & remote start

The Bus command timer (MO 208) decides who may change settings. Manual: HMI and fieldbus both write, last value wins. Off: HMI locked, fieldbus only. Set: HMI locked and a 5-minute timer starts (state reads Active).

Heartbeat & communication loss

With the Bus command timer in Set mode, Set must be written again at least every five minutes. If it lapses the state changes to Reset, the HMI gets access back and the fieldbus is locked until Set is written again.

Network setup

  • SC menus 5.1.2.1-5.1.2.5 set the BACnet MS/TP baud rate, bus address (MAC), parity, stop bits and device object ID.
  • BACnet IP uses an extra gateway (HD67686) wired to the panel's RS-485 port: set the SC to 38400 baud, MAC 5, no parity, 1 stop bit. The gateway defaults to 192.168.0.10, UDP 47808, no DHCP; change it with the free Compositor SW67686 tool.
  • Terminate the first and last node of the MS/TP segment (DIP switch or jumper, per panel hardware).
  • SC-Fire needs the extra communication PCB (art. no. 2543170) on the SC board; RS-485 is on terminal X8 (pins 73/74).

Watch out for

  • In Bus command timer Off mode the HMI stays locked; if the fieldbus fails there is no access until it recovers.
  • Alarm history: write the index (0-15 on SC) to AO 1990, then read the error code from AI 1995.

Integration notes

  • Taken from the 'SC Fire D EN12845' table in Wilo's SC BACnet supplement (English part, pp91-92). Wilo prints a 'BACnet ID' and an object type with its BACnet type code in brackets, e.g. 'Analog Input (0)'. The ID is used here as the instance and the type follows the code, so rows printed 'Binary Input (4)' are Binary Outputs.
  • Where Wilo prints several IDs against one name (pump state, switch box state, error state and other bitmaps), each ID is its own binary object for the element printed beside it; the element is shown in brackets after the name.
  • Analog objects that list several units report in the unit of the active control mode.
  • Wilo prints 'Error state' and 'FC state' rows with no BACnet IDs or elements in this table; they are left out.
  • The E, D and ED suffixes in the switch-state and fire-error names mark electric, diesel or both variants, as printed.

Questions about the Wilo SC Fire D EN12845 (BACnet MS/TP / IP)

How many BACnet points does the Wilo SC Fire D EN12845 (BACnet MS/TP / IP) have?

This list has 62 BACnet objects: 21 analog inputs, 2 analog outputs, 34 binary inputs, 3 binary outputs, 1 multi-state input, 1 multi-state output. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Wilo SC Fire D EN12845 (BACnet MS/TP / IP) BACnet points are writable?

6 of the 62 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
