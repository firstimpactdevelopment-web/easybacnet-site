Short answer

Wilo's SC-family switch boxes control multi-pump systems and act as a BACnet MS/TP slave on their RS-485 port; BACnet IP needs an added gateway in the panel. The SC Clean list covers the operating command, pump and valve modes and states, running hours and error bits. BMS integration notes: Wilo SC Clean (BACnet MS/TP / IP)

Integration in brief

Map Drives on/off (BO 224) as the start/stop command and the active setpoint (AO 416) as the setpoint. For fieldbus control, write Set to the Bus command timer (MO 208) and repeat it within five minutes. Read the collective run and fault signals (BI 976/977) and the Error state bits for alarms; acknowledge with BO 1985.

Enable & remote start

The Bus command timer (MO 208) decides who may change settings. Manual: HMI and fieldbus both write, last value wins. Off: HMI locked, fieldbus only. Set: HMI locked and a 5-minute timer starts (state reads Active).

Heartbeat & communication loss

With the Bus command timer in Set mode, Set must be written again at least every five minutes. If it lapses the state changes to Reset, the HMI gets access back and the fieldbus is locked until Set is written again.

Network setup

  • SC menus 5.1.2.1-5.1.2.5 set the BACnet MS/TP baud rate, bus address (MAC), parity, stop bits and device object ID.
  • BACnet IP uses an extra gateway (HD67686) wired to the panel's RS-485 port: set the SC to 38400 baud, MAC 5, no parity, 1 stop bit. The gateway defaults to 192.168.0.10, UDP 47808, no DHCP; change it with the free Compositor SW67686 tool.
  • Terminate the first and last node of the MS/TP segment (DIP switch or jumper, per panel hardware).

Watch out for

  • In Bus command timer Off mode the HMI stays locked; if the fieldbus fails there is no access until it recovers.
  • Alarm history: write the index (0-15 on SC) to AO 1990, then read the error code from AI 1995.

Integration notes

  • Taken from the 'SC Clean' table in Wilo's SC BACnet supplement (English part, pp88-89). Wilo prints a 'BACnet ID' and an object type with its BACnet type code in brackets, e.g. 'Analog Input (0)'. The ID is used here as the instance and the type follows the code, so rows printed 'Binary Input (4)' are Binary Outputs.
  • Where Wilo prints several IDs against one name (pump state, switch box state, error state and other bitmaps), each ID is its own binary object for the element printed beside it; the element is shown in brackets after the name.
  • Analog objects that list several units report in the unit of the active control mode.

Questions about the Wilo SC Clean (BACnet MS/TP / IP)

How many BACnet points does the Wilo SC Clean (BACnet MS/TP / IP) have?

This list has 41 BACnet objects: 13 analog inputs, 3 analog outputs, 15 binary inputs, 3 binary outputs, 3 multi-state inputs, 4 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Wilo SC Clean (BACnet MS/TP / IP) BACnet points are writable?

10 of the 41 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Wilo SC Clean (BACnet MS/TP / IP) BACnet documentation?

The source is BACnet - supplemental sheet SC manual (SC System): System-specific data-point list BACnet SC (wilo110041 (OPTION BACnet SC 2539869 Ed. 06)), revision 2020-07-10 (list 31.200), published free by Wilo at https://cms.media.wilo.com/cdndoc/wilo110041/4721760/wilo110041.pdf.

What are the minimum BACnet points to integrate the Wilo SC Clean (BACnet MS/TP / IP)?

Start with BO 224 Drives on/off (Automatic operation and all pumps on/off); AO 416 Active setpoint value (Active setpoint of the automatic control); MO 208 Bus command timer (Write Set (3) at least every 5 min to keep control); BO 1985 Acknowledge (Alarm acknowledge); BI 976 Switch box state (SBM) (Collective run signal); AI 400 Current value (Measured value; unit follows the control mode); BI 977 Switch box state (SSM) (Collective fault signal).

How do I enable BMS control of the Wilo SC Clean (BACnet MS/TP / IP)?

The Bus command timer (MO 208) decides who may change settings. Manual: HMI and fieldbus both write, last value wins. Off: HMI locked, fieldbus only. Set: HMI locked and a 5-minute timer starts (state reads Active).

Does the Wilo SC Clean (BACnet MS/TP / IP) need a BACnet heartbeat or have a communication timeout?

With the Bus command timer in Set mode, Set must be written again at least every five minutes. If it lapses the state changes to Reset, the HMI gets access back and the fieldbus is locked until Set is written again.
