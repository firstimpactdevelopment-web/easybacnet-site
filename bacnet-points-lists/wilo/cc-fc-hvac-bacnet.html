BMS integration notes: Wilo CC...FC HVAC (BACnet IP / MS/TP)

Integration in brief

Map Drives on/off (BV 224) as the start/stop command and Set point 1 (AV 1072) as the setpoint. For fieldbus control, write Set to the Bus command timer (MV 208) and repeat it within five minutes. Read the collective run and fault signals (BV 976/977) and the Error state bits for alarms; acknowledge with BV 1985.

Enable & remote start

The Bus command timer (MV 208) decides who may change settings. Manual: HMI and fieldbus both write, last value wins. Off: HMI locked, fieldbus only. Set: HMI locked and a 5-minute timer starts (state reads Active).

Heartbeat & communication loss

With the Bus command timer in Set mode, Set must be written again at least every five minutes. If it lapses the state changes to Reset, the HMI gets access back and the fieldbus is locked until Set is written again.

Network setup

  • Menu 4.3.8.3 sets the BACnet device name (default WILO CC BAC) and device object ID (0-4194303, default 22).
  • BACnet IP module: default IP 192.168.0.5, mask 255.255.255.0, gateway 0.0.0.0.
  • BACnet MS/TP module: baud 9600, 19.2k, 38.4k or 76.8k; node address 0-127 (default 2); max master default 10; max info frames 1-127.
  • The BACnet extension needs a switch box software update by Wilo service.

Watch out for

  • In Bus command timer Off mode the HMI stays locked; if the fieldbus fails there is no access until it recovers.
  • Active setpoint value (AV 416) is read-only in dp-v and dT-v control modes.
  • Alarm history: write the index to AV 1990, then read the code, year, month/day and time objects. Month/day and time are packed (value mod 100 and value / 100).

Integration notes

  • Taken from the CC...FC HVAC table in Wilo's CC BACnet supplement (English part, pp72-75). Wilo prints a 'BACnet ID' beside an explicit object type (AV, BV, MSV); the ID is used here as the object instance. The doc never says 'instance' in words, so confirm one point on the device.
  • Where Wilo prints several IDs against one name (pump state, error state and other bitmaps), each ID is its own Binary Value for the element printed beside it; the element is shown in brackets after the name. Elements printed as '-' or '---' are unused and left out (2 here).
  • Analog values with several units listed (bar, m, K, °C, psi...) report in the unit of the active control mode.
  • The 'Added' column gives the list version each object appeared in (1.000, 31.000, 31.100); older switch box software may lack some objects.
  • System control (BV 1122-1127) holds Extern off, pump change, add/remove pump and the regulator source (analog or fieldbus); with fieldbus regulator operation the BMS writes the value in % to AV 1139.

Questions about the Wilo CC...FC HVAC (BACnet IP / MS/TP)

How many BACnet points does the Wilo CC...FC HVAC (BACnet IP / MS/TP) have?

This list has 149 BACnet objects: 56 analog values, 83 binary values, 10 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Wilo CC...FC HVAC (BACnet IP / MS/TP) BACnet points are writable?

26 of the 149 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Wilo CC...FC HVAC (BACnet IP / MS/TP) BACnet documentation?

What are the minimum BACnet points to integrate the Wilo CC...FC HVAC (BACnet IP / MS/TP)?

Start with BV 224 Drives on/off (Automatic operation and all pumps on/off); AV 1072 Set point 1 (Setpoint 1; unit follows the control mode); MV 208 Bus command timer (Write Set (3) at least every 5 min to keep control); BV 1985 Acknowledge (Alarm acknowledge); BV 976 Switch box state (SBM) (Collective run signal); AV 400 Current value (Measured value; unit follows the control mode); BV 977 Switch box state (SSM) (Collective fault signal).

How do I enable BMS control of the Wilo CC...FC HVAC (BACnet IP / MS/TP)?

The Bus command timer (MV 208) decides who may change settings. Manual: HMI and fieldbus both write, last value wins. Off: HMI locked, fieldbus only. Set: HMI locked and a 5-minute timer starts (state reads Active).

Does the Wilo CC...FC HVAC (BACnet IP / MS/TP) need a BACnet heartbeat or have a communication timeout?

With the Bus command timer in Set mode, Set must be written again at least every five minutes. If it lapses the state changes to Reset, the HMI gets access back and the fieldbus is locked until Set is written again.
