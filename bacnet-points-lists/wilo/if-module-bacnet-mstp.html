BMS integration notes: Wilo IF-Module BACnet / IF-Module BACnet Stratos (BACnet MS/TP)

Integration in brief

Write BO 0 Bus Command Pump on and AO 0 Bus Setpoint, choose the control mode with MO 0, and keep the Bus Command Timer (MO 1) active so the pump stays under bus control. Read BI 10 Pump is operating, speed, power and the warning/error status bits, with MI 1 for the current error code.

Enable & remote start

MO 1 Bus Command Timer decides who controls the pump: MANUAL (the relinquish default) lets the pump menu and the bus both write, last write wins; SET locks the local menu for the timeout; OFF blocks local operation permanently. Commands then follow a fixed priority: Ext. off input at the pump, Override off, Override max, Override min, Override on.

Heartbeat & communication loss

With MO 1 = SET the BMS must write SET again before the Bus Command Timer timeout (AO 8, default 300 s, module SW 2.00+). When it lapses the state goes to RESET: local operation is possible again and bus writes are blocked. Use SET_PRESET instead to load the preset values (AO 100, BO 100, MO 100, MO 101) on bus failure. MI 2 shows the timer state.

Network setup

  • The module is MS/TP master from module software 2.00; a MAC address of 128 or higher makes it an MS/TP slave. Baud rates 9600-115200.
  • The device instance is set with the pump menu parameters C, E and F (instance split as hex digits, per the IF-Module manual).

Watch out for

  • Some commandable outputs use a floating default: the module writes it virtually at priority 16, so relinquishing all priorities does not always return the static relinquish default.
  • At double pumps fit the IF-Module in the master pump and use the integrated double-pump management.

Questions about the Wilo IF-Module BACnet / IF-Module BACnet Stratos (BACnet MS/TP)

How many BACnet points does the Wilo IF-Module BACnet / IF-Module BACnet Stratos (BACnet MS/TP) have?

This list has 57 BACnet objects: 16 analog inputs, 10 analog outputs, 17 binary inputs, 5 binary outputs, 3 multi-state inputs, 6 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Wilo IF-Module BACnet / IF-Module BACnet Stratos (BACnet MS/TP) BACnet points are writable?

21 of the 57 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

How do I enable BMS control of the Wilo IF-Module BACnet / IF-Module BACnet Stratos (BACnet MS/TP)?

MO 1 Bus Command Timer decides who controls the pump: MANUAL (the relinquish default) lets the pump menu and the bus both write, last write wins; SET locks the local menu for the timeout; OFF blocks local operation permanently. Commands then follow a fixed priority: Ext. off input at the pump, Override off, Override max, Override min, Override on.

Does the Wilo IF-Module BACnet / IF-Module BACnet Stratos (BACnet MS/TP) need a BACnet heartbeat or have a communication timeout?

With MO 1 = SET the BMS must write SET again before the Bus Command Timer timeout (AO 8, default 300 s, module SW 2.00+). When it lapses the state goes to RESET: local operation is possible again and bus writes are blocked. Use SET_PRESET instead to load the preset values (AO 100, BO 100, MO 100, MO 101) on bus failure. MI 2 shows the timer state.
