Short answer

Wilo's CC-family switch boxes run multi-pump systems and connect to a BMS through a plug-in BACnet IP or BACnet MS/TP extension module, acting as a BACnet server. The CC Lift list covers on/off, water level setpoints, level sensors, pump modes, pump state bits, running hours, error bits and an alarm history. Fieldbus write access is governed by a bus command timer that must be refreshed every five minutes.

This page lists 190 BACnet objects for the Wilo CC Lift (BACnet IP / MS/TP) — 22 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Wilo’s own free documentation, linked below.

BMS integration notes: Wilo CC Lift (BACnet IP / MS/TP)

Integration in brief

Map Drives on/off (BV 224) as the start/stop command and the water level setpoints (AV 1318-1337) if the BMS should adjust them. For fieldbus control, write Set to the Bus command timer (MV 208) and repeat it within five minutes. Read the collective run and fault signals (BV 976/977) and the Error state bits for alarms; acknowledge with BV 1985.

Enable & remote start

The Bus command timer (MV 208) decides who may change settings. Manual: HMI and fieldbus both write, last value wins. Off: HMI locked, fieldbus only. Set: HMI locked and a 5-minute timer starts (state reads Active).

Heartbeat & communication loss

With the Bus command timer in Set mode, Set must be written again at least every five minutes. If it lapses the state changes to Reset, the HMI gets access back and the fieldbus is locked until Set is written again.

Network setup

  • Menu 4.3.8.3 sets the BACnet device name (default WILO CC BAC) and device object ID (0-4194303, default 22).
  • BACnet IP module: default IP 192.168.0.5, mask 255.255.255.0, gateway 0.0.0.0.
  • BACnet MS/TP module: baud 9600, 19.2k, 38.4k or 76.8k; node address 0-127 (default 2); max master default 10; max info frames 1-127.
  • The BACnet extension needs a switch box software update by Wilo service.

Watch out for

  • In Bus command timer Off mode the HMI stays locked; if the fieldbus fails there is no access until it recovers.
  • Active setpoint value (AV 416) is read-only in dp-v and dT-v control modes.
  • Alarm history: write the index to AV 1990, then read the code, year, month/day and time objects. Month/day and time are packed (value mod 100 and value / 100).
  • AV 137 ('Cycles float switches P2 on') is probably 1437; the doc prints 137.

Integration notes

  • Taken from the CC Lift table in Wilo's CC BACnet supplement (English part, pp76-80). Wilo prints a 'BACnet ID' beside an explicit object type (AV, BV, MSV); the ID is used here as the object instance. The doc never says 'instance' in words, so confirm one point on the device.
  • Where Wilo prints several IDs against one name (pump state, error state and other bitmaps), each ID is its own Binary Value for the element printed beside it; the element is shown in brackets after the name. Elements printed as '-' or '---' are unused and left out (26 here).
  • Analog values with several units listed (bar, m, K, °C, psi...) report in the unit of the active control mode.
  • The 'Added' column gives the list version each object appeared in (31.000, 31.102); older switch box software may lack some objects.
  • Set points water level 1-4 are printed twice: IDs 1318-1321 are the pump start levels and 1326-1329 the stop levels (per Wilo's data-point descriptions). 'Cycles float switches P2 on' is printed as ID 137, which looks like a typo for 1437; it is kept as printed.

Questions about the Wilo CC Lift (BACnet IP / MS/TP)

How many BACnet points does the Wilo CC Lift (BACnet IP / MS/TP) have?

This list has 190 BACnet objects: 46 analog values, 138 binary values, 6 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Wilo CC Lift (BACnet IP / MS/TP) BACnet points are writable?

22 of the 190 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Wilo CC Lift (BACnet IP / MS/TP) BACnet documentation?

The source is BACnet - supplemental sheet CC manual (CC System): System-specific data-point list BACnet CC (wilo110044), revision CC BACnet 2016-04-05 (list 31.106), published free by Wilo at https://cms.media.wilo.com/cdndoc/wilo110044/794249/wilo110044.pdf.

What are the minimum BACnet points to integrate the Wilo CC Lift (BACnet IP / MS/TP)?

Start with BV 224 Drives on/off (Automatic operation and all pumps on/off); AV 1318 Set points water level 1 (Pump 1 start level, cm); MV 208 Bus command timer (Write Set (3) at least every 5 min to keep control); BV 1985 Acknowledge (Alarm acknowledge); BV 976 Switch box state (SBM) (Collective run signal); AV 1313 Level sensor 1 (Tank level, sensor 1); BV 977 Switch box state (SSM) (Collective fault signal).

How do I enable BMS control of the Wilo CC Lift (BACnet IP / MS/TP)?

The Bus command timer (MV 208) decides who may change settings. Manual: HMI and fieldbus both write, last value wins. Off: HMI locked, fieldbus only. Set: HMI locked and a 5-minute timer starts (state reads Active).

Does the Wilo CC Lift (BACnet IP / MS/TP) need a BACnet heartbeat or have a communication timeout?

With the Bus command timer in Set mode, Set must be written again at least every five minutes. If it lapses the state changes to Reset, the HMI gets access back and the fieldbus is locked until Set is written again.
