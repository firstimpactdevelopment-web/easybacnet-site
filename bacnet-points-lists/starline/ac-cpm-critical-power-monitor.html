Starline AC Critical Power Monitor (CPM) for busway BACnet points list

Updated 12 November 2026

Short answer

The AC CPM meters an infeed and up to six outlets, plus enclosure and node temperatures and breaker status. Its BACnet object list has 405 objects with a write-access level for each: device text fields, infeed voltages, currents, power, energy, demand and min/max values, per-outlet metering, alarm thresholds, hex alarm-status words and breaker status.

This page lists 405 BACnet objects for the Starline AC Critical Power Monitor (CPM) for busway — 254 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Starline’s own free documentation, linked below.

BMS integration notes: Starline AC Critical Power Monitor (CPM) for busway

Integration in brief

Read the infeed totals (energy, active power, average current and voltage, power factor) and the per-line currents, plus the infeed and outlet alarm status words. Add per-outlet metering for each plug-in unit you need to bill or monitor.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Watch out for

  • Many objects share the same name; map by object type and instance, not by name.
  • Alarm thresholds, ratings and resets are writable; Admin-level writes need the admin access level. Don't write them cyclically.

Integration notes

  • Object names are generic and repeat (e.g. INFEED LINE CURRENT for lines 1-3 and neutral); the description column says which line, outlet or node each object is.
  • Access comes from the Write Access Level column: User or Admin = writable, '-' = read-only. Admin-level objects are marked in the description.
  • About 90% of the objects match the M70 CPM list, but it is not a drop-in copy: it has no OUTLET 1 IDENTIFIER (CSV 14), no NUMBER OF BREAKERS, no breaker 5-6 status and no identify/reboot BVs, and the breaker objects are numbered differently (breaker alarm PIV 11, breaker 1-2 status PIV 13-14). Use the M70 list only for M70 meters.
  • The object list does not state the BACnet transport or network settings.
  • Source: AC CPM BACNet Object List, revision 4 (3/3/2023), pages 2-10 (405 objects).

Questions about the Starline AC Critical Power Monitor (CPM) for busway

How many BACnet points does the Starline AC Critical Power Monitor (CPM) for busway have?

This list has 405 BACnet objects: 88 analog inputs, 212 analog values, 1 binary value, 46 characterstring values, 47 large analog values, 11 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Starline AC Critical Power Monitor (CPM) for busway BACnet points are writable?

254 of the 405 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Starline AC Critical Power Monitor (CPM) for busway BACnet documentation?

The source is AC CPM BACNet Object List (Rev 4), revision 2023-03-03, published free by Starline at https://cdn.starlinepower.com/drupal-media-and-files/files/files/AC-CPM-BACNet-Object-List-v4.26-v5.07.pdf.

What are the minimum BACnet points to integrate the Starline AC Critical Power Monitor (CPM) for busway?

Start with LAV 17 INFEED TOTAL ENERGY (Total infeed energy, kWh); LAV 1 INFEED TOTAL ACTIVE POWER (Total infeed active power, W); AI 3 INFEED LINE CURRENT AVERAGE (Average infeed line current, A); AI 9 INFEED LINE CURRENT (Infeed current, line 1, A); AI 10 INFEED LINE CURRENT (Infeed current, line 2, A); AI 11 INFEED LINE CURRENT (Infeed current, line 3, A); AI 1 LINE TO NEUTRAL VOLTAGE AVERAGE (Average line-to-neutral voltage, V); AI 4 INFEED TOTAL POWER FACTOR (Total power factor); PIV 4 INFEED ALARM STATUS (Infeed alarm status bits); PIV 5 OUTLET ALARM STATUS (Outlet 1-4 alarm status bits).
