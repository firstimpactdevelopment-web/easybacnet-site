Short answer

The BT300 is Siemens' HVAC drive for fans and pumps, with BACnet MS/TP built in; the PICS also lists BACnet IP. It exposes 133 fixed objects: start/stop, enable, direction and reset commands as Binary Outputs, a speed reference and drive readings as Analog Values, fault history, PID values, bypass status and configurable fieldbus data objects.

BMS integration notes: Siemens BT300 HVAC drive (BACnet)

Integration in brief

Write BO 4 to start and stop, keep BO 3 run enable on, and send the speed reference to AV 0 in percent. Read BV 2 running status, AV 3 output frequency, AV 5 current and BV 4 fault, and reset trips with BO 6. BV 30 FB CONTROL and BV 31 FB REFERENCE select fieldbus control and reference; check the BT300 manual for how the drive must be set.

Enable & remote start

BO 4 CMD RUN STOP starts and stops the drive and BO 3 RUN ENABLE must be enabled. BV 30 FB CONTROL and BV 31 FB REFERENCE are writable selectors for fieldbus control and reference; the PICS does not explain them, so confirm the control place and reference source settings in the BT300 manual.

Network setup

  • BACnet MS/TP master at 9600, 19200, 38400 or 76800 baud; BACnet IP (with foreign device registration) is also listed in the PICS.
  • No default device instance is given in the PICS.
  • Max masters and max info frames exist on MS/TP only.

Watch out for

  • AV 40-50 change drive limits, ramps and motor data; don't write them cyclically.
  • FBDATAOUT / FB DATA IN contents depend on the drive's process data mapping.
  • BO 5 CMD FWD REV active state is REVRSE; leave it off for normal fan and pump rotation.

Integration notes

  • Access comes from each object's present-value entry in the PICS; writable objects with a priority array are shown as commandable.
  • The summary table spells 'Binray Input'; BI 0-5 are the drive's digital inputs.
  • FBDATAOUT and FB DATA IN objects carry whatever process data the drive is set up to map; the PICS does not say what.
  • AV 44 CURRENT LMT lists its units as enumeration 3, which is amperes in BACnet.
  • MS/TP baud rates 9600, 19200, 38400 and 76800; on BACnet IP it can register as a foreign device (it is not a BBMD).
  • AV 40-50 are drive parameters (limits, ramps, motor nameplate); writing them changes the drive setup.

Questions about the Siemens BT300 HVAC drive (BACnet)

How many BACnet points does the Siemens BT300 HVAC drive (BACnet) have?

This list has 133 BACnet objects: 2 analog inputs, 1 analog output, 70 analog values, 6 binary inputs, 7 binary outputs, 47 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Siemens BT300 HVAC drive (BACnet) BACnet points are writable?

43 of the 133 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Siemens BT300 HVAC drive (BACnet) BACnet documentation?

The source is Siemens BT300 BACnet Protocol Implementation Conformance Statement (PICS), revision 2015-12-28, published free by Siemens at https://www.bacnetinternational.net/catalog/manu/siemens/Siemens_BT300_PICS_20151228.pdf.

What are the minimum BACnet points to integrate the Siemens BT300 HVAC drive (BACnet)?

Start with BO 4 CMD RUN STOP (Start/stop from the BMS); BO 3 RUN ENABLE (Run enable; must be on to run); AV 0 SPEED REF (Speed reference in %); BO 6 FAULT RESET (Reset a tripped drive); BV 2 RUNSTP STAT (Running status); AV 3 OUTPUT FREQ (Output frequency in Hz); AV 5 MOTOR CRRNT (Motor amps); AV 10 KW HOURS (Energy counter, kWh); BV 4 FAULT STATUS (Any active drive fault); AV 16 ACTIVE FAULT (Active fault code).

How do I enable BMS control of the Siemens BT300 HVAC drive (BACnet)?

BO 4 CMD RUN STOP starts and stops the drive and BO 3 RUN ENABLE must be enabled. BV 30 FB CONTROL and BV 31 FB REFERENCE are writable selectors for fieldbus control and reference; the PICS does not explain them, so confirm the control place and reference source settings in the BT300 manual.

How do I check these points on the real BT300 HVAC drive (BACnet)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
