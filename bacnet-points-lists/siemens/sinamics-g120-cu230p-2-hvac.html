Short answer

The CU230P-2 HVAC control unit (used on G120P drives) has native BACnet MS/TP on its RS-485 terminals, selected with p2030 = 5. It exposes digital input and relay status, relay commands, run/stop, direction, reset, hibernation and override bits, plus analog values for frequency, speed, current, power, energy and fault and alarm history. This list comes from the firmware 4.3 manual; later firmware may add objects.

BMS integration notes: Siemens SINAMICS G120 CU230P-2 HVAC (BACnet MS/TP)

Integration in brief

Set p2030 = 5 (BACnet), give the drive a MAC address by DIP switch or p2021, set baud p2020 and device instance p2025[0], then set p0700 = 6 and p1000 = 6 so commands and setpoint come from the fieldbus. Write BV20 RUN/STOP CMD and AV17 FREQ STPT PCT, read BV0, BV2 and AV0/AV5/AV7, and reset with BV22. Raise p2040 from its 100 ms factory value.

Enable & remote start

p0700 = 6 (via fieldbus) selects BACnet as the command source and p1000 = 6 the setpoint source. BV93 CTL OVERRIDE CMD moves inverter control to BACnet override; the operator panel's Manual mode still has priority. BV26 RUN ENA CMD enables operation and BV24 CDS switches local/remote.

Heartbeat & communication loss

p2040 Fieldbus monitoring time (0-65535000 ms, factory 100 ms) is the comms watchdog; Siemens notes 100 ms is probably too short for BACnet and must be raised. The BACnet section does not say what the drive does when it expires.

Network setup

  • MS/TP MAC (1-127) comes from the Control Unit DIP switches, or p2021 when all address switches are off; a change needs a full power-off including any external 24 V.
  • p2020 sets baud: 9600 (factory), 19200, 38400 or 76800.
  • p2025[0] device instance (factory 1), [1] max info frames (1), [2] APDU retries (3), [3] max master (127).
  • p2024[0] APDU timeout, factory 1000 ms.
  • p2026 sets COV increments for AI0, AI1, AI10 and AI11 (factory 0.100); up to 32 COV subscriptions.
  • Maximum RS-485 cable length 1200 m.

Watch out for

  • Panel Manual mode beats BACnet override control.
  • AV16 RPM STPT 1, AV30-AV33 and AV12 write drive parameters directly.
  • This list comes from the FW 4.3 manual; newer firmware may differ.

Integration notes

  • Device instance is p2025[0] (factory setting 1); baud rate is p2020 (default 9600).
  • Command objects only act when command source p0700 and setpoint source p1000 are set to fieldbus.
  • The factory fieldbus monitoring time p2040 (100 ms) is usually too short for BACnet and should be raised.
  • Text active/inactive columns in the source look swapped on several BVs; states here use the 'possible values' column.
  • The manual describes AV29 as 'Signal from AO 1'; it is the AO 2 readback and is described that way here.
  • Source is the 02/2010 edition for FW 4.3; check against the manual for your firmware.

How many BACnet points does the Siemens SINAMICS G120 CU230P-2 HVAC (BACnet MS/TP) have?

This list has 73 BACnet objects: 4 analog inputs, 33 analog values, 11 binary inputs, 3 binary outputs, 22 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Siemens SINAMICS G120 CU230P-2 HVAC (BACnet MS/TP) BACnet points are writable?

21 of the 73 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
