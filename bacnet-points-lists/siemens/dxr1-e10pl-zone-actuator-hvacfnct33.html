The DXR1.E10PL is a damper actuator with a built-in BACnet IP room controller and airflow sensor for VAV, VVT and fan-powered boxes. BMS integration notes: Siemens OpenAir Zone Controller Actuator DXR1.E10PL - HvacFnct33 (with fan state, room units and sensors)

Integration in brief

Command the room operating mode (MV 9) and the room setpoint (AV 50) at priority 15, then read room temperature, heating/cooling state, supply airflow, fan state and the damper and heating positions.

Enable & remote start

The doc says the room operating mode is normally controlled from the BMS and must be written at priority 15; scheduled or manual central commands also use priority 15.

Sensors & values from the BMS

Room temperature, humidity and air quality come from a KNX PL-Link room unit or sensor, or from wired inputs; the effective values are AV 57 (temperature), AV 55 (humidity) and AV 56 (air quality).

Network setup

  • The device name, instance and description are set by the user when the device is engineered; the doc gives no default instance.
  • The device IP address is shown in a proprietary network-port object in hex format.

Watch out for

  • A value held at priority 5 means the equipment is in protection mode; check before overriding at a higher priority.
  • Fan state appears on BI 4, BI 5 or BI 6 depending on the input channel used (D1, X1 or X2).

Integration notes

  • Object names here are the short names; on site each object name is prefixed with the building structure path (the doc shows wildcards such as %RSegm%'VavSuPos).
  • Many outputs and inputs exist in several alternative instances, one per hardware option (valve type, number of electric heat stages, channel used, room unit model). Only the instances matching the configured option are present on a given device.
  • Access: 'C' marks objects the list shows as writeable; others are read-only. The doc says room operating mode and the room setpoint are normally commanded at priority 15, and a value held at priority 5 means equipment protection is active.
  • A proprietary network-port object (type 264) in the device section is left out.
  • US units as listed; flows are in cfm (ft³/min).
  • The doc lists two product types (DXR1.E10PL-112/US and -113/US) and two object sets (HvacFnct31 and HvacFnct33) but does not say which product or box type uses which set. This set adds fan state inputs (BI 4-6).
