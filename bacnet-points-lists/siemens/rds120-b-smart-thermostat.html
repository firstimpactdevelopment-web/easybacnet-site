BMS integration notes: Siemens RDS120.B Smart Thermostat (BACnet version of RDS120)

Integration in brief

Command the room operating mode with MV 75 ROpMod and set the Comfort heating and cooling setpoints (AV 176 / AV 191, or the _US twins). Read the present mode and setpoints, the room temperature and the heating/cooling state back. Map only the objects for the application and inputs actually configured.

Network setup

  • Pick °C or °F objects and stay consistent; the _US objects sit at instance + 256.

Watch out for

  • Objects for unused inputs or applications are still in the table; map only what the thermostat is configured for.
  • Several names repeat with different instances; always map by instance, not by name.

Which Siemens RDS120.B Smart Thermostat (BACnet version of RDS120) BACnet points are writable?
