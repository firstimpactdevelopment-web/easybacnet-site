Short answer

The Intelligent Valve is a hydronic control valve with a built-in flow sensor and temperature inputs, so it reports flow, power, energy and operating statistics. It talks BACnet IP (Modbus RTU runs in parallel) and can run as a dynamic control valve, a changeover valve, a flow temperature controller, a heating circuit controller or a differential pressure controller. Over BACnet IP the valve follows SpRel (AV 16), a 0-100 % setpoint that becomes a position, flow or power setpoint depending on CtlMod (MV 39).

BMS integration notes: Siemens Intelligent Valve EVG4U10E / EVF4U20E (BACnet IP)

Integration in brief

Commission the valve as a dynamic control valve with the setpoint coming over BACnet IP, so PrSpSrc (MV 54) reads 3. The BMS then writes SpRel (AV 16) and reads flow, power, the primary temperatures, valve position and the main fault code MnFlt (MV 57). The guide's own short list for integration also includes the present flow and power setpoints and the control state.

Enable & remote start

The application and setpoint source are set at commissioning; PrSpSrc (MV 54) shows the result. Option 3 (Relative setpoint remote) means the dynamic control valve takes SpRel (AV 16) from BACnet IP; options 7 and 8 do the same for flow temperature and differential pressure setpoints. VovrMod (MV 92) can override the valve (fully open, fully closed, minimum or maximum flow and so on).

Heartbeat & communication loss

BckpMod (MV 42) sets what the valve does when its setpoint is missing, for example when no remote setpoint is present: None (default), Last setpoint, or Predefined setpoint from AV 34-36. BckpModDly (PIV 0, seconds) is the delay before backup mode starts. Backup mode applies to the dynamic control valve and flow temperature applications only.

Network setup

  • BACnet IP per Annex J; the device has no BBMD function.
  • Modbus RTU on port 1 runs alongside BACnet IP: address PIV 14 (default 10), baud MV 93 (default 19200), stop bits MV 94, parity MV 95 (default Even); write MbPort1SetApy (MV 96) = 2 (Apply) to use new settings.
  • CtlMod (MV 39) picks position, volume flow or power control; VflMax (AV 22) and PwrMax (AV 27) scale SpRel into the flow or power setpoint.

Watch out for

  • SpTFl (flow temperature setpoint) has a priority array; priority 15 is used by the internal control, so the guide recommends commanding it at priority 14.
  • In the differential pressure function several objects move to other instances (for example CtlSta MV 63, PrVfl AV 70, PrPwr AV 71); map the right set for the function in use.
  • Pressure, flow temperature and outside temperature inputs change instance with the selected signal type; check which ID is live on the device.
  • Alarm BVs (Alm1004-Alm3050) print state 0 = Active and 1 = Inactive.

Questions about the Siemens Intelligent Valve EVG4U10E / EVF4U20E (BACnet IP)

How many BACnet points does the Siemens Intelligent Valve EVG4U10E / EVF4U20E (BACnet IP) have?

This list has 226 BACnet objects: 20 analog inputs, 3 analog outputs, 121 analog values, 1 binary output, 37 binary values, 1 schedule, 35 multi-state values, 8 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Siemens Intelligent Valve EVG4U10E / EVF4U20E (BACnet IP) BACnet points are writable?

112 of the 226 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Siemens Intelligent Valve EVG4U10E / EVF4U20E (BACnet IP) BACnet documentation?

The source is Intelligent Valve, BACnet Objects (A6V11757108), revision 2026-06-23, published free by Siemens at https://sid.siemens.com/api/khub/documents/Z90WHO9nj7QdzVxuByXoDQ/content.

What are the minimum BACnet points to integrate the Siemens Intelligent Valve EVG4U10E / EVF4U20E (BACnet IP)?

Start with AV 16 SpRel (Relative setpoint, 0-100 %); MV 54 PrSpSrc (Must read 3 (Relative setpoint remote) for BACnet IP); MV 40 CtlSta (Active control state); AV 39 PrVfl (Present volume flow, m³/h); AV 40 PrPwr (Present power, kW); AI 3 TFlPrim (Primary flow temperature, °C); AI 2 TRtPrim (Primary return temperature, °C); AI 1 VlvPosFb (Valve position, %); MV 57 MnFlt (Main fault code (1 = no fault)).

How do I enable BMS control of the Siemens Intelligent Valve EVG4U10E / EVF4U20E (BACnet IP)?

The application and setpoint source are set at commissioning; PrSpSrc (MV 54) shows the result. Option 3 (Relative setpoint remote) means the dynamic control valve takes SpRel (AV 16) from BACnet IP; options 7 and 8 do the same for flow temperature and differential pressure setpoints. VovrMod (MV 92) can override the valve (fully open, fully closed, minimum or maximum flow and so on).

Does the Siemens Intelligent Valve EVG4U10E / EVF4U20E (BACnet IP) need a BACnet heartbeat or have a communication timeout?

BckpMod (MV 42) sets what the valve does when its setpoint is missing, for example when no remote setpoint is present: None (default), Last setpoint, or Predefined setpoint from AV 34-36. BckpModDly (PIV 0, seconds) is the delay before backup mode starts. Backup mode applies to the dynamic control valve and flow temperature applications only.
