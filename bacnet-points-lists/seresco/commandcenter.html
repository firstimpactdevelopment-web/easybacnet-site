Short answer

Seresco's CommandCenter controller uses one BACnet object list across its NE/NV pool units, OA make-up air units and the NP/NW series; the source marks each object as standard or optional per series. Sensors are AI objects, setpoints and analog outputs are AV objects, and component status, modes, commands and alarms are BV objects. The BMS can override any sensor by setting it Out Of Service and writing its value, with a heartbeat timer to fall back to the unit's sensors. Command objects must first be enabled at the unit.

BMS integration notes: Seresco CommandCenter Dehumidifier Controller - BACnet Objects 5.8.0

Integration in brief

Enable the BACnet command objects at the unit first. Then use Blower Enabled (BV 512) for start/stop and Occupied (BV 516) for occupancy, and write the room temperature, humidity and pool setpoints (AV 0-2). Monitor the blower contactor, the mode BVs, return air conditions and the alarm count. If the BMS supplies sensor values, set the heartbeat timer (AV 515) so the unit falls back to its own sensors.

Enable & remote start

Command objects (BV 512-526) only work after they are enabled at the unit itself. BV 512 Blower Enabled starts and stops the main blower; stopping it stops all other components except a pool unit's auxiliary pool heater. BV 516 Occupied replaces the built-in occupancy scheduler. BV 524/525 A/C and Heat Override take over room temperature control and stay in effect until the unit restarts.

Heartbeat & communication loss

AV 515 Heartbeat Timer (0-600 s) applies when the BMS supplies sensor values. With a value above 0, the unit returns to its own sensors if no BACnet message arrives within that time, so BMS-written sensor values must be refreshed within the timer even if unchanged. 0 disables the fallback.

Sensors & values from the BMS

Any AI sensor can be taken over by setting its Out_Of_Service property to True and writing Present_Value from the BMS. Set AV 515 above 0 so the unit falls back to its installed sensors if BACnet communication stops.

Network setup

  • Default device instance is 150; default device name is 'Seresco Dehumidifier'.
  • Segmentation is not supported; max APDU length is 1476.
  • Reinitialize Device supports Warm Start only and needs the password given in the source document.

Watch out for

  • Command BVs do nothing until enabled at the unit.
  • A/C and Heat Override (BV 524/525) keep control until a system restart once activated.
  • Compressor data is only reliable when the matching Available BV (264-266) is active.
  • AV 13 Humidity Floating Setpoint can't be written; the wall temperature sensor sets it.

Integration notes

  • The source has no read/write column; access here follows its text: setpoints (except AV 13), AV 512/515 and the command BVs 512-526 are writable, everything else read-only.
  • Each description lists the series where the object is standard (Std) or optional (opt); optional objects only appear when that feature is configured.
  • Temperatures follow the unit's °F/°C keypad setting.
  • Default device name is 'Seresco Dehumidifier', segmentation is not supported and max APDU is 1476.
  • The heartbeat text refers to sensor override objects 128-131 that are not in the object tables.
  • All command BVs (512-526) are marked optional in the source and must be enabled at the unit before they respond.
