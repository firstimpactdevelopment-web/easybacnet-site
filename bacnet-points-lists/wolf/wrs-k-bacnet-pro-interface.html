Short answer

The BACnet-Pro interface is WOLF's newer BACnet connection for the WRS-K air-handling controller. Unlike the older BACnet interface it publishes measurements as Analog Inputs, BMS setpoints and offsets as commandable Analog Outputs, states and alarms as Binary Inputs, stages as Multistate Inputs, the operating mode as a Multistate Value, plus trend logs, schedules for the BMS setpoints and notification classes.

BMS integration notes: WOLF WRS-K air handling unit controller - BACnet-Pro interface

Integration in brief

Set MV 1006 Operation_Mode and write the BMS setpoints (AO 15 temperature, AO 16 / 17 fan speeds, MO 222 fan step). Read BI 5 Status_AHU, the supply and room temperatures and BI 1 Alarm_General plus the individual alarm BIs; reset alarms with BV 1.

Enable & remote start

MV 1006 Operation_Mode selects manual mode, the 7-day program or BMS mode. The EDE does not say which BMS setpoints take effect in which mode; check on site.

Sensors & values from the BMS

Outdoor and room temperature can be written from the BMS (AO 37 Temperature_Outdoor_BMS, AO 71 Temperature_Room_BMS, -50 to 60 °C); BI 128 / BI 134 flag problems with them.

Network setup

  • Default device instance 2000.
  • BACnet IP via the interface's network port.

Watch out for

  • Offset objects (AO 18-22, AO 1019-1023) shift setpoints rather than replace them; check which ones the unit uses.
  • BI 300 Alarm_Watchdog_KLM is a watchdog alarm flag; the EDE gives no timeout.

Questions about the WOLF WRS-K air handling unit controller - BACnet-Pro interface

How many BACnet points does the WOLF WRS-K air handling unit controller - BACnet-Pro interface have?

This list has 264 BACnet objects: 48 analog inputs, 22 analog outputs, 1 analog value, 115 binary inputs, 2 binary values, 5 multi-state inputs, 1 multi-state output, 4 notification classs, 11 schedules, 1 multi-state value, 54 trend logs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which WOLF WRS-K air handling unit controller - BACnet-Pro interface BACnet points are writable?

27 of the 264 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official WOLF WRS-K air handling unit controller - BACnet-Pro interface BACnet documentation?

The source is EDE-File BACnet-Pro-Schnittstelle fuer WRS-K, Index05 (BACnet-Pro_Index05_EDE_komplett.csv) (Index05), revision 08.07.2025, published free by WOLF at https://www.wolf.eu/download-asset/RmlkbTRXT2hDOHpMWEN6ZVZOOUVPQT09.

What are the minimum BACnet points to integrate the WOLF WRS-K air handling unit controller - BACnet-Pro interface?

Start with MV 1006 Operation_Mode (Operating mode: 1 manual, 2 7-day program, 3 BMS); MO 222 Setpoint_Fan_Step_BMS (Fan stage from BMS: 1 off, 2 on, 3-4 stages); AO 15 Setpoint_Temperature_BMS (Temperature setpoint from the BMS, °C); AO 16 Setpoint_Speed_SUP_BMS (Supply fan speed setpoint, %); AO 17 Setpoint_Speed_ETA_BMS (Extract fan speed setpoint, %); BV 1 Alarm_Reset_BMS (Remote alarm reset); BI 5 Status_AHU (Unit status); AI 1 Temperature_SUP (Supply air temperature, °C); AI 3 Temperature_Room (Room temperature, °C); BI 1 Alarm_General (General alarm).

How do I enable BMS control of the WOLF WRS-K air handling unit controller - BACnet-Pro interface?

MV 1006 Operation_Mode selects manual mode, the 7-day program or BMS mode. The EDE does not say which BMS setpoints take effect in which mode; check on site.

Can the BMS supply sensor values to the WOLF WRS-K air handling unit controller - BACnet-Pro interface?

Outdoor and room temperature can be written from the BMS (AO 37 Temperature_Outdoor_BMS, AO 71 Temperature_Room_BMS, -50 to 60 °C); BI 128 / BI 134 flag problems with them.
