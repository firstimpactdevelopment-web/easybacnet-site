BMS integration notes: Trane Symbio 800 RTAC (UC800)

Integration in brief

Put the chiller on the network (BACnet MS/TP or IP), then write the auto/stop command, chilled water setpoint, current limit and mode. Read back running state, leaving water temperature and capacity. Check the local-setpoint flag to confirm the BAS setpoints are actually in use. The alarm-present flag gives a single summary alarm.

Enable & remote start

MV 1 BAS Chiller Auto Stop Command (1 = Stop, 2 = Auto; relinquish default Auto) is the BMS auto/stop. BI 1 Run Enabled shows stop/auto. The document doesn't say how to hand setpoint control to the BAS; BI 2 Local Setpoint Control shows when the chiller is using local setpoints instead of BAS setpoints.

Heartbeat & communication loss

No timeout or heartbeat is described. BI 742 'Comm Loss: Local BAS Interface' is a diagnostic flag; the document doesn't say what the chiller does when it is set.

Network setup

  • With no protocol specified at order, the controller ships as BACnet MS/TP at 76,800 bps with the rotary address at 000, and MS/TP is disabled at 000. Set a rotary address of 001-127 to bring it online.
  • The rotary address sets the MS/TP MAC and the Device ID and takes effect without a power cycle. A software Device ID (1-4194302) can be set in the web UI, Tracer SC+ or Tracer TU.
  • The web UI is reached only over USB at http://198.80.18.1/; the Ethernet ports do not serve it.
  • BACnet IP uses Ethernet port 1 (or the optional USB Wi-Fi adapter); the default UDP port is 47808. Enable BBMD only if this is the only BACnet IP device on the subnet, then fill in the BDT.
  • MS/TP wiring lands on the P1 link; P2 and P3 are for factory devices only, and Ethernet port 2 is only for the touch-screen display.

Watch out for

  • Communicated units (I-P or SI) are fixed at the factory; changing them in the field needs a Trane representative. Web UI display units do not change the BACnet values.
  • Points that don't apply to the unit's configuration are absent, and a technician can 'recycle' (remove) factory points from the interface, so a missing object may have been recycled.
  • This list has no read/write column; writability of the command and setpoint objects is inferred from their object type and relinquish defaults.
  • Relinquish defaults: AV 1 44 °F (6.7 °C), AV 2 100 % RLA, MV 1 Auto, MV 2 Cool. Releasing MV 1 leaves the chiller in Auto.
  • Mode states skip 2: MV 2 and MI 2 use 1 = Cool and 3 = Ice.
  • Diagnostic BIs are one object per alarm condition and only exist for the options fitted.

Integration notes

  • Only the points that apply to the unit's factory configuration show up; the doc lists every possible point.
  • The tables have no read/write column: AI/BI/MI are read-only, and the AV/BV/MV objects (listed with a relinquish default and valid range) are the BAS setpoints and commands, marked writable here.
  • The analog tables give only the data type (Real) instead of engineering units, so units are blank here.
  • BI 500 and up are diagnostic flags, one per alarm condition; the document lists their names only, with no state text.
  • The Symbio 800 integration guide (BAS-SVP083) covers BACnet IP and BACnet MS/TP; the rotary address sets the MS/TP MAC and a default Device ID of 1-127, and a software Device ID can be set instead.
  • Trane titles this list 'RTAC (UC800)' and does not explain the suffix in the document. Its objects use short instance numbers (AI 1, BI 4...) instead of the 5-digit numbering in the standard Symbio 800 RTAC list (BAS-PTS023), so check which list matches the controller on site.
  • The same document also has a Modbus register map; only the BACnet side is listed here.

Questions about the Trane Symbio 800 RTAC (UC800)

How many BACnet points does the Trane Symbio 800 RTAC (UC800) have?

This list has 335 BACnet objects: 72 analog inputs, 2 analog values, 252 binary inputs, 1 binary value, 6 multi-state inputs, 2 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 800 RTAC (UC800) BACnet points are writable?

5 of the 335 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Trane Symbio 800 RTAC (UC800) BACnet documentation?

The source is Symbio 800 Integration Points List BACnet - RTAC (UC800) (BAS-PTS032A-EN), revision 12/6/2024, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS032A-EN_12062024.pdf.

What are the minimum BACnet points to integrate the Trane Symbio 800 RTAC (UC800)?

Start with MV 1 BAS Chiller Auto Stop Command (BMS auto/stop command (1 = Stop, 2 = Auto)); MV 2 BAS Chiller Mode Command (Cool/ice mode command); AV 1 BAS Chilled Water Setpoint (Chilled water setpoint from the BMS); AV 2 BAS Current Limit Setpoint (Current limit from the BMS, % RLA); BI 4 Chiller Running Indicator (Chiller on/off status); BI 2 Local Setpoint Control (Shows if local setpoints override BAS setpoints); AI 45 Evaporator Leaving Water Temp (Leaving chilled water temperature); AI 5 Actual Running Capacity (Actual running capacity in percent); BI 23 Alarm Present (Any active alarm on the chiller).

How do I enable BMS control of the Trane Symbio 800 RTAC (UC800)?
