BMS integration notes: Trane Symbio 700 Voyager 3

Integration in brief

Leave MV 11100 Arbitration Method Request at 'Enable External/BAS Control'. Then schedule the unit with MV 10106 Occupancy Request and send setpoints to the setpoint BAS points at a priority above 14. If the BMS supplies sensor values such as space temperature, rewrite the '... BAS' points within their 900 s heartbeat.

Enable & remote start

MV 11100 Arbitration Method Request picks the control type. 'Enable External/BAS Control' is the default: the controller weighs BAS, Air-Fi and wired sources. 'Standalone Control' ignores all BAS input and is meant for troubleshooting. BV 11113 Unit Stop Command (Auto/Stop) stops the unit from the BMS.

Heartbeat & communication loss

The sensor BAS points (AV 10113 Outdoor Air Temperature BAS, AV 10114 Space Temperature BAS, AV 10116-10119, AV 11103 Return Air Humidity BAS, AV 11119 Return Air Temperature BAS) have a 900 s heartbeat in the tables, so the BMS must keep rewriting them. The setpoint and command points have no heartbeat.

Sensors & values from the BMS

Write the value to the matching '... BAS' AV (e.g. AV 10114 Space Temperature BAS, AV 10113 Outdoor Air Temperature BAS) and keep refreshing it; the '... Arbitrator' object shows which source wins and the '... Active' object reports the value in use. Space setpoints go to AV 10127 (single setpoint) or AV 10159/10160 (dual setpoint). BV 10113 Occupancy Input BAS is the communicated occupancy input.

Network setup

  • The rotary address (001-127) sets the BACnet MS/TP MAC and the default Device ID; changing it takes effect without a power cycle.
  • A software Device ID (1-4194302) can be set in the Symbio Service and Installation mobile app (Bluetooth) or on the onboard display.
  • MS/TP default baud is 76,800 bps; MS/TP wiring lands on connector J17. BACnet IP uses the Ethernet port.
  • For BACnet IP set the IP address first, then the protocol, Device ID and UDP port; tick BBMD only if this is the only BACnet IP device on the subnet.
  • Communicated units can be switched between IP and SI in the mobile app or onboard display.

Watch out for

  • Wired setpoints write at priority 15 and Air-Fi at 14, so the BMS must write setpoint BAS points at a priority above 14 or the value is ignored.
  • Setpoints changed from the onboard display or mobile app go to the relinquish default, not the priority array.
  • Arbitrator objects are for reading only, even though the table marks them writable.
  • 'Command' points may be persisted once written, so don't write them cyclically.
  • Air-Fi installs are integrated through a Tracer SC+ system controller, not directly.

Integration notes

  • Only the points that match the unit's factory configuration show up; the guide lists every possible point.
  • Name suffixes carry meaning: Status/Local/Active/Input are read-only, BAS/Command/Request/Setpoint value objects are the ones a BAS writes, and Arbitrator objects show which source is winning.
  • Access 'C' marks writable objects whose arbitration pattern is setpoint with a priority array, plus AV 10127, AV 10159 and AV 10160, which the appendix calls commandable; other writable objects are 'W'.
  • Several objects are printed more than once with different descriptions or state lists for different unit configurations (PI gain/reset AVs, AI 11142-11143, BI 11231, BV 11100, MV 11110 Service Test State Request, MV 11128). Each is listed once here.
  • Eight objects whose rows ran together in the table (AI 10185, AI 10187, AV 11159, AV 11160, AV 11217, AV 11218, BV 11127, BV 11128) were checked against the page text.
  • The same guide gives Modbus RTU/TCP registers for every object; only the BACnet side is listed here.

Questions about the Trane Symbio 700 Voyager 3

How many BACnet points does the Trane Symbio 700 Voyager 3 have?

This list has 568 BACnet objects: 56 analog inputs, 260 analog values, 105 binary inputs, 108 binary values, 6 multi-state inputs, 33 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 700 Voyager 3 BACnet points are writable?

198 of the 568 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Trane Symbio 700 Voyager 3 BACnet documentation?

The source is Integration Guide: BACnet and Modbus Integration to Voyager 3 Packaged Rooftop Air-Conditioners with Symbio 700 Controls (BAS-SVP066B-EN), revision April 2024, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Integration/BAS-SVP066B-EN_04132024.pdf.

What are the minimum BACnet points to integrate the Trane Symbio 700 Voyager 3?

Start with MV 10106 Occupancy Request (Occupancy command (occupied/unoccupied/standby)); BV 11113 Unit Stop Command (BMS stop/auto of the whole unit); AV 10159 Occupied Cooling Setpoint BAS (Occupied cooling setpoint (dual-setpoint units)); AV 10160 Occupied Heating Setpoint BAS (Occupied heating setpoint (dual-setpoint units)); AV 10127 Space Temperature Setpoint BAS (Single-setpoint alternative to the two setpoints above); MI 10101 Heat Cool Mode Status (Current heat/cool operating mode); MV 11123 Occupancy Status (Confirms the occupancy the unit is running in); BI 10226 Supply Fan Status (Supply fan on/off status); AV 11178 Space Temperature Active (Space temperature the unit is actually controlling to); BV 11100 Alarm Indicator Status (Unit alarm output; on when the controller is in alarm).

How do I enable BMS control of the Trane Symbio 700 Voyager 3?

MV 11100 Arbitration Method Request picks the control type. 'Enable External/BAS Control' is the default: the controller weighs BAS, Air-Fi and wired sources. 'Standalone Control' ignores all BAS input and is meant for troubleshooting. BV 11113 Unit Stop Command (Auto/Stop) stops the unit from the BMS.

Does the Trane Symbio 700 Voyager 3 need a BACnet heartbeat or have a communication timeout?

The sensor BAS points (AV 10113 Outdoor Air Temperature BAS, AV 10114 Space Temperature BAS, AV 10116-10119, AV 11103 Return Air Humidity BAS, AV 11119 Return Air Temperature BAS) have a 900 s heartbeat in the tables, so the BMS must keep rewriting them. The setpoint and command points have no heartbeat.

Can the BMS supply sensor values to the Trane Symbio 700 Voyager 3?

Write the value to the matching '... BAS' AV (e.g. AV 10114 Space Temperature BAS, AV 10113 Outdoor Air Temperature BAS) and keep refreshing it; the '... Arbitrator' object shows which source wins and the '... Active' object reports the value in use. Space setpoints go to AV 10127 (single setpoint) or AV 10159/10160 (dual setpoint). BV 10113 Occupancy Input BAS is the communicated occupancy input.

How do I check these points on the real Symbio 700 Voyager 3?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
