Short answer

The BCI2-I is a non-programmable BACnet MS/TP card for IntelliPak rooftops and Commercial Self-Contained units. It scans the unit at first power-up and creates only the objects that match the installed options, so the full table is a superset. The BAS writes AO/BO/MO output objects (commands, setpoints, BAS sensor values) and reads AI/BI/MI status and diagnostics. This is the older IntelliPak interface, not the Symbio 800 IntelliPak controller.

BMS integration notes: Trane BCI2-I (IntelliPak)

Integration in brief

Set Unit Control to BAS/NETWORK at the unit's Human Interface, then set BO 1 System Control Command to Active (BAS Control). Put each output object the BMS will drive in service (Out_Of_Service = FALSE). Schedule with MO 7 Occupancy Request, set the mode with MO 8 and the space setpoint with AO 2 (or the discharge air setpoints on VAV units). Keep rewriting BAS sensor values.

Enable & remote start

At the unit Human Interface, BAS Communication Module must read Installed and Setup > Unit Control must be BAS/NETWORK. Then BO 1 System Control Command must be Active (BAS Control); while Inactive the unit runs on local sensors and setpoints and ignores BAS values. Output objects ship with Out_Of_Service = TRUE, so the unit uses its local value until the BMS sets Out_Of_Service to FALSE on each output it will write.

Heartbeat & communication loss

BAS-supplied sensor objects with a 900 s refresh rate (AO 10-15, AO 17, AO 18, AO 25) must be rewritten within that time. If not, the BCI2-I puts the object in fault and the unit reverts to its own sensor. At power-up these objects stay in fault until the first write. Setpoints and commands have no refresh limit (AO 22 is printed with a 5 s refresh rate).

Sensors & values from the BMS

Write BMS sensor values to the '... BAS' AOs (AO 11 Space Temperature BAS, AO 12 Discharge Air Temperature BAS, AO 13 Duct Static Pressure BAS, AO 14 Outdoor Air Temperature BAS, AO 15 Outdoor Air Humidity BAS, AO 17 Outdoor Air Flow BAS, AO 18 Space CO2 Concentration BAS, AO 25 Space Humidity BAS, AO 10 Space Static Pressure BAS) with the object in service, and keep refreshing them. The matching '... Active' AIs show the value in use.

Network setup

  • BACnet MS/TP at 9600, 19200, 38400 or 76800 bps; default 76,800.
  • There are no rotary dials on the BCI2-I: the factory address is on a label on the board. Change it in the embedded BCI2 Service Tool (USB cable, browser at 198.80.18.1, Tools > Installation and Communication > Protocol Configuration) or with Tracer TU 11.6 or later.
  • The Device ID defaults to the MS/TP address; tick 'Use Software Device ID' to set a different one.
  • Units default to SI. To switch to IP, clear the controller first, then change Device Units; mixed units are not supported.
  • The clock resets to 12:00 Jan 1 1970 after a power loss; send TimeSynchronization from the BMS periodically.
  • Older IntelliPak/CSC units need the correct HI and module software; units that show COMM 5 instead of BACnet on the revision screen need upgrades (see the guide).

Watch out for

  • Writing an output object has no effect while it is Out of Service (the factory default); the unit keeps using its local value.
  • The object list is built at first power-up from the unit configuration. Clear the controller so it rescans after adding options.
  • BO 13 Filter Timer Reset and BO 14 Reset Diagnostic go back to Inactive on their own after the reset.
  • BI 86, 88, 89 and 90 mean different diagnostics on rooftops and on CSC units; check the unit type before naming them in the BMS.
  • Diagnostic BIs send BACnet event notifications when they change.

Integration notes

  • The tables have no read/write column. The guide says output objects carry BAS commands, setpoints and sensor values and input objects are status; its object-type tables give AO, AV, BO and MO a priority array, so those are marked commandable.
  • 'When exists' conditions from the guide are shown in brackets where they fit. Objects marked 'Never' in the guide (Chemical Purge, CSC only) are kept as printed.
  • BI 86, 88, 89 and 90 are printed twice with different meanings by unit type. Listed here: BI 86 Velocity Press Sensor Fail (CSC, IntelliPak I, rooftop) and the rooftop meanings of BI 88-90. The other printed meanings are BI 86 'Diagnostic: Vel Press Sensor (Rear)' (rooftop, IntelliPak II), BI 88 'Diagnostic: WSM Communications Failure', BI 89 'Diagnostic: Compressor Trip - Ckt 3' and BI 90 'Diagnostic: Compressor Trip - Ckt 4' (Commercial Self-Contained).
  • The diagnostics table repeats BI 161-166, 243-246 and 311. BI 161-164 are named 'Evaporator Frost Protection Circuit n Status' in the binary input table and 'Circuit n Coil Frost Protection Status' in the diagnostics table; BI 166 is 'Diagnostic Stop Status' vs 'Diagnostic: Stop Status'. The binary input table names are used here.
  • Units are the IP defaults printed in the guide; the card ships set to SI and only switches to IP after a clear and units change.
  • Objects in the 1001 range (AI, AO, AV, BI 1001...) are only created when a digital scroll compressor is present.

Questions about the Trane BCI2-I (IntelliPak)

How many BACnet points does the Trane BCI2-I (IntelliPak) have?

This list has 331 BACnet objects: 82 analog inputs, 33 analog outputs, 3 analog values, 161 binary inputs, 11 binary outputs, 34 multi-state inputs, 7 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane BCI2-I (IntelliPak) BACnet points are writable?

54 of the 331 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Trane BCI2-I (IntelliPak) BACnet documentation?

The source is Integration Guide: BACnet Communication Interface (BCI2-I) for IntelliPak and Commercial Self-Contained (BAS-SVP054B-EN), revision September 2023, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Integration/BAS-SVP054B-EN_09222023.pdf.

What are the minimum BACnet points to integrate the Trane BCI2-I (IntelliPak)?

Start with BO 1 System Control Command (Active = BAS control; Inactive = standalone, monitor only); MO 7 Occupancy Request (Occupancy command (1 = Occupied, 2 = Unoccupied)); MO 8 Heat Cool Mode Request BAS (Heat/cool mode command (1 = Auto)); AO 2 Space Temperature Setpoint BAS (Space setpoint; occupied/standby offsets apply to it); AO 6 Discharge Air Cooling Setpoint BAS (Supply air cooling setpoint on VAV units); BI 1 System Control Status (Confirms the unit is under BAS control); MI 20 Occupancy Status (Confirms the occupancy the unit is running in); MI 41 Supply Fan Status (Supply fan on/off (2 = On)); AI 15 Space Temperature Active (Space temperature the unit is controlling to); BI 165 Alarm Relay Output Status (Unit alarm relay; Active = energized).

How do I enable BMS control of the Trane BCI2-I (IntelliPak)?

At the unit Human Interface, BAS Communication Module must read Installed and Setup > Unit Control must be BAS/NETWORK. Then BO 1 System Control Command must be Active (BAS Control); while Inactive the unit runs on local sensors and setpoints and ignores BAS values. Output objects ship with Out_Of_Service = TRUE, so the unit uses its local value until the BMS sets Out_Of_Service to FALSE on each output it will write.

Does the Trane BCI2-I (IntelliPak) need a BACnet heartbeat or have a communication timeout?

BAS-supplied sensor objects with a 900 s refresh rate (AO 10-15, AO 17, AO 18, AO 25) must be rewritten within that time. If not, the BCI2-I puts the object in fault and the unit reverts to its own sensor. At power-up these objects stay in fault until the first write. Setpoints and commands have no refresh limit (AO 22 is printed with a 5 s refresh rate).

Can the BMS supply sensor values to the Trane BCI2-I (IntelliPak)?

Write BMS sensor values to the '... BAS' AOs (AO 11 Space Temperature BAS, AO 12 Discharge Air Temperature BAS, AO 13 Duct Static Pressure BAS, AO 14 Outdoor Air Temperature BAS, AO 15 Outdoor Air Humidity BAS, AO 17 Outdoor Air Flow BAS, AO 18 Space CO2 Concentration BAS, AO 25 Space Humidity BAS, AO 10 Space Static Pressure BAS) with the object in service, and keep refreshing them. The matching '... Active' AIs show the value in use.
