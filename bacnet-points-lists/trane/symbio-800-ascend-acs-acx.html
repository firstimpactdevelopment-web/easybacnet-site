Short answer

Ascend ACS/ACX chillers expose about 400 BACnet objects through the Symbio 800. Status values are AI/BI/MI, and the BAS writes a small set of AV/BV/MV objects for chilled and hot water setpoints, demand limit, mode, circuit lockouts and auto/stop. Most binary inputs are individual diagnostic flags.

BMS integration notes: Trane Symbio 800 Ascend ACS / ACX

Integration in brief

Put the chiller on the network (BACnet MS/TP or IP), then write the auto/stop command, chilled water setpoint, demand limit and mode. Read back running state, leaving water temperature and capacity. Check the local-setpoint flag to confirm the BAS setpoints are actually in use. Most remaining objects are read-only status and per-alarm diagnostic flags.

Enable & remote start

BV 10107 BAS Chiller Auto Stop Command (0 = Stop, 1 = Auto) is the BMS auto/stop; with it at Auto the chiller runs when its own run conditions are met. BI 10130 External Auto Stop reports the hardwired external auto/stop input. The documents don't say how the two combine or how to hand setpoint control to the BAS; BI 10104 Local Setpoint Control shows when the chiller is using local setpoints instead of BAS setpoints, and MI 10102 Chiller Setpoint Source shows BAS, External or Front Panel.

Network setup

  • With no protocol specified at order, the controller ships as BACnet MS/TP at 76,800 bps with the rotary address at 000, and MS/TP is disabled at 000. Set a rotary address of 001-127 to bring it online.
  • The rotary address sets the MS/TP MAC and the Device ID and takes effect without a power cycle. A software Device ID (1-4194302) can be set in the web UI, Tracer SC+ or Tracer TU.
  • The web UI is reached only over USB at http://198.80.18.1/; the Ethernet ports do not serve it.
  • BACnet IP uses Ethernet port 1 (or the optional USB Wi-Fi adapter); the default UDP port is 47808. Enable BBMD only if this is the only BACnet IP device on the subnet, then fill in the BDT.
  • MS/TP wiring lands on the P1 link; P2 and P3 are for factory devices only, and Ethernet port 2 is only for the touch-screen display.

Watch out for

  • Communicated units (I-P or SI) are fixed at the factory; changing them in the field needs a Trane representative. Web UI display units do not change the BACnet values.
  • Points that don't apply to the unit's configuration are absent, and a technician can 'recycle' (remove) factory points from the interface, so a missing object may have been recycled.
  • The chiller lists have no read/write column; writability of the AV/BV/MV objects is inferred from Trane's naming convention.
  • Diagnostic BIs are one object per alarm condition and only exist for the options fitted.

Integration notes

  • Only the points that apply to the unit's factory configuration show up; the doc lists every possible point.
  • The chiller tables have no read/write column: AI/BI/MI are read-only, and AV/BV/MV are the BAS command and setpoint objects, marked writable here per Trane's naming convention.
  • Units are listed as a quantity (Temperature, Pressure, Percent...); the actual engineering unit follows the controller's display-unit setting.
  • Binary inputs named 'Diagnostic: ...' are individual alarm flags (0/false = normal, 1/true = in alarm).
  • The Symbio 800 integration guide (BAS-SVP083) covers BACnet IP and BACnet MS/TP; the rotary address sets the MS/TP MAC and a default Device ID of 1-127, and a software Device ID can be set instead.
  • The same document also maps every object to a Modbus register; only the BACnet side is listed here.

Questions about the Trane Symbio 800 Ascend ACS / ACX

How many BACnet points does the Trane Symbio 800 Ascend ACS / ACX have?

This list has 397 BACnet objects: 79 analog inputs, 5 analog values, 292 binary inputs, 10 binary values, 10 multi-state inputs, 1 multi-state value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 800 Ascend ACS / ACX BACnet points are writable?

16 of the 397 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Trane Symbio 800 Ascend ACS / ACX BACnet documentation?

The source is Symbio 800 Integration Points List BACnet - Ascend Models ACS and ACX (BAS-PTS011A-EN), revision 11/15/2024, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS011A-EN_11152024.pdf.

What are the minimum BACnet points to integrate the Trane Symbio 800 Ascend ACS / ACX?

Start with BV 10107 BAS Chiller Auto Stop Command (BMS auto/stop (enable) command); AV 10100 Chilled Water Setpoint (Chilled water setpoint from the BMS); AV 10101 Demand Limit Setpoint (Capacity (demand) limit from the BMS); MV 10100 Chiller Mode Command BAS (Cool/heat/ice/free-cooling mode command); BI 10110 Chiller Running State (Chiller on/off status); BI 10104 Local Setpoint Control (Shows if local setpoints override BAS setpoints); MI 10102 Chiller Setpoint Source (Which setpoint source is active (BAS/External/Front Panel)); AI 10101 Evaporator Leaving Water Temperature (Leaving chilled water temperature); AI 10116 Actual Running Capacity (Actual running capacity in percent).

How do I enable BMS control of the Trane Symbio 800 Ascend ACS / ACX?

BV 10107 BAS Chiller Auto Stop Command (0 = Stop, 1 = Auto) is the BMS auto/stop; with it at Auto the chiller runs when its own run conditions are met. BI 10130 External Auto Stop reports the hardwired external auto/stop input. The documents don't say how the two combine or how to hand setpoint control to the BAS; BI 10104 Local Setpoint Control shows when the chiller is using local setpoints instead of BAS setpoints, and MI 10102 Chiller Setpoint Source shows BAS, External or Front Panel.

How do I check these points on the real Symbio 800 Ascend ACS / ACX?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
