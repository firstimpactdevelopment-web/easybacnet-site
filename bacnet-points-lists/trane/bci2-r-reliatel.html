Trane BCI2-R (ReliaTel) BACnet points list

Updated 16 October 2026

Short answer

The BCI2-R is a BACnet MS/TP card for ReliaTel rooftop units. It talks Modbus to the unit's RTRM board and builds its BACnet object list from what the RTRM reports at first power-up, so only the objects for the installed option modules (RTEM, RTAM, RTDM, RTOM, RTVM...) appear. Objects use short instances (AI 1, AO 2, BO 1...). The BAS writes AO/BO/MO output objects and reads AI/BI/MI status and diagnostics.

This page lists 250 BACnet objects for the Trane BCI2-R (ReliaTel) — 53 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Trane’s own free documentation, linked below.

BMS integration notes: Trane BCI2-R (ReliaTel)

Integration in brief

Set BO 1 System Control Command to Active (Trane also recommends setting its relinquish default to Active). Then put each output object the BMS will drive in service with the BCI2 Service Tool or Tracer TU. Schedule the unit with MO 7 Occupancy Request, set the mode with MO 8 and the space setpoint with AO 2. BAS sensor values must be rewritten within 900 s.

Enable & remote start

BO 1 System Control Command must be in service and Active (BAS Control); while Inactive the unit runs standalone and the BMS can only monitor. BI 1 System Control Status shows which is in charge. Most output objects ship with Out_of_Service = True, so the unit uses its local value; set Out_of_Service to False (BCI2 Service Tool Points screens or Tracer TU) on each output the BMS will write.

Heartbeat & communication loss

The BAS sensor outputs with a 900 s refresh rate (AO 10, 11, 14, 15, 18, 25) must be rewritten within that time. If not, the BCI2-R puts the object in fault and the unit falls back to its own sensor. At power-up these objects start in fault until the first write. Setpoint and command outputs have no refresh limit.

Sensors & values from the BMS

Write BMS sensor values to the '... BAS' AOs (AO 11 Space Temperature BAS, AO 14 Outdoor Air Temperature BAS, AO 15 Outdoor Air Humidity BAS, AO 18 Space CO2 Concentration BAS, AO 25 Space Humidity BAS, AO 10 Space Static Pressure BAS) with the object in service, and keep refreshing them. The matching '... Active' AIs show the value in use.

Network setup

  • BACnet MS/TP default baud is 76,800 bps. The MS/TP address is set at the factory and printed on a label on the board; valid 001-127 (1-999 on Air-Fi).
  • There are no rotary dials on the current board: change the address in the embedded BCI2 Service Tool (USB cable, browser at 198.80.18.1, Installation > Identification and Communication > Protocol Configuration) or with Tracer TU 11.6 or later.
  • The Device ID defaults to the address; tick 'Use Software Device ID' to set a different one. Tracer SC builds its own Device IDs (e.g. 101030).
  • Non-Trane front ends: Max Master (Max Requestor) must be higher than the card's address or it won't be discovered.
  • Device units default to SI after the point list is built; to switch to IP, clear the controller with the Modbus cable unplugged (or the unit powered down) so the units selection is enabled.
  • The card's clock resets to Jan 1 1970 after a power loss; send TimeSynchronization from the BMS periodically.

Watch out for

  • Writing an output object has no effect while it is Out of Service (the factory default); the unit keeps using its local value.
  • The point list is fixed at first power-up. After adding an option such as an economizer, clear the controller so it rebuilds the list.
  • BO 13 Filter Timer Reset and BO 14 Reset Diagnostic return to Inactive on their own after the reset.
  • The guide also names Discharge Air Temperature BAS, Duct Static Air Pressure BAS and Outdoor Airflow BAS as BAS sensor values, but no such objects are in the point tables.
  • BO 8 Supply Fan Configuration Command: Inactive = Auto (cycling), Active = On (continuous).

Integration notes

  • The tables have no read/write column. The guide states that output objects (AO/BO/MO) carry the BAS commands, setpoints and sensor values and input objects (AI/BI/MI) are status; its object-type table gives AO/BO/MO/AV a priority array, so those are marked commandable.
  • 'When exists' conditions from the doc (RTEM, RTAM, RTDM, RTOM, RTVM, VSM option modules, gas heat, heat pump) are shown in brackets in the descriptions where they fit.
  • Units are given as IP/SI pairs; the BCI2-R communicates in whichever system is set under its device units (SI by default after the point list is built).
  • BI 151 is 'Diagnostic: Drain Pan Overflow' in the diagnostics table but 'Diagnostic: External Auto-Stop' in the doc's alphabetical index; the table name is used here.
  • The card can run Trane Air-Fi wireless (addresses 1-999) instead of wired BACnet MS/TP.
  • The 'Diagnostic:' BIs carry a BACnet notification class (001 Critical, 002 Service Required, 003 Advisory, 004 Information) and send event notifications.

Check it against the live device. A points list tells you what the controller can expose; the unit in front of you may differ by firmware or installed options. Questions about the Trane BCI2-R (ReliaTel)

How many BACnet points does the Trane BCI2-R (ReliaTel) have?

This list has 250 BACnet objects: 60 analog inputs, 35 analog outputs, 1 analog value, 114 binary inputs, 13 binary outputs, 23 multi-state inputs, 4 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane BCI2-R (ReliaTel) BACnet points are writable?

53 of the 250 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Trane BCI2-R (ReliaTel) BACnet documentation?

The source is Integration Guide: BACnet Communication Interface for ReliaTel Controllers (BCI2-R) (BAS-SVP053A-EN), revision April 2022, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Integration/BAS-SVP053A-EN_04162022.pdf.

What are the minimum BACnet points to integrate the Trane BCI2-R (ReliaTel)?

Start with BO 1 System Control Command (Active = BAS control; Inactive = standalone, monitor only); MO 7 Occupancy Request (Occupancy command (1 = Occupied, 2 = Unoccupied)); MO 8 Heat Cool Mode Request BAS (Heat/cool mode command (1 = Auto)); AO 2 Space Temperature Setpoint BAS (Space setpoint; occupied/standby offsets apply to it); BI 1 System Control Status (Confirms the unit is under BAS control); MI 20 Occupancy Status (Confirms the occupancy the unit is running in); MI 19 Heat Cool Mode Status/ Application Mode Status (Current heat/cool operating mode); MI 41 Supply Fan Status (Supply fan on/off (2 = On)); AI 15 Space Temperature Active (Space temperature the unit is controlling to); BI 165 Alarm Relay Output Status (Unit alarm relay; Active = energized).

How do I enable BMS control of the Trane BCI2-R (ReliaTel)?

BO 1 System Control Command must be in service and Active (BAS Control); while Inactive the unit runs standalone and the BMS can only monitor. BI 1 System Control Status shows which is in charge. Most output objects ship with Out_of_Service = True, so the unit uses its local value; set Out_of_Service to False (BCI2 Service Tool Points screens or Tracer TU) on each output the BMS will write.

Does the Trane BCI2-R (ReliaTel) need a BACnet heartbeat or have a communication timeout?

The BAS sensor outputs with a 900 s refresh rate (AO 10, 11, 14, 15, 18, 25) must be rewritten within that time. If not, the BCI2-R puts the object in fault and the unit falls back to its own sensor. At power-up these objects start in fault until the first write. Setpoint and command outputs have no refresh limit.

Can the BMS supply sensor values to the Trane BCI2-R (ReliaTel)?

Write BMS sensor values to the '... BAS' AOs (AO 11 Space Temperature BAS, AO 14 Outdoor Air Temperature BAS, AO 15 Outdoor Air Humidity BAS, AO 18 Space CO2 Concentration BAS, AO 25 Space Humidity BAS, AO 10 Space Static Pressure BAS) with the object in service, and keep refreshing them. The matching '... Active' AIs show the value in use.

How do I check these points on the real BCI2-R (ReliaTel)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
