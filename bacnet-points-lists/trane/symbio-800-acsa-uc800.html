BMS integration notes: Trane Symbio 800 ACSA (UC800)

Integration in brief

Put the chiller on the network (BACnet MS/TP or IP), then write the auto/stop command, chilled water setpoint, demand limit and mode. Read back running state, leaving water temperature and capacity. Check the local-setpoint flag to confirm the BAS setpoints are actually in use. Most remaining objects are read-only status and per-alarm diagnostic flags.

Enable & remote start

MV 1 BAS Chiller Auto Stop Command (1 = Stop, 2 = Auto) is the BMS auto/stop; with it at Auto the chiller runs when its own run conditions are met. MI 7 External Auto Stop reports the hardwired external auto/stop input, and BI 1 Run Enable shows whether the chiller is enabled to run. The documents don't say how the two combine or how to hand setpoint control to the BAS; BI 2 Local Setpoint Control shows when the chiller is using local setpoints instead of BAS setpoints, and MI 5 Active Chilled Water Setpoint Source shows front panel, external, ice machine or BAS.

Heartbeat & communication loss

No timeout or heartbeat is described. The list includes the diagnostic flags BI 881 'BAS Communication Lost', BI 882 'BAS Failed to Establish Communication' and BI 600 'Comm Loss: Local BAS Interface'; the document doesn't say what timeout sets them or what the chiller does when they are set.

Network setup

  • With no protocol specified at order, the controller ships as BACnet MS/TP at 76,800 bps with the rotary address at 000, and MS/TP is disabled at 000. Set a rotary address of 001-127 to bring it online.
  • The rotary address sets the MS/TP MAC and the Device ID and takes effect without a power cycle. A software Device ID (1-4194302) can be set in the web UI, Tracer SC+ or Tracer TU.
  • The web UI is reached only over USB at http://198.80.18.1/; the Ethernet ports do not serve it.
  • BACnet IP uses Ethernet port 1 (or the optional USB Wi-Fi adapter); the default UDP port is 47808. Enable BBMD only if this is the only BACnet IP device on the subnet, then fill in the BDT.
  • MS/TP wiring lands on the P1 link; P2 and P3 are for factory devices only, and Ethernet port 2 is only for the touch-screen display.

Watch out for

  • Communicated units (I-P or SI) are fixed at the factory; changing them in the field needs a Trane representative. Web UI display units do not change the BACnet values.
  • Points that don't apply to the unit's configuration are absent, and a technician can 'recycle' (remove) factory points from the interface, so a missing object may have been recycled.
  • The chiller lists have no read/write column; writability of the AV/BV/MV objects is inferred from Trane's naming convention.
  • Diagnostic BIs are one object per alarm condition and only exist for the options fitted.
  • Auto/stop is a multistate value (MV 1: 1 = Stop, 2 = Auto), not a binary as on the standard Symbio 800 lists.
  • MI 4 Setpoint Source (BAS/Ext/FP, Ext/FP, Front Panel) decides which setpoint sources are allowed; it is read-only here.

Integration notes

  • Only the points that apply to the unit's factory configuration show up; the doc lists every possible point.
  • The chiller tables have no read/write column: AI/BI/MI are read-only, and AV/BV/MV are the BAS command and setpoint objects, marked writable here per Trane's naming convention.
  • Trane titles this list 'ACSA (UC800)' and does not explain the suffix in the document. This list uses short instance numbers (AI 1, AV 1, BI 506...) unlike the standard Symbio 800 lists with 5-digit instances, so check which list matches the controller on site.
  • The analog tables give the data type ('Real') instead of units, so units are left blank; the communicated unit system (I-P or SI) is set at the factory.
  • The diagnostic BIs (BI 506 and up) have no state text in the doc; several share a name without a circuit or compressor suffix (e.g. six 'Comm Loss: Compressor Fault Input').
  • MI 10 and MI 11 skip state 2 in the doc.
  • The Symbio 800 integration guide (BAS-SVP083) covers BACnet IP and BACnet MS/TP; the rotary address sets the MS/TP MAC and a default Device ID of 1-127, and a software Device ID can be set instead.
  • The same document also maps every object to a Modbus register; only the BACnet side is listed here.

Questions about the Trane Symbio 800 ACSA (UC800)

How many BACnet points does the Trane Symbio 800 ACSA (UC800) have?

This list has 342 BACnet objects: 58 analog inputs, 4 analog values, 260 binary inputs, 6 binary values, 11 multi-state inputs, 3 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 800 ACSA (UC800) BACnet points are writable?

13 of the 342 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Trane Symbio 800 ACSA (UC800) BACnet documentation?

The source is Symbio 800 Integration Points List BACnet - ACSA (UC800) (BAS-PTS026A-EN), revision 12/6/2024, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS026A-EN_12062024.pdf.
