BMS integration notes: Trane Symbio 800 IntelliPak

Integration in brief

Schedule the unit with MV 10106 Occupancy Request and write the BAS setpoints you need: space, discharge air, duct static. MI 10119 Arbitration Method must read 'Full (Auto) Source' for BAS values to win over local ones. Sensor BAS points and the External setpoints AV 10183-10187 carry a 900 s heartbeat in the points list, so rewrite them periodically.

Enable & remote start

The integration guide describes an arbitration method: with 'full/auto' the BMS value is used ahead of local or default values, and with 'local' BMS values are ignored. MI 10119 Arbitration Method (read-only) shows which is active; the documents don't name a BACnet point to change it. BI 10211 Equipment Stop Status reports stop/auto; no BAS start/stop command is listed.

Heartbeat & communication loss

The points list gives a 900 s heartbeat for the sensor BAS values (AV 10111, 10113-10116, 10118, 10119) and the External setpoints (AV 10183-10187). The Symbio 800 integration guide doesn't describe what happens when it expires.

Sensors & values from the BMS

Write BMS values to the '... BAS' AVs (AV 10114 Space Temperature BAS, AV 10113 Outdoor Air Temperature BAS, AV 10119 Space Humidity BAS, AV 10118 Space CO2 Concentration BAS, AV 10111 Discharge Air Temperature BAS). The '... Arbitrator' AVs show all sources in their priority array; the guide notes the default for sensor arbitrators is invalid, so the value must come from the BMS or a local sensor. Direct capacity/fan/damper control uses the 'Setpoint External' AVs together with their 'Setpoint Enable External' BVs (e.g. AV 10187 with BV 10131).

Network setup

  • With no protocol specified at order, the controller ships as BACnet MS/TP at 76,800 bps with the rotary address at 000, and MS/TP is disabled at 000. Set a rotary address of 001-127 to bring it online.
  • The rotary address sets the MS/TP MAC and the Device ID and takes effect without a power cycle. A software Device ID (1-4194302) can be set in the web UI, Tracer SC+ or Tracer TU.
  • The web UI is reached only over USB at http://198.80.18.1/; the Ethernet ports do not serve it.
  • BACnet IP uses Ethernet port 1 (or the optional USB Wi-Fi adapter); the default UDP port is 47808. Enable BBMD only if this is the only BACnet IP device on the subnet, then fill in the BDT.
  • MS/TP wiring lands on the P1 link; P2 and P3 are for factory devices only, and Ethernet port 2 is only for the touch-screen display.

Watch out for

  • Communicated units (I-P or SI) are fixed at the factory; changing them in the field needs a Trane representative. Web UI display units do not change the BACnet values.
  • Points that don't apply to the unit's configuration are absent, and a technician can 'recycle' (remove) factory points from the interface, so a missing object may have been recycled.
  • BI-11000 to BI-11999 are reserved for user-created diagnostic points made in Tracer TU.
  • Arbitrator objects show as writable but are meant to be read; write the matching '... BAS' object instead.

Integration notes

  • Only the points that apply to the unit's factory configuration show up; the doc lists every possible point.
  • Name suffixes carry meaning: Status/Local/Active/Input are read-only, BAS/Command/Request/Setpoint value objects are the ones a BAS writes, and Arbitrator objects show which source is winning.
  • BI-11000 to BI-11999 are reserved for user-created diagnostic points made in Tracer TU; they are not listed.
  • The Symbio 800 integration guide (BAS-SVP083) covers BACnet IP and BACnet MS/TP; the rotary address sets the MS/TP MAC and a default Device ID of 1-127, and a software Device ID can be set instead.
  • The same document also maps every object to a Modbus register; only the BACnet side is listed here.

Questions about the Trane Symbio 800 IntelliPak

How many BACnet points does the Trane Symbio 800 IntelliPak have?

This list has 380 BACnet objects: 184 analog inputs, 65 analog values, 83 binary inputs, 24 binary values, 18 multi-state inputs, 6 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 800 IntelliPak BACnet points are writable?

95 of the 380 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Trane Symbio 800 IntelliPak BACnet documentation?

The source is Symbio 800 Integration Points List BACnet/Modbus - IntelliPak (BAS-PTS003C-EN), revision 12/17/2025, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS003C-EN_12172025.pdf.

What are the minimum BACnet points to integrate the Trane Symbio 800 IntelliPak?

Start with MV 10106 Occupancy Request (Occupancy command from the BMS schedule); MV 10104 Heat Cool Mode Request (Mode command from the BMS); AV 10127 Space Temperature Setpoint BAS (Space setpoint from the BMS); AV 10121 Discharge Air Cooling Setpoint BAS (Supply air cooling setpoint from the BMS); AV 10143 Duct Static Pressure Setpoint BAS (Duct static setpoint on VAV units); MI 10119 Arbitration Method (Must read Full (Auto) for BAS values to be used); MI 10103 Occupancy Status (Confirms the occupancy in effect); BI 10226 Supply Fan Output Status (Supply fan running (1 = on)); AI 10124 Discharge Air Temperature (Supply air temperature in use (BAS or local sensor)); BI 10176 Diagnostic Present (Summary alarm).

How do I enable BMS control of the Trane Symbio 800 IntelliPak?

The integration guide describes an arbitration method: with 'full/auto' the BMS value is used ahead of local or default values, and with 'local' BMS values are ignored. MI 10119 Arbitration Method (read-only) shows which is active; the documents don't name a BACnet point to change it. BI 10211 Equipment Stop Status reports stop/auto; no BAS start/stop command is listed.

Does the Trane Symbio 800 IntelliPak need a BACnet heartbeat or have a communication timeout?

The points list gives a 900 s heartbeat for the sensor BAS values (AV 10111, 10113-10116, 10118, 10119) and the External setpoints (AV 10183-10187). The Symbio 800 integration guide doesn't describe what happens when it expires.

Can the BMS supply sensor values to the Trane Symbio 800 IntelliPak?

Write BMS values to the '... BAS' AVs (AV 10114 Space Temperature BAS, AV 10113 Outdoor Air Temperature BAS, AV 10119 Space Humidity BAS, AV 10118 Space CO2 Concentration BAS, AV 10111 Discharge Air Temperature BAS). The '... Arbitrator' AVs show all sources in their priority array; the guide notes the default for sensor arbitrators is invalid, so the value must come from the BMS or a local sensor. Direct capacity/fan/damper control uses the 'Setpoint External' AVs together with their 'Setpoint Enable External' BVs (e.g. AV 10187 with BV 10131).

How do I check these points on the real Symbio 800 IntelliPak?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
