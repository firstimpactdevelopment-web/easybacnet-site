BMS integration notes: Trane Symbio 800 RTAC (CH530)

Integration in brief

Put the chiller on the network (BACnet MS/TP or IP), then write the auto/stop command, chilled water setpoint, current limit and mode. Read back running state, leaving water temperature and capacity. Check the local-setpoint flag to confirm the BAS setpoints are actually in use. The alarm-present flag gives a single summary alarm.

Enable & remote start

BO 1 Chiller Auto Stop Command (Inactive = Stop, Active = Auto) is the BMS auto/stop; its relinquish default is True (Auto). BI 1 Run Enabled shows whether the chiller is available to run. The document doesn't say how to hand setpoint control to the BAS; BI 2 Local Setpoint Control shows when the chiller is using local setpoints instead of BAS setpoints.

Network setup

  • With no protocol specified at order, the controller ships as BACnet MS/TP at 76,800 bps with the rotary address at 000, and MS/TP is disabled at 000. Set a rotary address of 001-127 to bring it online.
  • The rotary address sets the MS/TP MAC and the Device ID and takes effect without a power cycle. A software Device ID (1-4194302) can be set in the web UI, Tracer SC+ or Tracer TU.
  • The web UI is reached only over USB at http://198.80.18.1/; the Ethernet ports do not serve it.
  • BACnet IP uses Ethernet port 1 (or the optional USB Wi-Fi adapter); the default UDP port is 47808. Enable BBMD only if this is the only BACnet IP device on the subnet, then fill in the BDT.
  • MS/TP wiring lands on the P1 link; P2 and P3 are for factory devices only, and Ethernet port 2 is only for the touch-screen display.

Watch out for

  • Communicated units (I-P or SI) are fixed at the factory; changing them in the field needs a Trane representative. Web UI display units do not change the BACnet values.
  • Points that don't apply to the unit's configuration are absent, and a technician can 'recycle' (remove) factory points from the interface, so a missing object may have been recycled.
  • This list has no read/write column; writability of the command and setpoint objects is inferred from their object type and relinquish defaults.
  • Relinquish defaults: AO 1 44 °F (6.7 °C), AO 2 100 %, BO 1 Auto, BO 2 no reset, MO 1 Cool. Releasing BO 1 leaves the chiller in Auto.
  • MI 3 MP Communication Status is marked 'Do Not Use This Point' in the document.

Integration notes

  • Only the points that apply to the unit's factory configuration show up; the doc lists every possible point.
  • The tables have no read/write column: AI/BI/MI are read-only, and the AO/BO/MO objects (listed with a relinquish default) are the BAS setpoints and commands, marked writable here.
  • Units are listed as a quantity (Temperature, Pressure, Percent...); the actual engineering unit is the factory-configured I-P or SI set.
  • The Symbio 800 integration guide (BAS-SVP083) covers BACnet IP and BACnet MS/TP; the rotary address sets the MS/TP MAC and a default Device ID of 1-127, and a software Device ID can be set instead.
  • Trane titles this list 'RTAC (CH530)' and does not explain the suffix in the document. Its objects use short instance numbers (AI 1, BI 4...) instead of the 5-digit numbering in the standard Symbio 800 RTAC list (BAS-PTS023), so check which list matches the controller on site.
  • AI 52 is printed twice in the source (Oil Temp- Compressor 1A and Oil Temp- Compressor 1B); only the first is listed here. The RTAC (UC800) list numbers Oil Temp - Compressor 1B as AI 53, so the second entry is probably a misprint for AI 53.

Questions about the Trane Symbio 800 RTAC (CH530)

How many BACnet points does the Trane Symbio 800 RTAC (CH530) have?

This list has 86 BACnet objects: 60 analog inputs, 2 analog outputs, 14 binary inputs, 2 binary outputs, 7 multi-state inputs, 1 multi-state output. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 800 RTAC (CH530) BACnet points are writable?

5 of the 86 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Trane Symbio 800 RTAC (CH530) BACnet documentation?

The source is Symbio 800 Integration Points List BACnet - RTAC (CH530) (BAS-PTS031A-EN), revision 12/6/2024, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS031A-EN_12062024.pdf.
