Short answer

The Symbio 500 on commercial self-contained (SWUD) units exposes about 355 objects, including hardware AI/AO/BI/BO points. Writable setpoints are AVs and BVs with relinquish defaults, and the space temperature BAS value has a heartbeat. Points depend on the unit's control type (space or VAV), compressor and supply fan count, economizer and heat options.

BMS integration notes: Trane Symbio 500 Commercial Self-Contained (SWUD)

Integration in brief

In the Symbio UI (USB, http://198.80.18.1), use BAS Control Selection to set each sensor and setpoint to BAS or Local. Then schedule with MV 1 Occupancy Request, write the setpoint BAS AVs and use BV 329 Front Panel Auto Stop to run or stop the unit. MV 60/61/62 show whether each value is coming from the BAS, local or default.

Enable & remote start

BAS vs Local is chosen per sensor and setpoint with the BAS Control Selection tool in the Symbio UI. BV 329 Front Panel Auto Stop (Auto/Stop, relinquish default Stop) and BI 10 External Auto Stop Input Status cover unit start/stop. The documents don't spell out how those two interact.

Heartbeat & communication loss

Among the BAS inputs only AV 73 Space Temperature BAS lists a heartbeat (900 s) in the points list (AV 901 and AV 903-906 list 1); the documents don't describe what happens on expiry. BV 11 'Diagnostic: Space Temperature Source Failure' is the related alarm flag.

Sensors & values from the BMS

Set the sensor to BAS in BAS Control Selection, then write AV 73 Space Temperature BAS, AV 75 Outdoor Air Temperature BAS, AV 79 Space Humidity BAS or AV 81 Outdoor Air Humidity BAS. MV 62 Space Temperature Source Status shows BAS/Local/Default, and the 'Source Failure' BVs (BV 11-14, BV 42) flag a lost source.

Network setup

  • The three rotary switches set the MS/TP MAC and, by default, the Device ID. Use 001-120 on MS/TP (000 is reserved for Tracer SC+); IP or Zigbee units allow 001-999.
  • Set the rotary address before power-up; a change takes effect after a power cycle.
  • For a Device ID above 127, enable 'Use Software Device ID' in Symbio UI or Tracer TU (TU needs a power cycle); this disables the rotary method.
  • Saving protocol, IP or system-unit settings in Symbio UI restarts the controller, so the unit stops briefly.
  • System units (IP/SI) set in Symbio UI change the units sent over BACnet.

Watch out for

  • Only the points for the unit's options are present (control type, compressor and fan count, economizer, heat type).
  • AO/BO hardware outputs are read-only status in this list; command the unit through the BAS value objects.
  • AV 1 Occupied Cooling Setpoint and AV 2 Occupied Heating Setpoint are listed read-only; write AV 7 Space Temperature Setpoint BAS instead.
  • Tracer SC+ sets the software Device ID automatically during discovery; third-party systems must set it themselves.

Integration notes

  • Only the points that apply to the unit's factory configuration show up; the doc lists every possible point.
  • Name suffixes carry meaning: Status/Local/Active/Input are read-only, BAS/Command/Request/Setpoint value objects are the ones a BAS writes, and Arbitrator objects show which source is winning.
  • The Symbio 500 integration guide (BAS-SVP087) centers on BACnet MS/TP (rotary address 001-120) and also mentions BACnet IP connections.
  • BV 327 is printed with a garbled name ('Fixed Speed Compressor Rotate Schedul= BAS/Local'); it is kept as printed.

Questions about the Trane Symbio 500 Commercial Self-Contained (SWUD)

How many BACnet points does the Trane Symbio 500 Commercial Self-Contained (SWUD) have?

This list has 356 BACnet objects: 20 analog inputs, 12 analog outputs, 132 analog values, 22 binary inputs, 13 binary outputs, 113 binary values, 44 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 500 Commercial Self-Contained (SWUD) BACnet points are writable?

89 of the 356 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Trane Symbio 500 Commercial Self-Contained (SWUD) BACnet documentation?

The source is Symbio 500 Integration Point List BACnet - Commercial Self-Contained (SWUD*) (BAS-PTS038B-EN), revision 09/26/2025, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS038B-EN_09262025.pdf.

What are the minimum BACnet points to integrate the Trane Symbio 500 Commercial Self-Contained (SWUD)?

Start with MV 1 Occupancy Request (Occupancy command from the BMS schedule); BV 329 Front Panel Auto Stop (Auto/stop of the unit (relinquish default is Stop)); MV 3 Heat Cool Mode Request (Mode command from the BMS); AV 7 Space Temperature Setpoint BAS (Space setpoint from the BMS); AV 24 Discharge Air Cooling Setpoint BAS (Supply air cooling setpoint from the BMS); AV 91 Duct Static Pressure Setpoint BAS (Duct static setpoint from the BMS); MV 2 Occupancy Status (Confirms the occupancy in effect); BV 360 Supply Fan Calculated Status (Any supply fan running); AI 11 Discharge Air Temperature (Supply air temperature); MV 189 CSC Unit Status (Overall unit status: normal, off, warning, alarm, stops).

How do I enable BMS control of the Trane Symbio 500 Commercial Self-Contained (SWUD)?

BAS vs Local is chosen per sensor and setpoint with the BAS Control Selection tool in the Symbio UI. BV 329 Front Panel Auto Stop (Auto/Stop, relinquish default Stop) and BI 10 External Auto Stop Input Status cover unit start/stop. The documents don't spell out how those two interact.

Does the Trane Symbio 500 Commercial Self-Contained (SWUD) need a BACnet heartbeat or have a communication timeout?

Among the BAS inputs only AV 73 Space Temperature BAS lists a heartbeat (900 s) in the points list (AV 901 and AV 903-906 list 1); the documents don't describe what happens on expiry. BV 11 'Diagnostic: Space Temperature Source Failure' is the related alarm flag.

Can the BMS supply sensor values to the Trane Symbio 500 Commercial Self-Contained (SWUD)?

Set the sensor to BAS in BAS Control Selection, then write AV 73 Space Temperature BAS, AV 75 Outdoor Air Temperature BAS, AV 79 Space Humidity BAS or AV 81 Outdoor Air Humidity BAS. MV 62 Space Temperature Source Status shows BAS/Local/Default, and the 'Source Failure' BVs (BV 11-14, BV 42) flag a lost source.

How do I check these points on the real Symbio 500 Commercial Self-Contained (SWUD)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
