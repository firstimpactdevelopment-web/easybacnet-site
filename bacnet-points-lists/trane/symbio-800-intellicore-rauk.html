BMS integration notes: Trane Symbio 800 IntelliCore Split System (RAUK)

Integration in brief

Use BV 10140 Auto Stop Command BAS to run or stop the unit. On supply-air VAV or EVP units write AV 10121 Discharge Cooling Setpoint BAS; to limit capacity set AV 10163 Demand Limit Setpoint and turn on BV 10116 Demand Limit Request BAS. MI 10119 Arbitration Method must read Full Source for BAS values to be used. Sensor BAS points carry a 900 s heartbeat.

Enable & remote start

BV 10140 Auto Stop Command BAS (0 = Stop, 1 = Auto) is the BMS auto/stop. BI 10211 Equipment Stop Status reports the hardwired auto/stop input and BI 13000 Front Panel Auto Stop Status the local setting; BI 10210 shows an emergency stop that needs a manual reset. The integration guide describes the arbitration method: with Full the BMS value is used ahead of local or default values, with Local BMS values are ignored. MI 10119 Arbitration Method (read-only) shows which is active.

Heartbeat & communication loss

The points list gives a 900 s heartbeat for AV 10111 Discharge Temperature BAS and AV 10113 Outdoor Air Temperature BAS; the other AVs list 0. The documents don't describe what happens when it expires.

Sensors & values from the BMS

Write AV 10113 Outdoor Air Temperature BAS or AV 10111 Discharge Temperature BAS and keep refreshing them within the heartbeat. AV 10103 and AV 10101 (Arbitrator) show every source in their priority array, and AI 10118 Outdoor Air Temperature Active and AI 10124 Discharge Temperature show the value in use. The guide notes the default for sensor arbitrators is invalid, so the value must come from the BMS or a local sensor.

Network setup

  • With no protocol specified at order, the controller ships as BACnet MS/TP at 76,800 bps with the rotary address at 000, and MS/TP is disabled at 000. Set a rotary address of 001-127 to bring it online.
  • The rotary address sets the MS/TP MAC and the Device ID and takes effect without a power cycle. A software Device ID (1-4194302) can be set in the web UI, Tracer SC+ or Tracer TU.
  • The web UI is reached only over USB at http://198.80.18.1/; the Ethernet ports do not serve it.
  • BACnet IP uses Ethernet port 1 (or the optional USB Wi-Fi adapter); the default UDP port is 47808. Enable BBMD only if this is the only BACnet IP device on the subnet, then fill in the BDT.
  • MS/TP wiring lands on the P1 link; P2 and P3 are for factory devices only, and Ethernet port 2 is only for the touch-screen display.

Watch out for

  • Communicated units (I-P or SI) are fixed at the factory; changing them in the field needs a Trane representative. Web UI display units do not change the BACnet values.
  • Points that don't apply to the unit's configuration are absent, and a technician can 'recycle' (remove) factory points from the interface, so a missing object may have been recycled.
  • Arbitrator objects show as writable but are meant to be read; write the matching '... BAS' object instead.
  • AV 10139 Cooling Capacity Enable is also described as a BAS percentage that limits cooling capacity; the document doesn't say how it relates to AV 10163.
  • Points for circuit 2, extra compressors, the economizer and power monitoring only exist on the unit sizes and options that have them.

Integration notes

  • Only the points that apply to the unit's factory configuration show up; the doc lists every possible point.
  • Name suffixes carry meaning: Status/Local/Active/Input are read-only, BAS/Command/Request/Setpoint value objects are the ones a BAS writes, and Arbitrator objects show which source is winning.
  • Compressor run-time AIs (AI 10227, 10229...) report seconds to a third-party BAS and hours to Tracer SC+, per the source footnote; AI 10324-10329 give hours.
  • BI 10606 states are printed as '1 = No, 1 = Yes' in the source; BI 10605 uses 0 = No, 1 = Yes.
  • The Symbio 800 integration guide (BAS-SVP083) covers BACnet IP and BACnet MS/TP; the rotary address sets the MS/TP MAC and a default Device ID of 1-127, and a software Device ID can be set instead.
  • The same document also maps every object to a Modbus register; only the BACnet side is listed here.

Questions about the Trane Symbio 800 IntelliCore Split System (RAUK)

How many BACnet points does the Trane Symbio 800 IntelliCore Split System (RAUK) have?

This list has 136 BACnet objects: 70 analog inputs, 9 analog values, 40 binary inputs, 6 binary values, 10 multi-state inputs, 1 multi-state value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 800 IntelliCore Split System (RAUK) BACnet points are writable?

16 of the 136 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Trane Symbio 800 IntelliCore Split System (RAUK) BACnet documentation?
