BMS integration notes: Trane Symbio 500 Modular Self-Contained (SCWM)

Integration in brief

In the Symbio UI (USB, http://198.80.18.1), use BAS Control Selection to set each sensor and setpoint to BAS or Local. Then schedule with MV 1 Occupancy Request, write the setpoint BAS AVs and use BV 329 Front Panel Auto Stop to run or stop the unit. MV 60/61/62 show whether each value is coming from the BAS, local or default.

Enable & remote start

BAS vs Local is chosen per sensor and setpoint with the BAS Control Selection tool in the Symbio UI. BV 329 Front Panel Auto Stop (Auto/Stop, relinquish default Stop) and BI 10 External Auto Stop Input Status cover unit start/stop. The documents don't spell out how those two interact.

Heartbeat & communication loss

Only AV 77 Space Temperature BAS lists a heartbeat (900 s) in the points list; the other BAS points list 0. The documents don't describe what happens on expiry. BV 11 'Diagnostic: Space Temperature Source Failure' is the related alarm flag.

Sensors & values from the BMS

Set the sensor to BAS in BAS Control Selection, then write AV 77 Space Temperature BAS, AV 75 Outdoor Air Temperature BAS, AV 79 Space Humidity BAS or AV 81 Outdoor Air Humidity BAS. MV 62 Space Temperature Source Status shows BAS/Local/Default, and the 'Source Failure' BVs (BV 11-14, BV 42) flag a lost source.

Network setup

  • The three rotary switches set the MS/TP MAC and, by default, the Device ID. Use 001-120 on MS/TP (000 is reserved for Tracer SC+); IP or Zigbee units allow 001-999.
  • Set the rotary address before power-up; a change takes effect after a power cycle.
  • For a Device ID above 127, enable 'Use Software Device ID' in Symbio UI or Tracer TU (TU needs a power cycle); this disables the rotary method.
  • Saving protocol, IP or system-unit settings in Symbio UI restarts the controller, so the unit stops briefly.
  • System units (IP/SI) set in Symbio UI change the units sent over BACnet.

Watch out for

  • Only the points for the unit's options are present (compressor count, economizer, heat type).
  • AO/BO hardware outputs are read-only status in this list; command the unit through the BAS value objects.
  • Tracer SC+ sets the software Device ID automatically during discovery; third-party systems must set it themselves.

Questions about the Trane Symbio 500 Modular Self-Contained (SCWM)

How many BACnet points does the Trane Symbio 500 Modular Self-Contained (SCWM) have?

This list has 511 BACnet objects: 32 analog inputs, 17 analog outputs, 189 analog values, 30 binary inputs, 18 binary outputs, 178 binary values, 47 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 500 Modular Self-Contained (SCWM) BACnet points are writable?

111 of the 511 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Trane Symbio 500 Modular Self-Contained (SCWM) BACnet documentation?

The source is Symbio 500 Integration Point List BACnet - Modular Self-Contained (SCWM) (BAS-PTS037A-EN), revision 07/31/2025, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS037A-EN_07312025.pdf.

What are the minimum BACnet points to integrate the Trane Symbio 500 Modular Self-Contained (SCWM)?

Start with MV 1 Occupancy Request (Occupancy command from the BMS schedule); BV 329 Front Panel Auto Stop (Auto/stop of the unit (relinquish default is Stop)); AV 7 Space Temperature Setpoint BAS (Space setpoint from the BMS); AV 24 Discharge Air Cooling Setpoint BAS (Supply air cooling setpoint from the BMS); AV 91 Duct Static Pressure Setpoint BAS (Duct static setpoint from the BMS); MV 3 Heat Cool Mode Request (Mode command from the BMS); MV 2 Occupancy Status (Confirms the occupancy in effect); AI 11 Discharge Air Temperature (Supply air temperature); BV 360 Supply Fan Calculated Status (Fan status); MV 61 Space Temperature Setpoint Source Status (Shows if the BAS setpoint is the one in use).

How do I enable BMS control of the Trane Symbio 500 Modular Self-Contained (SCWM)?

BAS vs Local is chosen per sensor and setpoint with the BAS Control Selection tool in the Symbio UI. BV 329 Front Panel Auto Stop (Auto/Stop, relinquish default Stop) and BI 10 External Auto Stop Input Status cover unit start/stop. The documents don't spell out how those two interact.

Does the Trane Symbio 500 Modular Self-Contained (SCWM) need a BACnet heartbeat or have a communication timeout?

Only AV 77 Space Temperature BAS lists a heartbeat (900 s) in the points list; the other BAS points list 0. The documents don't describe what happens on expiry. BV 11 'Diagnostic: Space Temperature Source Failure' is the related alarm flag.

Can the BMS supply sensor values to the Trane Symbio 500 Modular Self-Contained (SCWM)?

Set the sensor to BAS in BAS Control Selection, then write AV 77 Space Temperature BAS, AV 75 Outdoor Air Temperature BAS, AV 79 Space Humidity BAS or AV 81 Outdoor Air Humidity BAS. MV 62 Space Temperature Source Status shows BAS/Local/Default, and the 'Source Failure' BVs (BV 11-14, BV 42) flag a lost source.
