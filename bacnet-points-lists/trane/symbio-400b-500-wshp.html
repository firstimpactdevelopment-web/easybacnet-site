BMS integration notes: Trane Symbio 400-B/500 Water-Source Heat Pump

Integration in brief

Set the rotary address, then use Symbio UI (USB, http://198.80.18.1) BAS Control Selection to pick BAS or Local for each sensor and setpoint. Schedule with MV 6 Occupancy Request, write AV 27 Space Temperature Setpoint BAS and MV 4 Heat Cool Mode Request, and put the BAS sensor objects in service and refresh them at least every 15 minutes.

Enable & remote start

The BAS controls the unit by writing values and putting points in or out of service. BAS Control Selection in Symbio UI chooses BAS or Local per sensor and setpoint. MV 9 Emergency Override BAS stops the unit for any value other than 1 = Normal, and AV 10 Compressor Enable BAS limits or disables compressor capacity.

Heartbeat & communication loss

BAS-supplied sensor objects (AV 14 Space Temperature BAS, AV 2 Space Humidity BAS, AV 4 Source Water Temperature BAS) must be rewritten at least every 15 minutes. If a write is not seen in time the object goes to fault and the unit uses its own sensor; at power-up they start in fault until written.

Sensors & values from the BMS

Put the BAS sensor objects in service (out of service by default), then write AV 14 Space Temperature BAS, AV 2 Space Humidity BAS and AV 4 Source Water Temperature BAS. AV 59, AV 6 and AV 5 show the value actually in use. AV 27 Space Temperature Setpoint BAS replaces the local setpoint while in service.

Network setup

  • Three rotary switches set the BACnet MAC address and Device ID; each controller on a link needs a unique value.
  • Symbio UI (USB only, http://198.80.18.1) sets protocol, IP, identification and system units; saving restarts the controller.
  • Tracer SC+ sets a software Device ID automatically during discovery; third-party systems must set it themselves.
  • System units (IP/SI) chosen in Symbio UI change the units sent over BACnet.

Watch out for

  • BAS sensor objects are out of service by default; put them in service before writing.
  • BV 2 Reset Diagnostic clears all diagnostics except Filter Change Required; BV 12 resets the filter timer.
  • Compressor failure diagnostics (BV 10, BV 15) auto-reset once; a repeat within 24 hours latches and needs a manual reset.
  • Only the points for the unit's options are present.

Integration notes

  • The guide's tables have no read/write column; access here is inferred (BAS, Request, Setpoint, Command, Enable and Reset values as writable; Active, Status and Diagnostic objects as read-only).
  • Points only exist when the unit has the matching option (2 compressors, electric heat, hot gas reheat, waterside economizer, variable-speed fan, leak detection).
  • BO 6 is Auxiliary Heat Command on electric heat units and Dehumidification Output on hot gas reheat units.
  • AV 68 is also printed as 'Space Relative Humidity Offset' in one table.
  • The alarm object table (Table 11) mostly matches the main tables but names BI 4 Frost Detection Input, BV 5 Low Coil Temperature Detect, BV 7 Freeze Avoidance Mode and MI 4 IMC Status; the main object tables are used here.
  • The protocol list in Symbio UI includes BACnet IP, but the guide only describes BACnet MS/TP addressing; the 400-B needs a CM2 module for an Ethernet port.

How many BACnet points does the Trane Symbio 400-B/500 Water-Source Heat Pump have?

Which Trane Symbio 400-B/500 Water-Source Heat Pump BACnet points are writable?

51 of the 102 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
