BMS integration notes: Trane Symbio 700 Precedent / Axiom

Integration in brief

Leave MV 11100 Arbitration Method Request at 'Enable External/BAS Control'. Then schedule the unit with MV 10106 Occupancy Request and send setpoints to the commandable setpoint BAS points at a priority above 14. If the BMS supplies sensor values such as space temperature, rewrite the '... BAS' points at least every 15 minutes, or the controller drops back to its own sensors.

Enable & remote start

MV 11100 Arbitration Method Request picks the control type. 'Enable External/BAS Control' is the factory default: the controller weighs BAS, Air-Fi and wired sources and uses the BAS value while it is valid. 'Standalone Control' ignores all BAS input. BV 11113 Unit Stop Command (Auto/Stop) stops the unit from the BMS.

Heartbeat & communication loss

The sensor BAS points (space temp, OA temp, humidity, CO2, return air) have a 900 s heartbeat in the points list. Per the integration guide, a BAS sensor or setpoint value that is not rewritten at least every 15 minutes fails. Its priority-12 entry then drops out of the Arbitrator and the controller falls back to the next source (Air-Fi, wired, then default). BV 10113 Occupancy Input BAS has the same 15-minute heartbeat; MV 10106 Occupancy Request has none.

Sensors & values from the BMS

Write the value to the matching '... BAS' AV (e.g. AV 10114 Space Temperature BAS, AV 10113 Outdoor Air Temperature BAS) and keep refreshing it. It shows on the '... Arbitrator' object at priority 12, above Air-Fi (14) and wired (15). The '... Active' object reports the value in use. Space setpoints go to AV 10127 Space Temperature Setpoint BAS (single setpoint) or AV 10159/10160 Occupied Cooling/Heating Setpoint BAS (dual setpoint).

Network setup

  • The rotary address (001-127) sets the BACnet MS/TP MAC and also the Device ID; changing it takes effect without a power cycle.
  • A software Device ID (1-4194302) can be set in the Symbio Service and Installation mobile app (Bluetooth) or on the onboard display.
  • MS/TP default baud is 76,800 bps; MS/TP wiring lands on connector J17.
  • For BACnet IP set the IP address first, then the protocol, Device ID and UDP port; tick BBMD only if this is the only BACnet IP device on the subnet.
  • Communicated units can be switched between IP and SI in the mobile app or onboard display; display units are separate.

Watch out for

  • Space setpoint BAS points are commandable: the wired setpoint sits at priority 15 and Air-Fi at 14, so the BMS must write at a priority above 14 or the value is ignored.
  • Setpoints changed from the onboard display or mobile app go to the relinquish default, not the priority array; that value is only used when no other valid source exists.
  • Use either BV 10113 Occupancy Input BAS (needs heartbeat) or MV 10106 Occupancy Request (no heartbeat), not both.
  • Arbitrator objects are for reading only, even though they show as writable.
  • 'Command' points may be persisted once written, so don't write them cyclically.

Integration notes

  • Only the points that apply to the unit's factory configuration show up; the doc lists every possible point.
  • Name suffixes carry meaning: Status/Local/Active/Input are read-only, BAS/Command/Request/Setpoint value objects are the ones a BAS writes, and Arbitrator objects show which source is winning.
  • Access 'C' marks objects whose arbitration pattern the doc lists as setpoint with a priority array.
  • The Symbio 700 integration guide (BAS-SVP085) covers BACnet IP and BACnet MS/TP; the rotary address (001-127) sets the MS/TP MAC and the default Device ID, and a software Device ID can be set instead.

Questions about the Trane Symbio 700 Precedent / Axiom

How many BACnet points does the Trane Symbio 700 Precedent / Axiom have?

This list has 639 BACnet objects: 53 analog inputs, 294 analog values, 119 binary inputs, 131 binary values, 8 multi-state inputs, 34 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Trane Symbio 700 Precedent / Axiom BACnet points are writable?

232 of the 639 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Trane Symbio 700 Precedent / Axiom BACnet documentation?

The source is Symbio 700 Integration Points List BACnet/Modbus - Precedent, Axiom Rooftop WSHP (BAS-PTS001C-EN), revision 08/12/2026, published free by Trane at https://elibrary.tranetechnologies.com/public/commercial-hvac/Literature/Points%20List/BAS-PTS001C-EN_08172026.pdf.

What are the minimum BACnet points to integrate the Trane Symbio 700 Precedent / Axiom?

Start with MV 10106 Occupancy Request (Occupancy command (occupied/unoccupied/standby)); BV 11113 Unit Stop Command (BMS stop/auto of the whole unit); AV 10159 Occupied Cooling Setpoint BAS (Occupied cooling setpoint (dual-setpoint units)); AV 10160 Occupied Heating Setpoint BAS (Occupied heating setpoint (dual-setpoint units)); AV 10127 Space Temperature Setpoint BAS (Single-setpoint alternative to the two setpoints above); MI 10101 Heat Cool Mode Status (Current heat/cool operating mode); MV 11123 Occupancy Status (Confirms the occupancy the unit is running in); BI 10226 Supply Fan Status (Supply fan on/off status); AV 11178 Space Temperature Active (Space temperature the unit is actually controlling to); BV 11100 Alarm Indicator Status (Unit alarm output; on when the controller is in alarm).

How do I enable BMS control of the Trane Symbio 700 Precedent / Axiom?

MV 11100 Arbitration Method Request picks the control type. 'Enable External/BAS Control' is the factory default: the controller weighs BAS, Air-Fi and wired sources and uses the BAS value while it is valid. 'Standalone Control' ignores all BAS input. BV 11113 Unit Stop Command (Auto/Stop) stops the unit from the BMS.

Does the Trane Symbio 700 Precedent / Axiom need a BACnet heartbeat or have a communication timeout?

The sensor BAS points (space temp, OA temp, humidity, CO2, return air) have a 900 s heartbeat in the points list. Per the integration guide, a BAS sensor or setpoint value that is not rewritten at least every 15 minutes fails. Its priority-12 entry then drops out of the Arbitrator and the controller falls back to the next source (Air-Fi, wired, then default). BV 10113 Occupancy Input BAS has the same 15-minute heartbeat; MV 10106 Occupancy Request has none.

Can the BMS supply sensor values to the Trane Symbio 700 Precedent / Axiom?

Write the value to the matching '... BAS' AV (e.g. AV 10114 Space Temperature BAS, AV 10113 Outdoor Air Temperature BAS) and keep refreshing it. It shows on the '... Arbitrator' object at priority 12, above Air-Fi (14) and wired (15). The '... Active' object reports the value in use. Space setpoints go to AV 10127 Space Temperature Setpoint BAS (single setpoint) or AV 10159/10160 Occupied Cooling/Heating Setpoint BAS (dual setpoint).

How do I check these points on the real Symbio 700 Precedent / Axiom?
