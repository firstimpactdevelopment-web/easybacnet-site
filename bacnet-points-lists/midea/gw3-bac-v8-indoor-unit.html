Midea GW3-BAC gateway - V8 VRF indoor unit device BACnet points list

Updated 11 November 2026

Short answer

The Midea GW3-BAC gateway serves V8 VRF systems on BACnet IP and creates one virtual BACnet device per indoor unit. Each indoor-unit device has 46 objects: on/off and fault status, mode, fan speed, setpoints (single and auto dual), room temperature, error code, swing, setpoint limits, locks, coil temperatures and EXV opening, plus AO/BO commands for mode, setpoints, fan, swing, limits and locks.

BMS integration notes: Midea GW3-BAC gateway - V8 VRF indoor unit device

Integration in brief

Wire the V8 outdoor units' X/Y/E terminals to one of the gateway's RS-485 ports, set the BACnet setting on the gateway web page, then discover one BACnet IP device per indoor unit and use AO 1 for on/off and mode, AO 2 for the setpoint and AO 5 for fan speed.

Enable & remote start

No enable point; AO 1 Ajuste del modo turns the unit on (239) or off (240).

Network setup

  • Gateway default IP 192.168.1.8; configure it on the gateway web page (PC on the same subnet).
  • BACnet UDP port default 47808 (1-65534).
  • Three isolated RS-485 ports (X0Y0E, X1Y1E, X2Y2E), each for up to 8 V8 refrigerant systems; 64 indoor units max.

Watch out for

  • Send commands no faster than every 500 ms; the internal command queue can fill and drop commands.
  • In auto mode the unit uses AO 3/AO 4 (cool/heat setpoints); in other modes AO 2.
  • Writing a mode or value the indoor unit does not support gives unpredictable results.

Integration notes

  • The manual is in Spanish; object names and state texts are kept as printed. The device may report different (for example English) names.
  • Every VRF unit is its own virtual BACnet device. Device ID = ABCDEFG: ABC = gateway BACnet setting (2-400), D = RS-485 port (0-2), E = refrigerant system (0-7), FG = unit address (indoor 0-63, outdoor 96-99). Example: 192405 = setting 19, port 2, system 4, indoor unit 05.
  • No units are given in the manual.
  • The manual describes inputs as read-only and outputs as write-only; no priority array is documented.
  • AO 1 Ajuste del modo also turns the unit on (239) or off (240). AO 15 is printed as SetLimtUDSwing on its detail page (SetLimitUDSwing in the object list).

Questions about the Midea GW3-BAC gateway - V8 VRF indoor unit device

How many BACnet points does the Midea GW3-BAC gateway - V8 VRF indoor unit device have?

This list has 46 BACnet objects: 23 analog inputs, 15 analog outputs, 6 binary inputs, 2 binary outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Midea GW3-BAC gateway - V8 VRF indoor unit device BACnet points are writable?

17 of the 46 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Midea GW3-BAC gateway - V8 VRF indoor unit device BACnet documentation?

The source is Manual de instalación y del usuario - Pasarela GW3-BAC (Spanish), revision 2024-04 (240417), published free by Midea at https://www.midea.es/wp-content/uploads/2024/04/240417_MI-MU_M_CTR_GW3-BAC-ES.pdf.

What are the minimum BACnet points to integrate the Midea GW3-BAC gateway - V8 VRF indoor unit device?

Start with AO 1 Ajuste del modo (On (239), off (240), auto (241) or mode); AO 2 Ajuste del punto de consigna (Setpoint command); AO 5 Ajuste del ventilador (Fan speed 1-7, 241 = auto); BI 1 Estado de encendido/apagado (Run status); AI 1 Modo (Operating mode (read with BI 3 auto flag)); AI 3 Punto de consigna (Setpoint in use); AI 6 Temperatura ambiente (Indoor room temperature); BI 2 Indicación de alarma (Unit fault); AI 7 Código de avería (Encoded error code).

How do I enable BMS control of the Midea GW3-BAC gateway - V8 VRF indoor unit device?

No enable point; AO 1 Ajuste del modo turns the unit on (239) or off (240).
