Short answer

GOLD generation C/D air handlers have a BACnet IP driver built into the unit controller (program version 6.08), acting as a B-ASC; no gateway is needed. The list covers fan airflows, pressures, levels and power, temperatures and regulator setpoints, heat exchanger and coil data, accessory functions (Xzone, ReCO2, AYC, MIRU, Blue Box, steam humidifier), time and year channels, one binary input per alarm and info number, and calibration commands. The BMS starts, stops and selects speed through one analog value.

BMS integration notes: Swegon GOLD generation C/D (RX/PX/CX/SD) BACnet IP

Integration in brief

Command the unit with AV 174 Communication operation mode (0 = Auto lets the time channels run it; 1-4 force stop or low/high speed) and read back AI 84 Operation mode 1 plus the low/high speed BIs. Adjust the main temperature setpoints (AV 40 supply, AV 41 extract/room) and the low/high speed airflow or pressure setpoints, and monitor BI 5/BI 6 for A/B alarms with BV 0 to reset. Page 3 of the guide lists these as the key points.

Enable & remote start

AV 174 Communication operation mode: 0=Auto (normal stop when the time channels are deactivated), 1=Communication stop 1, 2=Communication low speed, 3=Communication high speed, 4=Communication stop 2 (PV 5.00 or later; intermittent night heat and morning boost still work). AI 84 Operation mode 1 shows whether the unit is stopped or running from the hand terminal, an external input, communication or a time/year channel.

Sensors & values from the BMS

Room temperature can come from the BMS: set AV 200 EA/Room temperature external func. to 2 (Communication) and write AV 201. Outdoor temperature works the same with AV 202 = 2 and AV 203. AV 204 sets the timeout for these communicated temperatures.

Network setup

  • BACnet IP only; the device is a B-ASC. Swegon also publishes a BACnet PICS and an EDE file for GOLD.
  • Device instance and IP settings are not given in this document.

Watch out for

  • Setpoints are split by low and high speed (e.g. AV 0/1 SA airflow, AV 8/9 SA duct pressure); write the one for the active speed.
  • BV 42-73 start pressure-sensor zero calibration or set it to manual mode; do not write them from routine BMS logic.
  • Many objects only mean something when the related accessory or heat exchanger type (RX/PX/CX/SD) is installed.
  • The time channel status objects (AV 130, 135, ... 165) use 0-10 for low speed days and 16-26 for high speed days.

Questions about the Swegon GOLD generation C/D (RX/PX/CX/SD) BACnet IP

How many BACnet points does the Swegon GOLD generation C/D (RX/PX/CX/SD) BACnet IP have?

This list has 852 BACnet objects: 267 analog inputs, 462 analog values, 52 binary inputs, 69 binary values, 2 notification classs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Swegon GOLD generation C/D (RX/PX/CX/SD) BACnet IP BACnet points are writable?

531 of the 852 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Swegon GOLD generation C/D (RX/PX/CX/SD) BACnet IP BACnet documentation?

The source is BACnet IP GOLD RX/PX/CX/SD, Generation C/D (program version 6.08) (GB.BACnet480.121017), published free by Swegon at https://www.swegon.com/siteassets/_products-documents-archive/air-handling-units/gold-version-d-2010-2013/communication/_en/bacnet480.6.08.pdf.

What are the minimum BACnet points to integrate the Swegon GOLD generation C/D (RX/PX/CX/SD) BACnet IP?

Start with AV 174 Communication operation mode (BMS stop / low / high speed command (0 = Auto)); AV 40 SA Temperature setpoint (Supply air temperature setpoint); AV 41 EA/Room Temperature setpoint (Extract/room temperature setpoint); BV 0 Alarm reset (Resets alarms); AI 84 Operation mode 1 (Actual operating mode and what stopped the unit); AI 27 SA Temperature (Supply air temperature); AI 28 EA/Room temperature (Extract/room temperature); AI 29 Outdoor temperature (Outdoor air temp measured by the unit, °C); BI 5 A-alarm. (Any A-class alarm); BI 6 B-alarm. (Any B-class alarm).

How do I enable BMS control of the Swegon GOLD generation C/D (RX/PX/CX/SD) BACnet IP?

AV 174 Communication operation mode: 0=Auto (normal stop when the time channels are deactivated), 1=Communication stop 1, 2=Communication low speed, 3=Communication high speed, 4=Communication stop 2 (PV 5.00 or later; intermittent night heat and morning boost still work). AI 84 Operation mode 1 shows whether the unit is stopped or running from the hand terminal, an external input, communication or a time/year channel.

Can the BMS supply sensor values to the Swegon GOLD generation C/D (RX/PX/CX/SD) BACnet IP?

Room temperature can come from the BMS: set AV 200 EA/Room temperature external func. to 2 (Communication) and write AV 201. Outdoor temperature works the same with AV 202 = 2 and AV 203. AV 204 sets the timeout for these communicated temperatures.
