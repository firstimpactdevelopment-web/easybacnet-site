Swegon SuperWISE (generation 1) BACnet IP - system objects BACnet points list

Updated 7 November 2026

Short answer

SuperWISE gen 1 is the system controller of Swegon's WISE demand-controlled ventilation system and acts as a BACnet IP server (B-ASC) on its Ethernet port. Its EDE workbook gives fixed system objects (instances 65000 and up): summed supply/extract airflow per zone, the duct-pressure optimisation link to the GOLD air handler, demand flags, alarms, clock and commands. Room, damper and router objects come from per-product sheets whose instances are calculated from the zone, damper and room numbers.

This page lists 81 BACnet objects for the Swegon SuperWISE (generation 1) BACnet IP - system objects — 32 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Swegon’s own free documentation, linked below.

BMS integration notes: Swegon SuperWISE (generation 1) BACnet IP - system objects

Integration in brief

Read the per-zone summed airflows and SumAlarm (AI 65101) and the cooling/heating demand flags. The AV 65200 range is the pressure-optimisation link with the air handler: the AHU (or BMS) writes the real SA/EA pressures and running state, and SuperWISE returns the requested pressures (AI 65041/65042).

Enable & remote start

BACnet IP must be switched on in the SuperWISE Admin/Misc tab before the objects respond.

Network setup

  • BACnet IP on the Ethernet port (E), directly or through a switch; settings in SuperWISE Admin/Misc.
  • Read input register (relative address 2) of a room controller to see which product sheet applies (8 CONTROL Za, 13 Router, 6 CONTROL Ra A3, 10 W4, 1 W3, 2 W1, 11/12/15 ADAPT).

Watch out for

  • AlarmReset, RC_ForceScan and Reboot (AV 65221/65224/65225) are one-shot commands; AV 65225 = 1 reboots the server.
  • AlarmClear (AV 65242) can delete the alarm history; 2 clears all.

Integration notes

  • Taken from the LOCAL sheet of SuperWISE_BACnet_list_ver_1.3.xls in Swegon's SuperWISE gen 1 BACnet zip (EDE layout). The sheet gives no settable column, so access is inferred: AVs as writable, AIs as read-only.
  • The workbook's per-product sheets (CONTROL Za, Router, CONTROL Ra A3/A4, W1/W3/W4, ADAPT Master/Slave/WBCS, A1) calculate instances from zone (0-9), damper or branch (1-8) and room (1-60) numbers; those objects are not listed here.
  • The Optimize sheet in the same workbook repeats some LOCAL objects but shows CoolDemandFlag/HeatDemandFlag at 65054/65055 instead of 65055/65056; the LOCAL sheet values are used.
  • AI and AV objects share some instance numbers (65000-65005); they are different objects.

Questions about the Swegon SuperWISE (generation 1) BACnet IP - system objects

How many BACnet points does the Swegon SuperWISE (generation 1) BACnet IP - system objects have?

This list has 81 BACnet objects: 49 analog inputs, 32 analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Swegon SuperWISE (generation 1) BACnet IP - system objects BACnet points are writable?

32 of the 81 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Swegon SuperWISE (generation 1) BACnet IP - system objects BACnet documentation?

The source is SuperWISE BACnet list ver 1.3 (BACnet IP, Super WISE program version 1.25), in SuperWISE BACnet PICS gen 1 zip (GB.BACnetSuper WISE.140603), revision 2014-06-03, published free by Swegon at https://www.swegon.com/siteassets/_products-documents-archive/flow-control/wise/_multi/superwise-bacnet-pics_gen1.zip.

What are the minimum BACnet points to integrate the Swegon SuperWISE (generation 1) BACnet IP - system objects?

Start with AV 65215 WISE_DriftON (Write 1 while the AHU runs, 0 when stopped); AV 65216 WISE_FireAlarm (Fire alarm; 1 forces all regulators to emergency mode); AV 65200 WISE_SA_Pa (Real supply duct pressure from the AHU, Pa); AV 65201 WISE_EA_Pa (Real extract duct pressure from the AHU, Pa); AV 65221 AlarmReset (Alarm reset (returns to 0)); AI 65041 WISE_SA_ForcPa (Requested supply duct pressure for the AHU, Pa); AI 65042 WISE_EA_ForcPa (Requested extract duct pressure for the AHU, Pa); AI 65055 CoolDemandFlag (Any room needs cooling); AI 65056 HeatDemandFlag (Any room needs heating); AI 65101 SumAlarm (Any active alarm).

How do I enable BMS control of the Swegon SuperWISE (generation 1) BACnet IP - system objects?

BACnet IP must be switched on in the SuperWISE Admin/Misc tab before the objects respond.
