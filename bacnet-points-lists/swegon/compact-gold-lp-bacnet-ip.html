Swegon Compact / GOLD LP BACnet IP (PV 2.01+) BACnet points list

Updated 16 October 2026

Short answer

Swegon's Compact and GOLD LP air handlers have a built-in BACnet IP interface (B-ASC profile) on the unit controller. The list has 600 objects of four types: analog inputs for airflows, pressures, temperatures and operating modes, analog values for setpoints, regulator tuning, clock and time/year channels, plus binary inputs and values for outputs, alarms and functions. Several numbered 'Reserve' objects are placeholders.

This page lists 600 BACnet objects for the Swegon Compact / GOLD LP BACnet IP (PV 2.01+) — 401 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Swegon’s own free documentation, linked below.

BMS integration notes: Swegon Compact / GOLD LP BACnet IP (PV 2.01+)

Integration in brief

Write AV-174 Communication operation mode to run the unit from the BMS (0 hands control back to the unit's own time channels) and read AI-84 Operation mode 1 to see why it is running or stopped. Map supply and extract air temperature, the EA/room setpoint and the low/high speed airflow or pressure setpoints, plus BI-5/BI-6 A/B alarms and BV-0 alarm reset. These are the objects the source's overview page highlights.

Enable & remote start

AV-174 Communication operation mode: 0=Auto operation, 1=Communication stop 1, 2=Communication low speed, 3=Communication high speed, 4=Communication stop 2. Summer night cool, intermittent night heat and morning boost still run at stop 2.

Heartbeat & communication loss

Only for BMS-supplied temperatures: AV-204 'Timeout temperature com.' (0-9999 min) sets the timeout for room and outdoor temperatures written over communication. The document does not describe a timeout for the operation mode command.

Sensors & values from the BMS

Set AV-200 EA/Room temperature (external) func. to 2 (Communication) and write AV-201; set AV-202 Outdoor temperature (external) func. to 2 and write AV-203. AV-204 is the timeout for those written values.

Network setup

  • BACnet IP only; the device is a B-ASC supporting read/write property, COV and dynamic device/object binding.
  • Swegon refers to a separate BACnet PICS and EDE file; device instance and IP settings are not in this document.

Watch out for

  • Setpoints exist separately for low and high speed (e.g. AV-0/1 SA airflow, AV-8/9 SA duct pressure).
  • Fan regulation mode (AV-97 SA, EA equivalent) decides whether airflow, pressure or demand setpoints are used.
  • Clock, time-channel and year-channel AVs (around 120-290) are configuration settings.
  • Reserve objects return no meaningful data.

Integration notes

  • Only AI, AV, BI and BV objects are used; modes and selections are AVs with numbered states.
  • Instances are not contiguous and 'Reserve' objects carry no data.
  • Units are taken from the Min/Max column (l/s, Pa, °C, %, s, min); unitless ranges are left blank.
  • Operating state is reported as codes in AI-84 Operation mode 1 and AI-85 Operation mode 2.

Questions about the Swegon Compact / GOLD LP BACnet IP (PV 2.01+)

How many BACnet points does the Swegon Compact / GOLD LP BACnet IP (PV 2.01+) have?

This list has 600 BACnet objects: 143 analog inputs, 367 analog values, 56 binary inputs, 34 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Swegon Compact / GOLD LP BACnet IP (PV 2.01+) BACnet points are writable?

401 of the 600 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Swegon Compact / GOLD LP BACnet IP (PV 2.01+) BACnet documentation?

The source is BACnet IP Compact/GOLD LP, program version 2.01 and newer versions (GB.BACnet480.100129), revision 2010-01-29, published free by Swegon at https://www.swegon.com/globalassets/digizuite/11562-en-compactair_bacnet480_other_en.pdf.

What are the minimum BACnet points to integrate the Swegon Compact / GOLD LP BACnet IP (PV 2.01+)?

Start with AV 174 Communication operation mode (BMS stop / low / high / auto command); AI 84 Operation mode 1 (Current operating reason (stop, speed, channel)); AI 27 SA Temperature (Supply air temperature); AI 28 EA/Room temperature (Extract/room temperature); AV 41 EA/Room Temperature setpoint (Main temperature setpoint); AI 29 Outdoor temperatur (Outdoor temperature); BI 5 A-alarm. (A-class alarm active); BI 6 B-alarm. (B-class alarm active); BV 0 Alarm reset (Resets tripped alarms).

How do I enable BMS control of the Swegon Compact / GOLD LP BACnet IP (PV 2.01+)?

AV-174 Communication operation mode: 0=Auto operation, 1=Communication stop 1, 2=Communication low speed, 3=Communication high speed, 4=Communication stop 2. Summer night cool, intermittent night heat and morning boost still run at stop 2.

Does the Swegon Compact / GOLD LP BACnet IP (PV 2.01+) need a BACnet heartbeat or have a communication timeout?

Only for BMS-supplied temperatures: AV-204 'Timeout temperature com.' (0-9999 min) sets the timeout for room and outdoor temperatures written over communication. The document does not describe a timeout for the operation mode command.

Can the BMS supply sensor values to the Swegon Compact / GOLD LP BACnet IP (PV 2.01+)?

Set AV-200 EA/Room temperature (external) func. to 2 (Communication) and write AV-201; set AV-202 Outdoor temperature (external) func. to 2 and write AV-203. AV-204 is the timeout for those written values.
