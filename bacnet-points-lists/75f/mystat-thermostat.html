BMS integration notes: 75F MyStat thermostat (BACnet MS/TP server)

Integration in brief

Set MV 0 Conditioning Mode and MV 1 Fan Speed, write the heating/cooling setpoints AV 0/AV 1 (2 x °F) and BV 11 for occupancy, then read MI 0/MI 2 status and AI 0-2 room values.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

MV 0 Conditioning Mode sets off/auto/heating/cooling; BV 11 Unoccupied Mode switches between occupied and unoccupied.

Network setup

  • Comm Options page: protocol BACnet, address 5 (default), baud 9600 (9600-115200), no parity, 1 stop bit, Max Master 32, Max Info Frames 3.
  • The Device ID must be unique in the BACnet system.

Watch out for

  • Written values persist in memory; avoid cyclic writes of configuration objects.
  • Keep temperature writes inside the configured min/max limits and deadbands.

Integration notes

  • From the help-centre article "MyStat as a BACnet Server" (updated 2026-09-18) and its attachment BACnet_Mapping_MyStat__.xlsx.
  • The sheet has no access column; inputs (AI/BI/MI) are listed read-only and values (AV/BV/MV) writable. The article says read/write access depends on the object and configuration.
  • Many values are scaled integers: temperatures in 1/10 °F, setpoints as 2 x °F (120-180 = 60.0-90.0 °F).
  • Relay, analog output and universal input mapping MVs list their options without numbers.
  • BACnet-written values are kept through reboots and power cycles.

Questions about the 75F MyStat thermostat (BACnet MS/TP server)

How many BACnet points does the 75F MyStat thermostat (BACnet MS/TP server) have?

This list has 117 BACnet objects: 21 analog inputs, 53 analog values, 10 binary inputs, 17 binary values, 4 multi-state inputs, 12 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which 75F MyStat thermostat (BACnet MS/TP server) BACnet points are writable?

82 of the 117 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official 75F MyStat thermostat (BACnet MS/TP server) BACnet documentation?

The source is MyStat as a BACnet Server (with BACnet_Mapping_MyStat__.xlsx), revision 2026-09-18, published free by 75F at https://support.75f.io/hc/en-us/articles/51942488899347.

What are the minimum BACnet points to integrate the 75F MyStat thermostat (BACnet MS/TP server)?

Start with MV 0 Conditioning Mode (Mode: 0 off, 1 auto, 2 heating, 3 cooling); MV 1 Fan Speed (Fan: 0 off, 1 auto, 2 low, 3 medium, 4 high); BV 11 Unoccupied Mode (0 occupied, 1 unoccupied); AV 0 Set Temperature Heating (Heating setpoint, value = 2 x °F); AV 1 Set Temperature Cooling (Cooling setpoint, value = 2 x °F); MI 0 Operating Mode (Actual: off, heating, cooling); MI 2 Active Fan Speed (Actual fan speed); AI 0 Room Temperature (Room temperature, 0.1 °F); AI 1 Humidity (Room humidity, 0.1 %); AI 2 CO2 (Room CO2, ppm).

How do I enable BMS control of the 75F MyStat thermostat (BACnet MS/TP server)?

MV 0 Conditioning Mode sets off/auto/heating/cooling; BV 11 Unoccupied Mode switches between occupied and unoccupied.
