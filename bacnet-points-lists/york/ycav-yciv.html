Short answer

YORK by Johnson Controls YCAV and YCIV chillers with the 031-03478 microboard have BACnet MS/TP, Modbus RTU and N2 built in, so no gateway is needed. The BAS writes a remote setpoint, current limit, sound limit and start/stop (AV 1-3, BV 1). Everything else is read-only analog and binary inputs: chilled liquid and ambient temperatures, per-system pressures, temperatures, % FLA, hours, starts, flash tank values, operational and fault codes, and alarms.

BMS integration notes: York YCAV / YCIV Air-Cooled Screw Chiller (native BACnet MS/TP)

Integration in brief

Put the chiller in remote control (BI 14 reads Remote), then start/stop it with BV 1 and write the remote setpoint (AV 1) and current limit (AV 2). Read each system's state, the leaving chilled liquid temperature and VSD frequency, and the two alarm inputs.

Enable & remote start

BI 14 shows Local or Remote control mode. The sheet gives no point to change it and no write-enable point.

Heartbeat & communication loss

Operational code 67 is 'Loss Of External Communications'; the sheet gives no timeout or heartbeat point.

Network setup

  • BACnet MS/TP, Modbus RTU and N2 are native on the 031-03478 board; a gateway is only needed for Connected Services.
  • The sheet gives no default MAC address, baud rate or device instance.

Watch out for

  • Most data are AI/BI objects, not AV/BV; only the four write points are values.
  • Fault and operational codes are per system (AI 50-57); there is no single unit fault code, so alarm on BI 1 and BI 2.

Integration notes

  • Access follows the sheet's sections: analog and binary write points (AV 1-3, BV 1) and read-only points (AI, BI).
  • Points for systems 3 and 4 only report on units with that many systems; values that don't apply are sent as zero.
  • Operational and fault codes are numeric AIs; the states list the code values from the sheet's code table.
  • Spare objects (AV 4, BV 2-3) are left out. Units shown are imperial; SI units are in the sheet (pressures in bar).
