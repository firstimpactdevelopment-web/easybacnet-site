BMS integration notes: York L-Series LSWU / LSWD / LSWF Water-Cooled Self-Contained Unit, 25-105 ton (IPU2, native BACnet MS/TP)

Integration in brief

Connect to Port 1 of the IPU2 control board on BACnet MS/TP. Command occupancy with OCCUPNCY_CMD (BV 12), stop or release the unit with UNIT_STOP (BV 17) and write the occupied zone setpoints; read supply air, zone and condenser water temperatures, supply fan status, unit mode and the alarm input.

Enable & remote start

OCCUPNCY_CMD (BV 12) puts the unit in occupied (1) or unoccupied (0) mode and UNIT_STOP (BV 17) stops it (1) or returns it to normal operation (0). SYSTEM_STOP (AV 35) can turn off individual compressor systems.

Sensors & values from the BMS

ZONE_TMP_BAS (AV 40) lets the BAS supply zone temperature on a constant volume unit; OAT_CURR_BAS (AV 49) and OA_RH_BAS (AV 50) supply outdoor temperature and humidity when the airside economizer is selected; UND_TEMP_BAS / UND_HUMD_BAS (AV 37/36) feed under-floor values on FlexSys units.

Network setup

  • BACnet MS/TP must use Port 1 of the IPU2 board; Port 2 is the RS-232 terminal port.
  • Set the MAC address (1-127) with the SW2 DIP switches (switch 8 always ON) or the SERVICE key; the default device instance is 23000 plus the MAC address.
  • A different device instance is set with DE MODIFIER ADDRESS x 100 + DE MODIFIER OFFSET; to keep the automatic instance, DE MODIFIER OFFSET must be -1.
  • Cycle unit power after changing the MAC address or the port settings.

Watch out for

  • Setpoints, limits and enable values are setup values; don't write them cyclically.
  • Many points only exist on FlexSys, VAV or constant volume units, or with options such as the waterside economizer.

Integration notes

  • Access is from the READ/WRITE column; descriptions are the user interface names from the table. Points marked FlexSys, VAV or CV only exist on those units.
  • The table prints ACT_SLAB_CTL (Modbus 1102) as AI 5 and COMFORT_VENT (Modbus 1103) as AI 2, the same IDs as the pressure points AV_PRS_A_SUC and AV_PRS_DIS; those two writable on/off rows are left out because their real object IDs cannot be told from the doc.
  • The economizer method selector appears twice as AV 6 (ECONO_METHOD and ECON_METHOD); it is listed once. Ten on/off settings and commands (ECONO_INSTAL, FLSYS_REHEAT, HEAT_ENABLE, HEAT_VACTION, MORN_WARM_UP, MORN_WUP_CMD, NIGHT_SETBAC, OCCUPNCY_CMD, UNIT_STOP, VENT_ENABLE) are printed with both a BV and an AV ID (AV 81-95); they are listed by the BV ID.
  • Multistate status codes (unit mode, system status, compressor status) are published as AIs; the code lists are in the table description column and are not repeated here.
  • Units are taken from the description column where it states them. The Modbus register addresses in the same table are not reproduced.
  • The older Versecon YSWU/YSWD IPU (IPU1) IOM 145.05-NOM3 prints a largely overlapping list.
