BMS integration notes: York YZ Magnetic-Bearing Centrifugal Chiller (SC-EQ)

Integration in brief

Wire the BAS to the SC-EQ J12 RS-485 port and set the MAC address; the card detects BACnet MS/TP. Run/stop the chiller with BV 1 and write the leaving chilled liquid setpoint (AV 1) and input current limit (AV 2). Read MV 1 for the operating state, BV 5 for motor run, the leaving water temperature and % FLA, and MV 2/MV 3 for safety and cycling shutdowns. MV 5 and MV 12-15 show whether the chiller is taking its commands from the BAS.

Enable & remote start

BV 1 REM RUN STOP CMD (0 = Stop, 1 = Run) is the BAS run/stop and AV 1-3 are the remote setpoints. MV 5 shows the unit control source (Local, BAS, Analog, Digital, Remote); MV 12 shows the run/stop source (Local, BAS, Hardwire) and MV 13-15 the cooling setpoint, heating setpoint and current limit sources. Check they read BAS. The points list has no write-enable point.

Network setup

  • The BAS connects to the SC-EQ J12 port (RS-485: +, -, COM/REF, SHLD). The card detects BACnet MS/TP, Modbus RTU or N2 and the baud rate by itself; allow up to 120 seconds after power-up.
  • The MAC address (1-127) is set on DIP switch SW1 (switch 8 unused). Cycle the card's power after changing it.
  • The device instance defaults to 5000 + the MAC address (MAC 6 gives 5006). To use another number, set Device Instance Mode to Manual and enter the instance with the SC-AP / MAP tool, or write BV 65000 (mode) and AV 65000 (instance ID).
  • MV 65001 Units sets whether the BAS sees IP or SI values, independent of the chiller display; set it to match the chiller.

Watch out for

  • The remote (commandable) setpoints read as unreliable until the BAS writes them the first time.
  • The SC-EQ only exposes the points that apply to the chiller it detects; if it replaces an E-Link, re-discover the device so old non-applicable points don't sit offline.
  • Code points come in pairs: the MV state is the code + 1, and the AV copy (AV 52-59) carries the raw code.

  • Access is inferred: the sheet has no read/write column. The remote block (AV 1-3, BV 1) is treated as commandable and MV 65001 as writable; everything else as read-only.
  • Status-code MVs (operation, safety, cycling, warning, modified run, start inhibit, internal fault) are the printed code + 1, as the doc's status code tables say; the AV copies (AV 52-59) carry the raw code. MVs with their own enum in the points table are shown as printed; BACnet multistate values start at 1, so the card may report the printed number + 1. Confirm by discovery.
  • Harmonic filter, heat recovery, heat pump, hot gas bypass and dew point points only report when that option is fitted or enabled.
  • Units shown are the IP units; with MV 65001 set to SI the card reports °C, kPa and so on.
  • Spare objects (AV 4, BV 2-4 and the empty rows) are left out.

Start with BV 1 REM RUN STOP CMD (Remote run/stop (1 = run)); AV 1 REM LEAVING CHL TEMP SP (Remote leaving chilled liquid setpoint); AV 2 REMOTE INPUT CURRENT SP (Remote input current limit, %); MV 1 UNIT OPERATION CODE (Operating state (stopped, starting, running)); BV 5 COMPR MOTOR RUN (Compressor motor running); MV 5 UNIT CONTROL SOURCE (Control source; BAS for BMS control); AV 6 LEAVING CH LIQ TEMP (Leaving chilled liquid temperature); AV 18 MOTOR CURRENT PCT FLA (Motor current, % FLA (load indication)); MV 2 UNIT SAFETY FAULT CODE (Safety shutdown code (1 = none)); MV 3 UNIT CYCLING FAULT CODE (Cycling shutdown code (1 = none)).

How do I enable BMS control of the York YZ Magnetic-Bearing Centrifugal Chiller (SC-EQ)?

BV 1 REM RUN STOP CMD (0 = Stop, 1 = Run) is the BAS run/stop and AV 1-3 are the remote setpoints. MV 5 shows the unit control source (Local, BAS, Analog, Digital, Remote); MV 12 shows the run/stop source (Local, BAS, Hardwire) and MV 13-15 the cooling setpoint, heating setpoint and current limit sources. Check they read BAS. The points list has no write-enable point.
