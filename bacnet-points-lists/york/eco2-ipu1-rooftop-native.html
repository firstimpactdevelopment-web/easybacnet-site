BMS integration notes: York ECO2 Rooftop Unit, 50-130 ton, Mod D/E (IPU 1, native BACnet MS/TP)

Integration in brief

Connect to the IPU 1 board on BACnet MS/TP (default 38.4K baud). Command occupancy with AV 88, stop or release the unit with AV 93 and write the occupied zone setpoints; feed zone temperature through AV 40 if the control method is set to comm zone temp. Read supply and return air temperatures, the supply fan status, unit mode and the fault inputs.

Enable & remote start

AV 88 is the occupancy command (0 = unoccupied, 1 = occupied) and AV 93 the unit stop (0 = normal operation, 1 = stopped). BAS reset and BAS sensor inputs (AV 5, AV 28, AV 36, AV 37) must first be enabled at the unit with the service key; AV 40 zone temperature needs the control method set to comm zone temp.

Sensors & values from the BMS

AV 40 ZONE_TMP_BAS feeds zone temperature when the control method is set to comm zone temp. AV 36 and AV 37 feed under-floor humidity and temperature, and AV 5 and AV 28 give BAS duct static and supply air reset; these need enabling with the service key.

Network setup

  • BACnet MS/TP default baud rate is 38.4K. Modbus RTU defaults to 9600 and can be set to 19.2K, 38.4K or 57.6K at the keypad.
  • LON and N2 need an E-Link gateway; BACnet MS/TP and Modbus RTU are native on the IPU 1.
  • See the ECO2 installation and operation manual (form 100.50-NOM3) for setup details.

Watch out for

  • Binary commands are AVs that take 0 or 1, not BVs.
  • Optional points report only when the option is fitted (see the sales order).

Integration notes

  • Access comes from the sheet's Read/Write column. Binary commands (occupancy, unit stop, morning warm-up and so on) are analog values that take 0 or 1.
  • Availability is Standard or Optional (see the sales order); optional points only report when the option is fitted.
  • BACnet values are always in imperial units, whatever the ECO2 display is set to.
  • Rows with no BACnet object (gas heat stages, gas furnace names that share the electric heat BIs, OAT/RAT setpoints for high/low SAT, fan speed setpoints for high/low SAT) are left out; BI 26-32 carry the electric heat or gas furnace stage outputs.
  • The AV 35 System Stop comment is cut off in the sheet after 0 = all compressors OK to run; the other values stop compressor systems. The AI 15 condenser fan speed units are printed as hrs.
  • The Johnson Controls document portal files this sheet as Series 100 IPU 1 Native BACnet and Modbus.
