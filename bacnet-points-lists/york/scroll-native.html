Updated 4 November 2026

Short answer

YORK scroll chillers, heat pumps and condensing units with the 031-02550 board have BACnet MS/TP, Modbus RTU and N2 built in. The BAS writes the remote setpoint, load limit stage, cooling range, heating setpoint, heat pump mode and start/stop (AV 1-7, BV 1). Everything else is read-only AI and BI objects: liquid and ambient temperatures, per-system suction and discharge values, EEV output, timers, cutouts and setpoints, compressor run status, operational and fault codes, and system alarms.

BMS integration notes: York Scroll Chiller / Heat Pump / Condensing Unit (native BACnet MS/TP)

Integration in brief

Put the unit in automatic/remote control (BI 20 reads Auto), then start/stop it with BV 1 and write the remote setpoint (AV 1) and, if needed, the load limit stage (AV 3). Read the leaving chilled liquid temperature, compressor run status, each system's operational code and the two system alarms.

Enable & remote start

BI 20 shows the local/remote control mode (0 = Manual, 1 = Auto). The sheet gives no point to change it and no write-enable point. On heat pumps AV 7 selects panel, cool or heat.

Network setup

  • BACnet MS/TP, Modbus RTU and N2 are native on the board.
  • The sheet gives no default MAC address, baud rate or device instance.

Watch out for

  • Most data are AI/BI objects, not AV/BV; only AV 1-7 and BV 1 are writable.
  • Several write points are optional and only act on matching units (SP/DAT condensing units, heat pumps, YCWL HP).

Integration notes

  • Access follows the sheet's sections: analog and binary write points (AV, BV) and read-only points (AI, BI).
  • The sheet marks every point Standard, Optional or Not available for three firmware ranges. The points marked Not available on all of them (per-system start/stops BV 2-3 and the debug codes AI 29 and AI 31) are left out.
  • Optional points depend on the unit: suction-pressure (SP) or discharge-air (DAT) condensing units, heat pumps (HP), YCWL, EEV and refrigerant type. Values that don't apply are sent as zero.
  • Operational and fault codes are numeric AIs; the states list the code values from the sheet's code tables.
  • Units shown are imperial; SI units are in the sheet.

Which York Scroll Chiller / Heat Pump / Condensing Unit (native BACnet MS/TP) BACnet points are writable?

8 of the 86 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
