Short answer

YVWA chillers connect to a BAS through the SC-EQ communication card on BACnet MS/TP (or Modbus RTU / N2). The BAS can start/stop the unit, write the chilled liquid setpoint, current limit and heating setpoint, and switch between chiller and heat pump mode. Read-only points cover chilled and condenser liquid temperatures, per-system pressures, % FLA, hours and starts, VSD values, valve positions and multistate operational and fault codes per system.

BMS integration notes: York YVWA Water-Cooled Variable-Speed Screw Chiller (SC-EQ)

Integration in brief

Put the chiller in remote control (BV 20 reads Remote), then start/stop it with BV 1 and write the chilled liquid setpoint (AV 1) and current limit (AV 2); heat pump units also take BV 3 (mode) and AV 4 (heating setpoint). Read BV 5 for chiller run, the leaving chilled liquid temperature, VSD frequency and BV 6 for the chiller alarm; the fault code MVs give the cause.

Enable & remote start

BV 20 shows Local or Remote control mode. The points list gives no point to change it and no write-enable point. On heat pump units BV 3 selects chiller or heat pump operation.

Network setup

  • The BAS connects to the SC-EQ J12 port (RS-485: +, -, COM/REF, SHLD). The card detects BACnet MS/TP, Modbus RTU or N2 and the baud rate by itself; allow up to 120 seconds after power-up.
  • The MAC address (1-127) is set on DIP switch SW1 (switch 8 unused). Cycle the card's power after changing it.
  • The device instance defaults to 5000 + the MAC address (MAC 6 gives 5006). To use another number, set Device Instance Mode to Manual and enter the instance with the SC-AP / MAP tool, or write BV 65000 (mode) and AV 65000 (instance ID).

Watch out for

  • The remote (commandable) setpoints read as unreliable until the BAS writes them the first time.
  • The SC-EQ only exposes the points that apply to the chiller it detects; if it replaces an E-Link, re-discover the device so old non-applicable points don't sit offline.
  • The fault code table differs between one- and two-compressor units; check the compressor count before decoding MV 2.

Integration notes

  • Access is inferred: the sheet has no read/write column. The remote block (AV 1, AV 2, AV 4, BV 1, BV 3, BV 4) is treated as commandable; everything else as read-only.
  • System 2 points only report on two-compressor units. MV 2 / AV 502 are printed twice: Sys 1 fault code on two-compressor units and the unit fault code on one-compressor units, each with its own code table; they are merged here and both tables are given.
  • Operational and fault code MVs are the printed code + 1, as the doc's status code tables say; the AV copies (AV 501-504) carry the raw code. Binary states are as printed.
  • This list has no MV 65001 Units object. Units shown are the IP units.

Which York YVWA Water-Cooled Variable-Speed Screw Chiller (SC-EQ) BACnet points are writable?
