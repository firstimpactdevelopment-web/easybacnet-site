BMS integration notes: York YK-EP Centrifugal Chiller (SC-EQ)

Integration in brief

Wire the BAS to the SC-EQ J12 RS-485 port, set the MAC address on the DIP switch and let the card detect BACnet MS/TP. Write the remote run/stop, leaving chilled liquid setpoint and current limit, then read main and economizer motor run status, the operation code, leaving chilled liquid temperature, % FLA and the safety fault code. Check MV 5 and MV 10-13 to confirm the chiller is taking its commands from the BAS.

Enable & remote start

BV 1 REM RUN STOP CMD (0 = Stop, 1 = Run) is the BAS run/stop, and the REM AVs are the remote setpoints. MV 5 Unit Control Source shows Local, ISN (BAS), Analog, Digital, Modem or Remote. MV 10 shows the run/stop source (Local, BAS, Hardwire) and MV 11-13 the cooling setpoint, heating setpoint and current limit sources (Local, BAS, 0-10 V, 4-20 mA, PWM); check they read BAS. The points list has no write-enable point and doesn't say how the source is chosen at the chiller panel.

Network setup

  • The BAS connects to the SC-EQ J12 port (RS-485: +, -, COM/REF, SHLD). The card detects BACnet MS/TP, Modbus RTU or N2 and the baud rate by itself; allow up to 120 seconds after power-up.
  • The MAC address (1-127) is set on DIP switch SW1 (switch 8 unused). Cycle the card's power after changing it.
  • The device instance defaults to 5000 + the MAC address (MAC 6 gives 5006). To use another number, set Device Instance Mode to Manual and enter the instance with the SC-AP / MAP tool, or write BV 65000 (mode) and AV 65000 (instance ID).
  • MV 65001 Units sets whether the BAS sees IP or SI values, independent of the chiller display; set it to match the chiller.
  • Turn the card's RS-485 end-of-line switches on only when it is at the end of the trunk.

Watch out for

  • The BAS port is RS-485 only (BACnet MS/TP, Modbus RTU or N2); the card has no BACnet IP port.
  • AV 13-18 and AV 121-122 change meaning with the starter: VSD values on a VSD chiller, solid-state starter (SSS) values on an SSS chiller.
  • Remote setpoints show as unreliable until the BAS has written them once.
  • The card only exposes points that apply to the detected chiller and its options. Replacing an E-Link leaves the old, non-applicable points offline in the BAS until you rediscover the device.
  • Code points come in pairs: the MV state is the code + 1, and the AV copy (AV 401 and up) carries the raw code.

Integration notes

  • Points list for the SC-EQ (SC-EQUIP) communication card, which replaced the E-Link gateway. The list has no read/write column: the REM remote command/setpoint objects are treated as commandable and MV 65001 Units as writable; everything else as read-only.
  • Shares its base points with the YK SC-EQ list; the AV/BV 2xx objects are the economizer compressor.
  • Two object sets share instances by starter type: AV 13-18 and AV 121-122 change meaning with the starter: VSD values on a VSD chiller, solid-state starter (SSS) values on an SSS chiller. They are listed once here with both names.
  • Operating hours and kWh are also split into Low and Offset AVs: total = Offset x 10,000 + Low.
  • Units shown are the IP units; with MV 65001 set to SI the card reports °C, kPa and so on.
  • Status-code MVs (operation, fault, warning, modified run, start inhibit, internal fault) are the printed code + 1, as the doc's status code tables say; the AV copies (AV 401 and up) carry the raw code. MVs with their own enum in the points table (Units, control sources) are shown as printed, from 0; BACnet multistate values start at 1, so the card may report the printed number + 1. Confirm by discovery.
  • Long fault and warning code tables are summarised in the MV states; the full text is in the source document.

Questions about the York YK-EP Centrifugal Chiller (SC-EQ)

How many BACnet points does the York YK-EP Centrifugal Chiller (SC-EQ) have?

This list has 170 BACnet objects: 142 analog values, 15 binary values, 13 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which York YK-EP Centrifugal Chiller (SC-EQ) BACnet points are writable?

5 of the 170 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official York YK-EP Centrifugal Chiller (SC-EQ) BACnet documentation?

The source is YKEP SC-EQ BAS Points List, revision Rev 2.9, 2021-12-08, published free by York at https://docs.johnsoncontrols.com/chillers/api/khub/documents/WBwYCBJ~KihreRSMUxcxcQ/content.

What are the minimum BACnet points to integrate the York YK-EP Centrifugal Chiller (SC-EQ)?

Start with BV 1 REM RUN STOP CMD (Remote run/stop (1 = run)); AV 1 REM LEAVING CHL TEMP SP (Remote leaving chilled liquid setpoint); AV 2 REMOTE CURRENT SP (Remote motor current limit, %); MV 1 UNIT OPERATION CODE (Operating state (stopped, starting, running)); BV 5 COMPR MOTOR STATUS (Compressor motor running); MV 5 UNIT CONTROL SOURCE (Control source; ISN (BAS) for BMS control); AV 5 LEAVING CH LIQ TEMP (Leaving chilled liquid temperature); AV 12 MOTOR CURRENT PCT FLA (Motor current, % FLA (load indication)); MV 2 UNIT SAFETY FAULT CODE (Safety shutdown code (1 = none)); MV 3 UNIT CYCLING FAULT CODE (Cycling shutdown code (1 = none)).

How do I enable BMS control of the York YK-EP Centrifugal Chiller (SC-EQ)?

BV 1 REM RUN STOP CMD (0 = Stop, 1 = Run) is the BAS run/stop, and the REM AVs are the remote setpoints. MV 5 Unit Control Source shows Local, ISN (BAS), Analog, Digital, Modem or Remote. MV 10 shows the run/stop source (Local, BAS, Hardwire) and MV 11-13 the cooling setpoint, heating setpoint and current limit sources (Local, BAS, 0-10 V, 4-20 mA, PWM); check they read BAS. The points list has no write-enable point and doesn't say how the source is chosen at the chiller panel.
