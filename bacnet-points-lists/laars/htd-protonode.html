Laars HTD control - ProtoNode BACnet points list

Updated 16 October 2026

Short answer

The ProtoNode reads the HTD control over Modbus RTU and serves 180 objects per boiler. Analog inputs cover temperatures, flame signal, 0-10 V inputs and outputs, O2/CO2, pressures, firing rates, lockout and alarm codes, LMV burner data and lag states; binary inputs break out the safety chain, outputs and LMV I/O bits. Writable AVs and BVs hold the CH1-CH4, DHW, cascade and hybrid enables, setpoints, PID terms and demands.

This page lists 180 BACnet objects for the Laars HTD control - ProtoNode — 47 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Laars’s own free documentation, linked below.

BMS integration notes: Laars HTD control - ProtoNode

Integration in brief

Enable CH1 with AV 0, give it a call for heat with BV 1 and write the CH1 setpoint (or the cascade setpoint for a cascade). Read the run contact, outlet temperature and firing rate, and watch the alarm contact and lockout code.

Enable & remote start

AV 0 CH1 enable/disable (0 = disable, 1 = enable) and BV 1 CH1 demand (0 = no demand, 1 = demand). CH2-CH4 and DHW have matching objects.

Network setup

  • Device instance = Node_Offset + boiler Node-ID. Node_Offset defaults to 50000 and is changed in the ProtoNode web configurator; Node-IDs must be unique, 1-255.
  • Boiler to ProtoNode: Modbus RTU, 38400 baud, 8 data bits, no parity, 1 stop bit.
  • Default ProtoNode IP address 192.168.1.24, mask 255.255.255.0. Choose BACnet IP or BACnet MS/TP with the Protocol Selector, then add one profile per device with its Node-ID.
  • With more than one device on a ProtoNode, set BACnet Virtual Server Nodes to Yes. For BACnet MS/TP also set MAC address, baud rate and Max Master.
  • Two or more ProtoNodes on the same subnet need different BACnet Network Numbers (default 50).
  • A ProtoNode handles 1,500 registers in total; this profile uses 254 per device.

Watch out for

  • PID terms (P unitless, I and D in seconds) for each circuit are writable AVs; they are tuning values, not BMS commands.
  • AI 36 Alarm reason uses codes 30-44, continuing the lockout code list in AI 35.
  • BV 0 DHW demand reads 0 = Disable, 1 = Enable in the mapping, unlike the CH demand BVs.

Integration notes

  • Each boiler on the ProtoNode's RS-485 bus shows up as its own BACnet device, and every one uses the same object IDs. The device instance is Node_Offset (default 50000) plus the boiler's Node-ID, so Node-ID 1 = device 50001.
  • The mapping has no read/write column. AV, BV and MV objects are mapped to Metasys N2 outputs and LonWorks input variables, so they are listed here as writable; AI, BI and MI objects are read-only.
  • Temperatures are listed as °C/°F; the mapping does not say how the unit is chosen.
  • The LMV objects (phase, actuator positions, trim, error and diagnostic codes, LMV inputs and outputs) come from an LMV burner control; several have to be decoded with the LMV manual.
  • Bit-mapped registers (safety chain, digital outputs, gas valve, LMV inputs/outputs) are split into one BI per bit; the object names here join the register name and the bit label.
  • AI 13 is marked not used.

Questions about the Laars HTD control - ProtoNode

How many BACnet points does the Laars HTD control - ProtoNode have?

This list has 180 BACnet objects: 86 analog inputs, 42 analog values, 47 binary inputs, 5 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Laars HTD control - ProtoNode BACnet points are writable?

47 of the 180 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Laars HTD control - ProtoNode BACnet documentation?

The source is Vendor Protocol Mapping (LAARS Vendor Mappings for the ProtoNode FPC-N34 / FPC-N35) (4404), revision Document Revision 14.B, October 2020, published free by Laars at https://www.laars.com/uploads/products/4404.pdf.

What are the minimum BACnet points to integrate the Laars HTD control - ProtoNode?

Start with AV 0 CH1 enable/disable (CH1 enable (1 = enable)); BV 1 CH1 demand (CH1 call for heat (1 = demand)); AV 1 CH1 setpoint (CH1 water setpoint, °C/°F); AV 27 Cascade setpoint (Setpoint when boilers run in cascade); BI 11 Digital Output Status - Run Contact (Boiler run output); AI 1 Outlet sensor (Outlet water temperature, °C/°F); AI 33 Modulating Burner1 Firing rate (Burner 1 firing rate, %); BI 12 Digital Output Status - Alarm Contact (Alarm output); AI 35 Lockout code (Lockout code (0-29)).

How do I enable BMS control of the Laars HTD control - ProtoNode?

AV 0 CH1 enable/disable (0 = disable, 1 = enable) and BV 1 CH1 demand (0 = no demand, 1 = demand). CH2-CH4 and DHW have matching objects.

How do I check these points on the real HTD control - ProtoNode?
