Grundfos CIM 500 BACnet IP (booster systems) BACnet points list

Updated 16 October 2026

Short answer

The CIM 500 module gives Grundfos booster systems a BACnet IP interface. The booster object list differs from the single-pump profile: it adds per-subpump presence, communication, auto-mode, fault code, runtime, speed, current, power, motor temperature and start counts for up to six subpumps plus pilot and back-up pumps, tank-filling limits and system pressures, levels and flows. Availability depends on the booster type and fitted sensors.

This page lists 174 BACnet objects for the Grundfos CIM 500 BACnet IP (booster systems) — 27 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Grundfos’s own free documentation, linked below.

BMS integration notes: Grundfos CIM 500 BACnet IP (booster systems)

Integration in brief

Take bus control with BO 0 = 1, then start or stop the booster with MO 1 and write the setpoint to AO 0 (and the control mode to MO 0 on Hydro MPC). Read control source, rotation status, actual setpoint and the system fault and warning codes; reset alarms with BO 4.

Enable & remote start

Set control source BO 0 = 1 (bus control); 0 = local control (default). MO 0, MO 1 and AO 0 only act while bus control is enabled; BI 0 confirms the active source.

Network setup

  • BACnet IP only (Annex J); no segmentation.
  • AV 0 holds a custom device instance (range 0-0x3FFFFE, default 0xE7) that is used together with DIP switch SW3.
  • MO 2 product simulation lets you commission the BMS side with no booster connected.

Watch out for

  • A setpoint of 0 on AO 0 does not stop the booster; use MO 1 = 2 (Stop).
  • MO 3-10 forced start is listed as not available; only automatic or forced stop work.
  • Many points depend on the booster type and fitted sensors; check the availability note in each description.

Integration notes

  • For single Grundfos pumps (MAGNA3, E-pumps, CUE) see the CIM 300 / CIM 500 pump profile instead.
  • Descriptions show which booster types support each point (Hydro Multi-B, Hydro MPC, Hydro Multi-E) and when a sensor is needed.
  • AI 61-84 are printed with the bare name 'Subpump N'; the description says which value (current, power, motor temperature, starts) each one is.
  • MI 12 and MI 13 have no access column in the source; they are listed as read-only.
  • This 2014 PICS (BACnet protocol revision 9) does not list the BACnet watchdog object found in the later CIM functional profile.
  • Hydro Multi-E always runs in constant pressure mode; MO 0 only applies to Hydro MPC.

Questions about the Grundfos CIM 500 BACnet IP (booster systems)

How many BACnet points does the Grundfos CIM 500 BACnet IP (booster systems) have?

This list has 174 BACnet objects: 93 analog inputs, 5 analog outputs, 8 analog values, 41 binary inputs, 3 binary outputs, 13 multi-state inputs, 11 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Grundfos CIM 500 BACnet IP (booster systems) BACnet points are writable?

27 of the 174 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Grundfos CIM 500 BACnet IP (booster systems) BACnet documentation?

The source is BACnet PICS CIM 500 - Protocol Implementation Conformance Statement for Grundfos CIM 500 BACnet IP for Grundfos pumps and booster systems, revision 2014-04-25, published free by Grundfos at https://www.bacnetinternational.net/catalog/manu/grundfos%20management%20as/BACnet_PICS_CIM500_Print_88363.pdf.

What are the minimum BACnet points to integrate the Grundfos CIM 500 BACnet IP (booster systems)?

Start with BO 0 Set control source (Takes bus control (1) or gives it back (0)); MO 1 Set operating mode (Start/stop: 1 = Start, 2 = Stop); MO 0 Set control mode (Control mode (Hydro MPC only)); AO 0 Set setpoint (System setpoint in %); BO 4 Reset fault (Resets an alarm on a 0-to-1 edge (bus control only)); BI 0 Control source status (Confirms bus control (1) or local (0)); BI 2 Rotation status (One or more pumps running); AI 9 Actual setpoint (Setpoint actually in use); AI 0 Fault code (Active Grundfos alarm code).

How do I enable BMS control of the Grundfos CIM 500 BACnet IP (booster systems)?

Set control source BO 0 = 1 (bus control); 0 = local control (default). MO 0, MO 1 and AO 0 only act while bus control is enabled; BI 0 confirms the active source.
