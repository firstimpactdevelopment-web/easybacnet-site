Grundfos Level Control LC 2X1 (CIM 300 / CIM 500) BACnet points list

Updated 6 November 2026

Short answer

The LC 2X1 controls up to two wastewater pumps from a level sensor or float switches. With a CIM 300 or CIM 500 module it exposes a fixed object list: pit level, energy and run-time counters, per-pump status inputs, a block of 16 user digital inputs, writable level setpoints in centimetres and a multistate Auto/Forced start/Forced stop command per pump.

This page lists 79 BACnet objects for the Grundfos Level Control LC 2X1 (CIM 300 / CIM 500) — 10 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Grundfos’s own free documentation, linked below.

BMS integration notes: Grundfos Level Control LC 2X1 (CIM 300 / CIM 500)

Integration in brief

Read the operating state (MI 0), pit level (AI 6) and the per-pump running and alarm inputs, and use MO 0/MO 1 to put each pump in Auto, Forced start or Forced stop. Alarms are reset with BO 0. The start, stop, high and dry-running levels can be written in centimetres through AO 0-4.

Network setup

  • CIM 300 is a BACnet MS/TP master at 9600, 19200, 38400 or 76800 baud; CIM 500 uses BACnet IP (Annex J).
  • AV 0 lets the BMS set a custom device instance (0-0x3FFFFE).
  • The CIM module fits inside the controller or in an external CIU box; the object list is the same either way.
  • The PICS states that segmentation is not supported.

Watch out for

  • The level setpoints AO 0-4 are stored settings; write them only when they change, not cyclically.
  • Pump 2 has a start-level object (AO 4) but no stop-level object in this table.
  • AI 0/AI 1 are Grundfos fault and warning codes; decode them with the LC manual.

Integration notes

  • Object list from section 4.3 of the PICS (pages 20-23). It has no MI 2 and jumps from AI 29 to AI 39.
  • The same object table is printed in the CIM 500 PICS (98690071, https://api.grundfos.com/literature/Grundfosliterature-6226722.pdf); CIM 300 gives BACnet MS/TP and CIM 500 BACnet IP.
  • AI 39 bits 0-4 are warnings 1-5 and bits 8-12 alarms 1-5. AI 40 flags fitted sensors: bit 0 flow, 1 power/energy, 2-6 AI sensors 1-5, 7 turbidity, 8 pH, 9 conductivity, 10 pulse flow meter, 11 pressure, 12 level.

Questions about the Grundfos Level Control LC 2X1 (CIM 300 / CIM 500)

How many BACnet points does the Grundfos Level Control LC 2X1 (CIM 300 / CIM 500) have?

This list has 79 BACnet objects: 32 analog inputs, 5 analog outputs, 2 analog values, 34 binary inputs, 1 binary output, 3 multi-state inputs, 2 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Grundfos Level Control LC 2X1 (CIM 300 / CIM 500) BACnet points are writable?

10 of the 79 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Grundfos Level Control LC 2X1 (CIM 300 / CIM 500) BACnet documentation?

The source is BACnet PICS CIM 300 - Supplement (pumps, booster systems, Level Control LC 2X1 and LC 2X2) (97750025), revision 05.2021, published free by Grundfos at https://api.grundfos.com/literature/Grundfosliterature-6013137.pdf.

What are the minimum BACnet points to integrate the Grundfos Level Control LC 2X1 (CIM 300 / CIM 500)?

Start with MO 0 Control Pump 1 (Pump 1: 1 = Auto, 2 = Forced start, 3 = Forced stop); MO 1 Control Pump 2 (Pump 2: 1 = Auto, 2 = Forced start, 3 = Forced stop); BO 0 Reset alarms (Alarm reset (1 = reset)); MI 0 System Operating Mode (Operating state: standby, pumping, alarm states); AI 6 Pit water level (Pit level in cm); BI 8 Pump1Running (Pump 1 running status); BI 9 Pump2Running (Pump 2 running status); BI 12 Pump1Alarm (Pump 1 alarm); BI 13 Pump2Alarm (Pump 2 alarm); AI 0 Fault code (Active Grundfos fault code).
