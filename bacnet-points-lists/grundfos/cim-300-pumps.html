Grundfos CIM 300 / CIM 500 BACnet (pumps) BACnet points list

Updated 16 October 2026

Short answer

The CIM 300 add-on module (or CIU 300 box) gives Grundfos electronic pumps a BACnet MS/TP interface; the CIM 500 does the same over BACnet IP. The pump functional profile is a fixed object list: status binary inputs, command binary outputs, multistate objects for control and operating mode, analog inputs for measured values and counters, analog outputs for setpoint and flow limit, and analog values for module configuration. Many points depend on pump family, MGE motor model (G, H or later) and fitted sensors.

This page lists 105 BACnet objects for the Grundfos CIM 300 / CIM 500 BACnet (pumps) — 21 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Grundfos’s own free documentation, linked below.

BMS integration notes: Grundfos CIM 300 / CIM 500 BACnet (pumps)

Integration in brief

Set the control mode (MO 0), operating mode (MO 1) and setpoint (AO 0) first, then take control by writing BO 0 = 1 (bus control). Set AV 1 so the pump drops back to its local settings if BACnet goes quiet. Read status from the BI, MI and AI objects, and reset faults with BO 4.

Enable & remote start

Write the desired control mode (MO 0), operating mode (MO 1, 1 = Start, 2 = Stop) and setpoint (AO 0), then set BO 0 Set control source = 1 for bus control. BI 0 and MI 14 show the active control source. Relay, reset and simulation commands only act while bus control is on.

Heartbeat & communication loss

AV 1 BACnet watchdog: 0 = disabled (default), or 5-3600 s. If no BACnet traffic is seen for that time while in bus control, the pump switches to local control and uses its local settings. After comms return the BAS must set BO 0 back to 1. Make the local settings first (Grundfos GO or PC Tool).

Sensors & values from the BMS

AV 12 Remote sensor feedback lets the BAS send the sensor value (0-100 %) to MAGNA3 and MGE model H and later pumps.

Network setup

  • CIM 300 default device instance is 227000 + MAC address (227000-227127); for a custom value write AV 0 and turn DIP switch SW3 on.
  • MAC address is set with the hexadecimal rotary switches.
  • MS/TP baud with DIP switches SW4/SW5: 9600 (default), 19200, 38400 or 76800.
  • CIM 500 (BACnet IP) is set up from its built-in webserver; factory webserver address 192.168.1.100.

Watch out for

  • A setpoint of 0 does not stop the pump; use MO 1 = 2 (Stop).
  • AO 0 is a percentage: of the setpoint range in closed-loop modes and of nominal frequency in open loop. Use AI 133/134 and the sensor range to scale.
  • The manual's fault section refers to the fault and warning codes as AV 0 / AV 1, but the object tables list them as AI 0 / AI 1.
  • Many points only exist on certain pump families or MGE model G/H, or need an external sensor.

Integration notes

  • Writes to BO 1-6, MO 0-1 and AO 0 only act when bus control is enabled with BO 0 = 1.
  • If AV 1 (watchdog) is set and BACnet traffic stops for that time, the pump falls back to local control.
  • Point availability differs between MAGNA3, E-pumps 0.25-7.5 kW and E-pumps 11-22 kW/CUE; many points need MGE model G or H or an external sensor.
  • On MAGNA and TPE Series 2000 the flow value is estimated and meant for monitoring only.
  • CIM 300 MS/TP speed is set with DIP switches SW4/SW5 (9600 default, up to 76800).

Questions about the Grundfos CIM 300 / CIM 500 BACnet (pumps)

How many BACnet points does the Grundfos CIM 300 / CIM 500 BACnet (pumps) have?

This list has 105 BACnet objects: 59 analog inputs, 2 analog outputs, 8 analog values, 19 binary inputs, 8 binary outputs, 6 multi-state inputs, 3 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Grundfos CIM 300 / CIM 500 BACnet (pumps) BACnet points are writable?

21 of the 105 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
