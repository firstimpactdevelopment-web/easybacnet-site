BMS integration notes: S+S Regeltechnik RYMASKON 1000 room operating unit (Interface / Controller)

Integration in brief

Set the MS/TP MAC address and baud rate on the unit (default 38400), then write the temperature setpoint, operating mode and fan level and read room temperature, presence and operating state. Use IV 409 / the BV lock objects if occupants must not change values the BMS controls.

Enable & remote start

Controller variants: IV 1607 Controller OpMode sets how the internal controller drives the outputs (0 Off, 1 cooling, 2 heating, 3 both). The BMS can take over each output with the BMS Contr. objects (AV 1608-1610, 1613; IV 1611, 1612, 1615); -1 returns an output to the internal controller.

Network setup

  • BACnet MS/TP master; baud 9600-115200, default 38400; isolated transceiver, no internal bias or termination, 1/8 unit load.
  • Vendor ID 1545; application and firmware 2.00.2.

Watch out for

  • Configuration objects are kept in EEPROM; write them only during commissioning.
  • When the BMS takes over a heating/cooling output, set the display operating mode in IV 404 as well (per the object notes).

Integration notes

  • Object names are printed with their type prefix and instance (e.g. AI:TempS1Int_Value_1); line-break spaces inside names are removed.
  • Some names carry a different number than their instance as printed (AI 18 AI:SP1_Angle_Value_15, AI 213 AI:RODO_Fan_Level_212, TV 7512 TV:TP48_EventHour_7042); kept as printed.
  • Configuration values (AV/IV/CSV in the configuration sections) are stored in EEPROM and should only be changed during commissioning.
  • Several IV objects are bit fields (names ending _bitField); the bit meanings are listed in the source. TV (time value) objects are listed with type Other.
  • Objects marked 'Controller variants only' do not exist or do nothing on Interface variants.
  • Access is not printed for the bit-field objects IV 411, 413, 700, 1100, 1102 and 3802; shown as R.
