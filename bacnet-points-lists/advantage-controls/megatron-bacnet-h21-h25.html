Advantage Controls MegaTron Controller (BACnet H21 / H25) BACnet points list

Updated 4 November 2026

Short answer

With the H21 or H25 option the MegaTron is a read-only BACnet IP device. It reports conductivity, pH, ORP, temperatures, water meter and flow meter values and up to sixteen 4-20 mA / 0-5 V inputs for up to four systems, plus alarm flags, setpoints, timer run times and relay states. Every object in this manual is marked Read Only, so the BMS can monitor but not adjust the controller.

BMS integration notes: Advantage Controls MegaTron Controller (BACnet H21 / H25)

Integration in brief

Monitoring only. Read the chemistry inputs (conductivity, pH, ORP) and the flow switch for each system in use, and the per-system alarm BVs you need (there is no summary alarm object in this list). All objects are read-only, so setpoints and relays are changed at the controller, not from the BMS.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • BACnet IP only (Annex J), on the same Ethernet port used for the WebAdvantage service.
  • Set the device instance and UDP port (47808 shown) in Setup/Run > Configure > Network > Settings > BAC, then reset the communications card and cycle power.
  • On H25 (dual network card, MegaTron MT only) the dual network card must be enabled before the BAC options appear.
  • 4194303 means unconfigured; the BMS must be on the same subnet as the MegaTron or BACnet traffic must be routed.
  • Protocol revision 24, B-ASC; only DS-RP-B is listed for data sharing, so read one property per request.

Watch out for

  • There is no All Alarms summary object (H22 has BV 301); map individual alarm BVs.
  • No writable objects: setpoints, alarm limits and relays cannot be changed from the BMS on H21/H25.
  • Points exist for four systems and sixteen mA inputs whether or not they are installed.
  • AI 45-53 are flow meter contact values here, not totals as on H22.

Integration notes

  • Object names in the manual are generic (BI-000, BV-011, AI-008 ...); the Purpose column is used as the description.
  • Every object, including the setpoint AVs and relay state MSVs, is marked Read Only. The H22 manual marks the same AVs and MSVs Read / Write.
  • Compared with H22, this list adds mA inputs 9-16 (AI 64-71) and their alarms (BV 360-391), drops the 'Future Use' BVs, BV 300 Utility, BV 301 All Alarms, the M. Conductivity alarms and the mA input 'Alarm' flags, and labels AI 45-53 as flow meter contact values instead of totals.
  • Instances start at 0 and most points repeat for System #1 to #4. No engineering units are printed.
  • BV 316 is printed with the object name BV-216 (kept as printed); BV 348 is printed as Bv-348.
  • Relay state MSVs use the printed states 1=H-OFF, 2=H-ON, 3=OFF, 4=ON.

What are the minimum BACnet points to integrate the Advantage Controls MegaTron Controller (BACnet H21 / H25)?

Start with AI 0 AI-000 (System 1 conductivity); AI 8 AI-008 (System 1 pH); AI 12 AI-012 (System 1 ORP); BI 0 BI-000 (System 1 flow switch); AV 0 AV-000 (System 1 conductivity setpoint 1 (read only)).

How do I check these points on the real MegaTron Controller (BACnet H21 / H25)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
