Short answer

The IPS 4000 runs a group of variable-speed pumps. In the variable primary version its BACnet list adds chiller/boiler enables, minimum and maximum flow and differential pressure limits per chiller or boiler, and the related alarms, on top of pump modes, hand speeds, zone setpoints and values, pump speed, power, energy, head and flow, run hours and alarms.

BMS integration notes: Armstrong Fluid Technology IPS 4000 pumping system controller - variable primary

Integration in brief

Start and stop the IPS 4000 with BV 1 Remote Start, write the zone setpoints (AV 1-16) and read BI 110 IPS On Status, the active zone value, system flow and head, and BI 1 General Alarm. Reset alarms with BV 32. The BMS can also put each pump in Hand, Off or Auto (BV 2-25), set hand speeds, enable chillers/boilers and write zone values (bas Zone pv AVs).

Enable & remote start

BV 1 Remote Start (0 = Stop, 1 = Start). The Set Pump Hand/Off/Auto BVs are momentary commands that change one pump's mode.

Sensors & values from the BMS

The bas Zone 1-16 pv AVs (48-63) are writable, so the BMS can supply zone values, and the bas Chiller/Boiler dp pv AVs (78-85) do the same for chiller/boiler differential pressure. The data-points sheet does not say how the controller chooses between BMS and wired values.

Network setup

  • The sheet lists BACnet TCP/IP and BACnet MS/TP. For BACnet IP use UDP port 47808 (0xBAC0).
  • The device instance and MS/TP settings are not given in the sheet.

Watch out for

  • Set Pump Hand/Off/Auto BVs are momentary: write 1 to change the mode, and read the pump mode BIs to confirm it.
  • Design flow/head, BEP and dead-band AVs are commissioning settings; don't write them cyclically.
  • Units for pressure, temperature and flow follow the controller's unit setting.

Questions about the Armstrong Fluid Technology IPS 4000 pumping system controller - variable primary

How many BACnet points does the Armstrong Fluid Technology IPS 4000 pumping system controller - variable primary have?

This list has 362 BACnet objects: 153 analog inputs, 74 analog values, 100 binary inputs, 35 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Armstrong Fluid Technology IPS 4000 pumping system controller - variable primary BACnet points are writable?

109 of the 362 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Armstrong Fluid Technology IPS 4000 pumping system controller - variable primary BACnet documentation?

The source is IPS 4000 Integrated pumping system for variable primary application, Data points (communication interface ver-2.1.0) (90.9751), revision 2020-12-07, published free by Armstrong Fluid Technology at https://armstrongfluidtechnology.com/~/media/documents/installation_maintenance_parts/installation-and-operating-instructions/90-9751_ips4000_primary_bas-_ver-2-1-0_datapoints.pdf.

What are the minimum BACnet points to integrate the Armstrong Fluid Technology IPS 4000 pumping system controller - variable primary?

Start with BV 1 Remote Start (Start/stop from the BMS (1 = start)); AV 1 Zone 1 sp (Zone 1 control setpoint); BV 32 Alarm Reset (Reset alarms); BI 110 IPS On Status (Pumping system on status); AI 3 Active Zone pv (Value of the zone in control); AI 147 System Flow (Total system flow); AI 136 System Head (Total system head); BI 2 Pump Alarm (Any pump alarm); BI 1 General Alarm (Any active alarm).

How do I enable BMS control of the Armstrong Fluid Technology IPS 4000 pumping system controller - variable primary?

BV 1 Remote Start (0 = Stop, 1 = Start). The Set Pump Hand/Off/Auto BVs are momentary commands that change one pump's mode.

Can the BMS supply sensor values to the Armstrong Fluid Technology IPS 4000 pumping system controller - variable primary?

The bas Zone 1-16 pv AVs (48-63) are writable, so the BMS can supply zone values, and the bas Chiller/Boiler dp pv AVs (78-85) do the same for chiller/boiler differential pressure. The data-points sheet does not say how the controller chooses between BMS and wired values.
