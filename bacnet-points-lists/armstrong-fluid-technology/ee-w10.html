Short answer

The EE-W10 controls a small water-cooled chilled water plant. Its BACnet object list gives plant start/stop, alarm reset, plant load, power and efficiency, chilled and condenser water temperatures and flows, chiller, pump and tower run feedbacks and alarms, valve positions, drive data and Hand/Auto overrides for up to 3 chillers. The same document also lists the Modbus RTU registers.

BMS integration notes: Armstrong Fluid Technology EE-W10 chiller plant controller (water-cooled)

Integration in brief

The EE-W10 publishes a fixed BACnet object list. Start and stop the plant with BO 1 Remote Start, write the zone setpoint (AV 2), and read BI 1 Plant Status, plant load, chilled water temperatures, plant power and efficiency. Use BO 3 to reset alarms. Per-chiller, per-pump and per-valve alarms, run feedbacks and Hand/Auto overrides are there if the BMS needs more detail.

Enable & remote start

BO 1 Remote Start (0 = Stop, 1 = Start) starts and stops the plant from the BMS. The data-points sheet says nothing more about local/remote selection.

Network setup

  • The data-points sheet does not give the device instance, MAC address, baud rate or IP settings; get them from the controller setup.

Watch out for

  • BO 3 Alarm Reset acts on a positive edge (0 to 1); write 0 again before the next reset.
  • Hand/Auto BVs and Hand Command / Hand Speed objects override the plant sequence; leave them in Auto for normal operation.
  • Mode AVs are coded 0-3 (1 = Hand, 2 = Off, 3 = Auto); writing them takes that equipment out of automatic sequencing.
  • Set Lead Chiller / Pump objects act only when the value changes, so rewriting the same value does nothing.

Integration notes

  • The data-points sheet titles the table BACnet but does not say whether it is BACnet IP or MS/TP.
  • Mode objects (AV) use 0 = Not Used, 1 = Hand, 2 = Off, 3 = Auto. Duty/standby, chiller duty and chiller state objects are coded values; the codes are in each point's states.
  • Hand/Auto BVs and Hand Command BVs, plus the Hand Speed / Hand Position AOs, let the BMS run a valve, pump or fan by hand. Set Lead objects act only when the written value changes.
  • Units for temperatures, pressures and flows follow the controller's unit setting (the PDF lists the options).
  • Footnote asterisks after some pump names in the PDF are left off the object names. They mean: for dualArm or Twin pumps, pump numbers 1-5 are the A sides and 6-10 the B sides, and those pumps only report duty or standby because they run in dedicated mode with their chiller.
  • The PDF table is on pages 9-13. One Reserved AI is left out.

How many BACnet points does the Armstrong Fluid Technology EE-W10 chiller plant controller (water-cooled) have?

This list has 213 BACnet objects: 97 analog inputs, 11 analog outputs, 17 analog values, 65 binary inputs, 3 binary outputs, 20 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Armstrong Fluid Technology EE-W10 chiller plant controller (water-cooled) BACnet points are writable?

51 of the 213 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Armstrong Fluid Technology EE-W10 chiller plant controller (water-cooled) BACnet documentation?

The source is EE-W10 Data points (BAS data points - BACnet, Communication Interface Rev 24.071) (90.7651), revision 2025-07-18, published free by Armstrong Fluid Technology at https://armstrongfluidtechnology.com/~/media/documents/installation_maintenance_parts/installation-and-operating-instructions/90-7651_ee_w10_datapoints.pdf.

What are the minimum BACnet points to integrate the Armstrong Fluid Technology EE-W10 chiller plant controller (water-cooled)?

Start with BO 1 Remote Start (Plant start/stop from the BMS (1 = start)); AV 2 Zone 1 Setpoint (Zone 1 control setpoint); BO 3 Alarm Reset (Reset plant alarms (positive edge)); BI 1 Plant Status (Plant on/off status); AI 3 Plant Load (Plant cooling load, tons); AI 1001 chws Temp (Chilled water supply temperature); AI 1002 chwr Temp (Chilled water return temperature); AI 2 Total Plant Power Consumption (Total plant power, kW); AI 1 Plant Efficiency (Plant efficiency, kW/ton); BI 10 Refrigerant Leak Alarm (Refrigerant leak detected).

How do I enable BMS control of the Armstrong Fluid Technology EE-W10 chiller plant controller (water-cooled)?

BO 1 Remote Start (0 = Stop, 1 = Start) starts and stops the plant from the BMS. The data-points sheet says nothing more about local/remote selection.
