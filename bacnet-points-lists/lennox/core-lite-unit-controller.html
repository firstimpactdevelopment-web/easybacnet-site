Lennox CORE LITE Unit Controller BACnet points list

Updated 28 October 2026

Short answer

The CORE LITE Unit Controller talks BACnet MS/TP only, through an add-on BACnet plug-in module. Its object set is a smaller version of the full CORE controller's: occupancy, setpoints and network sensor inputs as Analog Outputs and Analog Values, status as Analog Inputs, an alarm log string and multistate status values. Commands are not stored through a reset and must be rewritten regularly.

This page lists 62 BACnet objects for the Lennox CORE LITE Unit Controller — 29 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Lennox’s own free documentation, linked below.

BMS integration notes: Lennox CORE LITE Unit Controller

Integration in brief

Set Configuration ID 1 network character to B (BACnet module installed), then run the Network Setup Wizard in the CORE LITE service app, set MAC, device instance and baud, and choose Room Sensor control mode. The BAS writes occupancy on AO104, setpoints on AV130-133 (or AO109 + AO110) and space temperature, RH and CO2 on AO113, AO112 and AO111 when those sources are set to Network.

Enable & remote start

No BACnet enable point. Configuration ID 1 must show B so the BACnet options appear, then the wizard sets the Control Mode: Monitor Only ignores network setpoints and mode demands, Room Sensor (recommended) uses AO104 occupancy plus AV130-133 or AO109 setpoints. AO101 = 6 (Off) disables the whole unit.

Heartbeat & communication loss

The controller must receive a write at least every 15 minutes or it treats the network as offline. Network space temperature (AO113), RH, CO2, AO101 demands, occupancy (AO104) and setpoints (AO109, AV130-133) must be rewritten at least every 5 minutes if used; Lennox recommends every 2 minutes.

Sensors & values from the BMS

Space temperature goes to AO113, space RH to AO112 and CO2 to AO111, with the matching sensor source set to Network in the wizard. After start-up the unit waits 5 minutes for AO113 in a no-run mode; after that it uses a local sensor if one is wired, otherwise logs a sensor failure and enters backup mode (code 93). Outdoor air temperature has no network input.

Network setup

  • Default device instance is 2 or the S-Bus address; Lennox suggests matching it to the MAC address. It can also be written to AO105.
  • MS/TP baud 9.6k, 19.2k, 38.4k or 76.8k; default 38.4k. Max_Master defaults to 127 and Max_Info_Frames to 1.
  • Use consecutive MAC addresses starting at 1, and set Max_Master to the highest MAC on the trunk.
  • Lennox recommends no repeaters and, above 9.6k baud, no more than 20 Lennox units and 30 devices per router.
  • Default device name is Lennox_M4_ followed by the MAC address.
  • Up to 32 units per MS/TP segment without a repeater.

Watch out for

  • Commands are not stored: rewrite all control points after every controller reset.
  • AO108 cannot be returned to the local setpoint once written, except by a controller reset.
  • AV130-133 are rejected as out of range if a heating setpoint is not below its cooling setpoint by the changeover deadband (Parameter 152, default 3 °F).
  • AO129 economizer control only works with the economizer in temperature mode (Configuration ID 1, position 2 = T).

Integration notes

  • Smaller sibling of the CORE Unit Controller: no BACnet IP, no occupancy override/sensor inputs (AO103, AO107), no static pressure or discharge air setpoints, no legacy error history or heat pump AVs.
  • AI253 Current Error is legacy; Lennox says to use CSV302 Alarm Log on new jobs.
  • AV142-AV143 appear only in the guide's object details and AV145 only in its object table; all three are listed here.
  • The guide's object tables list Present_Value as optionally writable for the CSV and MSV objects, but its quick start calls MSV310 and the status objects read-only; they report status, so they are shown read-only here.
  • The guide contradicts itself on COV: it says COV works with the plug-in module from firmware 9.03, and elsewhere that COV is not supported.

Questions about the Lennox CORE LITE Unit Controller

How many BACnet points does the Lennox CORE LITE Unit Controller have?

This list has 62 BACnet objects: 26 analog inputs, 17 analog outputs, 12 analog values, 3 multi-state values, 4 characterstring values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Lennox CORE LITE Unit Controller BACnet points are writable?

29 of the 62 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Lennox CORE LITE Unit Controller BACnet documentation?

The source is Lennox CORE LITE Unit Controller BACnet Setup Guide (508727-01), revision 04/2025, published free by Lennox at https://www.lennox.com/dA/84d3c99b01/508727-01.pdf.

What are the minimum BACnet points to integrate the Lennox CORE LITE Unit Controller?

Start with AO 104 Occupancy Scheduler Control (0 = occupied, 1-255 = unoccupied; rewrite every 2 min); AO 101 Application Mode Control (Mode command (0 = auto, 6 = off)); AV 130 Heating Occupied Setpoint (Occupied heating setpoint, 40-95 °F); AV 131 Cooling Occupied Setpoint (Occupied cooling setpoint, 40-95 °F); AV 132 Heating Unoccupied Setpoint (Unoccupied heating setpoint, 40-95 °F); AV 133 Cooling Unoccupied Setpoint (Unoccupied cooling setpoint, 40-95 °F); AO 113 Space Temperature Input (Network space temperature; rewrite every 2 min); AI 232 Unit Status (HVAC state code: 0 idle, 1 heat, 3 cool, 6 off, 9 fan); AI 239 Space Temperature (Space temperature in use); CSV 302 Alarm Log (Alarm codes, comma-separated; replaces AI 253).

How do I enable BMS control of the Lennox CORE LITE Unit Controller?

No BACnet enable point. Configuration ID 1 must show B so the BACnet options appear, then the wizard sets the Control Mode: Monitor Only ignores network setpoints and mode demands, Room Sensor (recommended) uses AO104 occupancy plus AV130-133 or AO109 setpoints. AO101 = 6 (Off) disables the whole unit.

Does the Lennox CORE LITE Unit Controller need a BACnet heartbeat or have a communication timeout?
