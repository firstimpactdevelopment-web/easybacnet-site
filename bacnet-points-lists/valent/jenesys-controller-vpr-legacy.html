Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX BACnet points list

Updated 6 November 2026

Short answer

Valent's older JENEsys controller (software version 4) supports optional, licensed BACnet IP and BACnet MS/TP. The BMS can enable BAS occupancy control and send the occupancy command, disable cooling or heating, issue an emergency shutdown, reset alarms, write space, supply, humidity, CO2 and static pressure setpoints, and send sensor values and fan and damper signals that override the unit's own. It reads temperatures, humidity, enthalpy, pressures, fan speeds, outputs, compressor and heat stages, alarms, occupancy mode and unit mode.

This page lists 108 BACnet objects for the Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX — 31 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Valent’s own free documentation, linked below.

BMS integration notes: Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX

Integration in brief

Check COMM LICENSE shows BACnet in the POINTS > COMMUNICATIONS menu and set the object ID and MS/TP address there. Set BV 15 to give the BAS occupancy control, then command occupancy with BV 16 and write the space temperature setpoint AV 30. Monitor occupancy mode, unit mode, supply temperature, fan status and the system alarm BV 21.

Enable & remote start

BV 15 BAS_Occ_Enable lets the BAS control occupancy through BV 16 BAS_Occ_Command. BV 19 is a BAS emergency shutdown command; BV 17 and BV 18 ask the unit to disable cooling or heating.

Sensors & values from the BMS

Writing the BAS-reported sensor AVs (AV 37-43: space temp, space RH, outdoor RH, outdoor temp, space and duct static, CO2) overrides the hardwired sensors. Fan speed and damper signals (AV 44-46) take effect when the matching override enable is set (BV 46-48).

Network setup

  • Object ID, IP and MS/TP network numbers and the MS/TP address are shown on the POINTS > COMMUNICATIONS tab of the LCD (example: object ID 11, MS/TP address 1).
  • BACnet IP uses the Ethernet port and BACnet MS/TP the 3-position RS-485 connector on the bottom of the controller.
  • COMM LICENSE must match the purchased protocol.

Watch out for

  • BAS sensor values replace hardwired sensors; stale values keep controlling the unit.
  • Settings cannot be changed until BACnet is licensed.

Integration notes

  • Writable points are the ones shaded as 'Editable' in the manual's BACnet Setpoint List; the manual says they accept writes at priorities 2-5 and 7-16.
  • BAS-reported sensor values (marked * in the manual) override any hardwired sensors while written.
  • BACnet is a licensed option; without the license the settings can be viewed but not changed.
  • Instances AV 33, BV 31 and BV 44 are not listed.
  • Engineering units are not printed in the BACnet table.
  • Source: BACnet Setpoint List, manual pages 34-36 (108 objects).

Questions about the Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX

How many BACnet points does the Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX have?

This list has 108 BACnet objects: 57 analog values, 49 binary values, 2 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX BACnet points are writable?

31 of the 108 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX?

Start with BV 15 BAS_Occ_Enable (Lets the BAS control occupancy); BV 16 BAS_Occ_Command (BAS occupancy command); AV 30 Space Temp Setpoint (Space temperature setpoint from the BAS); BV 20 AlarmReset (Alarm reset); MV 1 OccupancyMode (Occupancy mode (5 = occupied on)); MV 2 Unit Mode (Unit mode (fan only, cooling, heating, off...)); BV 3 SupplyFanStatus (Supply fan status); AV 1 Supply Temp (Supply air temperature); BV 21 Alarm Status (System alarm).

How do I enable BMS control of the Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX?

BV 15 BAS_Occ_Enable lets the BAS control occupancy through BV 16 BAS_Occ_Command. BV 19 is a BAS emergency shutdown command; BV 17 and BV 18 ask the unit to disable cooling or heating.

Can the BMS supply sensor values to the Valent JENEsys Controller (legacy) for VPR / VPRE / VPRC/P / VPRX?

Writing the BAS-reported sensor AVs (AV 37-43: space temp, space RH, outdoor RH, outdoor temp, space and duct static, CO2) overrides the hardwired sensors. Fan speed and damper signals (AV 44-46) take effect when the matching override enable is set (BV 46-48).
