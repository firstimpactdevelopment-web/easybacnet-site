BMS integration notes: ClimaCool SHC onDemand UCH Heat Pump (CoolLogic)

Integration in brief

Set the master controller DIP switches for the BMS port (MS/TP m protocol and baud), keep the device number at 516800, then set Control Source to BAS. Enable cooling and heating through the BAS enable points, write the leaving-water targets, and monitor unit mode, run commands and supply/return temperatures. Keep polling light: the IOM limits it to 50 points at 20-second intervals or slower.

Enable & remote start

Set the master panel LOCAL-OFF-REMOTE switch to Remote and turn Cool/Heat Mode BAS on; the bank then runs on the BAS command. Alternatives are a hard-wired remote enable relay (Digital Input mode) or keypad enable.

Sensors & values from the BMS

Remote cooling/heating targets can come in as analog inputs (input channel types 'Remote Cool Trg' / 'Remote Heat Trg', 4-20 mA or 2-10 VDC); the resulting values show in rem_chw_stp_stat_1 (AV 243) and rem_cw_stp_stat_1 (AV 246).

Network setup

  • Default master board device number is 516800; ClimaCool says other numbers need custom programming.
  • Port 1 is BACnet over ARC156 (Port 1 Mode jumper to ARC156); the BMS uses Port 2 with DIP 'BMS Port' ON and 'Enhanced Port 2a' OFF.
  • DIP switches 4-5 set the BMS baud rate and 6-8 the protocol; use 'MS/TP m' for BACnet MS/TP.
  • For BACnet IP set the IP-address DIP switch ON and configure the address in BACview under FN0 > IP; newer CoolLogic Touch panels use the Gig-E port for BACnet/IP.

Watch out for

  • Poll no more than 50 points, no faster than every 20 seconds.
  • When re-powering, the CoolLogic master must be the last device powered after the modules to restore communication.
  • Many writable points are configuration values (limits, delays, PID settings); limit BMS writes to enables and setpoints.

Questions about the ClimaCool SHC onDemand UCH Heat Pump (CoolLogic)

How many BACnet points does the ClimaCool SHC onDemand UCH Heat Pump (CoolLogic) have?

This list has 530 BACnet objects: 251 analog values, 261 binary values, 18 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which ClimaCool SHC onDemand UCH Heat Pump (CoolLogic) BACnet points are writable?

332 of the 530 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official ClimaCool SHC onDemand UCH Heat Pump (CoolLogic) BACnet documentation?

The source is Local Access Display Table - Product Line UCH, Chiller Type SHC-HP (UCH.SHC-HP.12b.13), published free by ClimaCool at https://files.climacoolcorp.com/Display-Tables/Control_Access_Display_Table_SHC-HP.pdf.

What are the minimum BACnet points to integrate the ClimaCool SHC onDemand UCH Heat Pump (CoolLogic)?

Start with MV 1 control_source_1 (Control source: Dig Input, Keypad or BAS); BV 576 enable_bas_cool_1 (Cool enable from the BAS); BV 577 enable_bas_heat_1 (Heat enable from the BAS); MV 16 unit_mode_1 (Unit mode / reason not running); BV 574 run_cool_1 (Chiller cool run command status); BV 575 run_heat_1 (Chiller heat run command status); AV 17 chws_stat_1 (Chilled water supply (leaving) temperature); AV 43 cws_stat_1 (Hot (condenser) water supply temperature); AV 41 chw_temp_stp_1 (Cooling leaving water target (writable)); AV 61 cw_temp_stp_1 (Heating leaving water target (writable)).

How do I enable BMS control of the ClimaCool SHC onDemand UCH Heat Pump (CoolLogic)?

Set the master panel LOCAL-OFF-REMOTE switch to Remote and turn Cool/Heat Mode BAS on; the bank then runs on the BAS command. Alternatives are a hard-wired remote enable relay (Digital Input mode) or keypad enable.

Can the BMS supply sensor values to the ClimaCool SHC onDemand UCH Heat Pump (CoolLogic)?

Remote cooling/heating targets can come in as analog inputs (input channel types 'Remote Cool Trg' / 'Remote Heat Trg', 4-20 mA or 2-10 VDC); the resulting values show in rem_chw_stp_stat_1 (AV 243) and rem_cw_stp_stat_1 (AV 246).
