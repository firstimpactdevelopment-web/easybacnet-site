Updated 4 November 2026

Short answer

JOY is a touch-display room thermostat that runs its own heating/cooling control for fan coils, valves and 6-way valves, with a time program, ECO mode and up to two universal inputs. Its BACnet MS/TP interface exposes the measured values and states, plus 'overwrite' objects the BMS uses to set occupancy, ECO, setpoint, change-over, fan stage and the outputs. Configuration is done with Thermokon's uConfig tool and sent as a file over BACnet.

BMS integration notes: Thermokon JOY BACnet room thermostats / fan coil controllers (5DO, ECAO2DO, HCAO2DO, EC3AO, HC3AO)

Integration in brief

Set the MAC address and baud rate in the JOY parameter menu, then command the unit through the overwrite objects: Device state (BV 1), occupancy (BV 2), ECO (BV 5), base setpoint (AV 1) and fan stage (MV 2). Read the room temperature, active setpoints, controller state and alarm inputs.

Enable & remote start

Device state overwrite (BV 1) switches the unit between on and standby; Occupancy state overwrite (BV 2) and ECO mode overwrite (BV 5) set the operating mode. An occupied command can override an active ECO mode if that option is configured.

Sensors & values from the BMS

Dew point (BV 3) and window (BV 4) states can come from the BMS instead of wired inputs. Writing the base setpoint (AV 1) overrides the time program until -1 is written back; output overwrites (AV 8-11) also use -1 for automatic.

Network setup

  • MAC address 0-127 and baud rate are set in the parameter menu.
  • Device instance = Offset Device ID (AV 100, default 100) + MAC address.
  • Configuration (time program, inputs, controller) is written as confJoy.bin through BACnet file transfer (FILE 0) with uConfig.

Watch out for

  • A written base setpoint stays in force and disables the time channel until -1 is written.
  • Output overwrite AVs keep forcing the output until set back to -1.

How many BACnet points does the Thermokon JOY BACnet room thermostats / fan coil controllers (5DO, ECAO2DO, HCAO2DO, EC3AO, HC3AO) have?

This list has 53 BACnet objects: 14 analog inputs, 7 analog values, 16 binary inputs, 6 binary values, 1 device, 1 file, 3 multi-state inputs, 5 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Thermokon JOY BACnet room thermostats / fan coil controllers (5DO, ECAO2DO, HCAO2DO, EC3AO, HC3AO) BACnet points are writable?

19 of the 53 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

What are the minimum BACnet points to integrate the Thermokon JOY BACnet room thermostats / fan coil controllers (5DO, ECAO2DO, HCAO2DO, EC3AO, HC3AO)?
