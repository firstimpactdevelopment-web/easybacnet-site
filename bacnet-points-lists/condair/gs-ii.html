Short answer

BMS integration notes: Condair Condair GS II

Integration in brief

Turn on BACnet in the Communication menu, set the control signal source to BACnet, and write demand or RH to AO 10044 (and a limiter value to AO 10045) within the BMS timeout. Read the operating and service status, error code and actual output.

Enable & remote start

Set Configuration > Control Settings > Source to BACnet (and the BACnet interface to MSTP or BACnet/IP); otherwise control values from BACnet are ignored and the unit follows its driver-board analog input.

Heartbeat & communication loss

BMS Timeout tab (1-300 s, default 300 s): if no valid control signal arrives from the BMS within this time, warning W35 BMS Timeout is raised and the unit stops until a valid signal returns. Only evaluated when the control signal source is not Analog, so keep rewriting the demand AO.

Sensors & values from the BMS

Control Mode Demand uses the AO as an output demand; RH P / RH PI modes use it as a measured humidity and the controller's setpoint/P-band AVs do the control. Setpoint and humidity can only be monitored through the controller in RH P/PI mode.

Network setup

  • Communication settings are in the Communication submenu (password 0335): BACnet = Off (factory), MSTP or BACnet/IP; some changes reboot the controller.
  • Node ID defaults to 1001 (range 1-4194303); BACnet IP port 47808; Foreign Device (BBMD) registration Off by default.
  • IP type defaults to DHCP and reverts to fixed addressing after 5 failed DHCP attempts.
  • MS/TP: Master by default, MAC 127 (0-127 master, 0-254 slave), baud 9600 (9600-76800).

Watch out for

  • Requires Integrated Controller software 5.10.1.14 or later for BACnet on-board.
  • Capacity units follow the Metric/Imperial setting.

Integration notes

  • BACnet is built into the Integrated Controller (RJ45 for BACnet IP, RS485 for MS/TP); no gateway card is needed.
  • To command the unit set the controller's signal source to BACnet; the demand AO must be refreshed within the signal timeout or the unit stops.
  • Channel 2 is a limiter (high-limit) signal.
  • Capacity units follow the controller's Metric/Imperial setting.

Questions about the Condair Condair GS II

How many BACnet points does the Condair Condair GS II have?

This list has 30 BACnet objects: 9 analog inputs, 2 analog outputs, 7 analog values, 9 binary inputs, 1 device, 2 multi-state inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Condair Condair GS II BACnet points are writable?

9 of the 30 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Condair Condair GS II BACnet documentation?

The source is BACnet on-board - Supplemental Installation and Operation Manual (RS, GS II, DL, ME and RO-A) (2595492-C), revision 2022-12, published free by Condair at https://www.condair.com/consense/bms-communication-ic-1.0/am_bms_interface_bacnet_on_board_2595492_en_condairltd.pdf.

What are the minimum BACnet points to integrate the Condair Condair GS II?

Start with AO 10044 Digital RH/Demand A1 (Demand or measured RH from the BMS); AO 10045 Digital RH/Demand A2 (Limiter (channel 2) signal from the BMS); AV 10010 Setpoint Channel 1 (Channel 1 humidity setpoint used in RH P/PI mode); AV 10008 Manual Capacity (Manual capacity limit); MI 614 Status (Operating status); MI 549 Service Status (Service/fault status); AI 10730 Error Code (Active error code); AI 10103 Output (Actual steam output).

How do I enable BMS control of the Condair Condair GS II?

Set Configuration > Control Settings > Source to BACnet (and the BACnet interface to MSTP or BACnet/IP); otherwise control values from BACnet are ignored and the unit follows its driver-board analog input.

Does the Condair Condair GS II need a BACnet heartbeat or have a communication timeout?

BMS Timeout tab (1-300 s, default 300 s): if no valid control signal arrives from the BMS within this time, warning W35 BMS Timeout is raised and the unit stops until a valid signal returns. Only evaluated when the control signal source is not Analog, so keep rewriting the demand AO.

Can the BMS supply sensor values to the Condair Condair GS II?

Control Mode Demand uses the AO as an output demand; RH P / RH PI modes use it as a measured humidity and the controller's setpoint/P-band AVs do the control. Setpoint and humidity can only be monitored through the controller in RH P/PI mode.

How do I check these points on the real Condair GS II?
