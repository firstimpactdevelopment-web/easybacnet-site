BMS integration notes: Condair Condair DL

Integration in brief

Turn on BACnet IP or MS/TP in the Integrated Controller, set the signal source to BACnet, then have the BMS write the demand or measured RH to AO 15059 at least every Signal Timeout period. Use BV 5187 for remote enable if Remote Enable is set to BACnet. Monitor the status and error MIs and the error code AI.

Enable & remote start

Set Menu > password 8808 > Controls > Signal Settings > Source to BACnet and pick the Control Mode (Demand, RH P or RH PI; On/Off also exists). With Source left at Analog the unit ignores BACnet control values. For BMS start/stop also set Remote Enable to BACnet; BV 5187 then enables the DL (controller software 1.4.0 or later).

Heartbeat & communication loss

When the signal source is not Analog, the demand/humidity value written over BACnet must be refreshed within the Signal Timeout (1-300 s, default 300 s). If it is not, warning W35 Signal Timeout is raised and the unit stops until a new value arrives, so the BMS must keep rewriting the AO.

Sensors & values from the BMS

In Demand mode the BMS writes the required output (0-100 %) to the RH/Demand AO. In RH P or RH PI mode the BMS writes the measured humidity there and the controller's own setpoint, P-band and I-time AVs do the control. Do not connect a hard-wired demand or sensor signal while the BACnet signal is used.

Network setup

  • BACnet settings are under Menu > password 8808 > Network > BACnet Settings; the BACnet Protocol parameter ships Off (options MS/TP Master, MS/TP Slave, BACnet/IP) and the controller restarts after changing it.
  • Node ID (device instance) defaults to 1001 (range 1-4194303); BACnet IP port defaults to 47808.
  • IP addressing defaults to DHCP; if no DHCP server answers the controller falls back to an APIPA 169.254.x.x address.
  • Foreign Device registration to a BBMD is Off by default; BBMD port 47808 and re-register time 10 are the factory values.
  • MS/TP: MAC defaults to 127 (0-127 master, 0-254 slave), baud 9600 (up to 115200); fit jumper JP6 only on the first and last device, remove JP8, and tie GND between all devices.

Watch out for

  • AO 15059 has a relinquish default of 0, so releasing it drops demand to zero.
  • Flushing and Ceramic Wash Over AVs: write 1 to start and 0 to stop; reading 100 means off and 0-99 is progress in %.
  • Points marked optional only report when the option is fitted.
  • Capacity, pressure and temperature units follow the controller's Metric/Imperial setting.

Integration notes

  • BACnet is built into the Integrated Controller (RJ45 for BACnet IP, RS485 for MS/TP master or slave); it ships with the BACnet protocol set to Off.
  • Factory Node ID (device instance) is 1001 and the MS/TP MAC is 127; BACnet IP uses UDP 47808 and supports registering with a BBMD.
  • To command the unit over BACnet set Controls > Signal Settings > Source to BACnet; the demand/humidity AO must then be rewritten within the Signal Timeout (default 300 s) or the unit stops with warning W35.
  • Points marked optional only report when that option is fitted; capacity, pressure and temperature units follow the controller's Metric/Imperial setting.
  • Remote enable over BACnet (BV 5187) needs Remote Enable set to BACnet and controller software 1.4.0 or later.

Questions about the Condair Condair DL

How many BACnet points does the Condair Condair DL have?

This list has 41 BACnet objects: 14 analog inputs, 1 analog output, 6 analog values, 14 binary inputs, 1 binary value, 1 device, 3 multi-state inputs, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Condair Condair DL BACnet points are writable?

9 of the 41 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Condair Condair DL BACnet documentation?

The source is BACnet on-board - Addendum manual for installation and operation (DL II, ME II, RS II, RO-E and Vita) (2603582-F), revision 2026-07, published free by Condair at https://www.condair.co.uk/consense/bms-communication-ic-2.0/am_bms_interface_bacnet_on_board_2603582_en.pdf.

Capacity (Actual spray water output); AV 15050 Setpoint (Humidity setpoint when using RH P/PI mode); AI 15068 Humidity Control (Humidity or demand the unit is acting on).

How do I enable BMS control of the Condair Condair DL?

Set Menu > password 8808 > Controls > Signal Settings > Source to BACnet and pick the Control Mode (Demand, RH P or RH PI; On/Off also exists). With Source left at Analog the unit ignores BACnet control values. For BMS start/stop also set Remote Enable to BACnet; BV 5187 then enables the DL (controller software 1.4.0 or later).

Does the Condair Condair DL need a BACnet heartbeat or have a communication timeout?
