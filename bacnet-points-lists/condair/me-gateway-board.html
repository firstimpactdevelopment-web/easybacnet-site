Short answer

Condair ME units can reach BACnet IP or MS/TP through the optional ProtoCessor gateway board. The virtual device reports status, maintenance countdowns, per-stage capacity and pump demand, water and air temperature, faults, and offers writable humidity and temperature loops, wash-over/drain commands and demand inputs.

BMS integration notes: Condair Condair ME (BACnet gateway board)

Integration in brief

Configure the ME controller for Modbus RTU with Signal Source = Modbus and System Mode (Humidifying or Cooling), set up the gateway's BACnet side, and write demand/RH to AO 1 and, for cooling, air temperature to AO 2. Check BI 19 for gateway-to-unit communication.

Enable & remote start

Set Control Settings (password 0335) > Signal Source to Modbus, choose the Control Mode (Demand, RH P or RH PI), and set the controller's Modbus RTU parameters to match the gateway. On the ME also set System Mode to Humidifying or Cooling.

Heartbeat & communication loss

Controller BMS Timeout (1-300 s, default 300 s): if the control signal is not updated within the timeout, warning W35 BMS Timeout is raised and humidification stops until a valid signal returns. The gateway only forwards the control value to the humidifier when it changes.

Sensors & values from the BMS

In Demand mode the BMS writes the required output (0-100 %) to the AO 1. In RH P or RH PI mode the BMS writes the measured humidity there and the controller's own setpoint, P-band and I-time AVs do the control. Do not connect a hard-wired demand or sensor signal while the BACnet signal is used. AO 2 carries the air temperature for cooling control.

Network setup

  • Integrated Controller Communication submenu (password 0335): Modbus/RTU, address 10, even parity, 9600 baud, MSR first; disable the controller's own BACnet function.
  • Gateway factory settings: BACnet IP device instance DL 300, ME 410, RS 710 (EL 220); MS/TP 9600 baud, MAC 127, Node_ID 1001.
  • Gateway IP defaults to 192.168.1.24/24 for boards built from February 2022 (10.232.72.172/16 before); configure via the FS-GUI web page on port 80.
  • Device instance, network number (default 101) and MS/TP MAC are edited in the gateway's config.csv.

Watch out for

  • Because the gateway only passes the control value on when it changes, rewriting an identical value may not refresh the controller's BMS timeout; the manual does not describe a workaround.
  • Object names and instances differ from the BACnet on-board interface of the same humidifier; do not reuse an on-board mapping.
  • Capacity, pressure and temperature units follow the controller's Metric/Imperial setting.

Integration notes

  • These objects belong to the optional ProtoCessor (FieldServer) BACnet/LonWorks gateway board, not the BACnet on-board interface; object names and instances differ between the two.
  • Gateway defaults: IP 192.168.1.24 (boards shipped from February 2022; earlier boards 10.232.72.172), network number 101, MS/TP MAC 127 and MS/TP Node_ID 1001; settings are edited in the gateway's config.csv via its web GUI.
  • The gateway talks to the Integrated Controller over Modbus RTU, so the controller signal source is set to Modbus (not BACnet) and its own BACnet on-board function must be Off.
  • Capacity, pressure and temperature units follow the controller's Metric/Imperial setting.

Questions about the Condair Condair ME (BACnet gateway board)

How many BACnet points does the Condair Condair ME (BACnet gateway board) have?

This list has 59 BACnet objects: 27 analog inputs, 2 analog outputs, 7 analog values, 19 binary inputs, 1 binary value, 1 device, 2 multi-state inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Condair Condair ME (BACnet gateway board) BACnet points are writable?

10 of the 59 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Condair Condair ME (BACnet gateway board) BACnet documentation?

The source is Gateway Board for BACnet and LonWorks - Supplemental Installation and Operation Manual (2585293-L), revision 2022-02, published free by Condair at https://www.condair.com/consense/bms-communication-ic-1.0/am_bms_interface_2585293_en_condairltd.pdf.

What are the minimum BACnet points to integrate the Condair Condair ME (BACnet gateway board)?

Start with AO 1 AO_RemRHorDem (Demand or measured RH from the BMS); AO 2 AO_RemTemp (Air temperature from the BMS (cooling)); AV 1 AV_SetPointHum (Humidity setpoint used in RH P/PI mode); MI 1 MI_HumStatus (Operating status); MI 2 MI_ServStatus (Maintenance/fault status); AI 1 AI_ErrorCode (Active error code); BI 19 BI_Connection (Gateway-to-humidifier node status); BV 1 BV_Reset (Remote reset).

How do I enable BMS control of the Condair Condair ME (BACnet gateway board)?

Set Control Settings (password 0335) > Signal Source to Modbus, choose the Control Mode (Demand, RH P or RH PI), and set the controller's Modbus RTU parameters to match the gateway. On the ME also set System Mode to Humidifying or Cooling.

Does the Condair Condair ME (BACnet gateway board) need a BACnet heartbeat or have a communication timeout?

Controller BMS Timeout (1-300 s, default 300 s): if the control signal is not updated within the timeout, warning W35 BMS Timeout is raised and humidification stops until a valid signal returns. The gateway only forwards the control value to the humidifier when it changes.

Can the BMS supply sensor values to the Condair Condair ME (BACnet gateway board)?

In Demand mode the BMS writes the required output (0-100 %) to the AO 1. In RH P or RH PI mode the BMS writes the measured humidity there and the controller's own setpoint, P-band and I-time AVs do the control. Do not connect a hard-wired demand or sensor signal while the BACnet signal is used. AO 2 carries the air temperature for cooling control.
