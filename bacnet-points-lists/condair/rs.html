Short answer

The Condair RS is an electric heating-element steam humidifier with one or two cylinders. The Integrated Controller exposes BACnet IP and MS/TP on-board. Objects report per-cylinder status, level, capacity, maintenance countdowns and safety chain inputs, plus two-channel setpoints and writable demand inputs for main and limiter signals.

BMS integration notes: Condair Condair RS

Integration in brief

Enable BACnet in the Integrated Controller, set the signal source to BACnet, and write demand or RH to AO 15012 (and a limiter value to AO 15014 if dual signal control is used) within the signal timeout. Read cylinder A/B status, the error status and code, and actual capacity.

Enable & remote start

Set Menu > password 8808 > Controls > Signal Settings > Source to BACnet and pick the Control Mode (Demand, RH P or RH PI; On/Off also exists). With Source left at Analog the unit ignores BACnet control values.

Heartbeat & communication loss

When the signal source is not Analog, the demand/humidity value written over BACnet must be refreshed within the Signal Timeout (1-300 s, default 300 s). If it is not, warning W35 Signal Timeout is raised and the unit stops until a new value arrives, so the BMS must keep rewriting the AO.

Sensors & values from the BMS

In Demand mode the BMS writes the required output (0-100 %) to the RH/Demand AO. In RH P or RH PI mode the BMS writes the measured humidity there and the controller's own setpoint, P-band and I-time AVs do the control. Do not connect a hard-wired demand or sensor signal while the BACnet signal is used. Channel 2 (AO 15014) is only active with dual signal control, typically a supply-air high limit.

Network setup

  • BACnet settings are under Menu > password 8808 > Network > BACnet Settings; the BACnet Protocol parameter ships Off (options MS/TP Master, MS/TP Slave, BACnet/IP) and the controller restarts after changing it.
  • Node ID (device instance) defaults to 1001 (range 1-4194303); BACnet IP port defaults to 47808.
  • IP addressing defaults to DHCP; if no DHCP server answers the controller falls back to an APIPA 169.254.x.x address.
  • Foreign Device registration to a BBMD is Off by default; BBMD port 47808 and re-register time 10 are the factory values.
  • MS/TP: MAC defaults to 127 (0-127 master, 0-254 slave), baud 9600 (up to 115200); fit jumper JP6 only on the first and last device, remove JP8, and tie GND between all devices.

Watch out for

  • Cylinder B objects only mean something on dual-cylinder units.
  • BI 28 is Remote Furnace/Fan on UL units and External Pipe Flush on CE units.
  • RS Drain AVs: write 1 to start, 0 to stop; a read of 100 means off.
  • Capacity units follow the Metric/Imperial setting.

Integration notes

  • BACnet is built into the Integrated Controller (RJ45 for BACnet IP, RS485 for MS/TP master or slave); it ships with the BACnet protocol set to Off.
  • Factory Node ID (device instance) is 1001 and the MS/TP MAC is 127; BACnet IP uses UDP 47808 and supports registering with a BBMD.
  • To command the unit over BACnet set Controls > Signal Settings > Source to BACnet; the demand/humidity AO must then be rewritten within the Signal Timeout (default 300 s) or the unit stops with warning W35.
  • Points marked optional only report when that option is fitted; capacity, pressure and temperature units follow the controller's Metric/Imperial setting.
  • Cylinder B objects only apply to dual-cylinder units; channel 2 is used for a limiter (e.g. supply-air high limit) when dual signal control is enabled.
  • BI 28 is Furnace Fan on UL units and External Pipe Flush on CE units.

Questions about the Condair Condair RS

How many BACnet points does the Condair Condair RS have?

This list has 62 BACnet objects: 19 analog inputs, 2 analog outputs, 10 analog values, 25 binary inputs, 1 device, 4 multi-state inputs, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Condair Condair RS BACnet points are writable?

13 of the 62 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
