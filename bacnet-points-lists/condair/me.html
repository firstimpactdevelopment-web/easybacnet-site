Short answer

The Condair ME is a multi-stage evaporative humidifier and adiabatic cooler. The Integrated Controller exposes BACnet IP and MS/TP on-board. Points include operating and error status, per-stage capacity and pump speeds, tank level, water quality, separate humidity and cooling PI loops, and writable humidity/demand and temperature inputs.

BMS integration notes: Condair Condair ME

Integration in brief

Enable BACnet in the Integrated Controller, set the signal source to BACnet, and write humidity demand (or measured RH) to AO 15044 within the signal timeout. When the ME runs as an evaporative cooler in system mode, also write the temperature to AO 15045. Monitor status, error status and the error code.

Enable & remote start

Set Menu > password 8808 > Controls > Signal Settings > Source to BACnet and pick the Control Mode (Demand, RH P or RH PI; On/Off also exists). With Source left at Analog the unit ignores BACnet control values.

Heartbeat & communication loss

When the signal source is not Analog, the demand/humidity value written over BACnet must be refreshed within the Signal Timeout (1-300 s, default 300 s). If it is not, warning W35 Signal Timeout is raised and the unit stops until a new value arrives, so the BMS must keep rewriting the AO.

Sensors & values from the BMS

In Demand mode the BMS writes the required output (0-100 %) to the RH/Demand AO. In RH P or RH PI mode the BMS writes the measured humidity there and the controller's own setpoint, P-band and I-time AVs do the control. Do not connect a hard-wired demand or sensor signal while the BACnet signal is used. For cooling, AO 15045 carries the air temperature (relinquish default 20 °C) and is only active when the ME is operated in system mode.

Network setup

  • BACnet settings are under Menu > password 8808 > Network > BACnet Settings; the BACnet Protocol parameter ships Off (options MS/TP Master, MS/TP Slave, BACnet/IP) and the controller restarts after changing it.
  • Node ID (device instance) defaults to 1001 (range 1-4194303); BACnet IP port defaults to 47808.
  • IP addressing defaults to DHCP; if no DHCP server answers the controller falls back to an APIPA 169.254.x.x address.
  • Foreign Device registration to a BBMD is Off by default; BBMD port 47808 and re-register time 10 are the factory values.
  • MS/TP: MAC defaults to 127 (0-127 master, 0-254 slave), baud 9600 (up to 115200); fit jumper JP6 only on the first and last device, remove JP8, and tie GND between all devices.

Watch out for

  • AO 15044 relinquishes to 0 % demand.
  • Draining and Matrix Wash Over AVs: write 1 to start, 0 to stop; a read of 100 means off.
  • Optional sensors (UV, conductivity, water/air temperature, tank levels) only report when fitted.
  • Temperature and capacity units follow the Metric/Imperial setting.

Integration notes

  • BACnet is built into the Integrated Controller (RJ45 for BACnet IP, RS485 for MS/TP master or slave); it ships with the BACnet protocol set to Off.
  • Factory Node ID (device instance) is 1001 and the MS/TP MAC is 127; BACnet IP uses UDP 47808 and supports registering with a BBMD.
  • To command the unit over BACnet set Controls > Signal Settings > Source to BACnet; the demand/humidity AO must then be rewritten within the Signal Timeout (default 300 s) or the unit stops with warning W35.
  • Points marked optional only report when that option is fitted; capacity, pressure and temperature units follow the controller's Metric/Imperial setting.
  • The temperature AO (15045) is only used when the ME runs in cooling/system mode.

Questions about the Condair Condair ME

How many BACnet points does the Condair Condair ME have?

This list has 61 BACnet objects: 27 analog inputs, 2 analog outputs, 9 analog values, 19 binary inputs, 1 device, 2 multi-state inputs, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Condair Condair ME BACnet points are writable?

12 of the 61 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Condair Condair ME BACnet documentation?

The source is BACnet on-board - Addendum manual for installation and operation (DL II, ME II, RS II, RO-E and Vita) (2603582-F), revision 2026-07, published free by Condair at https://www.condair.co.uk/consense/bms-communication-ic-2.0/am_bms_interface_bacnet_on_board_2603582_en.pdf.
