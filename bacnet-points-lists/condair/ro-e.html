BMS integration notes: Condair Condair RO-E

Integration in brief

The RO-E is monitoring-focused: enable BACnet in its Integrated Controller and read status, service status, error code, pressures and permeate quality. The only writable items are the tank pressure start/stop limits and an error/warning reset.

Network setup

  • BACnet settings are under Menu > password 8808 > Network > BACnet Settings; the BACnet Protocol parameter ships Off (options MS/TP Master, MS/TP Slave, BACnet/IP) and the controller restarts after changing it.
  • Node ID (device instance) defaults to 1001 (range 1-4194303); BACnet IP port defaults to 47808.
  • IP addressing defaults to DHCP; if no DHCP server answers the controller falls back to an APIPA 169.254.x.x address.
  • Foreign Device registration to a BBMD is Off by default; BBMD port 47808 and re-register time 10 are the factory values.

Watch out for

  • Permeate conductivity and drain valve are optional on RO-E and standard on RO-E+; the permeate valve is RO-E+ only.
  • AV 10127/10128 set the tank refill start/stop pressures.
  • Pressure, temperature and flow units follow the Metric/Imperial setting.

Integration notes

  • BACnet is built into the Integrated Controller (RJ45 for BACnet IP, RS485 for MS/TP master or slave); it ships with the BACnet protocol set to Off.
  • Factory Node ID (device instance) is 1001 and the MS/TP MAC is 127; BACnet IP uses UDP 47808 and supports registering with a BBMD.
  • Some points are RO-E+ only or optional on the RO-E (permeate conductivity, drain valve, permeate valve).
  • Pressure, temperature and flow units follow the controller's Metric/Imperial setting.

Questions about the Condair Condair RO-E

How many BACnet points does the Condair Condair RO-E have?

This list has 24 BACnet objects: 10 analog inputs, 3 analog values, 5 binary inputs, 1 device, 4 multi-state inputs, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Condair Condair RO-E BACnet points are writable?

4 of the 24 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Condair Condair RO-E BACnet documentation?

The source is BACnet on-board - Addendum manual for installation and operation (DL II, ME II, RS II, RO-E and Vita) (2603582-F), revision 2026-07, published free by Condair at https://www.condair.co.uk/consense/bms-communication-ic-2.0/am_bms_interface_bacnet_on_board_2603582_en.pdf.

What are the minimum BACnet points to integrate the Condair Condair RO-E?

Start with MI 121 RO Device Status (RO operating status); MI 122 RO Service Status (Maintenance/warning/error status); AI 10020 ErrorWarning Code (Active error or warning code); AI 10144 RO Permeate Conductivity (Permeate conductivity (water quality)); AI 10142 RO Tank Pressure (Product water tank pressure); AI 10210 RO Next Disinfection (Days to next disinfection); AV 30002 Error/Warning Reset (Remote error/warning reset).

How do I check these points on the real Condair RO-E?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
