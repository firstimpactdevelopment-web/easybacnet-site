Short answer

Condair Vita is a high-pressure water atomising system that serves up to 50 humidification areas from one System Master. BACnet on-board reports the reverse osmosis, deionisation and high-pressure stage states, system error category and code, and per-area state, temperature, humidity and a writable per-area humidity setpoint.

BMS integration notes: Condair Condair Vita

Integration in brief

Enable BACnet in the Vita System Master and alarm on error categories 1-7 (1 = most severe) plus the error code. Per-area state, temperature and humidity are read from instance blocks offset by area number, and each area's humidity setpoint can be written.

Sensors & values from the BMS

No BMS-fed sensor inputs are listed; the BMS can write each area's humidity setpoint (AV 1611600-1611649, 20-100 %).

Network setup

  • BACnet settings are under Menu > password 8808 > Network > BACnet Settings; the BACnet Protocol parameter ships Off (options MS/TP Master, MS/TP Slave, BACnet/IP) and the controller restarts after changing it.
  • Node ID (device instance) defaults to 1001 (range 1-4194303); BACnet IP port defaults to 47808.
  • IP addressing defaults to DHCP; if no DHCP server answers the controller falls back to an APIPA 169.254.x.x address.
  • Foreign Device registration to a BBMD is Off by default; BBMD port 47808 and re-register time 10 are the factory values.

Watch out for

  • Condair recommends alarming only on error categories 1-7 (7 = urgent warning or worse) to avoid nuisance alarms; category 11 (no error) needs software 3.2.0 or later.
  • Wrong area setpoints or bad sensor values can cause water damage; the operator must check them.
  • Only installed areas (see AI 15112 Number of Areas) return meaningful data.
  • Timestamp AIs are in seconds since an epoch, not dates.

Integration notes

  • BACnet is built into the Integrated Controller (RJ45 for BACnet IP, RS485 for MS/TP master or slave); it ships with the BACnet protocol set to Off.
  • Factory Node ID (device instance) is 1001 and the MS/TP MAC is 127; BACnet IP uses UDP 47808 and supports registering with a BBMD.
  • Per-area objects use instance blocks (e.g. MI 603100-603149, AV 1611600-1611649), one instance per area 1-50; only installed areas are meaningful.
  • Condair recommends alarming in the BMS only on error category 7 and higher; category 11 (no error) needs software 3.2.0 or later.
  • Wrong area setpoints or sensor values can cause water damage; the operator is responsible for checking them.

Questions about the Condair Condair Vita

How many BACnet points does the Condair Condair Vita have?

This list has 214 BACnet objects: 107 analog inputs, 50 analog values, 1 device, 56 multi-state inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Condair Condair Vita BACnet points are writable?

50 of the 214 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Condair Condair Vita BACnet documentation?

The source is BACnet on-board - Addendum manual for installation and operation (DL II, ME II, RS II, RO-E and Vita) (2603582-F), revision 2026-07, published free by Condair at https://www.condair.co.uk/consense/bms-communication-ic-2.0/am_bms_interface_bacnet_on_board_2603582_en.pdf.

What are the minimum BACnet points to integrate the Condair Condair Vita?

Start with AV 1611600 Area Setpoint 1 (Area 1 humidity setpoint); MI 5035 Pressure Status HP Line (High-pressure stage status); MI 5033 Reverse Osmosis State (Reverse osmosis stage status); MI 603100 Area State 1 (Area 1 state (one per area)); AI 1611300 Actual Humidity Area 1 (Measured RH in area 1, %); MI 5055 Error Category (Error severity; alarm on categories 1-7 (11 = no error)); AI 15232 Error Code (System Master error code).

Can the BMS supply sensor values to the Condair Condair Vita?

No BMS-fed sensor inputs are listed; the BMS can write each area's humidity setpoint (AV 1611600-1611649, 20-100 %).

How do I check these points on the real Condair Vita?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
