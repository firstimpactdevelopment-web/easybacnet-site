Short answer

The Lx5 is the controller in Blue Ridge Technologies lighting relay panels. Inputs (switches, occupancy sensors) control groups of relays, and BACnet MS/TP gives the BMS the same group-level control: each of the 60 groups has a command multistate value, binary and multistate status, a timer and a local schedule. The list adds six analog light-level inputs with their sensor ranges, the status of 60 relays and six common alarm flags.

BMS integration notes: Blue Ridge Technologies BR Series lighting controller (Lx5)

Integration in brief

Command each lighting group with its MV n (4 = ON, 3 = OFF, 2 = OFF with flash warning, 1 = do nothing) and read back BV 100+n or MV 100+n. Use either the BMS command or the group's local schedule, not both. Relay status (BV 201-260) and light levels are read-only.

Enable & remote start

Each group is commanded by its MV (cmd_GG). Write 1 (Do Nothing / null) in manual-on sequences or sweeps that need repeated OFF commands.

Network setup

  • Device ID is 132 (Blue Ridge vendor ID) followed by 0 and the two-digit Lx5 network address (1-99) set on rotary switches SW3/SW4, e.g. 132005 for address 5.
  • Baud rate, protocol and termination are set on the Lx5 hardware (see the Lx5 Hardware User Guide); fit the BT485 terminator on end-of-line controllers.
  • Default write priorities: BAS manual override 8, schedules 15/16, local overrides 16; Blue Ridge advises against changing them.

Watch out for

  • Do not use the group's local schedule and the BMS group command on the same group; clear the local schedule when the BMS commands it.
  • Command 2 (OFF with flash warning) uses the default flash warning parameters set in LPPK; no local flash settings are needed.
  • Only the groups programmed in the panel do anything; the object list always shows all 60.

Integration notes

  • Each of the 60 groups has five objects: Schedule n, BV 100+n, MV n, MV 100+n and AV n.
  • Analog inputs 1-6 are read as foot-candles (AV 101-106) and lux (AV 111-116); AV 121-136 set each sensor's minimum and maximum.
  • Relay status objects BV 201-260 cover relays 1-60; groups and relays not used in the panel still appear in the list.
  • The six common alarms (BV 4000000-4000005) are listed in the document as event alarms.
  • Access comes from the function table: commands, schedules and sensor ranges are read/write, all status objects read-only.

Questions about the Blue Ridge Technologies BR Series lighting controller (Lx5)

How many BACnet points does the Blue Ridge Technologies BR Series lighting controller (Lx5) have?

This list has 390 BACnet objects: 84 analog values, 126 binary values, 60 schedules, 120 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Blue Ridge Technologies BR Series lighting controller (Lx5) BACnet points are writable?

132 of the 390 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Blue Ridge Technologies BR Series lighting controller (Lx5) BACnet documentation?

Blue Ridge Technologies does not publish it on its own website. Ask Blue Ridge Technologies or its representative for the current revision.

What are the minimum BACnet points to integrate the Blue Ridge Technologies BR Series lighting controller (Lx5)?

Start with MV 1 cmd_1 (Group 1 command: 4 = ON, 3 = OFF, 2 = OFF+flash); BV 101 b_groupstat_1 (Group 1 on/off status); MV 101 ms_groupstat_1 (Group 1 state and what switched it); AV 1 timer_1 (Group 1 timer count-down, s); BV 201 relay1stat_61 (Relay 1 status); AV 101 ai1_fc_61 (Light level input 1, fc); BV 4000000 Module Halted Alarm (Controller halted).

How do I enable BMS control of the Blue Ridge Technologies BR Series lighting controller (Lx5)?

Each group is commanded by its MV (cmd_GG). Write 1 (Do Nothing / null) in manual-on sequences or sweeps that need repeated OFF commands.
