Short answer

Addison's ODO program runs on a factory OEMCtrl LS-1628u controller and exposes about 420 analog, binary and multistate value objects over BACnet IP. The list covers unit enable and occupancy, BMS-written sensor values, zone and discharge setpoints for cooling, heating and dehumidification, supply and exhaust fan and outdoor air flow control, compressor circuit data and a long set of alarm flags. Addison publishes it as a preliminary beta release.

This page lists 416 BACnet objects for the Addison ODO (On-Demand Options) outdoor air unit controls — 137 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Addison’s own free documentation, linked below.

BMS integration notes: Addison ODO (On-Demand Options) outdoor air unit controls

Integration in brief

Leave Unit Enable (BV 1) on and use BAS Manual Occ Control (BV 4) for occupancy, after checking which occupancy source MV 3 selects on the unit. Adjust the discharge cooling and heating supply air setpoints (AV 113, AV 413) if needed and feed outdoor or zone values from the BMS only if the unit is set to use them. Monitor State (MV 1), Mode (MV 2), Occupancy Status (BV 8), supply air temperature (AV 29) and Alarm Status (BV 27).

Enable & remote start

Per Addison's ODO startup guide, the unit is enabled when the internal software enable (BV 1 Unit Enable, default on) is on or the hardwired unit enable input is closed, with no shutdown condition; BV 3 shows the result. It is occupied when the internal occupancy control or the occupancy input calls for it. The occupancy source is chosen with Occupancy Control Options (MV 3) and a backup source with MV 4; the list prints no state texts for them.

Heartbeat & communication loss

The list has a BAS LOST alarm (BV 28) and a Communication Monitoring Status (BV 11), but gives no timeout or fallback behaviour.

Sensors & values from the BMS

Writable BMS inputs: OAT from BAS (AV 20, default 60 °F), OARH from BAS (AV 19), ZAT From BAS (AV 34), Z-RH From BAS (AV 32) and CO2 From BAS (AV 723). The list does not say which setting makes the unit use them instead of its own sensors.

Network setup

  • The ODO startup guide sets the BACnet IP port and device parameters on the LS-1628u Service Page (Device, Ports and BACnet tabs); the BACnet UDP port shown is 47808.
  • The startup guide's Device tab shows the device instance set to Autogenerated, with an Assigned option; the points list gives no default.

Watch out for

  • Beta release: object IDs may change in later versions of the list.
  • BV 1 Unit Enable does not stop the unit if the hardwired unit enable input is closed.
  • Several objects share a display name; map by object ID and check the reference name.

Integration notes

  • Addison marks this list as a beta (preliminary) release dated 1/2/2026; confirm object IDs and names against the unit before mapping.
  • Four rows print Object ID 0 (BV EXCESS OA, BV SCT1 FAIL, BV SCT2 FAIL and an MSV named 'point name', ref zn_prss_stat). They are not addressable as printed and are left out: 416 of 420 rows listed.
  • The doc gives a display name and a reference name for each object; names here are the display names and each description carries the reference name (ref ...), which may be the name the controller shows.
  • Some display names repeat for different objects as printed: AV 102/103 and AV 402/403 are all 'Unoccupied Zone Cooling Set Points' (the reference names show occupied/unoccupied cooling and heating), plus DCV CO2 Minimum, Manual OA % Of Design, Comp Disable High Humidity and Disc Dehum Disable LDB pairs.
  • Multistate objects are listed as MSV in the doc with no state texts; read the state text from the unit. Factory default values for writable points are given in the descriptions.
  • The table covers all ODO options (two compressor circuits, ECW, exhaust fan, dampers, DCV); expect objects for features a given unit does not have.

Questions about the Addison ODO (On-Demand Options) outdoor air unit controls

How many BACnet points does the Addison ODO (On-Demand Options) outdoor air unit controls have?

This list has 416 BACnet objects: 237 analog values, 165 binary values, 14 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Addison ODO (On-Demand Options) outdoor air unit controls BACnet points are writable?

137 of the 416 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Addison ODO (On-Demand Options) outdoor air unit controls BACnet documentation?

The source is Addison ODO BACnet Points List, Beta (Preliminary), revision 2026-01-02, published free by Addison at https://www.addison-hvac.com/wp-content/uploads/2026/05/ODO_BACnet_Beta-2.pdf.

What are the minimum BACnet points to integrate the Addison ODO (On-Demand Options) outdoor air unit controls?

Start with BV 1 Unit Enable (Software unit enable from the BMS); BV 4 BAS Manual Occ Control (Occupancy control from the BMS); AV 113 Discharge Cooling SAT SP (Supply air setpoint in discharge cooling, °F); AV 413 Discharge Heating SAT SP (Supply air setpoint in discharge heating, °F); BV 26 Alarm Reset (Resets latched alarms); MV 1 State (Unit operating state); MV 2 Mode (Active operating mode); BV 8 Occupancy Status (Confirms the unit is occupied); AV 29 SAT Status (Supply air temperature); BV 27 Alarm Status (Any active alarm).

How do I enable BMS control of the Addison ODO (On-Demand Options) outdoor air unit controls?

Per Addison's ODO startup guide, the unit is enabled when the internal software enable (BV 1 Unit Enable, default on) is on or the hardwired unit enable input is closed, with no shutdown condition; BV 3 shows the result. It is occupied when the internal occupancy control or the occupancy input calls for it. The occupancy source is chosen with Occupancy Control Options (MV 3) and a backup source with MV 4; the list prints no state texts for them.

Does the Addison ODO (On-Demand Options) outdoor air unit controls need a BACnet heartbeat or have a communication timeout?

The list has a BAS LOST alarm (BV 28) and a Communication Monitoring Status (BV 11), but gives no timeout or fallback behaviour.

Can the BMS supply sensor values to the Addison ODO (On-Demand Options) outdoor air unit controls?

Writable BMS inputs: OAT from BAS (AV 20, default 60 °F), OARH from BAS (AV 19), ZAT From BAS (AV 34), Z-RH From BAS (AV 32) and CO2 From BAS (AV 723). The list does not say which setting makes the unit use them instead of its own sensors.
