Short answer

The HTP 7350P-636 adapter plugs into the appliance's BIC-926/928 control and serves it on BACnet MS/TP (or Modbus RTU). It reports thermostat and safety inputs, pump, gas valve and alarm outputs, outlet, inlet and flue temperatures, firing rates and status/blocking/lockout codes for up to 8 cascaded boilers, and BIC-928 run-hour and fault counters. The BMS writes a configuration word that decides which values it supplies (enable, setpoint or rate, DHW setpoint, outdoor and system temperatures) and then writes those values.

BMS integration notes: HTP MODBUS/BACnet Adapter 7350P-636 (BIC-926/928 boilers and water heaters)

Integration in brief

Set the adapter for BACnet with its DIP switch, set the address and baud rate in the appliance installer menu, and discover it. Write AV 0 Configuration to say which values the BMS supplies, then write the coils (AV 1) for CH/DHW demand and the setpoint or rate (AV 2) and DHW setpoint (AV 3). Rewrite them at least once a minute, and read outlet temperature, firing rate and the status and lockout codes.

Enable & remote start

Set configuration bit B0 (boiler enable) or B1 (tank enable) in AV 0, then write the AV 1 Coils bits: b0 room thermostat (CH demand), b4 tank thermostat (DHW demand).

Heartbeat & communication loss

A 4-minute communication timer returns the appliance to its own controls if no write arrives; each write resets it. Update temperature values at least once a minute but not more than once a second.

Sensors & values from the BMS

Setting configuration bits B4-B7 makes the appliance use the BMS-written DHW temperature (AV 4), outdoor temperature (AV 5), system supply (AV 6) and system return (AV 7) instead of its own sensors.

Network setup

  • DIP switch 10 ON selects BACnet (OFF = Modbus); installer menu parameter 37 MODBUS MODE must be ON or AUTO (factory default OFF).
  • The appliance can also run on its own controls with the BMS only reading values (monitoring only).

Watch out for

  • While the BMS writes tank temperature and tank enable, the appliance ignores its internal DHW limit.
  • A bit set in AV 0 tells the appliance to ignore its own value and wait for the BMS one; leave bits clear for values it should measure itself.

Integration notes

  • The manual table gives no object names; names here are the 'Heating Appliance' descriptions. Where the water heater meaning differs it is in the description.
  • The manual header gives part # 64980290; HTP sells the adapter as 7350P-636. The source PDF is scanned (image only); this list was keyed from the page images and checked row by row.
  • Objects marked BIC-928 only (bold italics in the manual) do not exist on BIC-926 appliances.
  • Access is not printed per object: AV and BV (holding registers / coils) are taken as writable, AI and BI as read-only.
  • Temperatures are °F with 0.1 resolution; setpoint objects marked * are only valid during a heating cycle. AI 92-96 counts are in units of 5 hours (x5 resolution).
  • AV 12 (Pump 5 speed) is referenced in the configuration bits but not printed in the object table.

Questions about the HTP MODBUS/BACnet Adapter 7350P-636 (BIC-926/928 boilers and water heaters)

How many BACnet points does the HTP MODBUS/BACnet Adapter 7350P-636 (BIC-926/928 boilers and water heaters) have?

This list has 111 BACnet objects: 63 analog inputs, 13 analog values, 33 binary inputs, 2 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which HTP MODBUS/BACnet Adapter 7350P-636 (BIC-926/928 boilers and water heaters) BACnet points are writable?

15 of the 111 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
