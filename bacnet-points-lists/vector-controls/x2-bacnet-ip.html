BMS integration notes: Vector Controls X2 controllers with BACnet IP (CS2-BAC-001)

Integration in brief

Use BV 0 for on/off and MV 0 for occupancy, write loop set points (AV 211 for loop 1) and read inputs, loop outputs and alarms. Time schedules can be set over BACnet through the TS objects.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

BV 3-7 lock or unlock local access to modes, set points, manual control, heat/cool change and time programs.

Heartbeat & communication loss

Virtual inputs (AV 109-116) set to the communication module must be rewritten within the controller's timeout, or the input and its functions are disabled.

Sensors & values from the BMS

Write sensor values to the virtual inputs VI-01..VI-04 (AV 109, 111, 113, 115) when they are set to the communication module.

Network setup

  • IPv4 address and DHCP on/off are set in the controller's COM parameters.

Watch out for

  • Temperature units follow MV 2 (Temp-Unit).

Integration notes

  • Objects are created only for the inputs, outputs, loops and alarms the X2 product actually has; the datasheet scope table says which exist.
  • Digital output objects depend on how each output is configured (fan, 3-point floating, PWM or binary); the same instance can appear in several of these tables, listed here once.
  • Alarm MVs (601-608) can only be written to Not Active when the alarm is waiting for confirmation.
  • Other controller parameters are reached through ParAdd/ParValue (an address + value pair), not as separate objects.
  • Each of the 12 time schedules has TYPE, NR (group ID) and DAYS MVs and TIME and SP AVs; in holiday mode the same schedule uses the HDAY/HMONTH start/end AVs.
  • Object names in the controller-state block differ from the MS/TP module (e.g. MV 0 Occupation instead of OpStCoSt), and ParAdd/ParValue are AV 0/AV 1 here.

Questions about the Vector Controls X2 controllers with BACnet IP (CS2-BAC-001)

How many BACnet points does the Vector Controls X2 controllers with BACnet IP (CS2-BAC-001) have?

This list has 248 BACnet objects: 8 analog inputs, 137 analog values, 29 binary values, 74 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vector Controls X2 controllers with BACnet IP (CS2-BAC-001) BACnet points are writable?

186 of the 248 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vector Controls X2 controllers with BACnet IP (CS2-BAC-001) BACnet documentation?

The source is X2 BACnet IP (70-00-0899C V1.2), revision 2026-08-26, published free by Vector Controls at https://vectorcontrols.com/application/files/2417/8775/4816/70-00-0899C_X2_BACnetIP_V1_2.pdf.

What are the minimum BACnet points to integrate the Vector Controls X2 controllers with BACnet IP (CS2-BAC-001)?

Start with BV 0 OpStOo (Controller on/off); MV 0 Occupation (Occupied / unoccupied); MV 1 Ctrl-Mode (Cool / heat mode); AV 211 LP-01-SSP (Loop 1 set point); AI 101 UI-01 (Universal input 1 (e.g. room temperature)); MV 211 LP-01-ST (Loop 1 state); AV 213 LP-01-PROP (Loop 1 output, %); MV 601 AL-01 (Alarm 1 state).

How do I enable BMS control of the Vector Controls X2 controllers with BACnet IP (CS2-BAC-001)?

BV 3-7 lock or unlock local access to modes, set points, manual control, heat/cool change and time programs.

Does the Vector Controls X2 controllers with BACnet IP (CS2-BAC-001) need a BACnet heartbeat or have a communication timeout?

Virtual inputs (AV 109-116) set to the communication module must be rewritten within the controller's timeout, or the input and its functions are disabled.

Can the BMS supply sensor values to the Vector Controls X2 controllers with BACnet IP (CS2-BAC-001)?

Write sensor values to the virtual inputs VI-01..VI-04 (AV 109, 111, 113, 115) when they are set to the communication module.
