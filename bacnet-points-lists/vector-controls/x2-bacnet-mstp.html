Updated 12 November 2026

Short answer

The X2 BACnet MS/TP module maps the X2 operating system into a fixed set of objects: controller state and access locks, universal and virtual inputs with offsets, up to four control loops, analog and digital outputs (with override values and state), fan stages and eight alarms. Objects only appear for the I/O the specific X2 product has.

This page lists 148 BACnet objects for the Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002) — 76 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Vector Controls’s own free documentation, linked below.

BMS integration notes: Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002)

Integration in brief

Use BV 0 for on/off and MV 0 for occupied/unoccupied, write loop set points (AV 211 for loop 1) and feed sensor values through the virtual inputs if needed. Read the universal inputs, loop outputs and the alarm MVs.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

BV 3-7 lock or unlock local access to modes, set points, manual control, heat/cool change and time programs.

Heartbeat & communication loss

Virtual inputs (AV 109-116) set to the communication module must be rewritten within the controller's timeout, or the input and its functions are disabled and Err 4 shows.

Sensors & values from the BMS

Write sensor values from the BMS to the virtual inputs VI-01..VI-04 (AV 109, 111, 113, 115) when they are set to the communication module.

Network setup

  • MS/TP MAC (CO03, default 3), baud (CO04, 0 = auto-detect, 9600-115200), max master (CO05) and device ID (CO06-CO09) are set in the controller's COM parameters (login code 241).
  • Device object name auto-builds as AEX-BAC-<device ID> when CO15 = 2 or 3.

Watch out for

  • Vector does not recommend changing parameters through ParAdd/ParValue (AV 12/AV 13); use it only as a workaround.
  • Temperature units follow MV 2 (Celsius/Fahrenheit).

Integration notes

  • Objects are created only for the inputs, outputs, loops and alarms the X2 product actually has; the datasheet scope table says which exist.
  • Digital output objects depend on how each output is configured (fan, 3-point floating, PWM or binary); the same instance can appear in several of these tables, listed here once.
  • Alarm MVs (601-608) can only be written to Not Active when the alarm is waiting for confirmation.
  • Other controller parameters are reached through ParAdd/ParValue (an address + value pair), not as separate objects.
  • Controller information AVs 0-11 report how many loops, inputs, outputs, alarms and schedules the controller has.

Questions about the Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002)

How many BACnet points does the Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002) have?

This list has 148 BACnet objects: 8 analog inputs, 75 analog values, 29 binary values, 36 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002) BACnet points are writable?

76 of the 148 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002) BACnet documentation?

The source is X2-BACnet MS/TP (70-00-0218D V1.4), revision 2026-08-26, published free by Vector Controls at https://vectorcontrols.com/application/files/1517/8775/5952/70-00-0218D_X2-BACnet_V1_4.pdf.

What are the minimum BACnet points to integrate the Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002)?

Start with BV 0 OpStOo (Controller on/off); MV 0 OpStCoSt (Occupied / unoccupied); MV 1 OpStHeCo (Cool / heat mode); AV 211 LP-01-SSP (Loop 1 set point); AI 101 UI-01 (Universal input 1 (e.g. room temperature)); MV 211 LP-01-ST (Loop 1 state); AV 213 LP-01-PROP (Loop 1 output, %); MV 601 AL-01 (Alarm 1 state).

How do I enable BMS control of the Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002)?

BV 3-7 lock or unlock local access to modes, set points, manual control, heat/cool change and time programs.

Does the Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002) need a BACnet heartbeat or have a communication timeout?

Virtual inputs (AV 109-116) set to the communication module must be rewritten within the controller's timeout, or the input and its functions are disabled and Err 4 shows.

Can the BMS supply sensor values to the Vector Controls X2 controllers with BACnet MS/TP (CS1-BAC-002)?

Write sensor values from the BMS to the virtual inputs VI-01..VI-04 (AV 109, 111, 113, 115) when they are set to the communication module.
