Toshiba BN interface BMS-IFBN1281U BACnet points list

Updated 16 October 2026

Short answer

The BN interface is a Toshiba Carrier gateway that converts the TU2C-LINK / TCC-LINK central control line to BACnet/IP, serving up to 128 indoor units (64 on TCC-LINK). Every indoor unit gets the same block of objects, with the instance built from the unit's central control address and a fixed per-function code. Objects only exist for units found during the gateway's air conditioner search mode.

This page lists 68 BACnet objects for the Toshiba BN interface BMS-IFBN1281U — 26 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Toshiba’s own free documentation, linked below.

BMS integration notes: Toshiba BN interface BMS-IFBN1281U

Integration in brief

Give every indoor unit a central control address, run the BN interface's air conditioner search mode, then map each unit's block of objects (instance = address x 256 + code). Command through the output objects (start/stop, mode, fan, setpoint) and read the matching input objects back for status. Watch Alarm/BI, Alarm_Code/MI and Indoor_Communication_Failure for faults.

Enable & remote start

No enable point is described; units can be commanded once they have a central control address and were found by air conditioner search mode. Inhibit/MO can prohibit local remote-controller changes to start/stop, mode and setpoint.

Network setup

  • Factory default IP 192.168.1.100, subnet 255.255.255.0, BACnet/IP on UDP 47808.
  • Default device instance = last byte of the IP address (100), so changing the IP changes the device instance unless 'User Setting' is chosen in the engineering tool.
  • IP, device instance and other settings are changed with Toshiba Carrier's Setting File Creation Software2 and uploaded as a DEF file (over the network or by USB flash drive).
  • Central control addresses must be set on every indoor unit; holding the Shutdown button for 4 s or more starts air conditioner search mode to build the unit list.
  • When multiple BN interfaces are used, each needs its own IP address and device instance.

Watch out for

  • Re-run air conditioner search mode after any change to central control, line or unit addresses, or after replacing the microSD card.
  • Auto cool/heat setpoints are only sent when cool setpoint >= heat setpoint, should be changed while the unit is in Auto, need 10 s between changes, and must not be written together in one WritePropertyMultiple.
  • Fan speed and louver objects cannot be used on units whose fan speed or louver options are fixed; in Dry mode fan speed is auto only.
  • Setpoint limits depend on the indoor unit type (18-29 °C standard FCU, 16-27 °C fresh-air intake unit).
  • Duplicate central control addresses stop the search from completing correctly; check the search results file (SearchObjectLog.tsv).

Integration notes

  • Instance formula: equipment number n (central control address, 1-128) x 256 + function code (e.g. ON/OFF status code 0x02 gives n*256+2). This file lists unit n=1.
  • In object names, *** stands for the air-conditioner number 1-128.
  • The manual prints the name Notice_Code1/MI_*** for all five notice-code objects; their object IDs differ (codes 0x63-0x67).
  • ATW (air-to-water), RAC interface and ventilation objects only apply when that equipment is connected; ATW and RAC interfaces cannot be connected at the same time.
  • Analog values follow the gateway's Celsius/Fahrenheit setting (BMS-IFBN1281U-E/-TR default Celsius).
  • Output objects expose a Priority_Array; Out_Of_Service is writable on the I/O objects.

Questions about the Toshiba BN interface BMS-IFBN1281U

How many BACnet points does the Toshiba BN interface BMS-IFBN1281U have?

This list has 68 BACnet objects: 10 analog inputs, 6 analog outputs, 17 binary inputs, 13 binary outputs, 1 device, 14 multi-state inputs, 7 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Toshiba BN interface BMS-IFBN1281U BACnet points are writable?

26 of the 68 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the Toshiba BN interface BMS-IFBN1281U?

Start with BO 386 State/BO_*** (Start/stop the indoor unit); BI 258 State/BI_*** (Confirms the unit's on/off state); MO 387 Mode/MO_*** (Sets heat/cool/fan/dry/auto); AO 388 Temp/AO_*** (Writes the setpoint); AI 264 Room_Temp/AI_*** (Room temperature at the unit); MO 389 Fan/MO_*** (Sets fan speed); BI 320 Alarm/BI_*** (Unit alarm flag); MI 257 Alarm_Code/MI_*** (Check code present); BI 321 Indoor_Communication_Failure_*** (Lost communication with the indoor unit); MO 393 Inhibit/MO_*** (Lock out local remote start/stop, mode or setpoint).

How do I enable BMS control of the Toshiba BN interface BMS-IFBN1281U?

No enable point is described; units can be commanded once they have a central control address and were found by air conditioner search mode. Inhibit/MO can prohibit local remote-controller changes to start/stop, mode and setpoint.
