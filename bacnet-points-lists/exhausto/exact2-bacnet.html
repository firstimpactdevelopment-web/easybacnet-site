Short answer

EXact and EXact2 are the controls on EXHAUSTO VEX air handling units with heat recovery. The web server module makes the unit a BACnet IP or BACnet MS/TP device (B-ASC). The object list comes from EXHAUSTO's EDE file: fan outputs, airflows, pressures, filter drops, temperatures, setpoints, hour counters and 16 alarm slots as analog inputs; BMS setpoints (airflow, temperature, balance, fan speeds, filter limits, clock) as analog values; run and compensation states as binary inputs; and control mode, alarm reset and night cooling enable as binary values.

BMS integration notes: EXHAUSTO EXact / EXact2 air handling unit control (BACnet program file)

Integration in brief

Write the airflow setpoint (AV 6, 0-100 %, 0 stops the unit) and the temperature setpoint (AV 7, 10-35 °C); set BV 0 back to 1 to return the unit to its timer program. Read the operating state, airflows, temperatures and the A/B common alarms; BV 1 resets alarms.

Enable & remote start

Writing the airflow setpoint (AV 6) runs the unit at that level; 0 % stops it. BV 0 CtrlMode = 1 hands control back to the unit's timer program.

Sensors & values from the BMS

AV 10 (RH) and AV 11 (CO2) accept values from the BMS for the unit's compensation functions.

Network setup

  • Select BACnet MS/TP or BACnet IP in HMI menu 3.5 (BMS), then set Device ID (0-4194303) in menu 3.5.2; the device name can only be set in the web server.
  • BACnet MS/TP: CN3 on the main control (A, B, 0 V), address 0-127, baud 9600, 19200 or 115200; fit the 120 ohm terminator with jumper JP2 on the web server at the end of the line.
  • BACnet IP: UDP port 47808-47823; IP settings (static or DHCP) in menu 3.6.

Watch out for

  • The temperature setpoint may be limited by other settings and functions in the unit.
  • AV 19 / AV 20 fan setpoints only apply with air control method 8 (external control of fan speeds).
  • AV 8 fixed airflow setpoint only applies with air control methods 3 and 4.

Integration notes

  • Object names, types and instances are from the EDE file (09.08.2022); units are from the English register list in the manual's appendix; descriptions are our own short summaries. The appendix prints a few names differently (e.g. AI 79 Temp_Set.Setpoint); the EDE names are used.
  • The manual gives access only by type (AI and binary inputs read-only, AO and binary outputs read/write) and the EDE has no settable column; the BMSInValue / VEXConfig analog and binary values are shown writable and the BMSOutValue objects (AV 21-22) read-only.
  • Objects without a unit in the appendix (unit code 95) are left blank; hour counters, alarm codes and state objects carry no unit.
  • Which objects carry values depends on the unit's options (heating and cooling coils, heat pump, external cooling, sensors).
  • Alarm codes in AI 53-68 refer to the alarm list in the EXact documentation.

Questions about the EXHAUSTO EXact / EXact2 air handling unit control (BACnet program file)

How many BACnet points does the EXHAUSTO EXact / EXact2 air handling unit control (BACnet program file) have?

This list has 171 BACnet objects: 121 analog inputs, 23 analog values, 24 binary inputs, 3 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which EXHAUSTO EXact / EXact2 air handling unit control (BACnet program file) BACnet points are writable?

24 of the 171 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

What are the minimum BACnet points to integrate the EXHAUSTO EXact / EXact2 air handling unit control (BACnet program file)?
