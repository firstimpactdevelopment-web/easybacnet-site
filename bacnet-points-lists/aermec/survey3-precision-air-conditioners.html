Short answer

Its supervisor table maps each value to a Modbus register and a BACnet object: 530 objects covering digital inputs and alarms, outputs, return/supply temperature and humidity, remote probe modules, compressor and EEV data, fans, water circuit, humidifier, working hours, setpoints and regulation parameters, and alarm resets.

BMS integration notes: Aermec P / G / R / TMC precision air conditioners with SURVEY3 controller (software 3.0)

Integration in brief

Fit the BACnet MS/TP (RS485) or BACnet IP (RJ45) option and set Device ID, baud rate, max master and MAC ID in User set-up > BACnet. Switch the unit with SupervOFF (BV 1), write temperature and humidity setpoints, and read unit status, temperatures, humidity, outputs and alarms.

Enable & remote start

On/Off from supervisor is BV 1 (SupervOFF), writable.

Network setup

  • Software version B offers BACnet IP on the RJ45 port; version C offers BACnet MS/TP on RS485.
  • BACnet menu defaults: Device ID 127 (range 1-4194303), baud 76800 (9600/19200/38400/76800), Max Master 127, MAC ID 1. Section 10.2.1 lists 57600 as the MS/TP default instead.
  • BACnet IP defaults: 192.168.1.24 / 255.255.255.0, gateway 192.168.1.1, UDP port 47808.
  • Communication parameter changes need a controller reboot.

Watch out for

  • Regulation parameters (bands, times, offsets) are setup values; don't write them cyclically.
  • Alarm reset BVs reset latched alarms; write them only when needed.
