Samsung DMS2.5 BACnet Gateway (MIM-B17BN) BACnet points list

Updated 16 October 2026

Short answer

The MIM-B17BN works with the DMS2.5 central controller and publishes every Samsung unit as its own virtual BACnet IP device, with a device ID built from the gateway number and unit addresses. Inside each virtual device the object instances are small fixed numbers (1, 2, 3...), so one template per unit type covers the whole site. The DMS firmware offers a Basic and an Advanced point provision type; this list is the Advanced set, which adds points without renumbering the shared ones except the Notify object.

This page lists 174 BACnet objects for the Samsung DMS2.5 BACnet Gateway (MIM-B17BN) — 104 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Samsung’s own free documentation, linked below.

BMS integration notes: Samsung DMS2.5 BACnet Gateway (MIM-B17BN)

Integration in brief

Set the gateway's network information (IP, BACnet port, Network No.) in the DMS2.5 BACnet web pages and pick the Basic or Advanced point provision type. Each Samsung unit then appears as its own BACnet device whose ID encodes the network number and unit address; inside it, map Power, mode, setpoint, room temp and error code.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

No enable point is described. Remote controller limits are per unit via *_Remocon_Limit (Enable RC / Disable RC / Conditional RC), and operation-mode limits via *_Mode_Limit.

Heartbeat & communication loss

No BMS heartbeat. When a unit loses communication its objects get Reliability = COMMUNICATION_FAILURE and the fault flag in Status_Flags set, and Present_Value is no longer guaranteed. A general air-conditioner error sets Reliability = UNRELIABLE_OTHER.

Network setup

  • BACnet port defaults to 47808; BBMD port defaults to 0 (not used). Changing the BBMD port stops local network communication.
  • Network No. (DNET, 1-40) defaults to 9 and must be different for each gateway on the same network.
  • Device ID = DNET + 3-digit CPP code + 2-digit unit address, created automatically (example: 941732 for gateway 9, indoor unit 01.01.32).
  • Command priorities 1-16 are supported; priority 8 is recommended.
  • Changing the point provision type (Basic/Advanced) restarts the DMS and changes instance numbers.
  • The DMS2.5 itself ships with IP 192.168.0.100.

Watch out for

  • Do not send control commands repeatedly in a short time; the DMS can stop from overload.
  • COV subscriptions are lost when the gateway is switched off; resubscribe after a power cycle.
  • If a SIM/PIM, centralized controller or interface module loses communication, other functions such as power distribution may also be affected; watch the error points.
  • Many points are optional and only exist on units that support them.

Integration notes

  • Device ID = DNET (gateway number 1-40) + 3-digit CPP code + 2-digit unit address. Example from the manual: gateway 9, indoor unit 01.01.32 -> 9 + 417 (400 + 1x16 + 1) + 32 = 941732.
  • CPP ranges: 000-015 centralized controller, 100-115 SIM/PIM, 300-315 DMS DI/DO, 400-655 interface module (outdoor unit) and units behind it; the BACnet gateway itself uses 900.
  • Advanced vs Basic: Basic indoor units stop at 24 with Notify at 25 (Advanced: Notify 54, 37-53 reserved); Basic AHU kit stops at 26 with Notify at 27; Basic EHS stops at 31 with Notify at 32; Basic outdoor unit lacks 6-7 and has Notify at 6.
  • Many points are optional and only appear if the unit supports them (Wind-Free, MDS, dust sensors, ERV Plus, outdoor water temp/hot gas valve).
  • The manual does not mark read/write per point; access here is inferred from object type. Command priorities 1-16 are supported and level 8 is recommended.
  • Object names keep the manual's xx/xxxxxx placeholders, which the gateway fills with unit address digits.

Questions about the Samsung DMS2.5 BACnet Gateway (MIM-B17BN)

How many BACnet points does the Samsung DMS2.5 BACnet Gateway (MIM-B17BN) have?

This list has 174 BACnet objects: 41 analog inputs, 35 analog values, 18 binary inputs, 13 binary outputs, 34 binary values, 2 multi-state inputs, 9 notification classs, 22 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Samsung DMS2.5 BACnet Gateway (MIM-B17BN) BACnet points are writable?

104 of the 174 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the Samsung DMS2.5 BACnet Gateway (MIM-B17BN)?

Start with BV 9 AC_Power_xx_xxxxxx (Indoor unit on/off); MV 14 AC_Operation_Mode_xx_xxxxxx (Indoor unit operating mode); AV 2 AC_Temp_Set_xx_xxxxxx (Indoor unit setpoint); MV 15 AC_FanSpeed_xx_xxxxxx (1 = auto, 2 = low, 3 = mid, 4 = high, 5 = turbo); AI 1 AC_RoomTemp_xx_xxxxxx (Room temperature); AI 19 AC_Error_Code_xx_xxxxxx (Integrated indoor/outdoor error code); AI 2 DMS2.5_Status_xx (DMS2.5 / gateway communication status).

How do I enable BMS control of the Samsung DMS2.5 BACnet Gateway (MIM-B17BN)?

No enable point is described. Remote controller limits are per unit via *_Remocon_Limit (Enable RC / Disable RC / Conditional RC), and operation-mode limits via *_Mode_Limit.

Does the Samsung DMS2.5 BACnet Gateway (MIM-B17BN) need a BACnet heartbeat or have a communication timeout?

No BMS heartbeat. When a unit loses communication its objects get Reliability = COMMUNICATION_FAILURE and the fault flag in Status_Flags set, and Present_Value is no longer guaranteed. A general air-conditioner error sets Reliability = UNRELIABLE_OTHER.

How do I check these points on the real DMS2.5 BACnet Gateway (MIM-B17BN)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
