Short answer

The GMS GW is a Gree-branded gateway (built by CoolAutomation) that links up to 1 or 12 Gree split indoor units over two RS-485 lines to BACnet/IP or BACnet MS/TP. Every unit gets a common object set (on/off, mode, fan, setpoint, room temperature, locks) plus series-specific objects; this file is the common set plus the R-series extras.

BMS integration notes: Gree GMS BACnet Converter (GMS GW) - R series

Integration in brief

Address each split unit from its wired controller, pick BACnet/IP or MS/TP, set a unique device instance from the LCD menu, then map each unit's object block using the instance formula. On/off, mode, fan and setpoint are writable value objects; room temperature and failure status are read-only.

Enable & remote start

No enable point; a unit is controllable once it has a unique remote control address on line L1 or L2. BV 'Global Lock' and the two Lock BVs stop local wired-controller changes.

Network setup

  • Device instance is set from the gateway's LCD menu (Menu > BACnet > Instance number) and takes effect after a restart.
  • The BAC A/B RS-485 port runs either BACnet MS/TP or Modbus RTU; choose BACnet in the 'Line 3' setting of the USB configuration tool.
  • BACnet/IP runs on the Ethernet port; network settings are changed with the ifconfig command in the gateway terminal.
  • Set each indoor unit's remote control address (0-63) on its wired controller before mapping objects.

Watch out for

  • Instances are computed from line and remote control address, so re-addressing a unit moves all of its objects.
  • Operation Mode state 4 is not used (0 Cool, 1 Heat, 2 Auto, 3 Dry, 5 Fan).
  • Louver only supports Auto swing (5) and Off (6).
  • Class 1 (series-specific) objects differ between R-series and DWUNI units; confirm the unit series before mapping.

Integration notes

  • Instance formula: Class x 1048576 + (Line - 1) x 131072 + remote control address x 256 + object number. Common objects are Class 0, series-specific objects Class 1. This file lists line 1, address 1 (L1.001).
  • Each split unit needs a unique remote control address (0-63 per line), set from its wired controller; the gateway shows it as L<line>.<address>.
  • The manual has no read/write column; access was inferred from object type (BV/AV/MV writable, BI/AI/PIV read-only).
  • The gateway is made by CoolAutomation for Gree; GMS GW 1 handles one unit, GMS GW 12 up to 12 units over two RS-485 lines.
  • M, W, P and X series units on a DWUNI wired controller use a different Class 1 object set (see the separate GMS GW DWUNI entry).

Questions about the Gree GMS BACnet Converter (GMS GW) - R series

How many BACnet points does the Gree GMS BACnet Converter (GMS GW) - R series have?

This list has 32 BACnet objects: 1 analog input, 3 analog values, 5 binary inputs, 15 binary values, 3 multi-state values, 5 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Gree GMS BACnet Converter (GMS GW) - R series BACnet points are writable?

21 of the 32 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Gree GMS BACnet Converter (GMS GW) - R series BACnet documentation?

The source is Gree Mini Split (GMS) BACnet Converter User Manual (1.1), revision 2023-12-11 (Version 1.1), published free by Gree at https://www.greecomfort.com/assets/our-products/mini-split-controls/documents/cool-automation-mini-split-controls-user-manual.pdf.

What are the minimum BACnet points to integrate the Gree GMS BACnet Converter (GMS GW) - R series?

Start with BV 256 ON/OFF (Start/stop the split unit); MV 257 Operation Mode (Cool/heat/auto/dry/fan); AV 256 SetPoint Temperature (Writes the setpoint); AI 256 Room Temperature (Room temperature); MV 256 Fan Speed (Fan speed); BI 256 split unit Failure Status (Failure flag; Active_Text carries the code); BV 261 Global Lock (Block local wired-controller changes).

How do I enable BMS control of the Gree GMS BACnet Converter (GMS GW) - R series?

No enable point; a unit is controllable once it has a unique remote control address on line L1 or L2. BV 'Global Lock' and the two Lock BVs stop local wired-controller changes.
