AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI) BACnet points list

Updated 12 November 2026

Short answer

The LX-4 option runs AbsolutAire units on a JENEsys Edge534 Niagara controller with a touch-screen HMI. It offers BACnet IP, BACnet MS/TP and Modbus TCP as standard. The BMS can run the unit, pick heat/vent/cool/auto, override occupancy, write heating and cooling setpoints, discharge limits and economizer/VFD settings, and read temperatures, airflow, energy and alarm objects.

This page lists 88 BACnet objects for the AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI) — 40 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from AbsolutAire’s own free documentation, linked below.

BMS integration notes: AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI)

Integration in brief

Command the unit with UnitRunCommand (1 off, 2 on) and OperationMode, and use OccupancyOverride to force occupied or unoccupied or follow the schedule. Write the occupied heating (and cooling) setpoints and read Fan_ON, BurnerOn, temperatures and the alarm BIs. All writable objects are commandable with a priority array.

Enable & remote start

UnitRunCommand (MV 0): 1 = off, 2 = on.

Network setup

  • BACnet IP, BACnet MS/TP and Modbus TCP are standard on the Edge534 controller (2 Ethernet and 2 RS-485 ports).

Watch out for

  • Burner reset and maintenance run-time reset act on a toggle (1 to 2 or 2 to 1).
  • PID tuning MVs take 1 (most aggressive) to 11 (least); 6 is the default.

Integration notes

  • The points list (guide pages 25-26) is printed as a rotated image; values were keyed by hand from the rendered page and checked row by row.
  • Writable AV, BV and MV objects list priority levels 1-16, so they are shown as commandable; inputs list none.
  • The guide covers standard features only; custom-built units can differ, and objects for options a unit does not have (cooling, mixed air, filter transmitters, power exhaust) carry no meaning.
  • Units are only partly printed in the table; °F, %, CFM and hours here follow the descriptions.
  • MaintenanceMessage is an enumerated multistate input over BACnet; the guide does not list its states.

Questions about the AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI)

How many BACnet points does the AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI) have?

This list has 88 BACnet objects: 29 analog inputs, 26 analog values, 17 binary inputs, 1 binary value, 2 multi-state inputs, 13 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI) BACnet points are writable?

40 of the 88 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI) BACnet documentation?

The source is LX-4 User Guide - points list (LX-4 User Guide 072020), published free by AbsolutAire at https://www.absolutaire.com/wp-content/uploads/lx-4_user_guide.pdf.

What are the minimum BACnet points to integrate the AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI)?

Start with MV 0 UnitRunCommand (Unit run: 1 off, 2 on); MV 1 OperationMode (1 heat, 2 vent, 3 cool, 4 auto); MV 2 OccupancyOverride (1 manual unocc, 2 manual occ, 3 follow schedule); AV 7 OccupiedHeatSetPoint (Occupied heating setpoint, °F); AV 9 OccupiedCoolSetPoint (Occupied cooling setpoint, °F (if cooling)); BI 13 Fan_ON (Fan running status); BI 14 BurnerOn (Burner on status); AI 23 DischargeTemperature (Discharge air temperature); BI 7 BurnerLockoutAlarm (Burner lockout (1 = alarm)); BI 6 MotorNotRespondingAlarm (Fan motor not responding (1 = alarm)).

How do I enable BMS control of the AbsolutAire LX-4 control system (JENEsys Edge534 with touch-screen HMI)?

UnitRunCommand (MV 0): 1 = off, 2 = on.
