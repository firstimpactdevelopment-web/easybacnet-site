AbsolutAire UC-3 HTLV control system (heating and ventilating) BACnet points list

Updated 12 November 2026

Short answer

The UC-3 HTLV is AbsolutAire's controller for heat-and-vent make-up air units: it runs the burner to hold a discharge or space temperature, with occupied/unoccupied setpoints, a low-temperature limit and a mild-weather heat lockout. It joins a BACnet MS/TP network with the MAC address set on DIP switches. The BMS enables the unit through NetworkUnitEnable, sets occupancy and vent/heat mode, and writes the space and discharge setpoints.

This page lists 37 BACnet objects for the AbsolutAire UC-3 HTLV control system (heating and ventilating) — 13 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from AbsolutAire’s own free documentation, linked below.

BMS integration notes: AbsolutAire UC-3 HTLV control system (heating and ventilating)

Integration in brief

Write NetworkUnitEnable = 2 to run the unit (the guide marks it as the point to enable the unit), then set NetworkOccupancy and HVAC_Mode and the occupied/unoccupied space or discharge setpoints. Read the current temperatures, burner command and status, and the multistate alarms; BurnerReset clears a lockout when its value is changed.

Enable & remote start

NetworkUnitEnable (MV 51): 1 = off, 2 = on. The guide marks it as the point to use to enable the unit.

Network setup

  • The MS/TP MAC address is set on the controller's DIP switches (switch 1 = least significant bit).
  • Baud rate is detected automatically after a power cycle.
  • Device instance = 3640 followed by the MAC address (MAC 25 gives 364025).

Watch out for

  • Do not write the hardware outputs or the [DO NOT WRITE] configuration objects; the Override Output MVs alarm when an output has a network override.
  • BurnerReset acts on a change of value (1 to 2 or 2 to 1), not on a fixed value.

Integration notes

  • The Network Points List in the guide is printed as an image; values were keyed by hand from the rendered page and checked row by row.
  • The table also lists the controller's physical I/O as 'Hardware Input n' / 'Hardware Output n' (24 rows) without a BACnet object type; they are left out. The guide marks the outputs do-not-write.
  • For most multistate objects the guide gives only the enumeration names (e.g. ALARM / NORMAL), not the state numbers; NetworkUnitEnable, NetworkOccupancy and HVAC_Mode numbers are printed in the guide.
  • Several AV/BV objects are marked [DO NOT WRITE] configuration values.
  • Sensor alarm MVs use the controller's SensorReliability enumeration, which the guide does not list.

Questions about the AbsolutAire UC-3 HTLV control system (heating and ventilating)

How many BACnet points does the AbsolutAire UC-3 HTLV control system (heating and ventilating) have?

This list has 37 BACnet objects: 14 analog values, 4 binary values, 19 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AbsolutAire UC-3 HTLV control system (heating and ventilating) BACnet points are writable?

13 of the 37 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official AbsolutAire UC-3 HTLV control system (heating and ventilating) BACnet documentation?

The source is UC-3 HTLV User Guide - Network Integration / Network Points List (UC-3 HTLV User Guide 010622), published free by AbsolutAire at https://www.absolutaire.com/wp-content/uploads/uc-3_htlv_user_guide_0.pdf.

What are the minimum BACnet points to integrate the AbsolutAire UC-3 HTLV control system (heating and ventilating)?

Start with MV 51 NetworkUnitEnable (Unit enable: 1 off, 2 on); MV 52 NetworkOccupancy (1 occupied, 2 unoccupied, 3 follow schedule); MV 53 HVAC_Mode (1 vent, 2 heat); AV 51 OccupiedSpaceSetPoint (Occupied space temperature setpoint, °F); AV 53 DischargeTempSetPoint (Discharge temperature setpoint, °F); MV 15 CurrentBurnerStatus (Burner status (ENABLE / OFF)); AV 35 CurrentDischargeTemperature (Discharge air temperature); AV 33 CurrentSpaceTemperature (Space temperature); MV 12 BurnerLockoutAlarm (Burner lockout); MV 11 MotorNotRespondingAlarm (Fan motor did not start).

How do I enable BMS control of the AbsolutAire UC-3 HTLV control system (heating and ventilating)?

NetworkUnitEnable (MV 51): 1 = off, 2 = on. The guide marks it as the point to use to enable the unit.

How do I check these points on the real UC-3 HTLV control system (heating and ventilating)?
