Bell & Gossett FC-102 Embedded BACnet (pump drive) BACnet points list

Updated 16 October 2026

Short answer

Bell & Gossett pumps driven by the FC-102 HVAC drive can use the drive's embedded BACnet MS/TP over its RS-485 port. The embedded map covers drive I/O terminals, run/stop and reference commands, setpoints and bus feedback values, drive and motor readings, PID tuning, and bypass (ECB) status. It is shorter than the MCA 109 option map and does not include the individual warning and alarm bits.

This page lists 125 BACnet objects for the Bell & Gossett FC-102 Embedded BACnet (pump drive) — 62 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Bell & Gossett’s own free documentation, linked below.

BMS integration notes: Bell & Gossett FC-102 Embedded BACnet (pump drive)

Integration in brief

The embedded FC-102 list gives run/stop, reference select and fault reset commands, writable setpoints and bus feedback values, and read-only drive data. A typical integration writes BV 1 and a setpoint, then reads run/fault status, speed, power and fault codes.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

BV 1 RUN/STOP Command starts and stops the drive and BV 2 selects reference 1 or 2; BV 32 shows whether the drive is under bus control. The point list does not explain how bus control is set up on the drive.

Sensors & values from the BMS

AV 31, AV 36 and AV 41 Bus Feedback 1-3 and AV 1/AV 2 Input Reference are writable; the point list does not describe how the drive uses them.

Network setup

  • The point list applies to drive firmware 3.90 and above.

Watch out for

  • Many rows in the list are Reserved or NA and are not included here.
  • MO 0 is labelled MSO:0 but named multi_state_value in the list; check the object type on site.

Integration notes

  • The point list prints names as e.g. "analog_value: 1 (Speed Act Value)"; the text in brackets is used as the object name here.
  • Rows the list marks as Reserved or NA are left out.
  • MO 0 is labelled MSO:0 in the ID column but named multi_state_value in the list; check the object type on site.
  • Bus commands only take effect when the drive is set to accept bus control.

Questions about the Bell & Gossett FC-102 Embedded BACnet (pump drive)

How many BACnet points does the Bell & Gossett FC-102 Embedded BACnet (pump drive) have?

This list has 125 BACnet objects: 7 analog inputs, 7 analog outputs, 32 analog values, 16 binary inputs, 31 binary outputs, 30 binary values, 2 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Bell & Gossett FC-102 Embedded BACnet (pump drive) BACnet points are writable?

62 of the 125 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Bell & Gossett FC-102 Embedded BACnet (pump drive) BACnet documentation?

The source is BacNET Points Firmware 3.90 and above (MCA109 FC-102 Advanced BACnet Option / FC-102 Embedded BACnet) (BGBACNET), revision December 2019, published free by Bell & Gossett at https://prod.xylem.com/siteassets/brand/bell-amp-gossett/resources/manual/bgbacnet.pdf.

What are the minimum BACnet points to integrate the Bell & Gossett FC-102 Embedded BACnet (pump drive)?

Start with BV 1 RUN/STOP Command (Run / stop command); AV 1 Input Reference 1 (Speed reference from the BMS (open-loop control)); AV 30 Setpoint 1 (Process setpoint 1 (when the drive runs its own PID)); BV 3 Fault Reset Command (Fault reset); BV 4 RUN/STOP Monitor (Running status); BV 5 OK/FAULT Monitor (OK / fault status); BV 32 Bus Control (Drive is under bus control); AV 3 Output Speed (Output speed); AV 6 Power (Drive output power); AV 51 Fault Code (Fault code).

How do I enable BMS control of the Bell & Gossett FC-102 Embedded BACnet (pump drive)?

BV 1 RUN/STOP Command starts and stops the drive and BV 2 selects reference 1 or 2; BV 32 shows whether the drive is under bus control. The point list does not explain how bus control is set up on the drive.

Can the BMS supply sensor values to the Bell & Gossett FC-102 Embedded BACnet (pump drive)?

AV 31, AV 36 and AV 41 Bus Feedback 1-3 and AV 1/AV 2 Input Reference are writable; the point list does not describe how the drive uses them.

How do I check these points on the real FC-102 Embedded BACnet (pump drive)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
