Short answer

The Main DX Barrel Chiller Controller runs AAON DX chillers built with one or two barrel evaporators and has an on-board BACnet MS/TP port. The object map has 140 read-only analog inputs (water temperatures, pumping, WSE, evaporative condenser and per-circuit refrigerant data), 60 analog values (setpoints, calibration offsets, run command, relay and analog output overrides), 323 read-only binary inputs for status, faults, warnings and lockouts per circuit, and a multistate input for the unit mode.

BMS integration notes: AAON Main DX Barrel Chiller Controller

Integration in brief

Connect the on-board MS/TP port and set MAC address, device ID and baud on the LCD. The BAS runs the chiller with AV 81 Auto/Run/Off and reads the unit mode, leaving water temperature and alarm status. Leaving water reset limits are AV 1 and AV 2.

Enable & remote start

AV 81 Auto/Run/Off Command (0 = Auto, 1 = Run, 2 = Off) runs the chiller from the BAS; BI 1 shows the Run/Stop input and BI 6/7 the barrel disable commands. AV 80 resets a unit lockout.

Network setup

  • MAC address, device ID (up to seven digits) and MS/TP baud rate are set on the controller's LCD BACnet screens.

Watch out for

  • AV 82-91 switch main board relays and set analog output voltages directly; leave them alone unless the BAS is meant to drive those outputs.

Questions about the AAON Main DX Barrel Chiller Controller

How many BACnet points does the AAON Main DX Barrel Chiller Controller have?

This list has 524 BACnet objects: 140 analog inputs, 60 analog values, 323 binary inputs, 1 multi-state input. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AAON Main DX Barrel Chiller Controller BACnet points are writable?

60 of the 524 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official AAON Main DX Barrel Chiller Controller BACnet documentation?

The source is Main DX Barrel Chiller Controller Technical Guide (G070300 Rev. B), revision 2021-11, published free by AAON at https://www.aaon.com/hubfs/Controls%20Literature/G070300_DX-Barrel-B_TGD.pdf.

What are the minimum BACnet points to integrate the AAON Main DX Barrel Chiller Controller?

Start with AV 81 Auto/Run/Off Command (Chiller command: 0 auto, 1 run, 2 off); AV 80 Reset Unit Lockout { 1 = Reset } (Write 1 to reset a unit lockout); MI 1 Operating Status (Current unit mode); BI 8 Chiller Running On/Off Status (Chiller running); AI 4 Leaving Water Setpoint (Leaving water setpoint in use); AI 2 Entering Water Temperature (Entering water temperature); AI 3 Leaving Water Temperature (Leaving water temperature); BI 2 Proof of Water Flow #1 (Proof of water flow, barrel 1); BI 4 Emergency Shutdown (Emergency shutdown input).

How do I enable BMS control of the AAON Main DX Barrel Chiller Controller?

AV 81 Auto/Run/Off Command (0 = Auto, 1 = Run, 2 = Off) runs the chiller from the BAS; BI 1 shows the Run/Stop input and BI 6/7 the barrel disable commands. AV 80 resets a unit lockout.
