AAON BACnet General Controller (BGC) BACnet points list

Updated 6 November 2026

Short answer

AAON's BACnet MS/TP general controller: a fixed I/O point module with 8 configurable analog inputs (thermistor, 4-20 mA, 0-5/0-10 VDC or communicating sensors), 8 humidity readings from communicating sensors, 8 binary inputs, 8 relay outputs and 4 0-10 VDC analog outputs. The BMS writes the relays and analog outputs directly; the input type, scaling and sensor address are AV settings.

This page lists 69 BACnet objects for the AAON BACnet General Controller (BGC) — 44 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from AAON’s own free documentation, linked below.

BMS integration notes: AAON BACnet General Controller (BGC)

Integration in brief

Set the MAC address, ID Start and baud rate on the BGC display, configure each analog input type (AV 5-12) and scaling, then read the inputs and command the relays (BV 1-8) and analog outputs (AV 1-4) from the BMS.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • MS/TP baud 9600-76800, default 38400; MAC address 0-254, default 0.
  • Device ID = ID Start (0-30,000 in steps of 1000, default 15,000) plus the offset shown under DEVICE ID.
  • Set the jumper next to each analog input to match the selected sensor type (0-5 or 0-10 VDC).

Watch out for

  • AV 5-36 are configuration values; avoid writing them cyclically.

Integration notes

  • The points table has no read/write column; access is inferred: relay BVs and AV settings writable, AI/BI read-only.
  • Object names follow the PARAMETER column. AV 29-36 are all printed as 'Sensor #'; the description says which analog input each one serves.
  • Humidity inputs need a communicating digital temperature/humidity sensor on the matching analog input.
  • Units of AI 2-9 depend on the input type and scaling set in AV 5-28.

Questions about the AAON BACnet General Controller (BGC)

How many BACnet points does the AAON BACnet General Controller (BGC) have?

This list has 69 BACnet objects: 17 analog inputs, 36 analog values, 8 binary inputs, 8 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AAON BACnet General Controller (BGC) BACnet points are writable?

44 of the 69 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official AAON BACnet General Controller (BGC) BACnet documentation?

The source is BACnet General Controller (BGC) Technical Guide - Appendix A BGC BACnet Points (G042460 Rev. F), revision 2022-10 (221012), published free by AAON at https://www.aaon.com/hubfs/G042460-BGC%20Controller-F.pdf.

What are the minimum BACnet points to integrate the AAON BACnet General Controller (BGC)?

Start with BV 1 Relay #1 (Relay 1 on/off command); AV 1 Analog Output #1 (Analog output 1, 0-10 VDC); AI 2 Analog Input #1 (Analog input 1 value); BI 1 Binary Input #1 (Binary input 1 open/close).

How do I check these points on the real BACnet General Controller (BGC)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
