Short answer

AAON's PT-Link II BACnet5 gateway connects AAON controller loops to a BACnet MS/TP network. For the VCM controller it exposes 104 objects: setpoints, offsets and the schedule force as writable AVs, plus read-only temperatures, humidity, pressures, damper and VFD signals, unit mode, control status, enable flags and alarms.

BMS integration notes: AAON VCM Controller (legacy, via PT-Link II BACnet gateway)

Integration in brief

Wire the PT-Link II to the AAON controller loop and to the BACnet MS/TP trunk, set its MAC address and baud rate, and check the device instance. The BAS schedules the unit with SchdFrc (AV 66) and adjusts the occupied and supply air setpoints; status, temperatures and alarms are read-only objects.

Enable & remote start

SchdFrc (AV 66) sets occupancy: 0 = auto/unoccupied (the controller's own schedule and inputs decide), 1 = forced on, 2 = forced off.

Network setup

  • MS/TP MAC address must be 1-127; baud 9600, 19200, 38400 or 76800 is set on the PT-Link.
  • Device instance = Device Instance ID (default 50,000) + MS/TP MAC address; change the ID on the PT-Link web Configuration page.
  • The PT-Link web page defaults to 192.168.1.24 (user admin, password on the ProtoCessor label); AAON supports BACnet MS/TP only.

Watch out for

  • Alarm group and relay objects are bit-coded; decode them with the bit tables in the guide.
  • Points for MODGAS, REHEAT, preheat and expansion boards report only when that hardware is connected.

Integration notes

  • Objects are served by the AAON PT-Link II gateway, which reads the controller over its RS-485 loop; object names are the PT-Link data names (SchdFrc, SpcTp and so on).
  • Per the guide, AI and BI objects are read-only and AV objects are read/write; sensor inputs are read-only. No units column; AV limits are added to descriptions.
  • Unit Mode and Control Status enumerations are listed in the guide's property identifier page; alarm group and relay objects are bit strings described there.
  • The VCM is the legacy controller; its Control Status object is a bit string rather than an enumeration.

Questions about the AAON VCM Controller (legacy, via PT-Link II BACnet gateway)

How many BACnet points does the AAON VCM Controller (legacy, via PT-Link II BACnet gateway) have?

This list has 104 BACnet objects: 38 analog inputs, 21 analog values, 45 binary inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AAON VCM Controller (legacy, via PT-Link II BACnet gateway) BACnet points are writable?

21 of the 104 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official AAON VCM Controller (legacy, via PT-Link II BACnet gateway) BACnet documentation?

The source is PT-Link II BACnet5 Technical Guide - BACnet Properties and PT-Link Data Array Cross Reference for VCM (G114680 Rev A), revision 2022-10-12, published free by AAON at https://23126496.fs1.hubspotusercontent-na1.net/hubfs/23126496/G114680_PTLinkII_BACnet5_vA_221012.pdf.

What are the minimum BACnet points to integrate the AAON VCM Controller (legacy, via PT-Link II BACnet gateway)?

Start with AV 66 SchdFrc (Occupancy: 0 auto, 1 forced on, 2 forced off); AV 42 OcpClSt (Occupied cooling mode enable setpoint); AV 43 OcpHtSt (Occupied heating mode enable setpoint); AV 77 SaClSt (Supply air cooling setpoint); AV 78 SaHtSt (Supply air heating setpoint); AI 123 UnitMode (Occupancy mode in effect); AI 4 CtrlSts (Control status bits (demand, enables)); AI 72 SpcTp (Space temperature); AI 83 SaTp (Supply air temperature); AI 1 AlmSts (Summary of active alarm groups).

How do I enable BMS control of the AAON VCM Controller (legacy, via PT-Link II BACnet gateway)?

SchdFrc (AV 66) sets occupancy: 0 = auto/unoccupied (the controller's own schedule and inputs decide), 1 = forced on, 2 = forced off.
