AAON Touchscreen Controller BACnet points list

Updated 6 November 2026

Short answer

The AAON Touchscreen Controller runs the unit sequence (cooling, heating, dehumidification, economizer, heat wheel, fans) and offers BACnet MS/TP or Modbus on its RS-485 port. The list has 116 AVs (sensor readings, outputs and writable setpoints) and 42 BVs (stage, mode and alarm status plus three writable network commands: occupancy, VAV daytime heat and emergency shutdown).

This page lists 158 BACnet objects for the AAON Touchscreen Controller — 69 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from AAON’s own free documentation, linked below.

BMS integration notes: AAON Touchscreen Controller

Integration in brief

Select BACnet on the Network Config screen and set baud, parity and address. Occupancy can come from the internal schedule, the DI1 remote contact or BV 39 Network Occupy; write the occupied setpoints and read mode, fan and alarm status.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

Occupied mode comes from the internal schedule, a normally open remote forced-occupied contact on DI1, or the BACnet Network Occupy point (BV 39). BV 41 Network Emergency Shutdown stops the unit; BV 40 VAV Daytime Heat is the only way to start VAV daytime heating.

Network setup

  • Menu > Setup > Next > Network Config: Protocol (BACnet or Modbus), baud rate, bits/parity/stop and unit address for RS-485 port 1.

Watch out for

  • With the Unoccupied Mode setpoint OFF the unit stays off when unoccupied.
  • Space temperature and humidity (AV 114, AV 115) are read-only; there is no BAS sensor input in this list.

Questions about the AAON Touchscreen Controller

How many BACnet points does the AAON Touchscreen Controller have?

This list has 158 BACnet objects: 116 analog values, 42 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AAON Touchscreen Controller BACnet points are writable?

69 of the 158 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official AAON Touchscreen Controller BACnet documentation?

The source is AAON Touchscreen Controller User's Manual - Tables 3-7 BACnet Points List, revision 2019-07-02, published free by AAON at https://23126496.fs1.hubspotusercontent-na1.net/hubfs/23126496/AAON_TS_Controller_Manual_190702.pdf.

What are the minimum BACnet points to integrate the AAON Touchscreen Controller?

Start with BV 39 Network Occupy (Occupied command from the BMS); BV 41 Network Emergency Shutdown (Emergency shutdown command); AV 59 Occupied Cooling Spt (Occupied cooling setpoint); AV 77 Occupied Heating Spt (Occupied heating setpoint); BV 6 Occupancy Status (Occupied status); BV 7 Supply Fan Status (Supply fan proven); AV 24 Control Temp (Temperature the unit controls to); AV 8 Supply Air Temp (Supply air temperature); BV 23 Emergency Shutdown Alarm (Emergency shutdown alarm); BV 25 Supply Fan Alarm (Supply fan alarm).

How do I enable BMS control of the AAON Touchscreen Controller?

Occupied mode comes from the internal schedule, a normally open remote forced-occupied contact on DI1, or the BACnet Network Occupy point (BV 39). BV 41 Network Emergency Shutdown stops the unit; BV 40 VAV Daytime Heat is the only way to start VAV daytime heating.

How do I check these points on the real AAON Touchscreen Controller?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
