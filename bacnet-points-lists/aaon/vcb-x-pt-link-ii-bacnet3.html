Short answer

Object list the PT-Link II BACnet3 gateway (OE368-23B-BACNET3) publishes on BACnet MS/TP for a VCB-X controller. The gateway reads up to four Orion controllers over the WattMaster loop and serves them all from one BACnet device, offsetting each controller's objects by 500. AI and BI objects are read-only; AV objects (setpoints, offsets, force commands) are writable.

BMS integration notes: AAON VCB-X Controller (via PT-Link II BACnet3 MS/TP gateway)

Integration in brief

Address the Orion controllers 1-4 on the WattMaster loop, set the PT-Link's MS/TP MAC and baud on its DIP switches, and discover the single PT-Link device. Write occupancy through SchdFrc and the occupied setpoints, and read space/supply temperatures, unit mode, control status and the alarm objects.

Enable & remote start

No separate BAS enable is described; the BMS forces occupancy with SchdFrc (AV 66) and can force the HVAC mode with FrcHvacM (AV 262).

Network setup

  • Device instance = MS/TP MAC address + 50,000 by default; change the base in the FS-GUI if needed.
  • MS/TP MAC address (1-127) is set on DIP bank A; baud rate on DIP bank B (B1-B4).
  • Orion controllers must be addressed 1, 2, 3 and 4 on the WattMaster loop; one PT-Link serves up to four.
  • Each controller's objects are offset by 500 per address inside the one PT-Link device.

Watch out for

  • You cannot write to sensor input objects; only AV objects are writable.
  • FrcEcono (AV 267) and FrcFanSp (AV 266) override the controller; write 65535 to return them to Auto.
  • Address the controllers in sequence with no gaps to keep the 500-per-address offsets simple.

Integration notes

  • Instances shown are for the controller at loop address 1. For other controllers add (address - 1) x 500 (address 2 = +500, address 3 = +1000, address 4 = +1500).
  • Object names are the PT-Link data names; descriptions are the guide's parameter names. No units column is printed; AV limits are added to descriptions.
  • This BACnet3 guide prints Cooling, Heating and Economizer Enabled and Fan Starting Delay as AI objects for the VCB-X (AI 6, 15, 25, 30); the VCM-X tables in the same guide use BI for all four.
  • The VCB-X's own BACnet port (VCB-X field guide) uses different instance numbers; use this list only when the unit is read through a PT-Link II BACnet3.
  • Alarm group, control status, unit mode and relay objects are enumerations or bit strings defined on the guide's property identifier page (states column).
  • Many points exist only when the matching option or module is fitted (reheat, MODGAS, CFM sensors, 12-relay board, Title 24 economizer).

Questions about the AAON VCB-X Controller (via PT-Link II BACnet3 MS/TP gateway)

How many BACnet points does the AAON VCB-X Controller (via PT-Link II BACnet3 MS/TP gateway) have?

This list has 181 BACnet objects: 53 analog inputs, 66 analog values, 62 binary inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AAON VCB-X Controller (via PT-Link II BACnet3 MS/TP gateway) BACnet points are writable?

66 of the 181 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official AAON VCB-X Controller (via PT-Link II BACnet3 MS/TP gateway) BACnet documentation?

AAON does not publish it on its own website. Ask AAON or its representative for the current revision.

What are the minimum BACnet points to integrate the AAON VCB-X Controller (via PT-Link II BACnet3 MS/TP gateway)?

Start with AV 66 SchdFrc (0 = auto schedule, 1 = force occupied, 2 = force unocc); AV 262 FrcHvacM (Force HVAC mode (0 = Auto)); AV 42 OcpClSt (Occupied cooling setpoint); AV 43 OcpHtSt (Occupied heating setpoint); AI 123 UnitMode (Occupied/unoccupied/override state); AI 4 CtrlSts (Current operating mode (vent, cool, heat...)); AI 72 SpcTp (Space temperature); AI 83 SaTp (Supply air temperature); AI 1 AlmSts (Any active alarm).

How do I enable BMS control of the AAON VCB-X Controller (via PT-Link II BACnet3 MS/TP gateway)?

No separate BAS enable is described; the BMS forces occupancy with SchdFrc (AV 66) and can force the HVAC mode with FrcHvacM (AV 262).

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
