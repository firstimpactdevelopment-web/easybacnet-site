BMS integration notes: Contemporary Controls BASstat BAST-321HP-B2 Heat Pump Thermostat

Integration in brief

Turn the thermostat outputs on with On-Off Control (BV 5), set occupancy with Occupancy Command (BV 14), and write the system mode, cooling and heating setpoints and fan mode. Read the space temperature, occupancy status, output status and fan speed.

Enable & remote start

On-Off Control (BV 5) switches the thermostat outputs. Occupancy Command (BV 14) only takes effect when the ESI contact is disabled in Lock (AV 18 bit value 64); by default occupancy comes from the ESI dry contact.

Heartbeat & communication loss

A space temperature written to Space Temperature via Network (AV 1) is only used while the BMS keeps toggling Heartbeat (BV 16) within the Heartbeat Rate (AV 29) period, in seconds; otherwise the thermostat reverts to its own sensor.

Sensors & values from the BMS

Set Temperature Source (MV 3) to 3 (Assigned through BACnet) and write the space temperature to AV 1, toggling BV 16 as a heartbeat.

Network setup

  • BACnet MS/TP: MAC address set in the Engineering menu (Addr, 1-127) or AV 20; baud 9600-76800 set with bAud or Baud Rate (MV 6).
  • Device instance = devH x 1000 + devL in the Engineering menu, or write Device Instance (AV 21) once online.
  • The manual gives 600001 as the default device instance, MAC address 1 and 38400 baud.

Watch out for

  • Lock (AV 18) is bit-coded: add the bit values to lock buttons, ignore the ESI or door contact, block changes to the comms settings or hand the relays to BACnet (512).
  • The manual text calls the Lock object AV17 in places and the heartbeat rate AV-29; the object table numbers are used here.
  • Relay control BVs only drive the relays when Lock bit 9 (512) hands the outputs to the BACnet supervisor.

Questions about the Contemporary Controls BASstat BAST-321HP-B2 Heat Pump Thermostat

How many BACnet points does the Contemporary Controls BASstat BAST-321HP-B2 Heat Pump Thermostat have?

This list has 58 BACnet objects: 4 analog inputs, 27 analog values, 7 binary inputs, 12 binary values, 8 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Contemporary Controls BASstat BAST-321HP-B2 Heat Pump Thermostat BACnet points are writable?

46 of the 58 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Contemporary Controls BASstat BAST-321HP-B2 Heat Pump Thermostat BACnet documentation?

The source is BAST-321HP-B2 Heat Pump Thermostat User Manual (UM-15094000-AA0), published free by Contemporary Controls at https://www.ccontrols.com/pdf/um/BAST-321-B2-UserManual.pdf.

What are the minimum BACnet points to integrate the Contemporary Controls BASstat BAST-321HP-B2 Heat Pump Thermostat?

Start with BV 5 On-Off Control (Thermostat outputs on/off (1 = on)); BV 14 Occupancy Command (0 = occupied, 1 = unoccupied); MV 1 System Mode (Cool, heat or ventilation mode); AV 0 Cooling Temperature Setpoint (Occupied cooling setpoint); AV 3 Heating Temperature Setpoint (Occupied heating setpoint); MV 0 Fan Mode (1 = auto, then fan speeds); AI 0 Current Temperature (Space temperature in use); BI 0 Occupancy Status (0 = occupied, 1 = unoccupied); BI 2 Cooling-heating Status (Heating/cooling output active); MV 5 Fan Speed Status (Current fan speed).
