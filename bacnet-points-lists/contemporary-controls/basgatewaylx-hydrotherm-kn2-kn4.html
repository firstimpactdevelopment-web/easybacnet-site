BMS integration notes: Contemporary Controls Advanced Thermal Hydronics (Hydrotherm) KN-2 / KN-4 via BASgatewayLX

Integration in brief

Write HeatDemand and the setpoint, then read header/supply temperatures, boilers on and modulation. Enable the status bits for each member boiler you have.

Network setup

  • The BASgatewayLX presents each Modbus device as its own virtual BACnet device on BACnet IP; give it a unique device instance and Modbus address (serial) or IP address (Modbus TCP) when you add it with this profile.
  • One BASgatewayLX handles up to 100 Modbus devices and 1000 polled points in total, so leave unneeded rows unpolled.

Watch out for

  • SetpointTimer (AO 2, seconds) sits next to the setpoint in the profile; check the KN manual for how it limits a BMS setpoint before relying on it.
  • Member boilers 2-16 repeat boiler 1's status block at higher instances; they are unpolled by default.
  • Unpolled rows do not appear as BACnet objects until enabled in the gateway's device profile page.

Questions about the Contemporary Controls Advanced Thermal Hydronics (Hydrotherm) KN-2 / KN-4 via BASgatewayLX

How many BACnet points does the Contemporary Controls Advanced Thermal Hydronics (Hydrotherm) KN-2 / KN-4 via BASgatewayLX have?

This list has 674 BACnet objects: 112 analog inputs, 18 analog outputs, 544 binary inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Contemporary Controls Advanced Thermal Hydronics (Hydrotherm) KN-2 / KN-4 via BASgatewayLX BACnet points are writable?

18 of the 674 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Contemporary Controls Advanced Thermal Hydronics (Hydrotherm) KN-2 / KN-4 via BASgatewayLX BACnet documentation?

The source is BASgatewayLX Modbus device profile Hydrotherm_KN2_KN4_aRY_Boiler_a (Hydrotherm_KN2_KN4_aRY_Boiler_a_LX.csv), published free by Contemporary Controls at https://www.ccontrols.com/support/dp/Hydrotherm%20KN2_KN4_rAY_Modbus%20Profile.zip.

Start with AO 1 HeatDemand (Heat demand from the BMS); AO 3 Setpoint (System setpoint); AO 18 DHWSetpoint (DHW setpoint); AI 21 HeaderTemp (Header temperature); AI 22 SupplyTemp (Supply temperature); AI 23 ReturnTemp (Return temperature); AI 19 BoilersOn (Number of boilers on); AI 20 Modulation (System modulation); BI 47 Boiler01Status2 Alarm (Boiler 1 alarm).
