BMS integration notes: Contemporary Controls ABB ACH550 (ABB DRV LIM profile, 5305 = 0) via BASgatewayLX

Integration in brief

Set the drive for fieldbus control and 5305 = 0. Write the ABB DRV control word (AO 36, register 40001) for start/stop and Reference 1 (AO 37) for speed; read RDY_REF, TRIPPED, ALARM and the actual values.

Enable & remote start

Set the drive's EXT1 command and reference sources to COMM and parameter 5305 = 0; start/stop then comes from the control word at register 40001.

Network setup

  • The BASgatewayLX presents each Modbus device as its own virtual BACnet device on BACnet IP; give it a unique device instance and Modbus address (serial) or IP address (Modbus TCP) when you add it with this profile.
  • One BASgatewayLX handles up to 100 Modbus devices and 1000 polled points in total, so leave unneeded rows unpolled.

Watch out for

  • ACH550 parameter 5305 (EFB CTRL PROFILE) selects the control profile: 0 = ABB DRV LIM, 1 = DCU PROFILE, 2 = ABB DRV FULL. Load the BASgatewayLX profile that matches it.
  • Unpolled rows do not appear as BACnet objects until enabled in the gateway's device profile page.

Which Contemporary Controls ABB ACH550 (ABB DRV LIM profile, 5305 = 0) via BASgatewayLX BACnet points are writable?

4 of the 583 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

What are the minimum BACnet points to integrate the Contemporary Controls ABB ACH550 (ABB DRV LIM profile, 5305 = 0) via BASgatewayLX?

Start with AO 36 CONTROL WORD (Control word (40001): OFF1/OFF2/OFF3, start, reset); AO 37 Reference 1 (Speed reference REF1); BI 17 RDY_REF (Operation enabled (drive running)); AI 64 OUTPUT FREQ (Output frequency, Hz); AI 63 SPEED (Motor speed, rpm); AI 65 CURRENT (Motor current, A); AI 67 POWER (Output power, kW); BI 22 ALARM (Any active alarm); BI 18 TRIPPED (Drive tripped on a fault); AI 118 FAULT WORD 1 (Fault bits, word 1).

How do I enable BMS control of the Contemporary Controls ABB ACH550 (ABB DRV LIM profile, 5305 = 0) via BASgatewayLX?

Set the drive's EXT1 command and reference sources to COMM and parameter 5305 = 0; start/stop then comes from the control word at register 40001.
