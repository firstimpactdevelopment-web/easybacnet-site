BMS integration notes: Contemporary Controls BASstat BAST-221C/CH-BW2 Wireless Multi-Stage Thermostat

Integration in brief

Turn the thermostat outputs on with On-Off Control (BV 5), set occupancy with Occupancy Command (BV 14), and write the system mode, cooling and heating setpoints and fan mode. Read the space temperature, occupancy status, output status and fan speed.

Enable & remote start

On-Off Control (BV 5) switches the thermostat outputs. Occupancy Command (BV 14) only takes effect when the ESI contact is disabled in Lock (AV 18 bit value 64); by default occupancy comes from the ESI dry contact.

Heartbeat & communication loss

A space temperature written to Space Temperature Via BACnet (AV 1) is only used while the BMS keeps toggling Heartbeat signal (BV 16) within the Heartbeat Rate (AV 29) period, in seconds; otherwise the thermostat reverts to its own sensor.

Sensors & values from the BMS

Set Temperature Source (MV 3) to 3 (Assigned through BACnet) and write the space temperature to AV 1, toggling BV 16 as a heartbeat.

Network setup

  • BACnet IP over Wi-Fi; the UDP port defaults to 47808 (BAC0) and can be set in the Engineering menu (UdP) or by writing UDP Port No (AV 21).
  • Device instance = devH x 1000 + devL in the Engineering menu, or write Device Instance (AV 20) once online.
  • DHCP or static IP addressing is set from the thermostat's Wi-Fi setup pages.
  • The manual gives 100001 as the default device instance.

Watch out for

  • Lock (AV 18) is bit-coded: add the bit values to lock buttons, ignore the ESI or door contact, block changes to the comms settings or hand the relays to BACnet (512).
  • The manual text calls the Lock object AV17 in places and the heartbeat rate AV-29; the object table numbers are used here.
  • Relay control BVs only drive the relays when Lock bit 9 (512) hands the outputs to the BACnet supervisor.

Questions about the Contemporary Controls BASstat BAST-221C/CH-BW2 Wireless Multi-Stage Thermostat

How many BACnet points does the Contemporary Controls BASstat BAST-221C/CH-BW2 Wireless Multi-Stage Thermostat have?

This list has 61 BACnet objects: 6 analog inputs, 28 analog values, 9 binary inputs, 11 binary values, 7 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Contemporary Controls BASstat BAST-221C/CH-BW2 Wireless Multi-Stage Thermostat BACnet points are writable?

45 of the 61 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Contemporary Controls BASstat BAST-221C/CH-BW2 Wireless Multi-Stage Thermostat BACnet documentation?

What are the minimum BACnet points to integrate the Contemporary Controls BASstat BAST-221C/CH-BW2 Wireless Multi-Stage Thermostat?

Start with BV 5 On-Off Control (Thermostat outputs on/off (1 = on)); BV 14 Occupancy Command (0 = occupied, 1 = unoccupied); MV 1 System Mode (Cool, heat or ventilation mode); AV 0 Cooling Temperature Setpoint (Occupied cooling setpoint); AV 3 Heating Temperature Setpoint (Occupied heating setpoint); MV 0 Fan Mode (Fan mode; 1 = auto); AI 0 Current Temperature (Space temperature in use); BI 0 Occupancy Status (0 = occupied, 1 = unoccupied); BI 2 Cooling-heating Status (Heating/cooling output active); MV 5 Fan Speed Status (Current fan speed).

How do I enable BMS control of the Contemporary Controls BASstat BAST-221C/CH-BW2 Wireless Multi-Stage Thermostat?

On-Off Control (BV 5) switches the thermostat outputs. Occupancy Command (BV 14) only takes effect when the ESI contact is disabled in Lock (AV 18 bit value 64); by default occupancy comes from the ESI dry contact.

Does the Contemporary Controls BASstat BAST-221C/CH-BW2 Wireless Multi-Stage Thermostat need a BACnet heartbeat or have a communication timeout?

A space temperature written to Space Temperature Via BACnet (AV 1) is only used while the BMS keeps toggling Heartbeat signal (BV 16) within the Heartbeat Rate (AV 29) period, in seconds; otherwise the thermostat reverts to its own sensor.
