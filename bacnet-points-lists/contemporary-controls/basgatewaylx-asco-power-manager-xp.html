Network setup

  • The BASgatewayLX presents each Modbus device as its own virtual BACnet device on BACnet IP; give it a unique device instance and Modbus address (serial) or IP address (Modbus TCP) when you add it with this profile.
  • One BASgatewayLX handles up to 100 Modbus devices and 1000 polled points in total, so leave unneeded rows unpolled.

Watch out for

  • Nominal voltage/current/kW/frequency outputs (AO 41-44) are meter setup values; don't write them cyclically.

How many BACnet points does the Contemporary Controls ASCO Power Manager Xp via BASgatewayLX have?

This list has 356 BACnet objects: 110 analog inputs, 98 analog outputs, 44 binary inputs, 104 binary outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Contemporary Controls ASCO Power Manager Xp via BASgatewayLX BACnet points are writable?

202 of the 356 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Contemporary Controls ASCO Power Manager Xp via BASgatewayLX BACnet documentation?

The source is BASgatewayLX Modbus device profile Asco_Power_Manage_Xp_a (Asco_Power_Manage_Xp_a_LX.csv), published free by Contemporary Controls at https://www.ccontrols.com/support/dp/Asco_Power_Mgr_.zip.
