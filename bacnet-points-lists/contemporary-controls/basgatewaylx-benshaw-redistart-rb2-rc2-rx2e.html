Set Local/Remote to remote, then run/stop by BO 1; read running, up to speed, average current and the alarm/fault/lockout states.

Enable & remote start

Starter Control Local/Remote (BO 4) selects whether the network run command is used; check the Benshaw manual for which state is remote.

Network setup

  • The BASgatewayLX presents each Modbus device as its own virtual BACnet device on BACnet IP; give it a unique device instance and Modbus address (serial) or IP address (Modbus TCP) when you add it with this profile.
  • One BASgatewayLX handles up to 100 Modbus devices and 1000 polled points in total, so leave unneeded rows unpolled.

Watch out for

  • Unpolled rows do not appear as BACnet objects until enabled in the gateway's device profile page.

Which Contemporary Controls Benshaw RediStart RB2 / RC2 / RX2E soft starter via BASgatewayLX BACnet points are writable?

12 of the 307 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
