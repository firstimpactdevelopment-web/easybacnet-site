Short answer

The RI-A5IPBAC is a BACnet IP add-on module for the RI-F500 series power analysers. Its object list is about 1,000 objects: 4-20 mA and PT100 inputs and 4-20 mA outputs on extension modules, Analog Values for voltages, currents, power, energy (per phase, per quadrant, tariffs and monthly history), max/min and demand values, harmonics up to the 63rd order, pulse counters and event records, writable setup values (CT/PT, demand, limits, relay and AO configuration), plus digital input, relay output and alarm status objects.

This page lists 998 BACnet objects for the Rayleigh Instruments RI-F500 series power analyser with RI-A5IPBAC BACnet IP module — 175 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of Rayleigh Instruments’s documentation hosted by Reseller Shopify CDN, not by Rayleigh Instruments itself, so treat it as unofficial.

BMS integration notes: Rayleigh Instruments RI-F500 series power analyser with RI-A5IPBAC BACnet IP module

Integration in brief

Configure the module's network settings from the RI-F500 front panel, then read total power, energy and the main voltages and currents. Set CT and PT values on the meter (or AV 788-793) before trusting the readings.

Watch out for

  • Configuration AVs (784 onward) change meter setup; do not write them cyclically.

What are the minimum BACnet points to integrate the Rayleigh Instruments RI-F500 series power analyser with RI-A5IPBAC BACnet IP module?

Start with AV 27 Import Active Energy EP+ (Import active energy, kWh); AV 13 Total active power-P (Total active power, kW); AV 17 Total reactive power-Q (Total reactive power, kvar); AV 0 Phase voltage-V1 (Phase voltage L1, V); AV 3 Line voltage-V12 (Line voltage L1-L2, V); AV 6 Phase current-I1 (Phase current L1, A); AV 721 Present demand value -P (Present active power demand, kW); BV 3 High voltage alarm (High voltage alarm (1 = alarm)); BV 0 Phase Sequence (Phase sequence abnormal (1)).
