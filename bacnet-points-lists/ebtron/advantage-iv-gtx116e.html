Short answer

EBTRON's Advantage IV transmitters report averaged airflow and temperature from thermal dispersion probes, plus optional humidity, pressure and per-sensor traverse data. One object list covers the whole family: which objects exist depends on the transmitter model and probe types connected. Per the Network Port notes, the GTB, GTM and GTS variants carry the BACnet IP settings and the GTB and GTC variants the MS/TP settings.

BMS integration notes: EBTRON Advantage IV Airflow Transmitter (GTx116e / GTx108e)

Integration in brief

This is a read-only measurement device for a BMS. Map average airflow and temperature (AI1/AI2) and the alarm status, plus RH/dew point/enthalpy or the second location if those options are fitted. Per-node traverse data has to be turned on with AV10 before those objects carry values.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • The Device object is listed as instance 2; Object_Identifier, name, description, APDU timeout, Max Master (up to 127) and Max Info Frames (up to 255) are writable.
  • Network Port object NP1 (newer firmware) holds the BACnet IP mode and foreign-device BBMD settings on B/M/S variants, and Max Master/Max Info Frames on B/C variants.

Watch out for

  • Objects only exist when the matching probes, options and transmitter variant are present.
  • AV2 means AMD[-2] Area on EB-Flow2 units but Fan 1 Area on fan-probe units.
  • Analog Input present values can only be written after setting Out_Of_Service.

Integration notes

  • All objects are conditional: they only appear if the matching sensors/probe type/transmitter variant are present.
  • AV2 is AMD[-2] Area on EB-Flow2 dual-location units but Fan 1 Area on fan-probe units; AV2-AV9 carry Fan 1-8 Area.
  • Node velocity/temperature objects (AV21-AV56) are only populated after enabling traverse data in AV10, and only up to the installed node count.
  • Analog Input present values can only be written after setting Out_Of_Service; COV increment and units are writable.
  • Units follow the transmitter's IP/SI setting (bracketed values are SI).

Questions about the EBTRON Advantage IV Airflow Transmitter (GTx116e / GTx108e)

How many BACnet points does the EBTRON Advantage IV Airflow Transmitter (GTx116e / GTx108e) have?

This list has 71 BACnet objects: 10 analog inputs, 59 analog values, 1 device, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which EBTRON Advantage IV Airflow Transmitter (GTx116e / GTx108e) BACnet points are writable?

3 of the 71 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
