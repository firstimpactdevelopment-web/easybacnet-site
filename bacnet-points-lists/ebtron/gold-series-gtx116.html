EBTRON Gold Series GTx116 Airflow Transmitter (GTC116 / GTM116) BACnet points list

Updated 16 October 2026

Short answer

The Gold Series GTx116 is EBTRON's earlier (Advantage III) airflow transmitter. Over BACnet it reports average airflow, average temperature and alarm status, plus optional per-probe flow and temperature traverse values. GTC116 boards speak BACnet MS/TP (default 76,800 baud) or Modbus RTU; GTM116 boards speak BACnet IP or BACnet Ethernet, with Modbus TCP always on.

BMS integration notes: EBTRON Gold Series GTx116 Airflow Transmitter (GTC116 / GTM116)

Integration in brief

This is a read-only airflow station: map average flow, average temperature and alarm status. Turn on per-probe traverse data with AV2 only if you need it. Set a unique device instance and network address on each transmitter before connecting it.

Network setup

  • Factory device instance is 2 on both GTC116 and GTM116; set it in the NETWORK menu or by writing the Device object identifier (0 to 4,194,302).
  • GTC116 BACnet MS/TP default baud is 76,800 (Modbus 19,200), set in the NETWORK menu.
  • GTM116 defaults: BACnet IP, DHCP off, IP 10.0.0.100, mask 255.255.255.0, gateway 10.0.0.10; BACnet Ethernet can be selected instead.
  • BACnet IP uses port 47808; Modbus TCP (port 502) is always enabled on the GTM116.
  • RESET NET in the menu returns communication settings to factory defaults.

Watch out for

  • Traverse objects AV3-AV34 stay empty until AV2 is set to Flow, Temp or Both.

Integration notes

  • Factory device instance is 2 on both GTC116 and GTM116; change it from the NETWORK menu or by writing the Device object identifier.
  • GTM116 default IP is 10.0.0.100/255.255.255.0, gateway 10.0.0.10, DHCP off; use UDP port 47808.
  • Traverse objects AV3-AV34 only carry data after AV2 is set to Flow, Temp or Both.
  • The 16 flow traverse and 16 temperature traverse objects share the names printed in the manual; check actual object names on site.
  • Supported services listed: Subscribe COV, ReadProperty, WriteProperty, DeviceCommunicationControl, Who-Is.

How many BACnet points does the EBTRON Gold Series GTx116 Airflow Transmitter (GTC116 / GTM116) have?

Which EBTRON Gold Series GTx116 Airflow Transmitter (GTC116 / GTM116) BACnet points are writable?

2 of the 38 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
