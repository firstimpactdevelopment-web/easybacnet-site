Belimo Room Operating Unit 22RT-5U00 BACnet points list

Updated 16 October 2026

Short answer

The 22RT room operating unit is a wall sensor with a configurable display that measures room temperature and, depending on model, humidity and CO2. Over BACnet MS/TP it reports the measured values and lets the BMS read and write the temperature and ventilation setpoints, set the building operation mode, and control what the display shows (icons, buttons, CO2 traffic light). The occupant's local adjustments come back as the same setpoint objects.

BMS integration notes: Belimo Room Operating Unit 22RT-5U00

Integration in brief

Read AI 1 temperature (plus AI 2 humidity and AI 3 CO2 where fitted) and use AV 110 or the relative AV 111 as the zone setpoint, which the occupant can also change locally. Use MV 118 for comfort/eco/boost/off mode and AV 15 for the ventilation setpoint. Drive the heating/cooling and warning icons from the BMS if wanted.

Enable & remote start

BV 110 EnLocalAdjustment allows or blocks occupant changes to setpoints, Eco, Boost and On/Off on the unit.

Heartbeat & communication loss

AV 130 BusWatchdog, 30-3600 s (default 120 s), is for monitoring only; the document gives no fail action.

Network setup

  • MS/TP: baud 9600-115200, default 38400; MAC address 0-127, default 1; max 32 nodes without repeater.
  • Default device instance 1.
  • 120 Ω termination is off by default and is set with the Belimo Assistant App (shown in BV 99).
  • Parameterise with the Belimo Assistant App.

Watch out for

  • Writable persistent objects must not be written on a regular basis; avoid cyclic writes of display and limit settings.
  • Changing MV 127 changes the units of the temperature and setpoint objects.
  • The occupant's setpoint range is limited by AV 112 (centre) and AV 113 (range).
  • Max 5 active COV subscriptions.

Integration notes

  • Humidity, dew point and CO2 objects only apply to models with those sensors.
  • MV 127 sets the bus unit of AI 1, AV 12 and AV 110; MV 100 only changes the display unit.
  • MV 103 SetpointType uses state values 0 and 1 as printed in the document.
  • Display objects (BV 110-125, MV 110-117) configure the screen layout and icons rather than the HVAC process.

Questions about the Belimo Room Operating Unit 22RT-5U00

How many BACnet points does the Belimo Room Operating Unit 22RT-5U00 have?

This list has 44 BACnet objects: 3 analog inputs, 13 analog values, 1 binary input, 12 binary values, 15 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Belimo Room Operating Unit 22RT-5U00 BACnet points are writable?

37 of the 44 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Belimo Room Operating Unit 22RT-5U00 BACnet documentation?

The source is BACnet Interface Description, Room Operating Units 22RT...-5U00..., revision 2023-04 / V2.2/V3.0, published free by Belimo at https://www.belimo.com/mam/general-documents/system_integration/belimo_BACnet_Interface-description_room-sensors-am_en-us.pdf.

What are the minimum BACnet points to integrate the Belimo Room Operating Unit 22RT-5U00?

Start with AI 1 Temperature (Room temperature); AV 110 SetpointTemperature (Zone setpoint (BMS or occupant)); AI 2 Relative_Humidity (Room humidity); AI 3 Co2Value (Room CO2); MV 118 OperationMode (Off / comfort / eco / boost); AV 15 VentilationSetpoint (Ventilation demand from the occupant); BV 110 EnLocalAdjustment (Lock or allow local changes).

How do I enable BMS control of the Belimo Room Operating Unit 22RT-5U00?

BV 110 EnLocalAdjustment allows or blocks occupant changes to setpoints, Eco, Boost and On/Off on the unit.

Does the Belimo Room Operating Unit 22RT-5U00 need a BACnet heartbeat or have a communication timeout?
