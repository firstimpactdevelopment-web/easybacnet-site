Belimo VAV-Compact BACnet points list

Updated 16 October 2026

Short answer

The VAV-Compact is a damper actuator with a built-in differential pressure sensor and VAV controller for box-level airflow control. Over BACnet MS/TP it takes a relative setpoint on AO 1 that is scaled between the Min and Max limits and interpreted as airflow or position. It reports damper position, airflow, an optional sensor input and actuator status.

This page lists 23 BACnet objects for the Belimo VAV-Compact — 10 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Belimo’s own free documentation, linked below.

BMS integration notes: Belimo VAV-Compact

Integration in brief

Leave MV 122 SpSource on Bus (default), select flow control in MV 123, set Min and Max airflow once, then command AO 1 SpRel. Read AI 19 airflow, AI 1 position and BI 101 summary status. If you turn on the bus watchdog, keep rewriting AO 1 or MO 1 inside the timeout.

Enable & remote start

MV 122 SpSource = 2 (Bus, the default) makes the actuator follow AO 1. In hybrid mode (SpSource = Analog) the 0-10 V signal on wire 3 is the setpoint and only MO 1 is taken from the bus.

Heartbeat & communication loss

AV 130 Bus Watchdog, 0-3600 s, default 0 (off). When set, each write to AO 1 or MO 1 restarts the timer; on timeout the AO 1 priority array is cleared, the relinquish default (0%) applies and MI 110 shows Bus Watchdog triggered. In hybrid mode only MO 1 writes are tracked.

Sensors & values from the BMS

Sensor 1 can be read over BACnet when MV 220 is set to Active (AI 20, mV) or Switch (BI 20). Switch mode needs the control signal configured to 2-10 V; restart the actuator after changing the sensor type.

Network setup

  • MS/TP: baud 9600-76800, default 38400; MAC address 0-127, default 1; max 32 nodes without repeater.
  • Default device instance 1.
  • Quick addressing with the Address and Adaption buttons on the actuator (see datasheet).
  • Configuration tool: ZTH EU; bus termination state shows in BI 99.

Watch out for

  • Writable objects with instance 90 and above are persistent; do not write them on a regular basis.
  • Max must be at least Min and above 20%.
  • Fast open / Fast close overrides add mechanical wear; keep them for time-critical events such as frost protection.
  • Max 6 active COV subscriptions.

Integration notes

  • The same devices can also run Modbus RTU; this list covers the BACnet MS/TP mode.
  • The default setpoint source is Bus.
  • AI 20 and BI 20 are out of service unless MV 220 selects the matching sensor type and the setpoint source is Bus.
  • Actuator status faults are latched; clear them with MV 120 Command = Reset.
  • Flow unit of AI 19 and AV 104 follows MV 121.

Questions about the Belimo VAV-Compact

How many BACnet points does the Belimo VAV-Compact have?

This list has 23 BACnet objects: 6 analog inputs, 1 analog output, 4 analog values, 3 binary inputs, 3 multi-state inputs, 1 multi-state output, 5 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Belimo VAV-Compact BACnet points are writable?

10 of the 23 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Belimo VAV-Compact BACnet documentation?

The source is BACnet Interface Description, VAV-Compact, revision 2026-01 / V3.08, published free by Belimo at https://www.belimo.com/mam/general-documents/system_integration/BACnet/belimo_BACnet_Interface-description_VAV_V3_8_en-gb.pdf.

What are the minimum BACnet points to integrate the Belimo VAV-Compact?

Start with AO 1 SpRel (Airflow setpoint between Min and Max); AI 19 AbsFlow_UnitSel (Measured airflow); AI 1 RelPos (Damper position feedback); BI 101 SummaryStatus (Overall OK / not OK alarm).

How do I enable BMS control of the Belimo VAV-Compact?

MV 122 SpSource = 2 (Bus, the default) makes the actuator follow AO 1. In hybrid mode (SpSource = Analog) the 0-10 V signal on wire 3 is the setpoint and only MO 1 is taken from the bus.

Does the Belimo VAV-Compact need a BACnet heartbeat or have a communication timeout?

Can the BMS supply sensor values to the Belimo VAV-Compact?
