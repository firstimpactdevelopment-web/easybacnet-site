Updated 16 October 2026

Short answer

This family of Belimo sensors shares one BACnet MS/TP object map. AI 0-11 carry the measured values (temperature, humidity, derived absolute humidity, enthalpy and dew point, CO2, VOC, differential pressure and fan airflow), and AV objects hold offsets, output scaling limits, channel assignment, fan k-factors, device settings and the optional LCD. Only the values the particular model measures are in service; the rest show Out of Service.

This page lists 81 BACnet objects for the Belimo Duct and Pipe Sensors (22DTH, 22UTH, 22DTM, 22ADP) BACnet — 69 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Belimo’s own free documentation, linked below.

BMS integration notes: Belimo Duct and Pipe Sensors (22DTH, 22UTH, 22DTM, 22ADP) BACnet

Integration in brief

Set the MS/TP MAC address and baud rate on the RS-485 module's DIP switches, then read the AI objects the model supports. Offsets, limits and the SI/Imperial choice are configuration AVs to set once. For 22ADP fan airflow, set the fan manufacturer and k-factor first.

Network setup

  • MS/TP only; MAC address 1-127 set in binary on DIP1 switches 1-5 plus DIP2 switches 4-5 (0 is reserved).
  • Baud rate on DIP2 switches 2-3: 9600, 19200, 38400 or 76800.
  • DIP2 switch 1 turns on the 120 Ω terminator; all DIP switches ship OFF.
  • Device ID = AV 46 offset + MAC address.
  • Unconfirmed COV (AV 47) is the COV method; there are no COV subscriptions (DS-COVU-B only).

Watch out for

  • inWC offsets in AV 4/5 are written in thousandths (write 10 for 0.01 inWC).
  • AV 39 altitude is always entered in metres.
  • The 22ADP differential pressure range is set by DIP switches 1-3 on the sensor main board.
  • Channel numbers 1 and 2 also drive the two 0-10 V outputs AOU1/AOU2.

Integration notes

  • The document gives no BACnet object names, only instances and descriptions; names here are the printed descriptions.
  • Points not measured by a given model read Out of Service; check the datasheet for which apply.
  • SI or Imperial units are chosen with AV 38; on 22ADP models DIP switch 6 sets this instead.
  • AV 22-25 are printed as AI[22]-AI[25] in the document but sit in the AV limits table and are R/W.
  • AV 50 appears twice in the document (deduplicated); AV 56 and AV 57 share the same text.
  • Document cover says Edition 2024-03 / V4.2 although the file name says V4_1.

Questions about the Belimo Duct and Pipe Sensors (22DTH, 22UTH, 22DTM, 22ADP) BACnet

How many BACnet points does the Belimo Duct and Pipe Sensors (22DTH, 22UTH, 22DTM, 22ADP) BACnet have?

This list has 81 BACnet objects: 12 analog inputs, 69 analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Belimo Duct and Pipe Sensors (22DTH, 22UTH, 22DTM, 22ADP) BACnet BACnet points are writable?

69 of the 81 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
