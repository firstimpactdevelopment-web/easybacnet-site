Short answer

The VZ8250 is the VAV version of the Viconics VT8000 room controller. It is a BACnet application-specific controller (B-ASC) on BACnet MS/TP, with BACnet IP and Wi-Fi status objects for units set up through the Wi-Fi configuration web page. Its VAV objects cover airflow (measured, setpoint, min/max limits and offsets), damper positions, PI zoning demand, box type (PD/PI), reheat and fan configuration, alongside the common VT8000 setpoint, display, Lua and ZigBee wireless sensor objects.

BMS integration notes: Viconics VZ8250 VAV Zone Controller

Integration in brief

Command occupancy with MV 10 and on/off with MV 16 (Off/Auto), and write the occupied setpoints AV 39/AV 40. Read AV 100 room temperature, MI 33 effective occupancy, MV 112 control status and the airflow pair AV 110 / AI 350. Write at priorities 4-16 for live control; avoid 1-3.

Enable & remote start

No enable switch is needed. The BMS writes MV 10 Occupancy Command (1 = Loc. occ, the controller decides locally; 2 = Occupied; 3 = Unoccupied) and MV 16 System Mode (Off or Auto). MV 110 Occupancy Source chooses whether local occupancy follows motion, the schedule or a mix.

Sensors & values from the BMS

The guide has no BMS-written room temperature object: MV 145 Room Temperature Sensor selects the wired, internal or one of 20 paired ZigBee wireless sensors, and MI 309 shows which one is in use. Writing an AI present value only works with Out_Of_Service set TRUE.

Network setup

  • The Device Object_Identifier and Object_Name are writable; no default device instance is printed in the guide.
  • BACnet MS/TP baud rate is MV 8 (9600, 19200, 38400, 57600, 76800, 115200 or Auto; default Auto). Max_Master is writable, 0-127, default 127.
  • MI 317 shows whether BACnet IP is enabled; it is set from the BACnet/IP page of the Wi-Fi configuration web page.
  • COV subscriptions are supported (DS-COV-B), along with an internal schedule (SCHED-I-B) and time synchronization.

Watch out for

  • Priorities 1-3 are stored in EEPROM and lock the value at the thermostat, even after a power cycle, until it is released at the same priority or factory defaults are restored. Use them only for fixed configuration.
  • Priorities 4-16 are held in RAM and are lost on a power cycle, so the BMS has to write them again after the controller restarts.
  • The relinquish default (priority 17) is the value the occupant changes at the thermostat, which is kept through power cycles. Writes at 4-16 override local changes to setpoints and modes.
  • The controller does not support segmented requests or responses; keep Read Property Multiple requests small.
  • MV 172 Damper Override forces the damper (minimum, max cool, close, reheat, open); release it after balancing.
  • MV 170 VAV Box Type, AV 222 K-factor and the airflow limits AV 254-259 are commissioning settings; do not write them cyclically.

Integration notes

  • Viconics is a Schneider Electric brand; the guide is published on veris.com.
  • Airflow objects (AV 110, AI 350, AV 254-259) are in CFM; AV 222 'Flow @ 1 inch wc (K)' and AV 223 'Pressure Sensor Range' scale the airflow reading.
  • Access follows the guide's generic property tables: AV, AO, BV, BO and MSV present values are commandable, CSVs are writable, and AI/MSI present values can only be written while Out_Of_Service is TRUE.
  • Wireless Device 1-20 objects only report data for ZigBee sensors paired to the controller.
  • Printed as in the guide: MV 112 max printed 2 with three states; AI 404 is printed 'Wireless Device 20 - CO' with the '2' split off and is listed here as CO2.

Questions about the Viconics VZ8250 VAV Zone Controller

How many BACnet points does the Viconics VZ8250 VAV Zone Controller have?

This list has 440 BACnet objects: 76 analog inputs, 7 analog outputs, 96 analog values, 7 binary inputs, 6 binary outputs, 25 binary values, 1 file, 95 multi-state inputs, 96 multi-state values, 30 characterstring values, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Viconics VZ8250 VAV Zone Controller BACnet points are writable?

262 of the 440 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Viconics VZ8250 VAV Zone Controller BACnet documentation?

The source is VZ8250 BACnet Integration Guide - Variable Air Volume (VAV) - Firmware Revision 2.6 (028-0509-04_IG-VZ8250-BNET_A4_EN (Version 4)), revision 2022-05, published free by Viconics at https://www.veris.com/ASSETS/DOCUMENTS/CMS/EN/Static_Documents/DownloadCenter/028-0509-04_IG-VZ8250-2.6-BNET_A4_EN_RH20220530.pdf.

What are the minimum BACnet points to integrate the Viconics VZ8250 VAV Zone Controller?

Start with MV 10 Occupancy Command (BMS occupancy: local, occupied or unoccupied); MV 16 System Mode (Off / auto); AV 39 Occupied Heat Setpoint (Occupied heating setpoint); AV 40 Occupied Cool Setpoint (Occupied cooling setpoint); MV 112 Control Status (Current state: off, cooling or heating); MI 33 Effective Occupancy (Actual occupancy state); AV 100 Room Temperature (Space temperature used for control); AV 110 Airflow Level (Measured airflow, CFM); AI 350 Airflow Setpoint (Airflow setpoint calculated by the controller, CFM); BV 37 Service Alarm (Service alarm from an input set to Service).

How do I enable BMS control of the Viconics VZ8250 VAV Zone Controller?

No enable switch is needed. The BMS writes MV 10 Occupancy Command (1 = Loc. occ, the controller decides locally; 2 = Occupied; 3 = Unoccupied) and MV 16 System Mode (Off or Auto). MV 110 Occupancy Source chooses whether local occupancy follows motion, the schedule or a mix.

Can the BMS supply sensor values to the Viconics VZ8250 VAV Zone Controller?

The guide has no BMS-written room temperature object: MV 145 Room Temperature Sensor selects the wired, internal or one of 20 paired ZigBee wireless sensors, and MI 309 shows which one is in use. Writing an AI present value only works with Out_Of_Service set TRUE.

How do I check these points on the real VZ8250 VAV Zone Controller?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
