Short answer

Viconics TRC room controllers are wall thermostats that run fan coil (TRC3500) or rooftop / heat pump (TRC6500) sequences and expose them as a BACnet application-specific controller on BACnet MS/TP or BACnet IP. One object list covers all models; each object is marked for all models, wireless models only, or one of the two model families. Besides HVAC control the list has lighting and blind commands, demand-response (ADR) points, Zigbee wireless sensor data and Lua script variables.

BMS integration notes: Viconics TRCVT 3.0 Room Controller

Integration in brief

Set the COM address (AV 10) and baud rate (MV 8) for BACnet MS/TP, or the IP settings for BACnet IP. The BMS then writes Occupancy Command (MV 10), System Mode (MV 16), Fan Mode (MV 17) and the occupied setpoints (AV 39, AV 40), and reads Room Temperature (AV 100), Effective Occupancy (MI 33), Control Status (MV 112) and the alarm BVs. Write live commands at priorities 4-16; priorities 1-3 lock the value in EEPROM.

Enable & remote start

There is no separate enable point. Occupancy Command (MV 10) selects local occupancy, occupied or unoccupied; in local mode the controller follows its Occupancy Source (MV 110: motion, schedule or both). System Mode (MV 16) and Fan Mode (MV 17) act directly.

Sensors & values from the BMS

The guide lists no BACnet-written room temperature input. Room Temperature Sensor (MV 150) selects the wired, internal or one of 20 wireless sensors; humidity (MV 154) and CO2 (MV 155) have similar source selectors.

Network setup

  • COM address is AV 10 (0-254, default 254); the same address is used for BACnet or Modbus.
  • BACnet Baud Rate (MV 8) defaults to Auto; fixed rates are 9600 to 115200.
  • Max Master and Max Info Frames are writable on the device object for MS/TP.
  • For BACnet IP, Enable Static IP (MV 183) picks DHCP or static, and foreign device registration to a BBMD is set in the network port object; BBMD Status (MV 207) shows the result.
  • Vendor ID 140. No segmentation; maximum APDU 480 bytes. COV is supported.

Watch out for

  • Writes at priority 1-3 are stored in EEPROM, survive power loss and lock out local changes; release them at the same priority or by factory reset.
  • Writes at priority 4-16 are held in RAM and lost on power cycle, so the BMS must rewrite them after a restart.
  • Setpoints, system mode and fan mode changed at the thermostat are kept at the relinquish default and survive power loss.
  • Many objects exist only on TRC3500, TRC6500 or wireless models; check the description before mapping.
  • Fan Mode (MV 17) has six states on TRC3500 but only On and Auto on TRC6500.

Integration notes

  • Viconics is a Schneider Electric brand; the guide is published on veris.com.
  • Model applicability from the guide's Model(s) column is in each description: all models, wireless models only, TRC3500 (fan coil) only or TRC6500 (rooftop / heat pump) only.
  • Access comes from the guide's per-object-type tables, not a per-point column: AI, BI and MI values are writable only out of service; AO, AV, BO, BV and MV have priority arrays (shown as C); CSV values are writable.
  • Units shown are imperial (Network Units MV 6 defaults to Imperial); the guide also gives metric values.
  • Device, network port, schedule and calendar objects are described in the guide without instance numbers, so they are not in this list.
  • Lua Parameter (AV 25-36, 332-337) and Lua Scratchpad (AV 338-355) values are free variables for a custom Lua script. Light and blind values (AV 284-315) have a 0 to 201 range that the guide does not explain.

Questions about the Viconics TRCVT 3.0 Room Controller

How many BACnet points does the Viconics TRCVT 3.0 Room Controller have?

This list has 593 BACnet objects: 75 analog inputs, 8 analog outputs, 180 analog values, 8 binary inputs, 9 binary outputs, 41 binary values, 1 file, 72 multi-state inputs, 129 multi-state values, 69 characterstring values, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Viconics TRCVT 3.0 Room Controller BACnet points are writable?

438 of the 593 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Viconics TRCVT 3.0 Room Controller BACnet documentation?

The source is Viconics Room Controller TRCn500nnnn-VC BACnet Integration Guide, Firmware Revision 3.0 (998-23139903-5_EN), revision 2026-09, published free by Viconics at https://www.veris.com/ASSETS/DOCUMENTS/CMS/EN/Static_Documents/DownloadCenter/998-23139903-5_TRCVT-3.0-BACnet-Integration-Guide_EN_RH20260908.pdf.

What are the minimum BACnet points to integrate the Viconics TRCVT 3.0 Room Controller?

Start with MV 10 Occupancy Command (BMS occupancy: local, occupied or unoccupied); MV 16 System Mode (Off / auto / cool / heat); MV 17 Fan Mode (Fan mode; states differ on TRC3500 and TRC6500); AV 39 Occupied Heat Setpoint (Occupied heating setpoint); AV 40 Occupied Cool Setpoint (Occupied cooling setpoint); MV 112 Control Status (Current state: off, cooling or heating); MI 326 Fan Speed Status (Fan speed status: off / low / medium / high); MI 33 Effective Occupancy (Actual occupancy state); AV 100 Room Temperature (Space temperature used for control); BV 37 Service Alarm (Service alarm from an input set to Service).

How do I enable BMS control of the Viconics TRCVT 3.0 Room Controller?

There is no separate enable point. Occupancy Command (MV 10) selects local occupancy, occupied or unoccupied; in local mode the controller follows its Occupancy Source (MV 110: motion, schedule or both). System Mode (MV 16) and Fan Mode (MV 17) act directly.

Can the BMS supply sensor values to the Viconics TRCVT 3.0 Room Controller?

The guide lists no BACnet-written room temperature input. Room Temperature Sensor (MV 150) selects the wired, internal or one of 20 wireless sensors; humidity (MV 154) and CO2 (MV 155) have similar source selectors.
