Short answer

Viconics VT7200 and VT73xx thermostats join a BACnet MS/TP trunk through a plug-in communication module and act as BACnet application-specific controllers. One object list covers the VT7200 zoning models, the VT73xx fan coil models and the VTR73xx models, which add their own configuration and valve status objects (instances 81-95). The thermostats do not support COV, so the BMS must poll them.

This page lists 87 BACnet objects for the Viconics VT7200 / VT7300 Series PIR-Ready Thermostats — 58 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Viconics’s own free documentation, linked below.

BMS integration notes: Viconics VT7200 / VT7300 Series PIR-Ready Thermostats

Integration in brief

Give each thermostat a MAC address from 0 to 127 (the factory 254 leaves BACnet off) and let it auto-baud. The BMS writes Occupancy Command (MV 18), System Mode (MV 16), Fan Mode (MV 17) and the setpoints, and reads Room Temperature (AV 7), Effective Occupancy (MV 33), Fan Status (MV 28) and the alarm inputs. Poll no faster than every 5 seconds, since there is no COV.

Enable & remote start

There is no separate enable point. Occupancy Command (MV 18) selects local occupancy, occupied or unoccupied; System Mode (MV 16) and Fan Mode (MV 17) act directly.

Heartbeat & communication loss

No heartbeat point. If the thermostat goes offline, the room temperature, outdoor temperature and occupancy values written over the network are released.

Sensors & values from the BMS

Room Temperature (AV 7) can be written only after Room Temp Override (BV 8) is set to Override; Room Humidity (AV 10) needs Room Humid Override (BV 11) the same way. Outdoor Temperature (AV 9) is writable and is one of the global values the guide shows a BMS sending to all thermostats.

Network setup

  • Factory MAC address is 254, where BACnet communication is off; set it to 0-127 to join the trunk.
  • Baud rate auto-detects (9600, 19200, 38400, 76800) at power-up; after a network speed change the thermostat keeps the old rate for 10 minutes unless re-powered.
  • Default device ID is 72000 + MAC (VT7200) or 73000 + MAC (VT73xx); default device name is the model number plus the MAC. Both are writable.
  • Up to 64 Viconics devices per segment and 128 per network; 120 ohm end-of-line resistors where Viconics devices sit at the ends.
  • The guide suggests a 10000 ms APDU timeout and 3 retries on the supervisory controller to stop devices dropping offline.

Watch out for

  • No COV support: poll no faster than every 5 seconds and write from programs on change or in slow loops, not every scan.
  • System Mode (MV 16) states depend on Sequence of Operation (MV 15), and Fan Mode (MV 17) states on Fan Mode Sequence; rediscover the object after changing them.
  • Output 1 and Output 2 (MV 27, MV 26) change name and states with Control Type (BV 75) and Pipe Number (MV 52).
  • Viconics recommends removing the configuration objects (groups GRP 45, 55, 69, 74) from the BMS after setup to cut polling.

Integration notes

  • Viconics is a Schneider Electric brand; the guide is published on veris.com.
  • Object availability varies by model. The guide marks it in per-model check-mark columns, which are not reproduced here.
  • AV 10 is Room Humidity on humidity models and A02 ECM Value on others; both names are shown.
  • Fan Mode Sequence is MV 58 in the VT7200/VT7300 table and in the notes, but MV 57 in the VTR table and the state table; MV 57 is used here.
  • The range table also lists RH setpoint, hysteresis and max cooling at AV 45-47, which clashes with the object table (AV 71-73); the object table is used.
  • GRP group objects (bundles of related points) are listed as type Other.

Questions about the Viconics VT7200 / VT7300 Series PIR-Ready Thermostats

How many BACnet points does the Viconics VT7200 / VT7300 Series PIR-Ready Thermostats have?

This list has 87 BACnet objects: 1 analog input, 22 analog values, 13 binary inputs, 16 binary values, 26 multi-state values, 9 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Viconics VT7200 / VT7300 Series PIR-Ready Thermostats BACnet points are writable?

58 of the 87 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Viconics VT7200 / VT7300 Series PIR-Ready Thermostats BACnet documentation?

The source is PIR Ready VT72xx & VT(R)73xx Series BACnet Integration Manual (028-6009 R11 (ITG-VT(R) 72_73-BAC-E11)), revision 2012-02-07, published free by Viconics at https://www.veris.com/ASSETS/DOCUMENTS/CMS/EN/Static_Documents/DownloadCenter/028-6009-R11-ITG-VT-R-72-73-PIR-BAC-E11.pdf.

What are the minimum BACnet points to integrate the Viconics VT7200 / VT7300 Series PIR-Ready Thermostats?

Start with MV 18 Occupancy Command (BMS occupancy: local, occupied or unoccupied); MV 16 System Mode (Off / auto / cool / heat); MV 17 Fan Mode (Fan mode; states set by Fan Mode Sequence (MV 57)); AV 39 Occupied Heat Setpoint (Occupied heating setpoint); AV 40 Occupied Cool Setpoint (Occupied cooling setpoint); MV 28 Fan Status (Fan speed status: off / low / medium / high); MV 33 Effective Occupancy (Actual occupancy state); AV 7 Room Temperature (Space temperature used for control); BI 37 Service Alarm (Service alarm from an input set to Service).

How do I enable BMS control of the Viconics VT7200 / VT7300 Series PIR-Ready Thermostats?

There is no separate enable point. Occupancy Command (MV 18) selects local occupancy, occupied or unoccupied; System Mode (MV 16) and Fan Mode (MV 17) act directly.

Does the Viconics VT7200 / VT7300 Series PIR-Ready Thermostats need a BACnet heartbeat or have a communication timeout?

No heartbeat point. If the thermostat goes offline, the room temperature, outdoor temperature and occupancy values written over the network are released.

Can the BMS supply sensor values to the Viconics VT7200 / VT7300 Series PIR-Ready Thermostats?

Room Temperature (AV 7) can be written only after Room Temp Override (BV 8) is set to Override; Room Humidity (AV 10) needs Room Humid Override (BV 11) the same way. Outdoor Temperature (AV 9) is writable and is one of the global values the guide shows a BMS sending to all thermostats.

How do I check these points on the real VT7200 / VT7300 Series PIR-Ready Thermostats?
