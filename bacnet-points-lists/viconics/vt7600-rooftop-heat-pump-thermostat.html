Short answer

Viconics VT76xx thermostats control single- and two-stage rooftop units and heat pumps and join a BACnet MS/TP trunk through a plug-in communication module. One object list covers all models; several instances hold a different object on different models (for example heat pump balance points versus discharge air limits). The thermostats do not support COV, so the BMS must poll them.

This page lists 109 BACnet objects for the Viconics VT7600 Series PIR-Ready Rooftop / Heat Pump Thermostats — 67 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Viconics’s own free documentation, linked below.

BMS integration notes: Viconics VT7600 Series PIR-Ready Rooftop / Heat Pump Thermostats

Integration in brief

Give each thermostat a MAC address from 0 to 127 (the factory 254 leaves BACnet off) and let it auto-baud. The BMS writes Occupancy Command (MV 12), the system mode for the unit type (MV 14 on rooftop units, MV 13 on heat pumps), Fan Mode (MV 15) and the setpoints, and reads Room Temperature (AV 7), Effective Occupancy (MV 34), the G/Y/W output status BIs and the alarms. Poll no faster than every 5 seconds, since there is no COV.

Enable & remote start

There is no separate enable point. Occupancy Command (MV 12) selects local occupancy, occupied or unoccupied; the system mode (MV 14 or MV 13) and Fan Mode (MV 15) act directly.

Heartbeat & communication loss

No heartbeat point. If the thermostat goes offline, the room temperature, outdoor temperature and occupancy values written over the network are released.

Sensors & values from the BMS

Room Temperature (AV 7) can be written only after Room Temp Override (BV 8) is set to Override. Outdoor Temperature (AV 9) has its own override (BV 10) and is one of the global values the guide shows a BMS sending to all thermostats.

Network setup

  • Factory MAC address is 254, where BACnet communication is off; set it to 0-127 to join the trunk.
  • Baud rate auto-detects (9600, 19200, 38400, 76800) at power-up; after a network speed change the thermostat keeps the old rate for 10 minutes unless re-powered.
  • Default device ID is 76000 + MAC; default device name is the model number plus the MAC. Both are writable.
  • Vendor ID 140. Up to 64 Viconics devices per segment and 128 per network.
  • The guide suggests a 10000 ms APDU timeout and 3 retries on the supervisory controller to stop devices dropping offline.

Watch out for

  • No COV support: poll no faster than every 5 seconds and write from programs on change or in slow loops, not every scan.
  • Rooftop and heat pump models use different system mode objects (MV 14 and MV 13); map the one that exists.
  • The device has no Local_Time or Local_Date, so it does not claim time synchronization even though the network can set its clock.
  • Viconics recommends removing the configuration objects (GRP 46, 58, 69, 72, 76, 81, 87, 94) from the BMS after setup to cut polling.

Integration notes

  • Viconics is a Schneider Electric brand; the guide is published on veris.com.
  • Object availability varies by model. The guide marks it in per-model check-mark columns, which are not reproduced here.
  • Some instances hold different objects on different models (AV 17, AV 82, AV 83, AV 95-101); both names are shown, joined with ' / '.
  • Supply Heat Lockout Status is BV 58 in the object table but BI 58 in the state table; BV 58 is used.
  • Room Humidity (AV 11) and the PI demand, economizer and humidifier outputs are read-only per the PICS notes, although the object table shows R,W for AV 11.
  • GRP group objects (bundles of related points) are listed as type Other.

Questions about the Viconics VT7600 Series PIR-Ready Rooftop / Heat Pump Thermostats

How many BACnet points does the Viconics VT7600 Series PIR-Ready Rooftop / Heat Pump Thermostats have?

This list has 109 BACnet objects: 4 analog inputs, 37 analog values, 19 binary inputs, 18 binary values, 1 schedule, 18 multi-state values, 12 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Viconics VT7600 Series PIR-Ready Rooftop / Heat Pump Thermostats BACnet points are writable?

67 of the 109 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Viconics VT7600 Series PIR-Ready Rooftop / Heat Pump Thermostats BACnet documentation?

The source is PIR Ready VT76xx Series BACnet Integration Manual (028-6015 R2 (ITG-VT76xx-PIR-BAC-E02)), revision 2011-01-23, published free by Viconics at https://www.veris.com/ASSETS/DOCUMENTS/CMS/EN/Static_Documents/DownloadCenter/028-6015-R2-ITG-VT76xx-PIR-BAC-E02.pdf.

What are the minimum BACnet points to integrate the Viconics VT7600 Series PIR-Ready Rooftop / Heat Pump Thermostats?

Start with MV 12 Occupancy Command (BMS occupancy: local, occupied or unoccupied); MV 14 System Mode RTU (Off / auto / cool / heat (rooftop models)); MV 13 System Mode HP (Off / auto / cool / heat / emergency (heat pump models)); MV 15 Fan Mode (Fan mode: on / auto / smart); AV 42 Occupied Heat Setpoint (Occupied heating setpoint); AV 43 Occupied Cool Setpoint (Occupied cooling setpoint); BI 25 G Fan (Fan (G) output state); MV 34 Effective Occupancy (Actual occupancy state); AV 7 Room Temperature (Space temperature used for control); BI 40 Fan Lock Alarm (Fan lock alarm (1 = on)).
