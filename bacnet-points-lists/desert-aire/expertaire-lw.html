Desert Aire ExpertAire LW (Wide Temperature Range) - program 2.0.6 BACnet points list

Updated 16 October 2026

Short answer

The ExpertAire LW is a single-compressor dehumidifier for low and wide temperature ranges. Over BACnet the BMS can switch the unit off, command occupancy, write occupied and unoccupied space temperature and RH setpoints, and send its own zone temperature and RH readings. An optional heartbeat (enable, toggle point and delay) supervises the BMS link. Status and alarms are binary values; unit status and zone-sensor source are integer codes.

This page lists 65 BACnet objects for the Desert Aire ExpertAire LW (Wide Temperature Range) - program 2.0.6 — 13 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Desert Aire’s own free documentation, linked below.

BMS integration notes: Desert Aire ExpertAire LW (Wide Temperature Range) - program 2.0.6

Integration in brief

Command occupancy (BV 23) and, if the BMS owns start/stop, Remote Off (BV 22). Write the occupied space temperature and RH setpoints (AV 24, AV 23) and the unoccupied ones if used (AV 26, AV 25). If the heartbeat is enabled (BV 26), toggle BV 27 within the delay set in AV 29. Monitor Unit Status (AV 1001), space conditions and Active Alarm (BV 8, inverted).

Enable & remote start

BV 22 Remote Off turns the unit off when set to 1 and back on at 0. BV 23 Network Occupied Input selects occupied (1) or unoccupied (0); BV 7 confirms the occupied state. BV 25 Blower Continuous switches the blower between automatic and continuous.

Heartbeat & communication loss

Optional. Write BV 26 Network Heartbeat Enable = 1 to turn it on, then toggle BV 27 Network Heartbeat between 1 and 0 within the delay in AV 29 (1-999 s, default 120 s). The list does not say what the unit does when the heartbeat stops.

Sensors & values from the BMS

The BMS can send zone temperature (AV 27) and zone RH (AV 28). AV 1002 Zone Sensor Status shows which sensor is in use (0 = unit sensor, 1 = BMS, 2 = lead unit).

Network setup

  • The source gives no default device instance, MAC address, baud rate or IP settings.

Watch out for

  • BV 8 Active Alarm is inverted (0 = alarm).
  • Values are listed 'in tenths'; confirm the scaling your BMS sees.
  • Objects 1001 and up are listed only as "INT"; confirm their BACnet object type by discovery (shown here as AV).

Integration notes

  • BV 8 Active Alarm is inverted: 0 = alarm, 1 = normal.
  • The list gives many analog values 'in tenths' (two differential pressures in thousandths); check whether your BMS reads 72.5 or 725 and scale if needed.
  • The source lists instances 1001 and up as type "INT" and does not say which BACnet object type that is. They are shown here as AV, but Desert Aire does not confirm that; check the actual object type with a device discovery before mapping.
  • AV 30/31 show the setpoints actually in use; AV 23-26 are the BMS-written network setpoints.
  • The source does not say whether the unit uses BACnet IP or BACnet MS/TP.

Which Desert Aire ExpertAire LW (Wide Temperature Range) - program 2.0.6 BACnet points are writable?
