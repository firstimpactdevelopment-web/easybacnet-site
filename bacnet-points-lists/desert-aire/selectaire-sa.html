Short answer

SelectAire units are indoor pool dehumidifiers. The BACnet list is similar to the SelectAire Plus list but uses different instance numbers and a few different points: sensor analog inputs, four writable setpoints, component status and alarm binary inputs, seven writable binary values (occupancy, event, max outdoor air, purge, unit off, roof lockout, reset) and a multistate unit status. Program 3.0.11 added two discharge pressure sensor fault inputs.

This page lists 104 BACnet objects for the Desert Aire SelectAire (SA) Series - program 3.x.x — 11 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Desert Aire’s own free documentation, linked below.

BMS integration notes: Desert Aire SelectAire (SA) Series - program 3.x.x

Integration in brief

Write occupancy (BV 95) and, if the BMS owns start/stop, Network Off (BV 99). Set the space RH, space air and pool water setpoints through AV 26-29. Monitor Unit Status (MI 102), space conditions and Active Alarm (BI 35, inverted), and use Remote Reset (BV 101) to clear alarms.

Enable & remote start

BV 99 Network Off stops the unit when written 1 and releases it when written 0; BI 48 shows the remote-off state. BV 95 Network Occupied sets occupied (1) or unoccupied (0). Event, maximum outdoor air and purge modes are requested with BV 96, BV 97 and BV 98.

Network setup

  • The source gives no default device instance, MAC address, baud rate or IP settings.

Watch out for

  • BI 35 Active Alarm uses inverted logic (0 = alarm active).
  • BI 48 Remote Off reads 0 when the unit is off and 1 when normal.
  • BV 100 Network Roof Lockout must be written 1 while the roof or wall is open and 0 when closed.
  • BI 102/103 only exist on program 3.0.11 and later.

Integration notes

  • BI 35 Active Alarm is inverted: 0 = alarm active, 1 = normal.
  • BI 102/103 and MI 102 share instance 102 but are different object types.
  • BI 48 Remote Off is 0 when the unit is off and 1 in normal operation.
  • The source does not say whether the unit uses BACnet IP or BACnet MS/TP.
  • The list covers options a given unit may not have (second pool, cooling towers, VOC sensor, circuit B); those points won't carry real data.
  • The SelectAire Plus (SP) list has similar points at different instance numbers; don't reuse one unit's mapping on the other.

Questions about the Desert Aire SelectAire (SA) Series - program 3.x.x

How many BACnet points does the Desert Aire SelectAire (SA) Series - program 3.x.x have?

This list has 104 BACnet objects: 25 analog inputs, 4 analog values, 67 binary inputs, 7 binary values, 1 multi-state input. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Desert Aire SelectAire (SA) Series - program 3.x.x BACnet points are writable?

11 of the 104 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Desert Aire SelectAire (SA) Series - program 3.x.x BACnet documentation?

The source is BACnet Points List - Unit Type SA For Program Version 3.x.x and Above (EC-10880 (Rev. 01)), revision 2022-11-28, published free by Desert Aire at https://www.desert-aire.com/wp-content/uploads/2025/04/https___www.desert-aire.com_sites_default_files_SA20BACnet20Points203_x_x.pdf.

What are the minimum BACnet points to integrate the Desert Aire SelectAire (SA) Series - program 3.x.x?

Start with BV 99 Network Off (Unit off command (1 = off, 0 = on)); BV 95 Network Occupied (Occupancy command (1 = occupied)); AV 26 Zone Relative Humidity Setpoint (Space RH setpoint, 0-99 %); AV 27 Zone Air Temperature Setpoint (Space air setpoint, 65-99 °F); AV 28 Pool 1 Water Temperature Setpoint (Pool 1 water setpoint, 70-104 °F); BV 101 Remote Reset (Write 1 to reset the unit); MI 102 Unit Status (Operating state code (0-9)); AI 3 Zone Air Relative Humidity (Measured space RH, %); AI 4 Zone Air Temperature (Measured space air temperature); BI 35 Active Alarm (Unit alarm; 0 = alarm, 1 = normal).

How do I enable BMS control of the Desert Aire SelectAire (SA) Series - program 3.x.x?

BV 99 Network Off stops the unit when written 1 and releases it when written 0; BI 48 shows the remote-off state. BV 95 Network Occupied sets occupied (1) or unoccupied (0). Event, maximum outdoor air and purge modes are requested with BV 96, BV 97 and BV 98.
