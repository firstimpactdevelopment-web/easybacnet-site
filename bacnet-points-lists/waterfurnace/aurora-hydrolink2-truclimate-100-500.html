BMS integration notes: WaterFurnace Aurora HydroLink2 for TruClimate 100 / TruClimate 500 Modular Chillers

Integration in brief

For units without a header rack, choose aquastat, setpoint, network or setpoint-with-enable control on MSV 2. In setpoint mode the controller holds AV 22/23 against the input picked on MSV 3; in network mode the BAS calls compressor A on BV 35 and B on BV 34, and variable speed systems can take capacity targets on AV 306/307 when BV 301/302 are enabled. Keep BV 37 Enabled and set BV 36 to Network while the BAS has control.

Enable & remote start

BV 37 SystemEnable_c (default Enabled) must be Enabled for the compressors to run. The BAS sets BV 36 NetworkControl_c to Network when it takes control. With MSV 2 = 3 (Network), BV 35 and BV 34 call compressors A and B and BV 1 picks cool or heat. BV 2 EmShutdown_c forces an emergency shutdown.

Sensors & values from the BMS

AV 62 NetworkTemperature_c is the BAS-supplied control temperature for setpoint control on a network temperature (MSV 3 option 4). Header rack builds take BAS cold and hot water temperatures on AV 506/507 (MSV 502/503 option 4) and network loop temperatures on AV 508 and AV 510-515.

Watch out for

  • BV 5 EnableManualOverride_c lets BV 6-8 override compressor and reversing valve outputs; normal logic keeps running underneath.
  • BV 0 lead/lag enable is kept for compatibility; the sheet says BV 42 replaces it to avoid instance 0 problems.
  • Header rack mode comes from AV 568 or MSV 501, chosen by BV 511.
  • With BV 502 Active, all header rack valves follow their manual values.
  • Check the configuration columns in the source: many points only exist on some builds.

Integration notes

  • The workbook file is version 3.04, but its title row still reads version 3.01.
  • Writable points are marked with the BACnet priorities they accept (in1, in4, in5, in8, in16); they are shown here as commandable (C). Points marked 'no' are read-only.
  • Columns tick each point for 12 configurations: NXW dual scroll, modular dual scroll and modular variable speed (no header rack, 4-pipe standard or reversing, 6-pipe standard or dedicated source) and dual screw. Header rack and variable speed points only exist on those builds.
  • Successor of the HydroLink v1.03 list (PL2500EW): all 213 of its objects appear here with the same instance and name, and 89 were added for modular, variable speed and header rack builds.
  • MSV 3 option 4 names AV 12 as the network temperature, while AV 62 is described as the network temperature input.
  • The sheet does not state the BACnet transport or network settings.

Questions about the WaterFurnace Aurora HydroLink2 for TruClimate 100 / TruClimate 500 Modular Chillers

How many BACnet points does the WaterFurnace Aurora HydroLink2 for TruClimate 100 / TruClimate 500 Modular Chillers have?

This list has 302 BACnet objects: 210 analog values, 74 binary values, 18 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which WaterFurnace Aurora HydroLink2 for TruClimate 100 / TruClimate 500 Modular Chillers BACnet points are writable?

170 of the 302 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official WaterFurnace Aurora HydroLink2 for TruClimate 100 / TruClimate 500 Modular Chillers BACnet documentation?

The source is HydroLink2 BACnet Objects, revision Version 3.04, published free by WaterFurnace at https://www.waterfurnace.com/literature/aurora/HydroLink2-BACnet-Objects-Version-3.04.xlsx.

What are the minimum BACnet points to integrate the WaterFurnace Aurora HydroLink2 for TruClimate 100 / TruClimate 500 Modular Chillers?

Start with BV 37 SystemEnable_c (System enable; compressors stay off when Disabled); BV 36 NetworkControl_c (Set to Network while the BAS has control); BV 2 EmShutdown_c (Network emergency shutdown); BV 1 Mode_c (Cool or heat (non-header-rack units)); AV 22 CoolingSetpoint_c (Cooling setpoint, setpoint control mode); AV 23 HeatingSetpoint_c (Heating setpoint, setpoint control mode); BV 33 AlarmReset_c (Alarm reset; return to Normal after the lockout clears); MV 1 UnitMode_st (Current operating mode); AV 1 ControlTemp_st (Control temperature (input chosen on MSV 3)); MV 0 SystemStatus_st (Overall status: normal, alarm, shutdown, load shed).

How do I enable BMS control of the WaterFurnace Aurora HydroLink2 for TruClimate 100 / TruClimate 500 Modular Chillers?

BV 37 SystemEnable_c (default Enabled) must be Enabled for the compressors to run. The BAS sets BV 36 NetworkControl_c to Network when it takes control. With MSV 2 = 3 (Network), BV 35 and BV 34 call compressors A and B and BV 1 picks cool or heat. BV 2 EmShutdown_c forces an emergency shutdown.

Can the BMS supply sensor values to the WaterFurnace Aurora HydroLink2 for TruClimate 100 / TruClimate 500 Modular Chillers?

AV 62 NetworkTemperature_c is the BAS-supplied control temperature for setpoint control on a network temperature (MSV 3 option 4). Header rack builds take BAS cold and hot water temperatures on AV 506/507 (MSV 502/503 option 4) and network loop temperatures on AV 508 and AV 510-515.

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
