BMS integration notes: WaterFurnace Aurora UPC, Single Compressor Water-Source Heat Pump

Integration in brief

Set BV 54 to External, then command occupancy on MSV 1 and let the UPC hold its occupied, unoccupied and standby setpoints (AV 5-10). Read MSV 11 for the operating mode and MSV 8 for the lockout code. The BAS can also act as the thermostat with BV 44-48 (G, O, W, Y1, Y2).

Enable & remote start

The UPC runs its own internal weekday schedule until BV 54 schedule_selector_c is set to External (Active). Occupancy commands then go to MSV 1, or to AV 42 after BV 50 is set to AV. BV 25 e_stop_c shuts the unit down; BV 44-48 send G, O, W, Y1 and Y2 calls directly.

Sensors & values from the BMS

AV 4 zone_temp_ovrd_c replaces the zone sensor once BV 55 zone_temp_selector_c is set to BAS. AV 17 humidity_c, AV 22 co2_c and AV 24 voc_c take BAS values when no sensor is connected, and AV 26 oat_c takes an outdoor air temperature.

Network setup

  • Port 1a is the BAS port: EIA-485 for BACnet MS/TP (or N2), set by DIP switches, with baud 9600, 19.2k, 38.4k or 76.8k. It ships set to BACnet at 38,400 baud.
  • Port 1a can instead be jumpered for ARC156 (BACnet over ARCNET at 156 kbps). A LonWorks plug-in card uses port 1b and disables port 1a.
  • The MAC address is set on two rotary switches (tens and ones), 1 from the factory and 99 at most. The UPC only reads a new address after a power cycle.
  • The device instance is built from the network number and the MAC: network 7000 with MAC 12 gives 7012.
  • Wiring: 22 or 24 AWG shielded twisted pair, daisy-chained, polarity-sensitive (Net+, Net-, shield). About 30 devices and 2,000 ft per trunk; every MAC on a trunk must be unique.

Watch out for

  • Dip switch overrides (BV 11-18) only reach the ABC while BV 22 is enabled. Record the physical switch settings first, and a slow-flashing yellow LED on the ABC means a switch is overridden.
  • Alarm reset: command BV 5 On, then back to Off. Loss-of-communication and over/under-voltage alarms reset themselves and cannot be reset from the network.
  • Zone sensor warm/cool adjust (AV 15, default 5 F) only shifts the setpoints in occupied or temporary occupied mode.
  • Points shown with * in the source need the AXB board and its sensors.

  • The same PDF also carries N2 and LonWorks lists; only the BACnet list is captured here.
  • Multistate value numbers jump from MSV 1 to MSV 7 in the source; MSV 2-6 are not listed.
  • Alarm code meanings come from the alarm table in the Aurora UPC Application and Troubleshooting Guide (AG1568EW).
  • Transport and network settings come from AG1568EW; the points list itself does not state them.

Questions about the WaterFurnace Aurora UPC, Single Compressor Water-Source Heat Pump

How many BACnet points does the WaterFurnace Aurora UPC, Single Compressor Water-Source Heat Pump have?

This list has 201 BACnet objects: 119 analog values, 76 binary values, 6 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which WaterFurnace Aurora UPC, Single Compressor Water-Source Heat Pump BACnet points are writable?

55 of the 201 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official WaterFurnace Aurora UPC, Single Compressor Water-Source Heat Pump BACnet documentation?

The source is Aurora UPC Points List (BACnet Points for Single Compressor WSHP) (AG1569EW), revision 2014-07, published free by WaterFurnace at https://www.waterfurnace.com/literature/aurora/ag1569aw.pdf.
