BMS integration notes: WaterFurnace Aurora UPC, Variable Speed Water-Source Heat Pump

Integration in brief

Keep BV 54 at External and command occupancy on MSV 1; AV 145 sets the unit mode (off, auto, heat, cool, emergency heat). The UPC holds the occupied, unoccupied and standby setpoints (AV 5-10). Read MSV 11 for the operating mode and MSV 8 for the lockout code; AV 147 shows the compressor speed step.

Enable & remote start

BV 54 schedule_select_cmd picks the internal schedule or external BAS commands (External is the listed default). Occupancy commands go to MSV 1, or to AV 42 after BV 50 is set to AV. AV 145 op_mode sets off/auto/heat/cool/emergency heat. BV 25 e_stop_cmd shuts the unit down.

Sensors & values from the BMS

AV 4 zone_temp_ovrd replaces the zone sensor once BV 55 zone_temp_selector is set to BAS. AV 17 humidity_cmd, AV 22 co2_cmd and AV 24 voc_cmd accept BAS values when no sensor is connected, and AV 26 oat_cmd takes an outdoor air temperature.

Network setup

  • Port 1a is the BAS port: EIA-485 for BACnet MS/TP (or N2), set by DIP switches, with baud 9600, 19.2k, 38.4k or 76.8k. It ships set to BACnet at 38,400 baud. (From AG1568EW, written for the single-compressor UPC.)
  • Port 1a can instead be jumpered for ARC156 (BACnet over ARCNET at 156 kbps). A LonWorks plug-in card uses port 1b and disables port 1a.
  • The MAC address is set on two rotary switches (tens and ones), 1 from the factory and 99 at most. The UPC only reads a new address after a power cycle.
  • The device instance is built from the network number and the MAC: network 7000 with MAC 12 gives 7012.
  • Wiring: 22 or 24 AWG shielded twisted pair, daisy-chained, polarity-sensitive (Net+, Net-, shield). About 30 devices and 2,000 ft per trunk; every MAC on a trunk must be unique.

Watch out for

  • Unlike the single and dual compressor UPC lists, this one has no network G/Y1/Y2 command points; control is by occupancy, mode and setpoints.
  • Dip switch overrides (BV 11-18) only pass to the ABC while BV 22 is enabled; record the physical switch settings first.
  • BV 86 archive_now stores configuration changes; the sheet says archives should be limited.
  • Alarm reset: command BV 5 On, then back to Off.

Questions about the WaterFurnace Aurora UPC, Variable Speed Water-Source Heat Pump

How many BACnet points does the WaterFurnace Aurora UPC, Variable Speed Water-Source Heat Pump have?

This list has 268 BACnet objects: 170 analog values, 90 binary values, 8 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which WaterFurnace Aurora UPC, Variable Speed Water-Source Heat Pump BACnet points are writable?

124 of the 268 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official WaterFurnace Aurora UPC, Variable Speed Water-Source Heat Pump BACnet documentation?

The source is Aurora UPC BACnet Points List For Variable Speed WSHP (PL1700EW), revision 2017-12, published free by WaterFurnace at https://www.waterfurnace.com/literature/aurora/pl1700ew.pdf.

What are the minimum BACnet points to integrate the WaterFurnace Aurora UPC, Variable Speed Water-Source Heat Pump?

Start with MV 1 occ_man_cmd_msv (Occupied/unoccupied/temp occ/standby command); BV 54 schedule_select_cmd (Must be External for BAS occupancy commands); BV 25 e_stop_cmd (Network emergency shutdown); AV 145 op_mode (Mode command: 0 off, 1 auto, 2 heat, 3 cool, 4 em heat); AV 5 occ_clg_setpt (Occupied cooling setpoint); AV 6 occ_htg_setpt (Occupied heating setpoint); BV 5 alarm_reset_cmd (Reset manual-reset alarms (On, then back to Off)); AV 1 zone_temp_st (Space temperature (sensor or BAS override)); MV 11 mode_st_msv (Current operating mode); MV 8 lockout_enum_msv (Active alarm code (see alarm table)).

How do I enable BMS control of the WaterFurnace Aurora UPC, Variable Speed Water-Source Heat Pump?

BV 54 schedule_select_cmd picks the internal schedule or external BAS commands (External is the listed default). Occupancy commands go to MSV 1, or to AV 42 after BV 50 is set to AV. AV 145 op_mode sets off/auto/heat/cool/emergency heat. BV 25 e_stop_cmd shuts the unit down.

Can the BMS supply sensor values to the WaterFurnace Aurora UPC, Variable Speed Water-Source Heat Pump?

AV 4 zone_temp_ovrd replaces the zone sensor once BV 55 zone_temp_selector is set to BAS. AV 17 humidity_cmd, AV 22 co2_cmd and AV 24 voc_cmd accept BAS values when no sensor is connected, and AV 26 oat_cmd takes an outdoor air temperature.
