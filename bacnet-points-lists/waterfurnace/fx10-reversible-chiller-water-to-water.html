BMS integration notes: WaterFurnace Reversible Chiller Water-to-Water Heat Pump (FX10)

Integration in brief

The BAS stages this machine directly: MO1/MO2 are the Y1/Y2 compressor calls and MO3 is the reversing valve (O) call. Read load and source water temperatures, flow switches and the alarm code to supervise it. The two configuration values (freeze setpoint adjust, compressor on-delay) are flash-backed and should be set once.

Enable & remote start

The sheet has no separate enable or occupancy point. The BAS controls the unit with the MO1/MO2 compressor calls and the MO3 reversing-valve call.

Watch out for

  • AV/MV points are stored in flash (about 2,000,000 writes); write them only manually or by schedule, never from automatic reset logic.
  • Output points (AO/MO) are volatile and go back to uncommanded after a power cycle, so rewrite them after power is restored.
  • If the BAS shows 254 as uncommanded instead of 255, every multistate value is one lower (0=Off, 1=On).
  • With lead/lag enabled (factory default), a Y1 or Y2 call starts whichever compressor has been off longest.
  • AV1 Frz Setpt Adj only takes effect after the control board jumpers are removed.

Integration notes

  • Output-type points are volatile and fall back to uncommanded after a power cycle; unlimited writes.
  • Value-type points (AV/MV) are stored in flash (about 2,000,000 write life); never write them from automatic reset logic.
  • Multistate numbers assume the BAS shows 255 as uncommanded; if yours shows 254, every state number is one lower (0=Off, 1=On).
  • No engineering units are printed in the source; temperatures are presumably degrees F.
  • With lead/lag enabled (factory default) a Y1 or Y2 call starts whichever compressor has been off longest; with it disabled Y1 starts compressor 1 and Y2 compressor 2.
  • AI9-AI11 report on/off states as analog inputs using 1=Off, 2=On.

How many BACnet points does the WaterFurnace Reversible Chiller Water-to-Water Heat Pump (FX10) have?

This list has 33 BACnet objects: 14 analog inputs, 2 analog values, 9 multi-state inputs, 8 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which WaterFurnace Reversible Chiller Water-to-Water Heat Pump (FX10) BACnet points are writable?

10 of the 33 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
