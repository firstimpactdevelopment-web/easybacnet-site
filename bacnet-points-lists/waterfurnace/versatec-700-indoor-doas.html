BMS integration notes: WaterFurnace Versatec 700 Indoor DOAS (Aurora UPC)

Integration in brief

Enable the system with BV 302, pick the external schedule on BV 401 and drive occupancy with BV 400 (or MV 315 for standby and temporary occupancy). Set the cooling and heating SAT targets and reset options, and read mode, supply air temperature and the per-unit fault codes.

Enable & remote start

BV 302 sys_enable_c enables the system for network and setpoint control. BV 2 e_stop_c is the emergency shutdown, BV 102 a shutdown that keeps the exhaust fan running, and BV 4 load shed. Occupancy follows the internal schedule unless BV 401 is set to External; then BV 400 or MV 315 set the occupancy mode.

Sensors & values from the BMS

Each sensed value has a source selector and a BAS override: MV 303-307 and MV 311 pick Rnet sensor, unit/ERW sensor or BAS for supply, return, space and outdoor values, written on AV 502/505/512/515/522/525/532/535. MV 309/310/312/314 pick BAS or AEC for the energy recovery inputs (AV 9024-9065). AV 551 takes a BAS DOAS control temperature, AV 343 a BAS duct static value, and AV 591/593 BAS CO2 and VOC.

Network setup

  • MV 301 sets the blower configuration (multizone VAV, single zone VAV, CAV) and MV 302 the SAT control type; set them at commissioning.

Watch out for

  • Leave the factory/internal-use rows alone.
  • Points for heat pump units that are not installed stay meaningless.
  • Return BV 8 alarm reset to Off after use.

How many BACnet points does the WaterFurnace Versatec 700 Indoor DOAS (Aurora UPC) have?

Which WaterFurnace Versatec 700 Indoor DOAS (Aurora UPC) BACnet points are writable?

252 of the 748 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official WaterFurnace Versatec 700 Indoor DOAS (Aurora UPC) BACnet documentation?

What are the minimum BACnet points to integrate the WaterFurnace Versatec 700 Indoor DOAS (Aurora UPC)?

Start with BV 302 sys_enable_c (System enable for network and setpoint control); BV 2 e_stop_c (Emergency shutdown command); BV 400 occ_command_c (Occupancy command (external schedule)); BV 401 sched_select_c (Must be External for BV 400 to apply); AV 305 targ_clg_sat_c (Cooling supply air temperature target); AV 306 targ_htg_sat_c (Heating supply air temperature target); BV 8 alarm_reset_c (Alarm reset); MV 11 mode_st_msv (Unit operating mode); AV 500 sat_st (Supply air temperature in use); AV 7 system_fault1_st (Unit 1 fault or lockout code).

How do I enable BMS control of the WaterFurnace Versatec 700 Indoor DOAS (Aurora UPC)?

BV 302 sys_enable_c enables the system for network and setpoint control. BV 2 e_stop_c is the emergency shutdown, BV 102 a shutdown that keeps the exhaust fan running, and BV 4 load shed. Occupancy follows the internal schedule unless BV 401 is set to External; then BV 400 or MV 315 set the occupancy mode.

Can the BMS supply sensor values to the WaterFurnace Versatec 700 Indoor DOAS (Aurora UPC)?

Each sensed value has a source selector and a BAS override: MV 303-307 and MV 311 pick Rnet sensor, unit/ERW sensor or BAS for supply, return, space and outdoor values, written on AV 502/505/512/515/522/525/532/535.
