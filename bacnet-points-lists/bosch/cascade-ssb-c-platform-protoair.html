BMS integration notes: Bosch Buderus Cascade SSB 255 / 399 / 512 (ProtoAir FPA-W44, C_Platform)

Integration in brief

Map the CH mode and setpoint AVs for control and read State, Status, supply and return temperatures, firing rate, the error code and the dependent boilers' state. The guide does not explain the Control Register or the mode codes, so check the boiler's Modbus documentation before writing.

Enable & remote start

AV 144-155 are the writable mode, setpoint, reset-curve and night setback values (their read-back copies are AI 132-143). AV 2 Control Register is writable too; the guide does not say how it is used.

Network setup

  • ProtoAir FPA-W44 to the boiler: Modbus RTU, 9600 baud; the C_Platform profile is auto-discovered.
  • BACnet device instance = Node_Offset (default 50,000) + Node-ID; set BACnet Virtual Server Nodes when several devices share the gateway.
  • Field protocol (BACnet IP, BACnet MS/TP, Modbus TCP or N2) is chosen in the ProtoAir web app.

Watch out for

  • Access is inferred from the N2 type (AO = writable); the table has no read/write column.
  • No units, ranges or code tables are given; temperature units follow AV 1 Unit Selection.
  • Object AI 17 is not used; one writable object is printed as AV 140 where AV 150 is expected.

Questions about the Bosch Buderus Cascade SSB 255 / 399 / 512 (ProtoAir FPA-W44, C_Platform)

How many BACnet points does the Bosch Buderus Cascade SSB 255 / 399 / 512 (ProtoAir FPA-W44, C_Platform) have?

This list has 154 BACnet objects: 140 analog inputs, 14 analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Bosch Buderus Cascade SSB 255 / 399 / 512 (ProtoAir FPA-W44, C_Platform) BACnet points are writable?

14 of the 154 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Bosch Buderus Cascade SSB 255 / 399 / 512 (ProtoAir FPA-W44, C_Platform) BACnet documentation?

The source is ProtoAir FPA-W44 Start-up Guide for Bosch, Appendix C.1 C_Platform Modbus RTU Mappings to BACnet (Document Revision 5.D), revision 2020-03, published free by Bosch at https://www.bosch-homecomfort.com/us/media/country_pool/service/technical_guides/protoair_fpa-w44_start-up_guide_03.2020.pdf.

What are the minimum BACnet points to integrate the Bosch Buderus Cascade SSB 255 / 399 / 512 (ProtoAir FPA-W44, C_Platform)?

Start with AV 144 CH Mode (Central heating mode command); AV 146 CH Setpoint (Central heating setpoint); AV 2 Control Register (Control register; see the boiler Modbus manual); AI 3 State (Boiler state code); AI 4 Status (Boiler status code); AI 9 Supply Temperature (Supply water temperature); AI 15 Firing Rate (Firing rate); AI 87 Dependent 01 State (Dependent 01 state (repeat for 02-15)); AI 5 Error Code (Active error code).

How do I enable BMS control of the Bosch Buderus Cascade SSB 255 / 399 / 512 (ProtoAir FPA-W44, C_Platform)?

AV 144-155 are the writable mode, setpoint, reset-curve and night setback values (their read-back copies are AI 132-143). AV 2 Control Register is writable too; the guide does not say how it is used.
