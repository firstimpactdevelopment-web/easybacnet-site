Short answer

Each humiFog Multizone zone controller can be supervised on its own over BACnet MS/TP or BACnet IP. Its list starts at address 300 and holds the zone's production request and actual production, probe readings, humidity and temperature set points and limits, supervisor request, alarm and warning flags, supervisor on/off and enable commands, zone status, control mode and versions.

BMS integration notes: CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller

Integration in brief

Enable supervisor on/off and control for the zone, then switch it with SVOnOff and either write the humidity (or temperature) set point or a production request (SVReq). Monitor zone status, production, probe readings and the alarm and warning flags.

Enable & remote start

SVEnOnOff enables zone on/off from the supervisor and SVEnReg enables zone control from the supervisor; then SVOnOff switches the zone.

Heartbeat & communication loss

Zone warning and alarm objects report a supervisor offline condition (WRO05 / WRO09).

Sensors & values from the BMS

SVReq (AV 331) is the zone production request from the supervisor, used when the zone control mode takes an external request.

Network setup

  • Supervisor settings are under Menu > Settings > System > BMS: BMS port address, baud, stop bits, parity, Ethernet IP settings, and BACnet MS/TP station address, max masters, max frames and device instance.
  • MS/TP defaults: station address 0, max masters 127, max frames 10, device instance 77000 (range 0-4194302); BMS port default 19200 baud.
  • Only one BACnet instance is available: BACnet cannot run on the BMS (RS485) port and the Ethernet port at the same time.
  • Each supervisor channel (Menu > Settings > System > Functions > Channel 1-3) is set to Supervisor or Supervisor + Controller with a protocol + port (ModBus BMS/ETH, BACnet BMS/ETH).

Watch out for

  • Do not write variables that are not in the tables.
  • Values are scaled by the resolution shown (0.1 for most analog values).

Questions about the CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller

How many BACnet points does the CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller have?

This list has 117 BACnet objects: 34 analog values, 63 binary values, 20 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller BACnet points are writable?

48 of the 117 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller BACnet documentation?

What are the minimum BACnet points to integrate the CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller?

How do I enable BMS control of the CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller?

SVEnOnOff enables zone on/off from the supervisor and SVEnReg enables zone control from the supervisor; then SVOnOff switches the zone.

Does the CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller need a BACnet heartbeat or have a communication timeout?

Zone warning and alarm objects report a supervisor offline condition (WRO05 / WRO09).

Can the BMS supply sensor values to the CAREL humiFog Multizone / Multizone Touch / Touch Oil-free - zone controller?

SVReq (AV 331) is the zone production request from the supervisor, used when the zone control mode takes an external request.
