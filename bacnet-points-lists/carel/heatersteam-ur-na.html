Short answer

heaterSteam UR is CAREL's resistance-heated steam humidifier. This entry covers the earlier heaterSteam UR generation documented in the 2018 manual (rel. 1.4), before heaterSteam 4. Its c.pHC controller speaks BACnet MS/TP on the RS485 BMS port or BACnet IP on the Ethernet port (one at a time) with no extra card. This edition of the object list has 74 positive integer values, 45 analog values and 69 binary values covering status, probes, set points, scheduler settings, network units and alarms.

BMS integration notes: CAREL heaterSteam UR (2018 manual, before heaterSteam 4)

Integration in brief

Select BACnet on the BMS port (Eh01, plus MS/TP settings on Eh03) or on the Ethernet port (Eh06), set the device instance on Eh04, and enable 'On/Off from SV' and 'Control from SV'. The BMS then starts the unit with OnBySV (BV 6) and sends a production request on SV_PwrReq (AV 11), or writes the humidity set point (AV 14). Monitor OnOffStatus, UnitStatus, production and the summary alarm BVs.

Enable & remote start

On screen Eh01 set 'On/Off from SV' and 'Control from SV' to Yes (both default to No); otherwise the unit ignores the supervisor on/off and production request.

Sensors & values from the BMS

With control from supervisor the BMS sends the production request on SV_PwrReq (AV 11) instead of the unit using its own probe.

Network setup

  • Device instance default 77000 (screen Eh04).
  • BACnet MS/TP on the BMS port: Eh03 sets the MAC address, max masters and max info frames; Eh02 sets the serial settings.
  • BACnet on the Ethernet port is selected on Eh06; the Ethernet IP settings are on the Ethernet network screen.
  • Only one BACnet instance exists, so BACnet cannot run on the BMS port and Ethernet at the same time.

Watch out for

  • SV_Command (PIV 92) is a one-shot reset (1 = alarms, 2 = hour counter); read the result on PIV 93.
  • Scheduler and probe configuration values are settings; avoid cyclic writes.

Questions about the CAREL heaterSteam UR (2018 manual, before heaterSteam 4)

How many BACnet points does the CAREL heaterSteam UR (2018 manual, before heaterSteam 4) have?

This list has 188 BACnet objects: 45 analog values, 69 binary values, 74 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which CAREL heaterSteam UR (2018 manual, before heaterSteam 4) BACnet points are writable?

76 of the 188 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official CAREL heaterSteam UR (2018 manual, before heaterSteam 4) BACnet documentation?

The source is heaterSteam - UR Electric resistance humidifier - User manual (+0300080EN rel. 1.4), revision 2018-02-05, published free by CAREL at https://www.carel.com/documents/10191/0/%2B0300080EN/8e3b3908-4f1c-41c0-8712-bddd86881a07?version=1.12.

What are the minimum BACnet points to integrate the CAREL heaterSteam UR (2018 manual, before heaterSteam 4)?

Start with BV 6 OnBySV (Unit on/off from the BMS); AV 11 SV_PwrReq (Production request from the BMS, %); AV 14 GlbSetP_Hum (Humidity set point (own probe control)); BV 5 OnOffStatus (Unit on/off status); PIV 12 UnitStatus (Operating state code); AV 0 MainPrb (Main probe reading); AV 12 CurrProdPh (Current steam production, kg/h or lb/h); BV 14 CurrBlkAlrm.IsPresent (Resettable alarm active); BV 13 CurrBlkAlrm.IsBlocker (Shutdown alarm active).

How do I enable BMS control of the CAREL heaterSteam UR (2018 manual, before heaterSteam 4)?

On screen Eh01 set 'On/Off from SV' and 'Control from SV' to Yes (both default to No); otherwise the unit ignores the supervisor on/off and production request.

Can the BMS supply sensor values to the CAREL heaterSteam UR (2018 manual, before heaterSteam 4)?

With control from supervisor the BMS sends the production request on SV_PwrReq (AV 11) instead of the unit using its own probe.

How do I check these points on the real heaterSteam UR (2018 manual, before heaterSteam 4)?
