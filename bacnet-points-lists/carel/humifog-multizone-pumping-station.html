Short answer

The humiFog Multizone pumping station pressurises water for up to 12 atomising zones. Its c.pCO controller speaks BACnet MS/TP on the BMS port or BACnet IP on Ethernet. The list holds pump production, pressures and water temperature, alarm and warning flags, zone online status, operating hours and versions, plus the zone 1 objects (request, production, probes, set points, status, control mode). All zones can be supervised through the pumping station.

BMS integration notes: CAREL humiFog Multizone / Multizone Touch / Touch Oil-free high-pressure humidifier - pumping station

Integration in brief

Enable a supervisor channel with BACnet on the BMS port or Ethernet and set the device instance. Monitor unit status, pump production and pressures and the alarm flags. Zone production is driven per zone: write the zone set points or a zone request from the supervisor (zone 1 objects at 300+, other zones offset by 200).

Enable & remote start

Zone on/off and control from the supervisor must be enabled per zone (SVEnOnOff / SVEnReg in the zone tables), and the supervisor channel's control mode must be set for that zone.

Heartbeat & communication loss

Each supervisor channel has an 'Enable supervisor offline alarm' with a delay (1-999 s, default 180 s) when the channel type is Supervisor + Controller; objects report channel 1-3 offline warnings and alarms.

Sensors & values from the BMS

A zone can take a production request from the supervisor (ZoneData SVReq) instead of its own probes, depending on the zone control mode.

Network setup

  • Supervisor settings are under Menu > Settings > System > BMS: BMS port address, baud, stop bits, parity, Ethernet IP settings, and BACnet MS/TP station address, max masters, max frames and device instance.
  • MS/TP defaults: station address 0, max masters 127, max frames 10, device instance 77000 (range 0-4194302); BMS port default 19200 baud.
  • Only one BACnet instance is available: BACnet cannot run on the BMS (RS485) port and the Ethernet port at the same time.
  • Each supervisor channel (Menu > Settings > System > Functions > Channel 1-3) is set to Supervisor or Supervisor + Controller with a protocol + port (ModBus BMS/ETH, BACnet BMS/ETH).

Watch out for

  • Do not write variables that are not in the tables; the manual warns it can upset operation.
  • Values are scaled by the resolution shown (0.1 for most analog values).
  • If the pumping station is paused by the monitoring service, the whole system stops producing.

Integration notes

  • Zone objects are printed for zone 1 only (addresses from 300). For zone N add 200 x (N-1) to the zone 1 address, e.g. zone 5 = 300 + 800 = 1100; variable names use ZonesData_C[N]. A few per-zone objects (full standby enable, panel alarms, online status) are printed for all 12 zones.
  • Object type follows the data type column (Real = AV, Bool = BV, integers = PIV). The 9.4.2 Bool table is headed 'AnalogValue' in the manual; it is shown here as BV. Values are scaled 0.1 where the UoM column says 0.1.
  • The Multizone (+0300115EN) and Touch Oil-free (+0300127EN) manuals carry the same tables with small differences: the oil-free list lacks BV 176/177 (oil-change warnings) and adds BV 211/212 and PIV 191/192; both add PIV 202. These extra objects are included and marked in their description.
  • Rows printed with access 'OR' are read-only. Units switch between metric and imperial with the unit of measure setting.
  • Source: +0300116EN rel. 1.3 section 9.4.1-9.4.3, pages 84-91 (Touch pumping station tables).
