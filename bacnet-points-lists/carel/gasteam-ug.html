BMS integration notes: CAREL gaSteam (UG) gas-fired humidifier

Integration in brief

Enable BACnet on the Ethernet port (Eh06, on by default) or on the BMS port (Eh01 protocol BACnet plus Eh03), and set the device instance on Eh04. Then enable On/Off and control from supervisor on Eh07/Eh08. Start and stop the unit with OnBySV (BV 0) and send the production request on SV_PwrReq (AV 73), or let the unit run its own humidity control with the set point on AV 1. Monitor OnOffStatus, UnitStatus, current production and the alarm summary BVs.

Enable & remote start

On screens Eh07/Eh08 (Installer menu) select the supervisor port and enable 'On/Off signal from supervisor' and 'control from supervisor'; on the BMS port the Eh01 settings 'On/Off from SV' and 'Control from SV' do the same. Without them the unit ignores the supervisor on/off and production request.

Heartbeat & communication loss

Eh08 can enable a supervisor-offline alarm (ALP21, BV 135) with an activation delay. The manual does not say what the unit does with its output when the supervisor goes offline.

Sensors & values from the BMS

With control from supervisor the BMS sends the production request on SV_PwrReq (AV 73) instead of the unit using a probe. Up to four CAREL wireless probes can also feed the unit (WirelessPrbVal AI objects).

Network setup

  • Device instance default 77000 (screen Eh04).
  • BACnet MS/TP on the BMS port: Eh03 sets the MAC address (default 0), max masters (127) and max info frames (10); Eh02 sets the baud rate (default 19200).
  • For BACnet MS/TP the manual says to set Eh06 as well as Eh03 (BACnet on the Ethernet port is enabled by default).
  • BACnet IP on the Ethernet port is enabled by default on Eh06; the unit's default IP is 192.168.0.1/24 with DHCP off (Eh05).
  • Only one BACnet instance exists, so BACnet cannot run on the BMS port and the Ethernet port at the same time.

Watch out for

  • Every object is listed RW; don't write to readings, status or alarm objects.
  • Scheduler, probe range and drain settings (AV 15-29, PIV 10-28, BV 161-166) are configuration; avoid cyclic writes.
  • SV_Command (PIV 36) resets alarms (1) or cylinder hours (2); it is a one-shot command, not a value to hold.

Questions about the CAREL gaSteam (UG) gas-fired humidifier

How many BACnet points does the CAREL gaSteam (UG) gas-fired humidifier have?

This list has 350 BACnet objects: 8 analog inputs, 62 analog values, 150 binary values, 4 integer values, 126 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which CAREL gaSteam (UG) gas-fired humidifier BACnet points are writable?

350 of the 350 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official CAREL gaSteam (UG) gas-fired humidifier BACnet documentation?

The source is gaSteam - UG Gas-fired humidifier - User manual (+0300122EN rel. 1.4), revision 2026-02-26, published free by CAREL at https://www.carel.com/documents/10191/0/%2B0300122EN/b5f100a2-099e-475f-a2d6-26bd03b55518?version=1.5.

What are the minimum BACnet points to integrate the CAREL gaSteam (UG) gas-fired humidifier?

Start with BV 0 OnBySV (Unit on/off from the BMS); AV 73 SV_PwrReq (Production request from the BMS, 0-100 %); AV 1 GlbSetP_Hum (Humidity set point, %RH (own probe control)); BV 35 OnOffStatus (Unit on/off status); PIV 57 UnitStatus (Operating state code); AV 31 MainPrb (Main probe reading); AV 34 CurrProdPh (Current steam production, kg/h); BV 38 CurrBlkAlrm.IsPresent (At least one alarm active); BV 37 CurrBlkAlrm.IsBlocker (Non-resettable alarm active).

How do I enable BMS control of the CAREL gaSteam (UG) gas-fired humidifier?

On screens Eh07/Eh08 (Installer menu) select the supervisor port and enable 'On/Off signal from supervisor' and 'control from supervisor'; on the BMS port the Eh01 settings 'On/Off from SV' and 'Control from SV' do the same. Without them the unit ignores the supervisor on/off and production request.

Does the CAREL gaSteam (UG) gas-fired humidifier need a BACnet heartbeat or have a communication timeout?

Eh08 can enable a supervisor-offline alarm (ALP21, BV 135) with an activation delay. The manual does not say what the unit does with its output when the supervisor goes offline.

Can the BMS supply sensor values to the CAREL gaSteam (UG) gas-fired humidifier?

With control from supervisor the BMS sends the production request on SV_PwrReq (AV 73) instead of the unit using a probe. Up to four CAREL wireless probes can also feed the unit (WirelessPrbVal AI objects).
