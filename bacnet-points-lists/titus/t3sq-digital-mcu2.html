Short answer

The MCU 2 is the network gateway for the Titus Digital T3SQ diffuser system: it reports up to 60 diffuser control zones to a BMS as BACnet/IP (part BW2011-2B) or BACnet MS/TP (BW2011-2M). Each object type is laid out as blocks of 60 instances, one per zone, so instance = block start + zone - 1. Only master-diffuser data is available; slave diffusers and detailed setup or diagnostics are not exposed. Zones that are not set up on the MCU simply return no data.

BMS integration notes: Titus Titus Digital T3SQ (MCU 2 BACnet gateway)

Integration in brief

Discover the MCU 2 (one BACnet device for up to 60 zones) and map each zone by offset: zone n is instance n-1 in the first block of each type. Write the zone setpoint to the AO block and use the two MSO blocks for flush/emergency commands and occupancy override, after enabling Control Override on each zone master with the MLM Tool.

Enable & remote start

BMS commands (control override and occupancy override MSOs) only take effect after Control Override is ticked on the master diffuser of that zone in the MLM Tool (Process / Master Command, then Write). That setting is non-volatile. Write 1 (Normal) to release a command.

Sensors & values from the BMS

Only the zone setpoint (AO 0-59) is written from the BMS; there is no BMS-fed temperature input in the point map.

Network setup

  • BACnet/IP: default MCU IP address 192.168.0.251; device name, BACnet ID and BACnet UDP port are set on the MCU web page (Save).
  • Holding BOOT until ST1 flashes, then pressing DEF, resets the MCU to the default IP address.
  • BACnet MS/TP: default MAC 25 (range 0-127), default baud 76800; checked and set over USB with the MLM Tool (V8.xx required).
  • BACnet has to be activated on the MCU with a key (normally done at the factory); the web page shows the BACnet state.
  • ReadPropertyMultiple/WritePropertyMultiple are supported; segmentation is not; max APDU 480 bytes.

Watch out for

  • Instances start at 0, so zone n is instance n-1 (plus the block offset).
  • Multistate values are shown as numbers on many front ends; read State_Text for the labels.
  • A generic BACnet reader shows all 60 zones whether populated or not; unpopulated zones carry no data.
  • Slave diffusers mimic their master; no per-slave points are exposed.

Questions about the Titus Titus Digital T3SQ (MCU 2 BACnet gateway)

How many BACnet points does the Titus Titus Digital T3SQ (MCU 2 BACnet gateway) have?

This list has 840 BACnet objects: 120 analog inputs, 60 analog outputs, 420 analog values, 120 multi-state inputs, 120 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Titus Titus Digital T3SQ (MCU 2 BACnet gateway) BACnet points are writable?

180 of the 840 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Titus Titus Digital T3SQ (MCU 2 BACnet gateway) BACnet documentation?

The source is Titus Digital T3SQ MLM Integration with BMS (BW0070-3), revision 2015-06, published free by Titus at https://www.titus-hvac.com/file/11344/T3SQ%20Digital%20BMS%20Integration%20Manual%20(2).pdf.

What are the minimum BACnet points to integrate the Titus Titus Digital T3SQ (MCU 2 BACnet gateway)?

Start with AV 0 Space Temp 1 (Zone 1 space temperature (AV 0-59 for zones 1-60)); AO 0 Setpoint 1 (Zone 1 setpoint from the BMS (AO 0-59)); MI 0 Mode 1 (Zone 1 diffuser mode status (MSI 0-59)); MI 60 Occupancy 1 (Zone 1 occupancy status (MSI 60-119)); AV 120 Control Disk pos 1 (Zone 1 control disk position (AV 120-179)); MO 60 Occupancy override 1 (Zone 1 occupancy override (MSO 60-119)); MO 0 Control override 1 (Zone 1 BMS control override such as flush or emergency (MSO 0-59)).

How do I enable BMS control of the Titus Titus Digital T3SQ (MCU 2 BACnet gateway)?

BMS commands (control override and occupancy override MSOs) only take effect after Control Override is ticked on the master diffuser of that zone in the MLM Tool (Process / Master Command, then Write). That setting is non-volatile. Write 1 (Normal) to release a command.

Can the BMS supply sensor values to the Titus Titus Digital T3SQ (MCU 2 BACnet gateway)?

Only the zone setpoint (AO 0-59) is written from the BMS; there is no BMS-fed temperature input in the point map.
