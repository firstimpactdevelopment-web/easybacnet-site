Short answer

UbiquiSTAT is a touchscreen thermostat for conventional, heat pump and modulating RTU and zoning applications, with BACnet MS/TP (or TCSbus/Modbus) on RS-485. Appendix A of the product manual lists 244 objects: occupancy schedule and calendar, setpoint pairs, staging, fan, occupancy overrides, sensor inputs and BMS-writable sensor values, relay and analog outputs, economizer, demand ventilation, limits, service status and display settings. A per-model table shows which objects each model has.

BMS integration notes: TCS Basys Controls UbiquiSTAT commercial BACnet thermostat (US4010 / US4020 / US4040 / US4050)

Integration in brief

Set the RS-485 mode to BACnet, the MS/TP address and baud rate on the thermostat (device instance defaults to vendor ID 496 combined with the address), then command occupancy with MSV 700 or the schedule SCH 800 and write the setpoints. Read space temperature, system state and the outputs.

Heartbeat & communication loss

Commands written at priority 10 are relinquished automatically after PIV 401 Command Override Timeout (default 600 s, 0-604800 s); rewrite them before it expires or use another priority.

Sensors & values from the BMS

Space temperature, discharge, outdoor and mixed air temperature, CO2 and RH (AV 130-135) are commandable, so a BMS can supply them; MSV 120-123 choose the source for space temperature, mixed air, CO2 and RH.

Network setup

  • BACnet MS/TP default baud 38,400 bps (TCSbus defaults to 9,600).
  • Device instance default combines the TCS vendor ID (496) with the network address; set your own unique numbers.
  • RS-485 address, baud and mode are also objects (PIV 603, MSV 601, MSV 602).

Watch out for

  • Many objects are stored in non-volatile memory (NVM); avoid writing those cyclically.
  • Check the model columns: over 40 % of objects exist only on some models.

Questions about the TCS Basys Controls UbiquiSTAT commercial BACnet thermostat (US4010 / US4020 / US4040 / US4050)

How many BACnet points does the TCS Basys Controls UbiquiSTAT commercial BACnet thermostat (US4010 / US4020 / US4040 / US4050) have?

This list has 244 BACnet objects: 6 analog inputs, 2 analog outputs, 102 analog values, 3 binary inputs, 7 binary outputs, 36 binary values, 1 calendar, 5 files, 1 schedule, 45 multi-state values, 4 characterstring values, 30 positive integer values, 2 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which TCS Basys Controls UbiquiSTAT commercial BACnet thermostat (US4010 / US4020 / US4040 / US4050) BACnet points are writable?

202 of the 244 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the TCS Basys Controls UbiquiSTAT commercial BACnet thermostat (US4010 / US4020 / US4040 / US4050)?

Start with MV 700 Occupancy State (Occupancy command / state); MV 1000 System Mode (System mode (off/auto/heat/cool)); AV 71 Active Cool Setpoint (Active cooling setpoint); AV 70 Active Heat Setpoint (Active heating setpoint); MV 1101 Occupied Fan Mode (Occupied fan mode); AV 130 Space Temperature (Space temperature (BMS can write)); MV 1004 System State (Current heating/cooling state); BO 305 G (Fan output); Other 1200 Service Status (Service and fault bits).

Does the TCS Basys Controls UbiquiSTAT commercial BACnet thermostat (US4010 / US4020 / US4040 / US4050) need a BACnet heartbeat or have a communication timeout?

Commands written at priority 10 are relinquished automatically after PIV 401 Command Override Timeout (default 600 s, 0-604800 s); rewrite them before it expires or use another priority.

Can the BMS supply sensor values to the TCS Basys Controls UbiquiSTAT commercial BACnet thermostat (US4010 / US4020 / US4040 / US4050)?

Space temperature, discharge, outdoor and mixed air temperature, CO2 and RH (AV 130-135) are commandable, so a BMS can supply them; MSV 120-123 choose the source for space temperature, mixed air, CO2 and RH.
