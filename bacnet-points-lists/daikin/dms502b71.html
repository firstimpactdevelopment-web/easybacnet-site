Daikin DMS502B71 Interface for use in BACnet BACnet points list

Updated 16 October 2026

Short answer

The DMS502B71 BACnet Interface (with the optional DAM411B51 expansion for DIII-Net ports 3 and 4) is a BACnet IP server that maps every VRV indoor unit group to the same 35-member object template. Integrators read on/off, mode, fan speed, room temperature, alarm and malfunction code, and can write start/stop, mode, setpoint, fan speed, airflow direction and remote-controller permit/prohibit per group. Object names end in the three-digit indoor unit number and instance numbers are built from that unit number.

BMS integration notes: Daikin DMS502B71 Interface for use in BACnet

Integration in brief

Commission the interface with the Daikin test-operation/setup tool, then address each indoor unit group by its object suffix (000-255). Typical integration writes start/stop, mode, setpoint and fan speed per group and reads on/off status, room temperature, alarm and malfunction code.

Enable & remote start

There is no separate enable: the BMS writes the command objects directly. Remote-controller lockouts are available per group (RemoteControlStart, RemoteControlAirConModeSet, RemoteControlTempAdjust = Prohibit), and CL_Rejection (only on 000/064/128/192) disables Daikin centralized controllers on that DIII-Net line. SystemForcedOff stops all units on a DIII-Net line and blocks remote-controller starts; clearing it does not restart the units, so the BMS (or another controller) must start them again.

Network setup

  • BACnet/IP port factory setting 47808 (settable 1-65535).
  • Can register as a BACnet foreign device when a BBMD is on another subnet.
  • After power-up the interface needs about one minute to discover indoor units; reads return UNKNOWN_OBJECT until then.
  • The interface can communicate with at most 100 BACnet networks.

Watch out for

  • Setpoint, On/Off, mode, airflow direction and fan speed are stored in indoor-unit non-volatile memory with a write-count limit; avoid cyclic writes.
  • Out-of-range setpoints are rounded to the unit's min/max, and F/C conversion can return a value slightly different from what was written; do not keep resending until they match.
  • Room temperature from the return air sensor can be skewed when the fan is off or during defrost; treat it as a reference only.
  • Daikin centralized controllers keep the ability to change on/off, mode and setpoint unless CL_Rejection is active.

Integration notes

  • Instances shown are for indoor unit 000. For unit number N, instance = N x 256 + member number, and XXX in the name is N (000-255).
  • DIII-Net port 1 covers units 000-063, port 2 064-127, ports 3 and 4 (DAM411B51 option) 128-255.
  • Member 15 is blank. Members 17 (centralized control) and 21 (forced system stop) exist only for units 000, 064, 128 and 192.
  • Accumulated gas and power need the optional power-proportional-distribution setup; ERV members apply to VAM units.
  • Setpoint, On/Off, mode, airflow direction and fan speed are saved to indoor-unit non-volatile memory; avoid frequent writes.

Questions about the Daikin DMS502B71 Interface for use in BACnet

How many BACnet points does the Daikin DMS502B71 Interface for use in BACnet have?

This list has 34 BACnet objects: 2 analog inputs, 2 analog values, 10 binary inputs, 3 binary outputs, 6 binary values, 5 multi-state inputs, 4 multi-state outputs, 2 accumulators. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin DMS502B71 Interface for use in BACnet BACnet points are writable?

15 of the 34 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
