Short answer

The DCM014A51 software option turns a Daikin intelligent Touch Manager into a BACnet IP server. The iTM acts as a BACnet virtual router: each indoor unit becomes its own virtual BACnet device carrying the same 37-object list, and a separate system control device holds schedule, auto-changeover, timed-override and forced-off objects. Objects can be enabled or disabled per unit during commissioning, so a site may expose fewer points than listed.

This page lists 41 BACnet objects for the Daikin intelligent Touch Manager (iTM) BACnet Server Gateway DCM014A51 - Indoor Unit and System Objects — 24 of them writable — with each object’s type, instance number, name, engineering units and access. BMS integration notes: Daikin intelligent Touch Manager (iTM) BACnet Server Gateway DCM014A51 - Indoor Unit and System Objects

Integration in brief

Enable the DCM014A51 option on the iTM, assign each indoor unit a unique device ID and a BACnet network number for the virtual network, then use Occupancy Mode and the setpoint objects per indoor unit device. System-wide schedule, auto-changeover and forced-off objects sit on the separate system control device.

Enable & remote start

Writing Occupancy Mode (MO 1) is the start/stop: Occ sends On, Unocc sends Off, Standby sends On with energy saving (setpoint offset by 3.6 F / 2 C). The iTM sends the command even if the unit is already in that state, and Occupancy Mode is set to 1 (Unocc) at iTM start-up. The 'Enable iTM Schedule Operation' object on the system control device turns the iTM's own schedule on or off.

Heartbeat & communication loss

No BMS heartbeat is described. If a written value is not accepted by the indoor unit, the iTM reverts the BACnet present value to the previous value after a 10-minute timer.

Network setup

  • Recommended device IDs: 530000 for the system control device and 53PGGG for indoor units (P = port 1-8, GGG = DIII-Net group address, e.g. 531100).
  • Virtual BACnet network number must be unique; default is 100.
  • A virtual device's MAC address is the hex form of its device instance.
  • Can be configured as a BACnet foreign device with a BBMD IP address and port when the BMS is on another subnet.

Watch out for

  • In a multi-unit remote-controller group, only command the designated unit (#0); other units decide whether to follow.
  • Commands from cool to heat (or back) are refused unless the unit is the changeover master.
  • Objects can be disabled per unit during commissioning, so some points may be missing on site.
  • Setpoint values are rounded to the object's significant digits; temperature units follow the iTM locale.

Integration notes

  • Each indoor unit is a separate virtual BACnet device behind the iTM's virtual router; instances 1-37 repeat on every indoor unit device.
  • The last four points (BO 1, BO 2, MV 3, BO 4) live on the iTM system control device, not on indoor unit devices.
  • Temperature units follow the iTM regional setting (Celsius or Fahrenheit).
  • Commands that the indoor unit rejects are reverted by the iTM after about 10 minutes.
  • Only the remote-controller group's designated unit (#0) should receive commands in a multi-unit group.
  • Freeze Protection (BI 37) is only available on certain indoor unit models.

Which Daikin intelligent Touch Manager (iTM) BACnet Server Gateway DCM014A51 - Indoor Unit and System Objects BACnet points are writable?
