Short answer

The iLINQ DDC controller on Daikin light commercial packaged units talks BACnet MS/TP (port J25 BMS2) or BACnet IP (Ethernet) without extra hardware. Its object list covers space, supply and outdoor conditions, refrigerant pressures, setpoints, blower and economizer settings, network sensor inputs, relay status, individual alarm flags and multistate schedule, mode and configuration objects.

BMS integration notes: Daikin iLINQ DDC Controller (BACnet MS/TP and BACnet IP)

Integration in brief

Pick MS/TP or IP in the communication settings, set the instance ID (and MAC/baud for MS/TP) and set Update to Yes. Command occupancy by writing ScheduleSource (MV 0) and write OccCoolSP / OccHeatSP; read space and supply air temperature, HVAC mode, blower status and AlarmDO.

Enable & remote start

To schedule from the BAS, write 3 (Force Occupied) or 4 (Force Unoccupied) to ScheduleSource (MV 0); the onboard schedule and optimal start/stop are then ignored. If PushButtonOvrDuration (AV 79) is above 0, the space sensor button or the Remote Start Stop input can still give a temporary override.

Sensors & values from the BMS

Space temperature, space humidity, outdoor temperature, outdoor humidity and space CO2 can come from the BAS through AV 12-16 once each source is set to Network at the LCD or web interface (the source objects MV 9-13 are read-only over BACnet).

Network setup

  • Communication type defaults to BACnet MS/TP; MS/TP wires to terminal J25 BMS2, BACnet IP uses either Ethernet port.
  • Defaults: instance ID 15000, baud 38400 (9600-76800), MAC address 1, Max Master 127.
  • Settings take effect when Update is set to Yes, which restarts the controller.
  • COV subscriptions are supported; COV increments of AIs and AVs can be changed from the BACnet client.

Watch out for

  • The active setpoints (AV 6/7) are read-only and include local adjustment, load shedding and unoccupied offsets; write OccCoolSP / OccHeatSP instead.
  • UnitOccupiedStartDelay (AV 78) can stagger start-up when many units are commanded occupied together.
  • Offsets, bands, delays and calibration AVs are setup values; don't write them cyclically.

Questions about the Daikin iLINQ DDC Controller (BACnet MS/TP and BACnet IP)

How many BACnet points does the Daikin iLINQ DDC Controller (BACnet MS/TP and BACnet IP) have?

This list has 215 BACnet objects: 12 analog inputs, 101 analog values, 19 binary inputs, 69 binary values, 14 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin iLINQ DDC Controller (BACnet MS/TP and BACnet IP) BACnet points are writable?

76 of the 215 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin iLINQ DDC Controller (BACnet MS/TP and BACnet IP) BACnet documentation?

The source is Daikin iLINQ BACnet Design Guide (BDG-ILINQA), published free by Daikin at https://daikincomfort.com/docs/default-source/daikin-ilinq-controller/bdg-ilinq.pdf.

What are the minimum BACnet points to integrate the Daikin iLINQ DDC Controller (BACnet MS/TP and BACnet IP)?

Start with MV 0 ScheduleSource (3 = Force Occupied, 4 = Force Unoccupied from the BAS); AV 17 OccCoolSP (Occupied cooling setpoint, °F); AV 18 OccHeatSP (Occupied heating setpoint, °F); MV 2 HVACMode_BacMsv (Current HVAC mode); BV 6 BlowerStage1 (Blower stage 1 relay on/off); AI 0 SpaceTemp (Space temperature, °F); AI 1 SupplyAirTemp (Supply air temperature, °F); BV 20 AlarmDO (Any alarm active).

How do I enable BMS control of the Daikin iLINQ DDC Controller (BACnet MS/TP and BACnet IP)?

To schedule from the BAS, write 3 (Force Occupied) or 4 (Force Unoccupied) to ScheduleSource (MV 0); the onboard schedule and optimal start/stop are then ignored. If PushButtonOvrDuration (AV 79) is above 0, the space sensor button or the Remote Start Stop input can still give a temporary override.

Can the BMS supply sensor values to the Daikin iLINQ DDC Controller (BACnet MS/TP and BACnet IP)?

Space temperature, space humidity, outdoor temperature, outdoor humidity and space CO2 can come from the BAS through AV 12-16 once each source is set to Network at the LCD or web interface (the source objects MV 9-13 are read-only over BACnet).
