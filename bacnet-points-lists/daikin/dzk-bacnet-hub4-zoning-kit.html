Daikin DZK BACnet Interface (DZK-BACNET-HUB4) for the Daikin Zoning Kit BACnet points list

Updated 4 November 2026

Short answer

The DZK BACnet Interface plugs onto the DZK main control board and exposes the zoning system on BACnet IP (Ethernet or Wi-Fi) or BACnet MS/TP. The object list is fixed for six zones: per-zone on/off, heat and cool setpoints, room temperature, humidity, demands and damper step, plus the system mode, user mode and indoor unit status. One interface is needed per DZK system.

This page lists 86 BACnet objects for the Daikin DZK BACnet Interface (DZK-BACNET-HUB4) for the Daikin Zoning Kit — 26 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Daikin’s own free documentation, linked below.

BMS integration notes: Daikin DZK BACnet Interface (DZK-BACNET-HUB4) for the Daikin Zoning Kit

Integration in brief

Set BACnet IP or MS/TP and the device ID in the configuration app, then use DZK operation mode (MO 0) and user mode (MO 1) for the system, and Zx ON/OFF plus the zone heat and cool setpoints per zone. Read zone temperatures, IU status, IU speed and the error objects for monitoring.

Network setup

  • BACnet IP defaults: device ID 1000, UDP port 47808, DHCP (static default 192.168.0.100).
  • BACnet MS/TP: MAC 0-127, device ID 0-4194302 and baud rate are set in the app; select the MS/TP integration port.
  • One DZK BACnet interface per DZK control board.

Watch out for

  • In VRV heat pump systems the operating mode of a DZK on a slave indoor unit can be limited by the master indoor unit's mode.
  • The DZK address and group address (AV 13, 14) are learned at indoor unit start-up; if the DZK powers up after the indoor unit they may need a refresh from the controller.
  • IU Set Point (AV 0) is calculated by the zoning system and is read only; change the zone setpoints instead.

Integration notes

  • Objects for zones that do not exist report Out_Of_Service TRUE; only use values where Out_Of_Service is FALSE.
  • Z1 local ventilation is printed 'Z1 Local Ventilation'; zones 2-6 use 'Local ventilation'.
  • Temperature ranges are printed in both °F and °C; the unit follows the system setting.
  • IU errors (MI 1): convert the value to hex 0xXY, row = X-1, column = Y, then look up the Daikin malfunction code table in the manual.
  • The DZK error states are printed as display codes 1-3 mapping to errors 9, 10 and 11; the detailed text also lists 0 for normal operation.
  • Values are refreshed every second; COV subscriptions are supported.

Questions about the Daikin DZK BACnet Interface (DZK-BACNET-HUB4) for the Daikin Zoning Kit

How many BACnet points does the Daikin DZK BACnet Interface (DZK-BACNET-HUB4) for the Daikin Zoning Kit have?

This list has 86 BACnet objects: 6 analog inputs, 39 analog values, 2 binary inputs, 28 binary values, 3 multi-state inputs, 2 multi-state outputs, 6 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin DZK BACnet Interface (DZK-BACNET-HUB4) for the Daikin Zoning Kit BACnet points are writable?

26 of the 86 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin DZK BACnet Interface (DZK-BACNET-HUB4) for the Daikin Zoning Kit BACnet documentation?

The source is DZK-4 Integration manual (DZK BACnet Interface), revision Rev. 1, published free by Daikin at https://daikincomfort.com/docs/default-source/dzk-zoning-kit/um-dzk-bacnet-hub4.pdf.

What are the minimum BACnet points to integrate the Daikin DZK BACnet Interface (DZK-BACNET-HUB4) for the Daikin Zoning Kit?

Start with MO 1 DZK user mode (1 stop, 2 comfort, 3 unoccupied, 5 eco, 6 vacation); MO 0 DZK operation mode (1 auto, 2 cool, 3 heat, 4 dry, 5 emergency heat); BV 3 Z1 ON/OFF (Zone 1 on/off (repeat for zones 2-6)); AV 1 Z1 Heat Set point (Zone 1 heating setpoint); AV 2 Z1 Cool Set point (Zone 1 cooling setpoint); BI 0 IU Status ON/OFF (Indoor unit running); AI 0 Z1 Room Temperature (Zone 1 room temperature); MI 0 IU speed (Indoor unit fan step: low, medium, high); MI 1 IU errors (Indoor unit error; hex value = Daikin code); MI 2 DZK error (Zoning system error (bus, interface, P1P2)).
