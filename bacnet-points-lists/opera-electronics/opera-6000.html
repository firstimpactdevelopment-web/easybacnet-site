Opera Electronics Opera 6000 gas detector BACnet points list

Short answer

The Opera 6000 is a gas detector with one or two sensors, relays and an alarm output. On BACnet MS/TP it serves its own gas readings, ambient temperature, an input and the relay/alarm outputs. With BACnet enable P46 = 2 it also publishes the readings of up to 32 remote detectors (sensors A and B) on its local network.

This page lists 71 BACnet objects for the Opera Electronics Opera 6000 gas detector — 3 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of Opera Electronics’s documentation hosted by BACnet International catalog, not by Opera Electronics itself, so treat it as unofficial.

BMS integration notes: Opera Electronics Opera 6000 gas detector

Integration in brief

Set P46 to 1 for the local readings or 2 to add remote detectors, then read the gas readings and the relay/alarm objects. The relay and alarm BOs can also be written from the BMS.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

Parameter P46 enables BACnet: 1 = local readings, 2 = local plus remote detectors.

Network setup

  • MS/TP master at 9600, 19200, 38400 or 76800 baud.
  • Device object name is limited to 22 characters.

Watch out for

  • The gas reading objects change with P46, so rediscover the device after changing it.

Integration notes

  • AV 0 and AV 1 exist only with P46 = 1; AV 1 also needs a second sensor fitted.
  • AV 100-131 and AV 200-231 exist only with P46 = 2; instance = 100 + remote number (sensor A) or 200 + remote number (sensor B).
  • BO 1 is Relay 2 on A hardware and Alarm L2 on B hardware.
  • A hardware has 2 relays; B hardware has 1 relay, 2 analog outputs and a binary input.
  • Object types used: Analog Value, Binary Input, Binary Output and Device.

Questions about the Opera Electronics Opera 6000 gas detector

How many BACnet points does the Opera Electronics Opera 6000 gas detector have?

This list has 71 BACnet objects: 67 analog values, 1 binary input, 3 binary outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Opera Electronics Opera 6000 gas detector BACnet points are writable?

3 of the 71 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Opera Electronics Opera 6000 gas detector BACnet documentation?

Opera Electronics does not publish it on its own website. This list comes from BACnet Protocol Implementation Conformance Statement, Opera 6000 (PICS V1.6) (LC30001), revision 2016-12-06 (rev 1.4), a copy hosted by BACnet International catalog at https://www.bacnetinternational.net/catalog/manu/opera%20electronics%20inc/LC30001.PICS.48751328_Opera6000-PICS-V1.6.pdf. Ask Opera Electronics or its representative for the current revision.

What are the minimum BACnet points to integrate the Opera Electronics Opera 6000 gas detector?

Start with AV 0 Gas Reading 1 (Gas reading, local sensor A); AV 1 Gas Reading 2 (Gas reading, local sensor B); BO 0 Relay 1 (Relay 1 state); BO 1 Relay 2 (Relay 2 / alarm L2 state); BO 2 Alarm L3 (Alarm 3 indication).

How do I enable BMS control of the Opera Electronics Opera 6000 gas detector?

Parameter P46 enables BACnet: 1 = local readings, 2 = local plus remote detectors.

How do I check these points on the real Opera 6000 gas detector?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
