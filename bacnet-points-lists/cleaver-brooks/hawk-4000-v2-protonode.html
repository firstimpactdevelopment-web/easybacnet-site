Short answer

The ProtoNode maps the HAWK 4000 V2 boiler control to BACnet: a long list of alarm and status bits (limits, actuators, sensors, flame safeguard), steam pressure or water temperature, setpoints, firing rate, stack and economizer temperatures, burner control status lines, run time and cycles. The BMS can start the boiler, write a remote setpoint or firing rate, and must keep a heartbeat bit updated.

BMS integration notes: Cleaver-Brooks Hawk 4000 V2 boiler control (ProtoNode)

Integration in brief

Start the boiler with BV 2 and keep BV 1 heartbeat toggling; write the operating setpoint (AV 1) or a remote firing rate (AV 2). Read load demand, steam pressure or water temperature, firing rate and the alarm output.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

BV 2 Remote Start From BMS; BI 47 shows the boiler's remote enable input. The firing-rate mode bits (BI 58-60) show whether remote, manual or auto modulation is active.

Heartbeat & communication loss

BV 1 Heart Beat From BMS is written by the BMS; the guide does not state the timeout.

Network setup

  • BACnet Device Instance = the controller's Modbus Node-ID + Node_Offset (default 50,000), so Node-ID 1 = 50001. Change Node_Offset in the ProtoNode web configurator to pick other instances.
  • The ProtoNode RER does BACnet MS/TP or BACnet IP, selected on its S bank DIP switches.
  • BACnet MS/TP: one MAC address (1-127) for the whole ProtoNode on the A bank DIP switches; baud on B0-B3 (38400 factory default).
  • BACnet IP: default ProtoNode address 192.168.1.24; change it in the web configurator.

Watch out for

  • Elapsed time and cycle counts appear twice: as two 16-bit word objects and as single objects.
  • Objects named AWB[..] or AWR[..] are spare tags in the profile with no stated use.

  • The guide gives no engineering units or state texts; units appear only where the object name carries them (DEG F / DEG C).

Questions about the Cleaver-Brooks Hawk 4000 V2 boiler control (ProtoNode)

How many BACnet points does the Cleaver-Brooks Hawk 4000 V2 boiler control (ProtoNode) have?

This list has 378 BACnet objects: 96 analog inputs, 10 analog values, 240 binary inputs, 32 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Cleaver-Brooks Hawk 4000 V2 boiler control (ProtoNode) BACnet points are writable?

42 of the 378 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Cleaver-Brooks Hawk 4000 V2 boiler control (ProtoNode) BACnet documentation?

Cleaver-Brooks does not publish it on its own website. This list comes from Cloud Enabled ProtoNode Gateway Startup Guide (RER/LER) for interfacing Cleaver-Brooks products (750-426), revision 03/2018, a copy hosted by watmfg.com at https://watmfg.com/watmfg23082016/wp-content/uploads/2016/09/750-426-ProtoNode-Cloud.pdf. Ask Cleaver-Brooks or its representative for the current revision.

What are the minimum BACnet points to integrate the Cleaver-Brooks Hawk 4000 V2 boiler control (ProtoNode)?

Start with BV 2 Rem Start From BMS (Remote start from the BMS); BV 1 Heart Beat From BMS (Heartbeat written by the BMS); AV 1 Rem Op SP Boiler (Remote operating setpoint); AV 2 Rem Firing Rate (Remote firing rate); BI 57 Boiler Load Demand (Boiler load demand); AI 9 Steam Pressure or Hot Water Temp (Steam pressure or hot water temperature); AI 7 SP Steam Pressure/Water Temp (Active setpoint); AI 5 Firing Rate (Firing rate); BI 55 Alm Output (Alarm output).

How do I enable BMS control of the Cleaver-Brooks Hawk 4000 V2 boiler control (ProtoNode)?

BV 2 Remote Start From BMS; BI 47 shows the boiler's remote enable input. The firing-rate mode bits (BI 58-60) show whether remote, manual or auto modulation is active.

Does the Cleaver-Brooks Hawk 4000 V2 boiler control (ProtoNode) need a BACnet heartbeat or have a communication timeout?

BV 1 Heart Beat From BMS is written by the BMS; the guide does not state the timeout.

How do I check these points on the real Hawk 4000 V2 boiler control (ProtoNode)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
