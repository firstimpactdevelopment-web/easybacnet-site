Short answer

The ProtoNode maps the HSC boiler-plant controller to BACnet. Each condensing boiler (1-10) and non-condensing boiler (A-J) has a block of state, alarm word, hours, cycles, status bits, inlet and outlet temperature; the plant section adds header and return temperatures, active setpoints, reset-curve settings, lead/lag order, pump and damper module data and run counts. Four AVs let the BMS enable the system, send a setpoint and outdoor temperature, and write a heartbeat.

This page lists 318 BACnet objects for the Cleaver-Brooks HSC Hydronic System Controller (ProtoNode) — 4 of them writable — with each object’s type, instance number, name, engineering units and access. BMS integration notes: Cleaver-Brooks HSC Hydronic System Controller (ProtoNode)

Integration in brief

Enable the plant with AV 3 and write the setpoint with AV 1, keep AV 4 heartbeat updated, and optionally send outdoor air temperature on AV 2. Read system mode, header and return temperatures, boiler counts and the alarm words.

Enable & remote start

AV 3 Remote Modbus System Enable enables the plant; AV 1 Remote Modbus Setpoint Value sends the setpoint.

Heartbeat & communication loss

AV 4 Modbus Heartbeat is written by the BMS; the guide does not state the timeout.

Sensors & values from the BMS

AV 2 Remote Modbus Outdoor Air Temp takes an outdoor air temperature from the BMS.

Network setup

  • BACnet Device Instance = the controller's Modbus Node-ID + Node_Offset (default 50,000), so Node-ID 1 = 50001. Change Node_Offset in the ProtoNode web configurator to pick other instances.
  • The ProtoNode RER does BACnet MS/TP or BACnet IP, selected on its S bank DIP switches.
  • BACnet MS/TP: one MAC address (1-127) for the whole ProtoNode on the A bank DIP switches; baud on B0-B3 (38400 factory default).
  • BACnet IP: default ProtoNode address 192.168.1.24; change it in the web configurator.

Questions about the Cleaver-Brooks HSC Hydronic System Controller (ProtoNode)

How many BACnet points does the Cleaver-Brooks HSC Hydronic System Controller (ProtoNode) have?

This list has 318 BACnet objects: 314 analog inputs, 4 analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Cleaver-Brooks HSC Hydronic System Controller (ProtoNode) BACnet points are writable?

4 of the 318 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Cleaver-Brooks HSC Hydronic System Controller (ProtoNode) BACnet documentation?

Cleaver-Brooks does not publish it on its own website. This list comes from Cloud Enabled ProtoNode Gateway Startup Guide (RER/LER) for interfacing Cleaver-Brooks products (750-426), revision 03/2018, a copy hosted by watmfg.com at https://watmfg.com/watmfg23082016/wp-content/uploads/2016/09/750-426-ProtoNode-Cloud.pdf. Ask Cleaver-Brooks or its representative for the current revision.

What are the minimum BACnet points to integrate the Cleaver-Brooks HSC Hydronic System Controller (ProtoNode)?

Start with AV 3 Remote Modbus System Enable (Remote system enable); AV 1 Remote Modbus Setpoint Value (Remote setpoint); AV 4 Modbus Heartbeat (Heartbeat written by the BMS); AI 312 System Mode (System mode); AI 253 Main Supply Header Temp (Main supply header temperature); AI 254 System Return Temp (System return temperature); AI 213 Number of Cond Boilers Running (Condensing boilers running); AI 215 Number of Non-Cond Boilers Running (Non-condensing boilers running); AI 208 Alarm Word 1 Value (Alarm word 1).

How do I enable BMS control of the Cleaver-Brooks HSC Hydronic System Controller (ProtoNode)?

AV 3 Remote Modbus System Enable enables the plant; AV 1 Remote Modbus Setpoint Value sends the setpoint.

Does the Cleaver-Brooks HSC Hydronic System Controller (ProtoNode) need a BACnet heartbeat or have a communication timeout?

AV 4 Modbus Heartbeat is written by the BMS; the guide does not state the timeout.

Can the BMS supply sensor values to the Cleaver-Brooks HSC Hydronic System Controller (ProtoNode)?

AV 2 Remote Modbus Outdoor Air Temp takes an outdoor air temperature from the BMS.

How do I check these points on the real HSC Hydronic System Controller (ProtoNode)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
