BMS integration notes: Cleaver-Brooks Hawk 2000 boiler control (ProtoNode)

Integration in brief

Read-only. Map load demand, steam pressure or water temperature, setpoint, firing rate, main fuel valve and the burner control and low water alarms.

Network setup

  • BACnet Device Instance = the controller's Modbus Node-ID + Node_Offset (default 50,000), so Node-ID 1 = 50001. Change Node_Offset in the ProtoNode web configurator to pick other instances.
  • The ProtoNode RER does BACnet MS/TP or BACnet IP, selected on its S bank DIP switches.
  • BACnet MS/TP: one MAC address (1-127) for the whole ProtoNode on the A bank DIP switches; baud on B0-B3 (38400 factory default).
  • BACnet IP: default ProtoNode address 192.168.1.24; change it in the web configurator.

Watch out for

  • Elapsed time and cycle counts appear twice: as two 16-bit word objects and as single objects.

Integration notes

  • Each Cleaver-Brooks controller on the ProtoNode is its own BACnet device; the object instances below are the same on every device.
  • The profile has only AI and BI objects and the guide marks none as write points, so all are read-only.
  • The guide gives no engineering units or state texts; units appear only where the object name carries them (DEG F / DEG C).
  • Where a description is filled in, it gives the register from the guide's Modbus column.

Check it against the live device. A points list tells you what the controller can expose; the unit in front of you may differ by firmware or installed options.
