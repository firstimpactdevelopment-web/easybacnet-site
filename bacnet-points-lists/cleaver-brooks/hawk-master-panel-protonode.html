Short answer

The ProtoNode maps the Hawk master panel to BACnet: per-boiler communication, power, ready and start-output bits, sequence status, run time since last rotation, lead/lag order and control output, plus plant pressure or temperature, on/off points and setpoint limits. Writable AVs set lag start/stop points and timers, the boiler order and the setpoint.

BMS integration notes: Cleaver-Brooks Hawk Master Panel lead/lag (ProtoNode)

Integration in brief

Write the plant setpoint with AV 51 and read operating pressure or temperature, each boiler's sequence status and start output, and the sensor and low pressure alarms.

Network setup

  • BACnet Device Instance = the controller's Modbus Node-ID + Node_Offset (default 50,000), so Node-ID 1 = 50001. Change Node_Offset in the ProtoNode web configurator to pick other instances.
  • The ProtoNode RER does BACnet MS/TP or BACnet IP, selected on its S bank DIP switches.
  • BACnet MS/TP: one MAC address (1-127) for the whole ProtoNode on the A bank DIP switches; baud on B0-B3 (38400 factory default).
  • BACnet IP: default ProtoNode address 192.168.1.24; change it in the web configurator.

Integration notes

  • Each Cleaver-Brooks controller on the ProtoNode is its own BACnet device; the object instances below are the same on every device.
  • Access follows the guide's write-point stars: the starred AV/BV objects are writable, everything else is read-only.
  • The guide gives no engineering units or state texts; units appear only where the object name carries them (DEG F / DEG C).
  • Where a description is filled in, it gives the register from the guide's Modbus column.
  • Boilers E-H have their own blocks next to A-D; only boiler A objects are in the minimum list.
  • Objects named N510[..], AMB[..], AMI[..] or AMR[..] are spare tags in the profile with no stated use.

Check it against the live device. A points list tells you what the controller can expose; the unit in front of you may differ by firmware or installed options. Questions about the Cleaver-Brooks Hawk Master Panel lead/lag (ProtoNode)

How many BACnet points does the Cleaver-Brooks Hawk Master Panel lead/lag (ProtoNode) have?

This list has 196 BACnet objects: 80 analog inputs, 51 analog values, 64 binary inputs, 1 binary value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Cleaver-Brooks Hawk Master Panel lead/lag (ProtoNode) BACnet points are writable?

52 of the 196 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Cleaver-Brooks Hawk Master Panel lead/lag (ProtoNode) BACnet documentation?

Cleaver-Brooks does not publish it on its own website. What are the minimum BACnet points to integrate the Cleaver-Brooks Hawk Master Panel lead/lag (ProtoNode)?

Start with AV 51 Setpoint Value Write (Setpoint value written by the BMS); AI 404 Operating Pressure/Temp (Operating pressure or temperature); AI 419 Steam Pressure (Water Temp) SP (Steam pressure (water temperature) setpoint); AI 614 Boiler A Sequence Status (Boiler A sequence status); BI 1305 Boiler A Start Output (Boiler A start output); BI 1291 Steam/Water Sensor Fail (Steam/water sensor failure); BI 1292 Low Steam Pressure (Low steam pressure); BI 1323 I/O Module Failure (I/O module failure).

How do I check these points on the real Hawk Master Panel lead/lag (ProtoNode)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
