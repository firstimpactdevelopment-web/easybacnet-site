Short answer

The PXM 2000 serves its base meter data as a virtual BACnet IP device: volts, currents, power, power factor, energy, demand, THD and frequency as Analog Inputs, plus status, demand settings and nameplate data. Each optional I/O card (2DI/2DO, analog output, 4-channel digital) shows up as its own virtual BACnet device with a separate object list.

This page lists 157 BACnet objects for the Eaton Power Xpert Meter 2000 series (PXM 2000) - base meter — 0 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Eaton’s own free documentation, linked below.

BMS integration notes: Eaton Power Xpert Meter 2000 series (PXM 2000) - base meter

Integration in brief

Discover the meter data virtual device over BACnet IP and read total real power, energy, demand, power factor, average volts and currents, and frequency. Use sStatus to check the meter is in normal operation.

Network setup

  • BACnet IP (Annex J); the meter can register as a foreign device for BACnet networks across subnets.
  • Base meter data and each option card appear as separate virtual BACnet devices.

Watch out for

  • Line-to-neutral volts and neutral current objects apply to wye wiring only.
  • Percent THD objects need a PXM 2260 or higher.
