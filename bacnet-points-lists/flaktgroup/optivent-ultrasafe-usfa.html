Short answer

The UltraSafe USFA control unit runs a fire/smoke damper with an ultrasonic airflow sensor and an optional duct smoke detector. Its BACnet objects report damper position, current and test results, airflow, temperature and smoke detector values, accept a flow setpoint, manual override, damper test start, external alarm and interlock commands and an alarm reset, and include status bitstrings, trend logs, a PI loop and notification classes.

This page lists 74 BACnet objects for the FläktGroup OPTIVENT UltraSafe USFA control unit — 24 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from FläktGroup’s own free documentation, linked below.

BMS integration notes: FläktGroup OPTIVENT UltraSafe USFA control unit

Integration in brief

Read the machine state, damper position, airflow and the fire, fault and service alarm bits. If the BMS sets airflow, set BV 8 to Bus and write AV 2; BV 2 starts a damper test and BV 1 resets alarms.

Questions about the FläktGroup OPTIVENT UltraSafe USFA control unit

How many BACnet points does the FläktGroup OPTIVENT UltraSafe USFA control unit have?

This list has 74 BACnet objects: 20 analog inputs, 12 analog values, 4 binary inputs, 10 binary values, 1 loop, 3 multi-state inputs, 5 notification classs, 2 multi-state values, 6 trend logs, 2 integer values, 9 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which FläktGroup OPTIVENT UltraSafe USFA control unit BACnet points are writable?

24 of the 74 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official FläktGroup OPTIVENT UltraSafe USFA control unit BACnet documentation?

The source is OPTIVENT UltraSafe USFA Control Unit BACnet Objects (DC_10786GB 20231115_R0), revision 2023-11-15, published free by FläktGroup at https://www.flaktgroup.com/api/v1/Documents/1359816/Download.

What are the minimum BACnet points to integrate the FläktGroup OPTIVENT UltraSafe USFA control unit?

Start with AV 2 Volume flow setpoint (Relative airflow setpoint, %); BV 8 Air flow setpoint source (Active = Bus: BMS supplies the flow setpoint); BV 2 Damper test (Start a damper test); BV 1 Alarm & Event reset (Reset alarms and events); MI 1 Machine state (Unit state (normal, damper test, fault, interlock)); AI 11 Damper position (Damper position, %); AI 23 Volume flow relative (Relative airflow, %); MI 2 Smoke detector state (Smoke detector state incl. fire alarm); BI 4 Damper failure (Damper failure); BI 1 Service alarm (Service alarm active).

Can the BMS supply sensor values to the FläktGroup OPTIVENT UltraSafe USFA control unit?
