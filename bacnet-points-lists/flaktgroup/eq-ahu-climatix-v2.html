BMS integration notes: FläktGroup eQ AHU controls (Climatix), application eQ Fläkt AHU V2.xx

Integration in brief

Fit a Climatix BACnet IP (POL908) or MS/TP (POL904) module, set its network parameters on the controller and export the EDE file. Command the unit with the BMS time-switch-program objects (OpModeBmsTimeStSwtch or the steps/temperature variant) and the bus setpoint, then read operating mode, status, temperatures, fan signals and the alarm-class objects.

Enable & remote start

The document gives no access column. OpModeBmsTimeStSwtch (steps) and OpModeBmsTimeStTmpSwtch (steps/temperature) are the BMS time-switch-program commands (0 = Auto follows the unit's own program); which one applies depends on the unit's control mode.

Sensors & values from the BMS

ExtSetpointSpvCOM (AV 1884) is the external setpoint value from communication; the AI ExtSetpointSpv is the hard-wired external setpoint input.

Network setup

  • BACnet IP module POL908 or MS/TP module POL904 plugs onto the Climatix POL6xx controller; network settings are made on the controller.
  • EDE files can be exported from the controller for the BMS database.
  • Instance numbers are fixed by the Climatix application (they look random, e.g. OutTmp = AI 53218).

Watch out for

  • Climatix alarms are acknowledged as a whole, not per object; BACnet acknowledge does not clear pending Climatix alarms. The guide names a MultiStateValue 'Reset' for general acknowledgement.
  • Objects for options the unit does not have (ReCooler, extra heating/cooling, OJ-DV fan diagnostics) still appear in the list.
  • Multistate values are printed starting at 0; check the State_Text on site.
