BMS integration notes: FläktGroup ISYteq 4.0 AHU controls (SW 1.3.0.2)

Integration in brief

Set the BACnet datalink in the HMI (log in as Admin), export the EDE file, then command the unit with MV 3939011 Unit Operation Mode and the temperature setpoint. Keep the BMS heartbeat objects toggling if the unit uses them, and read temperatures, fan status and the collective alarm outputs.

Enable & remote start

MV 3939011 Unit Operation Mode (R/W) selects Automatic, Room Frost Protection, Low/High Speed, Free Profile 1/2 or Night Purge. BV 3030081 Unit Enable Via Temperature Control and the humidity / air-quality equivalents can also enable the unit. The integration manual's optional High priority function (Operating data > 8.8 BMS) lets BMS values override user inputs and profiles.

Heartbeat & communication loss

BV 3939041 BMS Heartbeat Read and BV 3939042 BMS Heartbeat Write are described only as objects to check that the BMS is alive; the list gives no timeout or fallback behaviour.

Network setup

  • Log in to the HMI as Admin (default password Admin) to change network settings.
  • BACnet MS/TP defaults on RS-485 interface 1: address 1, baud 19200, BC net 101, MaxMaster 127, MaxInfoFrames 10.
  • BACnet settings: /Configuration/Network/BACnet/General (device ID, EDE export; restart after changing the device ID). IP datalinks under /Datalinks.
  • Unit conversion for temperature, flow, pressure and area objects is set under /Configuration/Network/BACnet/Unit conversion.

Watch out for

  • Writing setpoints from the BMS does not save them to a profile; the integration manual describes a Modbus 'Save Profile Selection' tag for that.
  • With High priority enabled, BMS values override HMI and profile settings.

Questions about the FläktGroup ISYteq 4.0 AHU controls (SW 1.3.0.2)

How many BACnet points does the FläktGroup ISYteq 4.0 AHU controls (SW 1.3.0.2) have?

This list has 365 BACnet objects: 59 analog inputs, 16 analog outputs, 100 analog values, 44 binary inputs, 40 binary outputs, 99 binary values, 5 multi-state values, 2 integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which FläktGroup ISYteq 4.0 AHU controls (SW 1.3.0.2) BACnet points are writable?

47 of the 365 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the FläktGroup ISYteq 4.0 AHU controls (SW 1.3.0.2)?

Start with MV 3939011 Unit Operation Mode (Unit mode command: 1 Automatic, 3 Low, 4 High speed); AV 3030071 Temperature Control Setpoint (Temperature setpoint, °C); BV 3939042 BMS Heartbeat Write (BMS keep-alive written by the BMS); MV 3939091 Unit Operation Mode Actual (Actual operating profile); BO 101011 Supply Air Fan 1 On (Supply fan 1 running); AI 106011 Supply Air Temperature Sensor (Supply air temperature, °C); AI 206011 Extract Air Temperature Sensor (Extract air temperature, °C); AI 306011 Outdoor Air Temperature Sensor (Outdoor air temperature, °C); BO 3939101 Alarm Collective A/B On/Off (Any collective alarm); BO 3939031 Alarm Collected Active A (Collective A alarm active).

How do I enable BMS control of the FläktGroup ISYteq 4.0 AHU controls (SW 1.3.0.2)?

MV 3939011 Unit Operation Mode (R/W) selects Automatic, Room Frost Protection, Low/High Speed, Free Profile 1/2 or Night Purge. BV 3030081 Unit Enable Via Temperature Control and the humidity / air-quality equivalents can also enable the unit. The integration manual's optional High priority function (Operating data > 8.8 BMS) lets BMS values override user inputs and profiles.

Does the FläktGroup ISYteq 4.0 AHU controls (SW 1.3.0.2) need a BACnet heartbeat or have a communication timeout?

BV 3939041 BMS Heartbeat Read and BV 3939042 BMS Heartbeat Write are described only as objects to check that the BMS is alive; the list gives no timeout or fallback behaviour.
