BMS integration notes: FläktGroup ISYteq controller for eCO Top / eCO Side compact AHUs

Integration in brief

Set Protocol to MS/TP on the RS-485 channel (or use Ethernet port 1 for BACnet IP), set name and device instance in the HMI, then command the unit with MV 3939011 Unit Operation Mode and the temperature setpoint, and read temperatures, fan outputs and the collective alarms.

Enable & remote start

MV 3939011 Unit Operation Mode (R/W) selects Automatic, Room Frost Protection, Low/High Speed, Free Profile 1/2 or Night Purge. BV 3030081 / 3131081 / 3232081 let temperature, humidity or air quality control enable the unit.

Sensors & values from the BMS

The AI external setpoint objects (temperature 3030042, relative 3030043, humidity 3131042, air quality 3232042, fan flow/pressure/manual 133022-24 and 233022-24, outdoor air amount 2929011) are R/W inputs the BMS can write.

Network setup

  • MS/TP: HMI /Configuration/Network/RS485, choose channel 1 (A1/B1) or 2 (A2/B2), set Protocol = MS/TP, MAC, baud, BC net, MaxMaster, MaxInfoFrames.
  • BACnet IP: Ethernet port 1 (X23).
  • Name and device instance: HMI /Configuration/Network/BACnet/General; EDE export button on the same page. Admin login needed.

Watch out for

  • The same instance number is used by several object types; map by type and instance.
  • Check BMS_List.xlsm on the controller SD card for the object list of the installed software version.

How many BACnet points does the FläktGroup ISYteq controller for eCO Top / eCO Side compact AHUs have?

This list has 495 BACnet objects: 84 analog inputs, 49 analog outputs, 120 analog values, 24 binary inputs, 77 binary outputs, 128 binary values, 5 schedules, 8 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which FläktGroup ISYteq controller for eCO Top / eCO Side compact AHUs BACnet points are writable?

50 of the 495 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

How do I enable BMS control of the FläktGroup ISYteq controller for eCO Top / eCO Side compact AHUs?

MV 3939011 Unit Operation Mode (R/W) selects Automatic, Room Frost Protection, Low/High Speed, Free Profile 1/2 or Night Purge. BV 3030081 / 3131081 / 3232081 let temperature, humidity or air quality control enable the unit.
