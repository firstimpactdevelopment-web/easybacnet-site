Short answer

The BZ424-LX is the larger configurable VAV controller in the Onyxx LX range, with four universal inputs, two analog and four binary outputs and an integrated damper actuator and airflow sensor. Its fixed BACnet MS/TP map covers airflow and damper control, zone setpoints for up to three zones, humidity, CO2 and dewpoint/condensation logic, five auxiliary outputs, PID loops and configuration multi-states.

BMS integration notes: Lynxspring BZ424-LX configurable VAV controller (Onyxx LX)

Integration in brief

Set the address and baud on the DIP switches, configure box type, airflow limits, inputs and auxiliary outputs, then drive occupancy with BV 3 and set the occupied setpoints. Read room temperature, airflow, damper position, occupancy mode and the condensation status.

Network setup

  • MS/TP address is set on DIP switch bank DS2 (1-127); baud on DS1: 010 = 9600, 110 = 19200, 001 = 38400, 011 = 76800.
  • An EOL jumper terminates the MS/TP trunk on the last controller; a second jumper terminates the TZ sensor bus.
  • Firmware updates use a USB-COM adapter or a USB to MS/TP converter cable.

Watch out for

  • K-factor (AV 30) and duct area (AV 31) must match the box for airflow to read right.
  • BV 10 saves objects to flash and restarts the controller; do not write it cyclically.

Integration notes

  • The guide has no read/write column; access is inferred from its tags (Status = read-only; Cfg, User and Cmd = writable).
  • The four binary outputs are printed as AO 3-AO 6 (named BO_1-BO_4); AO 4 is printed as "A04".
  • Some MSV state lists are printed in short form (for example "AI-1, AI-2, AI-3 or AI-4"); those are kept as printed rather than numbered.
  • BV 3 OccSched is tagged "Clg" in the guide (likely Cfg); treated as writable.
  • PID loop objects LOOP0-LOOP9 are listed as LO with their printed action and default gains.
  • Temperature units are listed as °F; the guide prints °F and °C ranges and the controller can be set to metric.

Questions about the Lynxspring BZ424-LX configurable VAV controller (Onyxx LX)

How many BACnet points does the Lynxspring BZ424-LX configurable VAV controller (Onyxx LX) have?

This list has 127 BACnet objects: 5 analog inputs, 7 analog outputs, 58 analog values, 7 binary values, 9 loops, 41 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Lynxspring BZ424-LX configurable VAV controller (Onyxx LX) BACnet points are writable?

80 of the 127 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
