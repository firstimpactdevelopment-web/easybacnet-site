Short answer

The BW437-RTU-LX is a wall-mounted thermostat-style controller with built-in room temperature, humidity, CO2 and motion sensing that runs a rooftop unit or heat pump from preset applications (MSV 127). On BACnet MS/TP it exposes its seven relays, four analog outputs and inputs, setpoints, demands, economizer and humidity settings, and a long list of configuration multi-states.

This page lists 106 BACnet objects for the Lynxspring BW437-RTU-LX rooftop unit wall controller (Onyxx LX) — 65 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of Lynxspring’s documentation hosted by Cochrane Supply, not by Lynxspring itself, so treat it as unofficial.

BMS integration notes: Lynxspring BW437-RTU-LX rooftop unit wall controller (Onyxx LX)

Integration in brief

Pick the application in MSV 127, then command occupancy (MSV 6), system mode (MSV 3) and fan mode (MSV 4) from the BMS and adjust the occupied setpoints. Read room temperature, effective occupancy, supply air temperature and the help/alarm message.

Network setup

  • Network settings are entered in CONFIG MODE on the controller keypad.
  • A jumper sets the end-of-line termination on the last MS/TP node.
  • Firmware updates use the supplied USB-COM adapter or a USB to MS/TP converter cable.

Watch out for

  • Changing MSV 127 (application preset) reassigns the outputs and their descriptions.
  • Outdoor air temperature (AV 29) needs a sensor input or external value assigned in MSV 27.

Integration notes

  • The guide has no read/write column; access is inferred from its tags (Status = read-only; Cfg, User and Cmd = writable).
  • Binary and analog output descriptions are generated from the application chosen in MSV 127 (refreshed when BV 4 is on).
  • MSV 7-10, 16-19, 23, 27, 28, 30, 32, 44, 45, 48, 49, 52, 54, 55, 65 and 68 are for custom applications; set MSV 127 to custom before changing them.
  • A JP2 jumper selects whether the seventh output is BO 7 or AO 1 (ECM fan).
  • Temperature units are listed as °F; the guide prints °F and °C ranges and the controller can be set to metric.

How many BACnet points does the Lynxspring BW437-RTU-LX rooftop unit wall controller (Onyxx LX) have?

This list has 106 BACnet objects: 7 analog inputs, 4 analog outputs, 42 analog values, 1 binary input, 7 binary outputs, 7 binary values, 38 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Lynxspring BW437-RTU-LX rooftop unit wall controller (Onyxx LX) BACnet points are writable?

65 of the 106 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
