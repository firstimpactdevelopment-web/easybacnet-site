Short answer

The B848-LX and BP848-LX are configurable Onyxx LX field controllers with eight universal inputs, eight binary and four analog outputs. They run a fixed rooftop/air handler application that is set up through multi-state configuration objects: staging, economizer, power exhaust, humidification, supply pressure, zone averaging from VAV boxes and fan coil options. The BACnet MS/TP map lists the I/O, setpoints, zone data, status flags, PID loops and all configuration MSVs.

This page lists 198 BACnet objects for the Lynxspring B848-LX / BP848-LX configurable field controller (Onyxx LX) — 143 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of Lynxspring’s documentation hosted by Cochrane Supply, not by Lynxspring itself, so treat it as unofficial.

BMS integration notes: Lynxspring B848-LX / BP848-LX configurable field controller (Onyxx LX)

Integration in brief

Set the address and baud on the DIP switches and configure the application through the MSVs (equipment type, staging, economizer, sensors). Then set system mode and occupied setpoints from the BMS and read return/supply temperatures, fan status, static pressure and the freeze and TZ sensor status.

Network setup

  • MS/TP address is set on DIP switch bank DS2 (1-127); baud on DS1: 010 = 9600, 110 = 19200, 001 = 38400, 011 = 76800.
  • An EOL jumper terminates the MS/TP trunk on the last controller; a second jumper terminates the TZ sensor bus.
  • Firmware updates use a USB-COM adapter or a USB to MS/TP converter cable.

Watch out for

  • Most behaviour depends on the configuration MSVs; a missing location setting leaves the matching value unused.
  • BV 10 saves objects to flash and restarts the controller; do not write it cyclically.

Integration notes

  • The guide has no read/write column; access is inferred from its tags (Status = read-only; Cfg, User and Cmd = writable).
  • The B848-LX and BP848-LX guides print the same object table (one typo apart: AV 14 tagged "Staus"); the BP848-LX guide asks for firmware 2.238 or later.
  • MSV 4-7 names look shifted by one row in the guide (MSV 4 printed as Units_Type for cooling control type, MSV 5 Clg_Type, MSV 6 ClgBO_Loc, MSV 7 ClgAO_Loc); MSV 17-19 repeat the name as description; kept as printed. BV 7 FreezeCond and BV 15 FanStat print state texts (Night/Day, Continuous/Intermittent) that look copied from other rows; kept as printed.
  • Some MSV state lists are printed in short form (for example "AI-1..AI-8"); those are kept as printed rather than numbered. MSV 33 prints the power exhaust type states.
  • AV 40 is printed with a gap ("RTSPclg_STBd t"); listed as RTSPclg_STBdt to match AV 41.
  • Temperature units are listed as °F; the guide prints °F and °C ranges and the controller can be set to metric.

Questions about the Lynxspring B848-LX / BP848-LX configurable field controller (Onyxx LX)

How many BACnet points does the Lynxspring B848-LX / BP848-LX configurable field controller (Onyxx LX) have?

This list has 198 BACnet objects: 8 analog inputs, 4 analog outputs, 75 analog values, 8 binary outputs, 20 binary values, 9 loops, 74 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Lynxspring B848-LX / BP848-LX configurable field controller (Onyxx LX) BACnet points are writable?

143 of the 198 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Lynxspring B848-LX / BP848-LX configurable field controller (Onyxx LX) BACnet documentation?

Lynxspring does not publish it on its own website. What are the minimum BACnet points to integrate the Lynxspring B848-LX / BP848-LX configurable field controller (Onyxx LX)?
