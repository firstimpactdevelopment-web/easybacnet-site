Weil-McLain Evergreen / SlimFit Series 2 & 3 / SVF - ProtoNode BACnet points list

Updated 16 October 2026

Short answer

A ProtoNode FPC-N34 reads the boiler control over Modbus RTU and presents it as a BACnet IP or BACnet MS/TP device with 831 objects numbered in one sequence across AI, AV, BI and MI. Besides temperatures, status, counters and lockout history, it carries the priority and network (cascade) settings, a block per cascade member (Shadow 2-8), and bit-level BIs for relay outputs, inputs and lockout causes.

This page lists 831 BACnet objects for the Weil-McLain Evergreen / SlimFit Series 2 & 3 / SVF - ProtoNode — 111 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Weil-McLain’s own free documentation, linked below.

BMS integration notes: Weil-McLain Evergreen / SlimFit Series 2 & 3 / SVF - ProtoNode

Integration in brief

Most objects are read-only monitoring. Map boiler status, target and outlet temperatures, modulation rate, gas valve output and sensor warnings. The writable AVs are the priority, network and cascade settings (supply targets, outdoor reset, differentials, rates, times); the supplement does not say which one a BMS should use as a run or setpoint command.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • Device instance, MAC address and baud rate are set on the ProtoNode (see the ProtoNode start-up guide); this supplement does not list them.
  • Object IDs are unique across object types (1-831), so AI 7 and AV 7 never both exist.

Watch out for

  • No read/write column: AVs are writable settings, all AI/BI/MI are read-only.
  • Several names repeat (for example Boiler Status is MI 138 and AI 653, AI 75 Local Return Temp and AI 151 Local Return Temperature); use the object ID, not the name.
  • Writable AVs are boiler configuration values; avoid writing them cyclically.

Integration notes

  • This supplement only lists the objects; device instance, MAC address and baud rate are set on the ProtoNode as described in its start-up guide, which is a separate document.
  • The same object list is served over BACnet IP or BACnet MS/TP, depending on how the ProtoNode is set up.
  • No units or state texts are given. The LonWorks types in the source show which values are temperatures, percentages or hours.
  • The supplement has no read/write column. The 111 AVs map to LonWorks input variables, so they are marked writable; every other object is read-only.
  • Object IDs run in one sequence (1-831) across AI, AV, BI and MI; each ID is used by one object type only.
  • Shadow 2-8 blocks repeat the status of the other boilers in a cascade.
  • SlimFit 1000-2000 Series 1 (SOLA) boilers use a different object list.

Questions about the Weil-McLain Evergreen / SlimFit Series 2 & 3 / SVF - ProtoNode

How many BACnet points does the Weil-McLain Evergreen / SlimFit Series 2 & 3 / SVF - ProtoNode have?

This list has 831 BACnet objects: 487 analog inputs, 111 analog values, 214 binary inputs, 19 multi-state inputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Weil-McLain Evergreen / SlimFit Series 2 & 3 / SVF - ProtoNode BACnet points are writable?

111 of the 831 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Weil-McLain Evergreen / SlimFit Series 2 & 3 / SVF - ProtoNode BACnet documentation?

The source is ProtoNode FPC-N34 and ProtoNode FPC-N35 Complete Point List Supplement (Weil-McLain) (T17022), revision Document Revision 7.D, January 2019, published free by Weil-McLain at https://www.weil-mclain.com/wp-content/uploads/ProtoNode-Complete-Point-List-Supplement-JAN19_1.pdf.

What are the minimum BACnet points to integrate the Weil-McLain Evergreen / SlimFit Series 2 & 3 / SVF - ProtoNode?

Start with MI 138 Boiler Status (Boiler status code); AI 10 Active Target Supply Temperature (Supply temperature the boiler is aiming for); AI 7 Boiler Out 1 Temperature (Boiler outlet water temperature); AI 307 Boiler Modulation Rate (Burner modulation rate); BI 594 Relay Output Gas Valve ON (Gas valve energized (burner firing)); AI 19 Outdoor Temp (Outdoor air temperature); AI 160 Sensor Warnings (Sensor warning code).
