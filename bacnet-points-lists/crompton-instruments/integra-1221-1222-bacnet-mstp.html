Short answer

The Integra 1221/1222 is a multifunction electricity meter; a plug-on option module adds BACnet MS/TP. All measurements are read-only Analog Inputs (175 objects: per-phase and system voltage, current, power, VA, VAr, power factor, energy, demand, THD, min/max values and vector angles), and 17 Analog Values hold the meter settings such as demand period, CT and VT ratios and baud rate.

This page lists 192 BACnet objects for the Crompton Instruments Integra 1221 / 1222 digital metering system, BACnet MS/TP option module — 14 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of Crompton Instruments’s documentation hosted by Colterlec, not by Crompton Instruments itself, so treat it as unofficial.

BMS integration notes: Crompton Instruments Integra 1221 / 1222 digital metering system, BACnet MS/TP option module

Integration in brief

Set the MS/TP MAC address (1-127) and identity mode on the meter's Comms menu, then read the AI objects. Nothing has to be written for monitoring; settings live in the AV objects.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • MS/TP, default 38400 baud, no parity, 1 stop bit; MAC address 1-127, default 001.
  • The Identity setting picks whether the device instance is the MAC address or a 22-bit instance number.
  • Baud can also be changed through AV 16; power-cycle the meter to apply.

Watch out for

  • With the BACnet module fitted no other external protocol is available.
  • Writing 0 to AV 13 resets the energy readings.

Integration notes

  • In the printed Analog Value table the description column is out of step with the names: the texts for AV 6-10 sit one row low and AV 13's reset text sits on the AV 6 row. The descriptions and access here are paired by content (e.g. the serial-number text goes with Hi Serial, the reset text with Reset Parameter).
  • AI 32-34 (VAr hours and VA hours) use units the PICS marks as not ASHRAE-defined (enumerations 0xF2 / 0xEF; VA hours is proprietary 257).
  • AI 110 HRun and AI 111 PFTot are printed with units 'percent'.
  • AI 159-162 repeat the names VTHDAvg / ATHDAvg for the maximum and minimum values, as printed.
  • Some Analog Values are protected: write the password to AV 7 first.

Questions about the Crompton Instruments Integra 1221 / 1222 digital metering system, BACnet MS/TP option module

How many BACnet points does the Crompton Instruments Integra 1221 / 1222 digital metering system, BACnet MS/TP option module have?

This list has 192 BACnet objects: 175 analog inputs, 17 analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Crompton Instruments Integra 1221 / 1222 digital metering system, BACnet MS/TP option module BACnet points are writable?

14 of the 192 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
