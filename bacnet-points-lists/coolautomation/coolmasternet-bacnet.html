Short answer

CoolMasterNet and the CooLink family connect to the AC manufacturer's indoor-unit bus and serve every indoor unit as the same 16 BACnet objects, over BACnet MS/TP and/or BACnet IP. Instance numbers are built from the unit's virtual address (VA): instance = VA x 256 + object index. Configuration is done with text commands on the gateway's ASCII interface.

This page lists 16 BACnet objects for the CoolAutomation CoolMasterNet BACnet (indoor unit objects) — 12 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from CoolAutomation’s own free documentation, linked below.

BMS integration notes: CoolAutomation CoolMasterNet BACnet (indoor unit objects)

Integration in brief

Enable BACnet MS/TP on line L3 and/or BACnet IP, run 'va auto' so each indoor unit gets a virtual address, then map each unit's block of objects at VA x 256. Command BV ON/OFF, MV Operation Mode, AV Set Temperature and MV Fan Speed, and read AI Room Temperature and BI HVAC Failure Indication.

Enable & remote start

BACnet must be enabled on the gateway ('line type L3 BAC' for MS/TP, 'bacnet IP enable' for IP); no BMS enable object is documented.

Network setup

  • BACnet MS/TP: activate on line L3 with 'line type L3 BAC' (L4-L7 also possible on CoolMasterNet); default frame 9600 8N1, change with 'line baud L3 <rate>_8N1'; MAC (TS) default 0x40 = 64, change with 'line myid L3 <hex>'. Reboot after each change.
  • BACnet IP: enable with 'bacnet IP enable'; UDP port 47808 by default ('bacnet port <n>'). The server starts only once Ethernet is up with an IP address.
  • Default device instance 64 (0x40); change with 'bacnet instance <n>'.
  • Allocate virtual addresses with 'va auto' (one VA per detected indoor unit) or 'va + L1.102 0004'; list them with 'va'.
  • One MS/TP and one BACnet IP connection can run at the same time.

Watch out for

  • Running 'va auto' again deletes and re-allocates all VAs, which renumbers every object; only run it once all indoor units are connected.
  • Every configuration command needs a reboot to take effect.
  • Additional MS/TP connections are not supported even if more RS-485 lines exist.
  • The guide's MS/TP example output shows TS 64 and device instance 64 by default; set unique values for each gateway.

Integration notes

  • Points shown for virtual address VA 1 (instances 256-258); add 256 for each further VA.
  • The object identifier's instance field is VA in bits 21-8 and object index in bits 7-0.
  • Access follows the guide's object-type table: BV, AV, MV and PIV read/write; BI, AI and CSV read-only.
  • Object names are not printed in the guide; the object descriptions are used as names.
  • Fan speed, mode and louver states that a given unit does not support are simply not used.
  • Operation Mode state 8 is not printed in the guide.

Questions about the CoolAutomation CoolMasterNet BACnet (indoor unit objects)

How many BACnet points does the CoolAutomation CoolMasterNet BACnet (indoor unit objects) have?

This list has 16 BACnet objects: 1 analog input, 1 analog value, 3 binary inputs, 6 binary values, 3 multi-state values, 2 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which CoolAutomation CoolMasterNet BACnet (indoor unit objects) BACnet points are writable?

12 of the 16 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official CoolAutomation CoolMasterNet BACnet (indoor unit objects) BACnet documentation?

The source is BACnet Integration Guidelines - CoolMasterNet, CooLinkNet, CooLinkHub, CooLinkBridge, revision Rev 0.5, 2019-04-29, published free by CoolAutomation at https://coolautomation.com/Lib/doc/CoolMasterNet/manual/CoolMasterNet-BACnet-guidelines.pdf.

What are the minimum BACnet points to integrate the CoolAutomation CoolMasterNet BACnet (indoor unit objects)?

Start with BV 256 ON/OFF (Start/stop the indoor unit); MV 257 Operation Mode (Mode selection); AV 256 Set Temperature (Setpoint); MV 256 Fan Speed (Fan speed); AI 256 Room Temperature (Room temperature); BI 256 HVAC Failure Indication (Unit alarm (code in Active_Text)); BV 261 Global Lock (prohibit) (Lock out the wired remote if the BMS is in charge).

How do I enable BMS control of the CoolAutomation CoolMasterNet BACnet (indoor unit objects)?

BACnet must be enabled on the gateway ('line type L3 BAC' for MS/TP, 'bacnet IP enable' for IP); no BMS enable object is documented.

How do I check these points on the real CoolMasterNet BACnet (indoor unit objects)?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
