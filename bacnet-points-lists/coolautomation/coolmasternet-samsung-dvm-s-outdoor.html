BMS integration notes: CoolAutomation CoolMasterNet Samsung DVM S outdoor unit (PRO) objects

Integration in brief

Use these objects to monitor Samsung outdoor equipment only; control stays on the CoolMasterNet indoor-unit objects. Map the outdoor block's VA and trend the key temperatures, compressor data and error state.

Enable & remote start

BACnet must be enabled on the gateway; these objects belong to its PRO (service data) functionality.

Network setup

  • BACnet MS/TP: activate on line L3 with 'line type L3 BAC' (L4-L7 also possible on CoolMasterNet); default frame 9600 8N1, change with 'line baud L3 <rate>_8N1'; MAC (TS) default 0x40 = 64, change with 'line myid L3 <hex>'. Reboot after each change.
  • BACnet IP: enable with 'bacnet IP enable'; UDP port 47808 by default ('bacnet port <n>'). The server starts only once Ethernet is up with an IP address.
  • Default device instance 64 (0x40); change with 'bacnet instance <n>'.

Watch out for

  • The guide does not document how VAs are assigned to outdoor units; confirm instances with a BACnet discovery.

Integration notes

  • Instance = VA x 256 + index (object identifier bits 21-8 = VA, 7-0 = index). Points shown for VA 1; the guide does not explain how outdoor units receive their VA.
  • Access set to read-only: these are measured service values, although the guide's type table lists PIV as read/write.
  • Values marked (value x 0.1) or (value x 0.001) are raw and need scaling in the BMS.
  • Object names are the guide's short names; descriptions are the guide's object descriptions.
  • Operation mode, operation status and error code are PIV codes; the guide does not decode them.
