BMS integration notes: Mark Climate Airstream AHU (OJ Air2 controller)

Integration in brief

Run the unit from the BMS with AV244 BMSDrfCtrlReg (11 = stop, 105 = low, 414 = medium, 210 = high speed), which only works once the physical 'Operating mode via BMS' input is active (BI199 BMS InpStat reports it). Write the temperature setpoint to AV134, read AI0 DriftMode for the actual mode, the supply and outdoor temperatures and flows, BI29 for any active alarm, and pulse BV0 to reset alarms.

Enable & remote start

AV244 BMSDrfCtrlReg sets the BMS operating mode (11 stop, 105 low, 414 medium, 210 high, 211 summer night cooling, 220 night heating). BMS modes only take effect after the physical input 'Operating mode via BMS' is activated; BI199 BMS InpStat reports the BMS-control activation status. AV0 ManDriftMode is the controller's own auto/manual/calendar selection.

Sensors & values from the BMS

To use a BMS outdoor temperature set BV15 MBTOutDAct and write AV245 MBT_OutDoor; for room temperature set BV16 MBTRoom1Activ and write AV246 MBT_Room1. Alarms flag BMS room and outdoor values that are out of range.

Network setup

  • BACnet IP on the RJ45 port, UDP 47808.
  • The device instance is set automatically from the last 5 digits of the controller's IP address (e.g. 172.21.0.95 gives 95), only at power-up or restart.
  • Up to 300 values can be subscribed for COV at once.

Watch out for

  • Writing AV244 does nothing until the 'Operating mode via BMS' digital input is active.
  • Changing the IP address changes the device instance after the next restart.
  • Many AVs are commissioning settings (pump modes, alarm limits); keep cyclic BMS writes to the command and setpoint points.
  • Rows with NA in the BACnet column are Modbus-only and are not in this list; a few BACnet objects have no Modbus register.

Questions about the Mark Climate Airstream AHU (OJ Air2 controller)

How many BACnet points does the Mark Climate Airstream AHU (OJ Air2 controller) have?

This list has 878 BACnet objects: 265 analog inputs, 301 analog values, 290 binary inputs, 22 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Mark Climate Airstream AHU (OJ Air2 controller) BACnet points are writable?

323 of the 878 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the Mark Climate Airstream AHU (OJ Air2 controller)?

Start with AV 244 BMSDrfCtrlReg (BMS run mode: 11 stop, 105 low, 414 medium, 210 high); AV 134 TempRegSet (Temperature setpoint for the active control type); BV 0 Alr_Reset (Alarm reset (returns to 0 by itself)); AI 0 DriftMode (Actual mode: 0-99 stopped, 100+ running); AI 16 SupTemp (Supply air temperature); AI 20 OutDoorTemp (Outdoor air temperature); AI 5 SupFlow (Supply air flow); BI 29 AlrActive (Any active alarm).

How do I enable BMS control of the Mark Climate Airstream AHU (OJ Air2 controller)?

AV244 BMSDrfCtrlReg sets the BMS operating mode (11 stop, 105 low, 414 medium, 210 high, 211 summer night cooling, 220 night heating). BMS modes only take effect after the physical input 'Operating mode via BMS' is activated; BI199 BMS InpStat reports the BMS-control activation status. AV0 ManDriftMode is the controller's own auto/manual/calendar selection.

Can the BMS supply sensor values to the Mark Climate Airstream AHU (OJ Air2 controller)?

To use a BMS outdoor temperature set BV15 MBTOutDAct and write AV245 MBT_OutDoor; for room temperature set BV16 MBTRoom1Activ and write AV246 MBT_Room1. Alarms flag BMS room and outdoor values that are out of range.
