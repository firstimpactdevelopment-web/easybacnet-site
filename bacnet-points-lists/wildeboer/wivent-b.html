Short answer

The WiVent-B is a decentralised facade ventilation unit for classrooms and offices. Its Beckhoff CX9020 controller runs TwinCAT BACnet over BACnet IP and publishes a schedule and holiday calendar, command switches and push buttons as Binary Values, status and alarm flags as Binary Inputs, airflow and temperature settings as Analog Values, measurements for the master and up to five slave units as Analog Inputs, and operating mode, faults and warnings as multi-state objects.

BMS integration notes: Wildeboer WiVent-B decentralised ventilation unit, BACnet IP

Integration in brief

Command the operating mode with MSV 400 (or let the internal schedule run), keep the watchdog alive if it is enabled, and read the operating mode status, room temperature, CO2 and the fault and warning flags.

Enable & remote start

MSV 400 sets the operating mode; BV 204 (external release) and BV 205 (external fault shutdown) put the unit into protection mode.

Heartbeat & communication loss

BV 200 enables a connection watchdog; BV 201 is the watchdog pulse and must change faster than every 10 s. The document does not say what the unit does when the pulse stops.

Network setup

  • BACnet IP on the Beckhoff CX9020 (TwinCAT BACnet, vendor ID 415); the PICS also lists MS/TP via an EL6861 terminal.
  • The full set of objects for a given installation is defined in its EDE files.

Watch out for

  • Filter test, filter drying, presence and fault acknowledge are push-button Binary Values; write active, not a held state.
  • State texts of the multi-states are German.

How many BACnet points does the Wildeboer WiVent-B decentralised ventilation unit, BACnet IP have?

Which Wildeboer WiVent-B decentralised ventilation unit, BACnet IP BACnet points are writable?

39 of the 115 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

What are the minimum BACnet points to integrate the Wildeboer WiVent-B decentralised ventilation unit, BACnet IP?

Start with MV 400 WiVent_Betriebsart (Operating mode command); BV 201 WiVent_Takt_Watchdog (Watchdog pulse, toggle faster than every 10 s); BV 209 WiVent_Externe_Fehlerquittierung (Fault acknowledge); MI 450 WiVent_Betriebsart_Status (Current operating mode); AI 352 WiVent_Temperatur_IDA (Room temperature, °C); AI 353 WiVent_Luftqualität_IDA (Room CO2, ppm); AI 355 WiVent_Temperatur_SUP_Master (Supply air temperature, °C); BI 262 WiVent_Störung_1 (Master fault); BI 260 WiVent_Warnung_1B (Warning with unit shutdown); MV 460 WiVent_Warnung_System (System warning code (filters, schedule)).

How do I enable BMS control of the Wildeboer WiVent-B decentralised ventilation unit, BACnet IP?

MSV 400 sets the operating mode; BV 204 (external release) and BV 205 (external fault shutdown) put the unit into protection mode.

Does the Wildeboer WiVent-B decentralised ventilation unit, BACnet IP need a BACnet heartbeat or have a communication timeout?

BV 200 enables a connection watchdog; BV 201 is the watchdog pulse and must change faster than every 10 s. The document does not say what the unit does when the pulse stops.
