Short answer

The -E4 version of the WattsOn-Mark II serves its metering data over BACnet IP from an Ethernet or Wi-Fi module. Metering objects use the Modbus register offset as the instance: totals and per-phase power, voltage, current, power factor and angles, plus energy registers by quadrant. Writable Analog Values set CT/PT ratios, demand window, relay alarms and energy reset; the 70000/80000 ranges show network status and settings.

BMS integration notes: Elkor WattsOn-Mark II -E4 power meter (BACnet IP)

Integration in brief

Set the CT and PT ratios (AV 1280-1295) to match the installation, then read total kW, kWh import, demand, power factor, average current and voltage. Energy totals are zeroed by writing 42405 to Reset_Energy.

Network setup

  • BACnet port, device instance (-1 = derived from the MAC), APDU size, segmentation and BBMD foreign registration are set in the web interface; objects 80070-80078 (CSV and BI) show the values.
  • Ethernet or Wi-Fi can be static or DHCP; the active link and IP show at MI 70000 and CSV 70000-70006.
  • Set CT_Primary/Secondary_All and PT_Primary/Secondary_All (or the per-phase AVs) before trusting readings.

Watch out for

  • Reset_Energy only acts on the value 42405 (0xA5A5); Reboot_Device only on 43605 (0xAA55).
  • With the meter locked (BV 1321), settings writes need the passcode entered at PIV 1319.
  • kVAR/kVA unit text in the source table is swapped; trust the unit codes.

Integration notes

  • Metering, configuration and relay objects use the Modbus register offset as the instance number (0-65535); network status is at 70000-79999 and network settings at 80000-89999.
  • The unit text for kVAR and kVA is swapped in the table (kVAR objects say kilovolt-amperes, kVA objects say kilovolt-amperes-reactive), and kVAh_Import/Export_A-C say kilowatt-hours; units here follow the printed BACnet unit codes (12 = kvar, 9 = kVA, 240 = kVAh).
  • The 6 Structured View objects (SV 0-5) are not listed here. The network status rows are typed 'CS' in the table and are listed as CharacterString Values.
  • Input_Config (CT type: 1 mA, 2 mV, 3 5 A, 4 Rogowski, 0 custom) is printed with no instance number and is left out.
  • Network settings (80000 range) are read-only over BACnet and are changed in the web interface.
  • MSI 70000, CSV 70000 and DTV 70000 share the instance number but are different object types.

Questions about the Elkor WattsOn-Mark II -E4 power meter (BACnet IP)

How many BACnet points does the Elkor WattsOn-Mark II -E4 power meter (BACnet IP) have?

This list has 210 BACnet objects: 84 analog inputs, 34 analog values, 11 binary inputs, 2 binary values, 1 file, 3 multi-state inputs, 6 multi-state values, 67 characterstring values, 1 datetime value, 1 positive integer value. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Elkor WattsOn-Mark II -E4 power meter (BACnet IP) BACnet points are writable?

43 of the 210 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
