Elkor WattsOn-MCM modular multi-circuit meter (BACnet IP) BACnet points list

Updated 6 November 2026

Short answer

The WattsOn-MCM serves up to 60 metered channels (20 cards x 3) over BACnet IP. Fixed objects give network status, fault bitstrings, read-only settings, the MCM-V voltages, PT ratios, angles and frequency. Card data (per-card info and per-channel current, power, PF, energy) comes in groups that start at 131072; this list gives the first object of each group and the formula for the rest. Everything is read-only over BACnet.

This page lists 124 BACnet objects for the Elkor WattsOn-MCM modular multi-circuit meter (BACnet IP) — 0 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Elkor’s own free documentation, linked below.

BMS integration notes: Elkor WattsOn-MCM modular multi-circuit meter (BACnet IP)

Integration in brief

Set up cards, CT ratios and voltage mapping in the web interface; the BMS only reads. Map per-channel power (P11), net energy (P13) and current (P10) from the card groups using the instance formula, plus the MCM-V voltages and frequency and the fault_code bitstring.

Network setup

  • BACnet port, device instance, APDU size, segmentation and BBMD foreign registration are set in the web interface; objects 3070-3078 (CSV and BI) show the values.
  • Device instance -1 means it is generated from the MAC address.
  • Ethernet or Wi-Fi, static or DHCP (MI 3202 / MI 3203).

Watch out for

  • Channel objects only appear for fitted cards; a polled object can vanish if a card is removed.
  • Channel number, not card number, drives the per-channel offset: channel = (card - 1) x 3 + phase (A=1, B=2, C=3).
  • P14/P15 unit codes are printed swapped in the source table.

Integration notes

  • Card parameter objects: instance = 131072 + (Parameter ID - 1) x 256 + (card number - 1) for per-card groups, or + (channel number - 1) for per-channel groups (channels 1-60; channel 4 = card 2 phase A). Only the first object of each group is listed, with the template name as printed.
  • Card objects exist only when a card is fitted in that slot and supports the parameter; a full system has over 1,000 objects. P14, P15, P23 and P24 are only on some card models.
  • P14 (reactive power) is printed with unit code 9 and P15 (apparent power) with code 12; in BACnet those codes mean kVA and kvar, the reverse of the printed unit names. Units here follow the names (kvar, kVA).
  • fault_code, card_fault, voltage_fault, missing_fault, cards_present and P18 Chan Cfg are BitString Value objects (listed as type Other). Network status rows are typed 'CS' in the table and listed as CharacterString Values.
  • Up to 100 user-defined AIs (instances 0-99) can be created in the web interface; they are not listed. The Structured View objects are also left out.
  • All settings are read-only over BACnet and are changed in the web interface (System > Advanced Configuration).
