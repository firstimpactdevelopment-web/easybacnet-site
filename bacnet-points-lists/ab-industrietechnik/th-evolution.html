Updated 12 November 2026

Short answer

TH Evolution is a wall-mounted room controller for 2- and 4-pipe fan coils (3-speed or EC fans) with relays, 0-10 V outputs and inputs for remote sensors and contacts. The BACnet MS/TP version exposes sensor readings as Analog Inputs, output values, setpoints, offsets and tuning as Analog Values, input and relay states as Binary Inputs and Values, and regulation type, input functions, fan speed mode and display options as Multi-State Values.

BMS integration notes: AB Industrietechnik TH Evolution room thermostat / fan coil controller, BACnet MS/TP

Integration in brief

Set the device ID with parameters I62/I63 and the MS/TP address, then switch the unit with BV 2189, choose fan speed mode and occupancy settings, and adjust the heating/cooling setpoints. Read room temperature, the working setpoint and relay states.

Enable & remote start

BV 2189 ON_OFF_MANUAL switches the controller on or off.

Network setup

  • BACnet device ID = I63 x 10000 + I62, set from the parameter menu.
  • MS/TP master or slave at 9600, 19200, 38400 or 76800 baud (PICS).

Watch out for

  • Use the setpoint AV that matches the regulation type: 2138/2139 for non 4-pipe, 2140 for 4-pipe.
  • Out-of-scale 0-10 V input reads 32000 (or 3200) on INPUT_AI3.

Integration notes

  • Names are printed with "(Note n)" markers that point to rounding and working-setpoint notes; the markers are dropped here.
  • Temperature units follow BV 2176 UNIT_C_F; written temperatures are rounded to 0.5 °C or 0.2 °F steps.
  • AV 3016 WORKING_SET is calculated from the setpoint parameters and is forced to fixed values (for example 70.0 °C) on antifreeze or sensor alarm.
  • BV 2129, 2130 and 2176 print two value texts (EC / 3-SPEED, STANDARD / WITH AUX RELAY, CELCIUS / FARENHEIT) without saying which is active.
  • Regulation type abbreviations: H=heating, C=cooling, R=electric heater, c/o=season changeover, auto=water sensor, rem.=remote contact, par.=parameter.

Questions about the AB Industrietechnik TH Evolution room thermostat / fan coil controller, BACnet MS/TP

How many BACnet points does the AB Industrietechnik TH Evolution room thermostat / fan coil controller, BACnet MS/TP have?

This list has 92 BACnet objects: 5 analog inputs, 47 analog values, 5 binary inputs, 16 binary values, 19 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AB Industrietechnik TH Evolution room thermostat / fan coil controller, BACnet MS/TP BACnet points are writable?

71 of the 92 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
