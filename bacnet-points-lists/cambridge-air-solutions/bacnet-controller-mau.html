Cambridge Air Solutions BACnet Controller - MAU BACnet points list

Updated 28 October 2026

Short answer

Cambridge's BACnet Controller is a BTL-listed, programmable MS/TP controller mounted in the heater that runs the fan and burner and gives a BAS access to its points. The object list is mostly multistate values (statuses, commands, HOA, modes, alarms) and analog values (temperatures, setpoints, delays, runtimes), with four binary values for runtime/cycle-count resets. Operating mode (unit heat, make-up air, make-up air with reset, summer vent, off) is selected with the Normal and Override Mode MVs.

This page lists 77 BACnet objects for the Cambridge Air Solutions BACnet Controller - MAU — 42 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Cambridge Air Solutions’s own free documentation, linked below.

BMS integration notes: Cambridge Air Solutions BACnet Controller - MAU

Integration in brief

Enable the unit with MV-3011 Unit Enable Mode, choose the operating mode with MV-50052 Normal Mode (MV-50053 Override Mode for the alternate mode) and command occupancy with MV-3021 Occupancy Override or the controller's own schedule. Adjust the zone and discharge setpoints, read MV-3001 Unit Status, the burner/fan status MVs and the fault MVs, and reset faults with MV-50058. The controller runs stand-alone on its defaults (unit heater mode, 160°F discharge, 65°F zone) if the network is lost, provided a zone sensor is connected.

Enable & remote start

MV-3011 Unit Enable Mode (1=Shutdown, 2=Enable). Fan and burner Hand/Off/Auto overrides are MV-50050 Supply Fan HOA and MV-11 Burner HOA; leave them in Auto (3) for normal control.

Sensors & values from the BMS

Network values can replace the wired sensors: AV-3038 Network Override Outdoor Air Temperature and AV-3045 Network Override Zone Temperature. MV-50064 ZN-T Remote Setpoint Enable selects no remote setpoint, hardware only, network only, or network with hardware backup. The manual gives no timeout for these.

Network setup

  • MS/TP only, up to 76.8 kbaud; MAC address 4-127 (default 4), set from the local display (Controller > Network) or a MAP gateway (AV-3003).
  • Baud rate defaults to Auto (follows the bus supervisor); the manual suggests 38400 when used with a Smart Building Hub.
  • Device Object ID (AV-3004) must be unique; BACnet Encoding Type must match the rest of the network.
  • Disconnect from the bus while changing network settings and cycle power afterwards.
  • An EOL terminator is needed when the controller is at either end of the MS/TP trunk.

Watch out for

  • The heating lockout (AV-3010) stops the burner whenever outdoor temperature is above it, even with a heating call.
  • In summer vent mode with SF Bypass = No, the fan will not run if outdoor temperature is above zone temperature.
  • Continuous Fan Operation in Occupied (MV-50065) decides whether the fan keeps running when the zone is satisfied in the reset & on/off mode.
  • Some faults also need a reset from the local display (Commissioning > Overrides > Unit Reset) or MV-50058.

Integration notes

  • Optional points (mode switch, filter status/pressure, supply fan output and speed) exist only on units with those options.
  • Rows from the input/output tables point to the same MV/AV objects as the value tables; hardware terminal numbers are kept in the description.
  • The input/output tables show binary states as 0/1 while the MV table shows the same objects as 1/2; both are kept as printed.
  • MV-50052/50053/50054 share one mode state list in the source (merged cell).
  • Temperatures in °F by default (MV-3006 selects IP/SI); filter pressure in in. w.c.

Questions about the Cambridge Air Solutions BACnet Controller - MAU

How many BACnet points does the Cambridge Air Solutions BACnet Controller - MAU have?

This list has 77 BACnet objects: 39 analog values, 4 binary values, 34 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Cambridge Air Solutions BACnet Controller - MAU BACnet points are writable?

42 of the 77 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Cambridge Air Solutions BACnet Controller - MAU BACnet documentation?

The source is Operating Instructions - BACnet Controller - MAU (BACnet Controller MAU Technical Manual) (Version 4.0.3.0012), revision 2022-11-30, published free by Cambridge Air Solutions at https://www.cambridge-eng.com/Portals/0/Operating%20Instructions%20v4_0_3_0012.pdf.

What are the minimum BACnet points to integrate the Cambridge Air Solutions BACnet Controller - MAU?

Start with MV 3011 Unit Enable Mode (Shutdown / enable); MV 3021 Occupancy Override (Occupied / unoccupied / standby from the BAS); MV 50052 Normal Mode (Unit heat, make-up air, summer vent or off); AV 3037 Discharge Air Set Point – Makeup Air Mode (Discharge setpoint in make-up air mode); AV 3017 Occupied Zone Heating Set Point (Zone temp the burner heats to when occupied); MV 50058 Reset Unit Fault (Network fault reset); MV 3001 Unit Status (Heating / satisfied / cooling / sensor unreliable); AV 3011 Effective Discharge Air Temperature (Supply air temp leaving the unit, °F); MV 3018 Burner Status (Burner proven on); MV 50056 Burner Fault (Burner alarm).

How do I enable BMS control of the Cambridge Air Solutions BACnet Controller - MAU?

MV-3011 Unit Enable Mode (1=Shutdown, 2=Enable). Fan and burner Hand/Off/Auto overrides are MV-50050 Supply Fan HOA and MV-11 Burner HOA; leave them in Auto (3) for normal control.
