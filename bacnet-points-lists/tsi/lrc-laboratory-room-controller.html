TSI Laboratory Room Controller (LRC) BACnet points list

Updated 6 November 2026

Short answer

The TSI LRC controls a lab room by tracking supply, general exhaust and fume hood flows to hold an airflow offset and room pressure, with per-supply temperature control. Its BACnet object set is almost entirely Analog, Binary and Multi-state Values: setup values (flow ranges, setpoints, alarm limits, sensor calibration) plus live flows, temperatures, room pressure and alarm states. The list is long because every supply, exhaust and hood channel has its own block.

This page lists 1714 BACnet objects for the TSI Laboratory Room Controller (LRC) — 1251 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from TSI’s own free documentation, linked below.

BMS integration notes: TSI Laboratory Room Controller (LRC)

Integration in brief

Read room pressure, total supply and exhaust flow, the controller flow mode and the alarm status MVs. The BMS can set occupancy per supply (BV 24-27), trigger emergency or shutdown mode (BV 22/23) and change the room pressure setpoint (AV 268). TSI suggests picking only the points you need instead of auto-discovering the whole set.

Enable & remote start

No separate BMS enable is described. Occupancy per supply (BV 24-27, BV 297/298 for supplies 5-6), Emergency Mode (BV 22) and Shutdown Mode (BV 23) are writable and switch the controller between its occupied, unoccupied, emergency and shutdown flow setpoints.

Network setup

  • BACnet MS/TP runs at 9600, 19200, 38400 or 76800 baud; the end-of-line resistors on the LRC00 are DIP switches, off by default.
  • BACnet IP uses the two RJ-45 ports. TSI says the Ethernet IP is dynamic (DHCP) by default, but a new controller loaded with its initial file comes up at static 192.168.200.90 (set a laptop to 192.168.200.1 to reach it); change it in the controller web interface.
  • The PICS lists the LRC as a BACnet Building Controller (B-BC).

Watch out for

  • TSI warns that writing values can upset room control; leave objects marked DO NOT OVERWRITE (live readings, calibration and calculated values) alone.
  • Most objects are commissioning settings (flow ranges, K-factors, calibration, PID tuning); do not write them cyclically.
  • Auto-discovery of the full object set takes a long time; map only the points you need.
  • Units differ between the LRC00, LRC00-LPS and LRC00-CMH versions.

Questions about the TSI Laboratory Room Controller (LRC)

How many BACnet points does the TSI Laboratory Room Controller (LRC) have?

This list has 1714 BACnet objects: 1212 analog values, 308 binary values, 194 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which TSI Laboratory Room Controller (LRC) BACnet points are writable?

1251 of the 1714 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official TSI Laboratory Room Controller (LRC) BACnet documentation?

The source is Laboratory Room Controller Model LRC Operation and Service Manual (P/N 6013156), revision Revision E, December 2021, published free by TSI at https://tsi.com/getmedia/76e6ed5c-8c9c-407c-a413-5aa72c00268b/LRC_Lab_Room_Controller_Op_Svc_Mnl_6013156E-web?ext=.pdf.

What are the minimum BACnet points to integrate the TSI Laboratory Room Controller (LRC)?

Start with BV 24 Supply 1 Occupancy Mode (Supply 1 occupancy: 0 = occupied, 1 = unoccupied); BV 22 Emergency Mode (Emergency mode: 1 = active); AV 268 Room Pressure Setpoint (Room pressure setpoint, in. W.C); MV 91 Current Controller Flow Mode (Standard, Emergency, Shutdown or Balancer); AV 697 Room Pressure (Measured room pressure, in. W.C); AV 660 Current Total Supply Flow (Total supply airflow, CFM); AV 661 Current Total Exhaust Flow (Total exhaust airflow, CFM); AV 689 Supply 1 Room Temp (Supply 1 zone room temperature); MV 86 Current Room Pressure Alarm Status (1 = normal, 2 = low alarm, 3 = high alarm); MV 76 Current Supply 1 Flow Alarm Status (Supply 1 flow: 1 = normal, 2 = low, 3 = high alarm).

How do I enable BMS control of the TSI Laboratory Room Controller (LRC)?

No separate BMS enable is described. Occupancy per supply (BV 24-27, BV 297/298 for supplies 5-6), Emergency Mode (BV 22) and Shutdown Mode (BV 23) are writable and switch the controller between its occupied, unoccupied, emergency and shutdown flow setpoints.
