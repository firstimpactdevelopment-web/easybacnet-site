ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems) BACnet points list

Updated 12 November 2026

Short answer

The GW100K translates the Modbus RTU data of up to ten ActronAir ICUNO-MOD cards to BACnet IP, BACnet MS/TP or Modbus TCP. Each system gets the same 121-point block (on/off, mode, setpoint, fan, economiser, zones, temperatures, compressor data, alarms, error codes); this list shows system 1 plus the 24 shared gateway I/O points (Device 11).

This page lists 145 BACnet objects for the ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems) — 65 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from ActronAir’s own free documentation, linked below.

BMS integration notes: ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems)

Integration in brief

Turn the system on with D101, choose the mode with I103 and the setpoint with A101, and the fan with I101. Read room temperature, running capacity, compressor status and the alarm and error code points.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

Capacity demand (A131), supply fan speed demand (A132) and heat request (D106) only work in Advanced BMS mode; I110 reports the BMS demand mode (0 none, 1 basic, 2 advanced).

Network setup

  • Up to 10 ICUNO-MOD systems per gateway; protocol (BACnet IP, BACnet MS/TP or Modbus TCP) is chosen on the gateway.
  • BMS configuration details are in the ICUNO-MOD and system manuals, not in the register table.

Watch out for

  • Each system's points have their own instance blocks; map system 2-10 from their own sheets rather than adding a fixed offset.

Integration notes

  • Points are system (Device) 1 from the register table; systems 2-10 repeat the same 121 points with object names A2xx/D2xx/I2xx ... A10xx and their own instances (see sheets Device 2-10 in the XLSX).
  • Instances do not follow one offset: from system 1 to system 2, writable AVs/IVs move +35 (some writable AVs +36), read-only AVs/IVs +42, writable BVs +27 and read-only BVs +23. The table also prints system 10's A1010 at instance 526, out of sequence.
  • Device 11 points (A11xx, D11xx) are the gateway's own universal I/O and relays, shared by all systems.
  • Points marked Advanced BMS mode only (A131, A132, D106) need the ICUNO-MOD in Advanced BMS mode (I110 shows the mode).
  • Error codes (I116-I121) are listed in ActronAir document 9590-0000-05.

Questions about the ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems)

How many BACnet points does the ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems) have?

This list has 145 BACnet objects: 51 analog values, 61 binary values, 33 integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems) BACnet points are writable?

65 of the 145 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems) BACnet documentation?

The source is BMS Gateway Controller GW100K - BMS Register Table (9590-3038-03 V1.0.1), published free by ActronAir at https://actronair.com.au/wp-content/uploads/2025/03/9590-3038-03-BMS-Gateway-Register-Table.xlsx.

What are the minimum BACnet points to integrate the ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems)?

Start with BV 1 D101 (AC on/off (1 = on)); IV 542 I103 (Mode: heat, cool, auto, fan only); AV 517 A101 (Master setpoint, 16-30 °C); IV 540 I101 (Supply fan: low, medium, high, auto); AV 869 A115 (Room temperature); AV 885 A135 (Running capacity, %); BV 286 D125 (Compressor 1 running); BV 276 D115 (Alarm output); IV 897 I116 (Current error code); BV 282 D121 (No comms with indoor unit).

How do I enable BMS control of the ActronAir GW100K BMS Gateway Controller (ICUNO-MOD systems)?

Capacity demand (A131), supply fan speed demand (A132) and heat request (D106) only work in Advanced BMS mode; I110 reports the BMS demand mode (0 none, 1 basic, 2 advanced).
