Short answer

The hydrovar X HVX / HVX+ drive mounts on the pump motor and has BACnet MS/TP built in. Analog Inputs give the last ten errors with their logged operating data, actual pressure, flow, temperature and level, speed, current, power, voltages, temperatures, I/O status and firmware versions; Analog Values carry start/stop, error reset and the full drive parameter set (control mode, setpoints, ramps, limits, sensor scaling, multipump and communication settings). Three CharacterString values hold part and serial numbers.

BMS integration notes: Xylem Lowara hydrovar X HVX / HVX+ pump drive (BACnet MS/TP)

Integration in brief

Start and stop the pump with AV 0 and reset errors with AV 1. Choose the control mode (AV 3) and write the active setpoint; read pump status (AI 211), actual pressure (AI 205), motor speed (AI 215/216), power and the most recent error (AI 0).

Enable & remote start

AV 0 SET_STARTSTOP starts (1) and stops (0) the pump.

Network setup

  • Factory device instance 84003 (P08.2.04 or Object_Identifier); MAC address 1 (P08.2.01); MS/TP settings are AV 142-148.
  • Wire RS-485 to terminals 31 (B), 32 (A) and 33 (C).

Watch out for

  • Set P04.1.60 Limit Setpoint Saving (AV 163) to Yes before writing setpoints cyclically, to spare the EEPROM.
  • Bitfield objects (error, alarm, status) must be split into bits; the meanings are in the manual.

Integration notes

  • The tables have no read/write column; Analog Values (parameters and commands) are taken as writable and Analog Inputs as read-only.
  • Many units follow unit-selection parameters (P04.0.11 pressure, P04.0.12 flow, P04.0.13 temperature, P04.0.14 level, P04.0.15 power, P04.0.16 energy); the description names the parameter.
  • Objects marked "HVX+ only" (menu index flagged [X+]) exist only on the HVX+.
  • The manual prints AI 73-90 twice around the page 75/76 break (the repeat names AI 77 "Log: Motor load"); each is listed once. AV 41-44, 64, 88-89 and 126-127 are not in the table.
  • Error log objects (AI 0-199) repeat in blocks of 20 for errors 1-10; names carry the error number.
  • Set P04.1.60 Limit Setpoint Saving to Yes when setpoints are written often, to spare the EEPROM.
