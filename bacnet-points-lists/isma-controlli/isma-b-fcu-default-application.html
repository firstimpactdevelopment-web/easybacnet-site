iSMA CONTROLLI iSMA-B-FCU fan coil controller (default application) BACnet points list

Updated 12 November 2026Unofficial source?

Short answer

The iSMA-B-FCU ships with a ready-made fan coil application (2- or 4-pipe, digital or analog valve control, 3-speed or analog fan) that exposes a fixed set of BACnet Analog Value and Binary Value objects, the same data as its Modbus registers. The BMS can set occupancy mode, setpoint, fan mode and FCU mode, write the room temperature, and read the effective setpoint, valve and fan outputs and sensor values. Up to five slave FCUs can follow one master over BACnet.

This page lists 119 BACnet objects for the iSMA CONTROLLI iSMA-B-FCU fan coil controller (default application) — 86 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of iSMA CONTROLLI’s documentation hosted by Innon (iSMA distributor), not by iSMA CONTROLLI itself, so treat it as unofficial.

BMS integration notes: iSMA CONTROLLI iSMA-B-FCU fan coil controller (default application)

Integration in brief

Use the default application as shipped: write Occupancy_Mode, Setpoint, Fan_Mode and FCU_Mode from the BMS, and read Effective Setpoint, Occupancy Status, Fan Status and the valve outputs. If the room temperature comes from the BMS, write it to Net_Temperature. Only the master FCU of a group should be controlled from the BMS; slaves follow it.

Sensors & values from the BMS

Net_Temperature (AV 6) takes a room temperature from the network as the control value source.

Network setup

  • The MS/TP MAC address is set on the DIP switches (binary weights).
  • Device instance = 826 followed by the 3-digit MAC address (MAC 83 gives 826083).
  • For master/slave rooms, give slaves the BACnet device IDs from the auto-binding table, or set Remote_SlaveN_Device_ID and Local_Remote_Auto_Binding.
  • Only the master works with the room panel and the BMS; up to 5 slaves follow it.

Watch out for

  • Manual override objects (valve/fan manual value plus the matching enable BV) take outputs out of automatic control.
  • Check value scaling: the table defaults look like tenths (210 = 21.0 °C).

Integration notes

  • The manual lists App_status (application diagnostics) as BACnet Device object property 5002, not as an object; it is left out here.
  • Default values in the table look scaled x10 (Setpoint 210 for 21.0 °C; Fan_Scale default 30 while the text says 3 °C). Check whether the live BACnet values are scaled before writing.
  • AV 29 is printed wrapped as 'Second_Stage_Diff / Binary'; it is listed as Second_Stage_Diff_Binary to match AV 31 Second_Stage_Diff_Analog.
  • Names are kept as printed, including spelling slips (Coolling_Valve, Visable, Occuapancy, Conntact) and the few names printed with spaces.
  • The MAC address is set with DIP switches; master/slave grouping works only over BACnet.

Questions about the iSMA CONTROLLI iSMA-B-FCU fan coil controller (default application)

How many BACnet points does the iSMA CONTROLLI iSMA-B-FCU fan coil controller (default application) have?

This list has 119 BACnet objects: 72 analog values, 47 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which iSMA CONTROLLI iSMA-B-FCU fan coil controller (default application) BACnet points are writable?

86 of the 119 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the iSMA CONTROLLI iSMA-B-FCU fan coil controller (default application)?

Start with AV 0 Occupancy_Mode (0 unoccupied, 1 occupied, 2 standby); AV 4 FCU_Mode (0 off, 1 auto, 2 heat, 3 cool, 4 fan only); AV 3 Fan_Mode (0 off, 1-3 manual speed, 4 auto); AV 1 Setpoint (Room temperature setpoint); AV 100 Effective Setpoint (Setpoint in use after offsets); AV 101 Occupancy Status (0 unocc, 1 occ, 2 standby, 3 forced occupied); AV 102 Fan Status (0 off, 1-3 manual speed, 4-6 auto speed); AV 104 Cv (Room temperature used for control); AV 110 Heating_Valve (Heating valve output, %); AV 111 Coolling_Valve (Cooling valve output, %).
