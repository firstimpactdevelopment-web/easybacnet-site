Short answer

A FieldServer ProtoNode reads the GDA-1600 over Modbus and serves 300 read-only Analog Inputs: per-channel tag, units and value text blocks, numeric channel values and readings, channel status and sensor life, plus alarm, fault, call and LED status objects that each cover all 16 channels, and the relay status.

This page lists 300 BACnet objects for the Bacharach GDA-1600 gas detection controller (ProtoNode BACnet Protocol Converter Kit) — 0 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of Bacharach’s documentation hosted by Internet Archive (copy of mybacharach.com), not by Bacharach itself, so treat it as unofficial.

BMS integration notes: Bacharach GDA-1600 gas detection controller (ProtoNode BACnet Protocol Converter Kit)

Integration in brief

Read the channel readings for the channels in use, the per-channel status and the packed alarm and fault words; the text blocks are only needed for display.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • ProtoNode default IP address 192.168.1.24, subnet 255.255.255.0.

Watch out for

  • Each 1-16 status object covers all channels; the guide does not give the encoding, so check it on site.
  • Text blocks (tag, units, ASCII value) are split across several AIs.

Integration notes

  • Objects 1-224 carry text: each channel tag spans 8 objects, each units string and ASCII value 3 objects. The guide prints one name per block, so every object in a block shares that name.
  • The guide gives no units or scaling for Channel Value and Channel Reading.
  • Each '1-16' object reports all 16 channels in one value; the guide does not say how it is encoded.
  • All objects are read-only; the kit offers no writes.
  • The kit manual only gives the ProtoNode IP settings; it does not cover BACnet MS/TP.
