Short answer

The VFD-CP2000 has BACnet MS/TP built in on its RS-485 port and acts as a B-ASC. The object list is fixed: 27 commandable AVs (frequency reference and 16 user-mapped parameter slots), 42 read-only status AVs, 16 commandable command BVs and 16 read-only status BVs. Many instances are reserved and carry no data.

BMS integration notes: Delta Electronics VFD-CP2000 (embedded BACnet MS/TP)

Integration in brief

Write the frequency reference to AV 1 (Hz), switch the output on with BV 7 and set BV 0 to 1 so the frequency command follows AV 1. Read BV 23, AV 31, AV 44 and AV 49 for output state, frequency, current and power, BV 19 and AV 43 for faults, and reset with BV 15.

Network setup

  • BACnet MS/TP master; baud rate 9600, 19200, 38400 or 76800.
  • The device object's instance and name are writable over BACnet.
  • Segmentation is not supported; services are ReadProperty, ReadPropertyMultiple and WriteProperty.

Watch out for

  • The PICS does not say which drive parameters make BACnet the command and frequency source; check the CP2000 user manual.
  • BV 3 HALT, BV 4 LOCK and BV 6 QSTOP act while set to 1; 0 means no action.
  • Only AV 0-26 and BV 0-15 have a priority array and relinquish default; the status objects do not.
  • AV 11-26 change whatever parameter P9-11 to P9-26 point at; check the mapping before writing.

Integration notes

  • The document marks AV 0-26 and BV 0-15 RW and says they are commandable (priority array); they are listed here as C.
  • Reserved objects are kept because they are in the object list; they carry no data.
  • AV 11-26 write the drive parameters selected in P9-11 to P9-26; their units depend on the mapped parameter.
  • AV 39 packs the BV 16-31 status bits into one word.
  • Names kept as printed, including the 'SerovPower' spelling of BV 23.
  • Some printed units look wrong: AV 48 power angle is in power factor, AV 59 energy is in kW.

Questions about the Delta Electronics VFD-CP2000 (embedded BACnet MS/TP)

How many BACnet points does the Delta Electronics VFD-CP2000 (embedded BACnet MS/TP) have?

This list has 101 BACnet objects: 69 analog values, 32 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Delta Electronics VFD-CP2000 (embedded BACnet MS/TP) BACnet points are writable?

43 of the 101 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Delta Electronics VFD-CP2000 (embedded BACnet MS/TP) BACnet documentation?

The source is BACnet Protocol Implementation Conformance Statement, VFD-CP2000, revision 2014-07-24, published free by Delta Electronics at https://www.bacnetinternational.net/catalog/manu/delta%20electronics,%20inc./VFDCP2000_BACnet_PICS_20140724.pdf.

What are the minimum BACnet points to integrate the Delta Electronics VFD-CP2000 (embedded BACnet MS/TP)?

Start with BV 7 BV_007_ServoPower CMD (Output on/off (0 = coast to stop)); BV 0 BV_000_ACTIVE CMD (Frequency command: 1 = follow AV 1, 0 = 0 Hz); AV 1 AV_001_FreqRefValue (Frequency reference in Hz); BV 15 BV_015_RESET (Reset a tripped drive); BV 23 BV_023_SerovPower STATE (Output power on/off status); AV 31 AV_031_Output frequency (Output frequency in Hz); AV 44 AV_044_Output current (Motor amps); AV 49 AV_049_Output Power (Drive power in kW); BV 19 BV_019_ERROR STATE (Any active drive fault); AV 43 AV_043_Error code (Which fault is active).
