Short answer

The SAUTER ASV3 is a compact VAV controller: damper actuator, differential pressure sensor and airflow/temperature control in one unit, with BACnet MS/TP. Its object list exposes the hardware I/O, airflow and temperature setpoints and limits, PID tuning, room-unit (HMI) display settings, occupancy and cool/heat mode, plus many internal calculation objects.

BMS integration notes: SAUTER ASV3 VAV Compact Controller (ASV305BF7xxxW)

Integration in brief

Command occupancy (BV 1) and cool/heat mode (BV 2), set the cooling and heating setpoints (AV 33, AV 37) or the airflow limits, and read the current airflow, damper position and room temperature. Damper and airflow overrides (BV 5 with AV 6, BV 6 with AV 12) are available for balancing.

Enable & remote start

Occupancy is BV 1 (VAV box Occupied/unoccupied); Cool/Heat mode is BV 2. Overrides: Override airflow control (BV 5) with Forced airflow control (AV 6), Damper override (BV 6) with AV 12.

Network setup

  • BACnet MS/TP: MAC address on DIP switch SW8 (switches 1-7, binary); baud on SW4 S1/S2: 9600 (off/off), 19200 (on/off), 38400 (off/on), 76800 (on/on).
  • SW4 S3 is the MS/TP end-of-line terminating resistor (factory off).
  • Device instance is set from the BMS, the PC tool or an EY-RU305F700xW room unit; AV 0 shows it (default 1000, the PC tool value must be divided by 10).
  • Sauter suggests no more than 22 controllers per MS/TP segment.

Watch out for

  • Many objects, mostly from AV 57 and BV 46 upward, are marked Internal use or Arithmetic Operation (calculation buffers); do not write them.
  • Airflow units follow Airflow display unit select (AV 29).
  • Cooling and heating airflow limits (AV 7-10) and setpoint limits are stored settings; do not write them cyclically.

Questions about the SAUTER ASV3 VAV Compact Controller (ASV305BF7xxxW)

How many BACnet points does the SAUTER ASV3 VAV Compact Controller (ASV305BF7xxxW) have?

This list has 247 BACnet objects: 6 analog inputs, 2 analog outputs, 112 analog values, 2 binary inputs, 4 binary outputs, 121 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which SAUTER ASV3 VAV Compact Controller (ASV305BF7xxxW) BACnet points are writable?

79 of the 247 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official SAUTER ASV3 VAV Compact Controller (ASV305BF7xxxW) BACnet documentation?

The source is Manual SAUTER ASV3, published free by SAUTER at https://www.sauter-controls.com/wp-content/uploads/2021/08/Manual-SAUTER-ASV3.pdf.

What are the minimum BACnet points to integrate the SAUTER ASV3 VAV Compact Controller (ASV305BF7xxxW)?

Start with BV 1 VAV box Occupied/ unoccupied (Occupied/unoccupied: 1 = occupied); BV 2 Cool/Heat mode (0 = cooling, 1 = heating); AV 33 Cooling setpoint (Room cooling setpoint); AV 37 Heating set point (Room heating setpoint); AV 4 Current VAV airflow (Measured VAV airflow); AV 5 VAV demand airflow (Airflow demand); AV 61 Current VAV position feedback (0- 100) (Damper position feedback, 0-100 %); AV 23 HMI Temperature sensor (Room temperature from the HMI room unit); BV 10 No Airflow in main duct (Duct airflow alarm, 1 = no airflow).

How do I enable BMS control of the SAUTER ASV3 VAV Compact Controller (ASV305BF7xxxW)?

Occupancy is BV 1 (VAV box Occupied/unoccupied); Cool/Heat mode is BV 2. Overrides: Override airflow control (BV 5) with Forced airflow control (AV 6), Damper override (BV 6) with AV 12.
