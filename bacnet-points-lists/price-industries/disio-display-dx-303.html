Short answer

Disio Display is Price's room display/controller. In sequence DX-303 it exposes 66 BACnet MS/TP objects (its outputs are named Output 1 - Analog Fan, Output 3 - Cooling Valve, Output 4 - Binary Fan, Output 2 - Heating Valve), plus setpoints, loop settings, occupancy, units and network settings. The object list changes with the sequence loaded.

This page lists 66 BACnet objects for the Price Industries Disio Display DX-303 sequence — 61 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Price Industries’s own free documentation, linked below.

BMS integration notes: Price Industries Disio Display DX-303 sequence

Integration in brief

Write MV Occupancy and the room setpoint from the BMS, and read the room temperature, occupancy source and loop loads. AV 1 MAC Address and MV Baud Rate hold the network settings.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • MAC address is AV 1 (default 2); baud rate is the Baud Rate MV (0=9600, 1=19200, 2=38400, 3=76800).

Watch out for

  • Many objects are marked as retained on power failure; avoid writing those cyclically.

Questions about the Price Industries Disio Display DX-303 sequence

How many BACnet points does the Price Industries Disio Display DX-303 sequence have?

This list has 66 BACnet objects: 1 analog input, 2 analog outputs, 52 analog values, 2 binary outputs, 9 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Price Industries Disio Display DX-303 sequence BACnet points are writable?

61 of the 66 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Price Industries Disio Display DX-303 sequence BACnet documentation?

The source is Disio Display BACnet Object List - DX-303 (Disio Display BACnet Object List (DX-303)), published free by Price Industries at https://priceindustries.com/wp-content/uploads/Assets/literature/documents---bacnet/disio-display-bacnet-points-list.pdf.

What are the minimum BACnet points to integrate the Price Industries Disio Display DX-303 sequence?

Start with MV 6 Occupancy (Occupied / unoccupied command); AV 6 Room Temperature Setpoint (Room setpoint); AV 13 Room Temperature (Room temperature); MV 7 Occupancy Source (What set the occupancy); AV 20 Cooling Loop Load (Cooling loop load, %); AV 27 Heating Loop Load (Heating loop load, %).

How do I check these points on the real Disio Display DX-303 sequence?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
