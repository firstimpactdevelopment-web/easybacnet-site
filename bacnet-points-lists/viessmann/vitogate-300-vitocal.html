BMS integration notes: Viessmann Vitogate 300 (BN/MB) with Vitocal heat pumps (Vitotronic 200 WO1C)

Integration in brief

Set each heating circuit's operating mode (MV 4-6) and room setpoints, and the DHW setpoint. Read outdoor, system flow and DHW temperatures, circuit status, compressor state and output, and the energy balance.

Network setup

  • Set the system number and device number in the Vitogate; they offset every object instance (100000 per system, 1000 per device).

Watch out for

  • Object names are German; map by instance.
  • Objects for heating circuits 2-3, cooling, ventilation, solar or a second stage only return data when that equipment is present.
