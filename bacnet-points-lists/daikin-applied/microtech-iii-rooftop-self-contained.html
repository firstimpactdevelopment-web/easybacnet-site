Updated 16 October 2026

Short answer

The MicroTech III applied air controller is shared by Daikin Applied packaged rooftops, RoofPak air handlers and self-contained units, and exposes one BACnet object list over the BACnet IP or MS/TP communication module. Points cover unit and mode status, occupancy scheduling, temperatures, duct and building static pressure, fan capacity, cooling, heating, dehumidification, energy recovery, run hours and read-only unit configuration. Many objects only apply to certain unit types or options, and most network inputs require AHU Loc/Net (MV 38) to be set to Network at the keypad.

This page lists 294 BACnet objects for the Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller — 112 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Daikin Applied’s own free documentation, linked below.

BMS integration notes: Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller

Integration in brief

Set AHU Loc/Net to Network at the keypad, then drive the unit with Occupancy Mode or the Occupancy Scheduler Input, plus Application Mode and network setpoints. Use Emergency Override to stop the unit from the network, and read Unit State, unit status, capacities, temperatures and alarm objects.

Enable & remote start

AHU Loc/Net (MV 38) must be set to Network at the keypad/display (it is read-only over BACnet) for most network inputs to apply. Occupancy is then commanded with Occupancy Mode (MV 7) or, when Occupancy Mode is Auto, the Occupancy Scheduler Input (MV 8/MV 9/AV 3). Emergency Override (MV 10) = Off shuts the unit off (Unit Status OffNet) and only writing Normal restarts it. Application Mode (MV 5) only takes effect when Control Mode is Auto, which is set at the keypad.

Heartbeat & communication loss

Receive Heartbeat (AV 43, 0-6553.4 s, default 0 s) sets how long after the last update of the heartbeat-supervised network parameters the controller falls back to its default values. The guide says it is not supported on application versions 2506017300 or newer.

Sensors & values from the BMS

Space Temperature Input (AV 28) and Outdoor Air Temperature Input (AV 29) accept network temperatures; the space value falls back to the local sensor if the network value becomes unreliable, and out-of-range OA writes revert to Null. Network inputs also exist for space humidity (AV 19), space CO2/IAQ (AV 31), supply/return/exhaust fan capacity and minimum OA position. The relevant unit option or sensor type must be configured for each to apply.

Network setup

  • Initial device instance is calculated from the production code (IP) or MAC address (MS/TP); change it at the keypad and use Apply Changes in the BACnet setup menu.
  • BACnet IP defaults: DHCP on, given IP 127.0.0.1, mask 255.255.255.0, UDP port 47808.
  • BACnet MS/TP defaults: MAC address 18, 38400 baud, Max Master 127, Max Info Frames 1.
  • MS/TP terminating resistor is a keypad setting (Term Resistor); a physical resistor is recommended.

Watch out for

  • Points from the 2009 revision were changed from commandable to writable for the heartbeat function; most network points are plain writes.
  • Writing ClearAlarms (MV 13) continuously is discouraged; use it only to clear an active alarm.
  • Many objects apply only to certain unit types (RTU, SCU, MPS, DPS, DPH) or installed options.
  • File objects need BACnet firmware 9.26 or later.
  • Alarm BVs are legacy only and missing on current firmware; the guide advises against writing them.

Questions about the Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller

How many BACnet points does the Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller have?

This list has 294 BACnet objects: 29 analog inputs, 76 analog values, 89 binary inputs, 40 binary values, 9 files, 4 notification classs, 47 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller BACnet points are writable?

112 of the 294 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller BACnet documentation?

The source is MicroTech Unit Controller - Commercial Packaged Rooftop Systems, Applied Rooftop and Self-Contained Systems Network Protocol Information (ED 15112-20), revision 2023-06, published free by Daikin Applied at https://tahoeweb.daikinapplied.com/api/general/DownloadDocumentByName/media/ED%2015112-20.pdf.

What are the minimum BACnet points to integrate the Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller?

Start with MV 7 OccManCmd (Occupancy mode command (Occ/Unocc/TntOvrd/Standby/Auto)); MV 8 CurrentState (Occupancy Scheduler Input when Occupancy Mode is Auto); MV 10 EmergOverride (Network shutdown (Off) / Normal); MV 5 ApplicCmd (Application mode (heat/cool/fan only/auto)); AV 9 OccCoolSP (Occupied cooling setpoint); AV 11 OccHeatSP (Occupied heating setpoint); MV 38 AHULoc/Net (Must read Network for network inputs to apply); MV 15 UnitState (Current operating state); AI 1 DischAirTemp (Discharge air temperature); AV 26 ActiveFault (Highest-priority active fault number, 0 = none).

How do I enable BMS control of the Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller?

AHU Loc/Net (MV 38) must be set to Network at the keypad/display (it is read-only over BACnet) for most network inputs to apply. Occupancy is then commanded with Occupancy Mode (MV 7) or, when Occupancy Mode is Auto, the Occupancy Scheduler Input (MV 8/MV 9/AV 3). Emergency Override (MV 10) = Off shuts the unit off (Unit Status OffNet) and only writing Normal restarts it. Application Mode (MV 5) only takes effect when Control Mode is Auto, which is set at the keypad.

Does the Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller need a BACnet heartbeat or have a communication timeout?

Receive Heartbeat (AV 43, 0-6553.4 s, default 0 s) sets how long after the last update of the heartbeat-supervised network parameters the controller falls back to its default values. The guide says it is not supported on application versions 2506017300 or newer.

Can the BMS supply sensor values to the Daikin Applied MicroTech III Applied Rooftop and Self-Contained Unit Controller?

Space Temperature Input (AV 28) and Outdoor Air Temperature Input (AV 29) accept network temperatures; the space value falls back to the local sensor if the network value becomes unreliable, and out-of-range OA writes revert to Null. Network inputs also exist for space humidity (AV 19), space CO2/IAQ (AV 31), supply/return/exhaust fan capacity and minimum OA position. The relevant unit option or sensor type must be configured for each to apply.
