BMS integration notes: Daikin Applied MicroTech III WSHP Controller - Enfinity Single Stage

Integration in brief

Join the heat pump to the MS/TP trunk with a unique MAC and instance, then command occupancy and application mode and supply the space temperature or setpoint from the BMS if needed. Use Receive Heartbeat if overrides must fall back when the BMS goes quiet.

Enable & remote start

No local/remote switch is described. Network override objects take effect when written: Application Mode Input (MV 10) selects Auto/Heat/Cool/Off/Fan Only/Dehumid, Occupancy Override Input (MV 7) and Occupancy Scheduler Input (MV 8) set occupancy, and Compressor Enable Input (MV 1) permits compressor operation. Overrides revert to their default (Null) values after a controller reboot.

Heartbeat & communication loss

Receive Heartbeat (AV 20, cpRcvHrtBt, 0-6553.4 s, default 0 = disabled) is the maximum time a supported override may go without being rewritten before it reverts to its default. Each supported point has its own timer: AV 18, AV 35, MV 1, MV 8, MV 9, MV 10, MV 11 and MV 12. Send Heartbeat is not supported by the BACnet module; use COV instead.

Sensors & values from the BMS

Write the space temperature to Space Temperature Input (AV 18); Effective Space Temperature (AV 22) uses the local AI 1 sensor unless AV 18 holds a valid value. Temperature Setpoint Input (AV 19) sets the reference setpoint for Occupied/Standby, but local setpoint adjust must first be disabled with MV 14. Temperature Setpoint Offset Input (AV 35) shifts the occupied/standby setpoints. Occupancy Sensor Input (MV 9) accepts a network occupancy sensor.

Network setup

  • Default device instance is 3101000 plus the MS/TP MAC address (example 3101007); System Minimum Instance (AV 412) sets the base.
  • MS/TP baud rate (9600, 19200, 38400 or 76800) must be set in the BACnet module's serial configuration menu (DB-9 port, 19200 8-N-1).
  • MS/TP MAC address comes from address switch S3; it can only be set from the BAS or menu when S3 is at 255.
  • Set MaxMasters to the highest MS/TP master address on the segment to cut token traffic.

Watch out for

  • Configuration (cp...) objects are stored in non-volatile memory with a limited write life; do not write them cyclically.
  • Network overrides revert to default on controller reboot, so the BMS must restore them.
  • ReinitializeDevice password is McQuay (or MicroTech on newer software); a cold reset restores module defaults.

Integration notes

  • BACnet MS/TP only; there is no BACnet IP option on this controller.
  • Configuration (cp...) objects are stored in non-volatile memory with a limited write life; avoid frequent writes.
  • AV 5 is printed truncated as 'cpStandby_' in this table; the SmartSource table prints the full name cpStandby_Heat_Setpt.
  • AV 411 is named MacAddress or MacAddressSwitch depending on the physical address switch setting.
  • BinaryIn (BI 1) and BinaryOut (BV 2) are bit-packed status values explained in the guide.

How many BACnet points does the Daikin Applied MicroTech III WSHP Controller - Enfinity Single Stage have?

This list has 66 BACnet objects: 8 analog inputs, 37 analog values, 1 binary input, 2 binary values, 3 multi-state inputs, 15 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied MicroTech III WSHP Controller - Enfinity Single Stage BACnet points are writable?

39 of the 66 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
