Short answer

The MicroTech III fan coil controller joins a BACnet MS/TP trunk through a plug-in BACnet communication module (a LonWorks module is the alternative; only the BACnet objects are listed here). Points cover space, water and discharge temperatures, occupancy setpoints and differentials, valve and economizer tuning, network space temperature and setpoint inputs, occupancy and application mode commands, alarm status and PI loop objects. Configuration (cp...) objects live in non-volatile memory.

BMS integration notes: Daikin Applied MicroTech III Fan Coil Unit Controller

Integration in brief

Give the module a unique MAC and instance, then command occupancy and application mode and, if the BMS owns the setpoint, write Temperature Setpoint Input after disabling local setpoint adjust. Supply the space or water temperature from the BMS only when needed, and use Receive Heartbeat if overrides must fall back when the BMS goes quiet.

Enable & remote start

No local/remote switch is described. Network inputs take effect when written: Application Mode Input (MV 9) overrides the room sensor mode switch, Occupancy Override Input (MV 6) and Occupancy Scheduler Input (MV 7) set occupancy, Energy Hold Off (MV 11) forces standby setpoints. These overrides revert to Null after a controller reboot.

Heartbeat & communication loss

Receive Heartbeat (AV 34, cpRcvHrtBt, 0-6553.4 s, default 0 = disabled, v1.1 and later) is the longest a supported override may go without being rewritten before it reverts to its default. Supported points: AV 35, AV 36, AV 38, MV 7, MV 8, MV 9, MV 10, MV 11 and MV 13. Disabling device communication also triggers the revert.

Sensors & values from the BMS

Write the space temperature to Space Temperature Input (AV 36) and the water temperature to Remote Entering Water Temperature (AV 35); the effective values (AV 22, AV 20) use the local sensors unless these hold valid values. Temperature Setpoint Input (AV 37) sets the occupied/standby reference setpoint once local setpoint adjust is disabled with MV 12 = 1. Temperature Setpoint Offset Input (AV 38) shifts the occupied and standby setpoints. Occupancy Sensor Input (MV 8) accepts a network occupancy sensor.

Network setup

  • Default device instance is 3101000 plus the MS/TP MAC address (example 3101007); System Minimum Instance (AV 412) sets the base.
  • MS/TP baud (9600, 19200, 38400 default, 76800) is set only in the module's serial configuration menu (DB-9 port, 19200 8-N-1, null-modem cable).
  • MS/TP MAC address comes from address switch S3; it can only be set from the BAS or menu when S3 is at 255.
  • Set MaxMasters to the highest MS/TP master address on the segment.
  • Equipment configuration (BV 5) can only be set from the configuration menu, not from the BAS.

Watch out for

  • Configuration (cp...) objects are stored in non-volatile memory with a limited write life; do not write them cyclically.
  • Network overrides revert to Null on controller reboot, so the BMS must restore them.
  • ReinitializeDevice password is McQuay or MicroTech; the password wink makes the unit identify itself.
  • Occupancy setpoints must stay in order: unoccupied heat <= standby heat <= occupied heat <= occupied cool <= standby cool <= unoccupied cool.

Integration notes

  • BACnet MS/TP only; the same document also covers a LonWorks module, which is not listed here.
  • Configuration (cp...) objects are stored in non-volatile memory with a limited write life; avoid frequent writes.
  • BI 1 and BV 2-5 are bit-packed status words; the bits are returned in each object's Description property.
  • Loop objects LO 1-4 also expose writable Proportional_Constant and Integral_Constant properties (stored in non-volatile memory).
  • MV 9 text in the guide still says Null is 7 in one place; the state list (8 = Null) is the corrected one from revision 6.
  • Analog Null (sensor failed or unused) reads 621.806 °F / 327.67 °C.

How many BACnet points does the Daikin Applied MicroTech III Fan Coil Unit Controller have?

Which Daikin Applied MicroTech III Fan Coil Unit Controller BACnet points are writable?

50 of the 76 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
