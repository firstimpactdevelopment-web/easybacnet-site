Short answer

The EWAT-B-C and EWAF-B-C air-cooled chillers use a MicroTech 4 controller running the "ARES" software. BACnet IP or BACnet MS/TP comes from a POL908/POL904 module or the onboard software option. The list covers unit enable, mode and network setpoints, heat recovery, free cooling, variable primary flow, per-circuit refrigerant and fan data for up to four compressors per circuit, energy monitoring and alarm objects.

BMS integration notes: Daikin Applied EWAT-B-C / EWAF-B-C air-cooled chiller (Daikin Applied Europe)

Integration in brief

Select network control at the unit (CtrlSource BI 3 then reads Network), enable the chiller with UnitEnableStp, and write the mode, cool setpoint and capacity limit. Monitor unit status, leaving water temperature and the fault index/code; this list has no single alarm BI.

Enable & remote start

CtrlSource (BI 3) reads 0 = Network / 1 = Local and is read-only over BACnet, so network control has to be selected at the unit; the guide does not describe that step. With network control active the BMS writes UnitEnableStp (BV 2) = Enable, then the mode (MV 3) and network setpoints.

Sensors & values from the BMS

VarFlow'LoadDPres (AI 1905, plant differential pressure) is marked writable for variable primary flow; the guide does not say whether the BMS must supply it.

Network setup

  • BACnet IP comes from the POL908 module or, on MicroTech 4, the onboard BACnet IP software option (enabled under Commissioning > Configuration > Software Options with an unlock password).
  • BACnet MS/TP comes from the POL904 module or the onboard BACnet MS/TP software option.
  • BACnet IP defaults: device instance 1, UDP port 47808, DHCP off; set Apply Changes = Yes after editing, which restarts the controller.
  • BACnet MS/TP module defaults: MAC address 24, 38400 baud, Max Master 127, Max Info Frames 1; the device instance is derived from the production number and date code. Cycle power after changing the address.
  • EDE files are regenerated each time the BACnet server starts and can be downloaded by FTP from the POL908; re-export them after any configuration change.

Watch out for

  • The guide marks the enable, alarm-reset, mode, heat recovery and free-cooling enable objects as written at priority 8 (access C here); the network setpoints are plain W.
  • Compressor start counters and run-hour AVs are marked writable; don't write them from the BMS.
  • Alarms come as Warning, Problem and Fault index/code AVs (900-905); decode them with the alarm code table in section 5.1 of the guide.
  • MV 4 Units selects metric or English units for the BACnet values; set it once, not cyclically.

Integration notes

  • Close relative of the EWAT-B (NASH) list: the core unit objects keep the same instances; this version adds a fourth compressor per circuit, energy monitoring (AV 260-264), more alarm BVs, and has BI 10 GenericStatus in place of an alarm output.
  • Heat recovery, free-cooling, variable-flow and fourth-compressor objects only apply when the unit has those options.
  • Access "W (Prio 8)" in the guide is shown as C; plain "W" is shown as W. The network cool/heat/ice/capacity setpoints are printed as plain W in this revision.
  • AV 1997 is printed for both C1'FanStatus and C2'FanStatus; C2'FanStatus is listed without an instance.
  • Units "°Dc" in the guide (temperature difference) are shown as dK.
  • Default device instance 1 applies to BACnet IP; on the MS/TP module it is derived from the production number.

Which Daikin Applied EWAT-B-C / EWAF-B-C air-cooled chiller (Daikin Applied Europe) BACnet points are writable?
