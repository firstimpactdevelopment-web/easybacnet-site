Short answer

The MicroTech 4 controller on Rebel Applied (DPSA) rooftops joins BACnet IP or BACnet MS/TP through a plug-in communication module (a LonWorks module is the third option; only BACnet objects are listed here). Objects cover unit and occupancy status, network enables for cooling, heating and the economizer, temperatures and refrigerant readings, supply and return fan control, dehumidification, outdoor air, run hours, optional refrigerant, power and IAQ monitoring, expansion-board I/O, read-only unit configuration and alarm/event BIs. Most writable inputs only apply when AHU Loc/Net (MV 19) is set to Network at the HMI.

BMS integration notes: Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller

Integration in brief

Set AHU Loc/Net to Network at the HMI, then drive the unit with Occupancy Mode or Current State, plus Application Mode and the occupied setpoints. Use Emergency Override to stop the unit from the network, and read Unit State, unit status, capacities, temperatures and the alarm objects.

Enable & remote start

AHU Loc/Net (MV 19) must be set to Network at the HMI (it is read-only over BACnet) for most network inputs to apply. Occupancy is then commanded with Occupancy Mode (MV 7) or, when MV 7 is Auto, Current State (MV 8). Emergency Override (MV 10) = Off shuts the unit off (Unit Status OffNet) and only writing Normal restarts it. Application Mode (MV 5) only acts when Control Mode is Auto, which is set at the HMI. Cooling, heating and economizer can be enabled or capped from the network with AV 36/37, AV 38/39 and AV 34/35 (Ctrl Mode = Auto).

Heartbeat & communication loss

No BACnet heartbeat (Receive Heartbeat is listed as N/A for BACnet IP and MS/TP). Values written by the BAS stay at the last valid value if communication is lost; an invalid network value makes the controller use its default, and network sensor inputs fall back to the local sensor.

Sensors & values from the BMS

Space Temperature Input (AV 31) and Outdoor Air Temperature Input (AV 32) take network temperatures and revert to the local sensor if the network value becomes unreliable. Network inputs also exist for space humidity (AV 20/21), space CO2 (AV 33), supply and return fan capacity (AV 24/25) and outdoor air damper minimum and maximum position (AV 17/55). A LonWorks value takes precedence over the BACnet one if both are present.

Network setup

  • Initial device instance is calculated from the production code (IP) or MAC address (MS/TP); change it at the HMI and set Apply Changes in the BACnet IP or MS/TP setup menu (the controller restarts).
  • BACnet IP defaults: DHCP on, given IP 127.0.0.1, mask 255.255.255.0, UDP port 47808.
  • BACnet MS/TP defaults: MAC address 18, 38400 baud, Max Master 127, Max Info Frames 1.
  • MS/TP terminating resistor is an HMI setting (Term Resistor) and is lost at power-off; a physical resistor is recommended.
  • If the BAS cannot subscribe to the notification class recipient lists, enter its device instance in NC Dev 1 or NC Dev 2 in the BACnet setup menu and cycle power.

Watch out for

  • Multistate objects that are also unit configuration code items read with an extra '(n)' at the end of the state text over BACnet, e.g. 'OnOffT(1)'.
  • ClearAlarms (MV 13) clears by class and returns to No once the alarms clear; write it only to clear an active alarm.
  • Network Demand Shed Enable (MV 22) only works when DemandShed is also enabled in the HMI HtgClg ChgOvr Set-Up menu.
  • The guide prints MV 37 twice: RFEF1Status (ECM return fan 1) and VFD_RFEFStatus (return fan VFD: 1=OK, 2=Fault, 3=No Comm). Only RFEF1Status is listed; check the object name on the unit.
  • The refrigerant monitoring table names AI 50 and AI 60 C1DischLnTemp and C2DischLnTemp; the main table calls them C1DischLnTemp1 and C2DischLnTemp2.
  • The BACnet module and controller clocks re-sync about every 60-68 minutes, so BACnet date/time can differ for a while after a keypad change.

Questions about the Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller

How many BACnet points does the Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller have?

This list has 384 BACnet objects: 94 analog inputs, 12 analog outputs, 79 analog values, 127 binary inputs, 4 binary outputs, 4 notification classs, 64 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller BACnet points are writable?

94 of the 384 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller BACnet documentation?

The source is MicroTech 4 Rebel Applied Packaged Rooftop Unit Controller Protocol Information (BACnet MS/TP, IP and LonWorks) (ED 19117-3), revision 2022-11, published free by Daikin Applied at https://tahoeweb.daikinapplied.com/api/general/DownloadDocumentByName/media/Rebel%20Applied%20Rooftop%20Unit%20Controller%20Protocol%20Information%20ED%2019117-3.pdf/.

What are the minimum BACnet points to integrate the Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller?

Start with MV 7 OccManCmd (Occupancy mode command (Occ/Unocc/TntOvrd/Standby/Auto)); MV 8 CurrentState (Occupancy Scheduler Input when Occupancy Mode is Auto); MV 10 EmergOverride (Network shutdown (Off) / Normal); MV 5 ApplicCmd (Application mode (off/heat/cool/fan only/auto)); AV 10 OccCoolSP (Occupied cooling setpoint); AV 12 OccHeatSP (Occupied heating setpoint); MV 19 AHULoc/Net (Must read Network for network inputs to apply); MV 15 UnitState (Current operating state); AI 1 DischAirTemp (Discharge air temperature); AV 29 ActiveFault (Highest-priority active fault number, 0 = none).

How do I enable BMS control of the Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller?

AHU Loc/Net (MV 19) must be set to Network at the HMI (it is read-only over BACnet) for most network inputs to apply. Occupancy is then commanded with Occupancy Mode (MV 7) or, when MV 7 is Auto, Current State (MV 8). Emergency Override (MV 10) = Off shuts the unit off (Unit Status OffNet) and only writing Normal restarts it. Application Mode (MV 5) only acts when Control Mode is Auto, which is set at the HMI. Cooling, heating and economizer can be enabled or capped from the network with AV 36/37, AV 38/39 and AV 34/35 (Ctrl Mode = Auto).

Does the Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller need a BACnet heartbeat or have a communication timeout?

No BACnet heartbeat (Receive Heartbeat is listed as N/A for BACnet IP and MS/TP). Values written by the BAS stay at the last valid value if communication is lost; an invalid network value makes the controller use its default, and network sensor inputs fall back to the local sensor.

Can the BMS supply sensor values to the Daikin Applied MicroTech 4 Rebel Applied Rooftop Unit Controller?

Space Temperature Input (AV 31) and Outdoor Air Temperature Input (AV 32) take network temperatures and revert to the local sensor if the network value becomes unreliable. Network inputs also exist for space humidity (AV 20/21), space CO2 (AV 33), supply and return fan capacity (AV 24/25) and outdoor air damper minimum and maximum position (AV 17/55). A LonWorks value takes precedence over the BACnet one if both are present.
