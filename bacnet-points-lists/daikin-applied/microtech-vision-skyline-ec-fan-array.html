Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller BACnet points list

Updated 16 October 2026

Short answer

The MicroTech 4 fan array controller drives up to 20 EC fans (Delta, ebm-papst or Infinitum) over an internal Modbus bus and exposes the array on BACnet MS/TP (RS-485 port 2) or BACnet IP. Points cover demand, duct static and airflow setpoints, array speed, airflow and power, relay and input status, a unit alarm text, and per-fan speed, comm, fault, RPM and alarm-code objects. BACnet can only command the array when its Demand Source is set to BACnet at the HMI.

This page lists 146 BACnet objects for the Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller — 10 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Daikin Applied’s own free documentation, linked below.

BMS integration notes: Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller

Integration in brief

Set the Demand Source to BACnet at the fan controller HMI, then start and stop the array with Unit Control Mode (MV 23) and set capacity with Demand Setpoint (AV 11), or the duct static (AV 9) or airflow (AV 10) setpoint when the array runs in DSP or CFM mode. Read Unit State, fan speed, airflow and the alarm text and relay status.

Enable & remote start

Demand Source must be configured as BACnet in the Config Array HMI menu (MV 5 shows it). With the HMI Control Mode at Auto, Unit Control Mode (MV 23) toggles the array between Auto and Off; Off at the HMI overrides BACnet. With HMI, 0-10 VDC or 4-20 mA as the demand source, BACnet is read-only monitoring.

Heartbeat & communication loss

No receive heartbeat (listed as not applicable). BACnet values stay at the last valid value on communication loss; invalid network values fall back to defaults.

Network setup

  • Device instance defaults to the last 4 digits of the MT4 controller serial number; device name is MT4_DFA_<instance>.
  • BACnet MS/TP defaults: MAC 18, 38400 baud, Max Master 127, Max Info Frames 10.
  • BACnet IP defaults: 192.168.1.42 / 255.255.255.0, gateway 192.168.1.1, UDP 47808, DHCP off.
  • Set addressing in the HMI BMS Communications menus, then set Save Config to Yes; the controller restarts.
  • BACnet Units of Measurement (MV 18): SI, US (default) or CA.

Watch out for

  • Demand, DSP, airflow and RPM setpoints are linked: writing one re-scales the others.
  • Out-of-range setpoint writes are ignored and the last valid value is kept.
  • Clear Alarms (MV 20) returns to No after about 3 s; alarms also clear on a power cycle and come back if the cause remains.
  • Fire alarm input (BI 1) and safety input (BI 3) read 0 when the alarm is active.

Integration notes

  • Per-fan objects (AV 101-120, BV 11-30, BV 51-70, BV 101-120, MV 101-120) only exist for the configured number of fans.
  • Fan alarm code states (MV 101-120) differ by fan make: Delta, ebm-papst or Infinitum.
  • Active control needs Demand Source = BACnet (MV 5 reads BACnet); otherwise the BACnet objects are monitor-only.
  • DSP, CFM and fan tracking control are not in application 2.0 and earlier.
  • Total Fan Power (AV 5) is in kW but the object carries no units property.
  • Manual mode set at the HMI reverts to Normal after 60 minutes or a power cycle.

Questions about the Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller

How many BACnet points does the Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller have?

This list has 146 BACnet objects: 3 analog inputs, 35 analog values, 4 binary inputs, 62 binary values, 39 multi-state values, 3 characterstring values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller BACnet points are writable?

10 of the 146 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller BACnet documentation?

The source is MicroTech Vision and Skyline EC Fan Array Controller - Network Integration Guide (BACnet MS/TP and BACnet IP) (ED 19122-3), revision 2025-10, published free by Daikin Applied at https://tahoeweb.daikinapplied.com/api/general/DownloadDocumentByName/media/ED%2019122-3%20MicroTech%20Vision_Skyline%20EC%20Fan%20Controller%20Protocol%20Document.pdf.

What are the minimum BACnet points to integrate the Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller?

Start with MV 23 UnitCtrlMode (Array Auto/Off command (Demand Source must be BACnet)); AV 11 Demand SP (Capacity setpoint, 0-100 %); MV 20 ClearAlarms (Clear resettable alarms (2 = Yes)); MV 13 UnitState (Array operating state); MV 5 DmdSrc (Shows BACnet when the BMS has control); AV 4 AvgFanSpd (Average speed of all fans, rpm); AV 8 TotalAirFl (Total array airflow); MV 3 RO3 Alarm (Alarm relay output (2 = On)); CSV 2 Unit Alarm Info (Highest-priority active alarm text).

How do I enable BMS control of the Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller?

Demand Source must be configured as BACnet in the Config Array HMI menu (MV 5 shows it). With the HMI Control Mode at Auto, Unit Control Mode (MV 23) toggles the array between Auto and Off; Off at the HMI overrides BACnet. With HMI, 0-10 VDC or 4-20 mA as the demand source, BACnet is read-only monitoring.

Does the Daikin Applied MicroTech Vision / Skyline EC Fan Array Controller need a BACnet heartbeat or have a communication timeout?

No receive heartbeat (listed as not applicable). BACnet values stay at the last valid value on communication loss; invalid network values fall back to defaults.
