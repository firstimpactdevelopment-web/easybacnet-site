Short answer

iCM is a software option on a MicroTech 4 chiller that makes it the master of a multi-chiller plant: it stages a master and up to seven slaves and tracks system load, demand limit and the standby unit. Version 5.00 also manages evaporator/condenser pumps (iPM), up to ten cooling towers (iCT) and iSM pump groups. BACnet IP or BACnet MS/TP comes from a POL908/POL904 module or the onboard software option on that controller. Most objects are read-only plant data per chiller; writable ones cover master enable, staging priorities, standby unit, pump and tower network setpoints and alarm resets.

BMS integration notes: Daikin Applied iCM chiller plant manager, option 184 (Daikin Applied Europe)

Integration in brief

Read the plant view from the master chiller: system run state, common leaving water temperature, active setpoint, load and the state of each chiller. Write only the few plant settings exposed (master enable, staging priorities, standby unit, pump/tower network setpoints) and use the alarm reset MVs. Start/stop and setpoints for individual chillers are not in this list.

Enable & remote start

The guide exposes no plant start/stop or plant setpoint object. MasterEnablingSp (MV 1324) enables or disables the master unit, and the per-unit cooling/heating priorities (MV 1325-1340) and StandbyChillerSp (MV 51) set the staging; the guide does not describe how the plant itself is enabled from a BMS.

Sensors & values from the BMS

Pump speed and bypass control take network setpoints (AV 1370/1373/1376/1382/1385 evaporator, AV 1411/1414/1417/1422/1425 condenser) and the tower leaving water control takes iCT'LwtCtrl'SpNtwk (AV 1462); the guide does not say how these are selected over the local values.

Network setup

  • BACnet IP comes from the POL908 module or, on MicroTech 4, the onboard BACnet IP software option (enabled under Commissioning > Configuration > Software Options with an unlock password).
  • BACnet MS/TP comes from the POL904 module or the onboard BACnet MS/TP software option.
  • BACnet IP defaults: device instance 1, UDP port 47808, DHCP off; set Apply Changes = Yes after editing, which restarts the controller.
  • BACnet MS/TP module defaults: MAC address 24, 38400 baud, Max Master 127, Max Info Frames 1; the device instance is derived from the production number and date code. Cycle power after changing the address.
  • EDE files are regenerated each time the BACnet server starts and can be downloaded by FTP from the POL908; re-export them after any configuration change.

Watch out for

  • Several multistate objects use 0 = NULL as the first state; write the real value (e.g. 2 = Enable), not 0.
  • Staging priorities (MV 1325-1340, 1-8) and StandbyChillerSp are settings; write them once, not cyclically.
  • Slave state objects are named S1State-S7State, not SlaveDataN'State like the other slave objects.
  • There is no single plant alarm object: watch the master/slave State MVs, the slave CommErr/Missing BVs, the pump/tower GenAlm MVs and ConfigErrReason.
  • The guide prints the same description for several bypass and speed network setpoints; check the object name to tell them apart.

Integration notes

  • The guide does not spell out "iCM"; Daikin's product pages call it the Intelligent Chiller Manager. It is the plant-manager software (option 184) running on the master chiller.
  • SCMType (MV 1101) shows the plant type: Master/Slave, iCM Standard or iCM Advanced. Slave, energy, heat recovery, free-cooling, pump, tower, defrost and iSM objects only apply when configured.
  • Each chiller's own unit objects (enable, setpoints, alarms) are on its own controller; this list is the plant-level view.
  • The guide prints multistate objects as MSV; they are listed here as MV. Rows printed "as <other object>" are given that object's state texts or units.
  • Revision 11/2023 matches iCM software 5.00 (adds iCT cooling towers, system heat recovery, free cooling, defrost, iSM and iCM Expanded).
  • Units "°Dc" in the guide are shown as dK; counters and ranges are shown without units.

Questions about the Daikin Applied iCM chiller plant manager, option 184 (Daikin Applied Europe)

How many BACnet points does the Daikin Applied iCM chiller plant manager, option 184 (Daikin Applied Europe) have?

This list has 462 BACnet objects: 2 analog inputs, 212 analog values, 43 binary values, 205 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied iCM chiller plant manager, option 184 (Daikin Applied Europe) BACnet points are writable?

34 of the 462 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin Applied iCM chiller plant manager, option 184 (Daikin Applied Europe) BACnet documentation?

The source is BAS Integration guide - BACnet protocol (iCM, Option 184) (D-EIGOC00110-21_03EN), revision 2023-11, published free by Daikin Applied at https://my.daikin.eu/content/dam/document-library/installation-manuals/iCM_BAS%20Integration%20Guid%20BACNet_D-EIGOC00110-21_English.pdf.

What are the minimum BACnet points to integrate the Daikin Applied iCM chiller plant manager, option 184 (Daikin Applied Europe)?

Start with MV 1324 MasterEnablingSp (Master unit enable (1 = Disable, 2 = Enable)); MV 1448 EvapPM'ClearAlm (Reset evaporator pump manager alarms (2 = Reset)); MV 1100 SysOpSta (Plant run state (Stop / Run)); AI 1103 CommonLWT (Common leaving chilled water temperature); AV 1107 SysActSp (Active plant setpoint); AV 1112 SystemLoad (Plant load, %); MV 1136 MasterData'State (Master chiller state, incl. Alarm / ComErr); MV 1154 S1State (Slave 1 state; S2State-S7State follow); MV 1354 EvapPM'GenAlm (Evaporator pump manager general alarm); MV 1445 ConfigErrReason (Plant configuration alarm reason (1 = None)).

How do I enable BMS control of the Daikin Applied iCM chiller plant manager, option 184 (Daikin Applied Europe)?

The guide exposes no plant start/stop or plant setpoint object. MasterEnablingSp (MV 1324) enables or disables the master unit, and the per-unit cooling/heating priorities (MV 1325-1340) and StandbyChillerSp (MV 51) set the staging; the guide does not describe how the plant itself is enabled from a BMS.

Can the BMS supply sensor values to the Daikin Applied iCM chiller plant manager, option 184 (Daikin Applied Europe)?

Pump speed and bypass control take network setpoints (AV 1370/1373/1376/1382/1385 evaporator, AV 1411/1414/1417/1422/1425 condenser) and the tower leaving water control takes iCT'LwtCtrl'SpNtwk (AV 1462); the guide does not say how these are selected over the local values.
