Short answer

The EWWD-DZ and EWWH-DZ chillers run Daikin's VORTEX software. BACnet IP or BACnet MS/TP comes from a POL908/POL904 module. The list covers chiller enable, local/remote, mode, network cool/heat setpoints and capacity and current limits, water temperatures, per-compressor capacity, speed, IGV position, current, power and temperatures for up to three compressors, pump status, and individual alarm objects plus alarm index/code AVs.

BMS integration notes: Daikin Applied EWWD-DZ / EWWH-DZ water-cooled chiller, VORTEX software (Daikin Applied Europe)

Integration in brief

Set ChillerLocalRemote to Remote, enable the chiller with ChillerEnableStp and write the mode, cool setpoint and capacity limit. Monitor unit status, leaving water temperature, the general alarm and the fault code.

Enable & remote start

ChillerLocalRemote (BI 3, 0 = Local / 1 = Remote) is marked R/W in this guide; with Remote selected the BMS writes ChillerEnableStp (BV 2) = Enable, then the mode (MV 3) and network setpoints.

Network setup

  • BACnet IP comes from the POL908 module and BACnet MS/TP from the POL904 module.
  • BACnet IP module defaults: device instance 1, UDP port 47808, DHCP off; set Apply Changes = Yes after editing, which restarts the controller.
  • BACnet MS/TP module defaults: MAC address 24, 38400 baud, Max Master 127, Max Info Frames 1; the device instance is derived from the production number and date code.

Watch out for

  • Alarms come as Warning, Problem and Fault index/code AVs (900-905); the fault code table (Annex 1) is in the guide.
  • AV 175 CurrentLimSetpNtw is a current (A) limit; the main BMS capacity limit is AV 3 (%).
  • Objects for compressor 3 only apply to three-compressor units.

Integration notes

  • AV 992 is printed for both ChillerVoltage and Comp2AlarmActive; MV 1 is printed for both UnitStatus and CondFlowSwStatus; the object without a confirmed instance is listed without one.
  • Four rows print an invalid object type and are left out: Comp1OffCmpFault (type "CS", instance 322), UnitOFFEvapWaterFlow (701), UnitOFFPhaseVoltage (820) and UnitPwrRestore (515), which print type "0".
  • Several compressor 2 and 3 alarm objects are printed as BI where the matching compressor 1 object is a BV; types are kept as printed.
  • Binary alarm objects list a third state "2 = NULL" in the guide.
  • Daikin France (Easyspec) publishes this guide as a PDF inside a zip together with the Modbus guide.

How many BACnet points does the Daikin Applied EWWD-DZ / EWWH-DZ water-cooled chiller, VORTEX software (Daikin Applied Europe) have?

This list has 164 BACnet objects: 21 analog inputs, 51 analog values, 21 binary inputs, 66 binary values, 5 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied EWWD-DZ / EWWH-DZ water-cooled chiller, VORTEX software (Daikin Applied Europe) BACnet points are writable?

8 of the 164 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the Daikin Applied EWWD-DZ / EWWH-DZ water-cooled chiller, VORTEX software (Daikin Applied Europe)?

Start with BV 2 ChillerEnableStp (Network enable/disable of the chiller); BI 3 ChillerLocalRemote (Local/remote selection (1 = Remote)); MV 3 ChillerOperationMode (Ice / cool / heat / pursuit mode command); AV 4 NetworkCoolTempSetpoint (Leaving water cool setpoint from the BMS); AV 3 NetworkCapacityLimitPct (Capacity limit from the BMS, %); BV 8 ClearAlarm (Clear alarms from the network); MV 1 UnitStatus (Chiller run state); AI 2 LvgEvapWaterTempUnit (Leaving chilled water temperature); BI 10 AlarmDigitalOutput (Unit general alarm); AV 905 AVFaultAlarmCode (Active fault alarm code).

How do I enable BMS control of the Daikin Applied EWWD-DZ / EWWH-DZ water-cooled chiller, VORTEX software (Daikin Applied Europe)?

ChillerLocalRemote (BI 3, 0 = Local / 1 = Remote) is marked R/W in this guide; with Remote selected the BMS writes ChillerEnableStp (BV 2) = Enable, then the mode (MV 3) and network setpoints.
