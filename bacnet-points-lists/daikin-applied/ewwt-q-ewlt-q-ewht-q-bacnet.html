Short answer

BMS integration notes: Daikin Applied EWWT-Q / EWLT-Q / EWHT-Q water-cooled scroll chiller (Daikin Applied Europe)

Integration in brief

Select network control at the unit (ChillerLocalRemote BI 3 then reads Network), enable the chiller with ChillerEnableStp and write the network mode and cool/heat setpoints. Monitor unit status, leaving water temperature, the general alarm output and the alarm words.

Enable & remote start

ChillerLocalRemote (BI 3) reads 0 = Network / 1 = Local and is read-only over BACnet, so network control has to be selected at the unit; the guide does not describe that step. With network control active the BMS writes ChillerEnableStp (BV 2) = Enable, then the mode (MV 3) and network setpoints.

Network setup

  • BACnet IP runs on the controller's Ethernet port as a software option, supplied with connectivity kit EKRSCBMS.
  • The onboard RS485 port is for Modbus; this guide does not cover BACnet MS/TP.

Watch out for

  • Compressor and pump run-hour AVs are marked writable; don't write them from the BMS.
  • Alarms are bit-coded in the unit and circuit alarm words; decode them with Annex A.
  • MV 47 Units switches metric/imperial for the BACnet values; set it once, not cyclically.
  • MV 430/435 set each compressor to Off or Auto; leave them on Auto for normal running.

Integration notes

  • This is the Daikin Applied Europe guide; it is a different object list from the US MicroTech chiller documents.
  • Unit and circuit alarms are packed into 32-bit alarm words (AV 296-299, AV 396-399); the bit meanings are in Annex A of the guide.
  • AV 151 MUSECtrlTemp is printed twice (once read-only, once writable as the MUSE temperature setpoint); it is listed once as W.
  • BV 502 is printed twice (CommonLWTSenf and CmnLwtSenf) and BV 503 twice (CndLvgTempSensorFail and CommonCondLWTSenf); each is listed once under its first name, with the other name in the description.
  • MU2-MU4 and MUSE objects only apply to multi-unit (MUSE) installations.
  • Units shown are metric as printed; MV 47 Units switches the BACnet values between Imperial and Metric.
