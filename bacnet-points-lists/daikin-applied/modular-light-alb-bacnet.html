Short answer

The Modular Light (ALB) air handler uses a MicroTech III or MicroTech 4 controller; BACnet IP comes from a POL908 module and BACnet MS/TP from a POL904 module. The short list covers air temperatures, pressures and flows, fan and coil outputs, fan, temperature, humidity and air-quality setpoints, fan and alarm status, operating mode and summer/winter changeover. Object instances are fixed but non-sequential.

BMS integration notes: Daikin Applied Modular Light (ALB) air handler, EvoLVE controls (Daikin Applied Europe)

Integration in brief

Write NetworkCtrl to run or stop the unit, set summer/winter with SuWiNetworkChgover after setting SuWiChgSrc to BMS, and adjust the fan, economy, humidity and air-quality setpoints as needed. Read the operating mode and status, supply and controlled temperatures and the general alarm.

Enable & remote start

NetworkCtrl (MV 24562, "Network source", 1 = Off / 2 = On) is the writable on/off object; ActOpSta (MV 32321) reports 11 = BMS when the network is in control. Summer/winter changeover follows the BMS only when SuWiChgSrc (MV 9493) = 3 (BMS); then write SuWiNetworkChgover (MV 28594). The guide gives no further procedure.

Network setup

  • BACnet IP comes from a POL908 module and BACnet MS/TP from a POL904 module plugged onto the MicroTech controller.
  • BACnet IP defaults: device instance 1, UDP port 47808, DHCP off; set Apply Changes = Yes after editing, which restarts the controller.
  • BACnet MS/TP module defaults: MAC address 24, 38400 baud, Max Master 127, Max Info Frames 1; the device instance is derived from the production number and date code. Cycle power after changing the address.
  • Object instances are fixed, non-sequential numbers (e.g. SupplyTmp = AI 45150); map by instance, not by position.
  • EDE files are regenerated each time the BACnet server starts and can be downloaded by FTP from the POL908; re-export them after any configuration change.

Watch out for

  • Objects only appear when the AHU configuration uses them (fans, coils, recovery, humidity, air quality).
  • Engineering units of fan setpoints follow SplyEngUnit / ExhEngUnit (%, Pa or m3/h) and humidity units follow HumEngUnit.
  • Multistate commands are 1-based (1 = Off, 2 = On); 0 is not a valid state.
  • AckAlmPls (MV 39130) acknowledges every alarm in the controller at once.
  • Only the economy cooling/heating setpoints (AV 61866/35713) are writable here; the active setpoints (AV 4018/30105/56276) are read-only.

Integration notes

  • Which objects exist depends on the AHU configuration.
  • The cover names the control software EvoLVE; the page footers say Airstream.
  • AV 30105 ActMainSpvClg is printed twice; it is listed once.

How many BACnet points does the Daikin Applied Modular Light (ALB) air handler, EvoLVE controls (Daikin Applied Europe) have?

Which Daikin Applied Modular Light (ALB) air handler, EvoLVE controls (Daikin Applied Europe) BACnet points are writable?

18 of the 81 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
