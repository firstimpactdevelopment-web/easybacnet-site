Short answer

The MicroTech controller on SmartSource DOAS water source heat pumps has BACnet MS/TP built in (LonWorks needs an add-on module and is not listed here). Objects cover space, water, discharge, leaving coil, refrigerant and outdoor readings, outdoor-air changeover, leaving coil, reheat and dewpoint setpoints, duct and building static pressure, compressor timers and run hours, network inputs for space and outdoor temperature, humidity, CO2, entering water temperature, fan speed and DAT reset, occupancy commands, unit state and alarms. The physical binary inputs and outputs are listed as BI 1-8 and BO 1-14.

BMS integration notes: Daikin Applied MicroTech DOAS WSHP Unit Controller

Integration in brief

Give the controller a unique MAC address and device instance, then command occupancy with the override or schedule input and allow the compressors with Compressor Enable. Adjust the leaving coil cooling and discharge heating setpoints if the BMS owns them, and read Unit State, discharge air temperature and Current Alarm. Network inputs are cleared by a controller reset.

Enable & remote start

No local/remote switch is described. Network inputs take effect when written: Network Occupancy Override Input (MV 7) overrides the current occupancy, Network Occupancy Schedule Input (MV 8) commands the scheduled mode, and Compressor Enable (MV 1) disables compressor heating and cooling (Null = enabled). Network values override local settings and revert to their defaults after a controller reset.

Heartbeat & communication loss

No BACnet heartbeat. Receive Heartbeat is a LonWorks-only setting. BACnet network inputs stay in place until the controller powers up or resets, then return to the invalid value 32767.

Sensors & values from the BMS

Network Space Temperature Input (AV 18) feeds the effective space temperature (AV 22). Network inputs also exist for outdoor temperature (AV 45), outdoor and space humidity (AV 48, AV 50), space CO2 (AV 52), entering water temperature (AV 113), duct static pressure setpoint (AV 160), fan speed (AV 115, used when Fan Control Type MV 23 is Network) and discharge air temperature reset (AV 148). The local sensor value is used when the network value is not provided.

Network setup

  • Defaults: MAC address 120 (AV 411), device instance 3101120 = System Minimum Instance (AV 412, default 3101000) + MAC, 38400 baud, Max Master 127, device name DevName.
  • MS/TP baud (9600, 19200, 38400 or 76800) is set from the LUI keypad or ServiceTools; speeds above 38400 need tested wiring.
  • BACnet is on board; only LonWorks needs an add-on communication module.

Watch out for

  • Configuration (cp...) and other non-volatile objects have a limited write life; do not write them cyclically.
  • Network inputs return to 32767 (Null) after a controller reset, so the BMS must restore them.
  • Some analog objects only hold whole numbers; fractional writes are rounded.
  • MV 16 and MV 17 are described as network commands but printed read-only; test writes on the unit before relying on them. MV 17 states follow the range column (6 = Null); the description lists 6 = HtCl and 7 = Null.
  • Over BACnet, Current Alarm (MV 11) reads 1 when no alarm is active (LonWorks uses 0).

Integration notes

  • BACnet MS/TP only; the same guide also covers an optional LonWorks module, which is not listed here.
  • BI 1-8 and BO 1-14 are named with the configurable parameter names that the I/O parameter tables list against each BI/BO instance (BI 4 is unused); the tables give no access, so read-only is shown. Several outputs can be reassigned at the keypad or in ServiceTools.
  • Network inputs return to the invalid value 32767 (Null) after a controller power-up or reset.
  • Configuration (cp...) and other non-volatile objects have a limited write life; non-volatile values are saved every 20 minutes.
  • Current Alarm (MV 11), Previous Alarm (MV 5) and Unit Status - In Alarm (MV 24) return alarm numbers 1-45 from the guide's alarm table.
  • Dehumidification Enable (MV 16), Application Mode (MV 17) and Occupancy Sensor (MV 9) are described as network inputs but printed read-only (R) in the guide.

Questions about the Daikin Applied MicroTech DOAS WSHP Unit Controller

How many BACnet points does the Daikin Applied MicroTech DOAS WSHP Unit Controller have?

This list has 126 BACnet objects: 17 analog inputs, 64 analog values, 8 binary inputs, 14 binary outputs, 2 binary values, 1 multi-state input, 20 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied MicroTech DOAS WSHP Unit Controller BACnet points are writable?

54 of the 126 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin Applied MicroTech DOAS WSHP Unit Controller BACnet documentation?
