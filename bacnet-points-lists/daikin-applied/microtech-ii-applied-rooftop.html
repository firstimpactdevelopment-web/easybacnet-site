Short answer

The older MicroTech II applied rooftop controller connects to BACnet IP or BACnet MS/TP through a plug-in communication module (LonWorks modules also exist). It exposes a fixed set of standard objects, mostly analog values carrying numbered enumerations, covering unit status, application mode, occupancy, temperatures, duct and building static pressure, fan capacities, zone and discharge setpoints, outdoor air damper, economizer, energy recovery, dehumidification, schedule and alarms.

BMS integration notes: Daikin Applied MicroTech II Applied Rooftop Unit Controller

Integration in brief

Set switch S7 to AUTO and Control Mode to AUTO at the keypad. With Occupancy Mode left at Auto, the BMS commands occupancy through the Occupancy Scheduler Input BV at a priority higher than 15, turns the unit off with Application Mode or the Emergency Override flag, and writes setpoints at priority 16.

Enable & remote start

Put rocker switch S7 in AUTO and set Control Mode to AUTO at the keypad (password 4545). Leave Occupancy Mode (AV 3825) at Auto and command occupancy with the Occupancy Scheduler Input (BV 1455). Application Mode (AV 3605) = Off or Emergency Override Mode Flag (AV 3610) = Off shuts the unit down. For network setpoint control set Space Setpoint Type (AV 3615) to Keypad/Network.

Heartbeat & communication loss

No BACnet heartbeat point is given; the receive-heartbeat defaults in the doc apply to the LonWorks network variables. A BACnet value written to an out-of-service input (space, outdoor air temperature, building static pressure) is held at its last value if communication is lost.

Sensors & values from the BMS

Space Temperature (AI 100), Outdoor Air Temperature (AI 125) and Building Static Pressure (AI 1505) accept a BMS value once their Out_Of_Service property is set to TRUE; the controller keeps the last value written if communication is lost. Remote fan capacities are written to AV 3725 / AV 3740 when the matching control flag (AV 3720 / AV 3750) is set to Position.

Network setup

  • Communication parameters are changed with MicroTech II ServiceTools, not over the network.
  • BACnet IP defaults: IP 172.16.83.46, mask 255.255.0.0, UDP 47808, router 172.16.128.0, network number 1001; no DHCP.
  • For BACnet IP the device's Communication Option must be NONE; MSTP (the default) is used for MS/TP and LonWorks.
  • MS/TP MAC is set on the 8-position DIP switch of the MS/TP module (default 2 on MS/TP units); default 19200 baud, network number 2001.
  • Device instance = last six digits of the main control board serial number; device name MTII RTUC plus the last nine digits.

Watch out for

  • The keypad schedule writes the Occupancy Scheduler Input BV at priority 15; command it at a higher priority (e.g. 8) and relinquish at that priority to hand back to the keypad.
  • Write analog values at priority 16; a value written at another priority can differ from the one in use after a keypad change.
  • Occupancy Mode (AV 3825) is an override, not the normal occupancy command; leave it at Auto.
  • Clear alarms by class by writing the Clear All BV from Alarm (1) to Normal (0); it reads Alarm again if the condition is still present.
  • Individual alarm-number objects differ between 100-series and 200-series application software.

Integration notes

  • Five rows in the main table use Daikin proprietary object types (Runtime Totalization for cooling hours, and Application objects for the cooling and heating reset enables); they are left out.
  • The detail pages also describe other runtime-hour objects of the same proprietary type; they are not included.
  • Space Temperature (AI 100), Outdoor Air Temperature (AI 125) and Building Static Pressure (AI 1505) are marked R** in the table: a BMS can write a network value to them after setting Out_Of_Service to TRUE; if communication is then lost the controller keeps the last value written.
  • Many multi-state settings are analog values carrying an enumeration number (for example Application Mode AV 3605).
  • Two sets of individual alarm objects exist: AV 4861-4863 for 100-series application software v1.44 and later, AV 4870, 4872 and 4873 for 200-series v2.07/2.08.
  • Points marked N/A in the SCC or DAC column apply only to the other control type (zone temperature control vs discharge air control).
