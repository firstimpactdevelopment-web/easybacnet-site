Short answer

The MicroTech WME chiller unit controller on C-vintage Magnitude chillers supports BACnet MS/TP, BACnet IP and Modbus through its BAS communication module. The BACnet table is short and focused: water temperatures and flows, per-compressor current, power, voltage and refrigerant data for two compressors, alarm codes, run hours and starts, plus network enable, mode, cool setpoint and capacity limit.

BMS integration notes: Daikin Applied Magnitude WME C-vintage Chiller (MicroTech WME controller)

Integration in brief

At the chiller HMI set Control Source to BAS (for the network enable) and Remote Enable to Enable (for setpoint, mode and capacity limit). The BMS then writes ChillerEnableStp, the cool setpoint and capacity limit, and reads status, water temperatures and alarm codes.

Enable & remote start

Control Source must be set to BAS at the unit HMI for the controller to use Network Enable (BV 2). For the cool setpoint, mode and capacity limit setpoints, Remote Enable must also be set to Enable at the HMI. Writing Enable to BV 2 only allows a start if other conditions are met.

Network setup

  • Default device instance 9050; default device object name Daikin_MicroTech_ plus the instance.
  • BACnet IP defaults: IP 192.168.1.10, mask 255.255.255.0, gateway 192.168.1.1, UDP port 47808.
  • BACnet MS/TP default baud 38400.
  • Network parameters are set at the HMI; see IM 1283 for the communication module.

Watch out for

  • Only Cool mode applies to WME-C, although the mode objects list Ice, Heat and Heat Recovery.
  • Units (MV 4) changes the units sent to BACnet between English and Metric.
  • Some compressor-shutdown alarms cannot be cleared from the network.

Questions about the Daikin Applied Magnitude WME C-vintage Chiller (MicroTech WME controller)

How many BACnet points does the Daikin Applied Magnitude WME C-vintage Chiller (MicroTech WME controller) have?

This list has 68 BACnet objects: 23 analog inputs, 25 analog values, 14 binary inputs, 2 binary values, 4 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied Magnitude WME C-vintage Chiller (MicroTech WME controller) BACnet points are writable?

6 of the 68 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin Applied Magnitude WME C-vintage Chiller (MicroTech WME controller) BACnet documentation?

The source is MicroTech WME, C-vintage Chiller Unit Controller Protocol Information (ED 19111-1), revision 2020-05, published free by Daikin Applied at https://tahoeweb.daikinapplied.com/api/general/DownloadDocumentByName/media/MicroTech%20WME%20Chiller%20Unit%20Controller%20Protocol%20Information%20-%20ED%2019111-1.pdf.
