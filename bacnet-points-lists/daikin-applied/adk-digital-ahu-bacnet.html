Short answer

The ADK digital AHU uses a MicroTech III or MicroTech 4 controller; BACnet IP comes from a POL908 module and BACnet MS/TP from a POL904 module. The list covers air temperatures, humidity, pressures, flows and air quality (including Modbus room probes), damper, fan, coil and valve signals, comfort/economy/boost setpoints, fan and filter alarms, operating mode and source, summer/winter changeover, energy data and bit-coded alarm words for EC fans, valves and room probes. Object instances are fixed but non-sequential.

BMS integration notes: Daikin Applied ADK digital air handler, DSTREAM controls (Daikin Applied Europe)

Integration in brief

Write the operating command to NetworkCtrlBMS, set summer/winter with SuWiNetworkChgover after setting SuWiChgSrc to BMS, and write the comfort cooling/heating setpoints. Read the operating mode and status, supply and controlled temperatures and the general alarm; use the alarm words for fan and valve diagnostics.

Enable & remote start

NetworkCtrlBMS (MV 26007, 1 = Auto, 2 = Off, 3 = On, 4 = Ventilation, 5 = Economy, 6 = Boost) is the BMS operating command; NetworkCtrl (MV 24562) is the on/off source used by a Daikin iTM. ActOpSta (MV 32321) reports 11 = BMS when the network is in control. Summer/winter changeover follows the BMS only when SuWiChgSrc (MV 9493) = 3 (BMS); then write SuWiNetworkChgover (MV 28594).

Heartbeat & communication loss

No BMS heartbeat is described. Fan setpoints SplyFanSpvP2PCommAlm / RtrnFanSpvP2PCommAlm (AV 59879/18352) apply only when the controllers' peer-to-peer link fails.

Network setup

  • BACnet IP comes from a POL908 module and BACnet MS/TP from a POL904 module plugged onto the MicroTech controller.
  • BACnet IP defaults: device instance 1, UDP port 47808, DHCP off; set Apply Changes = Yes after editing, which restarts the controller.
  • BACnet MS/TP module defaults: MAC address 24, 38400 baud, Max Master 127, Max Info Frames 1; the device instance is derived from the production number and date code. Cycle power after changing the address.
  • Object instances are fixed, non-sequential numbers (e.g. SupplyTmp = AI 45150); map by instance, not by position.
  • EDE files are regenerated each time the BACnet server starts and can be downloaded by FTP from the POL908; re-export them after any configuration change.

Watch out for

  • Objects only appear when the AHU configuration uses them (fans, coils, recovery, humidity, air quality).
  • Engineering units of fan setpoints follow SplyEngUnit / ExhEngUnit (%, Pa or m3/h) and humidity units follow HumEngUnit.
  • Multistate commands are 1-based (1 = Off, 2 = On); 0 is not a valid state.
  • AckAlmPls (MV 39130) acknowledges every alarm in the controller at once.
  • CommTestEn (MV 1708) enables a test mode; leave it at 1 = No.
  • Damper signal AOs (64026, 59501, 50404, 40983, 11376, 50562) are marked writable; writing them can override the unit's own damper control.

Integration notes

  • Which objects exist depends on the AHU configuration (fans, coils, recovery, humidity, VOC/CO2 sensors, Sintra, Modbus fans/valves/room probes).
  • Positive integer value alarm words are bit-coded: guide table A covers EC fan words (e.g. bit 0 motor blocked, bit 1 phase loss, bit 15 communication error), table B Modbus valves and table C room probes.
  • AI 58004 is printed for both VOCSensor and AddVOCX8, and PIV 56094 for both SplyFan6AmWord2 and RtrnFan7AlmWord2; the second of each is listed without an instance. ByPassDmpFBDevAlm and MixingDmpFBDevAlm are each printed as the name of two different BIs.
  • GenAlm (BI 41868) and AlmOutHigh (BO 5714) give the same general alarm.
  • Fan setpoints with a summer/winter split use the base object for summer and the ...Wi objects for winter.
  • The cover reads D-EIGOC00108-22_05EN but the revision table only runs to _02EN (16/09/2025).

Questions about the Daikin Applied ADK digital air handler, DSTREAM controls (Daikin Applied Europe)

How many BACnet points does the Daikin Applied ADK digital air handler, DSTREAM controls (Daikin Applied Europe) have?

This list has 431 BACnet objects: 106 analog inputs, 38 analog outputs, 134 analog values, 72 binary inputs, 5 binary outputs, 2 multi-state outputs, 1 schedule, 31 multi-state values, 42 positive integer values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Daikin Applied ADK digital air handler, DSTREAM controls (Daikin Applied Europe) BACnet points are writable?

61 of the 431 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Daikin Applied ADK digital air handler, DSTREAM controls (Daikin Applied Europe) BACnet documentation?

The source is BAS integration guide - BACnet protocol (ADK (Digital AHU)) (D-EIGOC00108-22_05EN), published free by Daikin Applied at https://www.daikinapplied.uk/hubfs/portale-documentale/D_EIGOC00108_22_05EN_ADK.pdf.

What are the minimum BACnet points to integrate the Daikin Applied ADK digital air handler, DSTREAM controls (Daikin Applied Europe)?

Start with MV 26007 NetworkCtrlBMS (BMS mode: Auto/Off/On/Ventilation/Economy/Boost); MV 28594 SuWiNetworkChgover (Summer/winter command (1 = Winter, 2 = Summer)); MV 9493 SuWiChgSrc (Must be 3 = BMS for the summer/winter command); AV 8970 TmpSpvCoSpvClg (Comfort cooling setpoint); AV 22817 TmpSpvCoSpvHtg (Comfort heating setpoint); MV 39130 AckAlmPls (Acknowledge all alarms (2 = On)); MV 6080 ActOpMode (Operating mode (Off/On/Ventilation/Economy/Boost)); AI 45150 SupplyTmp (Supply air temperature); AV 52988 ActCtrlVal (Temperature being controlled); BO 5714 AlmOutHigh (General alarm (1 = Alarm)).

How do I enable BMS control of the Daikin Applied ADK digital air handler, DSTREAM controls (Daikin Applied Europe)?

NetworkCtrlBMS (MV 26007, 1 = Auto, 2 = Off, 3 = On, 4 = Ventilation, 5 = Economy, 6 = Boost) is the BMS operating command; NetworkCtrl (MV 24562) is the on/off source used by a Daikin iTM. ActOpSta (MV 32321) reports 11 = BMS when the network is in control. Summer/winter changeover follows the BMS only when SuWiChgSrc (MV 9493) = 3 (BMS); then write SuWiNetworkChgover (MV 28594).

Does the Daikin Applied ADK digital air handler, DSTREAM controls (Daikin Applied Europe) need a BACnet heartbeat or have a communication timeout?

No BMS heartbeat is described. Fan setpoints SplyFanSpvP2PCommAlm / RtrnFanSpvP2PCommAlm (AV 59879/18352) apply only when the controllers' peer-to-peer link fails.
