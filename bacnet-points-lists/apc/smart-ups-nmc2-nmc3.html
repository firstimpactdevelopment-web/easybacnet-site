BMS integration notes: APC Smart-UPS with Network Management Card 2 / 3 (BACnet IP)

Integration in brief

Enable BACnet on the Network Management Card (sumx/su firmware) and give the card a unique device instance. Read UPS state (MV 5), runtime remaining (AV 0), battery charge (AV 66), load (AV 19) and the alarm flags such as OnBattery, LowBattery and Overload. UPS Control (MV 6) and the outlet-group control MVs switch the UPS or its outlets, so restrict who can write them.

Enable & remote start

BACnet IP is part of the NMC2 'sumx' and NMC3 'su' application firmware and is turned on in the card's configuration. No BMS enable point is needed; UPS Control (MV 6) acts directly on the UPS.

Network setup

  • BACnet IP only; BACnet is configured on the Network Management Card (device instance and related settings are covered in the NMC User Guide).
  • Check the UPS model prefix on the UPS label (SMT/SMX/SRT, SURT, SURTD) to know which objects it will have.
  • On NMC3 firmware 3.1, read the object list again: several BV, MV and CSV instances shift (see notes).
  • Alarm BVs can send event notifications; add the BMS as a recipient of NC 0 DefaultNotifier.

Watch out for

  • Writing UPS Control or an outlet-group control MV can switch off the protected load.
  • BV 23-26 start real UPS tests (self test, alarm tests, runtime calibration); BV 27 cancels a running test.
  • Universal I/O probe objects exist only with an AP9631/AP9635 card and a probe fitted.
  • Instances differ between NMC2/NMC3 below 3.0 and NMC3 3.1 for alarm flags; remap after a card firmware upgrade.

Integration notes

  • Instances are the NMC2 / NMC3 (< v3.0) index column. NMC3 firmware 3.1 renumbers some objects: BV 51-68 move up by 1 and BV 69-237 (alarm flags) move up by 2; MV 13-14 move up by 1; CSV 27-34 move up by 2. Index 47 'UIO probe 1 contact 1 severity' prints as 48 in the v3.1 column.

How many BACnet points does the APC Smart-UPS with Network Management Card 2 / 3 (BACnet IP) have?

This list has 390 BACnet objects: 101 analog values, 238 binary values, 1 notification class, 15 multi-state values, 35 characterstring values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which APC Smart-UPS with Network Management Card 2 / 3 (BACnet IP) BACnet points are writable?

151 of the 390 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

What are the minimum BACnet points to integrate the APC Smart-UPS with Network Management Card 2 / 3 (BACnet IP)?

Start with MV 6 UPS Control (UPS on/off/reboot/sleep/bypass command); MV 5 UPS state (Online, on battery, bypass, fault and so on); AV 0 Runtime remaining (Battery runtime left, s); AV 66 Battery state of charge (Battery charge, %); AV 19 Output watts phase 1 (Load as % of the watt rating); AV 10 Output voltage 1 (Output voltage, V); BV 73 OnBattery (UPS is running on battery); BV 72 LowBattery (Battery low alarm); BV 70 Overload (Output overload alarm); BV 69 LostUPSComm (Card lost communication with the UPS).

How do I enable BMS control of the APC Smart-UPS with Network Management Card 2 / 3 (BACnet IP)?

BACnet IP is part of the NMC2 'sumx' and NMC3 'su' application firmware and is turned on in the card's configuration. No BMS enable point is needed; UPS Control (MV 6) acts directly on the UPS.
