Short answer

LG's ACP BACnet controller serves every indoor unit, ventilation unit and outdoor unit on its LG-NET as a fixed block of BACnet IP objects. The instance number is built from the product type, the unit address and the point number, so one table covers every unit: on/off, mode, fan speed, setpoint, room temperature, alarm and error code for indoor units, plus ERV and outdoor unit data.

This page lists 75 BACnet objects for the LG ACP BACnet gateway (PQNFB17C0 / PQNFB17C1) — 27 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from a copy of LG’s documentation hosted by SupplyHouse.com, not by LG itself, so treat it as unofficial.

BMS integration notes: LG ACP BACnet gateway (PQNFB17C0 / PQNFB17C1)

Integration in brief

Set the ACP BACnet's IP and Device ID (default 9000) on its front panel, let it find the units on LG-NET, then map each indoor unit's block at address x 256: on/off, mode, fan speed, setpoint and room temperature first, plus alarm and error code.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Integration notes

  • Instance = product type x 65536 + unit address x 256 + point number. Product type: indoor 0, ventilation 1, AHU 2, outdoor unit 3, AWHP 4, general 5. The unit address is LG's address read as hex (tag 1A = 26). Instances here are for unit address 00 (e.g. indoor point 13 = AV 13, address 1A = AV 6669).
  • Each product type is its own BACnet device: indoor units on the Device ID (default 9000), ERV +1, AHU +2, outdoor unit cycle data +3, AWHP +4. The product type bits stay in the object instance.
  • LG's examples: address 1 point 1 = 257, address 47 (0x2F) point 1 = 12033, ventilation address 0 point 1 = 65537.
  • Points 35-49 work only when 2Set Auto Mode is enabled in the environment settings; the manual adds that PQNFB17C0 does not support them.
  • Indoor point 28 (SetLowerTempCommand) is printed as AI; LG's BNU-BAC and AC Smart 5 manuals list it as AV. Check which one the gateway exposes.
  • The indoor table leaves the object type of point 16 (MalfunctionCode) blank; the ventilation table gives AI.
  • Outdoor unit data is for the master unit only, and some values read 0 on some models. The AHU and AWHP tables in the manual are not included here.
  • The manual has no read/write column: access is inferred from the object type and the Setting/Status labels.

Questions about the LG ACP BACnet gateway (PQNFB17C0 / PQNFB17C1)

How many BACnet points does the LG ACP BACnet gateway (PQNFB17C0 / PQNFB17C1) have?

This list has 75 BACnet objects: 24 analog inputs, 8 analog values, 17 binary inputs, 10 binary outputs, 2 binary values, 8 multi-state inputs, 6 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which LG ACP BACnet gateway (PQNFB17C0 / PQNFB17C1) BACnet points are writable?

27 of the 75 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official LG ACP BACnet gateway (PQNFB17C0 / PQNFB17C1) BACnet documentation?

LG does not publish it on its own website. This list comes from BACnet Gateway (ACP BACnet) Installation/User Manual (MFL67709501), revision 2014, a copy hosted by SupplyHouse.com at https://s3.amazonaws.com/s3.supplyhouse.com/product_files/LG-PQNFB17C1-Install-Instructions.pdf. Ask LG or its representative for the current revision.

What are the minimum BACnet points to integrate the LG ACP BACnet gateway (PQNFB17C0 / PQNFB17C1)?

Start with BO 1 StartStopCommand_XXX (On/off (address x 256 + 1)); MO 7 ModeCommand_XXX (1 Cool, 2 Dry, 3 Fan, 4 Auto, 5 Heat); MO 11 FanSpeedCommand_XXX (1 Low, 2 Middle, 3 High, 4 Auto); AV 13 SetRoomTemp_XXX (Setpoint); AI 14 RoomTemp_XXX (Room temperature); BI 15 Alarm_XXX (Unit alarm); AI 16 MalfunctionCode_XXX (LG error code).

How do I check these points on the real ACP BACnet gateway (PQNFB17C0 / PQNFB17C1)?
