Short answer

The MS8650 is LG's MultiSITE touchscreen room controller for rooftop units, heat pumps and indoor air quality. It is a BACnet MS/TP application specific controller (B-ASC) with about 310 objects: room, outdoor and supply temperature, setpoints, system and fan mode, Y/W/G stage outputs, economizer and CO2 ventilation settings, alarms, Wi-Fi status and paired ZigBee wireless sensor objects.

BMS integration notes: LG MultiSITE MS8650 Room Controller (rooftop / heat pump / IAQ)

Integration in brief

Command occupancy with MV 10, mode with MV 16 and fan mode with MV 17, and write the occupied setpoints AV 39/AV 40. Read AV 100 room temperature, MI 33 effective occupancy and MV 112 control status, plus the G fan output BO 25 and the fan lock alarm BV 39.

Enable & remote start

The BMS writes MV 10 Occupancy Command (1 = Loc. occ; 2 = Occupied; 3 = Unocc.) and MV 16 System Mode. MV 110 chooses whether local occupancy follows motion or the schedule.

Sensors & values from the BMS

The guide does not describe feeding room temperature from the BMS. MV 145 selects the wired, internal or a paired ZigBee wireless sensor, and MI 312 Effective Temperature Sensor shows which one is in use. Writing an AI present value only works with Out_Of_Service set TRUE.

Network setup

  • BACnet MS/TP baud rate is MV 8 (9600, 19200, 38400, 57600, 76800, 115200 or Auto; default Auto). Max_Master is writable, 0-127, default 127.
  • AV 10 COM Address holds the MS/TP address. Device Object_Identifier and Object_Name are writable; no default device instance is printed.
  • MI 317 BACnet IP Status shows whether BACnet IP is enabled; separate Wi-Fi objects report the Wi-Fi module state.
  • The controller is a B-ASC with COV, time synchronization and an internal schedule (SCHED-I-B); it does not support segmented requests or responses.

Watch out for

  • For the MS8350 the guide says writes at some priority levels go to EEPROM (locked at the controller and kept through a power cycle until released at the same priority or by Restore Factory Default) and others to RAM (lost on a power cycle), but it does not print which priority numbers fall in each group.
  • On the MS8350 the relinquish default is the value set at the thermostat and it survives power cycles; on the MS8650 the relinquish default of AV 100 and above is read-only.
  • Keep Read Property Multiple requests small; segmentation is not supported.

Integration notes

  • Access follows the guide's object-property tables: AV, AO, BV, BO and MSV present values are commandable, CSVs writable, and AI/MSI present values only writable while Out_Of_Service is TRUE.
  • The guide gives no description column, only default, range and a units/state column; descriptions here show the printed default and range.
  • Some object names print the subscript 2 of CO2 out of place (e.g. 'CO level 2'); they are written as CO2 here (AV 106 'CO2 level').
  • Wireless Device objects only report data for paired ZigBee Pro sensors.
  • The guide mentions 10 program (PG) objects for LUA4RC scripts but does not list them.
  • MI 312 prints its last state as '4 = WL GP' (the MS8350 table has 14); MV 110 is named 'Occupancy Screen' in the MS8650 table. Both are kept as printed.

Questions about the LG MultiSITE MS8650 Room Controller (rooftop / heat pump / IAQ)

How many BACnet points does the LG MultiSITE MS8650 Room Controller (rooftop / heat pump / IAQ) have?

This list has 311 BACnet objects: 34 analog inputs, 8 analog outputs, 84 analog values, 7 binary inputs, 9 binary outputs, 28 binary values, 40 multi-state inputs, 91 multi-state values, 10 characterstring values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which LG MultiSITE MS8650 Room Controller (rooftop / heat pump / IAQ) BACnet points are writable?

230 of the 311 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official LG MultiSITE MS8650 Room Controller (rooftop / heat pump / IAQ) BACnet documentation?

The source is MultiSITE MS8000 Series Room Controllers BACnet Integration Guide (MS8350 VUCQMS8350, MS8650 VUCQMS8650) (UM_MultiSITE_MS8000_Series_BACnet_Integration_05_20), revision 2020-05, published free by LG at https://media.us.lg.com/m/11d3a44fc9cab7aa/original/UM_MultiSITE_MS8000_Series_BACnet_Integration-pdf.pdf.

What are the minimum BACnet points to integrate the LG MultiSITE MS8650 Room Controller (rooftop / heat pump / IAQ)?

Start with MV 10 Occupancy Command (BMS occupancy: local, occupied or unoccupied); MV 16 System Mode (Off / auto / cool / heat); MV 17 Fan Mode (Fan mode: on / auto / smart); AV 39 Occ. Heat (Occupied heating setpoint); AV 40 Occ. Cool (Occupied cooling setpoint); MV 112 Control Status (Current state: off, cooling or heating); BO 25 G Fan Status (Fan (G) output state); MI 33 Effective Occupancy (Actual occupancy state); AV 100 Room Temperature (Space temperature used for control); BV 39 Fan Lock Alarm (Fan lock alarm (1 = on)).

How do I enable BMS control of the LG MultiSITE MS8650 Room Controller (rooftop / heat pump / IAQ)?

The BMS writes MV 10 Occupancy Command (1 = Loc. occ; 2 = Occupied; 3 = Unocc.) and MV 16 System Mode. MV 110 chooses whether local occupancy follows motion or the schedule.

Can the BMS supply sensor values to the LG MultiSITE MS8650 Room Controller (rooftop / heat pump / IAQ)?

The guide does not describe feeding room temperature from the BMS. MV 145 selects the wired, internal or a paired ZigBee wireless sensor, and MI 312 Effective Temperature Sensor shows which one is in use. Writing an AI present value only works with Out_Of_Service set TRUE.
