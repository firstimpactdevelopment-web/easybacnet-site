LG MultiSITE CRC2+Z Remote Controller (PREMTBVC4) BACnet points list

Updated 4 November 2026

Short answer

The CRC2+Z is LG's touchscreen wall controller for LG indoor units. It talks LG V-Net (RS-485) to the indoor units and exposes about 360 BACnet objects on BACnet MS/TP, with optional BACnet wireless IP through a Wi-Fi module. The submittal splits the objects into commandable points (on/off, mode, fan speed, setpoints, setback and override settings, display options) and monitor points (room temperature, error codes, pipe temperatures, ZigBee sensor values).

This page lists 362 BACnet objects for the LG MultiSITE CRC2+Z Remote Controller (PREMTBVC4) — 130 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from LG’s own free documentation, linked below.

BMS integration notes: LG MultiSITE CRC2+Z Remote Controller (PREMTBVC4)

Integration in brief

Turn the indoor unit(s) on/off with MV 528 IDUonOff, set the mode with MV 16 and fan speed with MV 17, and write the setpoints (AV 39/AV 40 for dual setpoint, or AV 507 for single setpoint as chosen by MV 538). Read AV 100 room temperature, MI 602 occupancy status, AI 503 current error code and BV 500 filter alarm.

Network setup

  • BACnet MS/TP is built in; BACnet wireless IP needs the optional VCM8002V504 Wi-Fi module.
  • AV 10 BACnetComAddr is the BACnet communications address; AV 16 is the BACnet stack poll rate.
  • The controller connects to the indoor units over LG V-Net (3-conductor 22 AWG, up to 164 ft) and can group up to 16 indoor units.

Watch out for

  • MV 538 SingleDualSP decides whether AV 507 or AV 39/AV 40 is in use.
  • Central controller limits (AI 510-515) can restrict the setpoint range.
  • BV 557 TestModeOccupancy is marked 'Reserved/Do Not Use'.
  • AV 56 ConfigPassword and AV 57 UserPassword hold the controller passwords.

Integration notes

  • The submittal gives object name, type, ID and description only. Access is inferred from its two sections: objects in 'COMMANDABLE Points' are marked commandable (C) or writable (W for AI/CSV), objects in 'MONITOR Points' read-only.
  • No state texts or units are printed; read State_Text and Units from the controller.
  • BACnet IP is wireless and needs the optional VCM8002V504 Wi-Fi module.
  • ZB_Zone1-20 objects only report data for paired ZigBee Pro sensors (up to 20).
  • Some printed descriptions repeat odd text (MV 790 'Ovverride', MI 188 Zone8 description on the Zone9 object); names are kept as printed.
  • Available functions differ with the connected indoor unit; some points apply only to dual vane 4-way cassettes or ventilation AHUs.

How many BACnet points does the LG MultiSITE CRC2+Z Remote Controller (PREMTBVC4) have?

This list has 362 BACnet objects: 80 analog inputs, 1 analog output, 58 analog values, 2 binary inputs, 2 binary outputs, 15 binary values, 93 multi-state inputs, 82 multi-state values, 29 characterstring values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which LG MultiSITE CRC2+Z Remote Controller (PREMTBVC4) BACnet points are writable?

130 of the 362 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
