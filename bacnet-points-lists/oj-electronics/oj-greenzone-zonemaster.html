Short answer

The OJ GreenZone ZoneMaster coordinates up to 25 ZoneModules (room VAV, valve and sensor controllers) and the air handling unit for demand-controlled ventilation. Its EDE lists AHU and section values, then a fixed block of about 59 objects for each of ZoneModules 1-25: room and supply temperatures, CO2/VOC and RH, VAV flows and damper positions, valve outputs, setpoints and alarm bitmaps.

BMS integration notes: OJ Electronics OJ GreenZone ZoneMaster, SW 3.47

Integration in brief

To drive the system from the BMS, set BV 110 to take digital inputs from the BMS, then use BV 103 (start), BV 105 / BV 106 (max / min air) and BV 104 (fire). Read AI 111 and AI 104 for operation and AHU status, each ZoneModule's room temperature and alarm bitmaps, and AI 109 for the section alarm.

Enable & remote start

Going by the object names, BV 110 (Enable Digital Input Values from BMS) has to be on before the BMS input values BV 103-109 (start, fire, max/min air, summer night cooling) are used. The EDE has no further explanation.

Network setup

  • The EDE gives device instance 22020 and device name OJ-ZoneMaster.

Watch out for

  • The EDE is a full map for 25 ZoneModules; only the installed ones carry data.
  • Alarm bitmaps (AI xx25-xx28 per zone) must be split into bits.

Questions about the OJ Electronics OJ GreenZone ZoneMaster, SW 3.47

How many BACnet points does the OJ Electronics OJ GreenZone ZoneMaster, SW 3.47 have?

This list has 1544 BACnet objects: 827 analog inputs, 596 analog values, 110 binary inputs, 11 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which OJ Electronics OJ GreenZone ZoneMaster, SW 3.47 BACnet points are writable?

607 of the 1544 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official OJ Electronics OJ GreenZone ZoneMaster, SW 3.47 BACnet documentation?

The source is OJ GreenZone ZoneControl EDE file (installer), v3.47 (67851), revision 06-07-2020, published free by OJ Electronics at https://ojelectronics.com/controllers-sensors/wp-admin/admin-ajax.php?action=productdownload&media_id=46526948&filename=67851-ZoneControl_v347_ede-installer.csv.

What are the minimum BACnet points to integrate the OJ Electronics OJ GreenZone ZoneMaster, SW 3.47?

Start with BV 103 DIN Start (BMS) (Start command from the BMS); BV 110 Enable Digital Input Values from BMS (Use BMS values instead of the digital inputs); BV 105 DIN Max Air (BMS) (Max air command from the BMS); BV 106 DIN Min Air (BMS) (Min air command from the BMS); BV 112 Clear All Alarms (BMS) (Clear all alarms); AI 111 ZoneMaster Operation Mode (Current operating mode of the zone system); AI 104 AHU status (Status of the air handling unit); AI 1009 ZoneModule 1 Room Temperature Actual Value (ZoneModule 1 room temperature); AI 109 Section Master Alarm Status (Section master alarm status).

How do I enable BMS control of the OJ Electronics OJ GreenZone ZoneMaster, SW 3.47?

Going by the object names, BV 110 (Enable Digital Input Values from BMS) has to be on before the BMS input values BV 103-109 (start, fire, max/min air, summer night cooling) are used. The EDE has no further explanation.
