Short answer

Each TMW module has its own factory controller (IO FLEX6126 with an EX8160 expander) that talks BACnet MS/TP, Modbus or N2 on the same port, chosen with DIP switches. The points list covers physical inputs and outputs, BAS enable commands for cooling and heating, leaving-water targets, compressor and valve status, setpoints and tuning values, and a long block of alarm BVs. One device per module.

BMS integration notes: ClimateMaster Tranquility Large Water-to-Water (TMW) 360-840

Integration in brief

Set the module's MS/TP address on the two rotary switches and the protocol and baud rate on the DIP switches. To run a module from the BAS, open the local enable inputs, write the leaving-water target (cool_temp_stp_1 or heat_temp_stp_1), turn the opposite mode's BAS enable off and the wanted one on, start the pumps once the motorized valves report open, and watch the flow and run status points.

Enable & remote start

The local digital enable inputs (dig_cool_enable_1 BI 4 and dig_heat_enable_1 BI 5) must be open. Then write cool_enable_bas_1 (BV 52) or heat_enable_bas_1 (BV 53) ON, with the other one OFF.

Network setup

  • Two rotary switches set the hardware address 02-99; it is read only at power-up and must be unique on the MS/TP segment.
  • DIP switches 1 and 2 set the baud rate (9600, 19.2k, 38.4k or 76.8k); DIP switches 5, 7 and 8 select MS/TP, N2 or Modbus.
  • The device ID is shown in the list as DEV:2460xx.

Watch out for

  • The cool leaving-water target accepts 42-62 °F and the heat target 80-135 °F.
  • Start the load and source pumps only after the motorized valves report open (BV 107, mot_vlv_status_1); the module will not run until both flows are proven.
  • Most alarms need a reset at the controller or from the BAS (reset BVs); high pressure also needs the manual reset on the unit's high-pressure switch.

Integration notes

  • The Read Only column of the list is used for access. AV/BV points without the read-only mark are shown as writable; many of them are configuration and tuning values. Nine alarm and calculated points with no Modbus mapping (so the column is blank) are shown read-only.
  • Descriptions are the list's own labels; the bracketed tag is the list's Note column: Physical I/O, Key status, BAS command input, Alarm reset or Alarm.
  • The Value column of the list holds sample live readings, not defaults. Units are taken from it where shown, so many temperature points have no unit here.
  • Object names end in _1 as printed; the object type labels in the list (BAI, BAV, BBV, BALM, BMSV) map to AI, AV, BV, BV and MSV.
  • AI:24 is not in the list (the AI numbers jump from 23 to 25).
  • The BAS start-up sequence in the manual calls the valve and source-flow points mot_valve_status_1 and source_flow_1; in the points list they are mot_vlv_status_1 (BV 107, mot_vlv_status_1) and src_flow_1 (BV 73).

Questions about the ClimateMaster Tranquility Large Water-to-Water (TMW) 360-840

How many BACnet points does the ClimateMaster Tranquility Large Water-to-Water (TMW) 360-840 have?

This list has 303 BACnet objects: 24 analog inputs, 2 analog outputs, 126 analog values, 6 binary inputs, 6 binary outputs, 130 binary values, 9 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which ClimateMaster Tranquility Large Water-to-Water (TMW) 360-840 BACnet points are writable?

110 of the 303 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official ClimateMaster Tranquility Large Water-to-Water (TMW) 360-840 BACnet documentation?

The source is Tranquility Large Water-to-Water (TMW) Series Models 360-840 - Installation, Operation & Maintenance (BACnet, Modbus, N2 Points List) (97B0090N01), revision 2021-11-29, published free by ClimateMaster at https://files.climatemaster.com/97b0090n01-climatemaster-commercial-tranquility-large-tmw-water-source-heat-pump-installation-manual.pdf.

What are the minimum BACnet points to integrate the ClimateMaster Tranquility Large Water-to-Water (TMW) 360-840?

Start with BV 52 cool_enable_bas_1 (BAS cooling enable); BV 53 heat_enable_bas_1 (BAS heating enable); AV 83 cool_temp_stp_1 (Leaving chilled water target); AV 88 heat_temp_stp_1 (Leaving hot water target); BV 75 reset_all_1 (Reset alarms from the BAS); BV 107 mot_vlv_status_1 (Valves open - start the pumps); BV 38 flow_1 (Load and source flow proven); BV 21 run_cool_1 (Module running in cooling); BV 22 run_heat_1 (Module running in heating); BV 7 alarm_bo_1 (Module alarm output status).

How do I enable BMS control of the ClimateMaster Tranquility Large Water-to-Water (TMW) 360-840?

The local digital enable inputs (dig_cool_enable_1 BI 4 and dig_heat_enable_1 BI 5) must be open. Then write cool_enable_bas_1 (BV 52) or heat_enable_bas_1 (BV 53) ON, with the other one OFF.
