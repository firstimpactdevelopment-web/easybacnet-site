Short answer

Each SWT module controller works under a bank controller and can be read by a BMS over BACnet MS/TP or BACnet IP (Gig-E port only). The 159-point list is mostly status: circuit pressures, temperatures, superheat and subcool, EEV positions, loop valves and flows, compressor status and run time, out-of-range sensor flags and alarms, plus manual-mode test commands and the bank's leaving-water targets.

BMS integration notes: ClimateMaster Tranquility Large Water-to-Water (SWT) 20-80 ton

Integration in brief

Set the module controller address on its three rotary switches and choose MS/TP with the Comm Selector rotary (position 1), or use the Gig-E port for BACnet IP. The modules are run by their bank controller; a BMS mainly monitors module status and alarms and can read or adjust the bank's leaving-water targets.

Enable & remote start

BV 2076 chiller_run_1 is the module enable from the bank controller; the manual does not describe a separate BMS enable.

Heartbeat & communication loss

BV 2068 comm_lost_1 alarms when the module loses communication with the bank controller; BV 2152 mod_comm_tx_stat_1 shows the module's communication transmit status.

Network setup

  • Address: set the hundreds, tens and ones rotary switches to the controller address (for example 0-0-1 for 001), before powering the unit.
  • Comm Selector rotary switch at 1 = BACnet MS/TP.
  • BACnet IP is only on the Gig-E Ethernet port; connect a CAT 5e cable there.

Watch out for

  • Manual-mode objects override normal control; check BV 2210 manual_mode_1 and AV 2175 man_mode_remain_time_1 before leaving a module.
  • The list gives no engineering units; check them on the device.

Questions about the ClimateMaster Tranquility Large Water-to-Water (SWT) 20-80 ton

How many BACnet points does the ClimateMaster Tranquility Large Water-to-Water (SWT) 20-80 ton have?

This list has 159 BACnet objects: 62 analog values, 97 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which ClimateMaster Tranquility Large Water-to-Water (SWT) 20-80 ton BACnet points are writable?

41 of the 159 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official ClimateMaster Tranquility Large Water-to-Water (SWT) 20-80 ton BACnet documentation?

The source is Tranquility Large Water-to-Water SWT Series - Installation, Operation & Maintenance Manual (Controller Points List) (C97B0004N07), revision 2026-03-09, published free by ClimateMaster at https://files.climatemaster.com/Commercial/Water-to-Water-Units/Tranquility/SWT/Resources/C97B0004N07-SWT-IOM.pdf.

What are the minimum BACnet points to integrate the ClimateMaster Tranquility Large Water-to-Water (SWT) 20-80 ton?

Start with AV 2156 cool_temp_stp_1 (Bank chilled water target); AV 2155 heat_temp_stp_1 (Bank hot water target); BV 2069 reset_alarms_1 (Reset all module alarms); BV 2073 module_run_1 (Module running); AV 2158 sysmode_1 (Module mode); BV 2074 module_ok_1 (Module condition); AV 2147 loop1_leaving_temp_1 (Loop 1 leaving water temperature); BV 2075 manager_lockout_alrm_1 (Module locked out); AV 2167 mod_act_mod_alarms_1 (Active module alarms).

How do I enable BMS control of the ClimateMaster Tranquility Large Water-to-Water (SWT) 20-80 ton?

BV 2076 chiller_run_1 is the module enable from the bank controller; the manual does not describe a separate BMS enable.

Does the ClimateMaster Tranquility Large Water-to-Water (SWT) 20-80 ton need a BACnet heartbeat or have a communication timeout?

BV 2068 comm_lost_1 alarms when the module loses communication with the bank controller; BV 2152 mod_comm_tx_stat_1 shows the module's communication transmit status.
