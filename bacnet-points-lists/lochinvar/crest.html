BMS integration notes: Lochinvar Crest

Integration in brief

Pick the BMS control mode at the boiler, then write AV 0 Configuration so the unit knows which values the BAS will supply. After that the BAS sends an enable, a rate command (AV 2), or both, and keeps rewriting them. Status, temperatures and the status, blocking and lockout codes can be read without taking control.

Enable & remote start

Set the Demand Configuration under Main Menu > Setup > BMS. ENABLE active / BMS inactive: local setpoints plus BV 0 enable. ENABLE and BMS active: BV 0 enable plus AV 2 rate or setpoint command. ENABLE inactive / BMS active: AV 2 modulation % or setpoint alone. Always set the matching AV 0 bits first. AV 2 means firing % or temperature setpoint depending on the BMS Type setting (Power or Setpoint); as a setpoint it is scaled like a 0-10 V signal between the BMS temperatures at low and high input.

Heartbeat & communication loss

If BAS-written temperatures stop arriving within the timeout, the unit reverts to its own sensor inputs. On Crest the timeout is programmable from 5 to 120 s (Main Menu > Setup > BAS); Lochinvar recommends the shortest value. On Hellcat and Regent it is fixed at 300 s. Other commands must be refreshed at least every 4 minutes or the boiler runs on its own inputs.

Sensors & values from the BMS

Set the AV 0 bits for the values the BAS will supply, then write them to the analog values: AV 3 tank setpoint, AV 4 tank temperature, AV 5 outdoor temperature, AV 6 system supply temperature, AV 7 system return temperature. Values are in °C. Temperatures must be rewritten every few seconds or the unit returns to its own sensors.

Network setup

  • MAC address from dip switches 1-8 (master only, so 0-127); baud from switches 9-10: 9600, 19200, 38400 or 76800.
  • Device instance = base + MAC address; bases are 610000 (FB 751-2001), 670000 (FB 2501-6001) and 680000 (FCB1000-6000). The base can be changed (0-4194048).

Watch out for

  • The manual says to resend the AV 0 configuration bits before each command.
  • In a cascade only the Leader needs the BACnet board for control; it then reports cascade totals only, so fit a board to every unit to see each one.
  • Without BMS mode active the board is monitor-only: the read-only points can be polled while the unit runs on its own controls.
  • Several BI/AI points exist only on certain Crest sizes or on FCB models; check the size notes in each description.

Integration notes

  • BACnet needs the optional Lochinvar Modbus/BACnet communication board; address and baud rate are set on its dip switches.
  • The BACnet board is an MS/TP master only, so MAC addresses 0-127 are usable.
  • AV 0 (Configuration) is a bitmask: set a bit to 1 to make the appliance use the BAS-written value instead of its own input.
  • BAS-supplied temperatures must be rewritten every few seconds and other commands at least every 4 minutes, or the unit reverts to local control.
  • Temperatures are in °C on the bus.
  • Several points only exist on certain Crest sizes; the size range is given in the point description.

Questions about the Lochinvar Crest

How many BACnet points does the Lochinvar Crest have?

This list has 77 BACnet objects: 34 analog inputs, 8 analog values, 33 binary inputs, 2 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Lochinvar Crest BACnet points are writable?

10 of the 77 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Lochinvar Crest BACnet documentation?

The source is Modbus and BACnet Communication Instructions (Crest FB/OF751-6001, FCB1000-6000 & Regent IWH500-1000) (100161012_2000020084), revision Rev X, 04/26, published free by Lochinvar at https://assets.lochinvar.com/damroot/Original/10017/MODB_100161012_2000020084_REV%20X_(71343).pdf.
