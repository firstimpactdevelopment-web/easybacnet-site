Short answer

Lochinvar's SMART TOUCH boilers and water heaters talk BACnet MS/TP through an add-on Modbus/BACnet communication board. The object map is small and fixed: binary values for enable and thermostat commands, binary inputs for safety switches and relay states, analog inputs for temperatures, firing rate and status codes, and analog values the BAS can write for setpoints and remote sensor values.

BMS integration notes: Lochinvar Knight / Armor (SMART TOUCH)

Integration in brief

Pick the BMS control mode at the boiler, then write AV 0 Configuration so the unit knows which values the BAS will supply. After that the BAS sends an enable, a rate command (AV 2), or both, and keeps rewriting them. Status, temperatures and the status, blocking and lockout codes can be read without taking control.

Enable & remote start

At the control enter installer code 5309, open Control Modes and set BMS to Active (BMS TSTAT for remote DHW). Set the matching AV 0 bits, then enable with BV 0 (also packed in AV 1). Mode 1: local setpoints plus BAS enable. Mode 2: enable plus AV 2 rate command. Mode 3: AV 2 modulation % alone, which also acts as the enable. AV 2 means firing % or temperature setpoint depending on the BMS Type setting (Power or Setpoint); as a setpoint it is scaled like a 0-10 V signal between the BMS temperatures at low and high input (defaults 2 V = 69.8 °F / 21 °C, 10 V = 179.6 °F / 82 °C).

Heartbeat & communication loss

If BAS-written temperatures or commands stop arriving, the unit reverts to its own sensors and controls. The Modbus T/O timer (installer menu, Control Modes, Modbus T/O; 5-120 s, default 10 s) is reset by every write; Lochinvar recommends the shortest setting. Commands without temperatures must still be refreshed at least every 4 minutes.

Sensors & values from the BMS

Set the AV 0 bits for the values the BAS will supply, then write them to the analog values: AV 3 tank setpoint, AV 4 tank temperature, AV 5 outdoor temperature, AV 6 system supply temperature. Values are in °C. Temperatures must be rewritten every few seconds or the unit returns to its own sensors.

Network setup

  • MAC address from dip switches 1-8 (master only, so 0-127); baud from switches 9-10: 9600, 19200, 38400 or 76800.
  • Device instance = base 600000 + MAC address; the base can be changed and reset by setting dip switches 1-8 on at power-up.
  • Default device name is "MTR-01 BACnet".

Watch out for

  • The manual says to resend the AV 0 configuration bits before each command.
  • In a cascade only the Leader needs the BACnet board for control; it then reports cascade totals only, so fit a board to every unit to see each one.
  • Without BMS mode active the board is monitor-only: the read-only points can be polled while the unit runs on its own controls.
  • The manual's control-mode tables use the Modbus register numbering alongside the AV numbers; AV 1 is the packed copy of the BV commands.

Integration notes

  • BACnet needs the optional Lochinvar Modbus/BACnet communication board; address and baud rate are set on its dip switches.
  • The BACnet board is an MS/TP master only, so MAC addresses 0-127 are usable.
  • AV 0 (Configuration) is a bitmask: set a bit to 1 to make the appliance use the BAS-written value instead of its own input.
  • BAS-supplied temperatures must be rewritten every few seconds and other commands at least every 4 minutes, or the unit reverts to local control.
  • Temperatures are in °C on the bus.
  • Default device name is "MTR-01 BACnet".

Questions about the Lochinvar Knight / Armor (SMART TOUCH)

How many BACnet points does the Lochinvar Knight / Armor (SMART TOUCH) have?

This list has 44 BACnet objects: 16 analog inputs, 7 analog values, 17 binary inputs, 4 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Lochinvar Knight / Armor (SMART TOUCH) BACnet points are writable?

11 of the 44 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
