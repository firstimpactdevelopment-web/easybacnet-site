Integration in brief

Discover the controller, check the application objects in KMC Connect if any are missing, then map occupancy, occupied setpoints and mode from the BMS and read space temperature and the equipment status points.

Enable & remote start

Occupancy is controlled through value objects such as MSV1 Occupied Mode and BV6 motion sensor; KMC's troubleshooting section says to check these when occupancy does not change.

Sensors & values from the BMS

Room temperature and setpoint come from STE-9000 NetSensors (mapped to value objects) or from AI1/AI2 analog sensors.

Network setup

  • Conquest controllers are BACnet MS/TP, or BACnet IP on Ethernet models.
  • Use KMC Connect, Converge or TotalControl to view or recreate objects.

Watch out for

  • Do not reuse objects reserved for KMC default programs for custom programming; create new ones.
  • A restart can zero objects or return present values to relinquish defaults depending on restart type.

Questions about the KMC Controls Conquest BAC-9301A four-pipe fan coil (Gen6)

How many BACnet points does the KMC Controls Conquest BAC-9301A four-pipe fan coil (Gen6) have?

This list has 102 BACnet objects: 7 analog inputs, 4 analog outputs, 37 analog values, 1 binary input, 6 binary outputs, 41 binary values, 6 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which KMC Controls Conquest BAC-9301A four-pipe fan coil (Gen6) BACnet points are writable?

60 of the 102 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official KMC Controls Conquest BAC-9301A four-pipe fan coil (Gen6) BACnet documentation?

The source is Conquest Gen6 Controller Application Guide (AG250415B), published free by KMC Controls at https://www.kmccontrols.com/wp-content/uploads/kmc_documents/AG_Conquest-Controllers-Gen6_SAG250415B.pdf.

What are the minimum BACnet points to integrate the KMC Controls Conquest BAC-9301A four-pipe fan coil (Gen6)?

Start with MV 1 OCCUPIED MODE (Occupancy command); AV 5 OCC_CL_STPT (Occupied cooling setpoint, °F); AV 6 OCC_HT_STPT (Occupied heating setpoint, °F); MV 2 SYSTEM_MODE (Heat / cool / auto mode); AV 1 SPACE_TEMP (Space temperature, °F); AV 3 ACT_COOL_STPT (Active cooling setpoint, °F); MV 8 OCCUPIED STATE (Current occupancy state); AI 3 DISCHARGE AIR (Discharge air temperature, °F); BV 14 FAN_STATUS (Fan proof status).

How do I enable BMS control of the KMC Controls Conquest BAC-9301A four-pipe fan coil (Gen6)?

Occupancy is controlled through value objects such as MSV1 Occupied Mode and BV6 motion sensor; KMC's troubleshooting section says to check these when occupancy does not change.

Can the BMS supply sensor values to the KMC Controls Conquest BAC-9301A four-pipe fan coil (Gen6)?

Room temperature and setpoint come from STE-9000 NetSensors (mapped to value objects) or from AI1/AI2 analog sensors.
