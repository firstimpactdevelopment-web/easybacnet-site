Updated 6 November 2026

Short answer

The BAC-7000 series are BACnet MS/TP VAV controllers with a built-in damper actuator and airflow sensor. The factory Control Basic programs run single-duct pressure independent or dependent VAV with modulating or staged reheat. The BMS mostly reads room temperature, airflow and damper position, and writes the occupancy command, setpoints and airflow limits.

This page lists 52 BACnet objects for the KMC Controls BAC-7000 series VAV controllers (BAC-7001 / 7003 / 7051 / 7053) — 24 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from KMC Controls’s own free documentation, linked below.

BMS integration notes: KMC Controls BAC-7000 series VAV controllers (BAC-7001 / 7003 / 7051 / 7053)

Integration in brief

Connect the controller to BACnet MS/TP (it auto-detects baud and can auto-assign MAC and device instance). From the BMS write BV 2 UNOCC for occupancy and AV 2 for the space setpoint if needed, and read space temperature, airflow and damper position.

Sensors & values from the BMS

Room temperature and setpoint come from a NetSensor (into AV1/AV2) or from AI1/AI2; the program copies AI1/AI2 to AV1/AV2 when no NetSensor is found.

Network setup

  • BACnet MS/TP up to 76.8 kbaud with automatic baud detection.
  • MAC address and device instance can be assigned automatically.
  • No more than 128 addressable devices per MS/TP network.

Watch out for

  • Changing objects or programs can make the controller run unpredictably; KMC warns to follow the configuration section.
  • BV 8 BALANCE override drops back after 2 hours.

Integration notes

  • The guide has no read/write column; access is inferred: values marked (auto) or written by the programs are read-only, setpoints, limits and commands writable.
  • Instances listed as --available-- are unused and left out (AV10, AV14, AV15, AV33-AV35, BV6, BV7).
  • Program objects 1-4 (SINGLEVAV, SINGLEPRESS, REHEAT, CALIB_UTIL) run the application and are not listed.
  • The output table prints AO4 with the name 'Damper Motor Drive', description 'MOTOR' and type 'Volts 0-10'; kept as printed.
  • When a NetSensor is connected its temperature and setpoint go to AV1 / AV2; otherwise AI1 / AI2 are copied there.

Questions about the KMC Controls BAC-7000 series VAV controllers (BAC-7001 / 7003 / 7051 / 7053)

How many BACnet points does the KMC Controls BAC-7000 series VAV controllers (BAC-7001 / 7003 / 7051 / 7053) have?

This list has 52 BACnet objects: 4 analog inputs, 2 analog outputs, 34 analog values, 2 binary outputs, 7 binary values, 3 loops. The exact set on a given unit depends on its firmware, installed options and configuration.

Which KMC Controls BAC-7000 series VAV controllers (BAC-7001 / 7003 / 7051 / 7053) BACnet points are writable?

24 of the 52 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official KMC Controls BAC-7000 series VAV controllers (BAC-7001 / 7003 / 7051 / 7053) BACnet documentation?

The source is Installation, Operation, and Applications Guide for BAC-7000 Series VAV controllers (AN0311A Rev C), revision 2014, published free by KMC Controls at https://www.kmccontrols.com/wp-content/uploads/kmc_documents/AG_BAC-7000_AN0311A_RevC.pdf.

What are the minimum BACnet points to integrate the KMC Controls BAC-7000 series VAV controllers (BAC-7001 / 7003 / 7051 / 7053)?

Start with BV 2 UNOCC (Unoccupied command (1 = unoccupied)); AV 2 SPACESSTPT (Space temperature setpoint, °F); AV 26 ACTIVESP (Active temperature setpoint, °F); AV 1 SPACETEMP (Space temperature, °F); AV 27 VOLUME1 (Measured airflow, cfm); AV 38 RQSTFLOWCFM (Requested airflow, cfm); AV 32 DMPR_POS (Damper position, %); AO 1 ANALOG_HEAT (Modulating reheat output, %).
