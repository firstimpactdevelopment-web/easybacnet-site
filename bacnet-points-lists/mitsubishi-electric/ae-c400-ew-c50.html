Short answer

The AE-C400 and EW-C50 centralized controllers (and the BACS-AP50 BM adapter, which behaves like an EW-C) expose the M-NET system to BACnet IP on their LAN2 port. Points are generated per group from a fixed template, plus separate blocks for PI controllers, outdoor units, interlocked units and chillers. The controller only creates objects that the connected unit type supports, so a Lossnay group or a chiller shows a different subset.

This page lists 71 BACnet objects for the Mitsubishi Electric AE-C400 / EW-C50 BACnet (BACS-AP50) — 28 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Mitsubishi Electric’s own free documentation, linked below.

BMS integration notes: Mitsubishi Electric AE-C400 / EW-C50 BACnet (BACS-AP50)

Integration in brief

Register the BACnet connection license, set the LAN2 (BACnet) IP and the device number with the BACnet Setting Tool, and wait for the controller to go ONLINE. Then map the per-group objects (01GGPP): On Off, mode, setpoint, room temp and alarm. Write only when a setting changes, never cyclically.

Enable & remote start

BACnet only runs when the controller is in ONLINE mode, which needs a valid BACnet connection license and consistent BACnet settings. Changing group/interlock settings sends it back to OFFLINE; returning to ONLINE can take up to about 10 minutes on large systems. Local remote-controller lockouts are the Prohibition BVs (13-17) per group.

Network setup

  • BACnet uses the LAN2 port (100BASE-TX); LAN1 and LAN2 must be on different networks and on separate switches. LAN2 cannot be used for cloud connection when BACnet is on.
  • UDP 47808 recommended for unicast and broadcast; Class C private address recommended (192.168.2.1 to 192.168.254.254).
  • Protocol revision is selectable in the BACnet Setting Tool (Rev.12 or Rev.21); pick Rev.12 for BMS front ends at Rev.4-11.
  • Device number, COV and event notification destinations and which objects are used are set in the BACnet Setting Tool; the manual gives no default device instance.
  • Each AE-C/EW-C is configured separately; the Setting Tool handles one controller at a time.

Watch out for

  • WriteProperty limit: 24 writes per day per property, 200 ms between writes. Do not rewrite on/off, setpoint, mode or prohibitions periodically; the units keep settings in nonvolatile memory.
  • Read interval: 200 ms per property; after a ReadPropertyMultiple of N properties wait N x 200 ms.
  • M-NET communication errors with a unit set Alarm Signal, Error Code, Error Code Detail and M-NET Communication State; the alarm part depends on the 'Not reflect communication error to alarm signal' setting.
  • If System Forced Off cannot be cleared from the BMS (for example after a comms fault), it can be force-reset from the BACnet Setting Tool.
  • Some property values are saved to nonvolatile memory only every 30 or 60 minutes, so a power cut can roll them back.
  • Energy accumulators and their trend logs need the Charge license.

Integration notes

  • Instance = 6 digits CCNNPP: CC = object class + fixed 1 (01 group, 41 PI controller, 51 outdoor unit, 61 interlocked unit, 71 chiller system, 91 chiller unit), NN = address (01-50; 99 = collective), PP = point. Instances here use address 01 (e.g. 010101 = 10101).
  • Outdoor unit (51zz) address is the M-NET outdoor address minus 50.
  • Apportioned energy accumulators and their trend logs need the Charge license; PI controller energy objects are 41mm40-43 with trend logs 41mm84-87.
  • Dry, Mid 1/Mid 2 fan speeds and Setback depend on BACnet Setting Tool / Initial Setting Tool options; dual-setpoint groups use Set Temp Cool/Heat (24/25) instead of Set Temp (10).
  • Chiller commands only work when the chiller's command source is the system controller; change chiller mode only while the chiller is off.
  • Printed document number is WT10808X04 although the download file name says X03.

Questions about the Mitsubishi Electric AE-C400 / EW-C50 BACnet (BACS-AP50)

How many BACnet points does the Mitsubishi Electric AE-C400 / EW-C50 BACnet (BACS-AP50) have?

This list has 71 BACnet objects: 5 analog inputs, 8 analog values, 13 binary inputs, 2 binary outputs, 11 binary values, 8 multi-state inputs, 7 multi-state outputs, 9 trend logs, 8 accumulators. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Mitsubishi Electric AE-C400 / EW-C50 BACnet (BACS-AP50) BACnet points are writable?

28 of the 71 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Mitsubishi Electric AE-C400 / EW-C50 BACnet (BACS-AP50) BACnet documentation?

The source is Centralized Controller AE-C400/EW-C50, BM ADAPTER BACS-AP50 Instruction Book <BACnet function> (WT10808X04), published free by Mitsubishi Electric at https://confort.mitsubishielectric.fr/documents/link/26707/stream/1766501797-GTC-BACS-AP50E-NOTICE-UTILISATION-WT10808X03-EN.pdf.

What are the minimum BACnet points to integrate the Mitsubishi Electric AE-C400 / EW-C50 BACnet (BACS-AP50)?

Start with BO 10101 On Off Setup (Start/stop the group); BI 10102 On Off State (Confirm run status); MO 10105 Operational Mode Setup (Command the operating mode); MI 10106 Operational Mode State (Read back the active mode); AV 10110 Set Temp (Setpoint for single-setpoint groups); AV 10124 Set Temp Cool (Cooling setpoint, dual-setpoint groups); AV 10125 Set Temp Heat (Heating setpoint, dual-setpoint groups); AI 10109 Room Temp (Space temperature); BI 10103 Alarm Signal (Group fault alarm); BV 10113 Prohibition On Off (Lock out local on/off at the remote controller).
