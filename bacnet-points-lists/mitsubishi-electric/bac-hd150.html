Short answer

The BAC-HD150 sits on the M-NET bus of a CITY MULTI system and serves BACnet IP objects for each indoor unit group. Every group gets the same block of control and status objects, so the point list is one template repeated per group. Which objects actually respond depends on the group type and on BAC-HD150 Setting Tool options such as dual setpoint and Old Model Compatibility Mode.

BMS integration notes: Mitsubishi Electric BAC-HD150 BM Adapter

Integration in brief

Set the BAC-HD150 IP addresses and groups with the BAC-HD150 Setting Tool, then map the same block of objects for each indoor unit group (instance MMGGPP). For a basic job you need On Off Setup/State, Operational Mode Setup/State, Set Temp (or Set Temp Cool/Heat for dual-setpoint groups), Room Temp and Alarm Signal. Space out requests: at least 200 ms per property.

Enable & remote start

No enable point is described; the BMS commands groups directly. Remote controller lockouts are separate Prohibition BVs (on/off, mode, filter reset, set temperature) per group, and System Forced Off works per group (MM GG 21) or for all groups (999921).

Network setup

  • Factory IP addresses: LAN1 (BACnet) 192.168.1.254, LAN2 (Setting Tool / expansion controller) 192.168.200.212. Set both with the Setting Tool before connecting LAN1.
  • UDP port 47808 for unicast and broadcast; 10BASE-T Ethernet; Class C private address recommended.
  • Instance MMGGPP: M-NET number 01-03, group 01-50 (99 for collective), point number.
  • Device instance is set with the BAC-HD150 Setting Tool; the instruction book does not give a default.
  • If a superior system controller is present, register it in the Setting Tool and register the BAC-HD150 on that controller.

Watch out for

  • Request interval: 200 ms per property or more; after a ReadPropertyMultiple of N properties wait N x 200 ms.
  • If the M-NET line to the BAC-HD150 is lost, every group's Error Code reads 08 (Communication error); M-NET Communication State (point 20) shows the link status.
  • Dual-setpoint groups need Set Temp Cool/Heat/Auto (24-26); writing those to single-setpoint groups returns an error. Enable Old Model Compatibility Mode if the BMS only handles one setpoint.
  • With a PAC-YG50ECA expansion controller, dual setpoints are not supported; Old Model Compatibility Mode and Expansion Controller Settings must be enabled.
  • Dry, Mid1/Mid2 fan speeds and Setback must be enabled in the Setting Tool. AHC is not supported.
  • Use a UPS if the BAC-HD150 must keep running through power failures.

Integration notes

  • Instance = 6 digits MMGGPP: MM = M-NET number (01-03), GG = group number (01-50, 99), PP = point number. Instances here use M-NET 01 / group 01 (e.g. 010101 = 10101).
  • System Forced Off for all groups at once is fixed at 999921; Expansion Controller Communication State is MM9981 (19981 for M-NET 01).
  • Set Temp Cool/Heat/Auto and the setback limits (24-28) only work with Old Model Compatibility Mode disabled; single-setpoint groups use Set Temp (10) and reject the dual-setpoint objects.
  • Dry mode and Mid 1/Mid 2 fan speeds must be enabled in the BAC-HD150 Setting Tool; Setback needs compatibility mode off and a setback-capable unit.
  • Mitsubishi Electric Canada's CMCN points list (MEAPP0002, Sept 2017) shows the same numbering without points 24-28 and Setback.

Questions about the Mitsubishi Electric BAC-HD150 BM Adapter

How many BACnet points does the Mitsubishi Electric BAC-HD150 BM Adapter have?

This list has 31 BACnet objects: 1 analog input, 6 analog values, 5 binary inputs, 1 binary output, 7 binary values, 6 multi-state inputs, 5 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Mitsubishi Electric BAC-HD150 BM Adapter BACnet points are writable?

19 of the 31 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Mitsubishi Electric BAC-HD150 BM Adapter BACnet documentation?

The source is Air-conditioner Control System BM ADAPTER BAC-HD150 Instruction Book (WT05542X04), published free by Mitsubishi Electric at https://library.mitsubishielectric.co.uk/pdf/download_full/373.

What are the minimum BACnet points to integrate the Mitsubishi Electric BAC-HD150 BM Adapter?

Start with BO 10101 On Off Setup (Start/stop the group); BI 10102 On Off State (Confirm run status); MO 10105 Operational Mode Setup (Command cool/heat/fan/auto/dry); MI 10106 Operational Mode State (Read back the active mode); AV 10110 Set Temp (Setpoint for single-setpoint groups); AV 10124 Set Temp Cool (Cooling setpoint for dual-setpoint groups); AV 10125 Set Temp Heat (Heating setpoint for dual-setpoint groups); AI 10109 Room Temp (Space temperature); BI 10103 Alarm Signal (Group fault alarm); BI 10120 M-NET Communication State (M-NET link to the group lost).

How do I enable BMS control of the Mitsubishi Electric BAC-HD150 BM Adapter?

No enable point is described; the BMS commands groups directly. Remote controller lockouts are separate Prohibition BVs (on/off, mode, filter reset, set temperature) per group, and System Forced Off works per group (MM GG 21) or for all groups (999921).
