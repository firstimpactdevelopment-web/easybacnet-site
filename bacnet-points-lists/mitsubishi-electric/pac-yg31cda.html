Short answer

The PAC-YG31CDA is an older Mitsubishi Electric interface that talks to G-50A central controllers over Ethernet and presents each air-conditioner group as a block of BACnet IP objects. Each G-50A and group combination repeats the same template, and the device and notification class instances can be changed in its setting software.

BMS integration notes: Mitsubishi Electric PAC-YG31CDA BACnet Interface

Integration in brief

PAC-YG31CDA is BACnet interface software that runs on a PC and talks to up to ten G-50A controllers over Ethernet. Register the BACnet license in each G-50A, enter each G-50A's number and IP address in the software, then map the per-group objects (AAGGPP).

Enable & remote start

A BACnet license number must be registered in each G-50A (Ver. 2.50 or later). Local remote-controller lockouts are the 'Prohibition of local operation' BVs (13-16) per group.

Network setup

  • Default Device ID 3 (range 1-4194303); the Notification Class also defaults to 3. Both instances can be changed.
  • BACnet UDP port is fixed at 47808.
  • Broadcast IP address defaults to 192.168.1.255; APDU timeout 3000 ms, 3 retries, I-Am interval 60 s.
  • Each G-50A gets a number 1-10 linked to its IP address in the software; that number forms the first two instance digits.

Watch out for

  • The interface is PC software: while the PC is rebooting or a G-50A has failed, control and monitoring may not work. After a power failure the PC must be restarted; a UPS is recommended.
  • LC (Lossnay) groups treat mode, setpoint and air direction as invalid, and their mode is fixed to ventilation.
  • Dry mode and Mid1/Mid2 fan speeds only work if enabled in the settings.

Integration notes

  • Instance = 6 digits AAGGPP: AA = G-50A number (01-10), GG = group number (01-50), PP = point. Instances here use G-50A 01 / group 01 (e.g. 010101 = 10101).
  • System Forced Off is AA9921 (one per G-50A); 19921 shown for G-50A 01.
  • Dry mode and Mid1/Mid2 fan speeds depend on settings and unit type; mode, setpoint and air direction objects depend on the unit model.
  • Reading Filter Signal Reset returns the same state as Filter Signal.

Questions about the Mitsubishi Electric PAC-YG31CDA BACnet Interface

How many BACnet points does the Mitsubishi Electric PAC-YG31CDA BACnet Interface have?

This list has 22 BACnet objects: 1 analog input, 1 analog value, 4 binary inputs, 1 binary output, 6 binary values, 1 device, 4 multi-state inputs, 3 multi-state outputs, 1 notification class. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Mitsubishi Electric PAC-YG31CDA BACnet Interface BACnet points are writable?

11 of the 22 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Mitsubishi Electric PAC-YG31CDA BACnet Interface BACnet documentation?

The source is Mitsubishi Electric Air Conditioning Network System BACnet Interface: PAC-YG31CDA (Ver. 1.30) Operation Manual (WT04221X03), revision 2004-03, published free by Mitsubishi Electric at https://library.mitsubishielectric.co.uk/pdf/download_full/2240.

What are the minimum BACnet points to integrate the Mitsubishi Electric PAC-YG31CDA BACnet Interface?

Start with BO 10101 On/Off (setup) (Start/stop the group); MO 10105 Operation mode (setup) (Command the operating mode); AV 10110 Set Temp. (Room temperature setpoint); MO 10107 Fan Speed (setup) (Fan speed: 1 low, 2 high, 3 mid2, 4 mid1); BI 10102 On/Off (state) (Confirm run status); AI 10109 Room Temp. (Room temperature of the group); BI 10103 Alarm signal (Group fault alarm); BI 10120 Communication State (Group communication fault).

How do I enable BMS control of the Mitsubishi Electric PAC-YG31CDA BACnet Interface?

A BACnet license number must be registered in each G-50A (Ver. 2.50 or later). Local remote-controller lockouts are the 'Prohibition of local operation' BVs (13-16) per group.
