Short answer

BMS integration notes: Mitsubishi Electric FR-E800 inverter (BACnet IP, Ethernet models)

Integration in brief

Put the inverter in Network operation mode with the Ethernet connector as command source, then write AV 300 Speed scale as the speed command and start/stop with BV 400. Read BV 0, AV 1, AV 2, AV 14 and the fault objects; BV 402 resets a fault.

Enable & remote start

The inverter must be in Network (NET) operation mode with the Ethernet port as command and speed source; otherwise writes are stored but not applied.

Heartbeat & communication loss

Pr.1432 Ethernet communication check time interval (0.1-999.8 s) trips the inverter with E.EHR if no allowed device talks to it; 9999 disables the check. Command devices are limited to the IP range in Pr.1449-Pr.1454.

Sensors & values from the BMS

AV 311 PID measured value CMD can feed the PID loop from the BMS when Pr.128 and Pr.610 select the network value.

Network setup

  • Device instance = Pr.728 x 10000 + Pr.729 (both default 0).
  • Set the command-source IP range (Pr.1449-Pr.1454) to include the BMS; at the default of 0 no device can send run or speed commands over Ethernet.

Watch out for

  • Commandable values are cleared at power-on or inverter reset; rewrite them after a restart.
  • Speed scale is a % of Pr.390 % setting reference frequency (default 60 Hz), not a frequency in Hz.

Integration notes

  • Access codes as printed: R read-only, W read/write, C commandable (priority array).
  • Footnoted BI/BO objects have no function on the Ethernet, safety-communication or IP67 models (see the manual's notes for each).
  • Values written to commandable objects go to the priority array even when the inverter rejects them because of the operation mode.
  • Speed scale and PID command objects are only applied when the speed command source is NET.
  • Source: Section 2.8 BACnet/IP, 'Supported BACnet object', pdf pages 123-126.

How many BACnet points does the Mitsubishi Electric FR-E800 inverter (BACnet IP, Ethernet models) have?

This list has 48 BACnet objects: 2 analog inputs, 25 analog values, 7 binary inputs, 4 binary outputs, 10 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Mitsubishi Electric FR-E800 inverter (BACnet IP, Ethernet models) BACnet points are writable?

17 of the 48 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
