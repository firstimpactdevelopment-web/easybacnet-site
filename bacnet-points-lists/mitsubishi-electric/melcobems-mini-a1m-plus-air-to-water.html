Short answer

For air-to-water (Ecodan) systems the MelcoBEMS MINI (A1M+) serves a large object set on BACnet MS/TP or BACnet IP: system on/off, operating mode, DHW and zone setpoints, prohibit and forced-DHW commands, then many read-only analog inputs for temperatures, flow, heat pump frequencies, run hours, error codes, energy produced and consumed, and FTC configuration. Many status values are coded integers in analog inputs rather than binary or multistate objects.

BMS integration notes: Mitsubishi Electric Procon MelcoBEMS MINI (A1M+) - Air-To-Water (Ecodan) units

Integration in brief

Select BACnet with DIP switch 7, then write system on/off, the operating mode, DHW tank and zone setpoints, and read flow, return and tank temperatures plus the error objects.

Enable & remote start

No separate enable; the Setup objects command the FTC directly. Prohibit objects (BO 11-15, AV 8) lock functions at the unit's remote controller.

Network setup

  • DIP switch 7 OFF selects BACnet (MS/TP and BACnet IP); ON selects Modbus RTU.
  • DIP switches 1-5 set the RS-485 node address 1-30 (all OFF = 1, all ON = set in software); it is the MS/TP station ID.
  • DIP switch 6 ON fixes RS-485 at 9600 baud, no parity; OFF uses the software baud rate (MS/TP up to 76800).
  • Default IP address 192.168.92.114; network settings are changed on the adapter's web page.
  • Device instance, Max Master and Max Info Frames are set through Modbus holding registers 272-275.

Watch out for

  • AV 8 (MRC prohibit) is bit-packed and the guide says it must not be written to Shizuoka-designed models.
  • Zone 2 objects only apply to two-zone systems; slave and refrigerant-address objects only apply to cascaded systems.

Integration notes

  • Access is not printed per object; it follows the guide's property table (AV, BO and multistate outputs have a writable present value and priority array; inputs are read-only).
  • The adapter detects the connected unit type and only serves the matching object list (Air-To-Air, Air-To-Water or Lossnay).
  • Temperature objects read in °C or °F according to the Temperature Units multistate output.
  • Several analog inputs carry coded values (0/1 flags, bit-packed DIP switch states, 7-segment error digits); the codes are in the states field where the guide lists them.
  • Some temperatures are documented as value x10 (e.g. AV 21 outdoor air temperature).

Questions about the Mitsubishi Electric Procon MelcoBEMS MINI (A1M+) - Air-To-Water (Ecodan) units

How many BACnet points does the Mitsubishi Electric Procon MelcoBEMS MINI (A1M+) - Air-To-Water (Ecodan) units have?

This list has 259 BACnet objects: 232 analog inputs, 11 analog values, 11 binary outputs, 5 multi-state outputs. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Mitsubishi Electric Procon MelcoBEMS MINI (A1M+) - Air-To-Water (Ecodan) units BACnet points are writable?

27 of the 259 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Mitsubishi Electric Procon MelcoBEMS MINI (A1M+) - Air-To-Water (Ecodan) units BACnet documentation?

The source is Procon MelcoBEMS MINI (A1M+) Installation Manual (manual 1.0.3, firmware 4.1.1), published free by Mitsubishi Electric at https://library.mitsubishielectric.co.uk/pdf/download_full/5538.

What are the minimum BACnet points to integrate the Mitsubishi Electric Procon MelcoBEMS MINI (A1M+) - Air-To-Water (Ecodan) units?

Start with BO 0 ATW Drive OFF/ON Setup (System on/off command); MO 1 ATW Mode Setup (Operating mode command); AV 5 ATW Tank Setpoint Int (DHW tank setpoint); AV 6 ATW Zone1 HC Target Temperature Int (Zone 1 target temperature); MO 3 ATW Zone 1 Operation Mode AC (Zone 1 operation mode (room/flow/curve)); AI 51 ATW Flow Temperature Int (Flow temperature); AI 52 ATW Return Temperature Int (Return temperature); AI 53 ATW Water Temperature Int (Water (tank) temperature); AI 29 ATW Refrigerant Error Info (Refrigerant error state, 0 = normal).

How do I enable BMS control of the Mitsubishi Electric Procon MelcoBEMS MINI (A1M+) - Air-To-Water (Ecodan) units?

No separate enable; the Setup objects command the FTC directly. Prohibit objects (BO 11-15, AV 8) lock functions at the unit's remote controller.
