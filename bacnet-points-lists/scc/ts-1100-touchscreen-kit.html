Short answer

The TS-1100 touchscreen kit is an HMI for Siemens LMV3/LMV5 linkageless burner controls with an optional RWF load or water-level controller. Its optional gateway serves the same address list over BACnet IP and BACnet MS/TP: burner phase, actuator positions, flame, setpoints, lockout and error history, RWF and feedwater values, EA annunciator inputs, and writable remote mode, setpoint and firing-rate commands for the LMV and RWF.

BMS integration notes: SCC Inc. TS-1100 touchscreen kit for Siemens LMV3 / LMV5 / RWF burner controls (BACnet IP / MS/TP)

Integration in brief

Keep BV 1 Active_Connection at 1 by rewriting it at least every 30 seconds, then pick a remote mode: AV 21 = 0 (auto) and write the setpoint to AV 22, or AV 21 = 1 (on) and write the firing rate to AV 23; AV 21 = 2 turns the LMV off. With an RWF, use AV 47 (1 setpoint, 2 full remote) with AV 48/AV 49. Read the burner phase, actual value, flame and alarm points for status.

Enable & remote start

Remote mode only works while BV 1 Active_Connection is held at 1 and the remote setpoint is above 0; the LMV local/remote mode then switches automatically. Writing BV 1 = 0 blocks remote mode.

Heartbeat & communication loss

BV 1 Active_Connection must be written to 1 at least once every 30 seconds; if it is not, the burner returns to local mode.

Network setup

  • Default device instance 100 (set with DEV INS on the touchscreen Unit Type screen).
  • BACnet IP uses UDP 47808; the gateway's default web address is 192.168.1.67 for changing its IP.
  • BACnet MS/TP: default MAC 1, 38400 baud, set on the Unit Type screen.
  • Protocol is chosen with the gateway DIP switches (BACnet IP or MS/TP profiles 1-4).

Watch out for

  • Full remote (firing rate) mode is not available on the RWF10; send the firing rate to the LMV3 instead.
  • BV 35 RWF_Disable = 1 disables the RWF.
  • AI and BI points are read-only; only the AV and BV points accept writes.

Integration notes

  • The table lists AV/AO and BV/BO for the writable points; AO/BO are the Metasys N2 equivalents, so they are given here as AV and BV.
  • AI 57 and AI 58 are both printed as FW_Current_SP (AI 57 is the feedwater E2 actual value).
  • Some names are printed with a space after an underscore (e.g. "LMV_EH_ Error_Code", "EA_ Ana_2_Total"); kept as printed.
  • The prose calls AV 21 LMV_Remote_Mode and AV 47 RWF_Remote_Mode; the table names are LMV_Rem_Mode and RWF_Command.
  • Points marked LMV5... or LMV52... only carry data with those burner controls; RWF40 and EA points need those options.
  • Units are not given in the table.
  • This is the touchscreen's own optional BACnet gateway. The Contemporary Controls BASgatewayLX profile for the TS-1100 reads the same data over Modbus RTU but uses its own object numbering and names; see that list if a BASgatewayLX is fitted instead.
