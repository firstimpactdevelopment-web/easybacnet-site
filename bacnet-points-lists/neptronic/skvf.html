Short answer

The SKVF is an evaporative media cooler that can control on humidity or temperature. Its controller provides BACnet MS/TP and BACnet IP with selectable control profiles, network RH and temperature readings and setpoints, occupancy, operating state and alarms.

BMS integration notes: Neptronic SKVF

Integration in brief

Select a network control profile (MSV 28) or set MSV 43 to Network and write demand to AV 138; for internal control feed room RH (AV 106) or temperature (AV 155) with their setpoints. Switch the unit with MSV 83 and supervise BV 44.

Enable & remote start

MSV 83 System Power State is writable (1 = Off, 2 = On); the control source follows MSV 28 Control Profile or the individual source MSVs (43, 33, 76) with the Custom profile.

Heartbeat & communication loss

AV 223 Network Timeout (1-900 s) sets how long the cooler tolerates loss of BACnet control communication before it stops; BV 44 Network Control State shows 1 = Fault.

Sensors & values from the BMS

Room RH to AV 106 (MSV 33 = Network), room temperature to AV 155 (MSV 76 = Network), setpoints AV 107-109 and AV 156-158; supply high limit RH AV 122 and temperature AV 175 with setpoints AV 123 and AV 176-178; direct demand AV 138.

Network setup

  • MS/TP MAC defaults to 1 (000-254; 128-254 are non-token-passing slaves); baud rate auto-detects (Auto, 9600, 19200, 38400, 76800); Max_Master 127.
  • Device instance defaults to 153000 + MAC (153001 out of the box) and can be changed from the menu or by writing Device Object_Identifier.
  • BACnet IP uses UDP 47808 (0xBAC0) by default.
  • Network/communication settings are in the controller's Integration menu (password 5544); power-cycle after connecting to the network.
  • Reinitialize Device (warm/cold reset) over BACnet uses the password 'nep'.

Watch out for

  • MSV 'BACnet Server List Mode' chooses which objects are published (Integrator, Advanced, Factory); objects marked Advanced in the guide, such as the program objects, only show in Advanced mode.
  • Writing Out_of_Service = True disconnects an object from its physical input so the Present_Value can be overwritten; remember to set it back.
  • The unit signals alarms through object values only; it does not send BACnet event notifications, so poll or use COV.
  • COV subscriptions are lost on a power cycle.
  • Lower Max_Master to the highest MAC on the trunk to speed up MS/TP token passing.

Questions about the Neptronic SKVF

How many BACnet points does the Neptronic SKVF have?

This list has 201 BACnet objects: 10 analog inputs, 2 analog outputs, 97 analog values, 9 binary inputs, 8 binary outputs, 16 binary values, 5 files, 2 schedules, 34 multi-state values, 7 characterstring values, 11 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Neptronic SKVF BACnet points are writable?

151 of the 201 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Neptronic SKVF BACnet documentation?

The source is Evaporative Cooler SKVF Series BACnet Communication Module User Guide (SKVF-BACnet Guide (v1.08)-250212), revision 2025-02-12, published free by Neptronic at https://www.neptronic.com/Humidifiers/pdf/2025/SKVF-BACnet%20Guide%20(v1.08)-250212.pdf.

What are the minimum BACnet points to integrate the Neptronic SKVF?

Start with MV 83 System Power State (System on/off from the BMS); MV 28 Control Profile (Control profile); MV 43 Control Demand Source (Control demand source); AV 138 Control Network Demand (Network control demand); AV 155 Room Temperature Network Reading (Network room temperature reading); AV 156 Room Temperature Setpoint (Room temperature setpoint); AV 106 Room RH Network Reading (Network room RH reading); MV 32 Occupancy State (Occupancy state); BV 44 Network Control State (Network control communication state); AV 223 Network Timeout (Network timeout).

How do I enable BMS control of the Neptronic SKVF?

MSV 83 System Power State is writable (1 = Off, 2 = On); the control source follows MSV 28 Control Profile or the individual source MSVs (43, 33, 76) with the Custom profile.

Does the Neptronic SKVF need a BACnet heartbeat or have a communication timeout?

AV 223 Network Timeout (1-900 s) sets how long the cooler tolerates loss of BACnet control communication before it stops; BV 44 Network Control State shows 1 = Fault.

Can the BMS supply sensor values to the Neptronic SKVF?

Room RH to AV 106 (MSV 33 = Network), room temperature to AV 155 (MSV 76 = Network), setpoints AV 107-109 and AV 156-158; supply high limit RH AV 122 and temperature AV 175 with setpoints AV 123 and AV 176-178; direct demand AV 138.

How do I check these points on the real SKVF?
