Short answer

The older SKH high pressure atomiser shows up on BACnet MS/TP as a pump station device plus one device per EZC zone controller. The pump station device carries the system mode, pump state and demand, zone capacity, pump inlet and outlet pressure and temperature, alarm relay outputs and a long list of pump and communication alarms, plus simulation and inactivity-drain settings.

This page lists 68 BACnet objects for the Neptronic SKH (legacy, pre-SKH4) high pressure atomiser - SKH pump station — 20 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Neptronic’s own free documentation, linked below.

BMS integration notes: Neptronic SKH (legacy, pre-SKH4) high pressure atomiser - SKH pump station

Integration in brief

Turn the system on with BV 1 SystemMode and read MSV 1 PumpState, AV 1 PumpDemand and the alarm flags (BV 50/51 service, BV 52 pump global alarm). Humidity control itself is done per zone on the EZC devices.

Enable & remote start

BV 1 SystemMode switches the system on or off.

Network setup

  • Baud rate and device instance can be automatic: the humidifier sets its device instance to 153000 + MAC address; the MAC (0-254) is set from the menu.
  • Max_Master defaults to 127; lower it for a faster MS/TP trunk.

Watch out for

  • Simulation objects (AV 3-8, BV 2-3) are for testing; leave them alone in normal operation.

Integration notes

  • Objects are grouped as Integrator, Integrator configuration and Advanced; MSV Cfg_ObjectListMode chooses which groups the device shows (Integrator, Advanced or Factory).
  • Access: "Present Value" in the W? column is listed as writable, "Out of Service" (only the out-of-service property is writable) as read-only; commandable BOs are marked C.
  • Out-of-service is cleared automatically after 15 minutes by default (Device proprietary property #1002).
  • The zone controllers are separate BACnet devices with their own object list (see the SKH EZC list).

Which Neptronic SKH (legacy, pre-SKH4) high pressure atomiser - SKH pump station BACnet points are writable?

20 of the 68 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
