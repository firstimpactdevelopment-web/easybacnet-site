BMS integration notes: Neptronic SKG4

Integration in brief

Select a network control profile (MSV 33) or demand source, write the demand to AV 141 or a room RH reading to AV 109 with setpoint AV 110, and switch the system with MSV 60. Monitor per-module state and alarm MSVs plus BV 104 for network control health.

Enable & remote start

MSV 60 System Power State is writable (1 = Off, 2 = On). The control source follows MSV 33 Control Profile (ExternNetwork / InternNetwork for BMS control) or the individual source MSVs with the Custom profile.

Heartbeat & communication loss

AV 248 Network Timeout (1-900 s) sets how long the humidifier tolerates loss of BACnet control communication before stopping; BV 104 Network Control State reports 1 = Fault.

Sensors & values from the BMS

With the room RH source on Network write room RH to AV 109 and setpoints to AV 110-112 (occupied/unoccupied/vacant); write the supply high limit reading to AV 125 and setpoint AV 126. A direct network demand goes to AV 141 and a network high limit to AV 142.

Network setup

  • MS/TP MAC defaults to 1 (000-254; 128-254 are non-token-passing slaves); baud rate auto-detects (Auto, 9600, 19200, 38400, 76800); Max_Master 127.
  • Device instance defaults to 153000 + MAC (153001 out of the box) and can be changed from the menu or by writing Device Object_Identifier.
  • BACnet IP uses UDP 47808 (0xBAC0) by default.
  • Network/communication settings are in the controller's Integration menu (password 5544); power-cycle after connecting to the network.
  • Reinitialize Device (warm/cold reset) over BACnet uses the password 'nep'.

Watch out for

  • MSV 'BACnet Server List Mode' chooses which objects are published (Integrator, Advanced, Factory); objects marked Advanced in the guide, such as the program objects, only show in Advanced mode.
  • Writing Out_of_Service = True disconnects an object from its physical input so the Present_Value can be overwritten; remember to set it back.
  • The unit signals alarms through object values only; it does not send BACnet event notifications, so poll or use COV.
  • COV subscriptions are lost on a power cycle.
  • Per-module request MSVs (64, 67, 70, 73) act on one module; MSV 61 acts on the whole system.

Questions about the Neptronic SKG4

How many BACnet points does the Neptronic SKG4 have?

This list has 303 BACnet objects: 3 analog inputs, 1 analog output, 144 analog values, 7 binary inputs, 5 binary outputs, 70 binary values, 5 files, 2 schedules, 54 multi-state values, 1 characterstring value, 11 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Neptronic SKG4 BACnet points are writable?

175 of the 303 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Neptronic SKG4 BACnet documentation?

The source is SKG4 Gas Fired Humidifier BACnet Communication Module User Guide (SKG4-BACnet Guide-250609 (V2.06)), revision 2025-06-09, published free by Neptronic at https://www.neptronic.com/Humidifiers/PDF/2025/SKG4-BACnet%20Guide-250609%20(V2.06).pdf.

What are the minimum BACnet points to integrate the Neptronic SKG4?

Start with MV 60 System Power State (System on/off from the BMS); MV 33 Control Profile (Control profile: choose a Network profile); AV 141 Humidity Control Network Demand (Network humidity demand written by the BMS); AV 110 Room RH Setpoint (Occupied room RH setpoint (internal control)); AV 109 Room RH Network Reading (Network room RH reading for internal control); MV 63 Module 1 State (Module 1 operating state); AV 148 System Power Output (Actual output of the whole system %); MV 65 Module 1 Alarm (Module 1 active alarm (1 = Normal)); BV 104 Network Control State (1 = fault: network control lost (AV 248 timeout)).

How do I enable BMS control of the Neptronic SKG4?

MSV 60 System Power State is writable (1 = Off, 2 = On). The control source follows MSV 33 Control Profile (ExternNetwork / InternNetwork for BMS control) or the individual source MSVs with the Custom profile.

Does the Neptronic SKG4 need a BACnet heartbeat or have a communication timeout?

AV 248 Network Timeout (1-900 s) sets how long the humidifier tolerates loss of BACnet control communication before stopping; BV 104 Network Control State reports 1 = Fault.

Can the BMS supply sensor values to the Neptronic SKG4?

With the room RH source on Network write room RH to AV 109 and setpoints to AV 110-112 (occupied/unoccupied/vacant); write the supply high limit reading to AV 125 and setpoint AV 126. A direct network demand goes to AV 141 and a network high limit to AV 142.

How do I check these points on the real SKG4?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
