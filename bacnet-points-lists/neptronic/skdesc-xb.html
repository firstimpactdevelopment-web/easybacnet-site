Neptronic SKDESC-xB BACnet points list

Updated 16 October 2026

Short answer

The SKDESC-xB is the electronic controller used on Neptronic steam injection humidifier valves. It communicates over BACnet MS/TP only and exposes setpoints, room and duct RH, PI tuning, high limit, network fallback settings, inputs and relay states.

This page lists 87 BACnet objects for the Neptronic SKDESC-xB — 30 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Neptronic’s own free documentation, linked below.

BMS integration notes: Neptronic SKDESC-xB

Integration in brief

Set MSV 2 Control Mode to Network to drive the valve from the BMS, or feed room RH to AV 2 (after turning on BV 14 NetworkRoomRH) with the internal setpoint AV 1. Configure the network fallback timeout and fallback setpoint, and switch the system with BV 1.

Enable & remote start

BV 1 PowerStatus (0 = Off, 1 = On) is writable; MSV 2 ControlMode selects External, Internal or Network control.

Heartbeat & communication loss

Network fallback is configured with AV 30 FallbackTimeout (0-900 s), AV 31 FallbackStpnt (0-100 %) and the AV 32 FallbackDownCntr countdown; the guide lists these objects but does not spell out the fallback sequence, so test it on site.

Sensors & values from the BMS

Room RH is written to AV 2 only while BV 14 NetworkRoomRH = On; duct RH is written to AV 3 only while MSV 3 HiLimitSensorSrc = Network. BV 15 enables an external RH setpoint.

Network setup

  • MS/TP MAC defaults to 000 (000-254; 128-254 are non-token-passing slaves), baud auto-detects (Auto, 9600, 19200, 38400, 76800), Max_Master 127.
  • Device instance defaults to 153000 + MAC and can be changed from the menu (password 637) or via Device Object_Identifier.
  • Reinitialize Device over BACnet uses the password 'nep'.

Watch out for

  • Out_of_Service automatically returns to False after 15 minutes by default (adjustable 0-120 min via a proprietary device property).
  • A Copy Config can be run over BACnet, but the BACnet schedule is not copied.
  • The controller does not send BACnet event notifications; poll alarm objects.

Questions about the Neptronic SKDESC-xB

How many BACnet points does the Neptronic SKDESC-xB have?

This list has 87 BACnet objects: 10 analog inputs, 47 analog values, 4 binary inputs, 22 binary values, 4 multi-state values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Neptronic SKDESC-xB BACnet points are writable?

30 of the 87 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Neptronic SKDESC-xB BACnet documentation?

The source is SKDESC-xB Series Electronic Steam Controller BACnet Communication Module User Guide (SKDESCXB-BACnet-250905-EUA), revision 2025-09-05, published free by Neptronic at https://www.neptronic.com/Humidifiers/PDF/2025/SKDESCXB-BACnet-250905-EUA.pdf.

What are the minimum BACnet points to integrate the Neptronic SKDESC-xB?

Start with BV 1 PowerStatus (System power on/off); MV 2 ControlMode (Control mode: External, Internal or Network); AV 2 RoomRH (Room RH (writable when BV 14 = On)); BV 14 NetworkRoomRH (Enable network room RH); AV 1 InternalStpnt (Internal RH setpoint); AV 4 SystemDemand (System demand); AV 30 FallbackTimeout (Network fallback timeout); AV 31 FallbackStpnt (Network fallback setpoint); BV 3 ServiceAlarm (Service alarm).

How do I enable BMS control of the Neptronic SKDESC-xB?

BV 1 PowerStatus (0 = Off, 1 = On) is writable; MSV 2 ControlMode selects External, Internal or Network control.

Does the Neptronic SKDESC-xB need a BACnet heartbeat or have a communication timeout?

Network fallback is configured with AV 30 FallbackTimeout (0-900 s), AV 31 FallbackStpnt (0-100 %) and the AV 32 FallbackDownCntr countdown; the guide lists these objects but does not spell out the fallback sequence, so test it on site.

Can the BMS supply sensor values to the Neptronic SKDESC-xB?

Room RH is written to AV 2 only while BV 14 NetworkRoomRH = On; duct RH is written to AV 3 only while MSV 3 HiLimitSensorSrc = Network. BV 15 enables an external RH setpoint.

How do I check these points on the real SKDESC-xB?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
