BMS integration notes: Neptronic SK300 / SKE (legacy) Steam Humidifier with NEPIC BACnet module

Integration in brief

Set the baud with DIP switches 2-3 and give the module a unique MAC and device instance. For BMS demand control set MSV 1 Ctl_Mode to 3 (remote) and write AV 1 Humidity_Demand; for internal PID set MSV 1 to 2, choose the setpoint and humidity sources (MSV 4, MSV 5) and write AV 11 and AV 2. MSV 2 turns the unit on, off or to drain.

Enable & remote start

MSV 2 Operation_Mode sets the unit off (1), on (2) or to drain (3). MSV 1 Ctl_Mode picks the demand source: 1 = local analog input, 2 = internal PID, 3 = remote demand over BACnet.

Sensors & values from the BMS

With MSV 5 Room_Hum_Source = 2 (remote) and MSV 6 Duct_Hum_Source = 3 (remote) the BMS writes AV 2 Room_Humidity and AV 3 Duct_Humidity; MSV 4 SP_Source = 3 takes the setpoint from BACnet.

Network setup

  • DIP switch 1 selects operational (OFF) or configuration (ON) mode; switches 2 and 3 set 9600, 19200, 38400 or 76800 baud (restart after a change).
  • Factory settings: MAC 0, device instance 153000, Max_Master 127; configuration mode uses MAC 254 as a non-token-passing slave.
  • Device instance, object name, Max_Master and MAC (proprietary property 1000) can be written to the Device object at any time.

Watch out for

  • Two modules left at the factory MAC 0 / instance 153000 will clash; configure each before connecting.
  • BV 30 Reload_Factory restores factory values.

Integration notes

  • The SK300 and SKE guides (SK300-BACNET Rev 060606 and SKE-BACNET Rev 081104) print identical object tables; one list covers both. These are the older models, separate from the SKE4/SKG4 lists.
  • Access is from the W? column. The alarm BVs are printed as writable.
  • Temperature values follow BV 27 Temp_Units (Celsius or Fahrenheit).
  • The module does not send BACnet event notifications; alarms are read from the BI/BV objects.

How many BACnet points does the Neptronic SK300 / SKE (legacy) Steam Humidifier with NEPIC BACnet module have?

Which Neptronic SK300 / SKE (legacy) Steam Humidifier with NEPIC BACnet module BACnet points are writable?

61 of the 83 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
