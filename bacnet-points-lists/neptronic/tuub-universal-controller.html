BMS integration notes: Neptronic TUUB universal wall-mount controller

Integration in brief

Command occupancy with MSV.13 NsbOccCommand, the mode with MSV.1 and the fan with MSV.2, and write the setpoint to AV.9. To feed the room temperature from the BMS, set MSV.21 to Network and keep writing AV.1 ControlTemp within the AV.2 timeout. Read MSV.14, AV.1, the ramp demands and the AL_ alarm BVs.

Enable & remote start

MSV.13 NsbOccCommand: Locally lets the controller follow its occupancy input; the other states force off, occupied/day or unoccupied/night from the BMS.

Heartbeat & communication loss

With MSV.21 Cfg_TempControlSource = Network, the BMS must keep writing AV.1 ControlTemp; if nothing arrives for AV.2 Cfg_NetworkTimeOut (0-60 min) the controller goes to OFF and AV.1 shows 999 °C in fault. With AV.2 = 0, AV.1 resets to the AV.9 setpoint.

Sensors & values from the BMS

Set MSV.21 Cfg_TempControlSource to Network (1) and write the room temperature to AV.1 ControlTemp (commandable).

Network setup

  • MAC address 0-254 (default 000) from the menu or Device proprietary property #1000; device instance defaults to 153000 + MAC.
  • Baud rate Auto (default), 9600, 19200, 38400 or 76800.
  • BV.1 Cfg_TempUnitBACnet selects Celsius or Fahrenheit for BACnet values.

Watch out for

  • Relinquish defaults of commandable setpoints are saved to non-volatile memory.
  • COV subscriptions are lost on a power cycle.

Integration notes

  • Objects marked Present Value in the W? column are writable; AV 1, AV 9, AV 73, MV 13 are commandable (priority array).
  • Inputs can be overridden by setting Out_of_Service; they return to normal after the time in Device proprietary property #1002 (default 15 min).
  • SystemMode (MSV.1) options depend on BV.3, BV.21, BV.98 and MSV.20; read State_Text from the device.
  • NsbOccCommand (MSV.13) has 4 states when an input is set to Occupancy or Night Setback (1 Locally, 2 Off, 3 Occupancy/Day, 4 No Occupancy/Night), otherwise 3 (1 Off, 2 Occupancy/Day, 3 No Occupancy/Night).
  • Object names are listed as printed, including the odd spaces (for example "AL_ DirtyFilter").
  • The program (PGM.1) and file (FIL.1) objects used for firmware updates are listed as type Other and FILE.

Questions about the Neptronic TUUB universal wall-mount controller

How many BACnet points does the Neptronic TUUB universal wall-mount controller have?

This list has 276 BACnet objects: 9 analog inputs, 4 analog outputs, 137 analog values, 1 binary input, 7 binary outputs, 73 binary values, 1 file, 1 schedule, 42 multi-state values, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Neptronic TUUB universal wall-mount controller BACnet points are writable?

232 of the 276 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Neptronic TUUB universal wall-mount controller BACnet documentation?

The source is TUUB BACnet Guide (TUUB-BACnet Guide-250829 (V1.13)), revision 2025-08-29, published free by Neptronic at https://www.neptronic.com/Controls/PDF/2025/TUUB-BACnet%20Guide-250829%20(V1.13).pdf.

What are the minimum BACnet points to integrate the Neptronic TUUB universal wall-mount controller?

Start with MV 13 NsbOccCommand (BMS occupancy command: local, off, occupied, unoccupied); MV 1 SystemMode (Mode: auto, heating, cooling, fan, off); MV 2 UserFanSpeedSelect (Fan speed: auto, low, medium, high); AV 9 TempSetPoint (Occupied/day temperature setpoint); MV 14 OccupancyStatus (Actual occupancy incl. override); AV 1 ControlTemp (Temperature used for control); AV 20 Heating1Demand (Heating ramp 1 demand, %); AV 35 Cooling1Demand (Cooling ramp 1 demand, %); BV 37 AL_FlowSwitch (Airflow alarm); BV 36 AL_ DirtyFilter (Filter change required).

How do I enable BMS control of the Neptronic TUUB universal wall-mount controller?

MSV.13 NsbOccCommand: Locally lets the controller follow its occupancy input; the other states force off, occupied/day or unoccupied/night from the BMS.

Does the Neptronic TUUB universal wall-mount controller need a BACnet heartbeat or have a communication timeout?

With MSV.21 Cfg_TempControlSource = Network, the BMS must keep writing AV.1 ControlTemp; if nothing arrives for AV.2 Cfg_NetworkTimeOut (0-60 min) the controller goes to OFF and AV.1 shows 999 °C in fault. With AV.2 = 0, AV.1 resets to the AV.9 setpoint.

Can the BMS supply sensor values to the Neptronic TUUB universal wall-mount controller?

Set MSV.21 Cfg_TempControlSource to Network (1) and write the room temperature to AV.1 ControlTemp (commandable).
