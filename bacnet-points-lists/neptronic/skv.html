Short answer

The SKV is a multi-module evaporative humidifier. Its controller speaks BACnet MS/TP and exposes control mode and source selection, network setpoints and readings, a network fallback timeout, and per-module (1-4) demand, state, valve, float and fault objects.

This page lists 277 BACnet objects for the Neptronic SKV — 242 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from Neptronic’s own free documentation, linked below.

BMS integration notes: Neptronic SKV

Integration in brief

Set MSV 4 ControlMode to Network (or an internal mode with network sources) and write demand to AV 5, or feed room RH via MSV 3 = Network. Turn the system on with BV 116 SystemPower and keep network values fresh inside the fallback timeout (AV 38).

Enable & remote start

BV 116 SystemPower: ON = normal operation, OFF = demand inhibited. MSV 4 ControlMode selects an analog input, internal temperature/RH control or Network.

Heartbeat & communication loss

AV 38 NetworkFallbackTimeout (1-15 min) applies whenever at least one control input uses Network as its source; AV 39 counts down and BV 121 NetworkFallbackAlarm turns on when it expires.

Sensors & values from the BMS

Set MSV 3 RoomRHSource or MSV 2 RoomTempSource to Network and write the values from the BMS; MSV 5 SetpointSource = Network uses the external setpoints AV 16 (RH) and AV 17 (temperature).

Network setup

  • MS/TP MAC defaults to 000 (000-254; 128-254 are non-token-passing slaves); baud auto-detects (Auto, 9600, 19200, 38400, 76800); Max_Master 127.
  • Device instance defaults to 153000 and can be set from the menu or via Device Object_Identifier.

Watch out for

  • Older (2018) guide: the W? column marks every object as Present Value, so confirm writability on site.
  • Faults that stop a module need a manual reset (BV 95 SystResetAlarms or the Diagnostic menu).
  • BV 107 RunWhileServiceAlarm decides whether modules keep running when a service alarm is due.

Questions about the Neptronic SKV

How many BACnet points does the Neptronic SKV have?

This list has 277 BACnet objects: 13 analog inputs, 100 analog values, 13 binary inputs, 121 binary values, 4 files, 2 schedules, 19 multi-state values, 5 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Neptronic SKV BACnet points are writable?

242 of the 277 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.

Where is the official Neptronic SKV BACnet documentation?

The source is SKV Evaporative Humidifier BACnet User Guide, revision 2018-09-05, published free by Neptronic at https://www.neptronic.com/Humidifiers/PDF/skv/20180905/SKV-BACnet-180905.pdf.

What are the minimum BACnet points to integrate the Neptronic SKV?

Start with BV 116 SystemPower (System power on/off); MV 4 ControlMode (Control mode (6 = Network)); AV 5 SystDemand (System demand); MV 5 SetpointSource (Setpoint source); AV 16 SetpointRH (External RH setpoint); MV 3 RoomRHSource (Room RH source); AV 38 NetworkFallbackTimeout (Network fallback timeout); BV 121 NetworkFallbackAlarm (Network fallback alarm); MV 16 Module1State (Module 1 state); BV 95 SystResetAlarms (Reset alarms).

How do I enable BMS control of the Neptronic SKV?

BV 116 SystemPower: ON = normal operation, OFF = demand inhibited. MSV 4 ControlMode selects an analog input, internal temperature/RH control or Network.

Does the Neptronic SKV need a BACnet heartbeat or have a communication timeout?

AV 38 NetworkFallbackTimeout (1-15 min) applies whenever at least one control input uses Network as its source; AV 39 counts down and BV 121 NetworkFallbackAlarm turns on when it expires.

Can the BMS supply sensor values to the Neptronic SKV?

Set MSV 3 RoomRHSource or MSV 2 RoomTempSource to Network and write the values from the BMS; MSV 5 SetpointSource = Network uses the external setpoints AV 16 (RH) and AV 17 (temperature).

How do I check these points on the real SKV?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
