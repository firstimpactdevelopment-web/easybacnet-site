BMS integration notes: Neptronic SKH4

Integration in brief

Choose a Network control profile (MSV 28) or demand source (MSV 43 = Network) and write demand to AV 138, or feed room RH/temperature readings (AV 106 / AV 155) for internal control. Per-zone control and occupancy are set with the Zone MSVs; watch BV 44 and the zone communication timeout BVs.

Enable & remote start

No writable system on/off object is listed (MSV 83 System Power State is read-only in this guide). Zones are switched with the Zone x Control MSVs (1 = Off, 2 = Normal...) and Zone x Occupancy; the demand source comes from MSV 28 / MSV 43.

Heartbeat & communication loss

AV 223 Network Timeout (1-900 s) is how long the unit tries to reach the BACnet or Modbus network before it stops operating; BV 44 Network Control State shows 1 = Fault. AV 441 sets the internal zone communication timeout, with per-zone alarms BV 86-91.

Sensors & values from the BMS

Network room RH to AV 106 (MSV 33 = Network) with setpoints AV 107-109; room temperature to AV 155 for cooling profiles; supply high limit RH to AV 122 (MSV 38 = Network) and temperature to AV 175 (MSV 71 = Network). Direct demand goes to AV 138 and high limit to AV 139.

Network setup

  • MS/TP MAC defaults to 1 (000-254; 128-254 are non-token-passing slaves); baud rate auto-detects (Auto, 9600, 19200, 38400, 76800); Max_Master 127.
  • Device instance defaults to 153000 + MAC (153001 out of the box) and can be changed from the menu or by writing Device Object_Identifier.
  • BACnet IP uses UDP 47808 (0xBAC0) by default.
  • Network/communication settings are in the controller's Integration menu (password 5544); power-cycle after connecting to the network.
  • Reinitialize Device (warm/cold reset) over BACnet uses the password 'nep'.

Watch out for

  • MSV 'BACnet Server List Mode' chooses which objects are published (Integrator, Advanced, Factory); objects marked Advanced in the guide, such as the program objects, only show in Advanced mode.
  • Writing Out_of_Service = True disconnects an object from its physical input so the Present_Value can be overwritten; remember to set it back.
  • The unit signals alarms through object values only; it does not send BACnet event notifications, so poll or use COV.
  • COV subscriptions are lost on a power cycle.
  • Many AVs in this guide are commandable (Relinquish_Default listed); write at a consistent priority.

Questions about the Neptronic SKH4

How many BACnet points does the Neptronic SKH4 have?

This list has 325 BACnet objects: 10 analog inputs, 2 analog outputs, 174 analog values, 11 binary inputs, 19 binary outputs, 25 binary values, 6 files, 2 schedules, 54 multi-state values, 7 characterstring values, 15 others. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Neptronic SKH4 BACnet points are writable?

238 of the 325 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Neptronic SKH4 BACnet documentation?

The source is SKH4 High-Pressure Atomizer BACnet Communication Module User Guide (SKH4-BACnet Guide-240126 (V1.00)), revision 2024-01-26, published free by Neptronic at https://www.neptronic.com/Humidifiers/pdf/2024/SKH4-BACnet%20Guide-240126%20(V1.00).pdf.

What are the minimum BACnet points to integrate the Neptronic SKH4?

Start with MV 95 Zone A Control (Zone A on/off: 1 = Off, 2 = Normal); MV 96 Zone A Occupancy (1 = occupied, 2 = unoccupied, 3 = off); MV 28 Control Profile (Control profile: choose a Network profile); AV 138 Control Network Demand (Direct demand written by the BMS, %); AV 107 Room RH Setpoint (Occupied room RH setpoint (internal control)); AV 106 Room RH Network Reading (Network room RH reading for internal control); MV 83 System Power State (System on/off status); AV 143 User Demand (Current humidity demand %); BV 68 Drive State (Drive status: 0 = Ok, 1 = Fault); BV 44 Network Control State (1 = fault: network control lost (AV 223 timeout)).

How do I enable BMS control of the Neptronic SKH4?

No writable system on/off object is listed (MSV 83 System Power State is read-only in this guide). Zones are switched with the Zone x Control MSVs (1 = Off, 2 = Normal...) and Zone x Occupancy; the demand source comes from MSV 28 / MSV 43.

Does the Neptronic SKH4 need a BACnet heartbeat or have a communication timeout?

AV 223 Network Timeout (1-900 s) is how long the unit tries to reach the BACnet or Modbus network before it stops operating; BV 44 Network Control State shows 1 = Fault. AV 441 sets the internal zone communication timeout, with per-zone alarms BV 86-91.

Can the BMS supply sensor values to the Neptronic SKH4?

Network room RH to AV 106 (MSV 33 = Network) with setpoints AV 107-109; room temperature to AV 155 for cooling profiles; supply high limit RH to AV 122 (MSV 38 = Network) and temperature to AV 175 (MSV 71 = Network). Direct demand goes to AV 138 and high limit to AV 139.

How do I check these points on the real SKH4?

Scan the network with a BACnet IP browser such as Easy BACnet, open the device and compare its object list with this table. Anything missing is usually an option that isn't installed or a point that is disabled in the controller's configuration.
