BMS integration notes: Neptronic HECB electric duct heater controller

Integration in brief

Set BV.1 SystemMode to Heat and MSV.2 Occupancy, then either write AV.1 SystemDemand (Network control mode) or, in internal control, AV.12 NetworkSetpoint with MSV.102 = Network setpoint and AV.14 NetworkTemp with MSV.101 = Network Temp. Read AV.3 HeatOutput, MSV.1 AirFlowStatus and BV.30 AL_GlobalAlarmMask.

Enable & remote start

BV.1 SystemMode switches the heater between Heat and Off. MSV.101 and MSV.102 select where the control temperature and setpoint come from.

Heartbeat & communication loss

When the setpoint and/or temperature source is Network, AV.105 Cfg_NetworkTimeout (1-15 min) is the time without BMS communication before the controller raises an alarm and turns the system off; AV.15 NetworkDowncounter shows the countdown, so keep writing the network values.

Sensors & values from the BMS

AV.14 NetworkTemp (with MSV.101 = Network Temp) and AV.12 NetworkSetpoint (with MSV.102 = Network setpoint) take BMS values in internal control mode.

Watch out for

  • Some objects exist only in certain control modes or with EAS sensors / current transducers fitted.

Questions about the Neptronic HECB electric duct heater controller

How many BACnet points does the Neptronic HECB electric duct heater controller have?

This list has 209 BACnet objects: 30 analog inputs, 1 analog output, 100 analog values, 3 binary inputs, 1 binary output, 63 binary values, 2 files, 1 schedule, 7 multi-state values, 1 other. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Neptronic HECB electric duct heater controller BACnet points are writable?

114 of the 209 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Neptronic HECB electric duct heater controller BACnet documentation?

The source is HECB Controller - BACnet User Guide (HECB Controller - BACnet User Guide -240311), revision 2024-03-11, published free by Neptronic at https://www.neptronic.com/Heaters/pdf/2024/HECB%20Controller%20-%20BACnet%20User%20Guide%20-240311.pdf.

What are the minimum BACnet points to integrate the Neptronic HECB electric duct heater controller?

Start with BV 1 SystemMode (Heat or off); MV 2 Occupancy (Occupied, unoccupied or vacant setpoint); AV 1 SystemDemand (Heating demand, 0-100 % (Network control mode)); AV 12 NetworkSetpoint (Setpoint from the BMS (MSV.102 = Network)); AV 8 PowerDemandLimitInput (Maximum output limit, %); AV 14 NetworkTemp (Temperature from the BMS (MSV.101 = Network)); AV 3 HeatOutput (Actual heat output, % of capacity); MV 1 AirFlowStatus (EAS airflow: no heat, no flow, low, regular); BV 30 AL_GlobalAlarmMask (Any alarm active).

How do I enable BMS control of the Neptronic HECB electric duct heater controller?

BV.1 SystemMode switches the heater between Heat and Off. MSV.101 and MSV.102 select where the control temperature and setpoint come from.

Does the Neptronic HECB electric duct heater controller need a BACnet heartbeat or have a communication timeout?

When the setpoint and/or temperature source is Network, AV.105 Cfg_NetworkTimeout (1-15 min) is the time without BMS communication before the controller raises an alarm and turns the system off; AV.15 NetworkDowncounter shows the countdown, so keep writing the network values.

Can the BMS supply sensor values to the Neptronic HECB electric duct heater controller?

AV.14 NetworkTemp (with MSV.101 = Network Temp) and AV.12 NetworkSetpoint (with MSV.102 = Network setpoint) take BMS values in internal control mode.
