Short answer

The Altivar 61 BACnet card serves a fixed object set on BACnet MS/TP: drive relays, logic and analog I/O (BI, BO, AI, AO, some only with the I/O extension cards), control and status Binary Values, and Analog Values for measurements, fault history, the BACnet speed reference, PID setpoint, a parameter mailbox and eight communication-scanner in/out words.

BMS integration notes: Schneider Electric Altivar 61 BACnet MS/TP card VW3A3319

Integration in brief

Set the drive's reference and command channels to the network card ([Ref.1 channel] and [Cmd channel 1] = Com. card), then write AV 16 as the speed reference and BV 10 to start/stop. Read BV 0, AV 1, AV 4 and BV 2 / AV 18 for status and faults; BV 14 resets faults.

Enable & remote start

Menu 1.6 COMMAND: [Ref.1 channel] (Fr1) and [Cmd channel 1] (Cd1) = [Com. card] (nEt). A logic input can be set to switch command and reference back to the terminals.

Heartbeat & communication loss

If the card receives no BACnet message for the [Time-out] (tLP) period (set in 0.1 s steps, display 1-600, default 10), a [Com. network] (CnF) fault occurs; [Network fault mgt] (CLL) sets the reaction (freewheel stop by default; ramp, fast or DC stop, ignore, fallback speed or speed hold).

Sensors & values from the BMS

AV 27 EXT PID STPT takes the PID setpoint from the BMS when the drive PID uses the network setpoint.

Network setup

  • MS/TP MAC address 1-127 from the card switches; baud AUTO (default), 9600, 19200, 38400 or 76800.
  • Device instance = InHP x 1000 + InLP (default 1).
  • Max Master default 127 (must not be below the card address), Max Info Frames default 10.
  • Communication parameters change only with the motor stopped and take effect after a power cycle.

Watch out for

  • Write INPUT REF 1 (AV 16) before RUN/STOP CMD (BV 10) when starting the drive.
  • Parameter changes through the communication scanner must be made with the motor stopped.
  • BO relay commands only work for relays not assigned to a drive function.

Integration notes

  • Objects marked (1) need the VW3A3201 logic I/O card and (2) the VW3A3202 extended I/O card.
  • BI 9 'DI 4 ACT' is described as 'Value of LI3' in the table, probably a typo for LI4.
  • The 2006 manual for the older VW3A3315 card has a slightly different table (BV 18/19 named SP1PRESET/SP2PRESET, BV 7 states BUSY/READY, AV 0 in Hz, AV 35 read-only), so this list is for the VW3A3319 only.
  • COM SCAN OUT/IN AVs (28-43) carry whatever drive parameters are assigned in the communication scanner menu; by default OUT1 = control word, OUT2 = speed reference, IN1 = status word, IN2 = output speed.
  • AV 0 units are printed as 'rmp' (rpm).

Questions about the Schneider Electric Altivar 61 BACnet MS/TP card VW3A3319

How many BACnet points does the Schneider Electric Altivar 61 BACnet MS/TP card VW3A3319 have?

This list has 92 BACnet objects: 5 analog inputs, 3 analog outputs, 41 analog values, 19 binary inputs, 8 binary outputs, 16 binary values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Schneider Electric Altivar 61 BACnet MS/TP card VW3A3319 BACnet points are writable?

35 of the 92 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Schneider Electric Altivar 61 BACnet MS/TP card VW3A3319 BACnet documentation?

The source is Altivar 61 BACnet card User's manual VW3 A3 319 (1765274), revision 2012-08, published free by Schneider Electric at https://download.se.com/files?p_Doc_Ref=1765274.

What are the minimum BACnet points to integrate the Schneider Electric Altivar 61 BACnet MS/TP card VW3A3319?

Start with BV 10 RUN/STOP CMD (Start command (1 = start)); AV 16 INPUT REF 1 (Speed/frequency reference, %); BV 14 FAULT RESET (Fault reset); BV 0 RUN/STOP ACT (Running status); AV 1 OUTPUT FREQ (Output frequency, Hz); AV 4 CURRENT (Motor current, A); BV 4 HAND/AUTO ACT (Hand/auto (local control) status); BV 2 FAULT ACT (Drive fault); AV 18 LAST FLT (Last fault code).

How do I enable BMS control of the Schneider Electric Altivar 61 BACnet MS/TP card VW3A3319?

Menu 1.6 COMMAND: [Ref.1 channel] (Fr1) and [Cmd channel 1] (Cd1) = [Com. card] (nEt). A logic input can be set to switch command and reference back to the terminals.

Does the Schneider Electric Altivar 61 BACnet MS/TP card VW3A3319 need a BACnet heartbeat or have a communication timeout?
