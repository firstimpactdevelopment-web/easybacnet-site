BMS integration notes: Schneider Electric SE7300 Series PIR Ready Fan Coil Controller

Integration in brief

Command occupancy with MV 18 and the mode with MV 16, fan mode with MV 17, and write the occupied setpoints AV 39/AV 40. Read AV 7 room temperature, MV 33 effective occupancy and MV 28 fan status. The BMS can also send outdoor temperature to AV 9.

Enable & remote start

BACnet stays off until the MAC address is changed from the factory 254 to 0-127. MV 18 Occupancy Command: 1 = Local Occupancy, 2 = Occupied, 3 = Unoccupied.

Sensors & values from the BMS

The BMS can write Outdoor Temperature (AV 9) and, for testing or override, Room Temperature (AV 7); AV 7 only accepts writes while BV 8 Room Temp Override is set to Override. On the humidity models, Room Humidity (AV 10) likewise needs BV 11 Room Humid Override. Written room temperature, outdoor temperature and occupancy are released if the controller goes offline.

Network setup

  • Controllers ship with MAC address 254, which keeps BACnet communication off. Set the MAC address (0-127) at the controller to enable BACnet MS/TP.
  • Default Device ID is 73000 + MAC address.
  • Baud rate auto-detects (9600, 19200, 38400, 76800) at power-up; after a network speed change the device keeps the old speed for 10 minutes unless re-powered.
  • Default Device Name is the model number plus the MAC address; Device Name and Device ID are writable.
  • No COV support: poll at 5 seconds or slower and write on change ('if once' or every few minutes), not every program scan.

Watch out for

  • If the controller goes offline, values the BMS wrote to Room Temperature, Outdoor Temperature and Occupancy are released.
  • Segmented requests and responses are not supported; keep Read Property Multiple requests small.
  • The device object has no Local_Time or Local_Date, so the controller cannot claim DM-TS-B even though time sync over the network works.

Integration notes

  • Access comes from the objects table (Present_Value R or R,W). Writable AV, BV and MV objects are marked commandable 'C'.
  • Group objects (GRP) are listed as type 'Other'; they only bundle related objects. Schneider suggests removing configuration objects from the BAS after setup to cut polling.
  • State texts and ranges come from the guide's enumeration tables where the object name and instance match; a few enumeration rows use different instances than the objects table and were not applied.
  • The PIR cover and the humidity sensor are model options: objects marked 'only ...' exist only on the listed part numbers.
  • The objects table prints 'General Options 2' as GRP 45, the same instance as 'General Options 1'; the SER7300 table and the configuration section give GRP 55. It is listed once here as GRP 45 General Options 1.
  • AV 10 is Room Humidity on the SE7350/SE7355 and 'A02 ECM Value' on the special SE7300F5x45B-2572; only Room Humidity is listed here.
  • In this table the alarms are BI 36 Window, BI 37 Filter and BI 38 Service Alarm; the enumeration table and GUI list call them BI 35-37. Other slips: the GUI list gives Unoccupied Cool Setpoint as 'AV34' and Output 1 as 'MV28', Figure 1 calls System Mode 'AV16', and the sample program writes occupancy to 'MV13'; the objects table has AV 44, MV 27, MV 16 and MV 18.
  • Fan Mode Sequence is printed as MV 58 in this table and in the Fan Mode enumeration notes, but as MV 57 in the SER table and the enumeration table; listed here as MV 58.

How many BACnet points does the Schneider Electric SE7300 Series PIR Ready Fan Coil Controller have?

Which Schneider Electric SE7300 Series PIR Ready Fan Coil Controller BACnet points are writable?

48 of the 71 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
