BMS integration notes: Schneider Electric PowerLogic PM5500 / PM5600 / PM5700 power meter (BACnet IP)

Integration in brief

Enable BACnet IP on the meter and set a unique Device ID, then read total power, energy, demand, power factor, average voltage and current. The meter is monitoring-only over BACnet.

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Network setup

  • Enable BACnet IP and set the Device ID, UDP port (default 47808) and BBMD/foreign-device settings on the display (Maint > Setup > Comm > BACnet) or the meter webpages.
  • The Device ID ships as the last 6 digits of the serial number; it must be unique on the network.
  • Up to 20 COV subscriptions are supported on AI, BI and MSI objects; no segmentation, max APDU 1476 bytes.

Watch out for

  • All configuration objects are read-only over BACnet; change meter settings on the display, webpages or ION Setup.
  • Out_Of_Service is writable for testing; set it back to false or the BMS sees the test value instead of the measurement.
  • Digital input and output status BIs read 0 = on, 1 = off as printed in the manual; check the polarity on site.
