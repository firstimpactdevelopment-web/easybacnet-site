Short answer

The HDPM6000 head unit meters up to 192 branch channels, three-phase mains meters and circuits built from channels, and serves them on BACnet IP. Objects are grouped in numbered blocks: one object per channel, phase, circuit, TAP or harmonic. This list gives the first object of each block with its printed name pattern (e.g. 'Ch n Vrms') and the instance range. Analog Inputs hold readings; AV, PIV, BitString and CharString Values hold settings, alarm states and names.

BMS integration notes: Schneider Electric PowerLogic HDPM6000 high-density power meter (BACnet IP)

Integration in brief

Enable BACnet in the head unit's protocol settings (web interface), then read the mains meter totals and the per-channel blocks you need, computing each channel's instance from the block start. Alarm and warning states are bitstrings.

Enable & remote start

BACnet is enabled with a protocol flag in the head unit's network settings (web interface or Modbus); there is no BMS enable point.

Network setup

  • BACnet IP only, over the head unit's Ethernet port; no BACnet MS/TP.
  • Network, protocol enables and device settings are set in the web interface (see the head unit installation guide Z208128) or by Modbus.
  • No segmentation is claimed in the PICS.

Watch out for

  • 'Ch n kWh resetting' (AI 600-719) is no longer supported and always reads 0; use 'Ch n kWh'.
  • Channel numbers above 120 use separate blocks (e.g. Ch n ITHD for 121-192); check the block's n range.
  • Some printed block starts are wrong in the guide (see notes); verify by reading the object names on site.

Integration notes

  • Each row is the first object (n = 1, or the first c, t or h) of a block; the description gives the variable range and the full instance range. Object k of a block is the first instance + (k - 1); harmonic blocks step over odd harmonics only, per the guide.
  • Names are the printed patterns; on the device n, c, t, p, v or h is replaced by the channel, circuit, TAP, port, value or harmonic number.
  • The guide prints some block starts wrongly: '3 phase meter 3 Ch n Demand Max Reactive Power' and '... Avg Current' as 17075 and 17078; by sequence they are 14075 and 14078 and are listed so. It also prints 13972-13984 for a 3-instance block (13972-13974) and overlapping ranges 1617-1689 / 1689-1760 for PIV channel alarm thresholds and warning delays.
  • Present_Value is writable for AV, PIV, BitString and CharString Value objects per the PICS, but the guide says configuration is normally done through Modbus or the web interface.
  • BitString Value objects (alarm and warning states, dry inputs) are listed as type Other. The environmental sensor block name prints '[3phm | TAP]'; shown here with a slash.
  • BACnet is only on Ethernet; the RS-485 port is Modbus RTU. Source: HDPM6000 Protocol Guide ZL0192-0G (04/2026), Section 4.

Which Schneider Electric PowerLogic HDPM6000 high-density power meter (BACnet IP) BACnet points are writable?

109 of the 386 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
