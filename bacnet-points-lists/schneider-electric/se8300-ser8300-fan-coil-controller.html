Short answer

The SE8300 and SER8300 are SE8000 Series touchscreen fan coil controllers on BACnet MS/TP (B-ASC). This 2014 manual prints one object list with tick columns for four models: SER8300, SER8350, SE8300 and SE8350. The 8350 models add humidity sensing and dehumidification objects; the SE models add universal outputs UO 9-12, remote sensor inputs and an auxiliary output, while the SER models have dedicated heating/cooling outputs. Object names are those of this older firmware and differ from the later SpaceLogic SE8350 guides.

BMS integration notes: Schneider Electric SE8300 / SER8300 Series Fan Coil Controller (SE8000 Series, 2014 BACnet list)

Integration in brief

Set a MAC address from 0 to 127 (the factory value 254 keeps BACnet off), then command occupancy (MV 10), system mode (MV 16), fan mode (MV 17) and the occupied setpoints (AV 39 / AV 40). Read room temperature (AV 100), effective occupancy (MI 33), the PI demands and the alarm BVs. Use priorities 4-16 for live commands.

Enable & remote start

BACnet communication starts once the MAC address is changed from the factory value 254 to 0-127. The BMS then writes MV 10 Occupancy Command (1 = Local Occupancy, 2 = Occupied, 3 = Unoccupied) and MV 16 System Mode.

Heartbeat & communication loss

No heartbeat point. If the controller goes offline, network-bound Room Temperature, Outdoor Temperature and Occupancy are released.

Sensors & values from the BMS

The manual lists Outdoor Temperature (AV 101) as a global value the BMS can send to all controllers, and Room Temperature (AV 100) for testing and override. Writes at priority 4-16 override the controller's own value until relinquished or power is lost.

Network setup

  • Factory MAC address is 254, which disables BACnet; set 0-127 to join the token ring.
  • Default Device ID is 83000 + MAC (MAC 63 gives 83063); default device name is the model number plus MAC. Both are writable.
  • Baud rate auto-detects at power-up (MV 8, default Auto); after a speed change the device keeps the old rate for 10 minutes before auto-bauding again.
  • Up to 64 nodes per EIA-485 segment; maximum data rate used is 76800 bps.

Watch out for

  • Priorities 1-3 are saved to flash and survive a power cycle, locking the value until a NULL is written at the same priority; use 4-16 (RAM) for live control and rewrite after a restart.
  • Writing the Relinquish_Default stores a new value in flash without bypassing the controller logic; the manual prefers it for configuration and user HMI objects.
  • CSV 1 / CSV 2 screen messages are not saved in flash and are lost on power loss.
  • Remove configuration objects from the BAS after setup to cut polling traffic, as the manual recommends.

Integration notes

  • Model availability is given at the end of a description when an object is not on all four models (SER8300, SER8350, SE8300, SE8350).
  • Access follows the manual's property tables: AV, AO, BV, BO and MV present values are commandable, CSVs are writable, and AI, BI and MSI (MI here) objects are read-only.
  • BI 29, BI 30, BI 91, MV 46 and MV 47 are printed with both names (e.g. 'BI 1 / UI 16 Status'): the part before the slash applies to SER83xx models, after the slash to SE83xx models.
  • The range tables use a few alternative names (e.g. Unoccupied Cooling Setpoint, RH Display for MV 70, Fan Menu Sequence for MV 57); names here follow the main object list. No state tables are printed for MV 49, 81, 91, 92 and 94, and no ranges for AV 5, 6 and 46.
  • For the newer SpaceLogic SE8350 / SER8350 firmware (much larger object list, different names) see the separate SE8350 and SER8350 lists.
