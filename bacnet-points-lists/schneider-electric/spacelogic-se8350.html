Short answer

The SE8350 is a 24 Vac touchscreen room controller for fan coil units and zoning, from the Schneider Electric SpaceLogic SE8000 line. It is a BACnet application-specific controller (B-ASC) on BACnet MS/TP, and the object list also includes Wi-Fi module and BACnet IP status objects, some set from the controller's configuration web page. BMS integration notes: Schneider Electric SpaceLogic SE8350 Fan Coil and Zone Controller

Integration in brief

Command occupancy with MV 10, mode with MV 16 and fan mode with MV 17, and write the occupied setpoints AV 39/AV 40. Read AV 100 room temperature, MI 33 effective occupancy, MV 112 control status and MI 326 fan speed. Write at priorities 4-16 for live control; avoid 1-3.

Enable & remote start

The BMS writes MV 10 Occupancy Command (1 = Loc. occ, local occupancy; 2 = Occupied; 3 = Unoccupied) and MV 16 System Mode. MV 110 Occupancy Source chooses whether local occupancy follows motion, the schedule or a mix.

Sensors & values from the BMS

The guide does not describe feeding room temperature from the BMS. MV 145 Room Temperature Sensor selects the wired, internal or one of 20 paired ZigBee wireless sensors, and MI 309 shows which one is in use. AI present values are only writable with Out_Of_Service set TRUE.

Network setup

  • The Device Object_Identifier and Object_Name are writable; no default device instance is printed in the guide.
  • BACnet MS/TP baud rate is MV 8 (9600, 19200, 38400, 57600, 76800, 115200 or Auto; default Auto). Max_Master is writable, 0-127, default 127.
  • MI 317 shows whether BACnet IP is enabled; the guide lists it on the BACnet/IP page of the configuration web page.
  • COV subscriptions are supported (DS-COV-B), along with an internal schedule (SCHED-I-B) and time synchronization.

Watch out for

  • Priorities 1-3 are stored in EEPROM and lock the value at the thermostat, even after a power cycle, until it is released at the same priority or factory defaults are restored. Use them only for fixed configuration.
  • Priorities 4-16 are held in RAM and are lost on a power cycle, so the BMS has to write them again after the controller restarts.
  • The relinquish default (priority 17) is the value the occupant changes at the thermostat, which is kept through power cycles. Writes at 4-16 override local changes to setpoints and modes.
  • The controller does not support segmented requests or responses; keep Read Property Multiple requests small.
  • MV 15 Sequence of Operation, AV 52 Number of Pipes and the UI/UO configuration objects are commissioning settings; do not write them cyclically.

Questions about the Schneider Electric SpaceLogic SE8350 Fan Coil and Zone Controller

How many BACnet points does the Schneider Electric SpaceLogic SE8350 Fan Coil and Zone Controller have?

Which Schneider Electric SpaceLogic SE8350 Fan Coil and Zone Controller BACnet points are writable?

257 of the 434 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Schneider Electric SpaceLogic SE8350 Fan Coil and Zone Controller BACnet documentation?

The source is SpaceLogic SE8350 BACnet Integration Guide - Low Voltage (24VAC) Fan Coil Unit (FCU) and Zone Control - Firmware Revision 2.6, Version 9 (028-0550-09_IG-SE8350-BNET_A4_EN (Version 9)), revision 2022-05, published free by Schneider Electric at https://download.se.com/files?p_Doc_Ref=IG-SE8300-BNET.

What are the minimum BACnet points to integrate the Schneider Electric SpaceLogic SE8350 Fan Coil and Zone Controller?

Start with MV 10 Occupancy Command (BMS occupancy: local, occupied or unoccupied); MV 16 System Mode (Off / auto / cool / heat); MV 17 Fan Mode (Fan mode: low / medium / high / auto / on); AV 39 Occupied Heat Setpoint (Occupied heating setpoint); AV 40 Occupied Cool Setpoint (Occupied cooling setpoint); MV 112 Control Status (Current state: off, cooling or heating); MI 326 Fan Speed Status (Fan speed status: off / low / medium / high); MI 33 Effective Occupancy (Actual occupancy state); AV 100 Room Temperature (Space temperature used for control); BV 37 Service Alarm (Service alarm from an input set to Service).

How do I enable BMS control of the Schneider Electric SpaceLogic SE8350 Fan Coil and Zone Controller?

The BMS writes MV 10 Occupancy Command (1 = Loc. occ, local occupancy; 2 = Occupied; 3 = Unoccupied) and MV 16 System Mode. MV 110 Occupancy Source chooses whether local occupancy follows motion, the schedule or a mix.

Can the BMS supply sensor values to the Schneider Electric SpaceLogic SE8350 Fan Coil and Zone Controller?

The guide does not describe feeding room temperature from the BMS. MV 145 Room Temperature Sensor selects the wired, internal or one of 20 paired ZigBee wireless sensors, and MI 309 shows which one is in use. AI present values are only writable with Out_Of_Service set TRUE.
