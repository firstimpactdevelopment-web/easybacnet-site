Short answer

Measurlogic DTS meters are DIN-rail, panel and socket energy meters for single-phase, three-phase and DC circuits. Meters ordered with the 'BACnet MS/TP ML' option use this object map: per-phase voltages, currents, frequency, power, power factor, unbalance and demand as analog inputs, net and split energy counters, demand time stamps as DateTime Value objects, and configuration and communication settings as writable analog and binary values. Meters without 'ML' on the label use a different map.

BMS integration notes: Measurlogic DTS meters with the BACnet MS/TP ML protocol option (DTS 305 / 307 / 310 / SMX / SKT / DC)

Integration in brief

Set a unique MAC address and Device ID (default MAC 1, Device ID 473001, 38400 baud), then read total power, energy, voltages, currents and demand. Confirm the energy resolution with AV 8023 EnerPowDivider before trending energy.

Network setup

  • Defaults: 38400 baud, Device ID 473001, MAC address 1, Max_Master 127; change them with AV 8060-8065 (Device ID and Max_Master also through the device object). BV 8060 shows pending changes and BV 8059 resets the protocol.
  • On meters with address switches the MAC address follows the switches and the Device ID is 473000 + MAC; set all switches ON to configure the address over the network instead.
  • Fit an external 120 ohm terminator where the meter has no Term_Resistor object (BV 8061).

Watch out for

  • Energy registers roll over at nine digits; the roll-over point depends on EnerPowDivider (AV 8023, default 10,000 = 10 W resolution).
  • To reset maximum demand, write 0 to AV 20001 and then 61442 to AV 20101.
  • Power factor sign shows import/export, not leading/lagging; use the reactive power sign for that.

Integration notes

  • The map has no read/write column: measurements are shown read-only and the configuration, communication and command objects writable, except BV 8060 Changes_Pending which is marked read-only.
  • Which objects carry data depends on the meter model and wiring; unused channels stay empty.
  • The main table lists the maximum demand objects as AI 6229 and AI 6230; the demand section (2.4) prints them as AI 6629 and AI 6630. The main table numbers are used here; check which instance the meter actually returns.
  • The demand time stamps (DTV 7029 / 7030) are DateTime Value objects, which need BACnet protocol revision 12 support in the front end.
  • Meters without 'ML' in the protocol description on the label use a different Measurlogic BACnet map.

Questions about the Measurlogic DTS meters with the BACnet MS/TP ML protocol option (DTS 305 / 307 / 310 / SMX / SKT / DC)

How many BACnet points does the Measurlogic DTS meters with the BACnet MS/TP ML protocol option (DTS 305 / 307 / 310 / SMX / SKT / DC) have?

This list has 96 BACnet objects: 82 analog inputs, 9 analog values, 3 binary values, 2 datetime values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Measurlogic DTS meters with the BACnet MS/TP ML protocol option (DTS 305 / 307 / 310 / SMX / SKT / DC) BACnet points are writable?

11 of the 96 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done. The source has no read/write column, so this is inferred from object type.
