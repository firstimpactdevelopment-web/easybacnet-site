Short answer

The M2000 talks BACnet through a plug-in daughterboard (BACnet MS/TP or BACnet/IP) that maps the meter's Modbus parameters to BACnet objects. Almost everything is an Analog Value: flow rate and velocity, forward/reverse/net totals in m³ and user units, batch total, plus the full meter setup (detector, units, scaling, outputs, filters, empty-pipe detection) and port diagnostics. Text items such as firmware names and display strings are CharacterString Values. Both manuals use the same instance numbers; the network-settings objects differ by card.

This page lists 165 BACnet objects for the Badger Meter ModMAG M2000 electromagnetic flow meter (BACnet MS/TP and BACnet/IP) — 92 of them writable — with each object’s type, instance number, name, engineering units and access. BMS integration notes: Badger Meter ModMAG M2000 electromagnetic flow meter (BACnet MS/TP and BACnet/IP)

Integration in brief

Set up the daughterboard from Main Menu > Communications > Daughterbrd Config (MS/TP baud, MAC, max master and instance, or IP/DHCP/port and instance), then cycle power. Read the flow rate and the forward, reverse and net totals in user units, and the flow direction. Leave the writable setup objects alone outside commissioning.

Network setup

  • MS/TP card defaults: 9600 baud, MAC 1, max master 127, instance 10001. Change them at Main Menu > Communications > Daughterbrd Config and cycle power.
  • BACnet/IP card defaults: DHCP on, static IP 192.168.0.1 / 255.255.0.0, gateway 10.0.1.1, UDP port 47808, instance 10001, web server on.
  • Before fitting a card in the field, set Port B to address 1, extended address 126, 9600 baud, 8 bits, even parity, 1 stop bit; needs meter firmware v1.22 or later.
  • BACnet/IP foreign-device registration is set on the web page; a zero BBMD address, port or TTL turns it off. Changes need a power cycle.

Watch out for

  • Configuration changes only take effect after a power cycle.
  • The MS/TP card is a B-SA device on MS/TP master; it supports ReadProperty, ReadPropertyMultiple and WriteProperty, no COV.
  • Many objects are calibration or setup values; writing them changes how the meter measures.
  • Totals in m³ (AV 82, 84, 86) are independent of the display units; the _User versions follow the configured volume units.

Integration notes

  • AV 149-152, 159, 160 and 166-169 (IP address, DHCP, UDP port, Ethernet MAC, web server, foreign-device settings) exist only on the BACnet/IP card. AV 155-157 and 164 are MS/TP settings; the BACnet/IP manual's communication-settings table marks 155-157 and 164 as reserved.
  • The manuals list the remaining instances in the communication-settings block as RESERVED; they are left out here.
  • Parameter indexes 120-136 have no BACnet object in either manual (AV 98-114 are not used).
  • Writable setup values (detector factors, units, outputs, filters) change the meter's calibration and configuration; leave them alone unless commissioning.
  • Enumerations for units, outputs and other settings are taken from the BACnet/IP manual's enumeration table.
  • Sources: MAG-UM-03547-EN-01 (MS/TP, April 2022) and MAG-UM-03548-EN-01 (BACnet/IP, July 2022).

Questions about the Badger Meter ModMAG M2000 electromagnetic flow meter (BACnet MS/TP and BACnet/IP)

How many BACnet points does the Badger Meter ModMAG M2000 electromagnetic flow meter (BACnet MS/TP and BACnet/IP) have?

This list has 165 BACnet objects: 148 analog values, 17 characterstring values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Badger Meter ModMAG M2000 electromagnetic flow meter (BACnet MS/TP and BACnet/IP) BACnet points are writable?

92 of the 165 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official Badger Meter ModMAG M2000 electromagnetic flow meter (BACnet MS/TP and BACnet/IP) BACnet documentation?

The source is Electromagnetic Flow Meters, M2000 BACnet MS/TP Communication Protocol, User Manual (MAG-UM-03547-EN-01), revision 2022-04, published free by Badger Meter at https://badgermeter.widen.net/content/wmrokmil4z/original?download=false&x.app=api.

What are the minimum BACnet points to integrate the Badger Meter ModMAG M2000 electromagnetic flow meter (BACnet MS/TP and BACnet/IP)?

Start with AV 93 FlowRate_User (Flow rate in the configured units); AV 91 FlowVelocity_Usr (Flow velocity in user units); AV 87 T3_TNet_User (Net total, user units); AV 83 T1_Tplus_User (Forward total, user units); AV 85 T2_Tminus_User (Reverse total, user units); AV 97 FlowDirection (Present flow direction); AV 94 RelFlowRatePerc (Flow as % of full scale); AV 125 EmptyPipeActRes (Empty pipe detection reading).
