Short answer

The TFX-500w's RS-485 port runs Modbus RTU or BACnet MS/TP. Over BACnet it gives flow rate and velocity (home-screen units, US and metric), net/positive/negative/gross totals as single-precision AVs and 64-bit Large Analog Values, overflow counters, unit selections, three writable cutoff settings, signal strength and four command BOs.

BMS integration notes: Badger Meter Dynasonics TFX-500w clamp-on ultrasonic flow meter (BACnet MS/TP)

Integration in brief

In Main Menu > System Setup > Communication select BACnet MS/TP, set MAC and BACnet ID, match the trunk settings and choose read-only or read/write access. Read flow rate, a net or positive total and signal strength.

Minimum points to map

The short list most integrators start with — enough to run the unit from a BMS. Map more as the job needs.

Enable & remote start

BACnet writes only work when the meter's Access setting in the BACnet MS/TP menu is read/write.

Network setup

  • Main Menu > System Setup > Communication > BACnet MS/TP: MAC 1-254, BACnet ID 0-4,194,303.
  • Baud (9600-115200), parity, stop bits and max MAC must match the master.
  • Built-in termination resistor is enabled in the communication settings.
  • Connecting the USB programming cable disables the RS-485 port.

Watch out for

  • Writing BO 0 Reset Totalizers zeroes every total.
  • Totals overflow; the overflow counters (AV 2304-2307) count rollovers of the home-screen totals.

  • Each total exists three ways: in home-screen units, gallons and liters; each as an AV (32-bit) and an LAV (64-bit). Map one set.
  • Names are the manual's descriptive names.
  • Writes need the meter's BACnet access setting to allow read/write; it can be set read-only.
  • MV 3001 is not listed.

Questions about the Badger Meter Dynasonics TFX-500w clamp-on ultrasonic flow meter (BACnet MS/TP)

How many BACnet points does the Badger Meter Dynasonics TFX-500w clamp-on ultrasonic flow meter (BACnet MS/TP) have?

This list has 46 BACnet objects: 27 analog values, 4 binary outputs, 3 multi-state values, 12 large analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which Badger Meter Dynasonics TFX-500w clamp-on ultrasonic flow meter (BACnet MS/TP) BACnet points are writable?

7 of the 46 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.
