AERCO Edge [ii] water heater controller (standalone / WHM) BACnet points list

Updated 28 October 2026

Short answer

The Edge [ii] controller on AERCO water heaters talks BACnet IP on its Ethernet port or BACnet MS/TP on the J14 RS-485 terminals. Standalone and client units expose analog inputs for status, temperatures, valve position, O2 and combustion-calibration data plus analog values for setpoints and setup. A WHM manager adds plant values and a read-only block for each of up to 16 units. Only analog inputs and analog values are used.

This page lists 206 BACnet objects for the AERCO Edge [ii] water heater controller (standalone / WHM) — 73 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from AERCO’s own free documentation, linked below.

BMS integration notes: AERCO Edge [ii] water heater controller (standalone / WHM)

Integration in brief

Enable the BAS port under Advanced Setup > Comm & Network > BAS (BACnet IP on the Ethernet port or BACnet MS/TP on J14), set the communication address and node offset, then have the BAS write the setpoint. For a WHM plant connect the BAS to the manager (or backup manager) only; it exposes plant values and a read-only block per unit.

Enable & remote start

Under Advanced Setup > Comm & Network > BAS pick BACnet IP or BACnet MSTP (default Off). The BAS controls the unit through AV 12 Operating Mode (1 = Remote Setpt), AV 13 Remote Signal (3 = BAS) and the setpoint (AV 4, or AV 245 on a WHM manager). AV 80 Remote Disable Code (AV 229 for the plant) disables with 85 and enables with 0, but only when Allow System Disable = Yes in the BAS menu.

Heartbeat & communication loss

The BAS screen has a BAS Comm Timeout setting (range and default not given). On a WHM manager, AV 53 Network Timeout is listed as 5-999 s. AV 24 Unit Failsafe Mode sets what a unit does on lost communication: 0 = Shutdown, 1 = Constant Setpt.

Sensors & values from the BMS

On a WHM manager AV 213 Hdr Temp Sensor can be set to 3 = BAS, after which the BAS writes the header temperature to AV 214. AV 215 selects the return header sensor source.

Network setup

  • BACnet MS/TP: baud 9600-115200, address 0-127, 8 data bits, no parity, 1 stop bit; wire to J14 pins 1 (+) and 2 (-), shield to J3 pin 8.
  • Terminate the BAS RS-485 with SW3 switch 5 ON only at the BAS and the first and last units on the daisy chain; biasing must be supplied externally.
  • BACnet IP: device instance = Node Offset + Communication Address; UDP port selectable 0xBAC0-0xBACF; DHCP enabled unless turned off in the Ethernet screen.
  • Each standalone unit or manager needs its own Ethernet connection through a switch; don't daisy-chain them.
  • AERCO recommends wiring the BAS to the backup manager too, so it can take over BAS communication.

Watch out for

  • Optional BAS IP/MAC security limits which server can talk to the controller.
  • Unit blocks repeat every 100 IDs (unit 1 = AI 300-319 ... unit 16 = AI 1800-1819); only unit 1 is listed.
  • Remote Disable only works with Allow System Disable = Yes.
  • AI 100-122 and AV 53 mean different things on a WHM manager and on a standalone/client unit; see the notes.

Integration notes

  • Access is given per table in the manual (AI tables read only, AV tables read/write), not per point; it is applied that way here.
  • Two tables in the manual give AI 100-122 and AV 53 different meanings. On a WHM manager they are the plant values listed here (AI 100-122) and AV 53 Network Timeout (5-999 s). On a standalone unit or WHM client the same IDs are calibration history instead (AI 99-106 Previous O2 at Cal 1-8, AI 107-114 Previous NOx at Cal 1-8, AI 115-122 Previous CO at Cal 1-8) and AV 53 is FFWD Temp Display.
  • AI 123-138 (previous calibration points and flame strength) are from the standalone/client table; the manager table marks AI 123-151 Not Used.
  • The WHM manager repeats a read-only block for each of up to 16 units; only unit 1 (AI 300-319) is listed here. Unit n uses the same names at AI 300 + 100 x (n - 1) to 319 + 100 x (n - 1), so unit 16 = AI 1800-1819.
  • Objects marked Not Used, Unused or NA for the Edge [ii] are left out.
  • Temperatures are listed in °F; the BAS Temp Format setting can switch the interface to Celsius. AERCO's BACnet vendor ID is 601.

Questions about the AERCO Edge [ii] water heater controller (standalone / WHM)

How many BACnet points does the AERCO Edge [ii] water heater controller (standalone / WHM) have?

This list has 206 BACnet objects: 133 analog inputs, 73 analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AERCO Edge [ii] water heater controller (standalone / WHM) BACnet points are writable?

73 of the 206 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official AERCO Edge [ii] water heater controller (standalone / WHM) BACnet documentation?

The source is Edge [ii] Controller Communication Manual (OMM-0162C), revision 2025-10-15, published free by AERCO at https://www.aerco.com/dfsmedia/0533dbba17714b1ab581ab07a4cbb521/659416-source/omm-0176-aerco-edge-ii-communication-manual-4-1-25.pdf.

What are the minimum BACnet points to integrate the AERCO Edge [ii] water heater controller (standalone / WHM)?

Start with AV 80 Remote Disable Code (85 = disable unit, 0 = enable); AV 12 Operating Mode (Selects constant or remote setpoint); AV 13 Remote Signal (Set to BAS so the remote setpoint comes from BACnet); AV 4 Setpoint (Unit temperature setpoint, 20-245 °F); AV 245 WHM Setpoint (Plant setpoint on a WHM manager); AI 1 Unit Status (Standby / manual / remote / auto / fault state); AI 2 Outlet (Outlet water temperature); AI 8 Current Valve Position (Firing (valve) position, %); AI 0 Message Code (Active event / fault code); AI 108 Units Faulted (Units faulted in the WHM plant).

How do I enable BMS control of the AERCO Edge [ii] water heater controller (standalone / WHM)?

Under Advanced Setup > Comm & Network > BAS pick BACnet IP or BACnet MSTP (default Off). The BAS controls the unit through AV 12 Operating Mode (1 = Remote Setpt), AV 13 Remote Signal (3 = BAS) and the setpoint (AV 4, or AV 245 on a WHM manager). AV 80 Remote Disable Code (AV 229 for the plant) disables with 85 and enables with 0, but only when Allow System Disable = Yes in the BAS menu.

Does the AERCO Edge [ii] water heater controller (standalone / WHM) need a BACnet heartbeat or have a communication timeout?

The BAS screen has a BAS Comm Timeout setting (range and default not given). On a WHM manager, AV 53 Network Timeout is listed as 5-999 s. AV 24 Unit Failsafe Mode sets what a unit does on lost communication: 0 = Shutdown, 1 = Constant Setpt.

Can the BMS supply sensor values to the AERCO Edge [ii] water heater controller (standalone / WHM)?
