AERCO Benchmark E / Edge X BACnet points list

Updated 16 October 2026

Short answer

The Edge X controller on AERCO's Benchmark E boilers talks BACnet IP on its Ethernet port or BACnet MS/TP on its RS-485 port. Standalone and client units expose their own setpoints and readings, while a BST cascade manager also exposes plant-level values and a block of read-only points for every unit in the cascade (up to 16). Only analog inputs (read only) and analog values (read/write) are used.

This page lists 390 BACnet objects for the AERCO Benchmark E / Edge X — 38 of them writable — with each object’s type, instance number, name, engineering units and access. It is re-typed from AERCO’s own free documentation, linked below.

BMS integration notes: AERCO Benchmark E / Edge X

Integration in brief

Enable the BAS port in the Edge X Comm & Failsafe menu (BACnet IP on the J5 Ethernet jack or MS/TP on the RS-485 terminals), choose the comm-loss behaviour, then have the BAS write the setpoint. For a cascade, connect the BAS to the BST manager only; it exposes plant values plus a read-only block for each unit. A technician-level password is needed before BAS points are available.

Enable & remote start

On the controller go to Settings > Advanced Setup > Comm & Failsafe and enable BAS; for IP turn on the "BAS (J6)" toggle, which actually uses the J5 jack. The object list has no separate start/stop object: the BAS controls the unit through AV 12 Operating Mode, AV 13 Remote Signal (0 = BAS) and the setpoint in AV 4, or AV 200 on a BST manager. Firing-rate control (Direct Drive) is listed only for legacy BMK units.

Heartbeat & communication loss

The BAS Comm Failsafe setting chooses whether the unit shuts down or runs at a constant setpoint when it loses the BAS (AV 24 Unit Failsafe Mode: 0 = Standby, 1 = Constant Setpt). The BACnet IP screen also has a delay-before-communication-fault setting; its range and default are not given.

Sensors & values from the BMS

AV 85 / AV 213 Supply Header Temp Source and AV 215 return header source can be set to BAS (2), but the object list has no writable header or outdoor temperature value. On BMK E the outdoor sensor source (AV 81 / AV 217) is listed as Direct only.

Network setup

  • BACnet IP settings on the controller include DHCP on/off, IP address, a device-instance offset to avoid duplicates, the UDP port, network number and comm-fault delay; defaults are not printed.
  • MS/TP uses the same configuration screen with only the baud rate added; wire to J16 pins 5 (+) and 7 (-) on the I/O board and use the MODBUS1 (SW4) TERM1 switch at the ends of the BAS trunk.
  • One BAS connection per cascade manager or standalone unit; manager and clients talk to each other over Modbus RS-485.
  • BACnet vendor ID 983; ReadProperty and WriteProperty only, no segmentation.

Watch out for

  • Cascade unit blocks: unit 1 = AI 300-320, unit 2 = AI 400-420 ... unit 16 = AI 1800-1820.
  • Several IDs have different names or ranges on legacy Benchmark (BMK) Edge units; check which controller you have.
  • AV 8 switches the BAS interface between English and Metric units.

Integration notes

  • A technician-level password is needed on the controller before BAS points are available.
  • BACnet vendor ID is 983; device profile B-ASC; ReadProperty and WriteProperty only, no segmentation.
  • Cascade unit points repeat in blocks: unit 1 uses IDs 300-320, unit 2 uses 400-420, and so on up to unit 16 at 1800-1820.
  • The manual lists one BAS connection per cascade manager or standalone unit; cascade members talk to the manager over Modbus RS-485.
  • Several IDs carry different names or ranges on legacy Benchmark (BMK) Edge units; legacy names are given in the descriptions, and points marked legacy BMK only are not used on BMK E.
  • Temperatures are listed in °F; AV 8 switches the BAS interface between English and Metric.

Questions about the AERCO Benchmark E / Edge X

How many BACnet points does the AERCO Benchmark E / Edge X have?

This list has 390 BACnet objects: 352 analog inputs, 38 analog values. The exact set on a given unit depends on its firmware, installed options and configuration.

Which AERCO Benchmark E / Edge X BACnet points are writable?

38 of the 390 objects accept a write. Points marked Command have a priority array: a write holds until it is released, so release it back to automatic when you are done.

Where is the official AERCO Benchmark E / Edge X BACnet documentation?

The source is Edge X Communication Guide for Systems Integrators (Edge X Communication Manual) (OMM-0173E), revision 2025-06-17, published free by AERCO at https://www.aerco.com/dfsmedia/0533dbba17714b1ab581ab07a4cbb521/664721-source/638954248340000000/omm-0173-edge-x-communication-manual-6-17-25.pdf.

What are the minimum BACnet points to integrate the AERCO Benchmark E / Edge X?

Start with AV 12 Operating Mode (Selects constant, remote or outdoor-reset setpoint); AV 13 Remote Signal (Set to BAS so the remote setpoint comes from BACnet); AV 4 Setpoint (Unit setpoint); AV 24 Unit Failsafe Mode (What the unit does if BAS comms are lost); AI 1 Unit Status (Unit state); AI 2 Outlet Temp (Outlet temperature); AI 0 Active Event ID (Active event / fault code); AV 200 Setpoint (Plant setpoint on a BST manager); AI 108 Units Faulted (Units faulted in the cascade).

How do I enable BMS control of the AERCO Benchmark E / Edge X?

On the controller go to Settings > Advanced Setup > Comm & Failsafe and enable BAS; for IP turn on the "BAS (J6)" toggle, which actually uses the J5 jack. The object list has no separate start/stop object: the BAS controls the unit through AV 12 Operating Mode, AV 13 Remote Signal (0 = BAS) and the setpoint in AV 4, or AV 200 on a BST manager. Firing-rate control (Direct Drive) is listed only for legacy BMK units.

Does the AERCO Benchmark E / Edge X need a BACnet heartbeat or have a communication timeout?

The BAS Comm Failsafe setting chooses whether the unit shuts down or runs at a constant setpoint when it loses the BAS (AV 24 Unit Failsafe Mode: 0 = Standby, 1 = Constant Setpt). The BACnet IP screen also has a delay-before-communication-fault setting; its range and default are not given.

Can the BMS supply sensor values to the AERCO Benchmark E / Edge X?

AV 85 / AV 213 Supply Header Temp Source and AV 215 return header source can be set to BAS (2), but the object list has no writable header or outdoor temperature value. On BMK E the outdoor sensor source (AV 81 / AV 217) is listed as Direct only.
