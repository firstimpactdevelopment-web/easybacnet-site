Short answer

With the SSD (Slave/Slave Device) profile the AERCO ProtoNode RER sits on the BST or WHM Modbus network at fixed address 247 and serves the master's operating values and a 20-value block for each of up to 8 units on BACnet IP or BACnet MS/TP. The BMS changes the plant setpoint and setback values by writing them and then writing 1 to a send command. This file lists the master points and unit 1.

BMS integration notes: AERCO C-More boilers / water heaters with BST or WHM (ProtoNode RER SSD)

Integration in brief

Select the SSD BACnet profile on the ProtoNode (S1 and A3 On, all other S and A1 Off); the gateway then talks to the BST/WHM master at address 247. To change the plant setpoint write AV 200 (and setback values AV 201-203 if used), then write 1 to AV 51 to send them. Read plant values from AV 100-119 and each unit's block from AV 300 onwards.

Enable & remote start

No start/stop object. Write the new setpoint (AV 200) and, if used, setback setpoint and times (AV 201-203), then write 1 to AV 51 Write Cntrl Val to BST/WHM to pass them to the master.

Network setup

  • SSD BACnet profile: S1 On and A3 On, S0/S2/S3 and A1 Off (SSD Modbus and SSD N2 profiles also exist).
  • Device instance = Node_Offset (set in the Web Configurator) + A-bank DIP value; MS/TP MAC is 1-127 on A0-A7, baud on B0-B3.
  • Default IP 192.168.1.24; change it in the ProtoNode web GUI.
  • Modbus side: every AERCO unit at 9600 baud, 8 data bits, 1 stop bit, no parity.
  • The gateway uses SSD address 247 on the BST/WHM Modbus network; units keep their own addresses.

Watch out for

  • Writes to AV 200-203 do nothing until 1 is written to AV 51.
  • AV 53 is read only despite sitting with the control values: 0 = WHM present, 1 = WHM absent.
  • Unit Type codes 6-8 (water heaters) apply to WHM only; BST uses 1-5.

Integration notes

  • Older document (OMM-0080_0H, November 2014) for the ProtoNode RER gateway.
  • Unit blocks: unit n (1-8) uses AV 200 + 100 x n to AV 219 + 100 x n, so unit 1 = AV 300-319 and unit 8 = AV 1000-1019; only unit 1 is listed here.
  • Run cycles = upper x 65536 + lower; run hours the same.
  • Setback times are minutes after midnight (360 = 6 AM).
  • The SSD keeps fixed Modbus address 247 so communication resumes after a BST/WHM master failover without BAS changes.
  • The manual's point name for AV 313 is spelled Value State; the definition table calls it Valve State.

Which AERCO C-More boilers / water heaters with BST or WHM (ProtoNode RER SSD) BACnet points are writable?
