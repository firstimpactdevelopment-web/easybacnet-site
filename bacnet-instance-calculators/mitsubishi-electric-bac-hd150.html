The BAC-HD150 BM Adapter numbers every CITY MULTI group's objects as M-NET number, group number and point number. Enter the M-NET number and group to get that group's instances.

Short answer

BAC-HD150 instances are six digits MM GG PP: M-NET number (01-03), group number (01-50) and point number. Leading zeros drop off the real number, so M-NET 1, group 12, Set Temp (point 10) is AV 11210, and M-NET 2, group 3, On Off Setup is BO 20301.

    Questions

    How do I work out a Mitsubishi Electric instance number?

    BAC-HD150 instances are six digits MM GG PP: M-NET number (01-03), group number (01-50) and point number. Leading zeros drop off the real number, so M-NET 1, group 12, Set Temp (point 10) is AV 11210, and M-NET 2, group 3, On Off Setup is BO 20301.

    Why is the instance five digits, not six?

    MMGGPP starts with a zero for M-NET 01 (010101), and BACnet stores numbers, so it shows as 10101. M-NET 02 and 03 give 2xxxx and 3xxxx.

    Which setpoint object should I use?

    Single-setpoint groups use Set Temp (point 10). Dual-setpoint groups use Set Temp Cool/Heat (24/25), which only work with Old Model Compatibility Mode turned off.

    Is this Mitsubishi Electric calculator official?

    No. It applies the formula printed in Mitsubishi Electric's own documentation to the points list in our library. Confirm the numbers against a scan of the live device before you map or write anything.
