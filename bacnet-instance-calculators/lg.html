    Questions

    How do I work out a LG instance number?

    On LG's ACP BACnet and AC Smart BACnet, instance = product type x 65536 + unit address x 256 + point, and the address is read as hex. Indoor units are type 0, so unit 1A (= 26) has on/off BO 6657, mode MO 6663, fan speed MO 6667 and setpoint AV 6669. Ventilation units add 65536, outdoor units 196608.

    Why is LG unit 1A's on/off 6657 and not 1A01?

    It is the same number: 0x1A01 in hex is 6657 in decimal. LG puts the hex unit address in the middle byte, so address x 256 + point gives the decimal instance your BMS shows.

    Does AC Smart use the same numbers as the ACP?

    Yes. LG's AC Smart BACnet manual prints the same formula and the same indoor, ERV and outdoor tables. AC Smart 5 adds points 50 and up; BNU-BAC has a shorter list but the same numbers for the points it has.

    Is this LG calculator official?

    No. It applies the formula printed in LG's own documentation to the points list in our library. Confirm the numbers against a scan of the live device before you map or write anything.
