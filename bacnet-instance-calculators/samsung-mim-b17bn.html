Samsung MIM-B17BN BACnet Device ID Calculator

Free browser tool · nothing is uploaded · 5 November 2026

Samsung's DMS2.5 BACnet gateway makes every unit its own BACnet device and builds the device ID from the network number and the unit address. Enter them to get the device ID, or decode one.

Short answer

The device ID is three parts written one after the other: DNET | CPP | XX. DNET is the gateway's network number (1-40), CPP = 400 + 16 x a + b for unit address a.b.c, and XX is the indoor address c (00-63) or 64 for an outdoor unit. Samsung's example: network 9, indoor unit 01.01.32 gives 9 | 417 | 32 = 941732.

    PartMeaningRange

    Samsung shows unit addresses as a.b.c, for example 01.01.32: OnOff controller, interface module (outdoor unit), indoor unit. Each gateway on the same network needs its own Network No. Inside every unit device the object instances are small fixed numbers, listed under each unit type below.

    Questions

    How do I work out a Samsung instance number?

    The device ID is three parts written one after the other: DNET | CPP | XX. DNET is the gateway's network number (1-40), CPP = 400 + 16 x a + b for unit address a.b.c, and XX is the indoor address c (00-63) or 64 for an outdoor unit. Samsung's example: network 9, indoor unit 01.01.32 gives 9 | 417 | 32 = 941732.

    Is the Samsung device ID a sum or the digits put together?

    The digits put together: network number, then the 3-digit CPP code, then the 2-digit address. 9, 417 and 32 make 941732. As arithmetic that is DNET x 100000 + CPP x 100 + XX.

    What device ID does an outdoor unit get?

    The same DNET and CPP as the indoor units behind it, with 64 as the last two digits. Network 9, outdoor unit 01.01 works out to 941764 (our worked example from Samsung's table, not printed in the manual).

    Are the address parts hex or decimal?

    Samsung's manual does not say. Its only example (01.01.32) reads the same either way. If your DMS shows letters in an address, confirm the device ID with a scan.

    Is this Samsung calculator official?

    No. It applies the formula printed in Samsung's own documentation to the points list in our library. Confirm the numbers against a scan of the live device before you map or write anything.
