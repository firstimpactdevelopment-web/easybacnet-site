The Systemair SYS GW IMS BAC(A) (IMMP-BAC in the manual) makes every SYSVRF indoor and outdoor unit its own BACnet device, numbered from the network number, port and unit address.

Short answer

Indoor unit device instance = network number x 10000 + port x 1000 + indoor address; outdoor units add 100 to the address. Network 5, port 2, indoor unit 14 is 52014; outdoor unit 0 on that port is 52100.

Which unit is this device?

    How the numbers are built

    device = network x 10000 + port x 1000 + address (outdoor + 100)

    PartMeaningRange
    networkBACnet network number set on the gateway's web page2-254
    portRS-485 port (0 = the one next to the Ethernet jack)0-3
    addressIndoor unit address (outdoor: 100 + outdoor address)0-63 (OU 0-31)

    Set a BACnet network number of 2-254 on the gateway's web page (each gateway needs a different one) and restart it. Port 0 is the RS-485 port next to the Ethernet port.

    Questions

    How do I work out a Systemair instance number?

    Indoor unit device instance = network number x 10000 + port x 1000 + indoor address; outdoor units add 100 to the address. Network 5, port 2, indoor unit 14 is 52014; outdoor unit 0 on that port is 52100.

    What do the Systemair error code numbers mean?

    0 is no error; then blocks of 20 per letter (1-20 = A0-AU, 21-40 = b, 41-60 = C and so on). The unit's service manual gives the meaning of each code.

    Is this Systemair calculator official?

    No. It applies the formula printed in Systemair's own documentation to the points list in our library. Confirm the numbers against a scan of the live device before you map or write anything.
