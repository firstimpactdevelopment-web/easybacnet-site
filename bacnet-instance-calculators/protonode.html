ProtoNode BACnet Device Instance Calculator (Boilers)

Free browser tool · nothing is uploaded · 5 November 2026

Boiler makers use FieldServer ProtoNode gateways to put Modbus boilers on BACnet. Every boiler becomes its own BACnet device numbered Node_Offset + Node-ID, and every one carries the same objects.

Short answer

Device instance = Node_Offset + Node-ID. Node_Offset is 50000 unless someone changed it in the ProtoNode Web Configurator, and the Node-ID is the boiler's Modbus address (on AERCO, the A-bank DIP switch value). Node-ID 3 is device 50003.

    Questions

    How do I work out a ProtoNode instance number?

    Device instance = Node_Offset + Node-ID. Node_Offset is 50000 unless someone changed it in the ProtoNode Web Configurator, and the Node-ID is the boiler's Modbus address (on AERCO, the A-bank DIP switch value). Node-ID 3 is device 50003.

    Why does every boiler have the same object numbers?

    The ProtoNode makes one BACnet device per boiler from the same profile, so the objects repeat and only the device instance changes. Point your BMS at the right device instance and the objects line up.

    Hamilton's BDB-CDB shows up at 50032. Why?

    Its ProtoNode profile uses Node-ID 32, so the default device is 50000 + 32.

    Is this ProtoNode calculator official?

    No. It applies the formula printed in ProtoNode's own documentation to the points list in our library. Confirm the numbers against a scan of the live device before you map or write anything.
