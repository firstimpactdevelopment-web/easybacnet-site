Carrier's Open controllers ship with a default device instance built from 16101 and the two-digit rotary switch (MAC) address. Enter the address to get it.

Short answer

Default device instance = 16101 followed by the 2-digit rotary address, i.e. 1610100 + address. Address 23 gives 1610123; address 5 gives 1610105. The object instances inside are the same on every controller of that type.

Which unit is this device?

    How the numbers are built

    device instance = 1610100 + rotary address

    PartMeaningRange
    16101Fixed prefix in Carrier's default (16 is Carrier's BACnet vendor ID)16101
    addressRotary switch (MS/TP MAC) address, two digits00-99

    The address is set on the controller's two rotary switches (tens and ones). This is the factory default; if the device instance was changed in the controller's setup, read it from a scan.

    Questions

    How do I work out a Carrier instance number?

    Default device instance = 16101 followed by the 2-digit rotary address, i.e. 1610100 + address. Address 23 gives 1610123; address 5 gives 1610105. The object instances inside are the same on every controller of that type.

    Why is my Carrier controller's device instance 16101xx?

    Carrier's default joins 16101 and the two-digit rotary address, so address 20 shows up as device 1610120. Change the rotary address and the default device instance changes with it.

    Is this Carrier calculator official?

    No. It applies the formula printed in Carrier's own documentation to the points list in our library. Confirm the numbers against a scan of the live device before you map or write anything.
