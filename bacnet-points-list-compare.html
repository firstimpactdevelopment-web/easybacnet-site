    How it compares

    Objects are matched by object type and instance number, the way a BMS finds them. A match with a different name usually means the integrator or the manufacturer renamed the point; the object is the same. Objects in the list but not on the device are normally options the unit does not have or a different firmware.

    Gateways that number objects by unit address (VRF gateways, boiler cascades) print only one unit in their list. For those, the tool says so and links the matching instance calculator.

    Getting a scan file

    Easy BACnet scans the network from an Android phone, reads every object on each device and exports the result to Excel; that file drops straight in here. Exports from other tools work too if they have an object type column and an instance column (EDE files from most BACnet tools do).
