# easybacnet.com — SEO audit (2026-09-25)

Scope: `build_site.py` (39 guides + decoder tool + index) and the generated HTML in this folder, plus live checks against https://easybacnet.com (robots, sitemap, home, guides, redirects, 404, OG image). Read-only audit; nothing was changed by it.

**Verdict.** The technical foundation is clean: no duplicate titles/descriptions, one H1 per page, self-referencing absolute clean-URL canonicals on all 44 indexable pages, valid JSON-LD everywhere, robots/sitemap correct, `.html` → clean 308, www → apex 301, http → https 301, custom noindexed 404. The real problems are (1) a quarter of the content is not deployed, (2) the "free Android app" cannot be obtained from the site, and (3) freshness signals are uniform and partly false. Everything else is polish.

## Confirmed issues

### 1. HIGH — 11 finished guides are not live
Local build has 44 sitemap URLs; the live sitemap has 33. Untracked locally: `what-is-bacnet`, `bacnet-glossary`, `how-to-release-a-bacnet-override`, `is-it-safe-to-write-to-bacnet`, `how-to-build-a-control-panel`, `bacnet-status-flags-explained`, `bacnet-engineering-units-explained`, `bacnet-multistate-values-explained`, `duplicate-bacnet-device-id`, `bacnet-add-device-by-ip`, `bacnet-add-object-by-number`. Live probes of three of them return 404. Last site commit is `4b0d575` (2026-09-21). Once pushed, 28 regenerated guides will link to these pages; pushing only part of the tree would create internal 404s.
Fix: commit + push the whole `site/` working tree, then `python build_site.py --ping`; request indexing in GSC for `what-is-bacnet` and `best-free-bacnet-explorer`. (The Control Panel guide mentions the PC app — a content decision, not a technical one.)

### 2. HIGH — No Google Play / install link anywhere
Zero occurrences of `play.google` in the source or output. The home page hero has no CTA; the guide footer says "a free Android app" with no link; `SoftwareApplication` has no `installUrl`/`downloadUrl`. Partly blocked on the Play listing being Draft, but the site is a dead end for every visitor today.
Fix: primary CTA under `.lede` in `INDEX`, repeat in the guide-template footer (build_site.py ~L296–302), add `installUrl`/`downloadUrl` (~L3813). Until the listing is live, an explicit "Coming to Google Play" line.

### 3. MEDIUM — Freshness signals are uniform and partly false
`UPDATED = "2026-09-21"` (L36) is written as `datePublished` AND `dateModified` on every page, as every sitemap `lastmod`, and as the visible "Updated" line. All 44 URLs carry the identical date; new guides claim a publish date before they were written; every rebuild rewrites `datePublished` site-wide. Google ignores `lastmod` that is not consistently accurate.
Fix: per-guide `published=`/`updated=` fields in each `GUIDES` entry, used in `page()` (~L217–241) and `main()` (~L4013–4023); keep the global constant as fallback only.

### 4. MEDIUM — FAQPage is the wrong primary schema
Every guide is a single-question `FAQPage`. Google shows FAQ rich results only for authoritative government/health sites since 2023; the node lacks `@id`, `mainEntityOfPage`, `author`, `publisher`, `headline`, `image`; `Answer.text`/`Question.name` contain raw HTML entities because `strip_tags()` (L318) does not unescape.
Fix: emit `TechArticle` (or `Article`) as the main node with headline/description/dates/author/publisher → `#org`, `mainEntityOfPage`, `image`; keep `BreadcrumbList`; `html.unescape()` before `jstr()`.

### 5. MEDIUM — Organization/WebSite schema is home-only and thin
`Organization.logo` points to an SVG (Google wants a raster ≥112×112); no `sameAs` (Play listing, GitHub org, easymodbus.com), no `contactPoint`/email; guides never reference `#org`. `SoftwareApplication` lacks `@id`, `softwareVersion`, `screenshot`, `featureList`.
Fix: a shared `ORG_JSONLD` constant included in `page()` and `tool_page()`; raster logo; `sameAs`; enrich `SoftwareApplication`.

### 6. MEDIUM — 20 of 44 meta descriptions over 155 chars; one title at 88 chars
Mostly the 11 undeployed guides (e.g. `how-to-build-a-control-panel` D244/T88, `what-is-bacnet` D197, `how-to-release-a-bacnet-override` D190).
Fix: trim `description=`/`title=` in the affected `GUIDES` entries; add a build-time assert (title ≤60, description ≤160) in `main()` so it cannot regress.

### 7. LOW — Images without width/height (CLS), unoptimised PNGs, hero not prioritised
`screenshot_block()` (L195) emits `<img loading="lazy">` with no dimensions; screenshots are 480×1068 PNG up to 225 KB. Home hero has no `fetchpriority="high"`.
Fix: `width="480" height="1068"`, WebP, `fetchpriority` on the hero.

### 8. LOW — Render-blocking Google Fonts: 3 families / 9 weights on every page
Archivo 600 and Manrope 500 appear unused in the CSS. Fix: prune weights or self-host two woff2 files with preload.

### 9. LOW — SVG-only favicon at a relative path
No PNG/ICO fallback, no `apple-touch-icon`. Fix: absolute `/icon.svg` plus `/favicon-48.png` and `/apple-touch-icon.png` in all three templates.

### 10. LOW — Legal pages use the old light design and are near-orphans
`privacy-desktop.html` and `terms.html` have one inbound link each. Fix: `noindex` them or add them to the shared footer.

Checked and correct: robots.txt; sitemap URL form; canonicals (44/44); no accidental noindex; single H1; heading hierarchy; viewport; redirects; custom 404; OG image 1200×630; GSC verification tags; IndexNow key live and `--ping` wired; llms.txt complete; no near-duplicate guides (<12% shingle overlap); every guide one click from the index with a Related section; average guide 676 words.

## Opportunities

- **A. Internal link equity is lopsided.** `bacnet-priority-and-stuck-overrides` and `why-cant-i-find-my-bacnet-devices` have 18 inbound links each; `best-free-bacnet-explorer` (the highest-commercial-intent page) has 1, `what-is-bacnet` 2, `bacnet-glossary` 2. Add them to more `related=` lists and to a persistent footer link row.
- **B. Search-phrase alignment.** "bacnet scanner", "bacnet browser", "bacnet app", "find bacnet devices", "bacnet gateway", "bacnet test tool" appear in no body copy. One literal sentence per relevant guide fixes it.
- **C. The comparison page has no outbound links** to YABE, CAS, Contemporary Controls or Chipkin despite naming them repeatedly. Linking them is a trust signal and makes the page citable (and the natural seed for a "YABE alternative" listing).
- **D. Standards citations.** ASHRAE 135 / ISO 16484-5 appear only as plain text in two guides; no link to ashrae.org or bacnet.org anywhere.
- **E. No author/about page.** Zero E-E-A-T signals outside the legal pages' mailto. A short `/about` referenced as `author`/`publisher` is the standard fix.
- **F. Home page H1** contains neither "app" nor "Android"; the `<title>` (52 chars) has room for "Android app".
- **G. Cross-site link.** Only one guide links to easymodbus.com; a footer "Also by us: Easy Modbus" on both sites is the cheapest backlink available.
- **H. hreflang** is N/A today; the template should grow `lang`/`alternates` parameters before any guide is translated.
