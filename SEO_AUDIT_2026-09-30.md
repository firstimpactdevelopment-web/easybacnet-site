# easybacnet.com — SEO audit (2026-09-30)

Scope: `build_site.py` and every generated page in `site/` (45 HTML files: index, 39 guides,
1 tool, privacy, privacy-desktop, terms, 404), plus `sitemap.xml`, `robots.txt`, `llms.txt`.
Follows up `SEO_AUDIT_2026-09-25.md`. Checks were run with a Python checker (stdlib
`html.parser` + `json.loads`) that resolves internal links the way Cloudflare Pages serves them
(`/x` -> `x.html`, `/` -> `index.html`, `#anchor` must exist on the target page).

## Fixed in this pass (all in `build_site.py`, then rebuilt)

1. **18 meta descriptions trimmed** to 110-155 chars (10 were 165-197 chars, 8 were 156-160).
2. **Build-time length guard** — `check_lengths()` runs at the start of `main()` and prints a
   WARNING for any guide/tool title > 60 or description outside 110-160 chars.
3. **Control-panel guide title** was 88 chars and mentioned the PC app; now
   "Build a multi-device BACnet control panel | Easy BACnet" (55).
4. **JSON-LD text cleaned** — Question/Answer strings are now HTML-unescaped (no raw `&mdash;`
   / `&rsquo;` in structured data) and `<` is emitted as `<` so decoded text can never
   close the `<script>` block. FAQPage pattern kept.
5. **Tool page** gained `twitter:title`, `twitter:description`, `twitter:image`.
6. **Layout shift** — every screenshot `<img>` (guides + home) now carries `width="480"
   height="1068"`; the home hero image has `fetchpriority="high"`.
7. **Legal pages no longer near-orphans** — guide footer now links *All guides* (`/#guides`),
   *Terms of use* and *Privacy policy*; home footer links Terms, Privacy and the contact email;
   the home Guides section has `id="guides"`.
8. **Internal links** — home "Using the app" list adds the control-panel, export and
   add-by-IP/BBMD guides; the scanner-app guide now links `best-free-bacnet-explorer` and
   `what-is-bacnet` (the two weakest-linked pages in the 09-25 audit).
9. **Content accuracy that also affects search snippets** — "CSV" replaced by the app's real
   export format (Excel `.xlsx`) in the footer, home meta/OG/Twitter descriptions,
   SoftwareApplication description and llms.txt. The `export-bacnet-points-to-csv` slug is
   **kept** (no redirect needed, no lost URL) and retitled "Export BACnet IP points to Excel or
   CSV".
10. **privacy.html** (hand-written) — new description (148 chars), twitter title/description,
    and footer link to Terms.

## Remaining (not fixed here)

- **HIGH — still not deployed.** Live `sitemap.xml` has 33 URLs vs 44 locally; the live privacy
  page is still the 16 Sep version. Commit + push the whole `site/` tree (pushing part of it
  would create internal 404s), then `python build_site.py --ping` and request indexing in GSC.
- **HIGH — no Google Play link / install CTA** anywhere on the site, and no
  `installUrl`/`downloadUrl` in `SoftwareApplication`. Needs the live Play listing URL.
- **MEDIUM — terms.html mentions the desktop app** ("Easy BACnet Explorer (mobile and
  desktop)") in its meta/OG description and body, and links privacy-desktop. That conflicts
  with "don't mention the PC version on the site", but it is a legal document — left unchanged
  for the owner to decide. Its description is also 108 chars and it lacks twitter title/desc.
- **MEDIUM — uniform freshness dates.** Every page shares one `UPDATED` date for
  `datePublished`, `dateModified`, sitemap `lastmod` and the visible line. Accurate today (every
  page's footer changed), but per-guide `published`/`updated` fields would be a better signal
  going forward.
- **MEDIUM — Organization schema** is home-only, logo is SVG (Google prefers raster >= 112 px),
  no `sameAs`. Guides don't reference `#org`.
- **LOW — screenshots**: PNG up to 225 KB (WebP would roughly halve them). `picker.png` likely
  still shows three mode cards; the app now has four (Control Panel Builder) — re-shoot when
  convenient. No screenshots of the export share sheet, Add device by IP or BBMD dialogs.
- **LOW — Google Fonts**: three families / nine weights, render-blocking.
- **LOW — favicon**: SVG only, relative path on guide pages (works because `guides/icon.svg`
  exists); no PNG/apple-touch-icon fallback.
- Opportunities from the 09-25 audit (about page/E-E-A-T, outbound standards citations,
  "YABE alternative" positioning, gap pages such as "BACnet router vs gateway") still stand.
